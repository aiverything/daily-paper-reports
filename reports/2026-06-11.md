## 1. ASR (Automatic Speech Recognition)

### **Phoneme-First Prediction for LLM-Based Speech Recognition (Jakob Poncelet, Hugo Van hamme — KU Leuven, 2026-06-09)** — arxiv preprint
- https://arxiv.org/abs/2606.10864
- **기존 문제:** LLM에 음성 인코더를 결합한 Speech-augmented LLM 기반 ASR에서, LLM의 시맨틱 임베딩과 음성 인코더의 음향 표현 간 정렬(alignment)이 핵심 난제. 특히 저자원 환경에서 음향적 혼동(acoustic confusion)으로 인한 전사 오류가 빈번.
- **기존 방법:** 음성 인코더의 출력을 프로젝터를 통해 LLM 입력 공간에 매핑하고, LLM이 직접 텍스트 전사를 생성하는 end-to-end 구조가 주류. 중간 표현의 음운적 구조를 명시적으로 학습하지 않아, LLM이 발음-철자 대응 관계를 충분히 획득하지 못함.
- **제안 방법:** LLM이 최종 전사를 생성하기 전에 음성 특징으로부터 음소(phoneme)를 먼저 예측하도록 학습. 음소 타겟은 기존 전사로부터 자동으로 도출되므로 추가 레이블링 비용이 없음. 중간 음소 예측 단계를 LLM 내부에 직접 통합.
- **핵심 차별점:** 음소 예측을 통해 LLM이 발음에 대한 세밀한 지식을 습득하여, 음향적 혼동을 줄이고 전사 정확도와 설명가능성(explainability)을 동시에 향상. 구현이 간단하고 비용이 낮은 실용적 접근.
- **실험 결과:** 종합 실험에서 중간 음소 예측이 음성 인식 성능을 개선함을 확인. 특히 저자원 환경에서 두드러진 향상. 출력이 음성에 대해 음향적으로 더 충실(acoustically faithful)한 결과를 생성.
- **우리 연구 관련도:** ★☆☆ — LLM 기반 ASR의 학습 전략 연구로, speech SSL과 직접 관련은 낮으나, 음소 수준의 중간 표현 학습이 speech representation의 음운 정보 포착 전략에 간접적 참고점 제공.

### **Entropy-Aware Domain-Routed Mixture-of-Experts Speech-LLM Framework: A Case Study of Multi-Domain Child-Adult ASR (Mohan Shi, Kaiyuan Zhang et al. — UCLA, 2026-06-09)** — arxiv preprint
- https://arxiv.org/abs/2606.10454
- **기존 문제:** Speech LLM이 성인 ASR에서 강력한 성능을 달성했으나, 아동 음성에 대한 효과는 미탐구. 단일 모델이 다양한 환경과 연령대에 걸친 성인-아동 음성을 동시에 처리하기 어려우며, 도메인 간 음향 특성 차이(피치, 발화 속도, 발음 패턴 등)가 성능 저하를 유발.
- **기존 방법:** 성인 음성에 최적화된 단일 Speech-LLM을 아동 음성에 직접 적용하거나, 도메인별 개별 모델을 별도 학습하는 방식. 도메인 간 지식 공유와 전문화를 동시에 달성하는 통합 프레임워크가 부재.
- **제안 방법:** MoE 기반 Speech-LLM 프레임워크 — Classifier-based Domain Router(C-DR)가 coarse-to-fine 전략으로 도메인을 분류하고, Mixture-of-Projectors(MoP)와 Mixture-of-LoRAs(MoL)가 도메인별 특화 처리를 수행. Entropy-Aware Routing(EAR) 메커니즘이 라우팅 불확실성이 높은 도메인 경계 영역에서 공유 전문가(shared expert)를 동적으로 활성화.
- **핵심 차별점:** 도메인 라우팅의 엔트로피 기반 불확실성을 명시적으로 모델링하여, 도메인 경계에서의 라우팅 오류를 공유 전문가로 보완하는 최초의 접근. MoP와 MoL의 이중 MoE 구조로 프로젝터와 LLM 적응을 동시에 전문화.
- **실험 결과:** 공개 아동 음성 코퍼스에서 베이스라인 대비 일관된 성능 향상 달성. 성인 ASR 성능을 유지하면서 아동 음성 인식 개선.
- **우리 연구 관련도:** ★★☆ — 도메인 라우팅에서의 엔트로피 기반 불확실성 모델링이 speech representation learning에서의 도메인 적응 전략에 방법론적 참고 가능. MoE 구조의 전문가 라우팅이 VQ-based representation의 코드북 활용 전략과 개념적으로 연결.

### **Contrastive Training with LLM-generated Near-Misses for Robust Code-Switching Speech Recognition (Tung X. Nguyen, Hieu Minh Truong, Giang-Son Nguyen, Nhu Vo, Wray Buntine, Dung D. Le — VinUniversity / UTS / Monash University, 2026-06-05)** — Interspeech 2026 Long Paper accepted
- https://arxiv.org/abs/2606.06985
- **기존 문제:** 코드스위칭(CS) 음성 인식에서 언어 전환 지점(code-switching point)의 인식 오류가 빈번. 다국어 CS 음성 데이터의 극심한 부족으로 인해 모델이 CS 임계 영역(CS-critical regions)에서 강건하지 못함.
- **기존 방법:** Whisper 등 다국어 ASR 모델을 LoRA로 파인튜닝하는 방식이 주류이나, CS 특화 학습 신호가 부재하여 언어 전환 지점에서의 음향적 혼동이 해소되지 않음. 기존 데이터 증강은 음향적 그럴듯함(acoustic plausibility)이 부족.
- **제안 방법:** Point-of-Interest(POI) 인식 대조 학습 프레임워크 — CS 스팬을 POI 검출로 식별하고, ASR N-best 출력에서 POI를 교란하여 음향적으로 그럴듯한 near-miss 가설을 생성. LLM으로 후보를 확장한 뒤 음향·음소·텍스트 제약 필터링으로 경성(hard) 부정 예를 선별. POI 가중 교차 엔트로피와 다중 부정 대조 랭킹 손실로 Whisper-small을 LoRA 파인튜닝.
- **핵심 차별점:** LLM 생성 near-miss를 대조 학습의 경성 부정 예로 활용하여, CS 임계 영역에 특화된 세밀한 구별 능력을 학습. POI 가중치로 CS 전환 지점에 학습 신호를 집중.
- **실험 결과:** CS-FLEURS(cmn-eng)와 ViMedCSS(vie-eng) 데이터셋에서 표준 LoRA 파인튜닝 대비 일반 오류율 및 CS 인식 오류율 모두 2% 이상의 일관된 감소 달성.
- **우리 연구 관련도:** ★★☆ — 대조 학습에서 LLM 생성 near-miss를 경성 부정 예로 활용하는 전략이 temporal contrastive learning에서의 부정 예 설계에 직접적 방법론적 시사점 제공. POI 기반 가중 학습이 표현 학습에서의 중요 영역 집중 전략에 참고 가능.

## 2. SpeechLLM (Speech Language Model)

### **LLM can Read Spectrogram: Encoder-free Speech-Language Modeling (Ruchao Fan, Yiming Wang, Yuxuan Hu, Bo Ren, Yufei Xia, Xiaofei Wang, Yao Qian, Jinyu Li — Microsoft, 2026-06-08)** — arxiv preprint
- https://arxiv.org/abs/2606.10231
- **기존 문제:** 기존 Speech-LLM은 사전학습된 음성 인코더(Whisper, HuBERT 등)에 의존하여 음성 특징을 추출한 뒤 LLM에 입력하는 구조. 이 인코더-의존 패러다임은 인코더의 사전학습 편향에 제약되며, 인코더-LLM 간 정렬 학습이 추가로 필요하여 아키텍처 복잡성 증가.
- **기존 방법:** Whisper 인코더 + 프로젝터 + LLM 구조가 표준. 인코더는 대규모 음성 데이터로 별도 사전학습되며, LLM과의 정렬을 위해 다단계 학습(adapter tuning, projector learning 등)이 필요. 인코더 없는(encoder-free) 접근은 성능 격차로 인해 실용적이지 않다고 간주.
- **제안 방법:** Mel-LLM — 사전학습된 음성 인코더 없이, 경량 전처리된 Mel 스펙트로그램 패치를 선형 프로젝션을 통해 LLM에 직접 입력. LLM 자체 파라미터만으로 음성-텍스트 정렬을 학습. 데이터 스케일링을 통해 인코더 초기화 모델과의 성능 격차를 좁힘.
- **핵심 차별점:** 전용 음성 인코더를 완전히 제거하고 LLM이 원시 스펙트로그램을 직접 읽는 최초의 실용적 실증. 데이터 스케일링이 인코더 초기화와 인코더 프리 모델 간의 격차를 해소함을 보여, 인코더 없는 패러다임의 실현 가능성을 입증.
- **실험 결과:** ASR과 TTS 양쪽에서 평가. OpenASR 리더보드 공개 셋에서 인코더 초기화 대비 제한적 성능 저하만으로 경쟁적 성능 달성. 프로덕션 수준 스케일링 실험에서도 인코더 프리 솔루션의 유효성 확인.
- **우리 연구 관련도:** ★★☆ — 사전학습 인코더 없이 LLM이 직접 음향 표현을 학습하는 접근이, speech SSL 인코더의 필요성과 역할에 대한 근본적 질문을 제기. 데이터 스케일링으로 인코더 사전학습을 대체할 수 있다는 발견이 speech representation learning 연구의 방향성에 시사점 제공.

### **Is Text All You Need? Text as a Universal Information Bottleneck for Speech LLMs (Ming-Hao Hsu, Yuxuan Hu, Shujie Liu, Jinyu Li, Yan Lu, Zhizheng Wu — Microsoft / CUHK-Shenzhen, 2026-06-08)** — arxiv preprint
- https://arxiv.org/abs/2606.09366
- **기존 문제:** 연속적 음향 신호를 동결된 LLM에 통합할 때, 기존 음성-LLM 인터페이스는 두 극단 사이에서 설계됨: (1) 근사적 이산 토큰 정렬을 강제하면 전사에는 유리하나 준언어적 정보 손실, (2) 비제약 연속 표현을 학습하면 LLM 입력 공간에서 이탈(drift)하여 자기회귀 디코딩이 저하.
- **기존 방법:** 어댑터/프로젝터 기반 연속 매핑, 이산 토큰 기반 입력, VQ 기반 이산화 등이 혼재. 음성 표현이 LLM 임베딩 공간 내에 위치해야 하는지, 또는 별도의 공간에서 학습되어야 하는지에 대한 체계적 분석이 부족.
- **제안 방법:** Convex Gate(C-Gate) — 아키텍처 수준의 볼록 껍질(convex-hull) 제약으로 모든 음성 표현이 LLM 입력 임베딩 매니폴드 내에 위치하도록 강제. 각 프레임을 토큰 임베딩들의 볼록 조합(convex combination)으로 표현하여, 사전학습된 LLM과의 호환성을 보장하면서 연속적 표현력을 보존.
- **핵심 차별점:** 정보는 이산 토큰 정체성이 아닌 임베딩 공간에서의 시간 해상 궤적(time-resolved trajectories)에 의해 전달된다는 핵심 통찰을 실증. 기하학(geometry)이 토큰 이산성보다 음성-LLM 인터페이스의 근본적 설계 요인임을 밝힘.
- **실험 결과:** 체크포인트, 샘플별 출력, 메커니즘 덤프, 개입 도구(intervention suite)를 모두 공개하여 재현성 보장. C-Gate가 기존 연속·이산 인터페이스 대비 우수한 성능을 달성하며, 궤적 기반 정보 전달 메커니즘을 실증적으로 확인.
- **우리 연구 관련도:** ★★★ — "정보는 이산 토큰이 아닌 임베딩 공간의 궤적에 있다"는 발견이 VQ-based representation 연구에 직접적 시사점. 볼록 조합 제약이 prediction-free SSL의 표현 공간 설계에 방법론적 참고. 연속 표현과 이산 토큰의 관계에 대한 체계적 분석이 speech tokenizer 연구에 핵심 인사이트 제공.

### **Liberating LLM Capabilities in Full-Duplex Speech Models (Luoyuan Zhang, Bokai Xu, Junbo Cui, Weiyue Sun, Yingjing Xu, Hanyu Liu, Yuan Yao, 2026-06-06)** — arxiv preprint
- https://arxiv.org/abs/2606.07547
- **기존 문제:** 음성 기반 LLM은 응답이 발화 가능한 내용으로 제한되어, 코드 생성, 구조화된 분석, 다단계 추론 등 텍스트 고유(text-native) 능력이 억제됨. 기존 연구는 음성 추론 개선이나 전이중 턴테이킹에 집중하되, 텍스트를 숨겨진 중간 상태나 부차적 모달리티로 취급.
- **기존 방법:** 기존 전이중 음성 모델은 음성 출력만을 최종 인터페이스로 사용하거나, 텍스트를 내부 사고 과정(hidden chain-of-thought)으로만 활용. 텍스트를 일급(first-class) 출력 채널로 활용하면서 동시에 음성 응답을 생성하는 통합 프레임워크가 부재.
- **제안 방법:** Listen-Write-Speak(LWS) — 텍스트 우선 삼중 채널(tri-channel) 패러다임. 단일 자기회귀 LLM이 (1) 사용자 오디오를 연속적으로 청취하고, (2) 가시적인 자유 형식 텍스트를 주요 출력으로 작성하며, (3) 공유 인과 어텐션 컨텍스트 하에서 실시간 음성 응답을 병렬 생성. Token Schema를 통해 구현되어 아키텍처 수정 불필요.
- **핵심 차별점:** 텍스트를 일급 출력 채널로 격상하여, 코드·표·구조적 분석 등 음성으로 전달 불가능한 LLM 능력을 전이중 실시간 대화에서 완전히 활용하는 최초의 패러다임. 아키텍처 변경 없이 Token Schema와 2단계 데이터 파이프라인만으로 구현.
- **실험 결과:** 실시간 전이중 상호작용에서 텍스트 출력(코드 생성, 구조적 분석 등)과 음성 응답을 동시에 생성하는 능력을 실증. 기존 음성 전용 모델 대비 LLM의 텍스트 고유 능력을 유지하면서 자연스러운 음성 대화를 달성.
- **우리 연구 관련도:** ★☆☆ — 전이중 대화 시스템의 출력 설계 연구로, speech SSL과 직접 관련은 낮으나, 다중 모달리티 출력을 공유 어텐션 컨텍스트에서 병렬 생성하는 설계가 멀티모달 표현 학습의 아키텍처 참고점 제공.

## 3. Speech Foundation Model

### **Gumbel-BEARD: Automatic Layer Selection for Self-Supervised Adaptation of Whisper in Low-Resource Domains (Zilai Wang, Natarajan Balaji Shankar, Mohan Shi, Kaiyuan Zhang, Abeer Alwan — UCLA, 2026-06-10)** — Interspeech 2026 accepted
- https://arxiv.org/abs/2606.11429
- **기존 문제:** 음성 파운데이션 모델(Whisper 등)은 저자원 도메인(아동 음성, 자발 발화 등)에서 도메인 불일치와 데이터 부족으로 성능이 급락. 기존 BEARD 방법은 BEST-RQ 자기지도학습 목적함수로 Whisper를 도메인 적응하지만, 최적 인코더 레이어 선택을 위해 모든 레이어를 순차적으로 탐색해야 하여 약 12 GPU-hour의 비용 발생.
- **기존 방법:** BEARD 프레임워크에서 BEST-RQ SSL 목적함수로 비전사 데이터를 활용한 인코더 적응 후 소량 전사 데이터로 파인튜닝. 그러나 목적함수의 예측 타겟 레이어를 수동으로 선택해야 하며, 완전 탐색(exhaustive search)이 필요하여 비효율적.
- **제안 방법:** Gumbel-BEARD — 경성 Gumbel-Softmax 선택기를 통해 Whisper 인코더 레이어 선택을 end-to-end로 자동화. BEST-RQ 자기지도 적응 과정에서 Gumbel-Softmax가 타겟 음향 특성에 최적인 레이어를 동적으로 선택하며, 수동 튜닝 없이 도메인 적응 수행.
- **핵심 차별점:** 레이어 선택의 자동화로 적응 비용을 약 12 GPU-hour에서 약 1 GPU-hour로 대폭 절감(~12배). 10시간 레이블 데이터만으로 파인튜닝 시 133시간 전체 지도학습 베이스라인에 필적하는 성능 달성.
- **실험 결과:** MyST 아동 음성 코퍼스에서 Whisper-medium 기반 WER 8.21% (SOTA), OGI Spontaneous 데이터셋에서 Whisper-small 기반 WER 11.06% (SOTA) 달성. 10시간 레이블 데이터로 133시간 지도학습 베이스라인 성능에 도달.
- **우리 연구 관련도:** ★★★ — BEST-RQ 기반 자기지도 적응에서의 레이어 자동 선택이 speech SSL의 레이어별 표현 특성 연구와 직접 연관. Gumbel-Softmax를 통한 미분 가능한 이산 선택이 VQ-based representation의 코드북 선택 메커니즘에 방법론적 시사점 제공. SSL 기반 도메인 적응의 효율성 향상이 prediction-free SSL의 실용화에 참고.

### **Which Speech Representation Better Matches Text-Native Reasoning? A Study of Speech-Text Alignment on Frame Rate and Representation (Zhen Ye, Xu Tan, Yiming Li et al. — HKUST / Tencent / University of Surrey / CUHK / HKBU / PolyU, 2026-06-11)** — arxiv preprint
- https://arxiv.org/abs/2606.12199
- **기존 문제:** 음성 대화 모델이 텍스트 LLM 백본에서 출발하지만, 음성 조건화 시 추론 능력이 저하되는 모달리티 격차(modality gap) 존재. 이 격차의 일부는 시간적 세분성 불일치(temporal-granularity mismatch)에 기인 — 음성 토큰은 시간적으로 중복적이고 텍스트 대비 훨씬 길어, 토큰당 시맨틱 밀도를 희석하고 텍스트 고유 추론 역학을 약화.
- **기존 방법:** 기존 연구는 프레임 레이트와 표현 유형을 독립적으로 탐구하거나, 고정된 설정에서 음성-LLM 정렬을 학습. 프레임 레이트, 표현 깊이, 정보율을 체계적으로 스윕하며 최적 영역을 탐색하는 연구가 부재.
- **제안 방법:** 음성 토큰 설계를 표현 선택 문제(representation selection problem)로 정식화. 동결된 LLM 백본에서 고정 정보율 하에 프레임 레이트를 체계적으로 스윕. 저프레임 레이트를 실현하기 위해 factorized FSQ(Finite Scalar Quantization)와 경량 비자기회귀 오디오 LM 헤드를 도입하여, 효율적 예측을 유지하면서 프레임당 약 300비트까지 용량 확장.
- **핵심 차별점:** 50→2.08 Hz 범위에서 프레임 레이트와 정렬 깊이를 체계적으로 스윕하여, 음성 QA에서 4.17 Hz + 중간 레이어 표현 정렬이 최적 영역임을 발견. factorized FSQ로 저프레임 레이트에서의 정보 병목을 해결.
- **실험 결과:** 음성 QA 태스크에서 프레임 레이트 4.17 Hz, 중간 레이어 표현 정렬이 일관되게 최적 성능을 달성. 고프레임 레이트(50 Hz)보다 저프레임 레이트(4.17 Hz)에서 LLM의 텍스트 고유 추론이 더 잘 보존됨을 실증.
- **우리 연구 관련도:** ★★★ — 프레임 레이트와 시맨틱 밀도의 관계 분석이 VQ-based representation의 temporal resolution 설계에 직접적 시사점 제공. factorized FSQ가 speech tokenizer의 양자화 전략에 방법론적 참고. 중간 레이어 표현이 최적이라는 발견이 speech SSL의 레이어별 표현 활용 연구에 핵심 인사이트.

### **A Comparative Study of Pre-trained Speech Encoders and Training Objectives for Large-Scale Indic Spoken Language Identification (Agneedh Basu, Pavan Kumar J, Sujith P, Visruth Sanka, Nihar Desai, Prasanta Kumar Ghosh — IISc Bangalore, 2026-06-08)** — arxiv preprint
- https://arxiv.org/abs/2606.09317
- **기존 문제:** 인도 언어의 음성 언어 식별(LID)은 42개 이상의 언어, 관련 변종 간 높은 음성적 유사성, 다수 저자원 언어의 레이블 데이터 부족으로 인해 난제. 사전학습된 음성 인코더의 LID 적용에서 인코더 유형과 학습 목적함수의 체계적 비교가 부족.
- **기존 방법:** 개별 사전학습 인코더(Whisper, wav2vec 2.0 등)를 특정 학습 목적함수(교차 엔트로피 등)와 결합하여 LID 태스크에 적용. 인코더 유형(지도학습 vs SSL), 학습 목적함수(CE, 대조학습, 계층적 소프트맥스), 동결 vs 파인튜닝의 체계적 교차 비교가 미흡.
- **제안 방법:** Whisper(지도학습)와 FastConformer(SSL 기반)를 선형 프로빙(동결) 및 파인튜닝 설정에서 체계적으로 비교. 세 가지 학습 목적함수 — 교차 엔트로피(CE), 지도 대조 학습 + 교차 엔트로피(CE + supCon), 계층적 소프트맥스(HSM) — 를 4개 언어 계통의 42개 인도 언어에 대해 평가.
- **핵심 차별점:** 대규모 인도 언어 LID에서 사전학습 인코더 유형과 학습 목적함수의 교차 분석을 최초로 수행. 교차 코퍼스 평가(Vaani → FLEURS, Kathbath)로 일반화 능력을 엄밀하게 검증.
- **실험 결과:** Vaani 데이터셋으로 학습 후 Vaani-Test(hold-out), FLEURS, Kathbath에서 교차 코퍼스 평가. 인코더 유형과 학습 목적함수 조합에 따른 체계적 성능 차이를 보고.
- **우리 연구 관련도:** ★★☆ — 사전학습 음성 인코더의 표현 품질을 다국어 LID로 평가하는 체계적 프레임워크가 speech SSL 표현의 언어 정보 포착 능력 분석에 참고. 지도 대조 학습(supCon) 목적함수가 contrastive learning 기반 표현 학습에 비교 기준 제공.
