## 1. ASR (Automatic Speech Recognition)

### **[Timestamped Hindi Speech Transcription using Whisper] (저자 미상, 2026-10-08)** — arxiv preprint
- https://arxiv.org/abs/2610.08847
- **기존 문제**: Whisper 기반 음성 전사에서 정밀한 단어 수준 타임스탬프를 얻으려면 WhisperX처럼 외부 CTC 모델(wav2vec2 등)을 별도로 로딩해야 하며, 이는 파이프라인 복잡도와 계산 비용을 증가시킨다.
- **기존 방법**: WhisperX는 외부 음소 인식 CTC 모델의 정렬 출력을 활용하여 단어별 타임스탬프를 생성. 두 개의 모델을 동시에 로딩해야 하는 부담이 있으며, cross-attention 기반 정렬은 시간 해상도가 제한적이다.
- **제안 방법**: Whisper 인코더 출력 위에 경량 CTC head를 직접 학습시켜 외부 CTC 모델 없이도 단어 수준 타임스탬프를 추출. WhisperX의 이중 모델 구조를 단일 모델로 통합한다.
- **핵심 차별점**: 외부 모델 의존성을 제거하면서도 동등한 타임스탬프 정확도를 달성. 파이프라인 단순화 및 추론 비용 절감.
- **실험 결과**: 외부 CTC 모델과 비교하여 동등 수준(comparable)의 타임스탬프 정확도 달성. 디코더 파인튜닝이 새 데이터셋 적응에 중요함을 확인.
- **우리 연구 관련도**: ★☆☆ — CTC head를 활용한 정렬 학습은 temporal alignment 관점에서 참고할 만하나, 음성 표현 학습의 핵심 방법론과는 직접적 관련이 적음.

## 2. SpeechLLM (Speech Language Model / Voice Agent)

### **[DiffuPlex: Accelerating Full-Duplex Spoken Dialog Models via Rolling Masked Diffusion] (Heeseung Kim, 2026-10-08)** — arxiv preprint (under review)
- https://arxiv.org/abs/2610.12214
- **기존 문제**: Full-duplex 음성 대화 모델은 매 인터랙션 프레임(~80ms)마다 backbone을 자기회귀적으로 한 스텝씩 전진시켜야 하며, 이로 인해 추론 속도가 실시간 대화의 병목이 된다.
- **기존 방법**: Moshi, LSLM 등 기존 full-duplex 모델은 프레임 단위 자기회귀(autoregressive) 디코딩을 사용. 매 80ms 간격마다 backbone forward pass가 필수적이며, 이를 가속하는 시도는 거의 없었다.
- **제안 방법**: Rolling Masked Diffusion을 활용하여 한 번의 backbone pass로 여러 미래 프레임(사용자+어시스턴트)을 동시에 예측. 예측의 confident prefix만 사용하고, 사용자의 실제 입력이 예측과 다를 경우 이미 재생된 오디오는 유지하면서 미재생 부분만 수정하는 divergence handling 메커니즘을 도입.
- **핵심 차별점**: 두 가지 추론 정책 제공 — (1) DiffuPlex-Listen: 어시스턴트 침묵 예측 시 다수 프레임 소비, (2) DiffuPlex-Speak: 어시스턴트 발화 예측까지 소비 가능. 모든 backbone 호출이 80ms 인터랙션 인터벌 내에서 완료.
- **실험 결과**: Listen 정책 1.46×, Speak 정책 1.59× 실시간 대비 wall-clock 가속. Core LM 기준 각각 1.61×, 1.80× 가속. 인간 평가에서 Listen은 자연스러움 유지, Speak는 일부 자연스러움 저하 관찰.
- **우리 연구 관련도**: ★★☆ — 자기회귀 디코딩 가속은 speech token 기반 모델의 추론 효율성 문제와 관련. Rolling masked prediction은 temporal contrastive learning과 다른 축이지만, token-level prediction 효율화 관점에서 참고 가능.

### **[People Making Conversation: Evaluating How Naturally Speech Models Converse] (저자 다수, 2026-10)** — NeurIPS 2026 Workshop on Real-Time Conversational Agents (RTCA) accepted
- https://neurips.cc/virtual/2026/162448
- **기존 문제**: 기존 음성 대화 모델 평가는 경계 검출, 턴테이킹 정책 준수, 또는 집계 통계 수준의 비교에 그쳤으며, 모델이 실제로 각 pause에서 "발화할지 침묵할지"를 자연스럽게 결정하는지를 직접 테스트하지 않았다.
- **기존 방법**: 턴테이킹 평가는 주로 IPU(Inter-Pausal Unit) 기반 정량 지표나 VAD 정확도로 이루어졌으며, 모델의 발화 결정(speak/silence decision) 자체를 평가하는 체계적 벤치마크가 부재했다.
- **제안 방법**: Seamless Interaction 코퍼스에서 176개 자연 대화를 선별하고 턴, 정지(pause), 백채널을 라벨링. 427개의 중간-턴 pause와 482개의 턴 종료 지점에서 모델의 발화/침묵 결정을 평가하는 벤치마크 구축.
- **핵심 차별점**: 모든 hosted 시스템(API 기반)은 endpointer가 침묵을 감지하면 **모든 pause 후에 즉시 발화** — 이것은 결정이 아니라 레이턴시(1~4초)에 의해 결정됨. 반면, full-duplex 모델만이 침묵을 유지하거나 인간 반응 시간(220~370ms) 내에 끼어들 수 있음을 최초로 실증.
- **실험 결과**: 12개 voice agent 대상 평가. Hosted 시스템은 대화 히스토리를 텍스트로 제공 시 질문의 33~61% 응답, full-duplex 모델은 오디오로 청취 시 2~22%만 응답. 코퍼스, 라벨, 평가 하네스 및 모든 시스템 출력 공개.
- **우리 연구 관련도**: ★★☆ — Speech representation이 대화적 맥락(턴테이킹, 백채널)을 얼마나 인코딩하는지의 관점에서 평가 프레임워크로 참고 가능. Speech SSL 표현의 대화적 정보량을 측정하는 간접적 지표로 활용 가능성.

### **[M3-DuplexBench: A Multi-Turn, Multilingual, Multidomain Benchmark for Full-Duplex Spoken Dialogue Models] (Ryo Fukuda, Atsushi Ando, Hiroki Kanagawa, Takatomo Kano, Marc Delcroix, Naohiro Tawara, Yuya Chiba — NTT, 2026-07-31)** — SLT 2026 제출
- https://arxiv.org/abs/2607.29125
- **기존 문제**: Full-duplex 대화 모델의 기존 벤치마크(Full-Duplex-Bench v1/v2 등)는 주로 영어 단일 턴에 집중되어, 다턴 대화에서의 맥락 유지, 다국어 대응, 도메인 다양성을 평가하지 못했다.
- **기존 방법**: Full-Duplex-Bench v1은 pause/interrupt/backchannel을 단일 턴에서 평가. v2는 다턴으로 확장했으나 영어 단일 도메인에 한정. MTVA-Bench, MSI-Bench 등은 텍스트 또는 수동 이해 중심 평가.
- **제안 방법**: 영어와 일본어 2개 언어, 일상 대화(casual conversation)와 다턴 질의응답(multi-turn QA) 2개 도메인을 포괄하는 벤치마크. 단일 턴, 사용자 전용(user-only), 교사 강제(teacher-forced full-context) 3가지 설정에서 대화 히스토리가 모델 행동에 미치는 영향을 체계적으로 분석.
- **핵심 차별점**: 다국어(영/일) + 다도메인(대화/QA) + 다턴 조건을 동시에 평가하는 최초의 full-duplex 벤치마크. 모델별 턴테이킹 특성 차이, 언어/도메인 간 뚜렷한 성능 격차, 대화 맥락의 혼합적 영향을 최초로 체계적으로 보고.
- **실험 결과**: 최근 full-duplex 시스템들을 대상으로 평가한 결과, (1) 모델별로 뚜렷한 턴테이킹 특성 차이 확인, (2) 언어 및 도메인 간 명확한 성능 갭 존재, (3) 대화 맥락이 모델 성능에 미치는 영향은 일관적이지 않고 모델/조건에 따라 상이함을 확인.
- **우리 연구 관련도**: ★☆☆ — Full-duplex 모델의 다국어/다도메인 평가 프레임워크. Speech representation 연구와의 직접적 관련성은 낮으나, 다국어 음성 토큰의 품질 평가 기준으로 간접 참고 가능.

## 3. Speech Foundation Model

### **[Steering Follows Geometry, Not Labels: Emotion Directions in a Full-Duplex Speech Model] (저자 다수, 2026)** — NeurIPS 2026 accepted
- https://neurips.cc/virtual/2026/162447
- **기존 문제**: Full-duplex 음성 모델(Moshi 등)의 내부에서 감정 정보가 어떻게 표현되고 조작 가능한지에 대한 이해가 부족했다. 모델을 재학습하지 않고 감정 스타일을 조종(steering)할 수 있는지가 열린 질문이었다.
- **기존 방법**: SteerDuplex 등은 supervised fine-tuning + RL을 통해 톤/페르소나를 학습시키는 방식. 내부 표현 공간에서의 선형 조작(activation steering)에 대한 체계적 분석은 full-duplex 음성 모델에서 시도되지 않았다.
- **제안 방법**: 오픈소스 full-duplex 모델 Moshi의 residual stream에서 4가지 감정(happy, angry, surprise, sad)에 대해 mean-difference activation steering을 적용. 프레임당 벡터 하나의 덧셈만으로 작동하며 재학습 불필요.
- **핵심 차별점**: (1) 감정이 Moshi의 residual stream에서 선형적으로 디코딩 가능함을 확인. (2) 그러나 activation steering은 부분적으로만 가능하며, happy/angry/surprise는 공유된 방향으로 이동하는 반면 sad만 독립적으로 조종 가능. (3) 세 감정의 공유 성분을 단순히 투영(project away)하는 것으로는 균등한 분리 불가.
- **실험 결과**: Moshi의 내부 표현에서 감정의 선형 디코딩이 확인되었으나, steering의 비균등성(unevenness)이 관찰됨. Happy, angry, surprise가 공유 방향을 가지며, 이 공유 성분을 제거하면 모든 감정의 steering이 동시에 약화되는 현상 보고.
- **우리 연구 관련도**: ★★★ — Speech foundation model의 내부 표현 구조를 기하학적으로 분석하는 연구. 감정 정보의 선형 분리 가능성과 한계는 speech SSL 표현의 disentanglement 연구와 직접적으로 관련. VQ-based representation에서 감정/화자/내용 정보의 분리 메커니즘 이해에 핵심적 시사점 제공.
