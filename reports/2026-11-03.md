## 1. ASR (Automatic Speech Recognition)

### **[FASTDIAR: Frame-Level Speaker Encoder for Streaming Diarization] (Nikita Torgashov, Okan Köpüklü — KTH / Microsoft, 2026-10)** — arxiv preprint

- **arxiv URL:** https://arxiv.org/abs/2610.02941
- **기존 문제:** 스트리밍 화자 분리(diarization)에서 기존 방법들은 짧은 세그먼트에서 화자 임베딩 품질이 저하되고, 4명 이상 화자 환경에서 성능이 급격히 떨어지는 문제가 있었다.
- **기존 방법:** 캐시 기반(cache-based) 온라인 클러스터링이나 EEND(End-to-End Neural Diarization) 방식이 주로 사용되었으며, 대부분 2초 단위 청크에서 오프라인 화자 인식 모델을 사용했다.
- **제안 방법:** 화자 인식 모델 ReDimNet을 causal하게 변환하고 temporal pooling을 제거하여 프레임 단위 화자 임베딩을 생성한다. Confidence-gated 온라인 클러스터링으로 고신뢰도 프레임만 화자 중심(centroid) 업데이트에 사용한다.
- **핵심 차별점:** 별도의 diarization 학습 데이터 없이 화자 인식 모델만으로 스트리밍 분리 가능. 960ms 고정 지연으로 실시간 처리. 화자 전환 구간의 임베딩이 클러스터를 오염시키는 문제를 confidence gating으로 해결.
- **실험 결과:** 저중첩(low-overlap) 벤치마크에서 기존 스트리밍 분리기 대비 우수한 성능. 4명 이상 화자 시나리오에서 캐시 기반 시스템 대비 성능 저하 폭이 적음. 모델 크기: Small(2.4M), Medium(4.6M), Large(10.4M).
- **우리 연구 관련도:** ★☆☆ — 화자 분리 특화 연구로, speech SSL이나 VQ 표현 학습과의 직접 연관은 낮으나, 프레임 단위 표현 활용 관점에서 참고 가능.

### **[StreamHear: Domain-Adapted Pseudo-Labeling for Semi-Supervised Streaming Speech Recognition] (Capital One 연구팀, 2026-08)** — NeurIPS 2026 accepted

- **arxiv URL:** https://arxiv.org/abs/2608.13717
- **기존 문제:** 스트리밍 ASR 모델은 도메인 이동(domain shift)된 오디오에서 성능이 크게 저하되며, 도메인 내 레이블 데이터는 비용이 높고 비레이블 데이터는 풍부한 비대칭 상황이 일반적이었다.
- **기존 방법:** 반지도학습(semi-supervised) 기반 pseudo-labeling에서 교사 모델을 반복 업데이트하거나 보조 모듈을 추가하는 복잡한 파이프라인이 사용되었다.
- **제안 방법:** 오프라인 transducer 교사 모델을 레이블 데이터로 fine-tune한 뒤 비레이블 데이터에 한 번만 pseudo-label을 생성하고, 사전학습된 스트리밍 학생 모델을 혼합 데이터로 학습. Prior-regularized dynamic programming 재정렬로 청크 수준 단어 위치를 교정한다.
- **핵심 차별점:** 교사 모델 고정, 단일 라운드 pseudo-labeling으로 반복 재학습 불필요. DP 기반 재정렬이 스트리밍 환경의 단어 경계 오류를 보정하는 점이 새롭다.
- **실험 결과:** 금융 통화, 읽기 음성, 전화 품질 대화 등 4개 데이터셋에서 지도학습 fine-tuning 대비 일관된 개선. 오프라인 교사와의 성능 격차 축소.
- **우리 연구 관련도:** ★☆☆ — ASR 도메인 적응 연구로, representation learning과는 거리가 있으나, pseudo-labeling 전략은 SSL 학습 데이터 구축 시 참고 가능.

### **[Gradient-Based Speech-to-Text Alignment for Any ASR Model: From CTC to Speech LLMs] (Albert Zeyer, Ralf Schlüter, Hermann Ney — RWTH Aachen, 2026-07)** — arxiv preprint

- **arxiv URL:** https://arxiv.org/abs/2607.06831
- **기존 문제:** CTC/Transducer 모델은 구조적으로 정렬(alignment)을 제공하지만, attention 기반 모델과 Speech LLM은 attention weight에 의존하여 시간 정밀도가 인코더 프레임 그리드에 제한되었다.
- **기존 방법:** CTC forced alignment, attention weight 기반 정렬, 또는 별도의 정렬 전용 모델(Montreal Forced Aligner 등)을 사용했다.
- **제안 방법:** Teacher-forced 디코딩에서 각 토큰의 log probability에 대한 입력 그래디언트를 계산하고, 프레임별 saliency로 환원한 뒤, 단일 DP(dynamic programming) 패스로 단어 경계를 디코딩한다. 모델 수정이나 추가 학습 불필요.
- **핵심 차별점:** 모든 ASR 아키텍처(CTC, Transducer, Attention, Speech LLM)에 범용 적용 가능한 최초의 gradient 기반 정렬 방법. 네이티브 정렬이 약한 스트리밍 모델에서 특히 효과적.
- **실험 결과:** TIMIT(읽기 음성)과 Buckeye(자연발화) 코퍼스에서 4개 계열 16개 모델 평가. 강력한 네이티브 정렬기 대비 약간 뒤지나, 네이티브 정렬이 약한 모델에서는 개선. 주요 단점은 토큰당 역전파 비용.
- **우리 연구 관련도:** ★★☆ — Gradient saliency 기반 분석은 speech SSL 표현의 temporal 구조를 이해하는 데 응용 가능. Temporal contrastive learning 연구에서 프레임-토큰 대응 관계 분석에 활용 가능성.

## 2. SpeechLLM (Speech Language Model)

### **[NemotronLabs VoiceChat: An Open Full-duplex Speech-to-Speech Model with Tool Calling Capabilities] (NVIDIA, 2026-09)** — NeurIPS 2026

- **arxiv URL:** https://arxiv.org/abs/2609.21967
- **기존 문제:** 기존 full-duplex 음성 대화 모델은 자연스러운 턴테이킹은 가능했으나, 대화 중 외부 도구(tool)를 호출하면서 대화 흐름을 유지하는 것은 불가능했다.
- **기존 방법:** Moshi, DuplexSLA 등의 full-duplex 모델이 존재했으나 tool calling 미지원. 별도의 파이프라인으로 ASR→LLM→TTS를 연결하는 cascaded 방식이 도구 호출에 사용되었다.
- **제안 방법:** Fast Conformer 음성 인코더 + Nemotron Nano v2 LLM 백본 + NVIDIA TTS 디코더의 11B 파라미터 통합 모델. 도구 호출을 별도 출력 채널로 처리하여 API 실행 중에도 대화 지속. 보조 RNN-T 브랜치로 사용자 발화를 점진적으로 전사.
- **핵심 차별점:** 오픈 웨이트 모델 중 최초로 full-duplex 대화와 tool calling을 동시에 지원. API 응답 대기 중 "on-hold" 발화로 자연스러운 대화 흐름 유지.
- **실험 결과:** Full-Duplex-Bench 1.0: 448ms 턴테이킹 지연, 100% 인터럽션 수용, 4.33/5 응답 품질. FDB 3.0 tool calling: 82.5% 도구 선택, 44.2% 인자 정확도. VoiceBench: 55.1 정규화 평균.
- **우리 연구 관련도:** ★★☆ — Speech-to-speech 모델의 내부 표현이 어떻게 tool calling과 대화 생성을 동시에 처리하는지는 speech representation 연구에 시사점 제공.

### **[EgoVoice: Proactive Spoken Assistance from Egocentric Multimodal Streams] (Heeseung Kim 외, 2026-10)** — EMNLP 2026 Main Conference

- **arxiv URL:** https://aclanthology.org/2026.emnlp-main.1277/
- **기존 문제:** 기존 음성 에이전트는 사용자의 명시적 요청에만 반응(reactive)하며, 시각-청각 맥락을 실시간으로 파악하여 선제적으로(proactively) 도움을 제공하는 것이 불가능했다.
- **기존 방법:** ProAssist(EMNLP 2025)가 자아중심(egocentric) 비디오에서 합성 대화 데이터를 만들어 대화 생성을 시도했으나, 음성 출력이 아닌 텍스트 기반이었으며 실시간 스트리밍이 아니었다.
- **제안 방법:** 자아중심 멀티모달 스트림(시각+청각)을 입력받아 "언제" 개입할지와 "무엇을" 말할지를 동시에 학습하는 프레임워크. 데이터셋, 코드, 모델 체크포인트 공개 예정.
- **핵심 차별점:** Reactive가 아닌 proactive 음성 지원을 학습 가능한 프레임워크로 처음 정식화. 시각-청각 멀티모달 조건에서의 발화 타이밍 결정을 포함.
- **실험 결과:** EMNLP 2026 본 학회 발표(pages 29112–29136). 구체적 벤치마크 수치는 논문 확인 필요.
- **우리 연구 관련도:** ★☆☆ — 멀티모달 에이전트 연구로 speech SSL과 직접 연관은 낮으나, 음성 표현이 시각 정보와 어떻게 통합되는지에 대한 아키텍처적 참고 가능.

### **[Interleaved Speech Language Models Latently Work In Text] (Talia Sternberg, Gallil Maimon, Yossi Adi — Hebrew University of Jerusalem, 2026-06)** — arxiv preprint

- **arxiv URL:** https://arxiv.org/abs/2606.22473
- **기존 문제:** 인터리브(interleaved) 음성-텍스트 LM이 음성을 처리할 때 내부적으로 어떤 표현을 사용하는지 불명확했다. 음성 토큰만으로 의미를 직접 처리하는지, 텍스트 공간을 경유하는지 알려지지 않았다.
- **기존 방법:** SpiRit-LM, TWIST 등의 인터리브 음성-텍스트 LM이 개발되었으나, 내부 처리 메커니즘에 대한 분석은 부재했다.
- **제안 방법:** Logit lens 분석을 통해 중간 레이어에서 음성 토큰이 텍스트 토큰으로 암묵적으로 전사(implicit transcription)되는 단계를 발견. 데이터의 77%에서 발화 단어의 텍스트 토큰이 상위 후보로 나타남.
- **핵심 차별점:** Speech LM의 "암묵적 전사" 현상을 최초로 실증. 모델이 음성→텍스트→다음 단어 예측→음성 순서로 처리한다는 메커니즘을 밝힘. Speech LM의 음성 능력이 학습된 텍스트 공간 표현에 근본적으로 의존할 수 있음을 시사.
- **실험 결과:** 인터리브 SLM의 중간 레이어에서 77% 데이터의 발화 단어가 텍스트 토큰으로 디코딩 가능. 텍스트 공간에서 다음 단어 예측 후 음성 도메인으로 재변환되는 패턴 확인.
- **우리 연구 관련도:** ★★★ — Speech LM 내부의 표현 공간 분석 연구로, speech representation이 텍스트 표현과 어떻게 상호작용하는지에 대한 핵심적 통찰 제공. Prediction-free SSL 연구에서 "예측 대상"의 본질에 대한 시사점.

### **[Continuous Audio Thinking for Large Audio Language Models (CoAT)] (Gyojin Han, Dong-Jae Lee 외 — KAIST, 2026-06)** — NeurIPS 2026

- **arxiv URL:** https://arxiv.org/abs/2606.18273
- **기존 문제:** 대형 오디오 언어 모델(LALM)이 음성/오디오 입력을 텍스트로 변환한 후 처리하면서 음향적 세부 정보(감정, 음색, 환경음 등)가 손실되는 문제가 있었다.
- **기존 방법:** 오디오 인코더 + LLM 조합에서 오디오 특징을 LLM 입력 임베딩에 한 번만 투사하는 방식. Chain-of-thought 추론은 텍스트 공간에서만 수행.
- **제안 방법:** 연속적 잠재 작업 공간(continuous latent workspace)을 통해 응답 생성 전 음향 정보를 정리. 오디오 전문가 모델로부터의 증류(distillation)로 잠재 공간을 학습.
- **핵심 차별점:** 텍스트 기반 사고 대신 오디오 도메인에서의 연속적 "사고"를 수행. 음향 추론과 텍스트 추론을 분리하여 음향 정보 보존.
- **실험 결과:** 오디오 추론, 오디오 이해, 음악 분류, 음성 감정 인식, 음성 전사 등 광범위한 벤치마크에서 평가. MELD 음성 감정 인식 60.8% (2차 자료 기준). Qwen2-Audio, Qwen2.5-Omni-7B, Audio Flamingo 3 백본에서 검증.
- **우리 연구 관련도:** ★★☆ — 오디오 표현을 텍스트 공간으로 전환하지 않고 연속 잠재 공간에서 처리하는 접근은 speech representation learning의 표현력 연구와 관련. VQ-based 이산 표현 vs 연속 표현 논쟁에 시사점.

## 3. Speech Foundation Model

### **[F3-Tokenizer: Taming Audio Autoencoder Latents for Understanding and Generation] (Dinghao Zhou, Xingchen Song 외, 2026-06)** — arxiv preprint

- **arxiv URL:** https://arxiv.org/abs/2606.06357
- **기존 문제:** 연속적 오디오 오토인코더는 파형 복원은 잘하지만 의미적으로 약한 잠재 표현을 생성. 반면 자기지도 인코더(SSL)는 의미를 잘 포착하지만 직접 디코딩이 불가.하나의 토크나이저로 이해와 생성을 동시에 서비스하는 것이 어려웠다.
- **기존 방법:** SpeechTokenizer, RepCodec 등이 의미적 토큰과 음향 토큰을 분리하거나, 별도의 이해용/생성용 토크나이저를 사용.
- **제안 방법:** (1) 노이즈 정규화 오토인코더 bottleneck: KL 기반 변분 학습 대신 채널 정규화 + 확률적 perturbation으로 스케일 제어. (2) 잠재 표현 인코더: 고정된 오토인코더 잠재에서 RQ-MTP + 고정 LLM 감독으로 의미적 표현을 학습.
- **핵심 차별점:** 이해(understanding)와 생성(generation)을 하나의 토크나이저로 통합. KL 정규화 없이 안정적인 잠재 공간 구축. 기존 오토인코더 위에 비파괴적으로(non-destructively) 의미를 주입.
- **실험 결과:** ESC-50 오디오 분류 75.2%, NSynth 악기 분류 58.12%, Seed-EN TTS WER 1.88% (2차 자료 기준).
- **우리 연구 관련도:** ★★★ — VQ-based representation 연구와 직접 관련. 오토인코더 잠재 공간에서의 의미 학습 방법론, RQ 구조, SSL과 코덱의 통합 방향 모두 핵심 참고 대상.

### **[Dissecting Sensitivity to Training Language in Self-Supervised Speech Learning Using Neural Audio Codec Tokens] (Daigo Takizawa, Tomohiko Nakamura, Samuele Cornell, William Chen 외, 2026-07)** — arxiv preprint

- **arxiv URL:** https://arxiv.org/abs/2607.26350
- **기존 문제:** 코덱 기반 자기지도 학습(codec-based SSL)은 이산 토큰으로 학습하여 효율적이지만, 코덱과 SSL 각각의 학습 언어가 하류 작업 성능에 어떤 영향을 미치는지 체계적으로 연구되지 않았다.
- **기존 방법:** HuBERT, wav2vec 2.0 등 연속 특징 기반 SSL이 주류. 코덱 토큰 기반 SSL(Codec2Vec 등)이 등장했으나 다국어 조건에서의 언어 민감도 분석 부재.
- **제안 방법:** 코덱의 학습 언어와 SSL 사전학습 언어를 독립적으로 변화시키며 영향을 측정. 다수의 공개 NAC(Neural Audio Codec)과 재학습된 DAC를 사용. 변동 계수(Coefficient of Variation)로 언어 민감도 정량화.
- **핵심 차별점:** 코덱 학습 언어보다 SSL 사전학습 언어가 훨씬 중요하다는 것을 실증. 하나의 코덱으로 여러 언어에 재사용 가능하나, SSL 사전학습은 목표 언어와 일치시켜야 함.
- **실험 결과:** 코덱 언어 변경 시 성능 변동이 작고(낮은 CoV), SSL 사전학습 언어 변경 시 변동이 큼(높은 CoV). 목표 언어와 SSL 학습 언어 일치 시 최적 성능.
- **우리 연구 관련도:** ★★★ — Codec token 기반 SSL 연구의 핵심 분석. VQ-based representation learning에서 토큰화 단계와 사전학습 단계의 역할 분리에 대한 직접적 시사점. 우리 연구의 speech tokenizer 설계에 중요한 참고.

### **[Do Speech Foundation Models Really Learn Words?] (Robin Huo, Ewan Dunbar, 2026-09)** — arxiv preprint

- **arxiv URL:** https://arxiv.org/abs/2609.10434
- **기존 문제:** Speech foundation model의 단어 수준 프로빙(probing) 결과가 좋다고 알려져 있으나, 이것이 진정한 단어 표현을 학습한 것인지, 단순히 음소(phoneme) 정보의 부산물인지 불명확했다.
- **기존 방법:** 단어 프로빙(word probing)으로 SSL 모델의 어휘 능력을 평가했으나, 음소 정보와 단어 정보를 분리하는 시도가 부족했다.
- **제안 방법:** 잔차화(residualization)를 통해 음소 정보를 제거한 후 단어 수준 정보가 남는지 검증. HuBERT, wav2vec 2.0 등의 레이어별 분석.
- **핵심 차별점:** 음소 인코딩과 의미적 단어 인코딩이 레이어별로 단계적으로 학습된다는 것을 실증. 후반 레이어에서 음소 정보와 독립적인 단어 표현이 존재함을 확인. 잔차화 접근이 단어 발견(word discovery) 작업의 성능도 향상.
- **실험 결과:** HuBERT, wav2vec 2.0 후반 레이어에서 음소 내용을 제거해도 단어를 합리적 수준으로 인코딩. 잔차화된 표현이 word discovery 작업에서도 성능 개선.
- **우리 연구 관련도:** ★★★ — Speech SSL 표현이 무엇을 학습하는지에 대한 핵심 분석 논문. Prediction-free speech SSL 연구에서 "표현이 포착해야 할 것"의 본질에 대한 직접적 시사점. Temporal contrastive learning에서 음소 vs 단어 수준 정보 분리 관점에서 매우 관련.
