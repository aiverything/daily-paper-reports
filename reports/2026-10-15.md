## 1. ASR (Automatic Speech Recognition)

### **[Phoneme-Guided Initialization for LLM-based Speech Recognition] (Ryo Magoshi, Shinsuke Sakai, Tatsuya Kawahara, 2026-10-06)** — IEEE SLT 2026 accepted

- https://arxiv.org/abs/2610.08994
- **기존 문제:** LLM 기반 ASR 모델은 음성 인코더와 LLM 간의 모달리티 격차로 인해, 특히 저자원 환경 및 동음이의어가 많은 언어에서 성능이 제한됨
- **기존 방법:** 음성 인코더를 직접 LLM에 연결하여 end-to-end 학습하거나, 캐스케이드 방식(음성→음소→텍스트)을 사용. 두 방식 모두 대규모 음성-텍스트 쌍 데이터에 의존
- **제안 방법:** 음성 인코더를 음소 변환(Speech-to-Phoneme, S2P)으로 사전 학습하고, LLM을 음소→문자 변환(Phoneme-to-Grapheme, P2G)으로 사전 학습한 후, 이를 연결하여 end-to-end ASR로 파인튜닝. P2G 학습 시 외부 텍스트 코퍼스에서 G2P 도구로 생성한 음소 시퀀스를 활용
- **핵심 차별점:** 음성 데이터 없이 텍스트만으로 LLM의 음소 이해 능력을 사전 학습할 수 있어, 저자원 환경에서 특히 효과적. 두 모달리티를 음소라는 공통 표현으로 연결
- **실험 결과:** 일본어(CSJ), 중국어(AISHELL-1), 저자원 언어(Tatar, Urdu — Common Voice 25.0)에서 캐스케이드 S2P-P2G 베이스라인 및 P2G 초기화 없는 end-to-end 모델 대비 동등 이상 성능 달성
- **우리 연구 관련도:** ★☆☆ — LLM 기반 ASR의 초기화 전략 연구로, prediction-free SSL이나 VQ 기반 표현과의 직접적 관련성은 낮음

### **[Lossless Inference Acceleration for ASR via EAGLE-Style Speculative Decoding] (Sen Zhang, Xianghu Yue, Yiming Chen, Wenhuan Lu, Jianguo Wei, Haizhou Li, 2026-10-09)** — arxiv preprint

- https://arxiv.org/abs/2610.13506
- **기존 문제:** 자동회귀 ASR 모델(Whisper, Conformer AED 등)의 추론 속도가 전사 길이에 비례하여 증가하며, 실시간 처리에 병목
- **기존 방법:** 기존 speculative decoding 접근법은 draft 모델의 acceptance rate가 낮거나, 특수 설계된 외부 draft 모델이 필요하여 범용성이 제한
- **제안 방법:** EAGLE-ASR — 경량 자동회귀 draft 모듈(Speech-Draft)이 인코더 음향 특징과 디코더 표현을 동시에 활용. Self-distilled 데이터 기반 multi-step 생성 전략으로 타겟 모델의 출력 분포에 대한 draft 품질 극대화
- **핵심 차별점:** Self-distillation으로 multi-token 생성 시 causal consistency를 유지하면서, 별도 외부 모델 없이 높은 acceptance rate 달성. 다국어 ASR 및 음성 번역까지 범용 적용 가능
- **실험 결과:** Whisper에서 최대 1.9배, Conformer AED에서 최대 2.4배 무손실(lossless) 속도 향상. VoxPopuli 5개 언어(영어, 독일어, 스페인어, 프랑스어, 이탈리아어)에서 검증
- **우리 연구 관련도:** ★☆☆ — 추론 가속화 연구로, SSL/VQ 기반 표현 연구와의 직접적 관련성은 낮음

### **[Whisfusion: Parallel ASR Decoding with Masked Diffusion] (Taeyoun Kwon et al., 2025-08, revised 2026)** — arxiv preprint

- https://arxiv.org/abs/2508.07048
- **기존 문제:** Whisper 등 자동회귀 인코더-디코더 모델이 고품질 다국어 ASR에서 우세하지만, 좌-우 순차 디코딩으로 인해 추론 지연이 전사 길이에 비례하여 증가
- **기존 방법:** CTC 기반 비자동회귀 방식은 빠르지만 전사 수준 모델링을 포기. 기존 비자동회귀 디코더(NAR)는 정확도 하락이 큼
- **제안 방법:** 고정된 Whisper-large-v3 인코더 위에 from-scratch masked diffusion transformer(24층, hidden 1280, 20 attention heads, ~830M 파라미터)를 학습. Parallel Diffusion Decoding + Minimum Bayes Risk(MBR) 합의 선택 + Whisper likelihood 재순위 적용
- **핵심 차별점:** 자동회귀 디코더를 완전히 대체하는 병렬 diffusion 디코딩으로, 정확도를 유지/개선하면서 대폭적인 속도 향상. ~68k시간 11개 언어 음성으로 학습
- **실험 결과:** 영어/유럽/CJK 벤치마크 그룹 평균에서 Whisper-large-v3 정확도 초과 + 4-5배 빠른 추론. Canary, Qwen3-ASR과 경쟁적 정확도에서 3-7배 빠른 추론 달성
- **우리 연구 관련도:** ★★☆ — Diffusion 기반 디코딩은 speech representation 활용 방식의 혁신으로, SSL 표현을 비자동회귀 생성에 활용하는 방향과 간접적 관련

## 2. SpeechLLM (Speech Language Model)

### **[PACE: A Playback-Aligned Context Engine for LLM-Based Full-Duplex Voice Dialogue] (Shibo Wang, Zicheng Zhang, Libo Wang, Junfeng Ma, 2026-08-07)** — arxiv preprint

- https://arxiv.org/abs/2608.07631
- **기존 문제:** 서버 측 생성 속도가 클라이언트 재생 속도보다 빠르면, 모델이 사용자가 실제로 듣지 못한 컨텐츠를 기반으로 응답을 생성하는 "Generative Context Mis-anchoring (GCM)" 문제 발생
- **기존 방법:** 단순 취소(cancellation) 기반 인터럽션 처리만 사용. 재생 경계를 고려하지 않아, 사용자가 참조하는 맥락과 모델의 맥락이 불일치
- **제안 방법:** PACE — 클라이언트 재생 경계에 모델 컨텍스트를 정렬하는 provider-independent 미들웨어 레이어. 인터럽션 발생 시 재생되지 않은 어시스턴트 컨텐츠를 컨텍스트에서 제거
- **핵심 차별점:** 모델 자체를 수정하지 않는 미들웨어 접근으로, 어떤 음성 대화 모델에든 범용 적용 가능. GCM이라는 새로운 문제를 정의하고 전용 벤치마크(GCM-Bench) 제시
- **실험 결과:** GCM-Bench(108개 케이스)에서 Referent Anchoring Accuracy 25.0%→96.3%. Full-Duplex-Bench v1(200개 인터럽션 샘플)에서 평균 응답 점수 4.975→4.995
- **우리 연구 관련도:** ★☆☆ — 시스템 아키텍처/미들웨어 연구로, SSL/VQ 기반 표현 연구와의 직접적 관련성은 낮음

### **[Multimodal Duplex Interaction Agent (Gander)] (Orantqing, Shengpeng Ji et al., 2026-09-15)** — arxiv preprint

- https://arxiv.org/abs/2609.08977
- **기존 문제:** 단일 모놀리식 모델로는 실시간 스트리밍 반응성과 복잡한 장기(long-horizon) 추론/에이전트 작업 간 균형 달성이 어려움
- **기존 방법:** 하나의 대규모 모델이 대화/추론/에이전트 작업을 모두 처리하거나, ASR-LLM-TTS 캐스케이드 파이프라인 사용. 전자는 지연시간, 후자는 에러 전파 문제
- **제안 방법:** 소뇌(Cerebellum)-뇌(Brain) 이중 구조 시스템 Gander. 소뇌(MiniCPM-o 4.5 기반)는 Thinker-Talker 아키텍처로 실시간 풀듀플렉스 스트리밍 상호작용(음성/카메라/화면) 담당. 뇌는 범용 태스크 워커로 복잡한 추론/에이전트 실행 담당. 도구 호출(tool calling)과 오케스트레이션 런타임으로 연결
- **핵심 차별점:** 뇌를 plug-and-play 컴포넌트로 설계하여 추가 학습 없이 교체 가능. 실시간 반응성(소뇌)과 깊은 추론(뇌)을 완전히 분리하여 각각 독립 최적화
- **실험 결과:** 대화 능력, 상호작용 능력, 이해력, 도구 기반 태스크 실행 능력에서 평가 수행 (구체적 벤치마크 수치는 검색 결과에서 미확인)
- **우리 연구 관련도:** ★☆☆ — 멀티모달 에이전트 아키텍처 연구로, SSL/VQ와의 직접적 관련성은 낮으나, speech tokenizer가 Cerebellum의 입출력 표현으로 중요한 역할

### **[DiffuPlex: Accelerating Full-Duplex Spoken Dialog Models via Rolling Masked Diffusion] (Heeseung Kim et al., 2026-10-08)** — arxiv preprint

- https://arxiv.org/abs/2610.12214
- **기존 문제:** 풀듀플렉스 음성 대화 모델은 매 인터랙션 프레임(~80ms)마다 백본을 한 번 실행해야 하여 추론 비용이 높고, 모델 크기 확장이 제한
- **기존 방법:** 프레임 단위 백본 호출로 실시간 대화 처리. 백본 크기를 줄이거나 하드웨어를 늘려 대응
- **제안 방법:** DiffuPlex — Rolling Masked Diffusion으로 한 번의 백본 패스에서 미래의 사용자/어시스턴트 프레임 블록을 한꺼번에 예측. 확신도(confidence)가 높은 접두사만 재생하고 나머지는 다음 패스에서 refinement
- **핵심 차별점:** 풀듀플렉스 모델 전용 추론 가속화 프레임워크. Listen(듣기 최적화)/Speak(말하기 최적화) 두 변형으로 자연스러움-효율성 트레이드오프 제공
- **실험 결과:** Listen 변형 약 1.46배, Speak 변형 약 1.59배 벽시계 시간 속도 향상. Core LM에서 각각 1.61배, 1.80배 가속. 모든 백본 호출이 80ms 인터랙션 인터벌 내 완료. Listen은 자연스러움+대화 품질 유지, Speak는 대화 품질 유지+약간의 자연스러움 감소
- **우리 연구 관련도:** ★★☆ — Diffusion 기반 디코딩 가속화는 speech token/representation의 효율적 생성과 관련. 특히 masked diffusion이 speech token 예측에 적용되는 점에서 VQ 기반 representation 연구와 간접적으로 연결

## 3. Speech Foundation Model

### **[ReLMCodec: Designing Predictable Speech Tokens from Pre-Quantization Phoneme Structure] (Zixiang Wan, Xusheng Yang, Zheng Wang, Peiji Yang, 2026-08-08)** — arxiv preprint

- https://arxiv.org/abs/2608.08286
- **기존 문제:** 기존 speech tokenizer의 토큰이 자동회귀 언어 모델(LM)에서 예측하기 어려우며, 어떤 표현 특성이 LM의 예측 가능성에 영향을 미치는지 체계적으로 분석되지 않음
- **기존 방법:** 재구성 품질(PESQ, speaker similarity 등) 중심으로 코덱을 설계하며, 다운스트림 LM에서의 토큰 예측 가능성(next-token accuracy)을 코덱 설계에 반영하지 않음
- **제안 방법:** "Preserve, Control, Refine" 3단계 접근. (1) 고정된 W2v-BERT 2.0 특징을 양자화 입력에 유지(Preserve), (2) Pre-quantization Anchor-Preserving Adaptation(PAPA)으로 재구성 학습에 의한 SSL 표현 드리프트 제한(Control), (3) WavLM-Large L24를 teacher로 활용한 knowledge distillation(Refine). 단일 코드북 저비트레이트 코덱
- **핵심 차별점:** 24개 다양한 표현에 대해 양자화 전 음소 구조와 LM 토큰 예측 정확도 간 강한 상관관계(Spearman ρ=0.911) 발견. 이 분석적 통찰을 직접 코덱 설계 원칙으로 반영
- **실험 결과:** 800 bps에서 LibriSpeech test-clean/test-other 기준 WER 3.96, speaker similarity 0.804, PESQ 2.40 달성. 다운스트림 TTS에서도 개선 보고
- **우리 연구 관련도:** ★★★ — SSL 표현(W2v-BERT 2.0, WavLM)을 기반으로 한 VQ 토큰 설계, 예측 가능성과 음소 구조의 관계 분석 등 prediction-free SSL 및 VQ 기반 representation 연구와 직접적으로 관련

### **[CleanCodec: Efficient and Robust Speech Tokenization via Perceptually Guided Encoding] (Eugene Kwek, Feng Liu, Rui Zhang, Wenpeng Yin, 2026-06-03)** — arxiv preprint

- https://arxiv.org/abs/2606.04418
- **기존 문제:** 기존 speech codec은 배경 소음, 녹음 아티팩트 등 비지각적 정보까지 모두 인코딩하여 토큰 효율성이 떨어지고, 다운스트림 태스크에 불필요한 정보 전달
- **기존 방법:** 고정 프레임레이트로 모든 음향 정보를 동등하게 인코딩. 노이즈 문제는 별도 전처리(speech enhancement)로 해결 후 코덱에 입력
- **제안 방법:** Denoising codec으로서 지각적으로 중요한 특징(언어적 내용 + 화자 정보)만 선택적으로 인코딩. 음성 향상(SE) 태스크와 음성 재구성을 결합한 공동 학습 목적함수. TitaNet 화자 임베딩으로 글로벌 인코더의 화자 정보 보존 감독
- **핵심 차별점:** 선택적 정보 병목(selective information bottleneck) 원리로 인코딩 전에 비지각적 정보를 제거. 별도 전처리 없이 코덱 자체가 denoising 수행. 12.5 tokens/sec의 높은 토큰 효율성
- **실험 결과:** 기존 코덱 대비 speaker similarity 및 speech intelligibility에서 상당한 개선. TTS 및 voice conversion 다운스트림 태스크에서 개선된 성능 + 최대 17배 빠른 추론
- **우리 연구 관련도:** ★★☆ — Speech tokenization 효율화로 VQ 기반 representation 연구와 관련. Denoising을 통한 정보 선택은 representation learning의 핵심 과제와 연결되나, SSL보다는 supervised 접근

### **[DuplexPO: Decoupling Conversational Dynamics in Full-Duplex Spoken Models through Reinforcement Learning] (Yuxin Li, Donghang Wu, Guan-Ting Lin, Hung-yi Lee, Chengwei Qin, Zhehuai Chen, Chen Chen, 2026-07-08)** — arxiv preprint

- https://arxiv.org/abs/2607.07148
- **기존 문제:** 풀듀플렉스 음성 모델에서 대화 역학(턴테이킹, 백채널링, 바지인 등)과 컨텐츠 추론 능력 사이에 트레이드오프가 존재한다고 여겨져, 한쪽 개선이 다른 쪽 저하로 이어짐
- **기존 방법:** 대화 역학과 컨텐츠 생성을 함께(jointly) 학습. SFT 기반으로 대화 행동과 응답 내용을 동시에 최적화하여, 타이밍 개선 시 추론 능력이 하락하는 문제
- **제안 방법:** DuplexPO — RL 프레임워크로 "언제 말할지"(타이밍)와 "무엇을 말할지"(컨텐츠)를 명시적으로 분리. 장문 인간 대화에서 턴 전환/백채널/바지인 구간의 학습 윈도우를 추출. Factorized Conversational Dynamics Reward(FCDR)로 턴 개시, 백채널링, 양보, 참여도를 별도 보상. GRPO 스타일 목적함수로 타이밍만 별도 최적화
- **핵심 차별점:** 대화 역학-추론 능력 간 트레이드오프가 본질적이지 않음을 보이고, 타이밍과 컨텐츠의 분리 학습으로 양쪽 모두 개선 가능함을 입증. 보상 설계에서 다차원적 대화 역학을 factorize하여 세밀한 제어
- **실험 결과:** 백채널 타이밍, 턴테이킹, 바지인 처리에서 개선 달성. 동시에 instruction-following 및 추론 성능 유지 보고 (구체적 벤치마크 수치는 검색 결과에서 미확인)
- **우리 연구 관련도:** ★☆☆ — RL 기반 대화 역학 분리 학습은 temporal contrastive learning의 "temporal structure 학습"이라는 관점에서 간접적 관련. 음성 표현에서 시간적 구조를 어떻게 활용하는가에 대한 시사점 제공
