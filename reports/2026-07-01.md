## 1. ASR (Automatic Speech Recognition)

### 1.1 TagSpeech: End-to-End Multi-Speaker ASR and Diarization with Fine-Grained Temporal Grounding

**[TagSpeech]** (Mingyue Huo, Yiwen Shao, Yuheng Zhang, 2026.01) — arXiv preprint

- **arxiv URL:** https://arxiv.org/abs/2601.06896
- **기존 문제:** 다화자 환경에서 "누가, 무엇을, 언제" 말했는지를 동시에 추정하는 것은 어려운 과제이며, 기존 end-to-end 모델은 화자 구분과 발화 시간 정보를 세밀하게 연동하지 못했다.
- **기존 방법:** 기존 멀티스피커 ASR은 SOT(Serialized Output Training) 기반 접근이나, 별도의 diarization 파이프라인을 후처리로 연결하는 방식이 주류였다. LLM 기반(Qwen-Omni, Gemini 등)도 발화 경계의 세밀한 시간 정보는 부족했다.
- **제안 방법:** LLM 기반 통합 프레임워크에 두 가지 핵심 설계를 도입. (1) 의미(semantic)와 화자(speaker) 정보를 분리한 이중 스트림을 SOT로 미세조정하여 턴 테이킹 역학을 학습. (2) 인터리브드 시간 앵커(time anchor) 메커니즘으로 세밀한 타임스탬프 예측과 의미-화자 스트림 간 동기화 신호를 동시 제공.
- **핵심 차별점:** LLM 백본을 동결(frozen)한 상태에서 경량 프로젝터만 학습하는 파라미터 효율적 학습 패러다임을 채택하여 낮은 계산 비용으로 강력한 성능 달성. 시간 앵커가 화자 추적과 음성 인식의 동기화 역할을 수행하는 점이 핵심 차별화 요소.
- **실험 결과:** AMI 및 AliMeeting 벤치마크에서 Qwen-Omni, Gemini를 포함한 강력한 end-to-end 베이스라인 대비 Diarization Error Rate(DER)에서 일관된 개선. 특히 겹침 발화(speech overlap) 처리에서 두드러진 성능 향상.
- **우리 연구 관련도:** ★☆☆ — 멀티스피커 ASR/다이어리제이션 통합이 주요 기여. 시간 앵커 기반 동기화 메커니즘은 temporal 구조 모델링 관점에서 참고할 수 있으나, speech SSL/VQ 표현 학습과의 직접적 연관은 제한적.

### 1.2 Balancing ASR and Diarization in End-to-End LLMs for Multi-Talker Speech Recognition

**[Balancing ASR and Diarization]** (Naijun Zheng, Yuke Lin, Sanli Tian, Mengtian Li, Zhiwei Lin, Longshuai Xiao, Dandan Tu — Huawei Technologies, 2026.06) — Interspeech 2026 accepted

- **arxiv URL:** https://arxiv.org/abs/2606.13095
- **기존 문제:** LLM 기반 다화자 ASR은 의미적(semantic) 정보와 화자(speaker) 정보를 동시에 학습해야 하지만, 대규모 다화자 학습 데이터 확보가 어렵고, 발화 겹침 시 환각(hallucination) 현상이 발생했다.
- **기존 방법:** 기존 Speech-LLM 접근법은 의미와 화자를 단일 인코더로 추출하거나, 대규모 다화자 코퍼스에 의존하여 joint 학습을 시도했으나, 제한된 실제 녹음 데이터로 높은 화자 귀속 정확도를 달성하기 어려웠다.
- **제안 방법:** (1) 의미 특징과 화자 특징을 각각 추출하는 듀얼 인코더 아키텍처, (2) 두 특징을 인터리빙 형식으로 LLM에 입력, (3) 길이 인지 화자 ID 손실(length-aware speaker ID loss)로 다이어리제이션 역량 강화, (4) 발화 겹침에 의한 환각을 완화하는 적응적 임계값 ASR 손실 전략.
- **핵심 차별점:** 제한된 실제 녹음 데이터 환경에서도 듀얼 인코더와 적응적 손실 전략을 통해 ASR 정확도와 화자 귀속을 동시에 균형 있게 개선. 특히 겹침 발화에서의 환각 문제를 임계값 전략으로 직접적으로 해결.
- **실험 결과:** 오픈소스 베이스라인 대비 AliMeeting에서 18%, Aishell4에서 24%의 상대적 개선을 달성.
- **우리 연구 관련도:** ★☆☆ — 다화자 ASR의 학습 전략 최적화가 주요 기여. 듀얼 인코더의 특징 분리 설계는 표현 학습 관점에서 참고할 수 있으나, prediction-free SSL과의 직접적 연관은 제한적.

### 1.3 G-STAR: End-to-End Global Speaker-Tracking Attributed Recognition

**[G-STAR]** (Jing Peng, Ziyi Chen, Haoyu Li, Yucheng Wang, Duo Ma, Mengtian Li, Yunfan Du, Dezhu Xu, Yu Xi, Kai Yu, Shuai Wang — Nanjing Univ / SJTU / Huawei / ETH Zürich, 2026.03) — arXiv preprint

- **arxiv URL:** https://arxiv.org/abs/2603.10468
- **기존 문제:** 장시간 다자간 대화에서 청크(chunk) 단위 추론 시 회의 전체에 걸쳐 화자 ID의 일관성을 유지하면서 타임스탬프가 포함된 화자 귀속 전사(speaker-attributed transcript)를 생성하는 것이 어렵다.
- **기존 방법:** 기존 Speech-LLM 시스템은 로컬 다이어리제이션 또는 글로벌 라벨링 중 하나에 편향되어, 세밀한 시간 경계(temporal boundary)와 견고한 교차 청크 화자 ID 연결(cross-chunk identity linking)을 동시에 달성하지 못했다.
- **제안 방법:** 캐시 조건부 화자 추적 모듈(cache-conditioned speaker-tracking module)과 Speech-LLM 전사 백본을 결합한 end-to-end 프레임워크. 추적기가 시간 기반(temporal grounding) 구조화된 화자 단서를 제공하고, LLM이 이를 조건으로 화자 귀속 텍스트를 생성.
- **핵심 차별점:** 컴포넌트별 최적화와 end-to-end 공동 학습을 모두 지원하여, 이질적 감독(heterogeneous supervision)과 도메인 전이(domain shift) 조건에서도 유연한 학습 가능. 캐시 메커니즘으로 긴 회의에서도 화자 일관성 유지.
- **실험 결과:** 다자간 회의 시나리오에서 기존 Speech-LLM 기반 SA-ASR 대비 화자 귀속 정확도와 시간 경계 정밀도에서 개선을 달성.
- **우리 연구 관련도:** ★☆☆ — 화자 추적 + LLM 결합이 주요 기여. 캐시 기반 글로벌 추적 메커니즘은 시퀀스 표현 학습 관점에서 참고할 수 있으나, speech SSL/VQ와의 직접적 연관은 제한적.

## 2. SpeechLLM (Speech Language Model)

### 2.1 Audio Interaction Model

**[Audio Interaction Model]** (Zhifei Xie, Zihang Liu, Ze An, Xiaobin Hu, Yue Liao, Ziyang Ma, Dongchao Yang, Mingbao Lin, Deheng Ye, Shuicheng Yan, Chunyan Miao, 2026.06) — arXiv preprint

- **arxiv URL:** https://arxiv.org/abs/2606.05121
- **기존 문제:** 현재의 대규모 오디오 언어 모델(LALM)은 오프라인 방식으로 동작하여, 실시간 오디오 스트림에서 지속적으로 듣고 즉각 반응하는 상호작용이 불가능했다.
- **기존 방법:** 기존 LALM은 오디오 전체를 입력받은 후 처리하는 오프라인 추론 방식으로 설계되어, 스트리밍 환경에서의 실시간 대화, 응답 타이밍 결정, 장시간 스트림 처리에 한계가 있었다.
- **제안 방법:** 항상 켜진(always-on) 인지-판단-응답(perceive-decide-respond) 루프를 형식화하고, 이를 구현하는 Audio-Interaction 모델을 제안. SoundFlow 프레임워크를 통해 스트리밍 네이티브 데이터 구축, 이해 인지(comprehension-aware) 학습, 비동기 저지연 추론까지 end-to-end로 파이프라인 구성.
- **핵심 차별점:** 오프라인 태스크 수행 능력을 유지하면서 온라인 범용 오디오 지시 따르기(대화, 음성 채팅)를 추가. 스트림 의미론(semantics)에 기반하여 응답 시점을 자율적으로 결정하는 comprehension-grounded response triggering.
- **실험 결과:** 주류 오디오 태스크에서 기존 오프라인 모델과 경쟁적 성능을 유지하면서, 오프라인 LALM이 수행할 수 없는 이해 기반 응답 트리거링, 장시간 스트림 상호작용, 사전 능동 지원(proactive assistance) 기능을 달성.
- **우리 연구 관련도:** ★★☆ — 실시간 스트리밍 오디오 이해를 위한 표현 처리 방식(comprehension-aware training)은 temporal representation 학습 관점에서 참고할 수 있음. 스트리밍 환경에서의 음성 표현 활용이 prediction-free SSL 연구의 응용 방향에 시사점 제공.

### 2.2 STITCH: Simultaneous Thinking and Talking with Chunked Reasoning for Spoken Language Models

**[STITCH]** (Cheng-Han Chiang, Xiaofei Wang, Linjie Li, Chung-Ching Lin, Kevin Lin, Shujie Liu, Zhendong Wang, Zhengyuan Yang, Hung-yi Lee, Lijuan Wang — NTU / Microsoft, 2025.07) — arXiv preprint

- **arxiv URL:** https://arxiv.org/abs/2507.15375
- **기존 문제:** 현재 음성 언어 모델(SLM)은 응답하기 전에 내부적으로 비발화(unspoken) 사고 과정을 수행할 수 없어, 수학적 추론 등 복잡한 과제에서 성능이 제한된다.
- **기존 방법:** 텍스트 LLM에서는 Chain-of-Thought(CoT) 추론이 효과적이지만, SLM에서 CoT를 적용하면 사고 토큰 생성에 따른 추가 지연 시간이 발생하여 실시간 음성 대화에 적합하지 않았다.
- **제안 방법:** 비발화 추론 청크와 발화 응답 청크를 교대로 생성하는 STITCH 방식을 제안. 핵심 관찰: 음성 청크의 오디오 재생 시간이 해당 토큰 생성 시간보다 훨씬 길다. STITCH-R은 이 시간 차이를 활용하여, 오디오가 재생되는 동안 남는 시간에 다음 청크를 위한 추론 토큰을 생성.
- **핵심 차별점:** CoT 추론을 추가하면서도 CoT를 사용하지 않는 베이스라인과 동일한 지연 시간을 유지. 오디오 재생 시간과 토큰 생성 시간의 비대칭성을 체계적으로 활용한 최초의 접근.
- **실험 결과:** 수학 추론 데이터셋에서 CoT 미사용 베이스라인 대비 15% 성능 향상을 달성하면서 동일한 지연 시간 유지. 비추론 데이터셋에서도 베이스라인과 동등한 성능 유지.
- **우리 연구 관련도:** ★☆☆ — SLM의 추론 능력 향상이 주요 기여. 음성-텍스트 간 시간 비대칭성 활용은 흥미로우나, speech SSL/VQ 표현 학습과의 직접적 연관은 제한적.

### 2.3 WavAlign: Enhancing Intelligence and Expressiveness in Spoken Dialogue Models via Adaptive Hybrid Post-Training

**[WavAlign]** (Yifu Chen, Shengpeng Ji, Qian Chen, Tianle Liang, Yangzhuo Li, Ziqing Wang, Wen Wang, Jingyu Lu, Haoxiao Wang, Xueyi Pu, Fan Zhuo, Zhou Zhao — Zhejiang Univ / Alibaba / BIT, 2026.04) — arXiv preprint

- **arxiv URL:** https://arxiv.org/abs/2604.14932
- **기존 문제:** End-to-end 음성 대화 모델에 강화학습(RL) 기반 후학습(post-training)을 적용할 때, 선호도(preference) 업데이트가 의미적 신호를 희석시키고 음향적 표류(acoustic drift)를 유발하는 최적화 불일치 문제가 존재했다.
- **기존 방법:** 기존 오픈소스 음성 대화 모델은 SFT(Supervised Fine-Tuning) 중심으로 학습되어, 지능(intelligence)과 표현력(expressiveness) 모두에서 부족. 텍스트 LLM에서 성공적인 RLHF를 음성 모달리티에 직접 적용하면 의미와 음향 간 간섭이 발생.
- **제안 방법:** 모달리티 인지 적응적 후학습(modality-aware adaptive post-training) 레시피를 제안. 선호도 업데이트를 의미 채널에 제한하고, 명시적 앵커링(explicit anchoring)으로 음향 행동을 개선하며, 롤아웃 통계로부터 두 요소의 혼합 비율을 동적으로 조절하여 불안정한 선호도 그래디언트를 회피.
- **핵심 차별점:** 의미적 품질과 음성 표현력을 동시에 개선하는 최초의 적응적 하이브리드 후학습 방법. 단순히 RL을 적용하는 것이 아니라, 의미-음향 채널을 분리하여 각각에 적합한 최적화 전략을 적용.
- **실험 결과:** 다양한 음성 대화 벤치마크와 대표적 아키텍처에서 의미적 품질과 음성 표현력 모두에서 일관된 개선 달성.
- **우리 연구 관련도:** ★★☆ — 의미-음향 채널 분리 및 모달리티 인지 최적화는 음성 표현 학습에서의 정보 분리(disentanglement) 연구와 개념적으로 관련. 특히 음성 표현의 의미적/음향적 요소 분리는 VQ 기반 표현 설계에 시사점 제공.

## 3. Speech Foundation Model

### 3.1 SpidR: Learning Fast and Stable Linguistic Units for Spoken Language Models Without Supervision

**[SpidR]** (Maxime Poli, Mahi Luthra, Youssef Benchekroun, Yosuke Higuchi, Martin Gleize, Jiayi Shen, Robin Algayres, Yu-An Chung, Mido Assran, Juan Pino, Emmanuel Dupoux — Meta / FAIR, 2025.12) — TMLR (Transactions on Machine Learning Research)

- **arxiv URL:** https://arxiv.org/abs/2512.20308
- **기존 문제:** 자기지도(self-supervised) 음성 표현 모델이 텍스트 없는(textless) 음성 언어 모델링에 사용될 때, 추출된 이산 유닛의 음소 정보 접근성과 학습 안정성이 충분하지 않아 하위 언어 모델링 성능이 제한되었다.
- **기존 방법:** wav2vec 2.0, HuBERT, WavLM, DinoSR 등 기존 SSL 모델은 마스크 예측(masked prediction) 또는 대조 학습(contrastive learning)으로 학습되었으나, 하위 spoken language modeling 벤치마크에서의 음소 정보 접근성이 최적화되지 않았다.
- **제안 방법:** 원시 파형에서 마스크 예측 목적 함수(masked prediction objective)와 자기 증류(self-distillation) 및 온라인 클러스터링(online clustering)을 결합하여 학습. 학생 모델의 중간 레이어가 교사 모델의 중간 레이어로부터 유도된 클러스터 할당을 예측하도록 설계.
- **핵심 차별점:** 중간 레이어의 자기 증류 + 온라인 클러스터링 조합으로, 음소 정보에 대한 접근성이 높은(phonetically accessible) 표현을 효율적으로 학습. 별도의 이산화(discretization) 후처리 없이도 높은 품질의 언어적 유닛을 직접 생성.
- **실험 결과:** sWUGGY, sBLIMP, tSC 등 하위 언어 모델링 벤치마크에서 wav2vec 2.0, HuBERT, WavLM, DinoSR을 일관되게 능가.
- **우리 연구 관련도:** ★★★ — 자기 증류 + 온라인 클러스터링을 통한 음성 SSL이 핵심이며, prediction-free SSL 및 VQ 기반 표현 학습과 직접적으로 관련. 중간 레이어 타겟 설정과 클러스터링 전략은 temporal contrastive learning 연구에도 참고 가치가 높음.

### 3.2 Codec2Vec: Self-Supervised Speech Representation Learning Using Neural Speech Codecs

**[Codec2Vec]** (Wei-Cheng Tseng, David Harwath — UT Austin, 2025.11) — ASRU 2025

- **arxiv URL:** https://arxiv.org/abs/2511.16639
- **기존 문제:** 기존 음성 SSL 모델(HuBERT, wav2vec 2.0 등)은 연속 파형을 직접 입력으로 사용하여, 대규모 데이터 저장/전송 비용이 높고 학습 속도가 느리며, 원시 오디오 보관에 따른 프라이버시 문제도 존재했다.
- **기존 방법:** 연속 파형 기반 SSL은 원시 오디오를 저장하고 실시간으로 특징을 추출해야 하므로, 저장 공간과 학습 시간이 선형적으로 증가. 코덱 기반 이산 표현을 SSL의 입력으로 활용하는 시도는 없었다.
- **제안 방법:** 뉴럴 오디오 코덱(neural audio codec)의 이산 유닛만을 입력으로 사용하는 최초의 음성 표현 학습 프레임워크. 3단계 파이프라인: (1) 사전학습 데이터에 대해 이산 코덱 유닛 사전 계산, (2) 마스크 예측 기반 SSL 사전학습, (3) 이산화된 입력으로 경량 다운스트림 모듈 미세조정.
- **핵심 차별점:** 연속 파형 대신 이산 코덱 유닛을 입력으로 사용함으로써 입력 모달리티의 근본적 전환. 원시 오디오 저장 없이도 학습 가능하여 프라이버시와 확장성 동시 개선.
- **실험 결과:** SUPERB 벤치마크에서 연속 입력 모델과 경쟁적 성능을 달성하면서, 저장 요구량 최대 16.5배 감소, 학습 시간 2.3배 단축.
- **우리 연구 관련도:** ★★★ — 이산 코덱 유닛 기반 SSL이라는 점에서 VQ 기반 표현 학습과 직접적으로 관련. 코덱 토큰을 SSL 입력으로 활용하는 패러다임은 prediction-free SSL 설계에 대안적 관점을 제공하며, speech tokenizer 연구와도 밀접하게 연결.

### 3.3 Kanade: A Simple Disentangled Tokenizer for Spoken Language Modeling

**[Kanade]** (Zhijie Huang, Stephen McIntosh, Daisuke Saito, Nobuaki Minematsu — University of Tokyo, 2026.01) — arXiv preprint

- **arxiv URL:** https://arxiv.org/abs/2602.00594
- **기존 문제:** 음성 토크나이저는 음소와 운율 정보를 추출하면서 화자 정체성 같은 언어적으로 무관한 정보를 억제해야 하지만, 기존 이산 코덱들은 화자 정보의 완전한 분리가 어렵거나 보조적 방법(auxiliary methods)에 의존했다.
- **기존 방법:** 기존 분리(disentangled) 코덱은 별도의 화자 인코더, 적대적 학습(adversarial training), 또는 다중 스트림 구조를 사용하여 화자 정보를 분리했으나, 구조가 복잡하고 분리 품질이 불완전했다.
- **제안 방법:** 단일 레이어 분리 음성 토크나이저로, 좁은 정보 병목(narrow information bottleneck)만으로 보조적 방법 없이 깨끗한 비지도 분리(unsupervised disentanglement)를 달성. 음향 상수(acoustic constants)를 분리하여 풍부한 음소와 운율을 포착하는 단일 토큰 스트림 생성.
- **핵심 차별점:** 600시간 데이터와 120M 비동결 파라미터만으로 학습 가능한 극도의 경량성. 보조적 방법 없이 정보 병목만으로 SOTA 수준의 화자 분리를 달성하는 단순하면서도 효과적인 설계.
- **실험 결과:** 코덱 모델 중 화자 분리(voice conversion, discrimination 태스크 기준)와 어휘 접근성(ASR, TTS 다운스트림 기준) 모두에서 SOTA 달성.
- **우리 연구 관련도:** ★★★ — 정보 병목 기반 비지도 분리 토크나이저라는 점에서 VQ 기반 표현 학습 및 speech tokenizer 연구와 직접적으로 관련. 화자-언어 정보 분리 방법론은 temporal contrastive learning에서의 정보 선택적 인코딩 설계에 핵심적 참고 자료.
