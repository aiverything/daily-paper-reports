## 1. ASR (Automatic Speech Recognition)

### 1-1. DiaScriber: A Speech LLM for Joint Diarization and Transcription in Multi-Speaker Scenarios

**[DiaScriber] (Bingshen Mu et al., 2026.08)** — arXiv preprint
- https://arxiv.org/abs/2608.22796
- **기존 문제:** 다화자 자동 음성 인식(MSASR)은 "누가, 무엇을, 언제 말했는가"를 동시에 예측해야 하지만, 빠른 턴 전환(fast turn transitions), 중첩 발화(overlapping speech), 복잡하고 다양한 다화자 시나리오에서 여전히 상당한 어려움에 직면
- **기존 방법:** 파이프라인 기반 접근(분리된 화자 분할 + ASR 모듈)이나, 기존 엔드투엔드 모델들은 제한된 시나리오에서만 학습되어 실제 환경의 다양한 다화자 상황(다수 화자, 다양한 중첩 비율, 빠른 턴 전환)에 대한 일반화가 부족
- **제안 방법:** DiaScriber — 사전훈련된 Qwen3.5-Omni 기반 엔드투엔드 다화자 분할+전사 모델. 다양한 데이터 파이프라인(검증·정제, 턴 전환 및 중첩 발화 시뮬레이션, 멀티모달 어노테이션)을 설계하여 광범위한 다화자 시나리오를 커버. 3단계 훈련 전략(지속적 사전훈련 → 지도 미세조정 → 추가 최적화)으로 모델을 점진적으로 특화
- **핵심 차별점:** 대규모 Speech LLM(Qwen3.5-Omni)을 다화자 분할+전사에 최초로 체계적으로 적용. 다양한 다화자 시뮬레이션 데이터 파이프라인을 통해 실제 환경의 복잡한 다화자 시나리오에 대한 강건한 일반화 달성
- **실험 결과:** 빠른 턴 전환, 중첩 발화, 복잡한 다화자 시나리오에서 기존 대비 개선된 분할+전사 성능 달성
- **우리 연구 관련도:** ★★☆ — Speech LLM 기반 다화자 처리 연구. 대규모 사전훈련 음성 모델이 화자 분할과 전사를 동시에 학습하는 방식은 음성 표현의 화자 정보 인코딩 능력과 관련

### 1-2. Mitigating Speaker Leakage in Cascaded Multi-talker ASR with Diarization-based Transcript Correction

**[Speaker Leakage Mitigation] (Hermann Yepdjio Nkouanga, Minwei Luo, Maggie Wigness, Suresh Singh, 2026.08)** — Interspeech 2026 accepted
- https://arxiv.org/abs/2608.22196
- **기존 문제:** 캐스케이드 방식의 다화자 ASR(MT-ASR)에서 음성 분리(separation) 단계의 화자 누출(speaker leakage)이 최종 전사 성능의 상한을 제한. 분리된 스트림에 다른 화자의 음성이 잔존하여 잘못된 전사 세그먼트가 생성됨
- **기존 방법:** 기존 보정 전략은 주로 어휘적 재라벨링(lexical re-labeling)에 초점을 맞춰 화자 귀속(speaker attribution)만 수정하며, 누출 아티팩트 자체를 제거하지 못함
- **제안 방법:** 가지치기(pruning) 기반 패러다임 — 사전훈련된 화자 분할 모델을 멀티모달 검증기(multimodal verifier)로 활용하여 누출 아티팩트를 식별·제거. 시간적 포함(temporal containment), 어휘적 교차 검증(lexical cross-validation), 시간적 정렬(temporal alignment)의 3중 합의 조건(tripartite consensus)을 충족하는 전사 세그먼트를 가지치기
- **핵심 차별점:** 기존의 재라벨링 기반 접근과 달리, 누출 아티팩트를 직접 제거하는 보완적 접근. 화자 분할 모델을 검증기로 활용한 멀티모달 검증이 누출 판별의 정확성을 크게 향상
- **실험 결과:** LibriMix, LibriSpeechMix, AMI Meeting corpus에서 다양한 중첩 조건에 걸쳐 일관된 cpWER 감소. 높은 화자 누출이 있는 서브셋에서 최대 29%의 상대적 cpWER 감소 달성
- **우리 연구 관련도:** ★☆☆ — 다화자 ASR 후처리 기법. 화자 분할 모델의 표현을 ASR 보정에 활용하는 접근으로, 음성 표현 내 화자 정보 활용의 실용적 응용

### 1-3. Leading-Silence Augmentation and Multi-Stage Synthetic Supervision for the Second MLC-SLM Challenge

**[MLC-SLM Challenge System] (authors, 2026.08)** — arXiv preprint (MLC-SLM Challenge 2 system description)
- https://arxiv.org/abs/2608.14150
- **기존 문제:** 제2회 다국어 대화 음성 언어 모델(MLC-SLM) 챌린지는 비분절(unsegmented) 다국어 대화 전체에 대해 화자 분할+인식(Task 1)과 대화 음성 이해(Task 2)를 평가하며, 두 태스크 모두 평가 시 오라클 발화 경계나 화자 라벨이 제공되지 않음
- **기존 방법:** 기존 ASR 모델은 깔끔하게 분절된 발화를 가정하며, 실제 대화에서의 발화 시작점 불확실성이나 선행 침묵(leading silence)에 대한 강건성이 부족. Task 2의 경우 질의응답 훈련 데이터가 제공되지 않아 지도 학습이 불가능
- **제안 방법:** Task 1 — VibeVoice-ASR-7B를 무작위 선행 침묵 자르기(random leading-silence cropping), 일관된 타임스탬프 보정, 지수 이동 평균(EMA) 훈련 전략으로 미세조정. Task 2 — 멀티모달 후보 생성, 무음 오디오 필터링, 분포 매칭 증강을 통한 합성 질의응답 쌍 구축 후 Qwen3-Omni-30B-A3B-Instruct 미세조정
- **핵심 차별점:** 선행 침묵 무작위 자르기라는 간단하면서 효과적인 데이터 증강으로 실제 대화 환경의 발화 경계 불확실성에 대한 강건성 확보. Task 2에서 합성 데이터 파이프라인으로 제로샷 조건 극복
- **실험 결과:** Task 1 평가 세트에서 선행 침묵 자르기로 tcpMER 18.30% → 17.27% 감소, EMA 추가로 16.73%까지 개선
- **우리 연구 관련도:** ★☆☆ — 대규모 Speech LLM의 실제 대화 시나리오 적용 연구. 데이터 증강 전략이 ASR 강건성에 미치는 영향 분석

## 2. SpeechLLM (Speech Language Model)

### 2-1. Efficient Chain-of-Modality Reasoning via Progressive Compression for Spoken Language Models

**[ECoM Reasoning] (Pengchao Feng, Chao-Hong Tan, Qian Chen, Wen Wang, Xiangang Li, Xie Chen, 2026.07)** — arXiv preprint
- https://arxiv.org/abs/2607.19932
- **기존 문제:** 음성 언어 모델(SLM)은 자연스러운 인간-컴퓨터 상호작용을 가능케 하지만, 특히 음성 수학 질의응답 등 추론 태스크에서 텍스트 기반 LLM 대비 추론 능력이 크게 뒤처짐. SLM이 수학 표현을 순전히 구어화된(verbalized) 형태로 처리해야 하므로 기호적 텍스트보다 해석이 어려움
- **기존 방법:** Chain-of-Modality(CoM) 아키텍처 — SLM이 먼저 음성으로부터 중간 텍스트를 생성한 후 음성 응답을 생성. 그러나 텍스트 생성 단계의 토큰 예산이 크고, 음성 안내(speech guidance)와 추론 표현(reasoning representation)이 분리되어 효율성이 낮음
- **제안 방법:** Efficient Chain-of-Modality Reasoning(ECoM Reasoning) — SLM에 최초로 압축 추론(compressed reasoning)을 도입. 텍스트 구성 요소를 압축하여 음성 안내와 추론 표현의 이중 역할을 동시에 수행하도록 설계. 점진적 압축(progressive compression)을 통해 토큰 예산을 줄이면서 추론 정확도를 유지
- **핵심 차별점:** SLM에 압축 추론을 최초로 적용한 프레임워크. 표준 CoM 대비 더 적은 토큰 예산으로 더 높은 추론 정확도 달성. 텍스트 단계를 압축하면서도 음성 안내 역할을 보존
- **실험 결과:** 표준 CoM 아키텍처 대비 음성 수학 QA 태스크에서 추론 정확도 향상과 동시에 토큰 예산 절감 달성
- **우리 연구 관련도:** ★★☆ — 음성 언어 모델의 추론 능력 강화 연구. 음성-텍스트 모달리티 간 압축 표현 학습은 음성 표현의 정보 밀도와 효율성 설계에 시사점 제공

### 2-2. Multilingual Emotion Neurons in Large Audio-Language Models

**[MLENs] (Xiutian Zhao, Philipp Koehn, Björn Schuller, Berrak Sisman — JHU CLSP / Imperial College London, 2026.08)** — arXiv preprint
- https://arxiv.org/abs/2608.08772
- **기존 문제:** 대규모 오디오-언어 모델(LALM)은 다국어 음성 태스크에서 강력한 성능을 달성하지만, 감정을 언어별 상관관계(language-specific correlations)로 인코딩하는지, 아니면 언어 불변(language-agnostic) 표현으로 인코딩하는지 불분명
- **기존 방법:** 단일 언어 기반 감정 뉴런 분석 — 각 언어별로 독립적으로 감정에 민감한 뉴런을 식별하지만, 언어 간 뉴런 중첩(overlap)이 거의 없어 교차언어 전이가 제한적. 인과적 개입(causal intervention) 분석도 단일언어 뉴런 집합에 국한
- **제안 방법:** Multilingual Emotion Neurons(MLENs) 정의 — 언어를 초월하여 안정적인 감정 선택성(emotional selectivity)과 정렬된 인과적 효과를 보이는 기능적 단위. Consistency-Regularized Fusion(CR-Fusion) 방법으로 MLENs를 식별
- **핵심 차별점:** 다국어 감정 뉴런이라는 개념을 최초로 정의하고 식별하는 체계적 프레임워크 제시. CR-Fusion으로 식별된 MLENs가 단일언어 뉴런 집합 대비 더 정밀하고 전이 가능한 감정 제어 달성
- **실험 결과:** 4개 최신 LALM과 12개 유형적으로 다양한 언어에 걸쳐, CR-Fusion 기반 MLENs가 제로샷 및 저자원 환경에서 단일언어 뉴런 대비 우수한 감정 전이 성능. Leave-one-out 절제 실험에서 저자원 언어가 교차언어 전이로부터 가장 큰 혜택을 받음을 확인
- **우리 연구 관련도:** ★★☆ — LALM 내부 표현의 해석가능성(interpretability) 연구. 음성 모델이 감정 정보를 어떻게 인코딩하는지에 대한 뉴런 수준의 분석은 음성 표현 학습의 메커니즘 이해에 기여

## 3. Speech Foundation Model

### 3-1. SemBridge: Semantic Token Anchoring for Continuous-Latent Autoregressive Speech Generation

**[SemBridge] (Hanke Xie, Haopeng Lin, Jiale Qian, Dake Guo, Yuepeng Jiang et al., 2026.08)** — arXiv preprint
- https://arxiv.org/abs/2608.07462
- **기존 문제:** 연속 잠재(continuous-latent) 자기회귀 음성 생성은 양자화 손실을 회피하여 더 풍부한 음향 정보를 보존하지만, 연속 음향 타겟은 언어적 구조를 명시적 토큰 수준 예측 타겟으로 노출하지 않아 생성 음성의 콘텐츠 충실도(content fidelity)가 저하될 수 있음
- **기존 방법:** 이산 토큰 기반 자기회귀 모델은 명시적 토큰 예측을 통해 언어적 구조를 직접 학습하나 양자화 정보 손실 발생. 연속 잠재 모델은 음향 품질은 우수하나 언어적 감독 부재로 콘텐츠 오류(삽입, 삭제, 치환) 발생
- **제안 방법:** SemBridge — 훈련 전용(training-only) 의미 토큰 앵커링 프레임워크. (1) 이산 의미 토큰(discrete semantic tokens)으로 자기회귀 LM 상태를 직접 감독, (2) Semantic-Aligned Acoustic VAE로 연속 타겟 공간을 동일한 의미적 참조 하에 구성. 추론 시에는 순수 연속 방식으로 동작하여 양자화 손실 없이 언어적 정확성 확보
- **핵심 차별점:** 훈련 시에만 이산 의미 토큰을 활용하고 추론은 완전 연속 — 이산과 연속의 장점을 모두 취하는 설계. 의미적 정렬된 VAE가 연속 공간에서도 언어적 구조를 유지
- **실험 결과:** 기존 연속 잠재 자기회귀 모델 대비 콘텐츠 충실도(intelligibility)와 음향 품질 모두에서 개선
- **우리 연구 관련도:** ★★★ — 이산 의미 토큰과 연속 음향 표현의 관계를 직접적으로 탐구한 연구. VQ-based representation과 연속 표현 간의 정보 보존-예측 가능성 트레이드오프를 다루며, speech tokenizer 설계에 핵심적 시사점 제공

### 3-2. Evaluating Pre-trained Speech Encoders for Spontaneous Speech Detection and Out-of-Domain Synthetic Speech Generalisation in Indic Languages

**[Speech Encoder Evaluation] (Varun Rai, Pavan Kumar J, Sujith Pulikodan, Nihar Desai, 2026.08)** — arXiv preprint
- https://arxiv.org/abs/2608.12536
- **기존 문제:** 트랜스포머 기반 사전훈련 음성 인코더가 자발적 음성(spontaneous speech) 대 스크립트 음성, 자연 음성 대 합성 음성 판별에서 강력한 성능을 보이지만, 이러한 결과는 소수의 고자원 언어 벤치마크에서만 확인되었고, 인도 제어 언어들(Indic languages)로의 확장이나 임베딩 기하학(embedding geometry)을 통한 인코더 행동 설명은 부재
- **기존 방법:** 개별 사전훈련 인코더를 단일 언어·단일 태스크에서 평가하는 방식으로, 다국어 환경에서의 인코더 표현 특성이나 도메인 외(out-of-domain) 일반화 메커니즘에 대한 체계적 분석이 부족
- **제안 방법:** 5개 프로즌 트랜스포머 인코더(AST, Vaani-FastConformer, Wav2vec2, Whisper, BEATs)를 22개 인도 제어 언어에 걸쳐 평가. 정확도 너머 언어 격리 프로빙(language isolation probing)과 중심점 근접도 분석(centroid proximity analysis)을 수행하여 인코더 표현의 내부 구조를 분석
- **핵심 차별점:** 인코더별 언어 판별성(language-discriminability)과 자발성 탐지(spontaneity detection) 간 트레이드오프를 최초로 발견. 도메인 외 일반화가 자연 음성과의 거리가 아닌, 훈련 시스템의 미관측 합성 임베딩과의 근접도에 의해 예측됨을 실증
- **실험 결과:** 22개 인도 제어 언어와 4개 TTS 시스템에 걸친 다중 시스템 실험에서, 언어 프로빙이 인코더 의존적 트레이드오프를 드러냄. 중심점 분석에서 도메인 외 일반화는 훈련 시스템의 미관측 TTS 임베딩 근접도로 예측 가능
- **우리 연구 관련도:** ★★☆ — 사전훈련 음성 인코더의 표현 분석 연구. 다양한 SSL/지도학습 인코더의 임베딩 공간 구조를 비교 분석하여, 각 사전훈련 방법이 어떤 정보를 인코딩하는지에 대한 통찰 제공. 음성 표현 학습의 설계 선택에 참고 가치
