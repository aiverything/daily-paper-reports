## 1. ASR (Automatic Speech Recognition)

---

**[Merging the Knowledge of LLMs for Automatic Speech Recognition] (Hayato Futami, Tatsuya Kawahara, 2026-09-14)** — arxiv preprint

- https://arxiv.org/abs/2609.15743
- **기존 문제:** LLM 기반 ASR 모델의 도메인 적응 시, 외부 언어 모델(LM)을 활용하면 디코딩 시 추가 연산 비용이 발생한다. 특히 최근 대형 LM을 사용하면 shallow fusion 등의 전통적 LM 융합 방식의 연산 부담이 크게 증가한다.
- **기존 방법:** Shallow fusion, density ratio 등의 방법으로 디코딩 시 외부 LM을 결합하여 ASR 성능을 개선했으나, 추론 시 LM 추가 연산이 필수적이었다.
- **제안 방법:** 모델 머징(model merging)을 통해 외부 LM의 지식을 LLM 기반 ASR 모델의 LoRA 파라미터에 직접 통합한다. LoRA 파라미터에 대한 산술 연산(arithmetic operations)으로 도메인 확장 및 전이를 공식화한다.
- **핵심 차별점:** 추론 시 추가 연산 비용 없이 LM의 도메인 지식을 ASR 모델에 내재화한다. 메모리 사용량과 추론 속도에 영향 없이 도메인 적응이 가능하다.
- **실험 결과:** CSJ 및 LibriSpeech로 학습한 LLM 기반 ASR에 대해 도메인 적응 실험을 수행. LM 머징이 타겟 도메인에서 일관되게 ASR 성능을 개선하며, 추론 속도와 메모리 사용량에 영향을 주지 않음을 확인.
- **우리 연구 관련도:** ★☆☆ — LLM 파라미터 수준의 지식 통합 기법으로, prediction-free SSL이나 VQ-based representation과는 직접적 관련이 적다.

**[Token Merging for Multilingual Speech Recognition: A Systematic Study Across Model Scale and Fine-Tuning] (Dylan Luke Holyoak, 2026-07-07)** — arxiv preprint

- https://arxiv.org/abs/2609.13151
- **기존 문제:** Whisper 등 대규모 다국어 ASR 모델은 높은 성능을 보이지만 연산 비용이 크다. 특히 저자원 언어 환경에서 효율적 배포가 어렵다.
- **기존 방법:** 모델 경량화를 위해 pruning, distillation, quantization 등의 기법이 적용되었으나, 추가 학습이 필요하거나 다국어 환경에서의 체계적 분석이 부족했다.
- **제안 방법:** Token merging을 Whisper 모델에 적용하여, 추론 시 중복된 특징을 동적으로 결합해 시퀀스 길이를 줄인다. 재학습 없이 바로 적용 가능하다.
- **핵심 차별점:** 16개 다국어, 3개 모델 스케일에 걸친 체계적 평가를 수행. DoRA 파인튜닝 이후에도 token merging이 효과적으로 동작함을 증명.
- **실험 결과:** 대부분의 저자원 언어와 모델 크기에서 전사 정확도 손실이 거의 없이 연산 효율성이 향상됨. 파인튜닝 후에도 효과가 유지되어 실용적 배포 방법으로 입증.
- **우리 연구 관련도:** ★☆☆ — 추론 효율화 기법으로, speech representation 연구보다는 모델 경량화에 초점이 있다.

**[CTC-Seeded Token Edit Refinement for Non-Autoregressive Speech Recognition] (Wanting Huang, Weiran Wang, 2026-06-27)** — arxiv preprint

- https://arxiv.org/abs/2606.28732
- **기존 문제:** 자기회귀(autoregressive) ASR 디코딩은 순차적 특성으로 인해 지연시간이 크다. 비자기회귀(non-autoregressive, NAR) 방식이 병렬 디코딩을 가능하게 하지만 성능 열위가 존재했다.
- **기존 방법:** Mask-CTC, CASS-NAT 등의 NAR ASR 방법이 제안되었으나, 고정 길이 가정이나 반복적 마스킹에 의존하여 유연성이 부족했다.
- **제안 방법:** ASR 디코딩을 CTC greedy 가설에 대한 가변 길이 편집 정제(edit refinement)로 공식화. 음향 조건부 Edit Flow 디코더가 축약된 CTC 가설에 대해 삽입, 삭제, 치환 연산을 병렬로 예측한다. CTC 모델과 연속 시간 이산 확산(continuous-time discrete diffusion) 손실로 공동 학습된다.
- **핵심 차별점:** 단 2번의 편집 단계만으로 상당한 WER 감소를 달성. Classifier-free guidance(CFG)로 추가 성능 향상을 이끌어 NAR ASR의 새로운 패러다임을 제시.
- **실험 결과:** LibriSpeech test-clean/test-other에서 ESPnet 인코더 기준 WER 3.5/7.9 → 2.6/5.8 (상대 25.7%/26.6% 감소), Whisper medium 인코더 기준 2.6/6.1 → 2.0/4.7 (상대 23.1%/23.0% 감소).
- **우리 연구 관련도:** ★☆☆ — 확산 기반 디코딩 기법으로, prediction-free SSL/VQ 연구와 직접적 관련은 적으나 discrete diffusion 접근이 참고가 될 수 있다.

## 2. SpeechLLM (Speech Language Model / Spoken Dialogue)

---

**[VoxMind: An End-to-End Agentic Spoken Dialogue System] (MM-Speech team, 2026-04-22)** — ACL 2026 accepted

- https://arxiv.org/abs/2604.15710
- **기존 문제:** 기존 음성 대화 모델은 외부 도구 호출(tool use)과 에이전트 기능이 결여되어 있다. 도구 통합 시 대규모 도구 풀로 인한 지연시간 병목이 발생한다.
- **기존 방법:** 캐스케이드 파이프라인(ASR→LLM→TTS)으로 에이전트 기능을 구현했으나, 비차별적이고 음성 고유 정보(감정, 화자 등)가 손실되었다.
- **제안 방법:** Think-before-Speak 패러다임을 중심으로, 모델이 응답 생성 전에 구조화된 추론을 내재화한다. Multi-Agent Dynamic Tool Management 아키텍처로 도구 검색을 보조 에이전트에 비동기적으로 위임하여 지연시간을 줄인다. 470시간 AgentChat 데이터셋을 구축하여 학습.
- **핵심 차별점:** 종단간(end-to-end) 음성 대화 모델에 에이전트 능력을 통합한 최초의 프레임워크. 추론-발화 분리와 비동기 도구 관리로 실용적 에이전트 음성 시스템을 구현.
- **실험 결과:** 강력한 베이스라인 대비 태스크 완수율 34.88% → 74.57%로 향상. 음성 에이전트 태스크에서 Gemini-2.5-Pro를 능가하면서 일반 대화 품질도 유지.
- **우리 연구 관련도:** ★☆☆ — 에이전트 음성 대화 시스템으로, speech SSL/VQ 연구와는 다른 방향이나 speech tokenizer를 활용한 종단간 모델 관점에서 참고 가능.

**[IRAF: Interference-Resilient Adaptive Fusion for Noise-Robust End-to-End Full-Duplex Spoken Dialogue Systems] (Tao Zhong et al., CUHK/Huawei/NTU, 2026-06-04)** — arxiv preprint

- https://arxiv.org/abs/2606.06559
- **기존 문제:** 전이중(full-duplex) 음성 대화 모델에서 사용자 마이크에 간섭 화자가 유입되면 사용자 쿼리가 오염되어 턴테이킹 불안정과 응답 품질 저하가 발생한다.
- **기존 방법:** 이중 채널 종단간 모델이 사용자와 에이전트 스트림을 동시 인코딩하지만, 현실적 음향 환경에서의 간섭에 대한 대응이 부족했다.
- **제안 방법:** IRAF는 경량 스트리밍 호환 모듈로, 프레임 단위로 사용자 오디오의 LLM 기여도를 조절한다. 타겟 화자와 사용자 오디오 임베딩에서 스칼라 신뢰도 게이트를 예측하고, 에이전트 임베딩과 융합 전에 사용자 표현을 재스케일링한다.
- **핵심 차별점:** 간섭 화자 조건에서 스트리밍 호환성을 유지하면서 풀듀플렉스 대화 품질을 향상시키는 최초의 프레임별 적응형 융합 기법.
- **실험 결과:** MS-MARCO 및 InstructS2S-200K 데이터셋에서 간섭 화자 조건 하 응답 품질과 전이중 상호작용에서 일관된 성능 향상을 확인.
- **우리 연구 관련도:** ★☆☆ — 음성 대화 시스템의 노이즈 강건성에 초점이 있어 speech SSL/VQ 연구와는 거리가 있다.

## 3. Speech Foundation Model (SSL / Tokenizer / Representation Learning)

---

**[TokenMapper: A Step Toward Interoperable Speech Token Translation] (Tal Kozakov, Tal Rosenwein, Eliya Nachmani, Ben-Gurion University, 2026-09-11)** — AACL-IJCNLP 2026 findings accepted

- https://arxiv.org/abs/2609.12563
- **기존 문제:** 뉴럴 오디오 코덱들은 서로 다른 어휘와 코드북 구조를 가지며, 모델 간 직접 통신이 불가능하다. 시스템 간 토큰 전달 시 파형 디코딩 후 재토큰화하는 과정이 필요하여 지연시간과 정보 손실이 발생한다.
- **기존 방법:** 소스 측 파형 합성 후 타겟 측 재토큰화를 거치는 웨이브폼 브릿징(waveform bridging) 방식이 표준이었으나, 지연시간이 크고 왕복 변환에서 정보 손실이 불가피했다.
- **제안 방법:** TokenMapper는 이질적 음성 토크나이저 간 이산 도메인에서의 직접 토큰-투-토큰 변환 프레임워크. 단일 코드북과 다중 코드북(RVQ) 표현 간 구조적 불일치를 지원한다.
- **핵심 차별점:** 파형 합성 및 재토큰화를 완전히 우회하여 오프라인 전송 경로 지연시간을 최대 94.5% 감소. 종단간 지연시간 4.8~94.5% 상대 감소(최대 972ms/발화 절감).
- **실험 결과:** GLM-4-Voice, MiMi, DualCodec 등 다양한 토크나이저 간 매핑 실험에서 웨이브폼 브릿징 대비 일관된 지연시간 감소 및 토큰 변환 품질 확인.
- **우리 연구 관련도:** ★★☆ — VQ-based representation 간 상호 변환 문제를 다루어, VQ 토큰 공간의 구조적 특성 분석과 관련이 있다. 서로 다른 토크나이저의 코드북 구조 비교 관점에서 참고 가치가 있다.

**[From Objectives to Applications: Aligning Architectural Biases in Audio Self-Supervised Learning] (Kele Xu et al., 2026-07-01)** — arxiv preprint

- https://arxiv.org/abs/2607.00387
- **기존 문제:** 오디오 자기지도학습(SSL)에서 사전학습 목적함수, 아키텍처 귀납적 편향, 다운스트림 태스크 간의 정렬(alignment)이 체계적으로 분석되지 않았다.
- **기존 방법:** 기존 연구들은 SSL 방법을 시간순이나 모델 패밀리별로 분류하는 데 그쳤으며, 서로 다른 감독 신호가 학습되는 표현에 어떤 영향을 미치는지에 대한 통합적 분석이 부족했다.
- **제안 방법:** 5가지 패러다임(보조 태스크, 대조학습, 생성적 복원, 이산 토큰 예측, 멀티모달 정렬)으로 오디오 SSL을 재구성하고, 각 패러다임이 모델에 요구하는 바를 분석한다: 국소적 구조 민감도, 대조적 불변성, 맥락적 추론, 이산 의미 추상화, 멀티모달 그라운딩.
- **핵심 차별점:** 프리텍스트 태스크 중심이 아닌, 목적함수-아키텍처-응용의 정렬 관점에서 오디오 SSL을 체계적으로 분석한 최초의 프레임워크.
- **실험 결과:** 각 패러다임별 대표적 방법들의 다운스트림 태스크(음성 인식, 화자 인식, 음향 이벤트 검출 등)에서의 성능을 비교 분석. 응용 목적에 따른 최적 SSL 패러다임 선택 가이드라인을 제시.
- **우리 연구 관련도:** ★★★ — 대조학습(contrastive learning)을 5가지 SSL 패러다임 중 하나로 직접 분석하며, prediction-free 방식과 prediction 기반 방식의 차이를 목적함수 관점에서 논의한다. Temporal contrastive learning 연구의 이론적 토대로 직접 참고 가능.

**[Language Orthogonalization of Self-Supervised Speech Representations for Cross-lingual Parkinson's Detection] (Minu Kim, Eunjung Yeo, Kwanghee Choi, June-Woo Kim, 2026-09-08)** — arxiv preprint

- https://arxiv.org/abs/2609.09499
- **기존 문제:** 자기지도 음성 모델(S3M)의 표현은 파킨슨병 탐지에 유용하지만, 교차 언어 전이 시 표현에 내재된 언어 정체성 정보가 병리 정보와 혼동되어 분류기가 병리 대신 언어를 분리하는 문제가 발생한다.
- **기존 방법:** 단일 언어 내 파킨슨 탐지에 S3M 표현을 직접 활용했으나, 교차 언어 시나리오에서는 언어 정보를 제거하는 체계적 방법이 부재했다.
- **제안 방법:** 언어 직교화(Language Orthogonalization) — VoxLingua107 언어 임베딩에 대한 릿지 잔차화(ridge residualization)를 통해 S3M 특징에서 언어 예측 가능 성분을 제거한다. 건강한 대조군 음성만으로 피팅하여 병리 관련 변이는 보존.
- **핵심 차별점:** 폐쇄형(closed-form) 선형 변환으로 SSL 표현에서 언어 정보만 제거하면서 병리 정보를 유지하는 최초의 접근법. 학습 없이(training-free) SSL 표현 조작이 가능.
- **실험 결과:** 직교화 후 건강 대조군(HC) 표현은 집중되고 파킨슨(PD) 표현은 분산되는 기하학적 구조를 형성하여 교차 언어 파킨슨 탐지 성능 향상.
- **우리 연구 관련도:** ★★☆ — Speech SSL 표현 공간의 구조 분석 및 조작 기법으로, prediction-free SSL 표현이 인코딩하는 정보의 분리(disentanglement) 연구와 직접 관련이 있다. 표현 공간에서 특정 정보를 제거/보존하는 방법론이 참고 가치가 높다.
