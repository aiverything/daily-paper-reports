## 1. ASR (Automatic Speech Recognition)

### **[Xing-Audio-NVVASR: Scaling and Refining Supervision for Joint Recognition of Speech and Non-Verbal Vocalizations] (Pengyu Xu et al., 2026-11-19)** — arxiv preprint

- **arxiv URL**: https://arxiv.org/abs/2611.26000
- **기존 문제**: 음성과 비언어적 발성(Non-Verbal Vocalizations, NVV — 웃음, 호흡, 기침, 울음 등)을 동시에 인식하는 과제에서, NVV가 포함된 학습 데이터가 부족하고 기존 이벤트 레이블의 정확도가 낮거나 누락이 많아 학습이 어려웠음.
- **기존 방법**: NVVSpeech Challenge 시스템들(Long-Tail Rebalancing 등)이 NVV 인식을 시도했으나, 단일 모델로 학습 데이터를 대규모 확보하고 레이블 품질을 반복적으로 개선하는 체계적 파이프라인은 부재했음.
- **제안 방법**: 점진적 데이터 마이닝(progressive data mining)과 반복적 레이블 정제(repeated label refinement)를 결합. 두 개의 이질적 모델이 상호 교차 감사(cross-audit)하여 불일치 구간을 교사 모델로 재레이블링하고, 인간 확인 레이블은 라운드 간 보존. 약 50만 시간의 내부 오디오에서 63만 발화를 점진적으로 마이닝하여 최종 약 80만 발화의 학습 코퍼스를 구축. 1.7B 파라미터 모델이 6개 NVV 클래스에 대한 인라인 태그를 출력.
- **핵심 차별점**: 이중 모델 교차 감사 + 교사 재레이블링이라는 반복적 데이터 품질 개선 루프를 통해 대규모 약한 레이블 데이터를 고품질로 정제. 단순 데이터 양 확대가 아닌 레이블 정확도의 체계적 향상이 핵심.
- **실험 결과**: 4개 인간 주석 벤치마크에서 9개 비교 시스템 중 복합 점수(composite score) 및 6-class Macro-F1 기준 1위 달성 (재레이블링 후 평가 기준). 원본 레퍼런스 기준에서는 Qwen3.5-Omni-Plus가 복합 점수 선두.
- **우리 연구 관련도**: ★☆☆ — NVV 인식 특화 시스템으로 speech SSL과 직접 관련은 낮으나, 이중 모델 교차 감사를 통한 레이블 정제 파이프라인이 대규모 비지도 음성 데이터 활용 방법론에 참고 가능.

### **[Dynamic Block-Online Streaming ASR for Low-Resource Agglutinative Code-Switching Speech with Morphology-Aware Evaluation] (2026-11-11)** — arxiv preprint

- **arxiv URL**: https://arxiv.org/abs/2611.15691
- **기존 문제**: 방글라어-영어 코드스위칭 환경에서의 스트리밍 ASR은 저자원(low-resource)이면서 교착어(agglutinative) 특성까지 겹쳐, 기존 평가 메트릭으로는 형태소 수준의 오류를 정확히 측정하기 어려웠음.
- **기존 방법**: 오프라인 글로벌 어텐션 모델이 높은 정확도를 보였으나, 실시간 배포가 불가능. 기존 스트리밍 ASR은 코드스위칭 + 교착어 조합에 대한 최적화가 부족했으며, 평가도 WER 중심으로 형태소 구조를 반영하지 못했음.
- **제안 방법**: VAD 기반 블록-온라인(block-online) 스트리밍 방식으로 오프라인 글로벌 어텐션 모델을 실시간 배포 가능하도록 변환. 교착어 특성을 반영한 형태소 인식 평가 메트릭(E_root)을 제안하여 어근 수준의 인식 정확도를 별도 측정.
- **핵심 차별점**: 코드스위칭 + 교착어 + 저자원이라는 삼중 과제를 하나의 스트리밍 프레임워크에서 해결하고, 형태소 인식 평가로 기존 WER이 놓치는 오류 유형을 포착.
- **실험 결과**: 스트리밍 모델이 E_root 0.35에서 포화(saturation)하는 구조적 한계가 보고됨. 스트리밍 설정의 구조적 제약이 성능 병목으로 분석됨.
- **우리 연구 관련도**: ★☆☆ — 코드스위칭 스트리밍 ASR 특화 연구로 speech SSL과 직접 관련은 낮으나, 형태소 인식 평가 메트릭 설계가 다국어 음성 표현 평가에 참고 가능.

## 2. SpeechLLM (Speech-Language Model)

### **[DuplexAct: How Interactive Are Frontier Full-Duplex Spoken Language Models?] (Jiaheng Dong, Shihong Tan, Gongping Huang, Jean Honorio, Abhirup Ghosh, Ting Dang, 2026-10)** — arxiv preprint

- **arxiv URL**: https://arxiv.org/abs/2610.17738
- **기존 문제**: 전이중(full-duplex) 음성 언어 모델의 상호작용 능력을 평가하는 기존 벤치마크는 구조화된 행동(action) 수준의 정형화가 부족하고, 행동의 발생 여부만 평가할 뿐 성공 여부를 측정하지 못하며, 실세계 대화의 다양한 시나리오 커버리지가 제한적이었음.
- **기존 방법**: Full-Duplex-Bench, τ-Voice 등 벤치마크가 존재했으나, 행동 분류 체계가 단순하고 발화 조건별 세분화가 부족. 대부분 단일 차원(예: 턴테이킹 정확도)으로만 평가.
- **제안 방법**: 3단계 행동 분류 체계(action taxonomy)를 설계하여 8개 상호작용 행동(interaction action)과 24개 상호작용 조건(interaction condition)을 정의. 일상 대화, 회의, 고객 서비스, 인터뷰를 포함하는 4,691개 테스트 인스턴스를 구축 (그 중 2,531개는 실제 대화 녹음에서 파생).
- **핵심 차별점**: 행동의 발생이 아닌 행동의 성공을 측정하며, 즉각적 행동 이후의 후속 추론(subsequent reasoning) 능력까지 평가. 시나리오별 대화 규범(conversational norms) 적응도를 측정하는 최초의 체계적 벤치마크.
- **실험 결과**: 14개 모델 평가 결과, 행동 공간 전반에서 불균등한 성능 분포를 보임. Wait(94.0%)와 Ignore(75.4%)처럼 모두 침묵을 요구하는 행동에서도 큰 성공률 차이가 존재. 즉각적 행동 이후의 후속 추론 능력이 전반적으로 약하며, 시나리오별 대화 규범 적응도 제한적.
- **우리 연구 관련도**: ★★☆ — 전이중 음성 모델 평가 프레임워크로 speech SSL과 직접 관련은 낮으나, 행동 수준의 정형화된 평가 방법론이 음성 표현의 대화 능력 평가에 참고 가치 있음.

### **[Evaluating Real-Time Voice Agents: From Component Quality to Grounded Outcomes] (Shivam Negi, Arpit Rawat, Rashi Jain, 2026-09-25, v2 2026-11-19)** — arxiv preprint

- **arxiv URL**: https://arxiv.org/abs/2609.30798
- **기존 문제**: 실시간 음성 에이전트의 평가가 아키텍처(지연시간), 턴테이킹(예측 정확도), 에이전트 태스크(과제 성공률) 세 커뮤니티로 분절되어 있어, 배포된 에이전트의 종합적 품질을 하나의 프레임워크로 측정할 수 없었음.
- **기존 방법**: 각 커뮤니티가 독립적 메트릭을 사용: 아키텍처 논문은 지연시간, 턴테이킹 논문은 예측 정확도, 에이전트 벤치마크는 과제 성공률을 보고. 통합 평가 기준 부재.
- **제안 방법**: 38개 주요 문헌을 애플리케이션 중심 분류 체계(6개 카테고리)로 정리한 구조적 리뷰. TRG(Timing-Recovery-Grounded) 평가 프레임워크를 제안: 타이밍(latency), 회복(disruption recovery), 근거 기반 결과(state-verified outcome)를 3축으로 측정하고, 다자 대화(multiparty) 배포 시 조건부 4번째 축을 추가.
- **핵심 차별점**: 에이전트가 주장한 결과가 아닌 백엔드 상태 검증(grounded verification)을 평가에 포함하여 환각(hallucination) 방지. 아키텍처 선택을 배포 제약으로 취급하고, 평가를 근거 기반 결과 중심으로 전환.
- **실험 결과**: 문헌 기반 리뷰로 별도의 실험 결과는 없으나, 최근 벤치마크들이 에이전트가 실행한 결과의 백엔드 상태 검증 방향으로 이동하고 있음을 체계적으로 확인. 검증 과정에서 유통 중인 arXiv ID 오류를 발견하여 보고.
- **우리 연구 관련도**: ★☆☆ — 음성 에이전트 평가 서베이로 speech SSL과 직접 관련은 낮으나, TRG 프레임워크의 근거 기반 평가 패러다임이 음성 표현 기반 에이전트 시스템 평가에 참고 가능.

### **[Real-Time Short-Response Selection for Spoken Dialogue Systems] (Ohnaka, Onishi, Yoshino, 2026-11-06)** — arxiv preprint

- **arxiv URL**: https://arxiv.org/abs/2611.09057
- **기존 문제**: 음성 대화 시스템에서 사용자 발화에 대한 짧은 응답(short response — 맞장구, 감탄사 등)을 실시간으로 선택해야 하는데, 응답 생성 및 음성 합성의 지연시간이 자연스러운 대화 흐름을 방해함.
- **기존 방법**: 무작위 선택(random selection) 또는 LLM 기반 생성이 주로 사용되었으나, 무작위 선택은 맥락 무관 응답을, LLM 기반은 높은 지연시간을 초래함.
- **제안 방법**: 대조 학습(contrastive learning) 기반으로 대화 맥락에서 적절한 짧은 응답을 사전 생성된 후보 중에서 선택하는 모델을 제안. 응답 생성·합성 지연시간을 마스킹하여 실시간 응답이 가능하도록 설계.
- **핵심 차별점**: 생성(generation)이 아닌 선택(selection) 패러다임으로 전환하여 지연시간 문제를 근본적으로 우회. 대조 학습으로 맥락-응답 매칭을 학습하므로 사전 합성된 고품질 응답을 즉시 출력 가능.
- **실험 결과**: 무작위 선택 및 LLM 기반 베이스라인을 성능에서 상회하는 것으로 보고됨.
- **우리 연구 관련도**: ★★☆ — 대조 학습 기반 음성 맥락 매칭은 temporal contrastive learning과 방법론적 연관성이 있으며, 실시간 음성 표현 활용의 응용 사례로 참고 가능.

## 3. Speech Foundation Model

### **[Acoustic Degradation Reorganizes Brain–Model Representational Geometry Across Speech and Language Hierarchies] (Francis Pingfan Chien, Chi-Hsiang Chao, Yu-En Tsai, Po-Jang Hsieh, Yu Tsao, 2026-11)** — NeurIPS 2026 accepted

- **arxiv URL**: https://arxiv.org/abs/2611.12291
- **기존 문제**: 음성 기반 모델(speech model)의 내부 표현이 인간 뇌의 음성 처리와 어떻게 정렬(align)되는지, 특히 소음 환경에서 이 정렬이 어떻게 변화하는지 불명확했음. 소음이 단순히 정렬을 약화시키는지, 아니면 재구조화(reorganization)를 유발하는지가 핵심 질문.
- **기존 방법**: Whisper, wav2vec2 등 음성 모델과 뇌 반응의 표현 유사성 분석(RSA)이 주로 깨끗한 음성 조건에서 수행되었으며, 소음 조건에서의 변화는 제한적으로 연구됨. 2025 NeurIPS에서 Whisper-Tiny와 소음 음성의 조건 의존적 정렬이 보고된 바 있음.
- **제안 방법**: 25명의 피험자에게 48개 중국어(보통화) 문장을 깨끗한 조건과 speech-shaped noise(−3 dB SNR) 조건에서 들려주며 fMRI 측정. 14개 청각-언어 영역에서 음성 모델(speech model)과 텍스트 LLM의 표현 기하학(representational geometry)을 비교.
- **핵심 차별점**: 소음이 뇌-모델 정렬을 단순 약화시키는 것이 아니라 선택적으로 재구조화함을 발견. 조건 불변(condition-invariant)이 아닌 조건 의존적(condition-dependent) 정렬 변화를 보고한 최초의 대규모 연구.
- **실험 결과**: 소음 하에서 음성 모델과의 정렬은 좌측 측두-전두 피질(left temporal-frontal cortex)에서 증가한 반면, 조건 불변 텍스트 LLM 기하학과의 정렬은 우반구(right-hemisphere) 영역에서 감소. 행동 수행(behavioral performance)의 저하에도 불구하고, 뇌의 음성 처리 정렬 패턴은 선택적 강화를 보임.
- **우리 연구 관련도**: ★★☆ — speech SSL 모델의 표현이 인간 뇌 처리와 어떻게 정렬되는지를 직접 분석한 연구로, speech representation learning의 생물학적 타당성(biological plausibility)을 검증하는 데 중요한 참고 자료. 소음 하 표현 재구조화 현상은 robust speech representation 설계에 시사점 제공.

### **[Towards Microphone-Invariant Speech Representations for Transformer-Based Voice Disorder Detection] (2026-11-16)** — arxiv preprint

- **arxiv URL**: https://arxiv.org/abs/2611.21140
- **기존 문제**: 트랜스포머 기반 음성 장애 탐지 시스템이 학습에 사용된 마이크와 다른 스마트폰 마이크로 녹음된 음성에서 성능이 크게 저하됨. 마이크 불일치(microphone mismatch)가 임상 배포의 핵심 장벽이었음.
- **기존 방법**: 기존 접근법은 주로 특정 마이크/녹음 환경에 맞춰 학습하거나, 데이터 증강(augmentation)으로 도메인 불일치를 완화하려 했으나, 마이크 특성을 표현 수준에서 명시적으로 불변(invariant)으로 만드는 방법은 부족했음.
- **제안 방법**: Barlow Twins 스타일의 자기지도(self-supervised) 모듈을 트랜스포머 기반 음성 모델에 추가하여, 동일 발화의 서로 다른 마이크 녹음에서 추출한 표현 간의 교차 상관(cross-correlation)을 항등 행렬에 근사시킴으로써 마이크 불변 표현을 학습.
- **핵심 차별점**: 명시적인 마이크 불변성을 Barlow Twins 목적함수로 표현 공간에 직접 주입. 추가 학습 데이터나 마이크 메타데이터 없이도 도메인 이전(domain transfer) 가능.

### **[Joint Language Modeling for In-the-Wild Speech-Scene Generation with Distinct Token Representations] (2026-11-19)** — arxiv preprint

- **arxiv URL**: https://arxiv.org/abs/2611.25503
- **기존 문제**: 실세계(in-the-wild) 오디오에서 음성과 환경 음향(배경 소리, 잔향 등)이 혼합되어 있으나, 기존 음성 생성 모델은 깨끗한 음성만을 대상으로 하여 실세계 오디오 씬(audio scene)을 생성하지 못했음.
- **기존 방법**: 텍스트-음성(TTS) 모델과 텍스트-오디오(text-to-audio) 모델이 별도로 발전해왔으며, 음성과 환경음을 동시에 모델링하는 통합 접근법이 부족했음. 시뮬레이션 데이터 기반 학습이 주류였으나 실세계 오디오와의 간극이 존재.
- **제안 방법**: 음성 토큰과 환경 토큰을 별도의 구별되는 표현(distinct token representations)으로 분리하고, 이를 하나의 언어 모델 프레임워크에서 공동으로 모델링(joint language modeling). 시뮬레이션 데이터로 학습 후 실세계 데이터로 적응(real-world adaptation) 수행.
- **핵심 차별점**: 음성과 환경음에 대한 별도의 토큰 표현 공간을 유지하면서도 단일 언어 모델 내에서 두 스트림 간의 의존성을 학습. 이를 통해 깨끗한 음성 생성 품질을 보존하면서도 씬 관련성(scene relevance)과 음향 품질을 동시에 개선.
- **실험 결과**: 동일한 시뮬레이션 데이터로 학습된 베이스라인 대비 명료도(intelligibility)에서 우수한 성능. 실세계 적응을 통해 씬 관련성과 오디오 품질이 추가 향상되었으며, 깨끗한 음성 생성 능력은 유지.
- **우리 연구 관련도**: ★★☆ — 음성과 환경음에 대한 별도 토큰 표현의 분리 설계는 speech tokenizer 연구에서 콘텐츠·화자·환경 정보의 분리(disentanglement)와 직접 관련. VQ-based representation에서의 정보 분리 전략에 참고 가능.
