## 1. ASR (End-to-End, Whisper, Multilingual, Diarization)

### **Adapting Where It Matters: Depth-Aware Adaptation for Efficient Multilingual Speech Recognition in Low-Resource Languages (Yang Xiao et al., 2026-02)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2602.01008
- 기존 문제: 다국어 ASR 모델(예: Whisper)을 저자원 언어에 적응시킬 때, 전체 파라미터를 미세조정하면 비용이 크고, 기존 PEFT 방법(LoRA 등)은 모든 레이어에 균일하게 어댑터를 삽입하여 비효율적임.
- 기존 방법: LoRA, Adapter, Prefix Tuning 등의 PEFT 기법을 Whisper 전 레이어에 균일 적용. 레이어별 역할 차이를 고려하지 않음.
- 제안 방법: DAMA(Depth-Aware Model Adaptation) 프레임워크를 제안. 다국어 ASR 모델의 레이어별 적응 필요도가 U자형 패턴을 따름을 발견 — 초기·후기 레이어는 언어 특화적이라 많은 적응이 필요하고, 중간 레이어는 언어 간 공유 의미를 보존하므로 적은 적응으로 충분. SVD 기반 초기화로 이 패턴을 보존하며 적응 용량을 차등 배분.
- 핵심 차별점: 레이어별 역할 분석에 기반한 비균일(non-uniform) 적응 전략. 중간 레이어의 frozen basis를 유지하여 다국어 지식 보존과 효율성을 동시 달성.
- 실험 결과: Common Voice·FLEURS 18개 저자원 언어에서 SOTA 대비 동등 이상의 정확도를 80% 적은 학습 파라미터로 달성. 극단적 데이터 부족 환경에서 29% 오류율 감소. 메모리·학습 시간도 대폭 절감.
- 우리 연구 관련도: ★★☆ (레이어별 표현 역할의 U자형 분석은 speech SSL 인코더의 레이어별 정보 분포 이해와 직결되며, prediction-free SSL 설계 시 어느 레이어를 타깃으로 할지 참고 가능)

### **When Audio-Language Models Fail to Leverage Multimodal Context for Dysarthric Speech Recognition (Pehuén Moure, Shih-Chii Liu et al., 2026-05)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2605.02782
- 기존 문제: ASR 시스템은 구음장애(dysarthric) 등 비정형 발화에서 여전히 취약. 임상 맥락(진단명, 중증도 등)을 프롬프트로 제공하면 성능이 향상될 것이라는 가설이 검증되지 않음.
- 기존 방법: Whisper 등 범용 ASR 모델의 zero-shot 적용, 또는 화자 적응(speaker adaptation) 기법. 최근 Audio-Language Model(ALM)에 텍스트 프롬프트로 맥락을 주입하는 시도가 등장.
- 제안 방법: Speech Accessibility Project(SAP) 데이터셋 기반 벤치마크를 구축하여, 진단 라벨·임상 평가·상세 설명 등 점진적으로 풍부한 임상 맥락을 9개 ALM 모델에 프롬프트로 제공하는 체계적 실험 수행. 별도로 LoRA 미세조정 접근도 평가.
- 핵심 차별점: 현재 ALM들이 임상 맥락 프롬프트를 실질적으로 활용하지 못함을 실증적으로 입증 — 프롬프트는 무시되거나 오히려 WER을 악화. 반면 LoRA 미세조정은 효과적.
- 실험 결과: 9개 모델 전반에서 임상 맥락 프롬프트의 WER 개선 효과 무의미. LoRA 적응 시 WER 0.066 달성(frozen baseline 대비 52% 상대 감소).
- 우리 연구 관련도: ★☆☆ (비정형 발화 인식 특화 연구로, SSL 표현 학습 자체와의 직접 관련은 낮으나, 표현의 강건성 평가 관점에서 참고 가능)

### **Mechanistic Interpretability of ASR Models Using Sparse Autoencoders (Dan Pluth, Zachary N. Houghton, Yu Zhou, Vijay K. Gurbani, 2026-05)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2605.12225
- 기존 문제: Sparse Autoencoder(SAE)를 활용한 mechanistic interpretability 연구는 텍스트 LLM에서 활발하나, 오디오 처리 모델(ASR)에는 적용 사례가 전무.
- 기존 방법: Probing classifier, attention 시각화 등으로 ASR 내부를 분석하는 기존 해석 기법은 모델 내부 특징의 단의미성(monosemanticity)을 직접 추출하지 못함.
- 제안 방법: Whisper 인코더의 프레임 수준 임베딩에 고차원 sparse latent space를 학습하는 SAE를 적용. 언어적(음소, 언어 ID 등)·비언어적(배경 소음, 음향 특성 등) 단의미 특징을 발견하고, 교차 언어 특징 조종(cross-lingual feature steering)을 시연.
- 핵심 차별점: ASR 모델에 SAE를 최초 적용하여 Whisper가 전사에 필요한 것 이상의 풍부한 언어 정보를 인코딩함을 입증. 특징 조종을 통해 인과적(causal) 해석 가능성을 시연.
- 실험 결과: 다양한 단의미 특징(음소별, 언어별, 음향 환경별) 발견. 교차 언어 특징 조종 실험에서 특정 특징 활성화/비활성화에 따른 출력 변화 확인.
- 우리 연구 관련도: ★★☆ (SSL 모델 내부 표현의 해석 가능성 연구와 직결. speech SSL 인코더의 어떤 차원이 어떤 정보를 담는지 분석하는 데 SAE 기법 적용 가능)

## 2. SpeechLLM (Speech-Language Model, Spoken Dialogue, Voice Agent)

### **How Should LLMs Listen While Speaking? A Study of User-Stream Routing in Full-Duplex Spoken Dialogue (Hui Lu et al., 2026-05)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2605.10199
- 기존 문제: Full-duplex 음성 대화에서 모델이 자체 응답을 생성하면서 동시에 사용자 입력을 수신해야 하지만, LLM은 단일 시퀀스 확장에 최적화되어 있어 생성 중 외부 입력 처리가 구조적으로 어려움.
- 기존 방법: LSLM, Moshi 등 기존 full-duplex 모델은 사용자 스트림을 LLM에 통합하는 방식을 제안했으나, 라우팅 전략 간 체계적 비교가 부재.
- 제안 방법: 텍스트 전용 LLM을 full-duplex 음성 대화 시스템으로 확장하고, 동일 학습 파이프라인에서 두 가지 라우팅 전략을 비교: (i) Channel Fusion — 사용자 스트림을 LLM 입력에 직접 주입, (ii) Cross-Attention Routing — 사용자 스트림을 cross-attention 어댑터를 통해 외부 메모리로 접근.
- 핵심 차별점: 최초의 공정한(fair) 비교 실험. Channel Fusion은 의미적 grounding이 강하나 인터럽션 시 context corruption에 취약. Cross-Attention Routing은 QA 성능은 떨어지나 생성 컨텍스트 보존과 인터럽션 강건성이 우수.
- 실험 결과: Channel Fusion이 QA 정확도에서 일관되게 우수. 그러나 의미적 중첩 조건(인터럽션)에서 context corruption 발생률이 높음. Cross-Attention Routing은 이 실패 모드에 더 강건.
- 우리 연구 관련도: ★☆☆ (full-duplex 대화 아키텍처 연구로, speech SSL 표현 자체와의 관련은 낮으나 음성-LLM 통합 설계 동향 파악에 유용)

### **DuplexCascade: Full-Duplex Speech-to-Speech Dialogue with VAD-Free Cascaded ASR-LLM-TTS Pipeline and Micro-Turn Optimization (Jianing Yang, Yusuke Fujita, Yui Sudo, 2026-03)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2603.09180
- 기존 문제: Cascaded ASR-LLM-TTS 파이프라인은 강력한 LLM 지능을 유지하지만, VAD 기반 세그멘테이션이 half-duplex 턴을 강제하고 제어가 불안정. 반면 end-to-end 모델은 full-duplex를 지원하지만 대화 지능 유지가 어려움.
- 기존 방법: (1) VAD 기반 cascaded 시스템 — half-duplex, 턴 전환 지연 큼. (2) End-to-end 음성 대화 모델(Moshi 등) — full-duplex 가능하나 LLM 추론 능력 활용 어려움.
- 제안 방법: DuplexCascade는 기존 발화(utterance) 단위 긴 턴을 청크(chunk) 단위 마이크로턴으로 변환. VAD 없이 cascaded 스트리밍 파이프라인을 구축하고, 대화 제어 특수 토큰(conversational special control tokens)을 도입하여 턴 테이킹과 응답 타이밍을 스트리밍 조건에서 조율.
- 핵심 차별점: VAD를 제거하면서도 cascaded 구조의 LLM 지능을 보존. 마이크로턴 최적화로 빠른 양방향 교환을 가능케 하여 end-to-end와 cascaded의 장점을 결합.
- 실험 결과: Full-DuplexBench, VoiceBench에서 오픈소스 음성 대화 시스템 중 SOTA full-duplex 턴 테이킹 성능. 대화 지능(conversational intelligence)도 최고 수준. 백본은 Qwen2-7B-Instruct.
- 우리 연구 관련도: ★☆☆ (음성 대화 시스템 파이프라인 연구로, speech 표현 학습과의 직접 관련은 낮으나 실시간 음성 처리 아키텍처 트렌드로 참고)

### **VITA-QinYu: Expressive Spoken Language Model for Role-Playing and Singing (Jiacheng Xu et al., 2026-05)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2605.06765
- 기존 문제: 기존 end-to-end SLM(Spoken Language Model)은 자연 대화에 초점을 맞추며, 역할극(role-playing)이나 노래(singing)와 같은 표현적(expressive) 음성 생성은 지원하지 못함.
- 기존 방법: GPT-4o, Moshi 등 기존 SLM은 대화 품질에 집중. 별도의 음성 합성(TTS) 또는 가창 합성(SVS) 모델이 표현적 생성을 담당하나 end-to-end 통합은 미비.
- 제안 방법: Hybrid speech-text 패러다임을 채택하여 interleaved 모델링을 병렬 multi-codebook 오디오 토큰 모델링으로 확장. 부언어적(paralinguistic) 표현력을 향상하면서 교차 모달 간섭을 감소. 2.6K시간 역할극 데이터셋(20K+ 캐릭터, 오디오북 기반)과 1.2K시간 가창 데이터셋(MIDI 기반 zero-shot SVS)을 구축.
- 핵심 차별점: 최초의 역할극+가창 가능 end-to-end SLM. 병렬 multi-codebook 모델링으로 표현적 음성의 다차원 특성(톤, 감정, 멜로디)을 포착.
- 실험 결과: VITA-QinYu-8B가 영어·중국어 모두에서 비교 SLM 중 1위. 역할극 벤치마크에서 기존 SLM 대비 객관적 지표 7%p 향상.
- 우리 연구 관련도: ★★☆ (multi-codebook 토큰 모델링은 VQ 기반 음성 표현 설계와 관련. 의미-음향 분리 모델링이 speech tokenizer 연구에 참고 가능)

## 3. Speech Foundation Model (Speech SSL, Tokenizer, Representation Learning)

### **UniWav: Towards Unified Pre-training for Speech Representation Learning and Generation (Alexander H. Liu, Sang-gil Lee, Chao-Han Huck Yang et al., 2025)** — ICLR 2025 accepted (MIT CSAIL, NVIDIA)
- arxiv URL: https://arxiv.org/abs/2503.00733
- 기존 문제: 음성 표현 학습(SSL)과 음성 생성(TTS, 코덱 등)은 별도의 foundation model로 학습되어 왔음. 하나의 모델로 이해와 생성을 동시에 수행하는 통합 사전학습이 부재.
- 기존 방법: 표현 학습 — HuBERT, wav2vec 2.0 등 인코더 전용 SSL. 생성 — SoundStream, EnCodec 등 코덱 모델 또는 Flow Matching 기반 디코더. 각각 별도 학습.
- 제안 방법: 인코더-디코더 통합 프레임워크 UniWav를 제안. 인코더는 self-distillation(EMA teacher) + masked audio modeling으로 표현을 학습하고, 디코더는 Flow Matching으로 오디오를 생성. 전체를 end-to-end로 학습. Discrete bottleneck을 추가하면 저비트레이트 토크나이저로도 활용 가능.
- 핵심 차별점: 단일 모델로 ASR·TTS·토크나이제이션을 모두 수행하는 최초의 통합 사전학습 프레임워크. 생성 목적함수가 인코더 표현 학습에도 긍정적 영향을 미침을 실증.
- 실험 결과: LibriSpeech test-other에서 WER 4.8%(100h 라벨), 4.0%(960h 라벨). 토크나이제이션에서 기존 방법 대비 저비트레이트에서 우수한 재합성 품질. TTS에서도 경쟁력 있는 자연스러움 달성.
- 우리 연구 관련도: ★★★ (self-distillation + masked modeling 기반 SSL과 생성을 통합하는 접근은 prediction-free SSL 및 VQ 표현 연구의 핵심 참조점. discrete bottleneck 설계가 speech tokenizer 연구와 직결)

### **PairAlign: A Framework for Sequence Tokenization via Self-Alignment with Applications to Audio Tokenization (Adhiraj Banerjee, Vipul Arora, 2026-05)** — arxiv preprint (IIT Kanpur)
- arxiv URL: https://arxiv.org/abs/2605.06582
- 기존 문제: 기존 오디오 토크나이저는 양자화(quantization), 클러스터링, 코덱 재구성 등 로컬 단위로 토큰을 할당하여, 시퀀스 수준의 일관성·컴팩트성·길이 제어·종료 판단·편집 유사성이 직접 최적화되지 않음.
- 기존 방법: VQ-VAE, 코덱 기반 토크나이저(EnCodec, SoundStream), K-means 클러스터링 기반 discrete unit 추출(HuBERT). 모두 프레임 단위 로컬 할당.
- 제안 방법: PairAlign은 토크나이제이션을 조건부 시퀀스 생성으로 재정의. 인코더가 음성을 연속 조건으로 매핑하고, 자기회귀 디코더가 BOS부터 토큰 정체성·순서·길이·EOS를 학습. 두 개의 content-preserving view 간 시퀀스를 교차 학습하여 시퀀스 수준 일관성을 확보.
- 핵심 차별점: 최초의 시퀀스 수준 자기정렬(self-alignment) 기반 토크나이제이션. 프레임 단위가 아닌 시퀀스 전체의 구조를 학습하여 컴팩트하고 편집 거리 보존이 가능한 토큰 시퀀스 생성.
- 실험 결과: LibriSpeech·TIMIT에서 넓은 어휘 사용과 강한 교차 뷰 일관성 달성. TIMIT 검색 태스크에서 의미 있는 편집 거리 검색을 유지하면서 아카이브 토큰 수 약 55% 감소.
- 우리 연구 관련도: ★★★ (시퀀스 수준 contrastive 학습과 자기정렬 기반 토크나이제이션은 temporal contrastive learning 및 VQ-based representation 연구와 직접 관련. prediction-free 접근의 대안적 학습 목표로 참고 가치 높음)

### **Speech Token Prediction via Compressed-to-fine Language Modeling for Speech Generation (Wenrui Liu et al., 2025)** — ACM Multimedia 2025 accepted (Zhejiang University)
- arxiv URL: https://arxiv.org/abs/2505.24496
- 기존 문제: Neural audio codec이 고충실도 재구성을 위해 긴 토큰 시퀀스를 생성하는데, 이는 downstream 언어 모델의 장문맥(long-context) 모델링에 큰 부담. 시퀀스 길이가 텍스트 대비 수배~수십 배.
- 기존 방법: VALL-E 등 codec LM은 전체 토큰 시퀀스를 자기회귀적으로 생성. RVQ 다층 코드북 활용 시 시퀀스가 더욱 길어짐. 컨텍스트 압축 없이 전체 히스토리를 참조.
- 제안 방법: 음성 토큰 시퀀스의 단거리 의존성(short-range dependency) 특성을 관찰 — TTS에서 텍스트-음성 간 단조 정렬로 인해 현재 토큰 예측은 주로 로컬 컨텍스트에 의존하고 장거리 토큰은 중복 정보. 이를 기반으로 Compressed-to-fine 언어 모델링을 제안: 프롬프트와 로컬 토큰은 세밀한 표현을 유지하고, 장거리 컨텍스트는 압축하여 효율적으로 참조.
- 핵심 차별점: 음성 토큰의 로컬 의존성 특성을 활용한 최초의 적응적 컨텍스트 압축. 전체 시퀀스를 균일하게 처리하는 기존 방식 대비 효율성과 품질을 동시 향상.
- 실험 결과: TTS 품질(자연스러움, 화자 유사도) 유지 또는 향상하면서 계산 비용 대폭 절감. 기존 codec LM 대비 추론 속도 향상.
