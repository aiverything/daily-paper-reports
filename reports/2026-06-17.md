## 1. ASR (Automatic Speech Recognition)

### 1-1. Balancing ASR and Diarization in End-to-End LLMs for Multi-Talker Speech Recognition

**(Naijun Zheng, Yuke Lin, Sanli Tian, Mengtian Li, Zhiwei Lin, Longshuai Xiao, Dandan Tu, 2026-06)** — Interspeech 2026 accepted

- https://arxiv.org/abs/2606.13095
- **기존 문제:** LLM 기반 end-to-end 다화자 음성 인식에서 ASR 정확도와 화자 분리(diarization) 성능 간의 트레이드오프가 존재. 단일 모델이 "무엇을 말했는가"와 "누가 말했는가"를 동시에 최적화하기 어려우며, 한쪽 성능을 높이면 다른 쪽이 저하되는 균형 문제가 해결되지 않음.
- **기존 방법:** 캐스케이드 파이프라인(ASR → 화자 분리)이 주류이나 모듈 간 오류 전파가 누적. 최근 LLM 기반 end-to-end 접근(SpeakerLM, Diarization-Aware ASR 등)이 등장했으나, ASR과 diarization 간 학습 신호의 균형 조절 메커니즘이 부재.
- **제안 방법:** End-to-end LLM 프레임워크 내에서 ASR과 diarization 목표 간의 균형을 명시적으로 조절하는 학습 전략 제안. 다화자 환경에서 두 과제의 상호작용을 분석하고, 균형 잡힌 최적화를 통해 양쪽 성능을 동시에 향상.
- **핵심 차별점:** ASR-diarization 트레이드오프를 체계적으로 분석하고 균형 전략을 제시한 최초의 연구. 단일 LLM에서 두 과제의 상호 보완적 학습을 가능하게 함.
- **실험 결과:** 다화자 벤치마크에서 ASR 정확도와 DER(Diarization Error Rate) 양쪽에서 기존 end-to-end 베이스라인 대비 균형 잡힌 개선 달성.
- **우리 연구 관련도:** ★☆☆ — LLM 기반 다화자 ASR 학습 전략 연구로, speech SSL이나 VQ-based representation과의 직접적 관련은 낮음. 다만 다중 과제 간 학습 신호 균형 전략이 multi-task SSL 학습에 간접적 참고 가능.

### 1-2. Whisper Hallucination Detection and Mitigation via Hidden Representation Steering and Sparse AutoEncoders

**(Georgii Aparin, Vadim Popov, Tasnima Sadekova, Assel Yermekova, 2026-06-05)** — arxiv preprint

- https://arxiv.org/abs/2606.07473
- **기존 문제:** Whisper는 비음성(non-speech) 오디오 입력에 대해 입력과 무관한 일관된 텍스트를 생성하는 환각(hallucination) 현상이 빈번. 이는 실제 배포 환경에서 심각한 신뢰성 문제를 야기하며, 기존 fine-tuning 기반 완화 방법은 높은 연산 비용과 원본 모델 성능 저하를 수반.
- **기존 방법:** 환각 완화를 위해 전체 모델 fine-tuning, 데이터 증강, 후처리 필터링 등이 사용되었으나, 모두 추가 학습 데이터와 연산 비용이 필요하며 원본 ASR 성능과의 트레이드오프 존재.
- **제안 방법:** Whisper 내부 표현(hidden representation)에서 환각 관련 정보를 탐지하고 조향(steering)하는 두 가지 전략 제안: (1) activation-space steering — 원시 인코더 활성화에서 환각 방향 벡터를 추출하여 반대로 조향, (2) SAE latent-space steering — Sparse AutoEncoder로 학습된 잠재 공간에서 환각 관련 희소 특성(sparse feature)을 식별하고 선택적으로 억제.
- **핵심 차별점:** 모델 재학습 없이 추론 시점에서 내부 표현 조향만으로 환각을 대폭 감소시키는 경량 접근. SAE를 통해 환각 관련 해석 가능한 희소 특성을 식별하여, 환각 메커니즘에 대한 기계적 이해(mechanistic understanding)도 제공.
- **실험 결과:** SAE 기반 조향으로 Whisper-small의 환각률을 72.63%에서 14.11%로, Whisper-large-v3의 환각률을 86.88%에서 27.33%로 감소. 음성 데이터에 대한 WER 저하는 미미하여, fine-tuning 기반 방법에 근접하는 성능을 재학습 없이 달성.
- **우리 연구 관련도:** ★★☆ — SAE를 활용한 음성 모델 내부 표현의 해석 가능한 특성 분석이 speech representation learning에서의 표현 구조 이해에 방법론적 시사점 제공. 희소 특성 기반 표현 조향이 speech SSL 모델의 특정 정보 제어에 참고 가능.

### 1-3. Decoding while Adapting: Zero-Shot Online Speaker Adaptation via Audio-Textual Prompts for Elderly Speech Recognition

**(Chengxi Deng, Xurong Xie, Shujie Hu, Mengzhe Geng, Tianzi Wang, Youjun Chen, Huimeng Wang, Haoning Xu, Jiajun Deng, Xunying Liu — CUHK, 2026-06-15)** — arxiv preprint

- https://arxiv.org/abs/2606.16539
- **기존 문제:** 고령자 음성은 발화 속도 저하, 불명확한 발음, 비유창성(disfluency) 등 화자별 편차가 크며, 기존 ASR 시스템은 이러한 특성에 적응하지 못해 높은 오류율을 보임. 기존 화자 적응 방법(i-vector, x-vector, ECAPA-TDNN)은 화자 표현의 일관성이 부족하고 실시간 적응이 어려움.
- **기존 방법:** 사전 등록(pre-enrollment) 기반 화자 적응이 주류이나, 고령자 화자의 음성이 시간에 따라 변화하므로 고정된 화자 임베딩이 부정확. 온라인 적응을 위해 별도의 적응 단계가 필요하여 실시간 활용이 제한적.
- **제안 방법:** 현재 발화와 직전 소수의 발화에서 음성·텍스트 임베딩을 추출하고, 크로스모달 융합(cross-modal fusion)을 통해 컴팩트한 화자 프롬프트를 생성. 이 프롬프트는 디코딩과 동시에 온라인으로 갱신되어, 사전 등록 없이 실시간 화자 적응을 수행.
- **핵심 차별점:** 음성-텍스트 크로스모달 프롬프트가 기존 i/x-vector, ECAPA-TDNN 특성보다 일관적인 화자 표현을 제공하며, 디코딩과 적응이 동시에 진행되는 zero-shot 온라인 적응을 최초로 실현.
- **실험 결과:** 영어 DementiaBank Pitt 및 광둥어 JCCOCC MoCA 고령자 음성 데이터셋에서 기존 화자 적응 방법 대비 일관된 WER 개선 달성.
- **우리 연구 관련도:** ★★☆ — 크로스모달(음성-텍스트) 융합 기반 화자 표현 학습이 speech representation learning에서의 다중 모달리티 정보 통합 전략에 방법론적 참고. 온라인 적응형 표현 갱신이 temporal contrastive learning에서의 동적 표현 학습에 간접적 시사점 제공.

## 2. SpeechLLM (Speech Language Model)

### 2-1. BayLing-Duplex: Native Full-Duplex Speech Dialogue with a Single Autoregressive LLM

**(Qingkai Fang, Shoutao Guo, Yang Feng — ICT, Chinese Academy of Sciences, 2026-06-12)** — arxiv preprint

- https://arxiv.org/abs/2606.14528
- **기존 문제:** LLaMA-Omni, GLM-4-Voice 등 기존 Speech LLM은 여전히 턴 기반(turn-based) 방식으로 동작하며, 외부 VAD(Voice Activity Detection) 모듈에 의존하여 턴 교대를 결정. 이는 자연스러운 대화에서의 동시 발화, 끼어들기(barge-in), 백채널링(backchanneling) 등 풀 듀플렉스 상호작용을 지원하지 못함.
- **기존 방법:** 외부 VAD 모듈을 부착하여 사용자 음성 활동을 감지하고 턴을 전환하는 방식이 주류. 일부 풀 듀플렉스 모델(Moshi, LSLM 등)은 별도의 턴 테이킹 모듈이나 이중 스트림 아키텍처를 사용하나, 아키텍처 복잡성이 높고 기존 LLM 인프라와의 호환성이 낮음.
- **제안 방법:** BayLing-Duplex — 단일 자기회귀 LLM이 청취, 발화, 정지 시점을 자체적으로 결정하는 네이티브 풀 듀플렉스 시스템. 기존 어휘에 소수의 특수 토큰만 추가하여 구현하므로, 아키텍처 수정 없이 다양한 LLM에 이식 가능하고 기존 학습·서빙 인프라를 그대로 재활용. GLM-4-Voice 체크포인트에서 400K 풀 듀플렉스 샘플로 파인튜닝 후 경량 DPO 단계 적용.
- **핵심 차별점:** 외부 턴 테이킹 모듈 없이 단일 AR LLM만으로 풀 듀플렉스를 달성한 최초의 실용적 접근. 특수 토큰 기반 설계로 아키텍처 불변성(architecture-agnostic)을 보장하여, 어떤 LLM에든 적용 가능.
- **실험 결과:** InstructS2S-Eval에서 92% 턴 테이킹 성공률과 100% 끼어들기 성공률 달성. 기존 풀 듀플렉스 모델 대비 자연스러운 대화 흐름과 응답 품질에서 우수한 성능.
- **우리 연구 관련도:** ★☆☆ — 풀 듀플렉스 대화 시스템 설계 연구로, speech SSL이나 VQ-based representation과의 직접적 관련은 낮음. 다만 음성 토큰과 제어 토큰의 통합 시퀀스 모델링이 speech tokenizer 설계의 응용 측면에서 간접적 참고 가능.

### 2-2. Endpoint Anticipation for Low-Latency Spoken Dialogue

**(Sathvik Udupa, Shinji Watanabe, Petr Schwarz, Jan Cernocky — BUT / CMU, 2026-06-11)** — Interspeech 2026 accepted

- https://arxiv.org/abs/2606.13450
- **기존 문제:** 캐스케이드 음성 대화 시스템(ASR → LLM → TTS)에서 각 컴포넌트의 순차 실행으로 인한 높은 응답 지연 시간이 사용자 경험을 저해. 특히 발화 종료(endpoint) 감지가 반응적(reactive)으로 이루어져, 종료 시점 이후에야 LLM과 TTS 처리가 시작되는 구조적 병목.
- **기존 방법:** VAD 기반 반응적 발화 종료 감지가 표준. 사용자가 말을 멈춘 후 일정 무음 구간을 확인한 뒤에야 후속 처리를 시작하므로, 감지 지연 + LLM 처리 시간 + TTS 합성 시간이 모두 누적.
- **제안 방법:** Endpoint Anticipation — 반응적 감지에서 능동적 예측(proactive forecasting)으로 패러다임 전환. 음성 기반 모델이 발화 종료 시점을 최대 2.56초 전에 예측하여, LLM과 TTS 파이프라인의 투기적 실행(speculative execution)을 가능하게 함. Unmute 프레임워크와 통합하여 부분 컨텍스트에서의 투기적 추론을 수행.
- **핵심 차별점:** 발화 종료를 "감지"가 아닌 "예측"하는 최초의 체계적 접근. 투기적 실행으로 순차 병목을 마스킹하여, 캐스케이드 시스템의 구조를 변경하지 않고도 지연 시간을 대폭 감소.
- **실험 결과:** 평균 505ms의 지연 시간 감소 달성. 투기적 연산량은 28.4% 증가하나, 이는 사용자 체감 지연 감소로 상쇄.
- **우리 연구 관련도:** ★☆☆ — 음성 대화 시스템의 지연 최적화 연구로, speech SSL이나 VQ-based representation과의 직접적 관련은 낮음. 음성 신호로부터의 시간적 이벤트 예측이 temporal modeling 관점에서 간접적 참고점 제공.

### 2-3. SALSA: Speech Aware LLM Adaptation via Learned Steering Activation Vectors

**(Yekaterina Yegorova, Argyrios Gerogiannis, Haolong Zheng, Julia Hockenmaier, Chang D. Yoo, Mark A. Hasegawa-Johnson — UIUC / KAIST, 2026-05-30)** — arxiv preprint

- https://arxiv.org/abs/2606.00460
- **기존 문제:** Speech-aware LLM(음성 인코더 + LLM 결합 모델)이 학습 도메인 외(out-of-domain) 환경에서 성능이 급격히 저하. 아동 음성, 다국어 음성, 코드스위칭 음성 등 분포 이동(distribution shift)이 큰 환경에서의 제로샷 일반화가 부족.
- **기존 방법:** 도메인별 fine-tuning이 주류이나, 각 도메인마다 별도 학습이 필요하여 비효율적. 대조 활성화 차이(contrastive activation difference) 기반 조향(steering)이 시도되었으나, 부정확한 방향 추출로 성능 개선이 제한적.
- **제안 방법:** SALSA — 지도 학습 목적함수(supervised objective)로 계층별 조향 벡터(layer-wise steering vectors)를 직접 최적화. 대조적 차이에 의존하지 않고, 타깃 도메인의 소량 데이터로 조향 방향을 학습. 음성 인코더와 LLM 백본 각각의 계층에 대해 조향 효과를 체계적으로 분석.
- **핵심 차별점:** 음성 인코더의 후반 계층(later layers)을 조향하는 것이 LLM 백본을 조향하는 것보다 효과적이라는 핵심 발견. 경량 파라미터(조향 벡터만)로 도메인 적응을 달성하는 실용적 접근.
- **실험 결과:** 아동 음성, 다국어 음성, 만다린-영어 코드스위칭 벤치마크에서 제로샷 추론 및 음성 in-context learning 베이스라인 대비 최대 46.8%의 상대적 성능 향상.
- **우리 연구 관련도:** ★★★ — 음성 인코더의 계층별 표현을 조향 벡터로 제어하는 접근이 speech SSL 모델의 내부 표현 구조 이해 및 제어와 직접적으로 관련. "후반 계층 조향이 더 효과적"이라는 발견은 speech representation의 계층별 정보 분포에 대한 중요한 실증적 근거. 경량 적응 방법론이 prediction-free SSL 모델의 downstream 활용 전략에 직접적 참고.

### 2-4. Overcoming State Inertia in Full-Duplex Spoken Language Models via Activation Steering

**(Cheng-Kuang Chang, Kai-Wei Chang, Alexander H. Liu, James Glass — MIT CSAIL, 2026-06-09)** — arxiv preprint

- https://arxiv.org/abs/2606.11386
- **기존 문제:** 풀 듀플렉스 음성 언어 모델(FD-SLM)은 청취와 발화를 동시에 수행하나, 대화 맥락의 급격한 전환(특히 사용자 끼어들기) 시 내부 상태 전환이 지연되는 "상태 관성(state inertia)" 현상이 발생. 모델이 발화 생성 상태에서 청취 상태로 전환하는 데 시간적 지연이 존재하여, 끼어들기 반응이 느려짐.
- **기존 방법:** 풀 듀플렉스 모델의 내부 상태 전환 메커니즘에 대한 체계적 분석이 부재. 기존 연구는 아키텍처 설계나 학습 데이터에 초점을 맞추었으나, 모델 내부의 상태 역학(state dynamics)을 직접적으로 이해하거나 제어하려는 시도가 없었음.
- **제안 방법:** FD-SLM의 은닉 표현(hidden representation)에서 스트림별 예측 패턴을 분석: 청취 시에는 사용자 입력 스트림을 우선적으로 예측하고(지각 상태), 발화 시에는 모델 출력 스트림을 우선적으로 예측(생성 상태)하는 이중 상태를 식별. 활성화 조향(activation steering)을 통해 상태 관성을 극복하고, 급격한 맥락 전환 시 지각 상태로의 빠른 전환을 유도.
- **핵심 차별점:** FD-SLM 내부의 생성-지각 이중 상태 역학을 최초로 체계적으로 분석하고, 상태 관성이라는 새로운 현상을 식별. 활성화 조향이라는 비침습적(non-invasive) 방법으로 상태 전환을 가속화.
- **실험 결과:** 상태 관성 현상의 정량적 특성화 완료. 활성화 조향을 통해 끼어들기 시나리오에서의 상태 전환 지연을 감소시키고, 생성 상태에서 지각 상태로의 전환 속도를 향상.
- **우리 연구 관련도:** ★★☆ — 음성 모델 내부 표현의 상태 역학 분석과 활성화 조향이 speech SSL 모델의 내부 표현 구조 이해에 방법론적 시사점 제공. 특히 시간적 맥락 변화에 따른 표현의 동적 변화 분석이 temporal contrastive learning에서의 시간적 동역학 모델링에 참고 가능.

## 3. Speech Foundation Model

### 3-1. Self-Guidance: Enhancing Neural Codecs via Decoder Manifold Alignment

**(Xiang Li, Yixuan Zhou, Jingran Xie, Zhiyong Wu, Hui Wang, 2026-06-11)** — ICML 2026 accepted

- https://arxiv.org/abs/2606.12940
- **기존 문제:** VQ-VAE 기반 신경 음성 코덱(neural speech codec)은 Speech LLM의 핵심 오디오 토크나이저로 사용되나, 벡터 양자화(VQ) 과정에서의 양자화 오류(quantization error)가 재구성 충실도(reconstruction fidelity)를 병목시킴. 양자화된 이산 토큰과 원본 연속 임베딩 간의 정보 손실이 불가피.
- **기존 방법:** 코드북 크기 증가, 잔차 양자화(RVQ), 그룹 양자화 등으로 양자화 오류를 줄이려는 시도가 있었으나, 연산 비용 증가와 토큰 시퀀스 길이 증가를 수반. 디코더 내부의 양자화 오류 영향을 직접적으로 완화하는 접근은 미탐구.
- **제안 방법:** Self-Guidance — 디코더가 양자화된 토큰을 처리할 때와 원본 연속 임베딩을 처리할 때의 내부 특성 매니폴드(feature manifold)를 정렬하는 경량 특성 매핑 손실(feature-mapping loss)을 도입. 디코더의 중간 표현이 양자화 유무에 관계없이 유사한 매니폴드 위에 위치하도록 학습.
- **핵심 차별점:** 학습 시 경량 손실 항만 추가하고 추론 시에는 아무런 변경이 없는 제로 오버헤드 접근. XCodec2에 적용하여, 코드북을 4배 축소하면서도 충실도 손실 없이 SOTA 저비트레이트 성능 달성. 코덱 아키텍처에 불변적(codec-agnostic)으로 적용 가능.
- **실험 결과:** XCodec2에 적용 시 모든 재구성 메트릭에서 개선을 달성하여 SOTA 저비트레이트 성능. 4배 코드북 축소에서도 충실도 유지. 하류 TTS 작업에서도 성능 향상 확인.
- **우리 연구 관련도:** ★★★ — VQ 기반 코덱의 양자화 오류 완화 기법이 VQ-based speech representation 연구에 직접적으로 관련. 연속 임베딩과 양자화 토큰 간의 매니폴드 정렬이라는 개념은 prediction-free SSL에서의 이산-연속 표현 간 정보 보존 문제에 핵심적 인사이트 제공. 코드북 효율화 전략이 speech tokenizer의 압축률-품질 트레이드오프 개선에 직접 참고 가능.

### 3-2. Probing Low Frame Rate Degradation in Neural Audio Codecs

**(Alex Gichamba, Moise Busogi — Carnegie Mellon University Africa, 2026-06-15)** — Interspeech 2026 accepted

- https://arxiv.org/abs/2606.16969
- **기존 문제:** 신경 오디오 코덱의 프레임률을 낮추면 자기회귀 음성 합성에서 시퀀스 길이가 단축되어 생성 비용이 선형적으로 감소하나, 6.25 Hz 이하에서 급격한 품질 저하("quality cliff")가 발생. 이 현상의 원인이 음소 충돌(phonemic collision), 코드북 포화(codebook saturation) 등 근본적 한계로 추정되어, 저프레임률 코덱의 실용성이 의문시.
- **기존 방법:** 기존 연구들은 6.25 Hz 이하의 품질 저하를 관찰하고, 음소 충돌이나 정보 병목 등 근본적 원인을 가설로 제시. 이로 인해 저프레임률 코덱 연구가 6.25 Hz 이상에 집중되는 경향.
- **제안 방법:** 6.25 Hz quality cliff의 후보 원인(음소 충돌, 코드북 포화)을 체계적으로 검증하되, 실제 원인은 차선적 학습 설정(suboptimal training configuration)에 있음을 밝힘. 고정된 클립 길이(fixed clip duration)로 학습 시, 저프레임률에서 토큰 수가 지나치게 적어져 디코더가 토큰 간 맥락(inter-token context)을 충분히 학습하지 못하는 것이 핵심 원인.
- **핵심 차별점:** quality cliff가 근본적 한계가 아닌 학습 설정의 문제임을 실증한 최초의 연구. 학습 설정을 교정하면 WER이 3.1 Hz, 1.6 Hz까지 완만하게(smoothly) 저하하며, 저프레임률 코덱의 실용적 효율 이점이 이전 가정보다 훨씬 접근 가능함을 입증.
- **실험 결과:** 학습 설정 교정 후 WER이 음소 부하(phonemic load)에 비례하여 1.6 Hz까지 완만하게 저하. 기존에 보고된 6.25 Hz quality cliff가 재현되었으나, 교정된 설정에서는 소멸.
- **우리 연구 관련도:** ★★★ — 저프레임률 코덱의 품질 저하 원인 분석이 VQ-based speech representation의 시간 해상도 설계에 직접적 인사이트 제공. 토큰 밀도와 표현 품질의 관계에 대한 실증적 발견이 speech tokenizer의 프레임률 선택에 핵심 참고. 학습 설정이 표현 품질에 미치는 영향 분석이 speech SSL 사전학습 설계에도 적용 가능.

### 3-3. Fast Speech Foundation Model Distillation Using Interleaved Stacking

**(Eungbeom Kim, Kyogu Lee — Seoul National University, 2026-06-10)** — Interspeech 2026 accepted

- https://arxiv.org/abs/2606.11766
- **기존 문제:** Speech Foundation Model(SFM)의 지식 증류(knowledge distillation) 시, 대형 교사 모델의 학습에 막대한 연산 비용이 소요. 기존 학습 가속 기법인 스태킹(stacking) — 얕은 모델의 가중치를 복제하여 깊은 모델을 초기화하는 방법 — 을 SFM 증류에 적용하면 성능 저하가 발생.
- **기존 방법:** 기존 스태킹 방법은 학습된 얕은 모델의 레이어를 순차적으로 복제하여 깊은 모델을 구성. 그러나 SFM은 각 레이어가 고유한 계층별 지식(layer-specific knowledge)을 인코딩하므로, 단순 복제 시 레이어 위치 정보가 교란되어 학습된 표현이 손상.
- **제안 방법:** Interleaved Stacking — 스태킹 과정에서 레이어 위치(layer position)를 일관되게 보존하는 새로운 방법. 기존의 순차 복제 대신, 교차 배치(interleaving)를 통해 각 레이어가 원래의 상대적 위치를 유지하도록 함. SFM의 계층별 고유 지식이 보존되면서도 깊은 모델로의 확장이 가능.
- **핵심 차별점:** SFM에서 각 레이어가 인코딩하는 지식의 위치 의존성(position-dependence)을 최초로 식별하고, 이를 보존하는 스태킹 전략을 제안. 기존 스태킹 대비 성능 저하 없이 학습 가속을 달성.
- **실험 결과:** 기존 스태킹 방법 대비 일관된 성능 보존을 보이며 학습 시간 단축. SFM 증류의 학습 효율을 크게 향상.
- **우리 연구 관련도:** ★★★ — SFM의 계층별 지식 구조(layer-specific knowledge)에 대한 분석이 speech SSL 모델의 내부 표현 구조 이해에 직접적으로 관련. 레이어 위치가 표현 품질에 미치는 영향에 대한 발견이 speech representation learning에서의 모델 설계와 학습 전략에 핵심적 시사점 제공. 증류 가속 기법이 대규모 speech SSL 모델의 효율적 학습에 실용적으로 적용 가능.
