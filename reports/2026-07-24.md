## 1. ASR (Automatic Speech Recognition)

### **[Diarization-Guided Qwen-ASR Adaptation for Multilingual Two-Speaker Conversational Speech] (Hao Wu, RongQi Han, Zhen Wang, Wei Liang, Wei Xu — 2026.07)** — MLC-SLM 2026 Challenge
- **arxiv:** https://arxiv.org/abs/2607.08208
- **기존 문제:** 다국어 2인 대화 음성 인식에서는 화자 분리와 ASR을 동시에 정확하게 수행하기 어렵고, 특히 저자원 언어에서 학습 데이터 부족으로 인해 성능이 크게 저하됨
- **기존 방법:** 별도의 화자 분리 모듈과 ASR 모듈을 파이프라인으로 연결하거나, end-to-end 다화자 ASR 모델을 사용하는 접근법이 존재했으나, 다국어 환경에서의 일반화가 부족
- **제안 방법:** 모듈형 화자 분리 프론트엔드(VAD + CAMPPlus 임베딩 + 스펙트럴 클러스터링)와 Qwen3-ASR-1.7B를 결합. ASR 적응은 (1) 풀 파인튜닝 → (2) TTS 합성 데이터로 LoRA 파인튜닝 → (3) GRPO 강화학습(WER/CER 기반 보상, 환각·반복·길이 편차 페널티) 3단계로 수행
- **핵심 차별점:** GRPO 강화학습을 ASR 적응에 적용하여 환각과 반복 오류를 체계적으로 억제하며, TTS 기반 합성 데이터 증강으로 저자원 언어 커버리지를 확대
- **실험 결과:** 공식 개발 셋에서 평균 tcpMER 23.70 달성(기본 Qwen-ASR 대비 6.83 포인트 절대 감소). 최종 평가 셋에서 평균 tcpMER 17.97
- **우리 연구 관련도:** ★☆☆ — ASR 파인튜닝 및 RL 기반 최적화 중심으로, prediction-free SSL이나 VQ 표현 학습과는 직접적 연관이 적음

- **기존 방법:** 단일 화자 TTS 합성 데이터를 ASR 학습에 활용하거나, 기존 대화 데이터를 증강하는 방식이 사용되었으나, 자연스러운 대화 시나리오를 재현하기 어려움
- **제안 방법:** LLM으로 시나리오 수준의 대화를 생성하고, 참여자 메타데이터를 TTS 음성 프로필에 매핑한 뒤, 합성 발화를 화자 인식 시뮬레이션 대화로 조립하는 증강 파이프라인 제안
- **핵심 차별점:** 단순 발화 합성이 아닌 시나리오 수준의 대화 맥락을 생성하여 화자 전환, 턴테이킹 등 자연스러운 대화 특성을 보존
- **실험 결과:** 67시간의 실제 대화와 636시간의 시뮬레이션 데이터만으로, 2700시간 헝가리어 음성으로 학습한 zero-shot 모델보다 우수한 성능 달성
- **우리 연구 관련도:** ★☆☆ — 데이터 증강 파이프라인 중심으로, 음성 표현 학습 자체와는 거리가 있음

## 2. SpeechLLM (Speech Language Model)

### **[NTPP: Generative Speech Language Modeling for Dual-Channel Spoken Dialogue via Next-Token-Pair Prediction] (Qichao Wang, Ziqiao Meng, Wenqian Cui et al. — 2025.06)** — ICML 2025 accepted
- **arxiv:** https://arxiv.org/abs/2506.00975
- **기존 문제:** 기존 음성 언어 모델(SLM)은 단일 채널 또는 단순 연결 방식으로 대화를 모델링하여, 실제 인간 대화의 이중 채널(dual-channel) 구조와 역동성을 충분히 활용하지 못함
- **기존 방법:** 단일 채널 음성 토큰을 순차적으로 예측하거나, 화자 구분 없이 대화를 하나의 시퀀스로 처리하는 방식이 주류
- **제안 방법:** Next-Token-Pair Prediction(NTPP) — decoder-only 아키텍처에서 최초로 화자 독립적 이중 채널 대화 학습을 가능하게 하는 생성 모델링 패러다임. 시간 정렬된 이중 채널 음성 시퀀스 구조를 활용하여 다음 토큰 쌍을 동시에 예측
- **핵심 차별점:** 기존의 단일 토큰 예측 대신 토큰 쌍 예측으로 화자 간 상호작용(턴테이킹, 오버랩 등)을 자연스럽게 모델링하며, 추론 지연시간도 크게 단축
- **실험 결과:** 턴테이킹 예측과 응답 일관성에서 기존 SLM 대비 유의미한 개선, 추론 지연시간 대폭 감소
- **우리 연구 관련도:** ★★☆ — 음성 토큰 기반 생성 모델링에서의 새로운 패러다임으로, speech tokenizer 설계와 관련성이 있음

### **[From Awareness to Adherence: Bridging the Context Gap in Spoken Dialogue Systems via Context-Aware Decoding] (Che Hyun Lee, Heeseung Kim, Sungroh Yoon — 2026.06)** — arxiv preprint
- **arxiv:** https://arxiv.org/abs/2606.16472
- **기존 문제:** End-to-end 음성 대화 시스템에서 다회차 대화 시 엄격한 맥락 준수가 어렵고, 이전 발화 내용을 무시하거나 모순되는 응답을 생성하는 문제 발생
- **기존 방법:** 대화 이력을 모델에 직접 입력하거나, 긴 컨텍스트 윈도우를 사용하는 방식이 일반적이었으나, 모델이 내부적으로 맥락을 인식하면서도 parametric prior에 의해 무시하는 현상이 존재
- **제안 방법:** 오디오 적응형 Context-Aware Decoding(CAD) — 내부 어텐션 메커니즘을 활용하여 핵심 과거 대화 라운드를 분리하고, 해당 맥락이 있을 때와 없을 때의 출력 분포를 대조하여 멀티모달 맥락 신호를 직접 증폭
- **핵심 차별점:** latent context awareness와 active adherence 사이의 간극을 규명하고, 학습 없이(inference-time) 맥락 충실도를 향상시키는 디코딩 전략 제안
- **실험 결과:** Audio MultiChallenge 벤치마크에서 Semantic Memory와 Self Coherence 하위 과제에서 유의미한 성능 향상
- **우리 연구 관련도:** ★☆☆ — 디코딩 전략 중심으로, 음성 표현 학습 자체와는 직접적 연관이 적음

### **[Efficient Chain-of-Modality Reasoning via Progressive Compression for Spoken Language Models] (Pengchao Feng, Chao-Hong Tan, Qian Chen, Wen Wang, Xiangang Li, Xie Chen — 2026.07)** — ACM Multimedia 2026 accepted
- **arxiv:** https://arxiv.org/abs/2607.19932
- **기존 문제:** 음성 언어 모델(SLM)의 추론 능력이 텍스트 기반 LLM에 비해 뒤처지며, 특히 음성 수학 문제 풀이(spoken mathematical QA)에서 순전히 구어화된 수학 표현으로 추론해야 하므로 정확도가 낮음
- **기존 방법:** Chain-of-Modality(CoM) 접근법으로 음성을 텍스트로 변환 후 추론하는 방식이 있었으나, 토큰 예산이 많이 소모되는 비효율 문제 존재
- **제안 방법:** Efficient Chain-of-Modality Reasoning(ECoM) — 텍스트 구성요소를 압축하여 음성 가이던스와 추론 표현을 동시에 수행하는 최초의 압축 추론 프레임워크. 표준 CoM 대비 더 적은 토큰 예산으로 추론 정확도 향상
- **핵심 차별점:** SLM에 압축 추론(compressed reasoning)을 최초로 도입하여, 음성→텍스트 변환의 완전한 토큰을 생성하지 않고도 효과적으로 추론 가능
- **실험 결과:** 표준 Chain-of-Modality 아키텍처 대비 더 적은 토큰 예산으로 추론 정확도 향상 달성
- **우리 연구 관련도:** ★★☆ — 음성-텍스트 간 표현 압축과 모달리티 전환에서의 효율적 추론으로, speech representation의 정보 밀도 연구와 관련성이 있음

## 3. Speech Foundation Model

### **[Which Speech Representation Better Matches Text-Native Reasoning? A Study of Speech-Text Alignment on Frame Rate and Representation] (Zhen Ye, Xu Tan, Yiming Li et al. — 2026.06)** — arxiv preprint
- **arxiv:** https://arxiv.org/abs/2606.12199
- **기존 문제:** 텍스트 LLM 백본에서 출발하는 음성 대화 모델에서, 음성 조건화 시 추론 능력이 텍스트 대비 저하되는 모달리티 갭 존재
- **기존 방법:** 고정된 프레임 레이트(일반적으로 12.5Hz~50Hz)의 음성 토큰을 LLM에 입력하는 방식이 주류였으나, 시간적 중복으로 인해 토큰당 의미 밀도가 낮아져 텍스트 네이티브 추론 역학이 약화됨
- **제안 방법:** 음성 토큰 설계를 표현 선택 문제로 정의하고, 고정 정보율 하에서 프레임 레이트를 체계적으로 탐색. 저프레임 레이트를 실현하기 위해 factorized FSQ와 경량 비자기회귀 오디오 LM 헤드를 도입하여 프레임당 약 300비트까지 용량 확장
- **핵심 차별점:** 프레임 레이트와 표현 정렬의 최적 지점을 체계적으로 분석한 최초의 연구. 4.17Hz에서 중간 레이어 표현 정렬이 음성 QA에 최적임을 발견
- **실험 결과:** 4.17Hz + 중간 레이어 정렬에서 음성 QA 과제에서 일관된 최적 성능 달성
- **우리 연구 관련도:** ★★★ — 음성 표현의 프레임 레이트, 정보 밀도, VQ 설계가 핵심 주제로, prediction-free SSL 및 VQ-based representation 연구와 직접적으로 관련됨

### **[Fast Speech Foundation Model Distillation Using Interleaved Stacking] (Eungbeom Kim, Kyogu Lee — 2026.06)** — Interspeech 2026 accepted
- **arxiv:** https://arxiv.org/abs/2606.11766
- **기존 문제:** 대형 음성 기반 모델(SFM)의 증류(distillation)는 추론 지연을 줄여주지만, 학생 모델 학습 자체에 소요되는 비용이 크며, SFM 증류의 학습 효율성에 대한 연구가 부족
- **기존 방법:** 기존 stacking 방법(모델 깊이를 점진적으로 증가시키며 학습)은 학습 속도를 향상시키나, 성능 저하 문제가 발생
- **제안 방법:** Interleaved stacking — 기존 stacking과 달리 깊이 확장 과정에서 레이어 위치를 일관되게 보존하는 새로운 방법. SFM에서는 각 레이어가 고유한 레이어별 지식을 인코딩하므로 위치 보존이 핵심적
- **핵심 차별점:** SFM의 레이어별 특화 지식을 보존하면서 학습 속도를 가속화. 기존 stacking의 성능 저하 문제를 해결
- **실험 결과:** SUPERB 벤치마크에서 기존 stacking 방법 대비 성능 저하 없이 학습 가속 달성
- **우리 연구 관련도:** ★★★ — SFM의 레이어별 표현 특성 보존과 효율적 학습에 관한 연구로, speech SSL 모델의 구조와 표현 학습 방식에 직접적 시사점 제공

- **실험 결과:** 음성 처리, 환경음 분석, 음악 정보 검색, 의료/생체음향 분석, 멀티모달 오디오 이해 등 5개 도메인에서의 일반화 능력을 체계적으로 비교 분석
