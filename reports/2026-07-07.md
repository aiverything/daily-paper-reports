## 1. ASR (Automatic Speech Recognition)

### 1-1. H-SAGE: Holistic Speaker-Aware Guided Experts for MoE-based Multi-Talker ASR
**(Yujie Guo, Jiaming Zhou, Yuhang Jia, Yang Chen, Yong Qin, NKU-HLT, 2026.07)** — ICME 2026

- **arXiv:** https://arxiv.org/abs/2607.01566
- **기존 문제:** Multi-talker ASR(다화자 중첩 음성 인식)에서 기존 MoE 기반 방법(GLAD)은 글로벌 정보를 단순 선형 투영으로 획득하며 명시적 지도가 없어, 장거리 의존성 모델링과 화자 역학 파악에 한계가 있었다. 또한 전문가 라우팅이 로컬 음향 특징에만 의존하여 글로벌 맥락 정보를 활용하지 못했다.
- **기존 방법:** SOT(Serialized Output Training)가 주류로, SA-SOT(화자 인식), BA-SOT(경계 인식), Speaker-Aware CTC 등이 화자 분리를 보조하는 방식이었다. GLAD는 MoE를 MTASR에 최초 적용했으나 글로벌 인코더가 단순 선형 구조였다.
- **제안 방법:** (1) Self-attention 기반 Speaker-Aware Encoder(SA-Encoder)로 장거리 음향 의존성을 포착하여 풍부한 글로벌 표현 생성, (2) 프레임 수준 음향 상태(단일 화자/중첩/묵음)를 예측하는 Overlap-Aware Loss(OA Loss)로 글로벌 특징에 명시적 지도 제공, (3) 로컬 음향 단서와 글로벌 맥락 표현을 동시에 평가하여 전문가 선택을 중재하는 Holistic Gating Mechanism 설계.
- **핵심 차별점:** 글로벌 표현에 대한 명시적 음향 상태 지도(OA Loss)를 도입하여, 추가 파라미터 0.52M(35.83M vs. 35.31M)만으로 전문가 협업을 효과적으로 강화. 약한/노이즈 지도 신호에서도 일관된 개선 달성.
- **실험 결과:** LibriSpeechMix 기준 — 2mix test WER 5.8%(GLAD 6.2% 대비 6.5% 상대 개선), 2mix 저중첩 4.4%(GLAD 5.0%, 12% 상대 개선), 3mix test WER 19.9%(GLAD 21.1%, 5.7% 상대 개선). 단일 화자 LibriSpeech test에서도 3.5%(GLAD 3.8%) 달성. 코드 공개(github.com/NKU-HLT/H-SAGE).
- **우리 연구 관련도:** ★☆☆ — MoE 기반 다화자 ASR로 SSL/VQ 표현 학습과 직접 관련은 낮으나, 화자 인식 표현의 명시적 지도 방식이 화자 관련 표현 학습 연구에 참고 가능.

### 1-2. Mind the Gap: Impact of Synthetic Conversational Data on Multi-Talker ASR and Speaker Diarization
**(Alexander Polok, Ivan Medennikov, Jan Černocký, Shinji Watanabe, Lukáš Burget, Samuele Cornell, BUT / CMU / NVIDIA, 2026.05)** — arxiv preprint

- **arXiv:** https://arxiv.org/abs/2605.15442
- **기존 문제:** 다화자 ASR(MT-ASR)과 화자 분할(SD) 모두 대규모 대화형 데이터의 부족으로 합성 데이터에 의존하지만, 시뮬레이션 설계 선택(턴 테이킹 역학, 소스 도메인, 음향 증강 등)이 각 태스크 성능에 미치는 영향은 체계적으로 연구되지 않았다.
- **기존 방법:** MT-ASR은 DiCoW, SD는 Sortformer 등 최신 시스템들이 합성 데이터로 학습되었으나, 시뮬레이션 레시피를 경험적으로 설정해왔다.
- **제안 방법:** 고효율 오픈소스 시뮬레이터 FastMSS(1,000시간 주석 다화자 오디오를 5분 이내 생성)를 도입하고, 턴 테이킹 역학, 소스 도메인, 음향 증강, 데이터 혼합 전략을 체계적으로 분석한다.
- **핵심 차별점:** 최적 시뮬레이션 레시피가 태스크 의존적임을 입증 — 음성 중첩 증가는 ASR에 유리하나 다이어리제이션에는 해로움. 노이즈+잔향 결합이 다이어리제이션에서 약 4% 절대 macro DER 감소 효과. 광범위한 소스 다양성이 정확한 도메인 매칭보다 일관되게 우수.
- **실험 결과:** 합성 전용 학습이 실제 데이터 베이스라인에 근접. 2단계 전략(합성 사전학습 → 실제 데이터 미세조정)이 실제 데이터 전용 학습 대비 양 태스크에서 상당한 개선 달성. FastMSS 오픈소스 공개.
- **우리 연구 관련도:** ★☆☆ — 다화자 시나리오의 데이터 시뮬레이션 연구로, SSL 표현 학습과 직접 관련은 낮으나 화자 관련 데이터 설계 통찰 제공.

### 1-3. Efficient and Generalizable Speaker Diarization via Structured Pruning of Self-Supervised Models
**(Jiangyu Han, Petr Pálka, Marc Delcroix, Federico Landini, Johan Rohdin, Jan Černocký, Lukáš Burget, BUT / NTT, 2025.06)** — arxiv preprint

- **arXiv:** https://arxiv.org/abs/2506.18623
- **기존 문제:** WavLM 등 SSL 모델이 화자 분할 성능을 크게 향상시켰으나, 높은 계산·메모리 비용으로 실시간 및 자원 제약 환경 배포에 한계가 있었다.
- **기존 방법:** SSL 모델을 그대로 활용하거나, 별도의 경량 모델을 학습하는 방식. 체계적인 SSL 모델 압축 연구는 화자 분할 분야에서 부족했다.
- **제안 방법:** 지식 증류로 안내되는 구조적 프루닝(structured pruning)을 통해 SSL 기반 다이어리제이션 모델을 압축. 모델 파라미터와 계산 복잡도를 동시에 목표로 하는 프루닝 목적함수를 조사하며, 단순 전체 프루닝이 효율성-정확도 간 최적 균형을 제공함을 입증. DiariZen 프레임워크(로컬 EEND + 화자 임베딩 클러스터링) 기반으로 WavLM과 Conformer를 통합.
- **핵심 차별점:** 최대 80% 모델 크기 감소, 4배 추론 속도 향상을 성능 저하 없이 달성. 8개 공개 다이어리제이션 데이터셋에서 프루닝된 모델이 원본 모델과 동등하거나 상회하는 일관된 성능 입증.
- **실험 결과:** 도메인 적응 없이 CHiME-6 평가셋에서 DER 33.3%(0.25초 칼라)로 CHiME-7 챌린지 3위 시스템에 필적. WavLM Base+와 Large 모두에서 프루닝 후 도메인 외 설정에서도 경미한 성능 저하만 발생. 코드 및 사전학습 모델 오픈소스 공개(DiariZen, HuggingFace).
- **우리 연구 관련도:** ★★☆ — SSL 모델(WavLM)의 구조적 프루닝으로 어떤 레이어/헤드가 화자 분할에 핵심적인지를 밝히며, SSL 표현의 정보 분포에 대한 통찰 제공. 효율적 SSL 모델 설계에 참고 가치.

## 2. SpeechLLM (Speech-Language Model)

### 2-1. A Survey of Full-Duplex Spoken Dialogue Systems: Architectural Hierarchy, Interaction Ontology, and Decision State Machine
**(Jingyu Lu et al., Zhejiang Univ. / Alibaba Qwen / Tencent HunYuan / ByteDance, 2026.06)** — arxiv preprint

- **arXiv:** https://arxiv.org/abs/2606.19453
- **기존 문제:** 최근 12개 이상의 음성 대화 시스템이 "full-duplex"를 표방하지만, 이 용어가 실질적으로 매우 다른 능력을 지칭하는 데 사용되어 분류 체계와 용어 정의에 혼란이 존재했다.
- **기존 방법:** WavChat, 기존 서베이 등이 음성 대화 모델을 개관했으나, full-duplex 능력에 대한 체계적 분류 프레임워크가 부재했다.
- **제안 방법:** 세 가지 분류 프레임워크를 제안한다. (1) L0-L3 Architectural Hierarchy — 시스템 아키텍처를 계층적으로 분류(L0: 캐스케이드, L1: 반이중, L2: 준전이중, L3: 완전전이중), (2) T×I×R Interaction Ontology — Turn-taking, Interruption, Response 세 축으로 상호작용 능력을 체계적으로 분류, (3) Decision State Machine — IDLE/LISTEN/SPEAK/WAIT/DUAL 다섯 상태로 시스템의 의사결정 프로세스를 모델링.
- **핵심 차별점:** "Full-duplex"의 모호한 사용을 해소하는 최초의 체계적 분류 체계. 34페이지, 5개 figure, 7개 table의 포괄적 분석. 프로젝트 페이지 및 인터랙티브 데모 제공.
- **실험 결과:** 기존 시스템들을 제안 프레임워크로 분류·비교 분석. 현재 시스템들의 능력 수준 분포와 향후 발전 방향을 체계적으로 정리.
- **우리 연구 관련도:** ★☆☆ — 음성 대화 시스템의 아키텍처 분류로 SSL/VQ와 직접 관련은 낮으나, 음성 기반 LLM 시스템의 전체 생태계를 이해하는 데 유용한 레퍼런스.

### 2-2. Dual-Axis Generative Reward Model Toward Semantic and Turn-taking Robustness in Interactive Spoken Dialogue Models
**(Yifu Chen, Shengpeng Ji, Zhengqing Liu, Qian Chen, Wen Wang et al., Zhejiang Univ. / Alibaba / BIT, 2026.04)** — ACL 2026 accepted

- **arXiv:** https://arxiv.org/abs/2604.14920
- **기존 문제:** Full-duplex 음성 대화 모델(SDM)의 상호작용 품질을 자동으로 평가하는 기존 메트릭은 행동 통계나 타이밍 예측 정확도 등 피상적 대리 지표에 의존하여, RL을 위한 신뢰할 수 있는 보상 신호를 제공하지 못했다. 인간 평가는 비용이 높고 일관성이 낮아 확장이 어려웠다.
- **기존 방법:** 대화 품질을 단일 점수로 평가하거나, 의미적 품질과 상호작용 타이밍을 분리하지 않는 평가 방식이 주류였다.
- **제안 방법:** 상호작용 역학의 체계적 분류 체계(taxonomy)와 합성+실제 full-duplex 상호작용 데이터셋으로 학습된 LLM 기반 보상 모델을 제안. 의미적 품질(semantic)과 상호작용 타이밍(turn-taking)을 이축(dual-axis)으로 분리 평가하여, SDM에 대한 정밀한 진단 피드백과 온라인 RL을 위한 신뢰성 있는 보상 신호를 제공.
- **핵심 차별점:** 의미적 품질과 턴 테이킹 견고성을 분리한 이축 평가로 SDM의 구체적 약점을 진단 가능. 생성형 보상 모델로 확장성과 일관성을 확보.
- **실험 결과:** 합성 대화와 복잡한 실세계 상호작용을 아우르는 광범위한 데이터셋에서 상호작용 품질 평가 SOTA 달성. 코드 공개(github.com/MM-Speech/DualAxisRM).
- **우리 연구 관련도:** ★☆☆ — RL 기반 음성 대화 모델 최적화로, 음성 표현 학습/VQ와 직접 관련은 낮으나 음성 LLM 시스템의 평가 체계 이해에 참고 가치.

## 3. Speech Foundation Model

### 3-1. Differentiable K-means for Fully-optimized Discrete Token-based ASR
**(Kentaro Onda, Yosuke Kashiwagi, Emiru Tsunoo, Hayato Futami, Shinji Watanabe, UTokyo / Sony / CMU, 2025.05)** — Interspeech 2025 accepted

- **arXiv:** https://arxiv.org/abs/2505.16207
- **기존 문제:** SSL 특징의 이산 토큰은 통상 k-means 클러스터링으로 획득되나, 이 과정이 다운스트림 태스크와 독립적으로 수행되어 특정 태스크에 대해 최적이 아닌 토큰이 생성되었다.
- **기존 방법:** SSL 특징(HuBERT 등)에 대해 고정된 k-means를 적용하고, 생성된 이산 토큰을 다운스트림 ASR 모델에 입력하는 2단계 파이프라인이 표준이었다.
- **제안 방법:** k-means 클러스터링을 미분 가능하게(differentiable) 만들어, 토큰화와 다운스트림 ASR 태스크의 공동 최적화를 가능케 한다. 이를 통해 ASR 목적함수로부터 SSL 특징까지의 역전파가 가능해지며, 다수 SSL 레이어 출력에 대한 가중치 학습도 지원한다.
- **핵심 차별점:** 이산 토큰 기반 ASR에서 최초로 토큰화 과정 자체를 다운스트림 최적화에 포함. 토큰화와 ASR을 end-to-end로 공동 최적화하여, 연속 SSL 특징 기반 시스템에 근접하는 성능을 이산 토큰으로 달성.
- **실험 결과:** LibriSpeech-100 기준 — full finetune 시 클러스터 100개에서 WER 5.4/9.2%(baseline 7.6/13.2%), 클러스터 2000개에서 WER 4.2/6.8%(연속 특징 시스템 3.7/6.6%에 근접). 다층 가중치 학습과 결합 시 최적 성능. 획득된 토큰이 음소 정보의 높은 순도(phonetic purity)를 보이며, 음성 재합성에서도 유용함을 확인. LibriSpeech-960 및 ML-SUPERB에서도 일관된 개선.
- **우리 연구 관련도:** ★★★ — VQ 기반 이산 토큰의 다운스트림 최적화를 미분 가능 k-means로 구현. VQ-based representation 연구에 직접적으로 관련되며, k-means 클러스터링의 토큰 품질 최적화 방법론이 우리의 VQ 코드북 설계에 시사점 제공.

### 3-2. SPARCLE: SPeaker-aware Aligned Representations via Contrastive Language Embeddings
**(Priyam Mazumdar, Yurii Halychanskyi, Steven Guo, Mark Hasegawa-Johnson, Volodymyr Kindratenko, UIUC, 2026.07)** — Interspeech 2026 accepted

- **arXiv:** https://arxiv.org/abs/2607.01238
- **기존 문제:** 기존 grapheme-to-phoneme(G2P) 시스템은 화자 독립적이어서, 동일 문자가 화자에 따라 다르게 발음되는 변이를 포착하지 못했다. 이는 특히 극소량 자원 TTS 환경에서 생성 품질 저하를 초래했다.
- **기존 방법:** 표준 G2P 변환 후 TTS 모델에 입력하는 방식이 주류. 화자별 음향 실현(acoustic realization)을 문자 표현에 반영하는 체계적 방법은 부재했다.
- **제안 방법:** 화자 정체성에 조건화된 contrastive 목적함수로 grapheme을 Wav2Vec2 음향 표현과 정렬하는 화자 인식 grapheme 표현 모델 SPARCLE을 제안. 각 문자에 해당 화자의 정확한 음향 실현을 풍부하게 포함시켜, 다운스트림 TTS에서 G2P 시스템을 대체한다.
- **핵심 차별점:** Contrastive learning으로 grapheme-음향 정렬을 화자 조건부로 학습하여, 화자별 발음 변이를 문자 수준에서 포착. 극소량 자원 TTS에서 WER을 절반으로 감소.
- **실험 결과:** 극소량 자원(extreme low-resource) TTS 환경에서 표준 grapheme 기반 모델 대비 WER 50% 감소. 5페이지, 1개 figure, 2개 table.
- **우리 연구 관련도:** ★★★ — Contrastive learning을 활용한 음향-언어 표현 정렬이 핵심 방법론. 화자 조건부 contrastive 학습으로 SSL 음향 표현(Wav2Vec2)과 언어 표현을 연결하며, temporal contrastive learning 및 화자 인식 표현 학습 연구와 직접적 관련.

### 3-3. UniAudio-Token: Empowering Semantic Speech Tokenizers with General Audio Perception
**(Yuhan Song, Linhao Zhang, Aiwei Liu, Chuhan Wu et al., Peking Univ. / Tencent WeChat AI, 2026.05)** — arxiv preprint

- **arXiv:** https://arxiv.org/abs/2605.31521
- **기존 문제:** Audio-LLM의 인터페이스로 사용되는 시맨틱 음성 토크나이저는 언어적 추상화에 집중하여 "음향적 맹목(acoustic blindness)"을 유발, 음성 중심 태스크 이외의 일반 오디오 태스크(환경음, 음악 등)에서 적용이 제한되었다.
- **기존 방법:** HuBERT 등 시맨틱 토크나이저는 언어 콘텐츠 위주로 정보를 압축하며, 음향적 세부사항(운율, 음색, 환경음)은 별도의 어쿠스틱 코덱이나 다중 코드북으로 보완하는 방식이었다.
- **제안 방법:** 두 가지 핵심 혁신을 도입한다. (1) Semantic-Acoustic Primitives(SAP) — 오디오를 언어 콘텐츠, 음성 속성, 청각 장면 프리미티브로 분해하는 구조화된 지도 제공, (2) Semantic-Acoustic Equilibrium(SAE) — 얕은 레이어에서 세밀한 음향 디테일을 적응적으로 복원하는 콘텐츠 인식 게이팅 메커니즘.
- **핵심 차별점:** 단일 코드북 토크나이저로 시맨틱(언어적)과 어쿠스틱(음향적) 정보를 동시에 포착하는 보편적 오디오 표현 학습. 이해(understanding)와 생성(generation) 태스크 모두에서 기존 단일 코드북 베이스라인 상회.
- **실험 결과:** 다운스트림 LLM과 통합 시 모든 단일 코드북 베이스라인 토크나이저 대비 이해 및 생성 태스크에서 우수한 성능. 고충실도 음성 생성을 유지하면서 포괄적 보편 표현 학습 달성. 코드, 학습 스크립트, 모델 체크포인트 공개(github.com/Tencent/Universal_Audio_Tokenizer).
- **우리 연구 관련도:** ★★★ — 시맨틱 토크나이저의 음향 정보 손실 문제를 해결하는 연구로, VQ 기반 음성 표현에서 언어적 vs. 음향적 정보의 균형 문제와 직접 관련. SAP의 구조화된 프리미티브 분해가 우리의 표현 학습 설계에 시사점 제공.
