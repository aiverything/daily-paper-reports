## 1. ASR (Automatic Speech Recognition)

### 1-1. Surprise-Gated Memory for Live Speaker Diarization

**[Surprise-Gated Memory for Live Speaker Diarization] (Louis Mouchon, Alexis Lainault, 2026-11-16)** — arxiv preprint
- https://arxiv.org/abs/2611.20819
- **기존 문제**: 온라인 스트리밍 화자 분리(diarization)에서 새로운 화자가 등장할 때 이를 즉시 인식하고 기존 화자와 구분하는 것이 어렵다. 오프라인 시스템 대비 온라인 시스템의 DER(Diarization Error Rate) 격차가 크다.
- **기존 방법**: Streaming Sortformer, LS-EEND 등 end-to-end 신경망 기반 스트리밍 다이어리제이션이 주류였으나, 화자 수가 미리 고정되거나 장시간 세션에서 성능이 저하되는 한계가 있었다. 별도의 클러스터링 단계(e.g., spectral clustering, AHC)를 사용하는 모듈러 접근도 존재.
- **제안 방법**: 연속 학습(continual learning) 분야의 Surprise-Gated Memory(SGM) 기법을 온라인 화자 분리에 적용한 SGM-Diar 제안. 고정된(frozen) 인코더가 생성하는 novelty 신호를 기반으로 새 화자 여부를 판단하고, one-shot episodic memory에 저장 후 replay를 통해 통합(consolidation)하는 구조.
- **핵심 차별점**: 학습 없이(training-free에 가까운) 메모리 기반 접근으로, 추론 시 그래디언트 업데이트 없이 화자를 인식. 화자 수에 대한 사전 가정이 불필요하며, 세션 종료 시 메모리를 초기화하는 단순한 설계.
- **실험 결과**: AMI-SDM 3개 미팅 + VoxConverse 5개 세션에서 평가. One-shot 화자 재인식(recall) 0.857, 거짓 novelty 비율 0.001. 나이브 온라인 베이스라인과 오프라인 오라클 간 9.2 DER 포인트 격차 중 4.8 포인트를 회복. Sliding replay window가 replay 없는 경우보다 오히려 나쁜 결과를 보임(시각적 SGM 연구의 예측을 재현). 2페이지 proof-of-concept 논문으로 단일 시드 실험임에 유의.
- **우리 연구 관련도**: ★☆☆ — 연속 학습 기반 메모리 메커니즘은 흥미로우나, speech SSL이나 VQ 표현과의 직접적 관련은 낮음.

### 1-2. eDIAR: Training-Free Open-Speaker Streaming Diarization for Long Meetings and Large Archives via e-means

**[eDIAR: Training-Free Open-Speaker Streaming Diarization for Long Meetings and Large Archives via e-means] (저자 미확인, 2026-11-13)** — arxiv preprint
- https://arxiv.org/abs/2611.18529
- **기존 문제**: 스트리밍 화자 분리 시스템들이 장시간 회의(1시간 이상)나 대규모 아카이브에서 성능이 급격히 저하된다. Streaming Sortformer 등 최신 모델도 회의 길이가 길어지면 화자 추적 정확도가 떨어지는 현상이 보고됨.
- **기존 방법**: NVIDIA Streaming Sortformer 기반 스트리밍 다이어리제이션이 최근 SOTA를 달성했으나, 고정 길이 세그먼트 처리와 화자 캐시 관리에서 장시간 열화(degradation) 문제가 있었다. 별도 학습이 필요한 end-to-end 모델들은 도메인 전이에 취약.
- **제안 방법**: e-means라는 학습 불필요(training-free) 온라인 클러스터링 알고리즘을 제안하여, Streaming Sortformer의 스트리밍 API 위에 경량 화자 추적 레이어를 구성. 별도의 모델 학습 없이 화자 임베딩의 점진적 클러스터링으로 오픈 화자 수를 처리.
- **핵심 차별점**: 완전히 학습이 필요 없는(training-free) 접근으로, 기존 스트리밍 다이어리제이션 모델의 출력을 후처리하여 장시간 녹음에서의 성능 저하를 완화. 화자 수 사전 지정 불필요.
- **실험 결과**: 기존 Streaming Sortformer 베이스라인이 장시간 회의에서 보이는 성능 저하를 개선. 구체적 수치는 검색으로 확인 불가하여 논문 원문 확인 필요.
- **우리 연구 관련도**: ★☆☆ — 학습 불필요 클러스터링 기법으로 speech SSL 표현의 활용 가능성은 있으나, 직접적 연관은 제한적.

## 2. SpeechLLM (Speech Language Model)

### 2-1. A Speech-LLM Framework for Enrollment-Free Wake-Word-Guided Target-Speaker Recognition in Complex Noisy Scenarios

**[A Speech-LLM Framework for Enrollment-Free Wake-Word-Guided Target-Speaker Recognition in Complex Noisy Scenarios for Seamless Human-Machine Interaction] (저자 미확인, 2026-11-15)** — arxiv preprint
- https://arxiv.org/abs/2611.19844
- **기존 문제**: 음성 인터페이스에서 목표 화자 인식(target-speaker recognition)은 사전 등록(enrollment) 음성이 필요하여, 실제 배포 환경에서 사용자 경험을 저해한다. 특히 복잡한 소음 환경에서 짧은 웨이크워드만으로 화자를 식별하는 것은 매우 어려운 과제.
- **기존 방법**: 기존 target-speaker extraction(TSE) 모델은 별도의 enrollment 음성을 요구하며, 웨이크워드만으로 등록하는 Enroll-on-Wakeup 접근(arXiv 2602.15519)이 제안되었으나 짧고 노이즈가 섞인 웨이크워드 세그먼트에서 TSE 모델의 성능이 크게 저하되었다.
- **제안 방법**: 웨이크워드의 텍스트(lexical cue)를 화자 식별의 조건 신호로 활용하는 Speech-LLM 프레임워크 제안. 사전학습된 음성 인코더를 웨이크워드 텍스트로 조건화(conditioning)하고, LLM 디코더가 목표 화자의 명령을 전사하거나 거부 토큰(rejection token)을 출력하는 구조.
- **핵심 차별점**: 별도의 등록 음성 없이 웨이크워드 텍스트만으로 목표 화자를 식별하는 최초의 Speech-LLM 기반 접근. 음향적 화자 임베딩 대신 어휘적(lexical) 단서를 활용하여 노이즈 환경에서의 강건성 향상.
- **실험 결과**: 구체적 벤치마크 수치는 검색으로 확인 불가. 복잡한 노이즈 시나리오에서의 목표 화자 인식 성능 평가를 수행한 것으로 확인.
- **우리 연구 관련도**: ★★☆ — Speech-LLM이 음성 표현을 어떻게 조건화하여 활용하는지에 대한 인사이트 제공. 음성 표현의 화자 정보와 언어 정보 분리 측면에서 speech SSL 연구와 간접적 관련.

### 2-2. Latency, Speech Recognition and Turn-Taking in Voice Agents for Spanish Phone Negotiation

**[Latency, Speech Recognition and Turn-Taking in Voice Agents for Spanish Phone Negotiation: An Externally Measured Comparison of Pipecat, LiveKit and GPT-Live] (저자 미확인, 2026-11-14)** — arxiv preprint
- https://arxiv.org/abs/2611.19118
- **기존 문제**: 음성 에이전트(voice agent)의 실시간 대화 성능 평가가 대부분 영어 중심이며, 비영어 언어(특히 스페인어)에서의 체계적 비교 연구가 부족하다. 또한 cascaded 파이프라인과 end-to-end 음성 모델 간의 실제 전화 환경에서의 비교 데이터가 희소.
- **기존 방법**: Pipecat, LiveKit Agents 등 cascaded 파이프라인(ASR → LLM → TTS)이 모듈러 접근으로 주류를 이루고, GPT-Live 등 end-to-end speech model이 별도 단계 없이 직접 듣고 말하는 접근을 제시. 기존 벤치마크는 주로 내부 측정(internal metrics)에 의존.
- **제안 방법**: 스페인어 전화 협상(phone negotiation) 태스크에서 세 가지 아키텍처(Pipecat, LiveKit, GPT-Live)를 외부 관찰자(externally measured) 관점에서 비교. 아키텍처당 77회 통화를 수행하여 지연 시간(latency), 음성 인식 정확도, 턴테이킹 품질을 측정.
- **핵심 차별점**: 실제 전화 환경에서의 외부 측정 기반 비교라는 점에서, 내부 로그 기반 평가의 한계를 극복. Cascaded vs end-to-end 구조의 실질적 차이를 스페인어라는 비영어 언어에서 실증.
- **실험 결과**: 구체적 수치는 검색으로 확인 불가. 아키텍처당 77회 × 3 = 231회 총 통화에서 비교 수행. 8kHz 전화 코덱 환경에서의 ASR 성능 차이와 턴테이킹 행동 패턴을 분석한 것으로 확인.
- **우리 연구 관련도**: ★☆☆ — 음성 에이전트 시스템 비교 연구로, speech SSL이나 VQ 표현과의 직접적 관련은 낮으나 음성 모델의 실환경 배포 방향성 파악에 참고 가치.

## 3. Speech Foundation Model

### 3-1. Factorized Self-Supervised Speech Tokenization (Facto)

**[Factorized Self-Supervised Speech Tokenization] (저자 미확인, 2026-11-13)** — NeurIPS 2026 accepted (poster)
- https://arxiv.org/abs/2611.18898
- **기존 문제**: 기존 음성 토크나이저는 화자 정보, 콘텐츠, 프로소디, 녹음 조건 등이 얽혀(entangled) 있어 토큰의 중복성이 높고, 하위 태스크(TTS, 음성 변환, 언어 모델링)에서 불필요한 정보가 간섭한다.
- **기존 방법**: FocalCodec, Kanade 등 분리형(disentangled) 토크나이저가 제안되었으나, 대부분 RVQ 기반 코덱 구조에 의존하여 분리의 질이 양자화 설계에 제약. HuBERT, wav2vec 2.0 등 자기지도 학습(SSL) 모델의 표현을 직접 분리하는 연구는 제한적.
- **제안 방법**: Facto — 자기지도 학습(SSL) 특징의 선형 인수분해(linear factorization)에 기반한 음성 토크나이저. 시간에 따라 변하는 정보(콘텐츠, 프로소디)와 정적 정보(화자 정체성, 녹음 조건)를 분리하고, 분리된 공간에서 클러스터링 후 경량 디코더로 오디오를 복원. 미지 화자(unseen speakers)로의 일반화를 위해 선형 인수분해 방법을 확장.
- **핵심 차별점**: SSL 특징을 직접 선형적으로 분해하는 접근으로, 코덱 구조에 의존하지 않는 토크나이저 설계. 단일 코드북(single codebook)으로도 콘텐츠와 프로소디를 포착하면서 화자를 분리. 토큰 안정성(stability)이 향상되어 하위 태스크 성능 개선.
- **실험 결과**: 토큰 안정성 향상이 TTS 성능 개선으로 직결됨을 실증. 음성 변환(voice conversion)과 spoken language modeling에서도 경쟁력 있는 결과. FocalCodec, Kanade 대비 비교 실험 수행. NeurIPS 2026 포스터로 채택.
- **우리 연구 관련도**: ★★★ — SSL 표현의 선형 인수분해를 통한 분리형 토큰화는 prediction-free speech SSL 및 VQ-based representation 연구와 직접적으로 관련. 자기지도 학습 특징 공간에서의 콘텐츠-화자 분리 메커니즘이 핵심 참고 대상.

### 3-2. What Do Multilingual Self-Supervised Speech Encoders Know About Sentence Meaning?

**[What Do Multilingual Self-Supervised Speech Encoders Know About Sentence Meaning?] (Kevin Krahn, Eric Fosler-Lussier, 2026-11-13)** — arxiv preprint
- https://arxiv.org/abs/2611.17686
- **기존 문제**: 자기지도 학습(SSL) 음성 모델이 음소, 프로소디 등 저수준 정보를 잘 포착한다는 것은 알려져 있으나, 문장 수준의 의미 정보를 얼마나 담고 있는지, 특히 다국어 환경에서 언어별 차이가 어떤지에 대한 체계적 분석이 부족했다.
- **기존 방법**: SUPERB 벤치마크 등에서 SSL 모델의 음소 인식, 화자 인식 등 프레임/토큰 수준 태스크 평가가 주류. SpeechGLUE 등 문장 수준 평가가 시도되었으나 대부분 영어 단일 언어에 국한. 다국어 SSL 모델(MMS, XLS-R, OmniASR 등)의 의미 표현 능력에 대한 대규모 비교 부재.
- **제안 방법**: 9개 다국어 SSL 음성 인코더를 76개 언어에 걸쳐 경량 선형 프로브(linear probe)로 분석. 고정된(frozen) 음성 표현에서 고정된 텍스트 임베딩 공간으로의 선형 매핑을 학습하고, cross-modal retrieval로 평가하여 문장 의미의 선형 접근성(linear accessibility)을 측정.
- **핵심 차별점**: 76개 언어에 걸친 대규모 다국어 분석으로, 언어 자원 수준(high/mid/low-resource)에 따른 의미 표현 능력의 불균등성을 체계적으로 밝힘. 모델 스케일링과 ASR 튜닝의 영향을 분리하여 분석.
- **실험 결과**: 문장 의미는 선형적으로 접근 가능(linearly accessible)하지만 언어 간 불균등. OmniASR wav2vec 계열에서 300M → 7B 스케일링 시 고자원 언어에 불균형적으로 이득. ASR 튜닝은 의미 디코딩 가능성을 크게 향상시키지만, 표현을 더 언어 특정적(language-specific)으로 만듦.
- **우리 연구 관련도**: ★★★ — SSL 음성 표현의 의미 정보 분석은 speech representation learning의 핵심 주제. 선형 프로브를 통한 표현 분석 방법론과 스케일링에 따른 표현 변화 패턴이 prediction-free speech SSL 연구의 표현 품질 평가에 직접 활용 가능.
