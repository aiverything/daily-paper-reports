**[MoLGE: Mixture of Language Group Experts for Efficient Scaling of Massively Multilingual Speech Recognition] (Sangmin Lee, Woojin Chung, Woongjib Choi, Hong-Goo Kang — Yonsei University, 2026-07)** — COLM 2026 accepted

- https://arxiv.org/abs/2607.24030
- **기존 문제**: 대규모 다국어 ASR 시스템은 지원 언어 수가 증가할수록 언어 간 간섭(language interference)이 발생하여 개별 언어 성능이 저하되는 문제가 있었으며, 이를 해결하기 위해 모델 크기를 단순히 확장하면 추론 비용이 급격히 증가하였다.
- **기존 방법**: 일반적인 MoE(Mixture of Experts) 기반 다국어 ASR은 개별 전문가(expert)를 언어 단위 또는 무작위로 할당하여, 언어 간 음성학적(phonetic) 유사성을 활용하지 못하고 전문가 활용 효율이 낮았다.
- **제안 방법**: Conformer 기반 다국어 ASR에서 언어 그룹(language group) 단위로 전문가를 조직하는 MoLGE를 제안. 음성학적으로 유사한 언어들을 그룹화하여 동일 전문가 세트를 공유하도록 하고, 그룹 수준의 라우팅(routing)으로 언어 간 긍정적 전이(positive transfer)를 극대화하면서 간섭을 최소화한다.
- **핵심 차별점**: 언어 그룹 기반 전문가 조직은 기존 언어 단위 또는 무작위 할당 방식 대비 전문가 활용 효율을 크게 향상시키며, 추론 시 활성화되는 파라미터 수를 제한하여 계산 비용을 억제하면서도 다국어 성능을 확장할 수 있다.
- **실험 결과**: 대규모 다국어 ASR 벤치마크에서 기존 MoE 기반 다국어 ASR 대비 더 적은 활성 파라미터로 우수한 성능을 달성하였으며, 언어 그룹 기반 라우팅이 무작위 할당 대비 일관된 개선을 보였다.
- **우리 연구 관련도**: ★★☆ — 언어 그룹 기반 전문가 라우팅은 다국어 음성 표현에서 언어 간 유사성과 차이를 구조적으로 모델링하는 접근으로, speech SSL에서의 다국어 표현 학습 전략에 참고 가치가 있다.

**[MEUSLI: A Multilingual Projector for LLM-based ASR and Beyond] (Lorenzo Concina, Seraphina Fong, Marco Matassoni, Alessio Brutti — Fondazione Bruno Kessler, 2026-07)** — arxiv preprint

- https://arxiv.org/abs/2607.22100
- **기존 문제**: LLM 기반 ASR에서 음성 인코더와 LLM을 연결하는 프로젝터(projector)는 대부분 영어 중심으로 학습되었으며, 다국어 확장 시 처음부터 재학습이 필요하여 새로운 언어 추가가 비효율적이었다.
- **기존 방법**: 기존 LLM 기반 ASR 시스템(예: Whisper + LLM)은 영어 전용 프로젝터를 사용하거나, 다국어 지원 시 폐쇄형(closed-source) LLM에 의존하였다.
- **제안 방법**: Whisper 인코더와 오픈소스 다국어 LLM을 연결하는 최초의 오픈 사이언스 다국어 프로젝터 MEUSLI를 제안. 28개 유럽 언어를 지원하며, 지속적 학습(continual learning)을 통해 기존 언어 성능을 유지하면서 새로운 언어를 점진적으로 추가할 수 있다.
- **핵심 차별점**: 오픈소스 다국어 LLM과의 결합 및 지속적 학습 기반 언어 확장이 핵심이며, 폐쇄형 모델에 의존하지 않고도 다국어 ASR을 구현할 수 있는 재현 가능한 프레임워크를 제공한다.
- **실험 결과**: 28개 유럽 언어에서 Whisper 단독 대비 유의미한 WER 개선을 달성하였으며, 지속적 학습으로 새 언어 추가 시 기존 언어 성능 저하가 미미함을 확인하였다.
- **우리 연구 관련도**: ★★☆ — 음성 인코더와 LLM 간 프로젝터 설계 및 다국어 지속적 학습 전략은 speech representation의 언어 간 전이 가능성 연구와 관련이 있다.

**[Reinforcement Learning for Data-Efficient Code-Switched ASR] (Ziwei Ye, Peter Vickers — Spotify, 2026-07)** — Interspeech 2026 accepted

- https://arxiv.org/abs/2607.02757
- **기존 문제**: 코드스위칭(code-switching) ASR은 동일 발화 내에서 두 개 이상의 언어가 혼합 사용되는 상황을 처리해야 하지만, 코드스위칭 학습 데이터가 극도로 부족하여 지도 학습(SFT) 기반 미세조정이 어려웠다.
- **기존 방법**: 기존 코드스위칭 ASR은 대량의 코드스위칭 데이터를 수집하여 LoRA 기반 SFT로 미세조정하였으나, 데이터 수집 비용이 높고 10개 이상의 언어 쌍으로 확장이 어려웠다.
- **제안 방법**: Qwen2-Audio 모델에 GRPO(Group Relative Policy Optimization) 기반 강화학습(RLVR)을 적용하여, 전체 학습 데이터의 10%만으로 코드스위칭 ASR을 수행. CER/WER 기반 보상 함수를 설계하여 코드스위칭 정확도를 직접 최적화한다.
- **핵심 차별점**: 전체 데이터의 10%만으로 전체 데이터 LoRA SFT와 동등한 성능을 달성하는 극한의 데이터 효율성이 핵심이며, RLVR이 저자원(low-resource) 코드스위칭 시나리오에서 SFT를 대체할 수 있음을 처음으로 입증한다.
- **실험 결과**: 10개 언어 쌍(영어-힌디, 영어-중국어 등)에서 10% 데이터 RLVR이 100% 데이터 LoRA SFT와 동등한 Mixed-CER/WER을 달성. Spotify 내부 및 공개 코드스위칭 벤치마크에서 검증하였다.
- **우리 연구 관련도**: ★★☆ — 강화학습 기반 데이터 효율적 학습 전략은 저자원 환경에서의 음성 표현 학습 최적화에 방법론적 참고가 될 수 있으며, Qwen2-Audio 모델의 코드스위칭 능력 분석이 다국어 음성 표현 연구와 관련된다.

**[X-Translator: A Real-Time Multilingual Speaker-Aware Speech-to-Speech Translation System] (Shanghai Jiao Tong University / Microsoft / AISpeech, 2026-07)** — arxiv preprint

- https://arxiv.org/abs/2607.17544
- **기존 문제**: 실시간 음성-음성 번역(S2ST) 시스템은 번역 품질과 지연 시간 간 트레이드오프가 심각하며, 원본 화자의 음성 특성(화자 정체성)을 번역 출력에 보존하는 것이 어려웠다.
- **기존 방법**: 기존 S2ST 시스템은 전체 발화가 완료된 후 번역을 시작하는 오프라인 방식이거나, 스트리밍 시 번역 품질이 크게 저하되었으며, 화자 정체성 보존은 별도의 후처리로 처리되었다.
- **제안 방법**: 모듈러 캐스케이드 기반 실시간 S2ST 시스템 X-Translator를 제안. 증분 세그먼트 커밋(incremental segment commitment) 전략으로 스트리밍 번역의 품질-지연 트레이드오프를 최적화하고, 온라인 화자 프롬프트 관리자(online speaker prompt manager)로 실시간 화자 정체성 보존을 구현한다.
- **핵심 차별점**: 증분 세그먼트 커밋은 부분 발화에 대한 번역을 점진적으로 확정하여 불필요한 재번역을 방지하며, 화자 프롬프트 관리자는 번역 과정에서 원본 화자의 음색과 운율을 동적으로 유지한다.
- **실험 결과**: 다국어 S2ST 벤치마크에서 기존 캐스케이드 시스템 대비 번역 품질을 유지하면서 지연 시간을 유의미하게 단축하였으며, 화자 유사도 평가에서도 기존 시스템을 능가하였다.
- **우리 연구 관련도**: ★☆☆ — S2ST 시스템 아키텍처에 초점. 화자 프롬프트 관리에서의 음성 표현 활용이 참고가 될 수 있으나, SSL/VQ 연구와의 직접적 관련성은 낮다.

**[ZipVoice-Dialog: Non-Autoregressive Spoken Dialogue Generation with Flow Matching] (Xiaomi Corp., 2026-07)** — ACL 2026 Findings

- https://arxiv.org/abs/2507.09318
- **기존 문제**: 기존 자기회귀(AR) 기반 음성 대화 생성 모델은 순차적 토큰 생성으로 인해 추론 속도가 느리며, 대규모 고품질 음성 대화 학습 데이터가 부족하여 자연스러운 턴테이킹 및 대화 역학을 학습하기 어려웠다.
- **기존 방법**: 기존 음성 대화 모델은 AR 디코딩에 의존하여 실시간 대화에 필요한 저지연 생성이 어려웠으며, TTS 데이터를 대화 데이터로 대체 사용하는 경우가 많았다.
- **제안 방법**: 플로우 매칭(flow matching) 기반 비자기회귀(NAR) 음성 대화 생성 모델 ZipVoice-Dialog를 제안. 제로샷 다화자 대화 생성이 가능하며, 6,800시간 규모의 OpenDialog 코퍼스를 구축·공개하여 대화 학습 데이터 부족 문제를 해결한다.
- **핵심 차별점**: NAR 생성으로 AR 베이스라인 대비 15배 빠른 추론 속도를 달성하면서도 음성 품질을 유지하며, 6,800시간 규모의 오픈소스 대화 코퍼스 공개는 음성 대화 연구 커뮤니티에 중요한 기여이다.
- **실험 결과**: 3.17% WER로 음성 명료도를 유지하면서 AR 베이스라인 대비 15배 빠른 생성 속도를 달성. 제로샷 화자 적응에서도 자연스러운 대화 생성을 확인하였다.
- **우리 연구 관련도**: ★★☆ — 플로우 매칭 기반 NAR 음성 생성은 VQ 토큰 기반 AR 생성의 대안적 패러다임으로, 음성 표현의 연속 공간(continuous space) 활용 가능성을 보여준다. OpenDialog 코퍼스도 대화 음성 연구에 유용하다.

**[Latent-IM: Latent Interaction Management for Speech LLMs] (Adar Avsian, Atahan Dokme, Tony Woo, Larry Heck — Georgia Tech, 2026-07-29)** — arxiv preprint

- https://arxiv.org/abs/2607.26928
- **기존 문제**: 고전적 음성 대화 시스템은 대화 관리(dialogue management)를 응답 생성과 분리하여 명시적으로 제어하였으나, LLM 기반 시스템에서는 이 분리가 사라져 대화 행위(conversational move)에 대한 명시적 제어가 불가능해졌다.
- **기존 방법**: 기존 SpeechLLM은 대화 행위(인정, 확인, 질의, 설명, 응답 등)를 모델의 숨겨진 표현에 암묵적으로 위임하여, 특정 대화 전략을 의도적으로 선택하거나 제어하는 것이 어려웠다.
- **제안 방법**: 동결된(frozen) SpeechLLM의 잔차 스트림(residual stream) 활성화에서 대화 행위 선택과 실현을 분리하는 Latent-IM 프레임워크를 제안. 선택(selection)은 잔차 활성화로부터 다음 대화 행위를 예측하고, 실현(realization)은 활성화 조향(activation steering)으로 선택된 행위를 생성 시 표현한다.
- **핵심 차별점**: 모델 파라미터를 동결한 상태에서 내부 표현만으로 대화 관리를 복원하는 점이 핵심이며, 미세조정(fine-tuning)과 동등한 성능을 추론 시 조향만으로 달성한다.
- **실험 결과**: 5가지 대화 행위에 대해 선택 정확도 0.60을 달성하였으며, 실현 단계에서 활성화 조향이 최강 베이스라인 대비 10.4 포인트 향상된 평균 대화 행위 정확도를 기록하였다.
- **우리 연구 관련도**: ★★☆ — SpeechLLM의 내부 표현에서 대화 행위를 분리·제어하는 접근은 speech representation이 인코딩하는 정보의 해석 가능성(interpretability) 연구와 관련이 있으며, 활성화 조향 기법이 음성 표현 조작에 참고가 될 수 있다.

**[Dissecting Sensitivity to Training Language in Self-Supervised Speech Learning Using Neural Audio Codec Tokens] (Daigo Takizawa, Tomohiko Nakamura, Samuele Cornell, William Chen, Satoru Fukayama, Shinji Watanabe — AIST / CMU, 2026-07)** — arxiv preprint

- https://arxiv.org/abs/2607.26350
- **기존 문제**: 자기지도 학습(SSL) 음성 모델과 신경 오디오 코덱(NAC)이 사전학습 언어에 얼마나 민감한지 체계적으로 분석된 바가 없었으며, 다국어 음성 처리에서 사전학습 언어 선택의 영향이 불분명하였다.
- **기존 방법**: 기존 연구는 SSL 모델(HuBERT, WavLM 등)과 NAC(EnCodec, DAC 등)를 주로 영어 데이터로 사전학습하고, 다국어 확장 시 경험적으로 언어를 선택하거나 다국어 데이터를 혼합하였다.
- **제안 방법**: SSL 모델과 NAC의 사전학습 언어 민감도를 체계적으로 비교 분석. NAC 토큰이 사전학습 언어에 비민감(insensitive)한 반면, SSL 사전학습 언어가 다운스트림 성능에 결정적(crucial) 영향을 미침을 실험적으로 규명한다.
- **핵심 차별점**: NAC와 SSL의 언어 민감도 차이를 최초로 체계적으로 분석한 연구로, NAC 토큰은 언어 불변(language-invariant) 특성을 보이지만 SSL 표현은 사전학습 언어에 강하게 의존한다는 중요한 발견을 제시한다.
- **실험 결과**: 다국어 다운스트림 태스크에서 NAC 토큰 기반 시스템은 사전학습 언어 변경에 강건한 반면, SSL 기반 시스템은 타겟 언어와 일치하는 사전학습 언어 사용 시 성능이 유의미하게 향상됨을 확인하였다.
- **우리 연구 관련도**: ★★★ — SSL 사전학습 언어의 다운스트림 성능 영향 분석은 prediction-free SSL 및 VQ 기반 표현 학습에서의 언어 의존성 이해에 직접적으로 관련되며, NAC vs SSL 표현의 언어 민감도 차이는 음성 토크나이저 설계에 핵심적인 시사점을 제공한다.

**[DONDO: Open w2v-BERT Speech-Recognition Base Models for African Languages] (2026-07)** — arxiv preprint

- https://arxiv.org/abs/2607.21540
- **기존 문제**: 아프리카 언어들은 음성 인식 연구에서 극도로 저자원(extremely low-resource) 상태에 놓여 있으며, 대부분의 사전학습 음성 모델이 이 언어들을 포함하지 않아 전이 학습의 혜택을 받지 못하였다.
- **기존 방법**: MMS(Meta의 Massively Multilingual Speech)나 Whisper 등 대규모 다국어 모델이 일부 아프리카 언어를 포함하지만, 개별 언어에 특화된 사전학습 모델은 거의 존재하지 않았다.
- **제안 방법**: w2v-BERT 2.0 아키텍처를 기반으로 27개 아프리카 언어 변종에 대해 21개 단일언어(monolingual) 모델과 5개 다국어(multilingual) 모델을 사전학습하여 공개. 각 언어별 최적화된 기반 모델을 제공하여 저자원 아프리카 언어 음성 인식의 진입 장벽을 낮춘다.
- **핵심 차별점**: 27개 아프리카 언어 변종을 포괄하는 최초의 대규모 오픈소스 w2v-BERT 기반 모델 컬렉션으로, 개별 언어에 특화된 단일언어 모델과 언어 그룹별 다국어 모델을 모두 제공한다.
- **실험 결과**: 21개 단일언어 모델 및 5개 다국어 모델이 해당 언어들의 ASR 태스크에서 범용 다국어 모델 대비 유의미한 성능 향상을 달성하였으며, 특히 극저자원 언어에서 개선 폭이 컸다.
- **우리 연구 관련도**: ★★★ — w2v-BERT 2.0 기반 다국어 SSL 사전학습의 실증적 연구로, 저자원 언어에서의 speech SSL 사전학습 전략(단일언어 vs 다국어)의 효과를 직접 비교한 점이 음성 표현 학습 연구에 중요한 참고 자료이다.
