## 1. ASR (Automatic Speech Recognition)

**[How to Recognize New Words: A Comparison Between Context Biasing Methods and Speech LLMs] (Christian Huber, Alexander Waibel — KIT, 2026-08-06)** — arxiv preprint

- https://arxiv.org/abs/2608.05759
- **기존 문제**: 고유명사, 약어, 도메인 특화 전문 용어 등 학습 데이터에 희소한 신규·희귀 단어(new and rare words)의 정확한 인식은 ASR 시스템의 핵심 과제로, 기존 모델들은 이러한 단어에 대해 높은 오류율을 보였다.
- **기존 방법**: 기존 접근법은 크게 두 갈래로 나뉜다: (1) 컨텍스트 바이어싱(context biasing) — ASR 모델에 추론 시 단어 리스트를 제공하여 해당 단어의 인식 확률을 높이는 방식, (2) Speech LLM — 프롬프트에 컨텍스트를 직접 제공하여 LLM이 인식을 수행하는 방식. 그러나 이 두 전략의 체계적 비교는 부재하였다.
- **제안 방법**: Whisper 기반 두 가지 컨텍스트 바이어싱 방법과 세 가지 Speech LLM을 읽기 음성(read speech)과 비읽기 음성(non-read speech) 양쪽에서 체계적으로 비교 평가하는 벤치마크 연구를 수행하였다.
- **핵심 차별점**: 컨텍스트 바이어싱과 Speech LLM이라는 두 가지 패러다임을 동일 조건에서 최초로 체계적으로 비교한 연구이다. 컨텍스트 바이어싱은 바이어스 단어 WER을 최대 88% 상대 감소시키면서 비바이어스 단어에는 영향을 주지 않는 반면, Speech LLM은 읽기 음성에서 우수하지만 비읽기 음성으로의 일반화가 부족하며 방해 단어(distractor) 수와 프롬프트 내 단어 순서에 민감하다는 차이를 규명하였다.
- **실험 결과**: 컨텍스트 바이어싱이 바이어스 단어 WER을 최대 88% 상대 감소. Speech LLM은 읽기 음성에서 경쟁력 있으나 비읽기 음성에서 일반화 부족. 방해 단어 수 증가 시 Speech LLM 성능 하락 확인.
- **우리 연구 관련도**: ★☆☆ — ASR 추론 전략 비교 연구로, speech SSL/VQ 표현 학습과의 직접적 관련성은 낮다. 다만 Speech LLM이 음성 표현에서 추출하는 정보의 한계를 분석한 결과가 표현의 정보 충분성 연구에 간접적 시사점을 제공한다.

**[TokAN: Accent Normalization Using Self-Supervised Speech Tokens] (Qibing Bai, Shuai Wang, Yuhan Du, Bohan Li, Yannan Wang, Haizhou Li, 2026-07-04)** — arxiv preprint

- https://arxiv.org/abs/2607.03928
- **기존 문제**: 비원어민(L2) 억양 음성은 ASR 시스템의 인식 정확도를 크게 저하시키며, 억양 정규화(accent normalization) — 비원어민 억양 음성을 표준(L1) 음성으로 변환하면서 화자 정체성을 보존하는 것 — 는 합성 감독 데이터에 의존하거나 프레임 수준의 변환에 한정되는 문제가 있었다.
- **기존 방법**: 기존 억양 정규화 연구는 프레임-투-프레임 직접 변환, 플로우 매칭 기반 직접 변환, 또는 프롬프트 기반 토큰 변환 방식을 사용하였으나, 합성 감독 음성에 의존하거나 억양 감소와 발음 명료도의 균형이 부족하였다.
- **제안 방법**: L1-L2 음성을 공동으로 학습한 벡터 양자화(VQ) 토크나이저에서 추출한 자기지도 이산 음성 토큰(self-supervised discrete speech tokens) 기반으로 동작하는 TokAN을 제안. 자기회귀 인코더-디코더 모델이 L2 토큰 시퀀스를 L1 표준 음성 토큰으로 변환하며, WER과 억양 분류기 신뢰도를 보상으로 사용하는 GRPO 기반 강화학습(RL) 후처리를 적용한다.
- **핵심 차별점**: 합성 감독 음성 없이 자기지도 이산 토큰 공간에서 억양 정규화를 수행하는 최초의 프레임워크이다. VQ 토크나이저의 공유 코드북이 L1-L2 간 음성 변환을 가능하게 하며, GRPO 기반 RL이 WER과 억양 감소를 동시에 최적화한다.
- **실험 결과**: 7개 영어 억양에서 WER을 12.40% → 9.89%(SFT 후) → 9.23%(RL 후처리 후)로 감소. 프레임-투-프레임, 플로우 매칭, 프롬프트 기반 토큰 변환 베이스라인을 억양 감소와 발음 명료도 모두에서 일관되게 능가.
- **우리 연구 관련도**: ★★☆ — L1-L2 공동 학습 VQ 토크나이저를 통한 이산 토큰 기반 음성 변환은 VQ-based representation 연구와 직접적으로 관련된다. VQ 코드북의 공유 구조가 억양 변이 간 음성 변환을 가능하게 하는 메커니즘은 speech SSL 표현에서의 화자·억양 정보 분리 연구에 시사점을 제공한다.

## 2. SpeechLLM (Speech-Language Model)

**[SwanTale: Unified Multi-Speaker Speech and Audio Generation for Instruct and Zero-Shot Tasks] (Yu Zhang, Ruiqi Li, Changhao Pan, Ke Lei, Xiang Yin, Cheng Yang — ByteDance, 2026-08-03)** — arxiv preprint

- https://arxiv.org/abs/2608.02023
- **기존 문제**: 애니메이션 더빙, 오디오 드라마, 영화, 광고, 게임 등 실제 콘텐츠 제작에서는 참조 녹음 없이 음성을 설계하거나, 자연어 지시로 화자 스타일을 제어하고, 환경음과 오디오 이펙트가 포함된 음향 장면을 지원해야 하지만, 기존 음성·오디오 생성 모델은 이러한 다화자 표현적 음성 생성과 범용 오디오 생성을 통합적으로 지원하지 못하였다.
- **기존 방법**: 기존 모델들은 제로샷 TTS 또는 지시 기반 음성 생성 중 하나에 특화되어 있었으며, 다화자 음성과 범용 오디오(환경음, 효과음 등)를 단일 모델에서 통합 생성하는 시도는 제한적이었다.
- **제안 방법**: 데이터와 모델 양면에서 접근. 데이터 측면에서는 SwanData-Caption으로 원시 음성·오디오 데이터를 정제하고 다단계 캡션을 부여하며, 합성 데이터로 커버리지를 보완한다. 모델 측면에서는 48kHz 파형 잠재 오토인코더 SwanVAE, 보상 조건부 품질 제어(reward-conditioned quality control), Engram 조건화, 태스크·오디오 라우터 기반 통합 MoE(Unified MoE)를 도입. 커리큘럼 학습(제로샷 → 캡션 조건 → 혼합 학습 → 표현적 SFT)과 GRPO 후처리로 발음 정확도, 생성 안정성, 화자 속성 제어를 향상시킨다.
- **핵심 차별점**: 제로샷(참조 음성 기반)과 인스트럭트(자연어 지시 기반) 태스크를 단일 모델에서 통합 지원하며, 다화자 음성과 범용 오디오 생성을 Unified MoE로 동시에 처리하는 최초의 모델이다. GRPO 기반 후처리가 음성 생성 품질을 직접 최적화한다.
- **실험 결과**: 다화자 음성 생성에서 제로샷과 인스트럭트 태스크 모두에서 경쟁력 있는 성능을 달성하였으며, 범용 오디오 생성까지 통합 지원. GRPO 후처리로 발음 정확도와 화자 속성 제어가 유의미하게 향상되었다.
- **우리 연구 관련도**: ★★☆ — SwanVAE의 48kHz 파형 잠재 오토인코더 설계는 VQ 기반 음성 표현의 정보 압축과 복원 품질 연구에 참고 가능하며, 통합 MoE의 태스크·오디오 라우팅 전략은 다중 태스크 음성 표현 학습의 아키텍처 설계에 시사점을 제공한다.

**[DIFFA-2: A Practical Diffusion Large Language Model for General Audio Understanding] (NKU-HLT 연구진, 2026-01-30)** — ACL 2026 Findings accepted

- https://arxiv.org/abs/2601.23161
- **기존 문제**: 자기회귀(AR) 방식이 지배적인 대형 오디오 언어 모델(LALM) 분야에서 확산(diffusion) 기반 접근법의 실용적 경쟁력이 충분히 검증되지 않았다. 선행 연구 DIFFA는 확산 기반 LALM의 가능성을 보였으나, 실용적 학습 예산 하에서 AR 기반 LALM과의 경쟁력이 제한적이었다.
- **기존 방법**: DIFFA(AAAI 2026)는 동결된 확산 언어 모델에 경량 어댑터를 연결하는 방식으로 확산 기반 음성 이해를 시도하였으나, 음성 인코더 용량과 학습 전략의 한계로 범용 오디오 이해 성능이 부족하였다.
- **제안 방법**: 음성 인코더를 업그레이드하고, 의미적(semantic) 어댑터와 음향적(acoustic) 어댑터의 이중 어댑터 구조를 도입한 DIFFA-2를 제안. 의미 정렬, 음향 정렬, 대규모 지도 미세조정, 분산 감소 선호도 최적화(variance-reduced preference optimization)의 4단계 커리큘럼으로 학습하며, 완전히 오픈소스 코퍼스만 사용한다.
- **핵심 차별점**: 확산 기반 모델링이 실용적 학습 예산 하에서 AR 기반 LALM과 경쟁할 수 있음을 입증한 연구이다. 이중 어댑터(의미+음향)가 다차원 오디오 정보를 효과적으로 포착하며, 분산 감소 선호도 최적화가 생성 품질을 안정화시킨다.
- **실험 결과**: MMSU, MMAU, MMAR 벤치마크에서 DIFFA 대비 일관된 성능 향상을 달성하였으며, 실용적 학습 예산 하에서 강력한 AR 기반 LALM과 경쟁력 있는 성능을 기록하였다.
- **우리 연구 관련도**: ★★☆ — 확산 기반 언어 모델이 음성 이해에서 AR 모델의 대안이 될 수 있음을 보인 연구로, 음성 표현의 소비 방식에 대한 새로운 관점을 제시한다. 이중 어댑터의 의미-음향 분리 구조는 speech SSL 표현에서의 정보 유형별 분리 연구에 참고가 될 수 있다.

**[Self-Guidance: Enhancing Neural Codecs via Decoder Manifold Alignment] (Xiang Li, Yixuan Zhou, Jingran Xie, Zhiyong Wu, Hui Wang, 2026-06-11)** — arxiv preprint

- https://arxiv.org/abs/2606.12940
- **기존 문제**: VQ-VAE 기반 신경 음성 코덱은 Speech LLM의 핵심 오디오 토크나이저이지만, 양자화 오류(quantization error)로 인해 복원 충실도(reconstruction fidelity)가 병목 현상을 겪는다. 코드북 크기를 늘리면 양자화 오류는 줄지만, 다운스트림 LLM의 토큰 모델링 복잡도가 급격히 증가하는 트레이드오프가 존재하였다.
- **기존 방법**: 기존 접근법은 코드북 크기 확대, 잔차 양자화(RVQ), 유한 스칼라 양자화(FSQ) 등을 통해 양자화 오류를 줄이려 하였으나, 양자화 자체의 손실을 디코더 측에서 보상하는 방법은 연구되지 않았다.
- **제안 방법**: 디코더가 양자화된 토큰과 원래 연속 임베딩을 처리할 때 내부 특징 매니폴드(feature manifold)를 정렬(align)시키는 경량 특징 매핑 손실(feature-mapping loss)인 Self-Guidance를 제안. 학습 시 최소한의 오버헤드만 추가하며 추론 시에는 변경이 불필요하다.
- **핵심 차별점**: 양자화기를 변경하지 않고 디코더 매니폴드 정렬만으로 양자화 오류의 영향을 효과적으로 완화하는 최초의 접근법이다. XCodec2에 적용 시 코드북 크기를 4배 줄여도(65,536 → 16,384) 충실도 손실 없이 SOTA 저비트레이트 성능을 달성하며, 이는 다운스트림 LLM 기반 TTS의 토큰 모델링을 크게 단순화한다. SimVQ, Residual FSQ 등 대안 양자화기에도 일관된 성능 향상을 보여 방법의 범용성을 확인하였다.
- **실험 결과**: XCodec2에 적용하여 모든 복원 지표에서 개선 달성. 16,384 코드북으로 65,536 코드북 베이스라인 XCodec2와 동등 이상의 성능. SimVQ, Residual FSQ 적용 시에도 일관된 개선. 다운스트림 TTS 실험에서 LLM 기반 음성 합성 품질 유의미하게 향상.
- **우리 연구 관련도**: ★★★ — VQ-VAE 기반 코덱의 양자화 오류 문제를 디코더 매니폴드 정렬로 해결하는 접근법은 VQ-based representation 연구에 핵심적으로 관련된다. 코드북 크기 감소 시에도 충실도를 유지하는 메커니즘은 VQ 표현의 정보 효율성 연구에 직접적 시사점을 제공하며, 양자화기 비의존적(quantizer-agnostic) 특성은 다양한 VQ 기반 speech SSL 시스템에 적용 가능한 범용적 방법론이다.

**[Audio-JEPA: Joint-Embedding Predictive Architecture for Audio Representation Learning] (Ludovic Tuncay, Etienne Labbé, Emmanouil Benetos, Thomas Pellegrini, 2025-07)** — arxiv preprint

- https://arxiv.org/abs/2507.02915
- **기존 문제**: 오디오 자기지도학습(SSL)은 마스크 오토인코더(MAE) 방식이 주류였으나, 원시 입력 재구성에 기반하여 저수준 세부사항에 과도한 연산을 소비하고, 고수준 의미 표현 학습이 제한적이었다. 또한 기존 오디오 SSL 모델(wav2vec 2.0, data2vec 등)은 대규모 학습 데이터를 필요로 하였다.
- **기존 방법**: AudioMAE, BEATs 등 기존 오디오 SSL은 마스크 영역의 원시 스펙트로그램 패치를 재구성하거나, 반복적 자기증류(iterative self-distillation)를 통해 토큰화 대상을 학습하는 방식을 사용하였다. wav2vec 2.0, data2vec 등은 대규모 데이터로 사전학습되었다.
- **제안 방법**: Joint-Embedding Predictive Architecture(JEPA) 패러다임을 오디오 도메인에 적용한 Audio-JEPA를 제안. Vision Transformer 백본을 사용하여 마스크된 스펙트로그램 패치의 잠재 표현(latent representation)을 예측하며, 원시 오디오를 재구성하지 않는다. 비레이블 AudioSet 클립(10초, 32kHz)에서 랜덤 패치 마스킹으로 사전학습한다.
- **핵심 차별점**: 원시 입력 재구성 대신 고수준 잠재 공간에서의 예측을 통해 의미적으로 풍부한 표현을 학습하는 JEPA 패러다임의 오디오 도메인 최초 적용이다. wav2vec 2.0, data2vec 대비 1/5 미만의 학습 데이터로 동등한 성능을 달성하며, 하이퍼파라미터 튜닝 없이도 경쟁력 있는 결과를 보인다.
- **실험 결과**: X-ARES 평가 스위트(음성, 음악, 환경음 태스크 포함)에서 wav2vec 2.0, data2vec와 동등한 성능을 달성하였으며, 학습 데이터는 이들의 1/5 미만을 사용. 하이퍼파라미터 튜닝 없는 직접 적용(straightforward translation)만으로 경쟁력 있는 결과를 시현하였다.
- **우리 연구 관련도**: ★★★ — JEPA의 잠재 공간 예측 패러다임은 prediction-free SSL과 개념적으로 밀접하게 관련된다. 원시 입력 재구성 대신 고수준 표현 공간에서의 학습은 prediction-free 접근법의 핵심 철학과 일치하며, 소규모 데이터로도 효과적인 표현 학습이 가능함을 보인 결과는 학습 효율성 연구에 직접적 시사점을 제공한다. 마스크 패치 예측 전략은 temporal contrastive learning의 시간적 구조 활용과 상보적 관계에 있다.
