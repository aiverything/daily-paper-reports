## 1. ASR (Automatic Speech Recognition)

### 1.1 Pushing the Limits of End-to-End Diarization

**[Pushing the Limits of End-to-End Diarization]** (Samuel J. Broughton, Lahiru Samarakoon, 2025.09) — Interspeech 2025

- arxiv URL: https://arxiv.org/abs/2509.14737
- **기존 문제**: EEND(End-to-End Neural Diarization) 기반 화자 분리 모델은 cascaded/modular 시스템에 비해 성능이 부족하다는 인식이 있었으며, 복잡한 다화자 시나리오에서 한계를 보였음
- **기존 방법**: VBx 클러스터링 기반 cascaded 시스템, EEND-EDA, pyannote 등 모듈형 파이프라인이 주류. EEND 아키텍처의 학습 설정 탐구가 충분히 이루어지지 않음
- **제안 방법**: EEND-TA(Target-speaker Attention) 아키텍처를 단일 통합 비자기회귀 모델로 활용. 8화자 시뮬레이션 혼합을 통한 사전학습 스케일링과 균형 잡힌 화자 구성 표현 학습
- **핵심 차별점**: cascaded 구성요소 없이 단일 EEND 아키텍처만으로 다수 벤치마크에서 SOTA 달성. 적절한 스케일링을 통해 EEND 패러다임의 미개척 학습 용량을 입증
- **실험 결과**: AliMeeting-far, AliMeeting-near, AMI-Mix, AMI-SDM, DIHARD III (DER 14.49%), MagicData RAMC에서 SOTA DER 달성. 효율적인 추론 속도 유지
- **우리 연구 관련도**: ★★☆ — 사전학습된 음성 표현을 활용하나, VQ 기반 표현이나 contrastive learning과 직접적 관련은 낮음. 다화자 음성 표현 학습 관점에서 참고 가치 있음

### 1.2 SphereVBx: Spherical Variational Bayes Clustering for Simplified EEND-VC Diarization

**[SphereVBx]** (Petr Palka, Jiangyu Han, Prachi Singh, Marc Delcroix, Naohiro Tawara, Lukas Burget, 2026.06) — Interspeech 2026 accepted

- arxiv URL: https://arxiv.org/abs/2606.24528
- **기존 문제**: EEND-VC(End-to-End Neural Diarization with Vector Clustering) 화자 분리 파이프라인의 클러스터링 단계가 복잡하여 하이퍼파라미터 튜닝과 배포가 어려움
- **기존 방법**: VBx 및 MS-VBx가 HMM 기반 변분 베이즈 클러스터링을 사용하여 EEND-VC 화자 분리에 적용
- **제안 방법**: 구면(spherical) 변분 베이즈 클러스터링을 도입하여 기존 EEND-VC 파이프라인의 복잡한 클러스터링 단계를 단순화
- **핵심 차별점**: 표준 EEND-VC 파이프라인을 단순화하면서도 경쟁력 있는 DER 성능을 유지. 복잡한 HMM 기반 클러스터링 대비 구현과 튜닝이 용이
- **실험 결과**: 기존 EEND-VC 파이프라인 대비 동등 이상의 DER을 달성하면서 시스템 복잡도 크게 감소
- **우리 연구 관련도**: ★☆☆ — 화자 분리 클러스터링 기법 중심으로, speech SSL이나 VQ 기반 표현 학습과 직접 관련 낮음

### 1.3 Adding Robust Code-Switching Capabilities to High Performance Multilingual ASR

**[Adding Robust Code-Switching Capabilities to High Performance Multilingual ASR]** (Enes Yavuz Ugan, Alexander Waibel, 2026.06) — arXiv preprint

- arxiv URL: https://arxiv.org/abs/2606.21990
- **기존 문제**: 강력한 다국어 ASR 모델을 합성 코드스위칭 데이터로 파인튜닝하면 기존 단일언어 성능이 하락하는 문제. 코드스위칭 능력 추가가 기존 능력과 상충
- **기존 방법**: 표준 파인튜닝 접근법은 코드스위칭 학습 시 기존 단일언어 성능을 불가피하게 손상
- **제안 방법**: 베이지안 팩터화 적응(Bayesian factorized adaptation)을 통해 소량의 합성 데이터만으로 사전학습 모델에 스위칭 관련 지식을 통합. 기존 가중치를 덮어쓰지 않으면서 새로운 능력을 학습
- **핵심 차별점**: 원칙적인 베이지안 적응 프레임워크로 강력한 단일언어 베이스라인을 보존하면서 코드스위칭 능력을 추가하는 최초의 방법
- **실험 결과**: 코드스위칭 단어 전사 오류 32.87% 감소, 전체 WER 5.31% 개선. 단일언어 성능 보존
- **우리 연구 관련도**: ★☆☆ — 모델 적응 기법 중심으로, 표현 학습 방법론과 직접 관련 낮음

## 2. SpeechLLM (Speech Language Model)

### 2.1 Spatial-Omni: Spatial Audio Understanding Integration in Multimodal LLMs via FOA Encoding

**[Spatial-Omni]** (2026.06) — arXiv preprint

- arxiv URL: https://arxiv.org/abs/2606.10738
- **기존 문제**: 최근 멀티모달 LLM들이 오디오를 모노럴 신호로만 처리하여 음원 위치 추정, 공간 관계 추론, 공간 장면 이해에 필요한 공간 단서를 모두 폐기
- **기존 방법**: 기존 옴니 LLM(Qwen-Omni, GPT-4o 등)은 공간 오디오 인식 능력이 전무하며, 모든 오디오를 단일 채널로 처리
- **제안 방법**: SO-Encoder를 구현하여 First-Order Ambisonics(FOA) 공간 오디오를 기존 옴니 LLM에 독립 모달리티로 주입. 기존 오디오 인코더 수정 없이 적용 가능. SO-Dataset (40만 FOA 클립), SO-QA (210만 QA 쌍), SO-Bench (16개 서브태스크) 벤치마크 구축
- **핵심 차별점**: 옴니 LLM에 공간 오디오 이해를 추가하는 최초의 경량 방법론. 기존 아키텍처 수정 없이 플러그인 방식으로 적용 가능하며 최초의 종합 공간 오디오 벤치마크 제공
- **실험 결과**: 16개 공간 오디오 이해 서브태스크에서 기존 모노럴 기반 LLM 대비 유의미한 성능 향상 달성
- **우리 연구 관련도**: ★☆☆ — 공간 오디오 처리 중심으로, speech SSL이나 VQ 기반 표현 학습과 직접 관련 낮음

### 2.2 Integrating Facial Generation into Full-Duplex Spoken Dialogue Systems (Moshi-Face)

**[Moshi-Face]** (Jingjing Jiang, Atsumoto Ohashi, Ryuichiro Higashinaka, 2026.06) — arXiv preprint

- arxiv URL: https://arxiv.org/abs/2606.21970
- **기존 문제**: Moshi 등 전이중(full-duplex) 음성 대화 모델이 오디오만 생성하며, 체화형 대화 에이전트에 필요한 얼굴 표정 생성 기능이 부재
- **기존 방법**: Moshi는 실시간 전이중 음성 대화를 지원하지만 오디오 모달리티만 출력. 별도의 얼굴 생성 모델과 파이프라인 연결이 필요
- **제안 방법**: VQ-VAE 기반 얼굴 코덱을 구축하여 얼굴 비디오의 3D 헤드 메시를 소형 이산 토큰으로 인코딩. Moshi에 Face Transformer를 추가하여 얼굴 토큰을 비자기회귀적으로 생성. 오디오와 얼굴 토큰의 실시간 동기 생성
- **핵심 차별점**: 오디오+얼굴 입력을 동시에 처리하고 음성+얼굴 동작을 동시에 생성하는 최초의 전이중 대화 모델. VQ-VAE를 통한 효율적인 얼굴 표현
- **실험 결과**: 낮은 지연 시간으로 시청각 동기화를 달성하면서 원래 오디오 전용 Moshi 모델의 대화 품질 유지
- **우리 연구 관련도**: ★★☆ — VQ-VAE 기반 얼굴 코덱을 사용하며, 이산 토큰 기반 멀티모달 표현의 확장 관점에서 VQ 기반 표현 연구와 관련 있음

### 2.3 Evaluation of LLMs in Speech is Often Flawed: Test Set Contamination

**[Evaluation of LLMs in Speech is Often Flawed: Test Set Contamination in Large Language Models for Speech Recognition]** (2025.05) — arXiv preprint

- arxiv URL: https://arxiv.org/abs/2505.22251
- **기존 문제**: LLM 기반 ASR 평가의 신뢰성 문제 — LibriSpeech와 Common Voice 평가 세트의 상당 부분이 공개 LLM 사전학습 코퍼스에 이미 포함되어 있어, 평가 결과가 왜곡될 가능성
- **기존 방법**: 기존 LLM 기반 ASR 연구에서 테스트 세트 오염(data contamination)을 체계적으로 조사하거나 통제하지 않음
- **제안 방법**: 오염된 LLM과 비오염 LLM을 비교하여 오류율(WER)과 전사에 부여되는 확률 점수를 체계적으로 측정. 오염의 실질적 영향을 정량화
- **핵심 차별점**: LLM 기반 음성 인식 평가에서 데이터 오염 영향을 최초로 체계적으로 연구. 표준 WER 메트릭의 한계를 지적
- **실험 결과**: 오염된 LLM은 WER 차이는 미묘하지만 이미 본 전사에 유의미하게 높은 확률을 부여. 표준 WER만으로는 오염 효과가 은폐될 수 있음을 증명
- **우리 연구 관련도**: ★☆☆ — 평가 방법론 연구로 표현 학습과 직접 관련 낮으나, speech SSL 모델 평가 시 벤치마크 오염 주의 필요

## 3. Speech Foundation Model

### 3.1 Bridging the Gap between Continuous and Informative Discrete Representations by Random Product Quantization

**[Random Product Quantization]** (Xueqing Li, Hao Ma, Zehan Li et al., 2025.04) — arXiv preprint

- arxiv URL: https://arxiv.org/abs/2504.04721
- **기존 문제**: 고차원 SSL 표현의 이산화(discretization)가 효율성에 필수적이나, 기존 k-means 기반 방법이 심각한 정보 손실을 겪음. 연속 표현과 이산 표현 사이의 품질 격차가 큼
- **기존 방법**: HuBERT의 k-means 클러스터링으로 이산 타겟 생성; BEST-RQ의 랜덤 프로젝션 양자화. 두 방법 모두 고차원 공간에서 정보 보존 한계
- **제안 방법**: 두 가지 양자화 방법 제안: (1) Product Quantization(PQ) — 특징 벡터를 부분 공간으로 분할하여 각각 독립적으로 양자화, (2) Random Product Quantization(RPQ) — 차원을 무작위 샘플링하여 다양한 부분벡터를 구성하고 양자화
- **핵심 차별점**: BEST-RQ 스타일의 랜덤 양자화를 다중 부분공간 분해로 직접 개선하여 연속-이산 표현 간 정보 격차를 체계적으로 해소. Prediction-free SSL 프레임워크에 직접 적용 가능
- **실험 결과**: PQ — LibriSpeech test-clean 상대 WER 21.8% 개선, ML-SUPERB 상대 CER 24.1% 개선 (k-means 대비). RPQ — 상대 WER 20.0%, CER 19.6% 개선
- **우리 연구 관련도**: ★★★ — VQ 기반 표현 학습의 핵심 연구. BEST-RQ 패러다임의 직접 확장으로 prediction-free SSL과 매우 높은 관련성. 양자화 타겟 품질 개선은 우리 연구 방향과 직접 연결

### 3.2 Latent-RQ: Enhancing Speech Pre-training with Latent Representations and Random Quantization

**[Latent-RQ]** (Mohammad Huzaifah et al., 2026) — AAAI 2026 Workshop on Audio-Centric AI (Audio-AAAI), PMLR 312:78-93

- URL: https://proceedings.mlr.press/v312/huzaifah26a.html
- **기존 문제**: BEST-RQ가 양자화기 입력으로 멜 스펙트로그램에 의존하여 수렴이 느리고 예측 타겟의 품질이 제한됨
- **기존 방법**: BEST-RQ는 멜 스펙트로그램에 랜덤 프로젝션을 적용하여 마스크 예측의 타겟을 생성. 입력 특징의 한계로 타겟 품질 제약
- **제안 방법**: 멜 스펙트로그램 대신 사전학습된 인코더의 풍부한 잠재(latent) 표현을 양자화기 입력으로 사용. 학습 중 타겟 인코더를 주기적으로 업데이트하여 점진적으로 품질 향상
- **핵심 차별점**: BEST-RQ의 단순성과 효율성을 유지하면서, 학습된 잠재 표현을 통해 예측 타겟 품질을 직접 개선. 랜덤 양자화의 한계를 입력 품질 개선으로 극복
- **실험 결과**: SUPERB 벤치마크 전반에서 일관된 개선, 특히 음성 인식과 화자 식별 태스크에서 우수. 더 적은 최적화 단계로 기존 BEST-RQ와 동등한 성능 달성. t-SNE 시각화에서 더 선명한 음소/화자 클러스터링 확인
- **우리 연구 관련도**: ★★★ — BEST-RQ 패러다임의 직접 확장으로 prediction-free SSL의 핵심 관련 연구. 랜덤 양자화 + 잠재 표현 결합은 VQ 기반 표현 학습의 새로운 방향 제시

### 3.3 CodecSlime: Temporal Redundancy Compression of Neural Speech Codec via Dynamic Frame Rate

**[CodecSlime]** (2026.02) — arXiv preprint

- arxiv URL: https://arxiv.org/abs/2506.21074
- **기존 문제**: 현재 신경 음성 코덱이 고정 프레임 레이트(FFR)를 사용하여 콘텐츠와 무관하게 모든 시간 구간에 동일한 수의 토큰을 할당. 장모음, 무음 등 정상 상태 구간에서 토큰이 낭비됨
- **기존 방법**: EnCodec, SoundStream, WavTokenizer 등 모든 주류 신경 음성 코덱이 고정 프레임 레이트(40~75 Hz)로 동작
- **제안 방법**: 최초의 동적 프레임 레이트(DFR) 지원 방법. 플러그인 방식, 비지도, 아키텍처 무관. (1) ScheDFR — 추론 시 스케줄링 기반 동적 프레임 레이트 적응, (2) Melt-and-Cool — 학습 시 DFR 적응 전략. 두 혁신의 결합으로 기존 코덱에 즉시 적용 가능
- **핵심 차별점**: 신경 음성 코덱에서 동적 프레임 레이트를 최초로 구현. 음성의 비균일 시간적 정보 밀도를 활용. 기존 아키텍처에 플러그인으로 적용 가능한 범용성
- **실험 결과**: 40 Hz DFR (~600 bps)에서 동일 아키텍처, 유사 비트레이트의 FFR 베이스라인 대비 재구성 WER 최대 32% 상대 감소
- **우리 연구 관련도**: ★★☆ — 음성 토큰화 효율성 연구로, 가변 프레임 레이트를 통한 표현 압축은 VQ 기반 표현 연구와 관련. 시간적 중복 제거는 temporal representation 연구에 시사점 제공

## 이번 주 트렌드 요약 (2026.06.23 ~ 06.26)

1. **EEND 화자 분리의 재조명**: "Pushing the Limits of EEND"와 "SphereVBx" 등에서 end-to-end 화자 분리 모델의 미개척 잠재력이 재확인됨. Cascaded 시스템 없이도 단일 모델로 SOTA를 달성할 수 있음을 입증하는 추세가 지속

2. **BEST-RQ/랜덤 양자화 패러다임의 진화**: "Random Product Quantization"과 "Latent-RQ"에서 BEST-RQ 패러다임을 부분공간 분해 및 잠재 표현으로 확장하여 prediction-free SSL의 타겟 품질을 개선하는 연구가 활발. 양자화 방법론의 체계적 개선이 주요 연구 방향으로 부상

3. **멀티모달 전이중 대화의 확장**: "Moshi-Face"에서 음성 전이중 대화 모델이 시각(얼굴) 모달리티로 확장. VQ-VAE 기반 이산 표현의 활용 범위가 음성을 넘어 얼굴 모션까지 넓어지는 추세

4. **동적 토큰화와 시간 효율성**: "CodecSlime"에서 고정 프레임 레이트의 한계를 극복하는 동적 토큰화 연구 등장. 음성의 비균일 시간적 정보 밀도를 활용한 적응적 토큰 할당이 새로운 연구 방향

5. **LLM 기반 음성 평가의 신뢰성 재검토**: "Evaluation of LLMs in Speech is Often Flawed"에서 테스트 세트 오염 문제가 체계적으로 분석됨. 기존 벤치마크 결과의 재평가 필요성이 대두되며, 평가 방법론 자체에 대한 비판적 연구가 증가
