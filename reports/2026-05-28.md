## 1. ASR (End-to-End ASR, Multilingual ASR, Continual Learning)

### **Open ASR Leaderboard: Towards Reproducible and Transparent Multilingual Speech Recognition Evaluation (Vaibhav Srivastav, Steven Zheng, Eric Bezzam, Eustache Le Bihan, Nithin Rao Koluguri, Piotr Żelasko, Somshubra Majumdar, Adel Moumen, Sanchit Gandhi — Hugging Face / NVIDIA / University of Cambridge / Mistral AI / OpenAI, 2025-10)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2510.06961
- 기존 문제: ASR 모델 평가의 재현성과 투명성이 부족. 연구마다 자체 벤치마크와 전처리 파이프라인을 사용하여 모델 간 공정한 비교가 어려우며, 정확도(WER)와 효율성(추론 속도) 간 트레이드오프를 통합적으로 비교할 수 있는 표준화된 플랫폼이 부재.
- 기존 방법: 개별 논문에서 자체 선택한 데이터셋과 전처리로 WER만 보고. ESPnet, NeMo, SpeechBrain, Transformers 등 툴킷별로 평가 방식이 상이하여 교차 비교 불가.
- 제안 방법: 커뮤니티 기여 기반 재현 가능한 벤치마킹 플랫폼. 86개 오픈소스/상용 ASR 시스템을 12개 데이터셋에서 표준화된 WER 및 RTFx(역실시간비) 평가. 영어 단문/장문 및 다국어(독일어, 프랑스어, 이탈리아어, 스페인어, 포르투갈어) 트랙 제공.
- 핵심 차별점: 18개 기관의 64개 모델(57개 오픈소스)을 동일 조건에서 정확도-효율성 동시 비교. 아키텍처(CTC, TDT, RNN-T, Attention)와 인코더(Conformer, Whisper 계열) 간 체계적 분석.
- 실험 결과: NVIDIA Canary-Qwen-2.5B가 영어 최고 WER 5.63% 달성. CTC 기반 Conformer(NVIDIA Parakeet CTC 1.1B)가 RTFx 2793.75로 최고 처리량(Whisper-large-v3 대비 40배 이상). Conformer+LLM 디코더가 최저 WER이나 추론 속도 느림. Whisper 계열 인코더는 영어 fine-tuning 시 정확도 향상되나 다국어 커버리지 감소.
- 우리 연구 관련도: ★☆☆ (ASR 시스템 벤치마킹으로 speech SSL/VQ 표현 연구와의 직접적 관련은 낮으나, 다양한 인코더 아키텍처의 성능-효율 분석이 speech representation 설계의 실용적 참고점 제공)

### **Efficient Rehearsal for Continual Learning in ASR via Singular Value Tuning (Steven Vander Eeckt, Hugo Van hamme — KU Leuven, 2026-01)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2601.18266
- 기존 문제: ASR 모델이 새로운 태스크, 도메인, 화자에 적응할 때 이전 태스크 성능이 급감하는 catastrophic forgetting 문제. Rehearsal 기반 방법은 이전 데이터 저장이 비용/프라이버시 규제 측면에서 어렵고, 사전학습 모델에서는 원본 데이터 접근이 불가능한 경우가 많음.
- 기존 방법: Experience Replay(ER), Elastic Weight Consolidation(EWC) 등 CL 기법이 존재하나, 대규모 rehearsal 데이터 저장이 필요하거나 태스크별 정규화 파라미터 관리가 복잡. Parameter-efficient fine-tuning(PEFT)과 CL의 결합이 초기 단계.
- 제안 방법: 2단계 접근 — (1단계) 새 태스크 데이터로 모델 전체를 fine-tuning. (2단계) Linear layer의 파라미터 변화량에 SVD(특이값 분해)를 적용하고, singular value에 대한 gating vector만 극소량의 rehearsal 데이터로 재학습. 각 singular value의 수용/거절을 gating으로 제어하여 새 태스크 적응과 이전 지식 보존을 균형.
- 핵심 차별점: 이전 태스크당 단 1개 utterance만으로도 forgetting을 효과적으로 억제. SVD 기반 gating이 fine-tuning 변화의 어떤 방향이 유익하고 해로운지를 자동으로 분리.
- 실험 결과: 기존 SOTA CL 접근법(ER, EWC 등) 대비 forgetting 감소 및 전반적 성능 향상. 극소량 rehearsal(태스크당 1 utterance)에서도 유효하여 실용적 CL 시나리오에 적합.
- 우리 연구 관련도: ★☆☆ (ASR 모델의 continual learning으로 speech SSL 연구와의 직접적 관련은 낮으나, SVD 기반 파라미터 분석이 representation의 정보 구조 이해에 간접적 시사점 제공)

### **Improving Code-Switching Speech Recognition with TTS Data Augmentation (Yue Heng Yeo et al., 2026-01)** — APSIPA 2025 / arxiv preprint
- arxiv URL: https://arxiv.org/abs/2601.00935
- 기존 문제: 중국어-영어 코드스위칭(CS) ASR의 학습 데이터가 극도로 부족하며, 기존 데이터의 화자 다양성이 제한적. 대화체 코드스위칭 음성의 자연스러운 합성이 어려워 데이터 증강이 제한적.
- 기존 방법: 제한된 실제 CS 음성 데이터(SEAME 등)에 의존한 학습. 텍스트 기반 언어 모델 증강, 단일 언어 음성 데이터 결합 등이 시도되었으나 음향적 다양성과 자연스러운 언어 전환 패턴을 재현하지 못함.
- 제안 방법: 다국어 TTS 모델(CosyVoice2)을 SEAME 코드스위칭 데이터셋에 fine-tuning하여 대화체 중국어-영어 CS 음성을 합성. 합성 음성으로 학습 데이터의 양과 화자 다양성을 대폭 확장.
- 핵심 차별점: 다국어 TTS를 코드스위칭 음성 데이터 증강에 활용하는 새로운 접근. CosyVoice2의 다국어 능력을 활용하여 자연스러운 언어 전환 패턴 보존. 대규모 합성 데이터로 화자 다양성 확보.
- 실험 결과: DevMan에서 MER 12.1% → 10.1%(16.5% 상대 개선), DevSGE에서 17.8% → 16.0%(10.1% 상대 개선)으로 일관된 성능 향상.
- 우리 연구 관련도: ★☆☆ (코드스위칭 ASR 데이터 증강으로 speech SSL/VQ 연구와의 직접적 관련은 낮으나, 합성 데이터 품질이 speech representation의 다국어 능력에 미치는 영향에 대한 간접적 참고점 제공)

## 2. SpeechLLM (Speech-Language Model, Spoken Dialogue, Speech Understanding/Generation with LLM)

### **DrVoice: Parallel Speech-Text Voice Conversation Model via Dual-Resolution Speech Representations (Chao-Hong Tan, Qian Chen, Wen Wang, Chong Deng, Qinglin Zhang, Luyao Cheng, Hai Yu, Xin Zhang, Xiang Lv, Tianyu Zhao, Chong Zhang, Yukun Ma, Yafeng Chen, Hui Wang, Jiaqing Liu, Xiangang Li, Jieping Ye — Alibaba, 2025-06)** — ICLR 2026 accepted
- arxiv URL: https://arxiv.org/abs/2506.09349
- 기존 문제: 음성 토큰(~25Hz)과 텍스트 토큰(~5Hz) 간의 temporal resolution 불일치로 인해 음성 LLM에서 연산 비용이 높고, 음성-텍스트 정렬이 어려움. 기존 interleaved 생성은 시퀀스 길이를 크게 증가시키고, parallel 생성은 정렬 품질이 저하.
- 기존 방법: Moshi, SpeechGPT 등이 interleaved 또는 sequential 방식으로 음성/텍스트를 생성. 높은 해상도의 음성 토큰이 LLM 컨텍스트를 과도하게 점유하여 효율성 저하.
- 제안 방법: Dual-Resolution 전략 — (이해) grouping 메커니즘으로 25Hz 이산 음성 토큰을 5Hz 음성 표현으로 매핑하여 temporal resolution 불일치 완화. (생성) shared LLM layer의 hidden state에서 Text Head와 Speech Refined Head(SRH)를 병렬로 구동하여 텍스트와 ungrouped 음성 토큰을 동시 생성. Joint autoregressive modeling 기반.
- 핵심 차별점: 이해와 생성 양쪽에서 dual-resolution 전략을 적용한 최초의 통합 모델. Grouping으로 LLM 입력을 5배 압축하면서도 음성 정보 보존. 7B 규모에서 오픈소스 SOTA 달성.
- 실험 결과: DrVoice-7B가 OpenAudioBench에서 69.24(SOTA), Big Bench Audio에서 66.3(2위 대비 10점 이상 격차)으로 새로운 SOTA. VoiceBench 76.02로 최고 수준과 경쟁(76.93). UltraEval-Audio에서도 상위 성능.
- 우리 연구 관련도: ★★☆ (Dual-resolution에서 25Hz → 5Hz grouping이 speech representation의 temporal granularity 설계에 직접 참고 가능. 이산 음성 토큰의 LLM 활용 방식이 VQ-based representation의 downstream 적용에 시사점 제공)

### **Towards Efficient Speech-Text Jointly Decoding within One Speech Language Model (Haibin Wu, Yuxuan Hu, Ruchao Fan, Xiaofei Wang, Kenichi Kumatani, Bo Ren, Jianwei Yu, Heng Lu, Lijuan Wang, Yao Qian, Jinyu Li — Microsoft, 2025-06)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2506.04518
- 기존 문제: Speech LM에서 음성과 텍스트를 동시에 생성하는 joint decoding의 최적 전략이 불명확. Interleaved, parallel 등 다양한 패러다임이 제안되었으나, 동일 조건에서의 공정한 비교가 부재하여 실무적 선택 기준이 모호.
- 기존 방법: VALL-E 계열의 interleaved 생성, SpeechGPT의 sequential 생성, Moshi의 parallel 생성 등이 각각 다른 모델/데이터/학습 설정으로 제안되어 직접 비교 불가.
- 제안 방법: 동일한 베이스 LM(Phi-4 MM), 음성 토크나이저(S3Tokenizer), SFT 데이터, 학습 파라미터를 고정하고 3가지 대표적 joint decoding 전략(interleaved, parallel, 기타)을 체계적으로 비교. 추가로 Early-Stop Interleaved(ESI) 패턴을 제안하여 interleaved의 품질을 유지하면서 디코딩 속도를 대폭 개선.
- 핵심 차별점: 최초의 통제된 조건(same LM, tokenizer, data, params)에서의 joint decoding 전략 비교 연구. ESI 패턴이 interleaved의 정렬 품질과 parallel의 속도를 동시 달성.
- 실험 결과: Interleaved가 최고의 음성-텍스트 정렬 품질이나 긴 토큰 시퀀스로 인퍼런스 느림. ESI 패턴이 interleaved 대비 유의미한 디코딩 가속과 동등 이상의 성능 달성.
- 우리 연구 관련도: ★★☆ (S3Tokenizer 기반의 음성 토큰화 방식과 joint decoding에서의 음성-텍스트 정렬 분석이 VQ-based representation의 LLM 통합 방식 설계에 직접 참고 가능. ESI의 토큰 시퀀스 효율화가 speech token 설계에 시사점 제공)

### **PredGen: Accelerated Inference of Large Language Models through Input-Time Speculation for Real-Time Speech Interaction (Shufan Li, Aditya Grover — UCLA, 2025-06)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2506.15556
- 기존 문제: Speech LLM 기반 실시간 음성 상호작용에서 사용자 발화 종료 후 응답 생성까지의 지연(latency)이 커서 자연스러운 대화가 어려움. 기존 speculative decoding은 출력 시점에서만 적용되어 입력 처리 지연을 줄이지 못함.
- 기존 방법: 기존 Speech LLM은 사용자 발화 완료 → 텍스트 응답 생성 → TTS 변환의 순차적 파이프라인. Speculative decoding(Leviathan et al.)은 출력 생성 단계에서만 가속을 제공. 입력 수신 중의 유휴 시간을 활용하지 못함.
- 제안 방법: Predictive Generation — 사용자가 아직 말하고 있는 동안(입력 시점)에 speculative decoding을 수행하여 후보 응답을 미리 생성. 사용자 발화 종료 시점에 이미 생성된 후보를 검증하고, 유효한 경우 즉시 TTS 처리 시작.
- 핵심 차별점: 입력 시점(input-time)에서의 speculative decoding이라는 새로운 패러다임. 기존 출력 시점 가속과 직교적으로 적용 가능하여 추가 조합 효과. 최소한의 연산 오버헤드.
- 실험 결과: Lmsys 및 MT-Bench 데이터셋에서 약 2배 지연 감소(latency ~50% 감소). 추가 연산 비용 최소화하면서 다양한 사용 시나리오에서 일관된 지연 개선.
- 우리 연구 관련도: ★☆☆ (Speech LLM 추론 효율화로 speech SSL/VQ 연구와의 직접적 관련은 낮으나, 음성 토큰의 스트리밍 처리와 투기적 생성이 실시간 음성 시스템에서의 representation 활용에 간접 참고 가능)

## 3. Speech Foundation Model (Speech SSL, Speech Tokenizer, Audio Pre-training)

### **SAC: Neural Speech Codec with Semantic-Acoustic Dual-Stream Quantization (Wenxi Chen, Xinsheng Wang, Ruiqi Yan, Yushen Chen, Zhikang Niu, Ziyang Ma, Xiquan Li, Yuzhe Liang, Hanlin Wen, Shunshun Yin et al., 2025-10)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2510.16841
- 기존 문제: 기존 음성 코덱에서 semantic과 acoustic 정보가 단일 양자화 스트림에 혼합되어 각각의 역할에 최적화하기 어려움. 특히 시맨틱 표현의 충실도가 코덱의 재구성 학습 과정에서 손상되어, downstream 언어 모델링에서의 시맨틱 품질이 저하.
- 기존 방법: SoundStream, EnCodec 등 단일 RVQ 스트림으로 모든 정보를 압축. SpeechTokenizer가 첫 번째 양자화기에 시맨틱 증류를 시도했으나, 재구성 목적함수가 시맨틱 정보를 왜곡. WavTokenizer는 단일 코드북으로 극한 압축을 달성했으나, 시맨틱-어쿠스틱 분리가 불완전.
- 제안 방법: Dual-Stream 양자화 — 사전학습된 speech tokenizer(HuBERT 등)로 시맨틱 토큰을 추출하고 동결(freeze)하여 언어적 정보 충실도를 보장. 별도의 어쿠스틱 토큰 스트림이 시맨틱 토큰에서 누락된 음향 정보(프로소디, 화자 특성, 음질)를 보완. 각 스트림이 고유 역할에 특화되어 최적화.
- 핵심 차별점: 시맨틱과 어쿠스틱을 토큰 수준에서 완전 분리한 최초의 dual-stream 코덱. 시맨틱 스트림 동결로 사전학습 SSL 모델의 표현 품질을 무손실 보존. 어쿠스틱 스트림이 시맨틱 잔차(residual)를 모델링하여 효율적 비트 할당.
- 실험 결과: 다양한 비트레이트에서 클린/노이즈 조건 모두에서 강력한 재구성 성능. UTMOS(자연스러움) 및 WER(지능도)에서 기존 코덱 대비 우수. 시맨틱 표현 품질이 SSL continuous embedding 수준에 필적하여 기존 코덱 대비 시맨틱 표현에서 현저한 우위.
- 우리 연구 관련도: ★★★ (시맨틱-어쿠스틱 분리가 VQ-based representation 연구의 핵심 과제와 직결. Dual-stream 양자화에서의 정보 분리 전략이 speech tokenizer 설계에 직접 적용 가능. 시맨틱 스트림 동결이 prediction-free SSL 표현의 downstream 활용 방식에 중요 참고점)

### **LongCat-Audio-Codec: An Audio Tokenizer and Detokenizer Solution Designed for Speech Large Language Models (Xiaohan Zhao, Hongyu Xiang, Shengze Ye, Song Li, Zhengkun Tian, Guanyu Chen, Ke Ding, Guanglu Wan — Meituan LongCat Team, 2025-10)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2510.15227
- 기존 문제: 기존 음성 코덱이 Speech LLM의 산업적 요구사항(저지연 스트리밍 합성, 초저비트레이트, 높은 음질)을 동시에 만족하지 못함. 시맨틱 모델링 능력, 유연한 음향 특징 추출, 저지연 스트리밍 합성을 하나의 코덱에 통합하는 것이 미해결.
- 기존 방법: EnCodec, SoundStream 등은 비트레이트-품질 트레이드오프가 큼. WavTokenizer가 40/75 tokens/s로 압축률을 높였으나 스트리밍 합성과의 통합이 부족. 기존 코덱은 Speech LLM 백엔드로서의 end-to-end 최적화가 미흡.
- 제안 방법: Decoupled 모델 아키텍처 + 다단계 학습 전략. 시맨틱 토큰과 어쿠스틱 토큰을 병렬로 생성하여 고충실도 재구성. 16.67Hz 초저 프레임레이트로 인코딩. 최소 0.43kbps(2 코드북)~최대 0.87kbps(4 코드북)의 초저비트레이트 달성. 스트리밍 합성을 위한 저지연 디코더 내장.
- 핵심 차별점: 산업급 end-to-end Speech LLM을 위한 토크나이저/디토크나이저 통합 솔루션. 극도로 낮은 비트레이트(0.43~0.87kbps)에서 높은 지능도와 화자 유사도 유지. 시맨틱+어쿠스틱 병렬 생성으로 코딩 효율과 디코딩 품질 동시 확보.
- 실험 결과: 0.87kbps(4 코드북)에서 WER 1.48, PESQ 2.30, STOI 0.921, 화자 유사도 0.942 달성. 0.43kbps(2 코드북)에서도 높은 지능도 유지. 기존 코덱 대비 비트레이트 대 품질 비율에서 우수.
- 우리 연구 관련도: ★★☆ (초저비트레이트에서의 시맨틱-어쿠스틱 병렬 토큰화가 VQ-based representation의 압축 효율 연구에 직접 관련. 16.67Hz 프레임레이트가 temporal representation의 최적 해상도 탐색에 참고점. 다만 산업급 코덱 최적화에 초점으로 SSL 학습과의 직접적 연결은 제한적)

### **Efficient Training of Self-Supervised Speech Foundation Models on a Compute Budget (Andy T. Liu, Yi-Cheng Lin, Haibin Wu, Stefan Winkler, Hung-yi Lee — National Taiwan University / ASUS Intelligent Cloud Services, 2024-09)** — ICASSP 2025 accepted
- arxiv URL: https://arxiv.org/abs/2409.16295
- 기존 문제: Speech SSL 사전학습이 대규모 메모리와 연산 비용을 요구하여, 제한된 예산에서 효율적 학습이 어려움. SSL 성능에 기여하는 요소(목적함수, 모델 아키텍처, 모델 크기, 데이터 크기)의 상대적 중요도가 불명확하여 자원 배분의 최적화가 어려움.
- 기존 방법: HuBERT, wav2vec 2.0, data2vec 등이 대규모 연산자원(수백~수천 GPU-hours)으로 학습. 개별 논문이 각자의 설정에서 결과를 보고하여, 동일 연산 예산에서의 공정한 비교 부재. 모델 크기를 키우는 것이 항상 유리한지에 대한 scaling law 분석도 미흡.
- 제안 방법: 동일한 연산 예산에서 SSL 목적함수(HuBERT, wav2vec 2.0, data2vec 등), 모델 아키텍처(표준 vs slimmer), 모델 크기, 사전학습 데이터 크기를 체계적으로 벤치마크. Neural scaling law 관점에서 주어진 예산에서의 최적 배분 탐색.
- 핵심 차별점: SSL 목적함수보다 모델 아키텍처, 모델 크기, 데이터 크기가 성능에 더 크게 기여함을 실증. 슬림한(slim) 아키텍처가 동일 파라미터/연산 예산에서 일반적인 소형 아키텍처를 능가. 데이터 증강이 사전학습 데이터 부족을 대체할 수 없음을 확인.
- 실험 결과: 동일 연산/파라미터 예산에서 slimmer 아키텍처가 common small 아키텍처를 일관되게 능가. 사전학습 데이터 크기가 SSL 성능에 가장 큰 영향(제한된 데이터에서 반복 학습 시 성능 저하). 주어진 연산 예산에서 최적 모델 크기가 존재(무조건 크다고 좋지 않음).
- 우리 연구 관련도: ★★★ (Speech SSL의 효율적 학습에 대한 체계적 분석으로, prediction-free speech SSL 연구의 학습 전략 설계에 직접 적용 가능. 모델 아키텍처와 데이터 크기의 상대적 중요도 분석이 VQ-based representation 학습의 자원 배분에 핵심 참고점. SSL 목적함수 비교가 새로운 학습 목적함수 설계의 기준선 제공)
