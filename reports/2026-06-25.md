## 1. ASR (Automatic Speech Recognition)

### Tight Boundary Prediction in Speaker Diarization Using Causal-Anticausal Consistency (Shota Horiguchi, Marc Delcroix, Naohiro Tawara, Takanori Ashihara, Atsushi Ando — NTT, 2026.06) — Interspeech 2026 accepted (Long Paper)

- **arxiv URL:** https://arxiv.org/abs/2606.11795
- **기존 문제:** 다화자 대화 음성 인식(ASR) 데이터를 사용하여 화자 분리(diarization) 모델을 학습할 때, ASR 데이터는 의미적 연속성을 우선시하여 휴지(pause)와 경계 여유분을 발화 구간 내에 포함시키므로, 결과적으로 느슨한(loose) 레이블이 생성되어 경계 예측 정확도가 저하된다.
- **기존 방법:** 기존 화자 분리 모델은 학습 데이터의 레이블 품질에 직접적으로 의존하며, 느슨한 레이블로 학습된 모델은 필연적으로 느슨한 예측을 생성한다. 레이블 품질 향상을 위한 별도의 정밀 어노테이션 작업은 비용이 높아 대규모 적용이 어려웠다.
- **제안 방법:** 인과(causal) 모델과 반인과(anticausal) 모델을 활용하여 더 정밀한 의사 레이블(pseudo label)을 생성. 인과 모델은 시간 순방향으로, 반인과 모델은 역방향으로 처리하여 본질적으로 느슨해지는 학습 편향을 방지. 두 모델의 공동 학습(co-training) 방식으로 반복적으로 레이블을 정밀화하고 모델을 업데이트.
- **핵심 차별점:** 추가 어노테이션 없이 기존 느슨한 레이블만으로 정밀한 경계 예측이 가능 — 인과-반인과 일관성(causal-anticausal consistency)이라는 새로운 자기 개선 메커니즘을 제시.
- **실험 결과:** 이상적인 정밀 레이블 학습 대비 약 70%의 경계 정밀화 효과를 회복하며, 다운스트림 성능도 개선.
- **우리 연구 관련도:** ★☆☆ — 화자 분리의 레이블 정밀화에 초점. 자기지도 학습 관점에서 레이블 없이 표현을 개선하는 패러다임은 참고할 수 있으나, prediction-free SSL/VQ 표현과의 직접적 연관은 제한적.

### Whisper Hallucination Detection and Mitigation via Hidden Representation Steering and Sparse AutoEncoders (Georgii Aparin, Vadim Popov, Tasnima Sadekova, Assel Yermekova, 2026.06) — arxiv preprint

- **arxiv URL:** https://arxiv.org/abs/2606.07473
- **기존 문제:** Whisper ASR 모델은 비음성(non-speech) 오디오 입력에 대해 입력과 무관한 일관된 텍스트를 생성하는 환각(hallucination) 현상이 심각하다. 이는 신뢰성과 안전성에 중대한 문제를 초래한다.
- **기존 방법:** 미세조정(fine-tuning) 기반 방법은 환각을 줄일 수 있으나, 모델 가중치를 직접 변경해야 하며 추가 학습 데이터와 비용이 필요하다. 환각의 내부 메커니즘에 대한 분석은 부족했다.
- **제안 방법:** 오디오 인코더 활성화(activation)를 추출하여 두 가지 표현 공간에서 분석: (1) 원시 Whisper 활성화, (2) Sparse AutoEncoder(SAE) 잠재 공간. 활성화 공간 조향(activation-space steering)과 SAE 잠재 공간 조향(SAE latent-space steering) 두 가지 전략을 제안.
- **핵심 차별점:** 모델 가중치 변경 없이(training-free) 추론 시 표현 조향만으로 환각을 억제 — Mechanistic Interpretability 기법(SAE)을 ASR 환각 문제에 최초 적용.
- **실험 결과:** SAE 기반 조향으로 Whisper small의 환각률을 72.63%에서 14.11%로, Whisper large-v3를 86.88%에서 27.33%로 감소. 일반 음성 데이터에서의 WER 저하는 미미하여 미세조정 기반 방법에 근접하는 성능.
- **우리 연구 관련도:** ★★☆ — SAE를 통한 음성 모델 내부 표현 분석 방법론이 speech SSL 표현의 해석 및 활용 연구에 참고 가치. 표현 공간의 구조적 이해 관점에서 관련.

### G-STAR: End-to-End Global Speaker-Tracking Attributed Recognition (Jing Peng, Ziyi Chen, Haoyu Li et al. — Nanjing Univ./SJTU/Huawei/ETH Zurich, 2026.03) — arxiv preprint

- **arxiv URL:** https://arxiv.org/abs/2603.10468
- **기존 문제:** 장시간 다화자 회의 음성에서 시간 정보 포함(timestamped) 화자 귀속 자동 음성 인식(SA-ASR)은 청크 단위 추론 시 회의 전체의 화자 정체성 일관성을 유지하면서 시간 표시가 부착된 화자별 전사를 생성해야 하는 어려운 과제이다.
- **기존 방법:** 기존 파이프라인 방식은 음성 인식, 화자 분리, 화자 귀속을 별도로 수행하여 오류가 전파되었다. 최근 Speech-LLM 기반 접근법이 등장했으나, 장시간 오디오에서의 글로벌 화자 추적은 여전히 미해결 과제였다.
- **제안 방법:** 캐시 조건부(cache-conditioned) 화자 추적 모듈과 Speech-LLM 전사 백본을 결합한 엔드투엔드 프레임워크. 추적 모듈이 시간적 기반(temporal grounding)이 있는 구조화된 화자 단서를 제공하고, LLM이 이를 조건으로 귀속된 텍스트를 생성. 컴포넌트별 최적화와 엔드투엔드 공동 학습 모두 지원.
- **핵심 차별점:** 이기종 지도(heterogeneous supervision) 및 도메인 전이(domain shift) 환경에서도 유연한 학습이 가능한 최초의 글로벌 화자 추적 SA-ASR 프레임워크.
- **실험 결과:** 다화자 회의 시나리오에서 기존 파이프라인 및 Speech-LLM 기반 방법 대비 화자 귀속 정확도와 전사 품질 모두 개선.
- **우리 연구 관련도:** ★☆☆ — SA-ASR 시스템 아키텍처가 주요 기여이며, SSL/VQ 기반 표현 학습과의 직접적 연관은 제한적.

## 2. SpeechLLM (Speech-Language Model)

### BayLing-Duplex: Native Full-Duplex Speech Dialogue with a Single Autoregressive LLM (Qingkai Fang, Shoutao Guo, Yang Feng — ICT/CAS, 2026.06) — arxiv preprint

- **arxiv URL:** https://arxiv.org/abs/2606.14528
- **기존 문제:** 실시간 전이중(full-duplex) 음성 상호작용은 차세대 음성 챗봇의 핵심 기능이지만, 기존 모델들은 외부 VAD나 별도의 턴 제어 모듈에 의존하여 자연스러운 겹침(overlap), 주저함(hesitation), 끼어들기(barge-in) 처리가 어려웠다.
- **기존 방법:** Moshi 등 기존 전이중 모델은 별도의 턴 테이킹 모듈이나 듀얼 스트림 아키텍처를 필요로 했으며, 응답 품질과 상호작용 자연스러움 간에 트레이드오프가 존재했다.
- **제안 방법:** 단일 자기회귀 LLM이 사용자 음성, 어시스턴트 텍스트, 어시스턴트 음성을 하나의 다채널 인터리브 시퀀스로 표현. 턴 테이킹, 중단 처리, 텍스트 계획, 음성 토큰 생성 모두가 다음 토큰 예측(next-token prediction)으로 통합. 기존 어휘에 소수의 특수 토큰만 추가하여 LLM 간 이식이 용이.
- **핵심 차별점:** 보조 모듈 없이 단일 LLM만으로 전이중 대화를 달성 — "듣기와 말하기 동시 모델링이 응답 품질을 희생하지 않는다"는 것을 실증.
- **실험 결과:** GLM-4-Voice 체크포인트에서 400K 전이중 샘플로 미세조정 후 DPO 적용. InstructS2S-Eval에서 턴 테이킹 성공률 92%, 중단 처리 성공률 100% 달성. Moshi 대비 음성 응답 점수 2.17→3.39로 향상. Llama Questions, Web Questions, Alpaca-Eval에서 턴 기반 모델과 동등 이상의 성능.
- **우리 연구 관련도:** ★☆☆ — 전이중 대화 시스템 아키텍처가 주요 기여이며, SSL/VQ 기반 표현 학습과의 직접적 연관은 제한적.

### Continuous Audio Thinking for Large Audio Language Models (Gyojin Han, Dong-Jae Lee, Changho Choi, Jongsuk Kim, Junmo Kim — KAIST, 2026.06) — arxiv preprint

- **arxiv URL:** https://arxiv.org/abs/2606.18273
- **기존 문제:** 대규모 오디오 언어 모델(LALM)은 음성 전사부터 음악 분석까지 다양한 오디오 이해 작업에서 인상적인 성능을 보이지만, 음향 정보를 응답 생성 전에 체계적으로 조직하고 추론하는 능력은 부족하다.
- **기존 방법:** 기존 LALM들은 오디오 인코더의 출력을 직접 LLM에 전달하여 텍스트를 생성하는 단순한 파이프라인을 사용. Chain-of-thought 프롬프팅은 텍스트 영역에서의 추론에만 적용되었고, 오디오 영역에서의 연속적 사고 과정은 탐구되지 않았다.
- **제안 방법:** Continuous Audio Thinking (CoAT) — 오디오 언어 모델에 연속 잠재 작업 공간(continuous latent workspace)을 부여하여, 응답 생성 전에 음향 정보를 조직할 수 있게 하는 프레임워크. 오디오 전문가(audio expert) 모델로부터의 증류(distillation)를 통해 기반(grounding)을 확보.
- **핵심 차별점:** 텍스트 기반 CoT가 아닌 연속 잠재 공간에서의 "오디오 사고(audio thinking)"를 최초로 제안 — 오디오 모달리티에 특화된 추론 과정을 가능하게 함.
- **실험 결과:** 다양한 오디오 이해 벤치마크에서 기존 LALM 대비 성능 향상을 달성.
- **우리 연구 관련도:** ★★☆ — 연속 잠재 공간에서의 오디오 표현 조직 방법론이 speech representation learning과 관련. 잠재 공간의 구조적 활용 관점에서 prediction-free SSL 연구에 영감을 줄 수 있음.

### WildSpeech-Bench: Benchmarking End-to-End SpeechLLMs in the Wild (Linhao Zhang, Jian Zhang, Bokai Lei, Chuhan Wu, Aiwei Liu, Wei Jia, Xiao Zhou — Tencent, 2025.06) — arxiv preprint

- **arxiv URL:** https://arxiv.org/abs/2506.21875
- **기존 문제:** 엔드투엔드 SpeechLLM의 평가 방법이 부재. 기존 평가는 텍스트 기반 벤치마크를 음성에 적응시킨 것으로, 운율(prosody), 동음이의어(homophones), 더듬기(stuttering), 사용자 기대 차이 등 음성 고유의 특성과 과제를 간과했다.
- **기존 방법:** 기존 벤치마크(VocalBench, SOVA-Bench 등)는 주로 음성-텍스트(S2T) 성능에 초점을 맞추었으며, 음성-음성(S2S) 대화 능력에 대한 전용 평가 프레임워크가 부족했다.
- **제안 방법:** 실제 채팅 데이터에서 음성 시나리오에 관련된 쿼리를 체계적으로 수집하고, 화자 속성과 음향 조건의 다양성을 도입하며, 음성 특유의 현상으로 증강하여 1,100개의 쿼리로 구성된 5개 주요 카테고리 벤치마크를 구축. S2S 능력까지 포괄적으로 평가.
- **핵심 차별점:** SpeechLLM의 S2S 능력을 평가하는 최초의 전용 벤치마크 — S2T에서의 우수한 성능이 S2S로 전이되지 않음을 실증적으로 규명.
- **실험 결과:** 모든 테스트 모델에서 환경 잡음과 배경 음성에 대한 범용적 강건성 부족을 발견. S2T 대화 벤치마크에서의 강한 성능이 S2S 설정으로 전이되지 않음을 확인.
- **우리 연구 관련도:** ★☆☆ — 벤치마크 및 평가 프레임워크가 주요 기여이며, SSL/VQ 표현 학습과의 직접적 연관은 제한적.

## 3. Speech Foundation Model

### P2PSynCodec: An Ultra-Low-Bitrate Neural Speech Codec with Plain-to-Pseudo Synergistic Vector Quantization (Xiao-Hang Jiang, Yang Ai, Fei Liu, Rui-Chen Zheng, Jian-Qing Gao, Zhen-Hua Ling, Ji Wu — USTC/iFLYTEK/Tsinghua, 2026.06) — arxiv preprint

- **arxiv URL:** https://arxiv.org/abs/2606.05876
- **기존 문제:** 초저비트레이트(ultra-low-bitrate) 음성 코덱은 제한된 비트 예산으로 인해 고품질 음성 재구성이 어려우며, 기존 VQ 기반 방법은 더 많은 코드북을 사용할수록 전송 비트레이트가 비례하여 증가하는 한계가 있다.
- **기존 방법:** SoundStream, EnCodec 등 기존 코덱은 Residual Vector Quantization(RVQ)을 사용하여 다수의 코드북으로 품질을 향상시키지만, 각 코드북이 추가 비트레이트를 소비하여 초저비트레이트 환경에서는 코드북 수가 심각하게 제한된다.
- **제안 방법:** Plain-to-Pseudo Synergistic Vector Quantizer(P2PSVQ) — 하나의 일반(plain) VQ와 다수의 유사(pseudo) VQ로 구성. 일반 VQ는 양자화를 통해 기본 토큰을 생성하고, 유사 VQ는 신경망 예측을 통해 보조 토큰을 생성하여 전송 비트레이트를 전혀 추가하지 않음.
- **핵심 차별점:** 유사 VQ의 보조 토큰이 전송 비용 없이(zero transmitted bitrate) 추가 정보를 제공 — 비트레이트 대비 품질의 파레토 최적 한계를 돌파하는 새로운 VQ 패러다임.
- **실험 결과:** 0.5 kbps의 초저비트레이트에서 경쟁 코덱의 2.0 kbps 수준에 필적하는 음성 재구성 품질 달성.
- **우리 연구 관련도:** ★★★ — VQ 기반 표현 학습의 핵심 혁신. Plain-Pseudo VQ 개념은 VQ-based representation 연구에 직접적으로 관련되며, 예측 기반 보조 토큰 생성 전략은 prediction-free SSL과 대조적으로 비교 연구 가치가 높음.

### Self-Guidance: Enhancing Neural Codecs via Decoder Manifold Alignment (Xiang Li, Yixuan Zhou, Jingran Xie, Zhiyong Wu, Hui Wang, 2026.06) — arxiv preprint

- **arxiv URL:** https://arxiv.org/abs/2606.12940
- **기존 문제:** VQ-VAE 기반 신경 음성 코덱은 Speech LLM의 핵심 오디오 토크나이저이지만, 양자화 오차(quantization error)로 인해 재구성 충실도가 병목 현상을 일으킨다. 양자화된 이산 토큰과 원래의 연속 임베딩 사이의 정보 손실이 디코더 성능을 제한한다.
- **기존 방법:** 코드북 크기 확대, 다단계 RVQ 적용, 더 복잡한 디코더 아키텍처 설계 등의 방법이 사용되었으나, 모두 모델 크기나 연산 비용 증가를 수반한다.
- **제안 방법:** 양자화된 토큰과 원래의 연속 임베딩을 처리할 때 디코더 내부의 특성 매니폴드(feature manifold)를 정렬시키는 경량 특성 매핑 손실(feature-mapping loss)을 도입. 학습 시에만 추가 비용이 발생하고 추론 시에는 변경 없음.
- **핵심 차별점:** 추론 비용 제로의 자기 안내(self-guidance) 메커니즘 — 디코더가 양자화 오차에도 불구하고 연속 임베딩 처리 시와 유사한 내부 경로를 따르도록 유도하여 재구성 품질 개선.
- **실험 결과:** XCodec2에 적용 시 모든 재구성 메트릭에서 개선. SOTA 저비트레이트 성능 달성. 코드북 크기를 4배 축소해도 충실도 손실 없음.
- **우리 연구 관련도:** ★★★ — VQ 기반 음성 코덱의 양자화 오차 문제를 직접적으로 해결. 연속-이산 표현 간의 매니폴드 정렬 개념은 VQ-based representation learning 연구에 핵심적으로 관련. 코드북 축소 가능성은 효율적 speech tokenizer 설계에 직접 기여.

### AudioPG: From Physics to Representation — Audio Learning with Synthetic Pre-training via Procedural Generation (Fengrui Liu, Ruiyang Huang, Qijian Zheng, Yuanfang Wang, Feng Liu, 2026.06) — ACM ICMR 2026 accepted

- **arxiv URL:** https://arxiv.org/abs/2606.14791
- **기존 문제:** 자기지도 오디오 표현 학습은 대규모 실제 오디오 데이터에 의존하며, 데이터 수집과 저작권 문제가 학습 규모 확장의 장벽이 된다. 또한 학습된 표현이 어떤 물리적 특성을 포착하는지에 대한 이해가 부족하다.
- **기존 방법:** wav2vec 2.0, HuBERT, BEATs 등 기존 자기지도 모델은 대규모 실제 오디오/음성 데이터로 사전학습하며, AudioMAE 등 마스크 기반 접근법도 실제 데이터에 의존한다.
- **제안 방법:** AudioPG — 절차적 합성(procedural synthesis) 프레임워크로, 기본 음향 원시 요소(acoustic primitives)와 조합 규칙으로부터 파형을 즉석 생성(on-the-fly)하여 Transformer 기반 마스크 오토인코더(masked autoencoder)를 학습. 실제 오디오 데이터를 전혀 사용하지 않음.
- **핵심 차별점:** 실제 데이터 없이 물리 기반 합성 데이터만으로 사전학습 — 단일 GPU에서 20분 이내에 학습 완료. 잠재 공간 분석에서 기본 주파수, 상대 강도 등 물리적 요소가 직교 부분공간(orthogonal subspace)에서 자발적으로 분리되어 선형 디코딩 가능.
- **실험 결과:** ESC-50에서 90.60% 정확도, FSD50K에서 0.546 mAP, UrbanSound8K에서 88.17%, Speech Commands V2에서 97.03% 달성.
- **우리 연구 관련도:** ★★★ — 합성 데이터 기반 자기지도 사전학습과 직교 부분공간에서의 물리적 요소 분리 발견은 prediction-free speech SSL 및 representation learning 연구에 직접적으로 관련. 데이터 독립적 사전학습 패러다임과 표현의 해석 가능성 측면에서 핵심 참고 논문.
