## 1. ASR (Automatic Speech Recognition)

### **[DiaScriber: A Speech LLM for Joint Diarization and Transcription in Multi-Speaker Scenarios] (Qwen Team, 2026-08-24)** — arxiv preprint
- https://arxiv.org/abs/2608.22796
- **기존 문제**: 다화자 환경에서 "누가, 무엇을, 언제 말했는가"를 동시에 예측하는 것은 기존 ASR 파이프라인에서 diarization과 transcription이 분리되어 있어 오류 전파 및 정보 불일치 문제가 존재
- **기존 방법**: 별도의 speaker diarization 모듈과 ASR 모듈을 cascade로 연결하거나, 단순한 end-to-end multi-talker ASR 모델 사용. TagSpeech 등이 joint 접근을 시도했으나 대규모 다양한 시나리오 대응이 부족
- **제안 방법**: Qwen3.5-Omni 기반으로 3단계 학습 전략(CPT → SFT → RL) 적용. CPT 단계에서 85,000시간의 대규모 다화자 데이터(대화, 회의, 교실, 인터뷰, 팟캐스트 등) 활용. 다양한 데이터 파이프라인(검증·정제, turn-transition 및 overlapping-speech 시뮬레이션, 멀티모달 어노테이션)으로 복잡한 다화자 시나리오 커버
- **핵심 차별점**: 범용 speech LLM을 MSASR 전문 모델로 전환하는 체계적 3단계 학습과 대규모 시뮬레이션 데이터 구축 방법론. RL 단계까지 적용하여 출력 품질 최적화
- **실험 결과**: 다화자 diarization과 transcription을 동시 수행하며, 기존 cascade 및 end-to-end 방식 대비 종합적 성능 향상 달성
- **우리 연구 관련도**: ★☆☆ — ASR/diarization 응용 중심으로, speech SSL이나 representation learning과는 직접적 연관 적음

### **[Speaker Attributed Automatic Speech Recognition Using Speech Aware LLMS] (Hagai Aronowitz, Zvi Kons, Avihu Dekel, George Saon, Ron Hoory — IBM Research, 2026-04-13)** — arxiv preprint
- https://arxiv.org/abs/2604.11269
- **기존 문제**: 기존 ASR은 발화 내용만 전사하며, "누가 말했는가"에 대한 speaker identity 정보를 포함하지 않음. 별도의 speaker diarization 후 ASR을 수행하는 cascade 접근은 오류 누적 및 시스템 복잡도 증가 문제
- **기존 방법**: 순차적 diarization → ASR pipeline, 또는 speaker embedding을 별도 모듈로 추출하여 ASR 출력과 병합하는 방식. Multi-talker ASR 모델도 존재하나 speaker attribution 정확도가 낮음
- **제안 방법**: Granite-speech (speech-aware LLM)을 minimal한 아키텍처 변경으로 Speaker-Attributed ASR (SAA) 태스크에 적응. Speaker cluster identification tag ([Speaker 1 cluster 42]:)를 도입하여 SAA와 jointly 학습. 인위적으로 연결된 다화자 대화 데이터 증강 기법 적용
- **핵심 차별점**: 기존 speech LLM에 최소한의 변경만으로 speaker attribution 기능 추가. Speaker cluster ID tag를 통한 joint training이 정확도를 크게 향상시킴
- **실험 결과**: 다수 벤치마크에서 기존 diarization+ASR sequential pipeline 대비 우수한 성능 달성
- **우리 연구 관련도**: ★☆☆ — Speaker representation과 ASR 통합 관점에서 참고 가능하나, SSL/VQ 기반 연구와는 거리가 있음

### **[Diarization-Guided Qwen-ASR Adaptation for Multilingual Two-Speaker Conversational Speech] (Hao Wu et al. — Shanghai Qi Zhi Institute, Megatronix, 2026-07-09)** — arxiv preprint (MLC-SLM 2026 Challenge)
- https://arxiv.org/abs/2607.08208
- **기존 문제**: 다국어 2화자 대화 음성 인식에서 화자 분리와 정확한 전사를 동시에 달성하기 어려움. 기존 Qwen-ASR 모델은 단일 화자에 최적화되어 다화자 시나리오에서 성능 저하
- **기존 방법**: 기본 Qwen-ASR 모델 직접 적용 또는 단순 fine-tuning. 다화자 데이터 부족으로 인한 성능 한계
- **제안 방법**: 모듈형 speaker diarization front-end(VAD → 서브세그먼트 생성 → CAMPPlus speaker embedding → 2화자 spectral clustering → RTTM 기반 오디오 분할)과 Qwen3-ASR-1.7B를 결합. 3단계 적응: (1) supervised full fine-tuning, (2) TTS 기반 합성 음성 증강 + LoRA fine-tuning, (3) GRPO 강화학습
- **핵심 차별점**: TTS 기반 3-pipeline 합성 음성 증강 프레임워크와 GRPO RL을 결합한 다단계 적응 전략. 실제 다화자 데이터 부족 문제를 합성 데이터로 효과적으로 해결
- **실험 결과**: 공식 dev set에서 평균 tcpMER 23.70 (Qwen-ASR-1.7B 대비 6.83 포인트 절대 감소), 최종 eval set에서 tcpMER 17.97 달성
- **우리 연구 관련도**: ★☆☆ — ASR 적응 및 데이터 증강 기법 중심으로, representation learning과는 직접적 연관 적음

## 2. SpeechLLM (Speech-Language Model)

### **[DuplexSLA: A Full-Duplex Spoken Language Model with Synchronized Speech, Language, and Action] (Haoyu Zhang et al., 2026-05-27)** — arxiv preprint
- https://arxiv.org/abs/2605.20755
- **기존 문제**: 기존 full-duplex 음성 대화 모델은 turn-taking을 외부 VAD에 의존하거나, 대화 중 tool calling/planning이 음성 출력을 중단시키는 문제 존재. 음성, 언어, 행동(action)의 동기화가 부족
- **기존 방법**: 외부 semantic VAD를 통한 turn-taking 제어, 별도의 tool-use 파이프라인. FlexDuo, Moshi 등이 full-duplex를 시도했으나 action channel 통합은 미비
- **제안 방법**: 단일 backbone에서 3개 채널(연속 사용자 오디오, 이산 어시스턴트 오디오, rate-limited 텍스트 action 채널)을 160ms 청크 타임라인에서 동시 디코딩하는 dual-stream 구조. Semantic-driven turn-taking(인터럽트, 일시정지, 백채널을 backbone 내부에서 처리)과 in-conversation planning/tool calling(action 채널에서 음성 중단 없이 계획 텍스트 및 구조화된 tool call 출력)
- **핵심 차별점**: 음성·언어·행동의 동기화된 joint decoding으로 대화 중 tool calling과 turn-taking을 통합. DuplexSLA-Bench 벤치마크 제공
- **실험 결과**: DuplexSLA-Bench에서 pause, interrupt, backchannel turn-taking과 3가지 스타일의 in-conversation tool calling 평가. 기존 full-duplex 모델 대비 종합적 우위
- **우리 연구 관련도**: ★☆☆ — 대화 시스템 아키텍처 중심으로, speech representation 연구와는 직접적 연관 적음

### **[VoxMind: An End-to-End Agentic Spoken Dialogue System] (Tianle Liang, Yifu Chen, Shengpeng Ji et al., 2026-04-21)** — ACL 2026 accepted
- https://arxiv.org/abs/2604.15710
- **기존 문제**: 기존 음성 대화 모델은 외부 tool/API 호출 등 agentic 능력이 부족하여, 실제 태스크 완수(예약, 검색, 제어 등)에 한계. 대규모 tool 통합 시 추론 지연 증가 문제
- **기존 방법**: 텍스트 기반 LLM agent에 TTS/ASR cascade를 연결하는 방식. 일부 speech-to-speech 모델은 대화 능력은 있으나 tool calling 미지원
- **제안 방법**: (1) 470시간 AgentChat 데이터셋 구축, (2) Think-before-Speak 메커니즘으로 구조화된 추론을 응답 생성의 전제 조건으로 내재화, (3) Multi-Agent Dynamic Tool Management 아키텍처로 보조 에이전트가 비동기적으로 tool 검색을 수행하여 추론 지연과 toolset 크기를 분리
- **핵심 차별점**: End-to-end 음성 대화 모델에 agentic 능력(tool calling, planning)을 통합한 최초의 체계적 프레임워크. Think-before-Speak으로 추론 품질 향상
- **실험 결과**: Task completion rate 34.88% → 74.57%로 향상. Gemini-2.5-Pro를 spoken agent 태스크에서 능가하면서 일반 대화 품질 유지
- **우리 연구 관련도**: ★☆☆ — Spoken dialogue agent 시스템 중심으로, speech representation 연구와는 직접적 연관 적음

### **[CORTIS: Text-Only Adaptation of Spoken Language Models for Task-Oriented Voice Agents] (Youngwon Choi et al. — Maum AI, SNU, KAIST, 2026-06-19)** — arxiv preprint
- https://arxiv.org/abs/2606.21453
- **기존 문제**: Task-oriented voice agent는 음성 입력을 semantic frame, 실행 가능한 action, function call 등 구조화된 출력으로 매핑해야 함. ASR+LLM cascade 접근은 전사 오류가 하위 구조화 출력 생성에 전파되며, 특히 잡음 환경에서 심화
- **기존 방법**: ASR → 텍스트 LLM cascade, 또는 음성-타겟 쌍 데이터로 직접 SLM fine-tuning. 후자는 태스크별 음성-타겟 어노테이션 데이터 구축 비용이 매우 높음
- **제안 방법**: CORTIS — SLM(Spoken Language Model)을 텍스트 형태의 태스크 supervision만으로 fine-tuning하여, 추론 시에는 음성 기반 구조화 출력 생성 가능. 태스크별 음성-타겟 어노테이션 없이 적응 가능
- **핵심 차별점**: 텍스트만으로 SLM을 태스크 적응시키는 실용적 전략. 음성-타겟 쌍 데이터 수집 비용을 제거하면서도 cascade 대비 경쟁력 유지, 음향 열화 조건에서는 오히려 우위
- **실험 결과**: 2개의 Qwen2.5-Omni 백본과 3개의 task-oriented 음성 데이터셋에서 평가. ASR-LLM cascade와 경쟁적 성능, 잡음 환경에서는 명확한 우위
- **우리 연구 관련도**: ★★☆ — 텍스트-음성 표현 간 cross-modal transfer 관점에서 representation alignment 연구와 관련 가능

## 3. Speech Foundation Model

### **[F3-Tokenizer: Taming Audio Autoencoder Latents for Understanding and Generation] (Dinghao Zhou et al. — Nanjing University, WeNet, 2026-06-04)** — arxiv preprint
- https://arxiv.org/abs/2606.06357
- **기존 문제**: 연속 오디오 오토인코더는 파형 복원은 잘하지만 latent의 구조가 이해(understanding) 태스크에 약함. 반면 self-supervised 오디오 인코더는 의미를 잘 포착하지만 직접 디코딩이 불가능. 이해와 생성을 모두 지원하는 단일 토크나이저 설계가 어려움
- **기존 방법**: 이해용(HuBERT, wav2vec 2.0 등 SSL 표현)과 생성용(neural codec, VQ-VAE 등) 토크나이저를 별도로 사용하거나, 두 가지를 결합하는 복잡한 파이프라인 구성
- **제안 방법**: (1) Noise-regularized autoencoder bottleneck — KL 기반 variational training 대신 channel normalization과 stochastic perturbation 사용하여 scale-controlled continuous latent 생성, (2) Representation encoder — frozen autoencoder latent 위에 RQ-MTP와 frozen-LLM supervision으로 학습하여 고차원 이해 표현 제공
- **핵심 차별점**: 단일 토크나이저에서 이해(고차원 표현)와 생성(정규화된 연속 latent)을 동시에 지원. Noise regularization이 KL 정규화보다 효과적으로 latent 구조를 제어
- **실험 결과**: 이해 태스크(음성 인식, 오디오 분류 등)와 생성 태스크(음성 합성, 오디오 생성) 모두에서 기존 개별 토크나이저 대비 경쟁적 또는 우수한 성능
- **우리 연구 관련도**: ★★★ — VQ 기반 representation, speech tokenizer, 이해·생성 통합 아키텍처는 우리의 VQ-based representation 연구와 직접적으로 관련. Noise regularization 접근법은 prediction-free SSL과 유사한 철학

### **[Do speech foundation models really learn words?] (Robin Huo, Ewan Dunbar, 2026-09-09)** — arxiv preprint
- https://arxiv.org/abs/2609.10434
- **기존 문제**: Speech foundation model(HuBERT, wav2vec 2.0 등)이 단어를 잘 구별한다는 연구는 있으나, 이것이 진정한 단어 표현(word representation) 학습인지, 아니면 단순히 음소(phoneme) 정보의 좋은 인코딩에 의한 것인지 불분명
- **기존 방법**: 기존 분석은 speech SSL 모델의 layer별 표현을 probing하여 단어 구별 능력을 측정했으나, 음소 정보와 단어 정체성(identity) 정보를 분리하지 않음
- **제안 방법**: Residualization 기법을 사용하여 음소 정보를 통계적으로 제거(partial out)한 후 잔여 표현에서 단어 정보가 남아있는지 분석. 이를 통해 음소 수준을 넘어서는 형태 독립적(form-independent) 단어 표현 존재 여부 검증
- **핵심 차별점**: 단어 구별 능력에서 음소 기여분을 체계적으로 제거하는 최초의 분석. 단순 probing을 넘어 인과적 분석에 가까운 접근
- **실험 결과**: Residualization 후에도 후반 layer에서 HuBERT와 wav2vec 2.0 모두 음소 내용과 독립적으로 단어를 합리적 정확도로 인코딩함을 확인. 이 분리 기법이 word discovery 태스크의 성능도 향상시킴
- **우리 연구 관련도**: ★★★ — Speech SSL 모델의 내부 표현 분석은 우리의 prediction-free speech SSL 연구에 직접적 시사점. 어떤 정보가 어떤 layer에서 인코딩되는지에 대한 이해가 representation learning 설계에 핵심

### **[Learning task-specific subspaces via interventional post-training of speech foundation models] (Jack Cox, Jon P Barker — University of Sheffield, 2026-06-24)** — arxiv preprint
- https://arxiv.org/abs/2606.17967
- **기존 문제**: Speech foundation model의 사전학습 표현은 범용적이나, 음성의 다양한 변수(화자, 내용, 감정 등)가 분산적(distributed)으로 얽혀 있어 특정 downstream 태스크에 불필요한 변수까지 포함. 이로 인해 task-specific 성능이 최적이 아님
- **기존 방법**: Layer 선택, fine-tuning, adapter 등으로 downstream 태스크에 적응. 그러나 표현 공간 자체를 구조적으로 분리하는 접근은 부족
- **제안 방법**: Interventional contrastive learning을 통한 post-training 정제. Interventional dataset과 multi-part contrastive loss를 사용하여 얽힌 표현 공간을 content 서브스페이스와 speaker 서브스페이스로 분리하는 변환 학습
- **핵심 차별점**: Contrastive learning 기반으로 사전학습 표현의 서브스페이스를 task-specific하게 구조적으로 분리. 기존 fine-tuning/adapter와 달리 표현 공간의 기하학적 구조를 직접 변환
- **실험 결과**: 학습된 표현으로 speaker verification과 keyword spotting 평가. Out-of-domain speaker verification에서 성능 향상, content와 speaker 정보가 서브스페이스 간에 분리됨을 확인
- **우리 연구 관련도**: ★★★ — Temporal contrastive learning 기반 표현 분리 접근은 우리 연구의 contrastive learning 방법론과 직접적으로 관련. Interventional dataset 구성과 multi-part loss 설계가 참고 가치 높음
