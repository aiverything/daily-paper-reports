## 1. ASR (End-to-End, Multilingual, Diarization)

### **Efficient Multilingual ASR Finetuning via LoRA Language Experts (Jiahong Li, Yiwen Shao, Jianheng Zhuo, Chenda Li, Liliang Tang, Dong Yu, Yanmin Qian, 2025-06)** — Interspeech 2025 accepted
- arxiv URL: https://arxiv.org/abs/2506.21555
- 기존 문제: 대규모 다국어 ASR 모델(Whisper 등)은 다언어 동시 학습 시 언어 간 간섭(curse of multilinguality)이 발생하여, 특정 목표 언어에 대한 인식 성능이 저하됨. 모델 용량을 여러 언어가 공유하면서 각 언어의 고유 특성을 효과적으로 모델링하기 어려움.
- 기존 방법: Whisper 전체 모델을 목표 언어로 직접 fine-tuning하는 방식이 주류. 이 경우 다른 언어 성능이 저하(catastrophic forgetting)되거나, 언어별 별도 모델을 유지해야 하여 배포 비용이 증가함.
- 제안 방법: Whisper 기반으로 언어별 LoRA expert를 사전 학습한 후, 목표 언어 조합에 맞게 LoRA expert fusion 또는 knowledge distillation을 통해 단일 모델로 통합. 언어 인식(language-aware)과 언어 비인식(language-agnostic) 두 시나리오 모두 지원.
- 핵심 차별점: 모델 전체 fine-tuning 없이 LoRA 수준의 경량 적응으로 다국어 성능 향상 달성. Expert fusion과 distillation이라는 두 가지 통합 전략을 체계적으로 비교하여 실용적 가이드라인 제시.
- 실험 결과: 언어 인식 시나리오에서 약 10%, 언어 비인식 시나리오에서 약 15%의 상대적 성능 개선 달성.
- 우리 연구 관련도: ★☆☆ (LoRA 기반 경량 적응 전략으로, speech SSL의 표현 학습과 직접 관련도는 낮으나, 다국어 음성 표현의 언어별 특성 분리 관점에서 간접 참고 가능)

### **ASR-Synchronized Speaker-Role Diarization (Arindam Ghosh, Mark Fuhs, Bongjun Kim, Anurag Chowdhury, Monika Woszczyna et al., 2025-07)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2507.17765
- 기존 문제: 화자 역할 다이어리제이션(Role Diarization, 예: 의사 vs. 환자)은 단순 화자 구분(speaker-1, speaker-2)보다 실용적으로 유용하나, 기존 end-to-end ASR+RD 접근법은 단일 transducer로 단어와 역할 예측을 직렬화하여 ASR 성능이 저하되는 문제가 있음.
- 기존 방법: 단일 transducer가 단어 토큰과 역할 태그를 직렬로 출력하는 serialized output training 방식. ASR과 역할 다이어리제이션이 동일 디코더를 공유하여 두 태스크 간 트레이드오프 발생.
- 제안 방법: ASR transducer를 동결(freeze)한 상태에서 보조 RD transducer를 병렬로 학습하여 각 ASR 예측 단어에 역할을 할당. 태스크별 전용 predictor network를 설계하고, ASR 인코더의 상위 레이어 특징을 RD 인코더 입력으로 활용하여 역할 판별 정보를 강화.
- 핵심 차별점: ASR 성능 저하 없이 역할 다이어리제이션을 수행. 기존 학습된 ASR 모델을 동결하고 RD 모듈만 추가 학습하므로 기존 ASR 시스템에 플러그인 방식으로 적용 가능.
- 실험 결과: 기존 직렬화 방식 대비 ASR 성능 유지하면서 역할 다이어리제이션 정확도 향상. RNN-T 기반 아키텍처에서 CTC 대비 우수한 성능 달성.
- 우리 연구 관련도: ★☆☆ (RNN-T 기반 다이어리제이션으로 speech SSL과 직접 관련도는 낮으나, 인코더 상위 레이어의 화자 역할 정보 활용 전략이 표현 학습의 계층별 정보 분석에 참고 가능)

### **All-in-One ASR: Unifying Encoder-Decoder Models of CTC, Attention, and Transducer in Dual-Mode ASR (Takafumi Moriya et al., 2025-12)** — ASRU 2025 accepted
- arxiv URL: https://arxiv.org/abs/2512.11543
- 기존 문제: CTC, Attention-based Encoder-Decoder(AED), Transducer 등 다양한 ASR 패러다임은 각각 오프라인/스트리밍 시나리오에서 장단점이 다름. 시나리오별로 개별 모델을 유지해야 하여 개발·배포 비용이 크게 증가.
- 기존 방법: Joint CTC-Attention 학습, 4D ASR(CTC+AED+RNN-T+Mask-Predict 공유 인코더) 등이 제안되었으나, 오프라인/스트리밍 모드의 통합은 충분히 다뤄지지 않음. 각 모드별 별도 모델이 필요한 상황.
- 제안 방법: Multi-mode joiner를 도입하여 CTC, AED, Transducer를 단일 모델 내에서 오프라인·스트리밍 모드 모두 지원. 하나의 공유 인코더와 다중 디코더 헤드를 통해 추론 시 원하는 ASR 모드를 선택적으로 활성화.
- 핵심 차별점: 단일 모델로 6가지 ASR 모드(3 패러다임 × 2 모드)를 지원하여 모델 풋프린트를 대폭 절감. Joint decoding을 통해 서로 다른 ASR 모드의 상보적 강점을 결합하여 추가 성능 개선 달성.
- 실험 결과: 개별 최적화된 ASR 모델과 동등하거나 상회하는 인식 성능을 유지하면서 총 모델 크기를 대폭 축소. Joint decoding 시 추가적 인식 정확도 향상 확인.
- 우리 연구 관련도: ★☆☆ (ASR 아키텍처 통합 연구로 speech SSL과 직접 관련도는 낮으나, 공유 인코더 기반 다중 태스크 학습의 표현 공유 전략이 범용 음성 표현 설계에 간접 참고 가능)

## 2. SpeechLLM (Speech-Language Model, Voice Agent, Spoken Dialogue)

### **The Speech-LLM Takes It All: A Truly Fully End-to-End Spoken Dialogue State Tracking Approach (Nizar El Ghazal, Antoine Caubrière, Valentin Vielzeuf, 2025-10)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2510.09424
- 기존 문제: 대화 상태 추적(Dialogue State Tracking, DST)은 대화 시스템의 핵심 구성 요소이나, 기존 음성 기반 DST는 ASR→텍스트 DST의 캐스케이드 파이프라인에 의존하여 오류 전파 및 음성 고유 정보(운율, 감정 등) 손실이 발생.
- 기존 방법: 텍스트 기록(history)과 현재 턴의 음성을 혼합하는 멀티모달 컨텍스트 방식이 주류. 전체 대화 히스토리를 음성으로 처리하는 방식은 컨텍스트 길이 제한으로 시도되지 않음.
- 제안 방법: Speech-LLM을 활용하여 전체 대화를 음성 입력으로 직접 처리하는 fully end-to-end 접근. 전통적 멀티모달 컨텍스트, 전체 음성 히스토리, attention-pooling 기반 압축 음성 히스토리의 세 가지 전략을 체계적으로 비교.
- 핵심 차별점: 전체 음성 대화를 입력으로 제공할 때 최고 성능을 달성함을 실증. Attention-pooling 기반 히스토리 압축이 정확도를 유지하면서 컨텍스트 크기를 줄이는 효과적 트레이드오프를 제공.
- 실험 결과: SpokenWOZ 코퍼스에서 전체 음성 히스토리 입력이 동일 크기 모델 중 최고 성능 달성. 기존 텍스트 히스토리 기반 방식을 유의미하게 상회.
- 우리 연구 관련도: ★★☆ (Speech-LLM이 음성의 의미 정보를 장기 컨텍스트에서 얼마나 보존하는지 실증. 음성 표현의 semantic content 보존 능력 평가 관점에서 speech SSL 연구에 참고 가능)

### **Can Speech LLMs Think while Listening? (Yi-Jen Shih, Desh Raj, Chunyang Wu, Wei Zhou, SK Bong, Yashesh Gaur, Jay Mahadeokar, Ozlem Kalinli, Mike Seltzer, 2025-10)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2510.07497
- 기존 문제: Speech LLM은 음성 입력 직접 처리로 캐스케이드 파이프라인을 대체하지만, 복잡한 추론(reasoning) 태스크에서 텍스트 LLM 대비 성능이 크게 저하됨. Chain-of-thought(CoT)가 텍스트 LLM에서 효과적이지만 speech LLM에서의 적용은 충분히 탐구되지 않음.
- 기존 방법: Speech LLM은 음성 입력을 받아 직접 답변을 생성하는 단순 구조. CoT를 적용하려면 음성 입력 완료 후 추론을 시작해야 하여 추가 지연(latency)이 발생.
- 제안 방법: Multi-stream speech LLM에서 CoT fine-tuning을 적용. "생각하면서 듣기(thinking while listening)" 전략으로 스트리밍 ASR 토큰과 추론 토큰을 인터리빙하여 음성 입력이 끝나기 전에 추론을 시작. 텍스트 채널에서 모드 전환용 특수 토큰을 도입.
- 핵심 차별점: 텍스트 공간에서의 추론이 음성 공간 추론보다 2배 토큰 효율적이면서 동등한 성능을 달성. 음성 입력 수신 중 동시 추론을 통해 CoT의 추가 지연을 상쇄하는 최초의 접근.
- 실험 결과: Spoken reasoning 태스크 모음에서 CoT fine-tuning이 평균 2.4배 정확도 향상 달성. 텍스트 기반 CoT가 음성 기반 CoT와 동등한 성능을 보이면서 2배 토큰 효율적.
- 우리 연구 관련도: ★★☆ (음성 표현에서 추론에 필요한 semantic 정보가 얼마나 보존되는지를 분석. Multi-stream 구조에서 음성/텍스트 표현의 상호 보완성 연구가 speech representation learning에 참고 가능)

### **SALM-Duplex: Efficient and Direct Duplex Modeling for Speech-to-Speech Language Model (Hae-Jun Huh et al., 2025-05)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2505.15670
- 기존 문제: 현재 speech language model은 턴 기반(turn-based) 교환에 제한되어 있어, 실시간 사용자 끼어들기(barge-in) 등 자연스러운 대화 상호작용을 지원하지 못함. 기존 duplex 모델은 대규모 음성 사전학습이 필요하여 학습 비용이 높음.
- 기존 방법: 기존 duplex speech-to-speech 모델은 사용자와 에이전트 스트림을 동일한 이산 코덱 토큰으로 모델링하고, 대규모 음성 데이터로 사전학습을 수행. 높은 비트레이트(~1.2 kbps)와 복잡한 학습 파이프라인이 필요.
- 제안 방법: 사전학습된 스트리밍 인코더로 사용자 입력을 처리하고, 코덱 출력으로 에이전트 응답을 생성하는 비대칭 아키텍처. 채널 퓨전(channel fusion)으로 사용자·에이전트 스트림을 직접 동시 모델링. 에이전트와 사용자 모델링을 분리하여 코덱 fine-tuning을 용이하게 함.
- 핵심 차별점: 음성 사전학습 없이 duplex S2S 모델을 구축한 최초의 접근. 비트레이트를 기존 대비 절반(0.6 kbps)으로 줄이면서 추론·턴테이킹·끼어들기 성능 모두 향상. 임의의 텍스트 LLM으로부터 duplex S2S 모델 구축 과정을 대폭 간소화.
- 실험 결과: 기존 duplex 모델 대비 추론, 턴테이킹, barge-in 능력에서 모두 우수한 성능 달성. 음성 데이터 요구량을 크게 감소시키면서도 경쟁력 있는 에이전트 음질 확보.
- 우리 연구 관련도: ★★☆ (연속 스트리밍 인코더 표현과 이산 코덱 토큰의 비대칭 활용이 speech representation의 연속 vs. 이산 논쟁에 실증적 근거 제공. VQ-based representation 연구에서 비트레이트-품질 트레이드오프 분석에 참고 가능)

## 3. Speech Foundation Model (Speech SSL, Tokenizer, Representation Learning)

### **Scaling Spoken Language Models with Syllabic Speech Tokenization (Nicholas Lee, Cheol Jun Cho, Alan W Black, Gopala K. Anumanchipalli, 2025-09)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2509.26634
- 기존 문제: 기존 Spoken Language Model(SLM)은 SSL 모델에서 추출한 고프레임률(high-frame-rate, ~50 Hz) 이산 토큰을 사용하여, Transformer의 self-attention이 시퀀스 길이에 대해 이차적으로 스케일링되어 학습·추론 비용이 매우 높음.
- 기존 방법: HuBERT/WavLM 등에서 추출한 프레임 단위(~20ms) 이산 토큰을 BPE 등으로 후처리하여 시퀀스 길이를 줄이는 방식. 그러나 BPE 토큰은 언어학적으로 해석 불가능하며 압축률에 한계가 있음.
- 제안 방법: 음절(syllable) 수준의 음향 토크나이제이션(4-5 Hz)을 SLM에 최초 체계적 적용. SSL 표현을 음절 단위로 분할·압축하여 시퀀스 길이를 10배 이상 단축하면서도 의미 정보를 보존. 학습 데이터 규모에 따른 성능 변화를 체계적으로 분석.
- 핵심 차별점: 음절 토큰이 기존 고프레임률 토큰과 동등하거나 상회하는 SLU 성능을 달성하면서 학습 시간 2배 이상 단축, FLOPs 5배 감소. 언어학적으로 해석 가능한 토큰 단위로 speech SSL 표현의 실용적 압축 달성.
- 실험 결과: SLU 벤치마크 모음에서 음절 토큰이 기존 고프레임률 토큰 대비 동등 이상의 성능. 학습 시간 2배 이상 단축, FLOPs 5배 감소 확인.
- 우리 연구 관련도: ★★★ (음절 단위 토크나이제이션은 prediction-free speech SSL에서의 temporal granularity 설계에 직접 관련. VQ-based representation의 시간 해상도 선택과 정보 보존 간 트레이드오프 분석에 핵심 참고 자료)

### **Continuous Audio Language Models (Simon Rouard, Manu Orsini, Axel Roebel, Neil Zeghidour, Alexandre Défossez, 2025-09)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2509.06926
- 기존 문제: 기존 Audio Language Model(ALM)은 오디오를 이산 토큰 시퀀스로 표현하여 생성하나, 오디오 토큰은 텍스트 토큰과 달리 손실(lossy) 코덱에서 추출되어 제한된 비트레이트를 가짐. 오디오 품질 향상을 위해 더 많은 토큰을 생성해야 하여 품질-계산 비용 간 트레이드오프가 존재.
- 기존 방법: 다중 코드북 RVQ(Residual Vector Quantization) 기반 이산 토큰을 auto-regressive 또는 multi-stream 방식으로 생성. 품질을 높이려면 코드북 수를 늘려야 하고, 이는 생성 비용을 급증시킴.
- 제안 방법: Continuous Audio Language Model(CALM)을 제안. 대형 Transformer 백본이 매 타임스텝마다 contextual embedding을 생성하고, MLP가 consistency modeling을 통해 audio VAE의 다음 연속 프레임을 직접 생성. 이산 양자화 없이 연속 공간에서 직접 오디오를 생성.
- 핵심 차별점: 손실 압축을 우회하여 이산 토큰 기반 ALM보다 낮은 계산 비용으로 더 높은 품질 달성. 연속 프레임 생성으로 코드북 수에 의존하지 않는 확장성 확보. 음성과 음악 모두에서 유효성 검증.
- 실험 결과: 음성 및 음악 실험에서 SOTA 이산 ALM 대비 더 높은 품질을 더 낮은 계산 비용으로 달성. 연속 표현이 이산 토큰의 정보 병목 문제를 효과적으로 해결함을 실증.
- 우리 연구 관련도: ★★★ (VQ-based 이산 표현의 정보 손실 한계를 연속 표현으로 극복하는 접근으로, prediction-free speech SSL에서 이산 vs. 연속 표현 선택의 핵심 참고 자료. Temporal contrastive learning에서도 연속 표현 공간의 설계에 영향)

### **Balancing Speech Understanding and Generation Using Continual Pre-training for Codec-based Speech LLM (Jiatong Shi, Chunlei Zhang, Jinchuan Tian, Junrui Ni, Hao Zhang, Shinji Watanabe, Dong Yu, 2025-02)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2502.16897
- 기존 문제: 텍스트 LLM에 음향적으로 풍부한 코덱 기반 음성 표현을 통합할 때, 모달리티 불일치(modality mismatch)로 인한 catastrophic forgetting이 발생하여 음성 이해와 생성 간 균형을 맞추기 어려움.
- 기존 방법: 텍스트 LLM을 음성 데이터로 fine-tuning하면 기존 언어적 추론 능력이 저하됨. 의미(semantic) 토큰과 음향(acoustic) 토큰을 별도로 모델링하는 이중 토큰 방식은 복잡한 파이프라인을 요구.
- 제안 방법: Continual Pre-training(CPT) 프레임워크를 통해 텍스트 LLM을 코덱 이산화된 음성에 적응. 음성 전용(speech-only) 데이터로 지속적 사전학습하여 모달리티 불일치를 완화하면서 언어적 추론 능력을 보존. 단일 모델로 이해(ASR, S2T-Trans)와 생성(TTS, S2S-Trans)을 동시 지원.
- 핵심 차별점: 신경 코덱 토큰만으로 end-to-end 단일 패스 S2S 번역을 수행하는 최초의 시스템. 중간 전사(transcription), 번역, 의미 토큰 없이 코덱 토큰만으로 음성-음성 번역 달성. CPT가 TTS 성능을 유의미하게 향상시킴을 실증.
- 실험 결과: ASR, TTS, S2T-Trans, S2S-Trans 전 태스크에서 강력한 성능 달성. CPT 적용 후 TTS 성능이 유의미하게 향상. 코덱 토큰만 사용한 최초의 end-to-end 단일 패스 S2S-Trans 시스템 구현.
- 우리 연구 관련도: ★★★ (코덱 기반 이산 토큰의 이해·생성 양면 활용을 실증하여, VQ-based representation의 범용성 평가에 직접 관련. Speech SSL 모델이 생성한 표현의 코덱 토큰 대비 장단점 비교 연구에 핵심 참고 자료)
