**[Qwen-Audio-3.0-ASR Technical Report] (Chuanmeng Bian, Daren Chen, Peixin Chen et al. — Qwen-Audio ASR Team, Alibaba, 2026.09)** — arxiv preprint

- https://arxiv.org/abs/2609.07549
- **기존 문제**: LLM 기반 ASR 시스템이 학술 벤치마크에서는 높은 성능을 보이나, 실제 프로덕션 환경에서 다양한 방언(dialect), 동적 엔티티(hotword), 장문 컨텍스트, 비유창 자발 발화 등을 안정적으로 처리하지 못하는 격차가 존재
- **기존 방법**: Whisper, Qwen3-ASR 등 단일 밀집(dense) LLM 기반 ASR 모델. 대규모 음성 데이터로 학습하나 방언 커버리지와 프로덕션 기능(핫워드 커스터마이제이션, 전사 후처리 등)이 제한적
- **제안 방법**: Qwen-Audio-3.0-ASR — Mixture-of-Experts(MoE) LLM 기반 ASR 시스템. Qwen 백본 위에 수천만 시간 규모의 음성 데이터로 학습. 통합 instruction-following 프레임워크로 30개 언어 + 16개 중국어 방언(8대 방언 권역)을 지원. 산업 도메인 엔티티 인식, 계층적 핫워드 커스터마이제이션, 네이티브 단일 패스 전사 교정(polishing), 장문 오디오 컨텍스트 모델링 기능 내장
- **핵심 차별점**: MoE 아키텍처를 ASR에 본격 적용하여 프로덕션급 다기능 통합. 방언 16종까지 커버하는 최대 규모의 다방언 중국어 ASR. 핫워드 커스터마이제이션과 전사 교정을 별도 후처리 없이 단일 모델에서 수행
- **실험 결과**: 중국어, 영어, 다국어, 실제 산업 테스트셋에서 state-of-the-art 또는 고도로 경쟁력 있는 인식 성능 달성. 45명 저자 규모의 대형 프로젝트
- **우리 연구 관련도**: ★☆☆ — 프로덕션 ASR 시스템 설계에 초점. speech SSL/representation 연구와 직접 관련은 낮으나, MoE 아키텍처의 음성 도메인 적용과 대규모 데이터 활용 전략은 참고 가치

**[Soft Posterior Speaker Injection for Multi-Talker Speech Recognition] (Jian Zhu, Cheng Luo, 2026.09)** — ICASSP 2027 제출

- https://arxiv.org/abs/2609.01287
- **기존 문제**: 다화자 중첩 음성(overlapping speech)에서의 자동 음성 인식(MT-ASR)이 여전히 어려운 과제. 기존 Serialized Output Training(SOT) 방식은 화자 정보를 명시적으로 활용하지 못하여 중첩 구간에서 성능 저하
- **기존 방법**: SOT 기반 다화자 ASR, 화자 보조 목적함수(speaker-auxiliary objectives), VAD 파이프라인 기반 분리 후 인식 접근법
- **제안 방법**: SPSI(Soft Posterior Speaker Injection) — 경량 헤드가 프레임 수준 화자 사후 확률(speaker posterior)을 예측하고, 이를 Whisper에 다층 Feature-wise Linear Modulation(FiLM)과 디코더 화자 메모리 프롬프트를 통해 주입. 화자 정보를 연성(soft) 확률 분포로 전달하여 이산 화자 레이블의 정보 손실을 방지
- **핵심 차별점**: 화자 사후 확률의 연성 주입이라는 새로운 패러다임 제시. FiLM 기반 다층 조건화로 Whisper 인코더의 화자 인식 능력 강화. 기존 SOT 대비 경량 추가 모듈만으로 성능 향상
- **실험 결과**: 2화자 LibriSpeech 중첩 데이터에서 cpWER을 50.7%(SOT)에서 49.6%로 감소. 고중첩 구간에서는 60.4%에서 58.8%로 더 큰 감소폭. 동일 백본의 화자 보조 목적함수 및 VAD 파이프라인은 SOT를 능가하지 못함
- **우리 연구 관련도**: ★★☆ — FiLM 기반 화자 조건화는 표현 학습에서의 조건부 변조(conditional modulation) 기법과 관련. 연성 화자 사후 확률을 통한 표현 공간 조건화 방식이 speech representation 연구에 참고 가능

**[Summary of the ChinaVoices Challenge 2026: Data, Tasks, Baseline, and Methods] (Yujie Liao, Bingshen Mu, Shuiyuan Wang, Liumeng Xue, Hexin Liu, Xian Shi, Jie Hu, Lei Xie, 2026.09)** — 챌린지 요약 논문

- https://arxiv.org/abs/2609.03471
- **기존 문제**: 중국어 방언 음성 처리에 대한 통일된 과제 정의와 평가 조건이 부재하여 다방언 식별(dialect identification) 및 ASR 연구의 비교 가능성이 제한됨. 방언 간 음향적 유사성과 데이터 불균형 문제
- **기존 방법**: 개별 방언별 ASR 모델 구축, 또는 Whisper/Qwen3-ASR 등 다국어 모델의 직접 적용. 통일된 벤치마크 부재로 방법론 간 공정 비교 곤란
- **제안 방법**: ChinaVoices Challenge 2026 — 16개 방언 범주에 대해 약 320시간의 음성 데이터(Reference Set 3시간/방언, Open Eval 7시간/방언, Hidden Eval 10시간/방언)를 구성. 화자 분리된(speaker-disjoint) 세 세트로 구성. 두 과제 정의: (1) 다방언 식별(macro-averaged ACC), (2) 다방언 ASR(macro-averaged CER). Qwen3-ASR-1.7B 베이스라인 제공
- **핵심 차별점**: 중국어 방언 16종을 통합한 최대 규모의 공개 방언 음성 벤치마크. 수동 전사 품질 검수된 데이터. 28개 팀 참가, 17개 시스템 리포트, 15개 팀 분석 포함
- **실험 결과**: 28개 팀 참가 결과 분석. 제한 데이터 트랙과 개방 데이터 트랙에서의 성능 비교. 상위 시스템들의 전략 분석 포함
- **우리 연구 관련도**: ★☆☆ — 방언 ASR 벤치마크 논문으로 speech SSL 연구와 직접 관련은 낮으나, 다방언 음성 표현의 평가 프레임워크로서 참고 가치

**[TurnFSM for Full-Duplex Dialogue System: Internalizing State-Machine Logic for Streaming Semantic Voice Activity Detection and Utterance-Level Rejection] (Zhiwei Lin, Tianjiao Du, Qiaochu Huang, Zihan Zhang, Naijun Zheng, Longshuai Xiao, Yunfei Lu, Jun Chen, Zhiyong Wu, 2026.08)** — Interspeech 2026 accepted

- https://arxiv.org/abs/2609.04240
- **기존 문제**: 전이중(full-duplex) 음성 어시스턴트가 발화하면서 동시에 청취해야 하는 상황에서, 사용자 인터럽션을 저지연·제한된 자원 조건의 스트리밍 환경에서 처리하는 것이 어려움. 기존 end-to-end 전이중 모델은 음성 도메인 적응 후 추론 관련 능력이 저하되며, 캐스케이드 파이프라인은 추론 오버헤드와 수작업 제어 로직을 초래
- **기존 방법**: End-to-end 전이중 모델(speech domain adaptation 후 추론 능력 저하), 캐스케이드 파이프라인(ASR + NLU + 제어 로직), Phoenix-VAD 등 스트리밍 시맨틱 VAD
- **제안 방법**: TurnFSM — LLM 기반 상태 예측 프레임워크. 턴 제어(turn control)를 명시적 유한 상태 전이(finite-state transition)로 내재화하여 스트리밍 시맨틱 VAD와 발화 수준 거부(utterance-level rejection)를 통합. 제출(submission)과 거부(rejection)를 직렬 결정 과정으로 분해하여 다중 과제 간섭을 감소시키면서 단일 과제 모델에 필적하는 성능 유지
- **핵심 차별점**: 턴 제어를 FSM 상태 전이로 명시적 모델링한 최초 시도. 스트리밍 시맨틱 VAD와 발화 거부를 단일 프레임워크에서 통합. LLM의 추론 능력을 보존하면서 전이중 턴 제어 수행
- **실험 결과**: 단일 과제 모델에 필적하는 성능을 유지하면서 다중 과제 간섭 감소 달성. Interspeech 2026 리뷰어 피드백 반영 개정판
- **우리 연구 관련도**: ★☆☆ — 전이중 대화 시스템의 턴 제어에 초점으로, speech SSL 연구와 직접 관련은 낮음. 다만 LLM의 상태 기반 제어와 음성 스트리밍의 통합은 음성 에이전트 설계 관점에서 참고 가능

**[Decoupling Turn-Taking from Semantics: A Decoupled Data Approach for Finite-State-Machine-Based Full-Duplex Dialogue] (Yihang Li, Chenhui Chu, 2026.09)** — EMNLP 2026 Main Conference 제출

- https://arxiv.org/abs/2609.03321
- **기존 문제**: Neural Finite State Machine(NFSM) 프레임워크가 합성 텍스트 데이터에 의존하여 전이중 대화의 턴 전환 자연스러움이 제한됨. LLM이 실제 인간 대화의 미세한 음향 시간 역학을 충실히 시뮬레이션할 수 없기 때문
- **기존 방법**: NFSM 프레임워크 — 턴 제어와 응답 생성을 단일 인과적 테이프에 직렬화하여 표준 next-token prediction 목적함수로 학습. 그러나 합성 텍스트 데이터로 턴 전환 패턴을 학습하므로 자연스러움 부족
- **제안 방법**: 분리 데이터 접근법(Decoupled Data Approach) — 턴 전환 학습은 실제 인간-인간(HH) 음성 대화에서, 의미적 응답 행동은 구성 가능한 인간-에이전트(HA) 텍스트 대화에서 분리하여 학습. 규칙 기반 이벤트 유도 데이터 변환 방법(rule-based event-guided data transformation)을 도입하여, HH 음성 대화를 턴 전환 이벤트 분류와 결정론적 매핑 규칙으로 FSM 테이프에 직렬화. LLM 생성 데이터 없이 확장 가능한 감독 실현
- **핵심 차별점**: 턴 전환(turn-taking)과 의미 생성(semantics)을 데이터 수준에서 분리하는 최초의 체계적 접근. 실제 HH 대화에서 턴 전환의 시간적 역학을 직접 학습. LLM 합성 데이터 의존성 제거
- **실험 결과**: 합성 데이터 기반 NFSM 대비 턴 전환 자연스러움 향상. 의미적 응답 품질을 유지하면서 턴 제어 성능 개선
- **우리 연구 관련도**: ★☆☆ — 전이중 대화 모델의 학습 데이터 전략에 초점. speech representation 연구와 직접 관련은 낮으나, 음성 대화의 시간적 역학 모델링은 temporal contrastive learning 설계에 간접 참고 가능

**[Motion-Omni: End-to-End Joint Speech and Full-Body Motion for Spoken Dialogue] (Chengqian Ma, Wei Tao, Haoyu Zhang, Yiwen Guo, 2026.08)** — arxiv preprint

- https://arxiv.org/abs/2609.04250
- **기존 문제**: 대화형 아바타가 발화 내용과 동작을 동시에 결정해야 하나, 음성 생성과 모션 생성이 별도 모델 계열에 존재. 표준 캐스케이드 방식은 먼저 음성 응답을 생성한 후 완성된 오디오 위에 모션 모델을 실행하므로, 두 번째 추론 패스가 필요하고 두 모달리티 간 공동 최적화가 불가능
- **기존 방법**: 캐스케이드 파이프라인 — 음성 대화 모델(SpeechLLM) → 음성 완성 → 모션 생성 모델(gesture/motion generator). 순차 처리로 지연 시간 증가, 음성-모션 간 일관성 부족
- **제안 방법**: Motion-Omni — spoken dialogue model이 음성을 생성하는 은닉 상태(hidden states)로부터 직접 표정(facial expression), 손, 상체, 하체 동작을 네이티브로 출력하는 end-to-end 프레임워크. 음성과 모션이 동일한 추론 패스에서 공동 생성되어 공동 최적화 가능
- **핵심 차별점**: 음성 생성과 전신 모션 생성을 단일 모델에서 end-to-end로 통합한 최초 시도. 음성 생성의 은닉 상태를 모션 생성에 직접 활용하여 모달리티 간 일관성 확보. 캐스케이드 대비 5배 이상 빠른 추론
- **실험 결과**: Motion-Omni-Q7 모델로 평가. VoiceBench에서 다른 omni-modal LLM 대비 음성 대화 품질 우수. SwDA-500에서 speech-to-motion 평가 대부분 지표 1-2위. 전체 응답 4.32초(RTF 0.78)로, 대응하는 LOM 캐스케이드 대비 5배 이상 빠른 속도
- **우리 연구 관련도**: ★★☆ — 음성 은닉 상태에서 모션을 생성하는 접근은 speech representation이 다양한 다운스트림 모달리티로 전이될 수 있음을 시사. 멀티모달 표현 학습 및 공동 생성 관점에서 참고 가치

**[BiMTokenizer: Preserving Semantic-Acoustic Balance in Low-Bitrate Speech Tokenization via Bidirectional State-Space Modeling] (Xin Zhang, Lin Li, Chuanbo Liu, Jianquan Liu, Kong Aik Lee, 2026.09)** — EMNLP 2026 Main Conference accepted

- https://arxiv.org/abs/2609.00562
- **기존 문제**: 음성 코덱이 연속 음성 신호와 LLM 사이의 브릿지 역할을 하나, 음향 충실도(acoustic fidelity)와 의미 보존(semantic preservation) 간 본질적 충돌 존재. 최근 이중 타워(dual-tower) 아키텍처가 의미와 음향 모델링을 분리하려 하나, 상당한 아키텍처 오버헤드 발생
- **기존 방법**: 단일 타워 코덱(EnCodec, DAC 등)은 의미-음향 균형 어려움. 이중 타워 코덱(SwitchCodec 등)은 별도 인코더로 분리하나 파라미터 수 2배 이상 증가
- **제안 방법**: BiMTokenizer — 양방향 상태 공간 모델(Bidirectional State-Space Model) 백본과 Residual Spherical Leech Quantization(RSLQ)을 결합한 저비트레이트(~1.1 kbps) 음성 코덱. 양방향 백본으로 시간적 모델링 강화. RSLQ는 고정된 잘 분리된 격자(lattice) 병목을 제공하여 학습된 코드북 붕괴(learned-codebook collapse) 없이 안정적 의미-음향 토큰화 실현
- **핵심 차별점**: 단일 타워 아키텍처로 이중 타워 베이스라인의 절반 이하 파라미터로 우수 성능. 학습된 코드북 대신 수학적으로 보장된 격자 양자화(RSLQ) 사용으로 코드북 붕괴 문제 근본적 해결. Mamba 기반 양방향 SSM의 음성 코덱 적용
- **실험 결과**: 클린/노이지 환경 모두에서 저비트레이트 코덱 베이스라인 중 최우수 음향 재구성 성능과 최저 WER 달성. 최근 이중 타워 베이스라인 대비 절반 이하 파라미터 사용
- **우리 연구 관련도**: ★★★ — VQ-based representation 연구와 직접 관련. Residual Spherical Leech Quantization은 기존 RVQ/FSQ의 대안으로서 speech tokenizer 설계에 중요한 참고. 양방향 SSM 기반 음성 표현 학습 아키텍처도 prediction-free SSL 설계에 시사점 제공

**[Semantic Refinement of Universal Audio Representations through Audio-Description Alignment] (Lejun Min, Junyu Dai, Ruichen Zheng, Xinyue Fan, Yang Xiang, Huaichen Zhang, Xingchen Song, Yufei Shi, Han Zhao, Xiangang Li, 2026.09)** — arxiv preprint

- https://arxiv.org/abs/2609.08429
- **기존 문제**: 범용 오디오 표현(universal audio representations)은 음향적 세부 정보를 보존하면서 동시에 고수준 의미 개념을 음성·음악·환경음 등 다양한 도메인과 다양한 용량의 다운스트림 모델에 접근 가능하게 만들어야 함. 기존 음향 사전학습 인코더는 의미 수준 이해가 부족
- **기존 방법**: BEST-RQ 기반 마스크 예측 사전학습, 재구성(reconstruction) 손실, CTC 목적함수 등을 결합한 음향 사전학습. 의미 정보는 별도 텍스트 인코더나 추가 학습 단계에서 주입
- **제안 방법**: 음향 사전학습된 인코더에 오디오-설명 정렬(audio-description alignment)을 추가하여 의미적 정제(semantic refinement) 수행. BEST-RQ + 재구성 + CTC 기반 위에 오디오와 텍스트 설명 간 대조적 정렬(contrastive alignment)을 적용. 매칭 제어(matched control), 셔플된 설명(shuffled-description), 올바른 쌍(correctly paired) 궤적을 비교하여 올바른 대응(correspondence)의 효과를 추가 대조 목적함수의 효과와 구분
- **핵심 차별점**: 대조적 오디오-설명 정렬이 단순히 추가 대조 목적함수를 더하는 것이 아니라, 올바른 의미적 대응에서 비롯되는 효과임을 실험적으로 입증. 음향 사전학습 위에 의미 정제를 순차적으로 적용하는 2단계 전략
- **실험 결과**: 3개 paired seed에서 올바른 정렬이 도메인 균형 분류를 선형 프로브에서 4.66점, 시퀀스 인식 LLM에서 2.59점 향상. 모든 도메인에서 양의 변화. 셔플 제어 대비 올바른 쌍의 일관된 우위 확인
- **우리 연구 관련도**: ★★★ — speech representation learning 연구와 직접 관련. 음향 SSL 사전학습 위에 의미적 정제를 추가하는 2단계 전략은 prediction-free SSL의 표현 품질 향상에 직접 적용 가능. 대조적 정렬의 효과를 통제 실험으로 분리한 방법론이 temporal contrastive learning 연구에 참고 가치

**[AuK Technical Report: An Open-Source Foundational Model for Speech Generation and Editing] (Ziyang Ma, Zhikang Niu, Wenming Tu et al. — Tencent Hunyuan, 2026.09)** — arxiv preprint (Tencent)

- https://arxiv.org/abs/2609.08936
- **기존 문제**: 음성 생성과 편집 과제들이 개별 모델로 처리되어, 통합된 음성 기반 모델(foundation model)이 부재. TTS, 음성 편집, 음질 향상, 분리 등을 하나의 시스템에서 처리하기 어려움
- **기존 방법**: 개별 과제별 전용 모델(TTS 전용, 음성 향상 전용, 분리 전용 등). 일부 통합 시도(AudioLM, SpeechX 등)가 있으나 과제 범위가 제한적이거나 오픈소스 미공개
- **제안 방법**: AuK — 자연어 지시(natural-language instructions)와 오디오 컨텍스트의 공통 인터페이스로 음성 생성 및 편집을 통합하는 오픈소스 기반 모델. 약 30.3억 instruction-audio 인스턴스와 195만 시간의 유효 감독으로 5개 과제 계열(음성 생성, 내용 편집, 향상 및 분리, 준언어적 편집, 음향 편집) 학습. 아키텍처: 멀티모달 LLM(의미 조건화) + VAE(음성·일반 오디오·음악 공동 학습, 음향 조건화) + 하이브리드 rectified-flow Transformer(이중 스트림 MMDiT → 단일 스트림 DiT)
- **핵심 차별점**: 5개 과제 계열을 하나의 기반 모델에서 통합한 최대 규모 오픈소스 음성 기반 모델. 30.3억 instruction-audio 쌍 규모의 데이터셋. MMDiT + DiT 하이브리드 아키텍처로 의미-음향 조건의 이중 스트림 처리 후 통합 생성. MIT 라이선스로 완전 오픈소스
- **실험 결과**: 33명 저자 규모의 대형 프로젝트. 5개 과제 계열에 걸친 종합 평가 수행. 코드, 모델, 데이터 오픈소스 공개
- **우리 연구 관련도**: ★★☆ — VAE 기반 음성·오디오·음악 공동 학습은 범용 오디오 표현 학습과 관련. MMDiT 기반 의미-음향 이중 조건화 구조가 speech representation의 디코딩 및 활용 방법론으로 참고 가치. 다만 생성 중심 모델로 SSL/표현 학습 자체와는 방향성 차이
