## 1. ASR (End-to-End, Whisper, Multilingual, Diarization)

### **SE-DiCoW: Self-Enrolled Diarization-Conditioned Whisper (Alexander Polok, Dominik Klement, Samuele Cornell, Matthew Wiesner, Jan Černocký, Sanjeev Khudanpur, Lukáš Burget, 2026-01)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2601.19194
- 기존 문제: Whisper 기반 타겟 화자 ASR 모델인 DiCoW는 Silence-Target-Non-target-Overlap(STNO) 마스크에 모호성이 존재하여, 완전히 겹치는 두 화자가 거의 동일한 조건부 입력을 갖게 되어 전사 구분이 어려움.
- 기존 방법: DiCoW는 다이어리제이션 결과를 STNO 마스크로 변환하여 인코더에 조건부 입력으로 제공하고 화자별로 개별 디코딩을 수행. 그러나 마스크 모호성으로 인해 겹침 구간에서 성능이 저하됨.
- 제안 방법: 다이어리제이션 출력에서 타겟 화자가 가장 활발한 구간을 자동으로 찾아 등록(enrollment) 세그먼트로 사용. 이 등록 세그먼트를 각 인코더 레이어에서 cross-attention을 통한 고정 조건부 입력으로 활용. 개선된 데이터 세그멘테이션, 모델 초기화, 증강 전략을 함께 적용.
- 핵심 차별점: STNO 마스크 대신 self-enrollment 기반 cross-attention 조건부 입력을 사용하여 마스크 모호성 문제를 근본적으로 해결. 외부 화자 등록 데이터 없이 대화 자체에서 등록 세그먼트를 자동 추출.
- 실험 결과: EMMA MT-ASR 벤치마크에서 기존 DiCoW 대비 macro-averaged tcpWER을 52.4% 상대적으로 감소. 다국어·다도메인 환경에서 강건한 성능 입증.
- 우리 연구 관련도: ★★☆ (타겟 화자 추출을 위한 cross-attention 기반 조건부 표현 학습은 disentangled speech representation 연구와 관련. 화자 정보 분리 메커니즘 참고 가능)

### **Frontend Token Enhancement for Token-Based Speech Recognition (Takanori Ashihara, Shota Horiguchi, Kohei Matsuura, Tsubasa Ochiai, Marc Delcroix, 2026-02)** — ICASSP 2026 accepted
- arxiv URL: https://arxiv.org/abs/2602.04217
- 기존 문제: SSL 모델(HuBERT 등)에서 추출한 이산 음성 토큰을 입력으로 사용하는 토큰 기반 ASR에서, 잡음 환경 시 토큰 추출 단계에서 오류가 발생하면 후단 ASR 성능이 크게 저하됨.
- 기존 방법: 파형 수준의 음성 향상(wave-to-wave enhancement)을 프론트엔드로 적용하거나, 연속 SSL 특징을 직접 ASR 백엔드에 입력하는 방식. 토큰 도메인에서의 향상은 체계적으로 탐구되지 않음.
- 제안 방법: 4가지 입출력 도메인 조합의 향상 모델을 체계적으로 비교: (1) wave-to-wave, (2) token-to-token, (3) 연속 SSL features-to-token, (4) wave-to-token. ASR 백엔드와 독립적으로 향상 모델을 학습.
- 핵심 차별점: 음성 토큰 도메인에서의 향상을 최초로 체계적으로 연구. ASR 백엔드와 독립적 학습이 가능하여 모듈화된 시스템 설계 지원. 이산 토큰 표현의 잡음 강건성 문제를 직접 다룸.
- 실험 결과: CHiME-4 데이터셋에서 wave-to-token 향상이 모든 프론트엔드 중 최고 성능 달성. 기존 연속 SSL 특징 기반 ASR 시스템보다 높은 인식 정확도 기록. NTT의 ICASSP 2026 발표 21편 중 하나.
- 우리 연구 관련도: ★★★ (이산 음성 토큰의 잡음 강건성 연구로, VQ-based representation의 한계와 개선 방향을 직접적으로 다룸. 토큰 도메인 향상은 speech tokenizer 설계에 핵심 참고)

### **Do LLM Decoders Listen Fairly? Benchmarking How Language Model Priors Shape Bias in Speech Recognition (Srishti Ginjala, Eric Fosler-Lussier, Christopher W. Myers, Srinivasan Parthasarathy, 2026-04)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2604.21276
- 기존 문제: 사전 학습된 LLM이 ASR 디코더로 사용되면서, 텍스트 사전 지식(prior)이 인종·억양·성별·연령·모국어 등 인구통계 그룹 간 인식 공정성에 미치는 영향이 체계적으로 평가되지 않음.
- 기존 방법: ASR 공정성 연구는 개별 모델이나 소수 축(주로 인종·성별)에 집중. CTC, 인코더-디코더, LLM 기반 등 세대별 아키텍처를 동일 조건에서 비교한 연구가 부재.
- 제안 방법: 3세대 아키텍처(CTC/내재적 LM 인코더-디코더/명시적 LLM 디코더) 9개 모델을 약 43,000 발화에 대해 5개 인구통계 축으로 평가. Common Voice 24와 Meta Fair-Speech 데이터셋 사용. 깨끗한 오디오·열화 오디오·마스킹 조건 비교.
- 핵심 차별점: LLM 디코더가 인종 편향을 증폭하지 않는다는 발견(Granite-8B max/min WER 비율 2.28). 마스킹 시 Whisper가 인구통계 선택적 환각(86% 반복 삽입)에 빠지는 반면, 명시적 LLM 디코더는 38배 적은 삽입 오류 생성.
- 실험 결과: 심한 열화는 역설적으로 공정성 격차를 줄임(모든 그룹이 높은 WER로 수렴). 침묵 삽입은 Whisper의 억양 편향을 최대 4.64배 증폭. 결론: 오디오 인코더 설계가 LLM 스케일링보다 공정하고 강건한 ASR의 핵심 레버.
- 우리 연구 관련도: ★★☆ (SSL 기반 오디오 인코더의 표현 강건성이 공정성에 직결됨을 입증. speech SSL 표현의 인구통계 불변성·강건성 연구에 참고)

## 2. SpeechLLM (Speech-Language Model, Spoken Dialogue, Voice Agent)

### **DualSpeechLM: Towards Unified Speech Understanding and Generation via Dual Speech Token Modeling with Large Language Models (Yuanyuan Wang, Dongchao Yang, Yiwen Shao, Hangting Chen, Jiankun Zhao, Zhiyong Wu, Helen Meng, Xixin Wu, 2025-08)** — AAAI 2026 accepted
- arxiv URL: https://arxiv.org/abs/2508.08961
- 기존 문제: 음성 이해(ASR, 번역 등)와 음성 생성(TTS, 음성 변환 등)은 서로 다른 수준의 정보를 필요로 하여, 하나의 통합 아키텍처에서 두 태스크를 동시에 잘 수행하기 어려움. 생성에는 세밀한 음향 특징이, 이해에는 고수준 의미 정보가 각각 유리.
- 기존 방법: 기존 Speech LLM은 단일 유형의 음성 토큰(음향 토큰 또는 의미 토큰)을 사용하여 이해와 생성 중 한쪽에 치우치거나, 별도의 모델을 사용.
- 제안 방법: Understanding-driven Speech Tokenizer(USTokenizer)로 고수준 의미 정보를 추출하는 새로운 토크나이저 설계. DualSpeechLM 프레임워크에서 USToken을 입력(이해)으로, 음향 토큰을 출력(생성)으로 동시에 모델링하는 이중 토큰 아키텍처 구성.
- 핵심 차별점: 이해용·생성용 토큰을 분리하되 하나의 end-to-end 아키텍처에서 통합. USToken은 텍스트 모달리티와의 정렬이 우수하여 LLM의 텍스트 능력을 학습 중 유지. 소규모 데이터(약 4,500시간)로도 빠른 수렴과 우수한 성능 달성.
- 실험 결과: 이해와 생성 태스크 간 상호 향상 효과 입증. ASR(WER), 번역(BLEU-4), TTS/VC(DNSMOS) 등 다양한 메트릭에서 경쟁적 성능. USToken의 텍스트 정렬이 음향 토큰 대비 우수한 이해 성능을 제공.
- 우리 연구 관련도: ★★★ (이해용과 생성용 음성 토큰의 분리 설계는 VQ-based representation의 의미-음향 분리 연구와 직접 관련. USTokenizer의 설계 원리는 speech SSL 토크나이저 연구에 핵심 참고)

### **Adapting Text LLMs to Speech via Multimodal Depth Up-Scaling (Kazuki Yano, Shinji Watanabe, Jun Suzuki, 2026-04)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2604.00489
- 기존 문제: 텍스트 LLM을 음성 데이터로 continual pretraining하여 Speech LM으로 변환할 때, 원래의 텍스트 이해·추론 능력이 심하게 저하되는 catastrophic forgetting 문제 발생.
- 기존 방법: Full fine-tuning은 텍스트 능력을 크게 훼손. LoRA(Low-Rank Adaptation)는 텍스트 저하를 줄이지만 ASR 성능도 함께 제한. 두 목표(ASR 성능 + 텍스트 유지)의 트레이드오프가 불가피.
- 제안 방법: Multimodal Depth Up-Scaling — 동결된 텍스트 LLM에 새 Transformer 레이어를 삽입하고, 추가된 레이어만 음성 데이터로 학습. 추론 시 추가 레이어를 제거하면 텍스트 태스크에서 제로 열화 보장. E-Branchformer(음성 인식 특화 아키텍처)를 삽입 레이어로 활용.
- 핵심 차별점: 추가 레이어 제거 시 원래 텍스트 LLM을 완벽히 복원 가능한 구조적 보장. E-Branchformer 삽입으로 음성 특화 모듈의 효율적 통합. Full fine-tuning 대비 학습 파라미터 60% 감소, 텍스트 열화 75% 이상 감소.
- 실험 결과: SmolLM2-360M 및 1.7B 모델에 48,000시간 영어 ASR 데이터 적용. Depth up-scaling이 full fine-tuning과 동등한 ASR 성능 달성. E-Branchformer 삽입 시 대형 모델에서 full fine-tuning을 상회하는 ASR 성능. 텍스트 지시 추종(번역·요약 등) 능력 유지(full fine-tuning은 완전 상실).
- 우리 연구 관련도: ★★☆ (speech representation을 LLM에 통합하는 효율적 아키텍처 설계. E-Branchformer의 음성 인코더로서의 활용은 speech SSL 인코더의 LLM 연계 방식에 참고 가치)

### **UniAudio 2.0: A Unified Audio Language Model with Text-Aligned Factorized Audio Tokenization (Dongchao Yang, Yuanyuan Wang, Dading Chong, Songxiang Liu, Xixin Wu, Helen Meng, 2026-02)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2602.04683
- 기존 문제: 기존 오디오 언어 모델은 이해와 생성을 동시에 지원하는 중간 표현(토크나이저) 설계가 부재. 의미 토큰은 이해에 유리하나 생성 품질이 낮고, 음향 토큰은 반대.
- 기존 방법: 단일 유형의 오디오 토큰(의미 또는 음향)을 사용하거나, 별도의 모델로 이해·생성을 분리 처리. 텍스트와의 의미적 정렬이 약한 토큰 설계로 인해 교차 모달 일반화가 제한적.
- 제안 방법: ReasoningCodec — 오디오를 (1) 텍스트 정렬 고수준 분석·계획 표현인 reasoning tokens과 (2) 의미 풍부한 음향 단서인 reconstruction tokens으로 분해하는 이산 코덱. 텍스트·reasoning·reconstruction 토큰에 대한 통합 autoregressive 아키텍처. 오디오 이해·교차 모달·생성 전문가 통합.
- 핵심 차별점: Reasoning tokens이 텍스트 기반 의미론을 포착하고, reconstruction tokens이 세밀한 음향 디테일을 보존하는 계층적 분해. 100B 텍스트 + 60B 오디오 토큰 규모의 학습으로 강건한 일반화.
- 실험 결과: 음성·사운드·음악 태스크에서 in-domain 경쟁적 성능. 미지의 태스크에 대한 강건한 few-shot 및 zero-shot 일반화 입증.
- 우리 연구 관련도: ★★★ (ReasoningCodec의 의미-음향 토큰 분해는 VQ-based representation의 계층적 설계와 직접 관련. 텍스트 정렬 토큰 설계는 speech tokenizer 연구의 핵심 방향)

## 3. Speech Foundation Model (Speech SSL, Speech Tokenizer, Representation Learning)

### **AudioMosaic: Contrastive Masked Audio Representation Learning (Hanxun Huang, Qizhou Wang, Xingjun Ma, Cihang Xie, Christopher Leckie, Sarah Erfani, 2026-05)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2605.14231
- 기존 문제: 오디오 SSL에서 생성적 접근법(masked autoencoder 등)은 세밀한 복원에 치중하여 발화 수준의 판별적(discriminative) 표현 학습이 부족. 대조 학습은 효과적이나 대규모 배치가 필요하여 메모리 사용량이 높음.
- 기존 방법: BEATs, Audio-MAE 등 생성적 마스크 모델이 주류. 기존 대조 학습 기반 접근은 두 개의 전체 뷰(augmented view)를 필요로 하여 메모리 비효율적.
- 제안 방법: 스펙트로그램 패치에 구조화된 시간-주파수 마스킹을 적용하여 양성 쌍(positive pair)을 구성. 마스킹된 뷰만 인코더에 입력하여 메모리 사용량 감소 및 대규모 배치 학습 가능. 대조 학습 목표로 전역적·판별적 발화 수준 표현 학습.
- 핵심 차별점: 마스킹을 데이터 증강이 아닌 대조 학습의 양성 쌍 구성 전략으로 활용. 생성적 접근 대비 더 판별적인 발화 수준 표현 학습. 데이터셋·도메인·음향 조건 간 강건한 전이 가능성.
- 실험 결과: 선형 프로빙과 파인튜닝 모두에서 여러 표준 오디오 벤치마크에서 SOTA 달성. 사전 학습된 AudioMosaic 인코더를 오디오-언어 모델에 통합 시 성능 향상 확인.
- 우리 연구 관련도: ★★★ (마스크 기반 대조 학습은 prediction-free speech SSL 및 temporal contrastive learning 연구와 직접적으로 관련. 시간-주파수 마스킹 전략은 음성 표현 학습의 새로운 방향 제시)

### **Scaling Open Discrete Audio Foundation Models with Interleaved Semantic, Acoustic, and Text Tokens (Potsawee Manakul, Woody Haosheng Gan, Martijn Bartelds, Guangzhi Sun, William Held, Diyi Yang, 2026-02)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2602.16687
- 기존 문제: 현재 오디오 언어 모델은 대부분 텍스트 우선(text-first) 설계로, 사전 학습된 텍스트 LLM을 확장하거나 의미 전용(semantic-only) 오디오 토큰에 의존하여 범용 오디오 모델링이 제한적.
- 기존 방법: 텍스트 LLM 백본에 오디오 어댑터를 추가하거나, 단일 유형의 오디오 토큰(의미 또는 음향)만 사용. 이산 오디오 모델의 스케일링 법칙이 연구되지 않음.
- 제안 방법: 의미(semantic)·음향(acoustic)·텍스트 토큰을 인터리빙하여 next-token prediction으로 대규모 학습하는 네이티브 오디오 파운데이션 모델. 데이터 소스·텍스트 혼합 비율·토큰 구성 등 설계 선택을 체계적으로 탐구. 64개 모델에 대한 IsoFLOP 분석(3×10^18 ~ 3×10^20 FLOPs).
- 핵심 차별점: 이산 오디오 모델에 대한 최초의 스케일링 법칙 연구. 최적 데이터 크기가 최적 모델 크기보다 1.6배 빠르게 성장함을 발견. 텍스트 우선이 아닌 네이티브 오디오 모델링으로 오디오 생성과 교차 모달 능력 동시 지원.
- 실험 결과: IsoFLOP 분석을 통해 검증된 학습 레시피 확립. 의미·음향·텍스트의 3중 토큰 인터리빙이 단일·이중 조합 대비 우수. 범용 오디오 생성과 교차 모달 태스크에서 경쟁적 성능.
- 우리 연구 관련도: ★★★ (이산 오디오 토큰의 스케일링 법칙과 의미-음향 인터리빙 전략은 VQ-based representation 설계의 핵심 참고. speech tokenizer 연구의 스케일링 방향 제시)

### **UniAudio 2.0** 논문은 SpeechLLM 섹션에 포함되어 있습니다. Foundation Model 관점에서의 추가 논문으로 **DualSpeechLM**의 USTokenizer와 **UniAudio 2.0**의 ReasoningCodec이 모두 speech tokenizer / representation learning에 직접 기여하는 연구입니다.
