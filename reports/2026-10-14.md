## 1. ASR (Automatic Speech Recognition)

### **[Towards Privacy-Preserving ASR: Speaker-Level Machine Unlearning] (Seaone Ok, Seungu Han, Eungbeom Kim, Kyogu Lee, 2026-10-12)** — Interspeech 2026 accepted
- https://arxiv.org/abs/2610.16196
- **기존 문제**: ASR 모델이 학습 데이터에 포함된 특정 화자의 음성 정보를 내재화하여, 프라이버시 관련 '잊혀질 권리(right to be forgotten)' 요청에 대응하기 어려운 문제가 있었음
- **기존 방법**: 기존 machine unlearning 연구는 주로 이미지/텍스트 도메인에 집중되었으며, ASR에서 화자 수준의 unlearning을 전사 성능 유지와 함께 달성한 연구는 부재했음
- **제안 방법**: Self-supervised ASR 표현의 layer-wise 분석을 통해 화자 정체성이 주로 중간 인코더 레이어에 저장됨을 확인하고, 이를 기반으로 feature-level dispersion objective를 설계하여 'forget' 화자의 표현을 잠재 공간 centroid로부터 분산시킴
- **핵심 차별점**: 화자 정보가 인코딩된 특정 레이어를 식별하고 해당 레이어에서만 선택적으로 unlearning을 수행하여, 전체 전사 품질 저하를 최소화하면서 특정 화자의 영향을 제거
- **실험 결과**: VCTK 코퍼스에서 특정 화자의 영향을 제거하면서 전사 품질을 유지하는 데 성공
- **우리 연구 관련도**: ★☆☆ — Self-supervised 표현의 layer별 정보 분석이 흥미로우나, prediction-free SSL이나 VQ 기반 표현과의 직접적 관련성은 낮음

### **[Learning New Words from Unlabeled Test Data in Automatic Speech Recognition] (Mengqi Wang, Mark A. Hasegawa-Johnson, Haolong Zheng, Chang D. Yoo, 2026-09-24)** — arxiv preprint
- https://arxiv.org/abs/2609.28877
- **기존 문제**: ASR 시스템이 학습 데이터에 없는 OOV(Out-of-Vocabulary) 단어를 인식하지 못하는 문제. 특히 고유명사, 전문 용어 등에서 심각한 성능 저하 발생
- **기존 방법**: 외부 사전 확장, contextual biasing, 또는 추가 학습 데이터를 통한 fine-tuning이 주로 사용되었으나, 레이블이 없는 테스트 데이터만으로 새 단어를 학습하는 접근은 제한적이었음
- **제안 방법**: Frozen CTC 음향 모델이 후보 철자를 생성하고, frozen 언어 모델이 OOV 단어를 탐지하는 구조. 별도의 adaptation 모듈이 KL-divergence 목적함수를 통해 후보 토큰 표현을 학습하며, log-likelihood ratio와 Pinsker 부등식을 활용한 이론적 프레임워크 제시
- **핵심 차별점**: 레이블 없는 테스트 데이터만으로 새로운 단어를 학습하는 test-time adaptation 방식. 음향 모델과 언어 모델 모두 frozen 상태로 유지하여 기존 성능 보존
- **실험 결과**: LibriSpeech에서 OOV 문자 오류율(CER) 최대 14.97% 상대적 감소, Speech Accessibility Project의 구음장애 음성에서 6.67% 상대적 감소 달성
- **우리 연구 관련도**: ★☆☆ — CTC 기반 접근법이지만, self-supervised representation이나 VQ 기반 방법과의 직접적 연결은 약함

### **[Toward Accurate Speaker Inventories for Online Speaker Diarization] (Youngki Kwon, Hee-Soo Heo, Minjae Lee, Bong-Jin Lee, 2026-10-08)** — ICASSP 2027 submitted
- https://arxiv.org/abs/2610.11278
- **기존 문제**: 온라인 화자 분할(diarization)에서 화자 목록(inventory) 관리가 부정확한 문제. 화자 수를 고정하면 초과 화자가 병합되고, 임베딩 거리만으로 추가하면 노이즈나 턴 경계에서 화자가 불필요하게 분리됨
- **기존 방법**: 사전 설정된 화자 수 고정 방식 또는 임베딩 거리 기반의 단순 화자 추가 방식이 사용되었으며, 두 방법 모두 실제 환경에서 화자 수 추정 오류가 심각했음
- **제안 방법**: 임베딩 기반 화자 추적기에 후보 풀(candidate pool) 메커니즘을 도입. 충분한 수의 상호 호환 임베딩이 수집된 후에만 새 화자로 등록하며, 확인 전까지 레이블 할당을 보류하는 방식
- **핵심 차별점**: 화자 등록 규칙만 변경하는 경량 접근으로, 기존 온라인 다이어리제이션 시스템에 쉽게 통합 가능. 거짓 화자 생성과 화자 병합 문제를 동시에 해결
- **실험 결과**: 9개 공개 데이터셋에서 매크로 화자 수 오류(speaker-count error) 225%→21%로 대폭 감소, 매크로 DER 17.59%→15.95%, 평균 추가 지연 0.109초
- **우리 연구 관련도**: ★☆☆ — 다이어리제이션 특화 연구로 SSL 표현이나 VQ 기반 방법과의 직접 관련은 없으나, 온라인 음성 처리 파이프라인에 활용 가능

## 2. SpeechLLM (Speech Language Model)

### **[DirectSpeech2LLM: A Simple End-to-End Framework to Mitigate Prompt Overfitting in Speech-LLMs] (IIIT Delhi, Microsoft Research, NUS, 2026-10-06)** — arxiv preprint
- https://arxiv.org/abs/2610.08085
- **기존 문제**: ASR instruction만으로 학습된 Speech-LLM이 새로운 instruction(음성 번역, 감정 인식 등)에 일반화하지 못하고 ASR 시스템처럼만 동작하는 prompt overfitting 문제
- **기존 방법**: 다중 태스크 학습 데이터 확보, 또는 cascaded 시스템(ASR→LLM)을 사용. 별도의 regression loss를 통한 음성-텍스트 임베딩 정렬이 일반적이었음
- **제안 방법**: Frozen LLM 임베딩 행렬 위에서 distance-based CTC loss를 계산하고, greedy CTC 레이블로부터 기하학적·시간적으로 정렬된 음성 임베딩을 생성하여 LLM에 입력. 명시적 regression loss 없이 CTC loss만으로 충분한 기하학적 grounding을 달성
- **핵심 차별점**: ASR 데이터(LibriSpeech 960시간)만으로 학습하면서도 음성 번역, 감정 인식에 zero-shot 전이가 가능. Cascaded 시스템의 상한에 근접하는 성능을 달성하면서 end-to-end 구조의 효율성 확보
- **실험 결과**: ASR에서 cascaded 시스템을 능가하며, 음성 번역과 감정 인식에서 cascaded 상한에 근접하는 zero-shot 성능. 두 가지 LLM 계열에서 일관된 결과 확인
- **우리 연구 관련도**: ★★☆ — CTC 기반 음성-텍스트 정렬이 speech SSL 표현의 LLM 활용과 관련. 특히 frozen LLM 임베딩 공간에서의 기하학적 정렬 방식이 representation learning 관점에서 참고 가치 있음

### **[VoiceChat-TTS: A Low-Latency Continuous Speech Synthesis Model for Interactive Agents] (Edresson Casanova et al., NVIDIA, 2026-08)** — arxiv preprint
- https://arxiv.org/abs/2608.13831
- **기존 문제**: 기존 음성 대화 모델이 turn-based 방식에 한정되어 실시간 적응성이 부족하고, 사용자 끼어들기(barge-in) 지원이 어려움. End-to-end 모델은 ASR·끼어들기·고품질 합성을 동시에 최적화해야 해서 음성 품질 저하 발생
- **기존 방법**: 전체 파이프라인을 하나의 end-to-end 모델로 대체하는 방식(full-duplex speech LM) 또는 독립적인 TTS 모듈 사용. 전자는 품질 저하, 후자는 끼어들기 대응이 어려웠음
- **제안 방법**: LLM의 텍스트 토큰 스트림을 입력받아 연속적으로 음성을 생성하는 streaming TTS. Start-of-turn 토큰, padding 토큰, interruption 토큰 등 제어 심볼로 끼어들기를 관리. KV 캐시 초기화 없이 중간 발화 끼어들기 지원
- **핵심 차별점**: 모듈식 파이프라인을 유지하면서도 실시간 끼어들기를 지원. 778M Gemma 3 기반 디코더 + 199M causal 오디오 코덱(12.5Hz, 31 RVQ 레벨)으로 구성. Mixture-of-Gaussians 헤드로 RVQ 레벨 병렬 예측
- **실험 결과**: KV 캐시 리셋 없이 mid-utterance 끼어들기 지원. 모듈식 구성으로 음성 품질과 실시간성을 동시에 유지 (NemotronLabs VoiceChat의 음성 생성 모듈로 채택)
- **우리 연구 관련도**: ★☆☆ — Neural audio codec과 RVQ 기반 토큰화를 활용하지만, self-supervised learning이나 representation learning보다는 생성 모델 최적화에 초점

### **[MP-Bench: Evaluating Voice Agents as a Multiparty Conversation Participant] (Yi-Jen Shih, Guan-Ting Lin, Shinji Watanabe, Hung-yi Lee, David Harwath et al., 2026-09-11)** — arxiv preprint
- https://arxiv.org/abs/2609.13076
- **기존 문제**: 기존 음성 에이전트 벤치마크가 1:1 대화만 평가하여, 다자간 대화에서의 에이전트 능력(적절한 발화 시점, 맥락 이해 등)을 측정하지 못함
- **기존 방법**: 텍스트 기반 다자간 대화 평가, 또는 음성 기반이지만 1:1 상호작용만 테스트하는 벤치마크(예: MSI-Bench). 오디오에서 직접 음향·맥락 신호를 동시에 처리하는 능력은 평가하지 않았음
- **제안 방법**: 다자간 음성 대화에서 에이전트를 적극적 참여자로 평가하는 최초의 벤치마크. 두 가지 주요 차원(turn-taking awareness, response appropriateness)과 보완적 QA 기반 이해력 평가를 포함. 오디오에서 직접 음향·맥락 신호를 처리하도록 설계
- **핵심 차별점**: 텍스트가 아닌 오디오 기반으로 다자간 환경에서의 에이전트 행동을 직접 평가. Turn-taking과 응답 적절성을 음향 신호로부터 판단하는 능력을 측정
- **실험 결과**: 12개 음성 에이전트 평가 결과, 다자간 이해력에서 22% 이하의 정확도, turn-taking에서 우연 수준(chance-level)에 근접하는 저조한 성능을 보여 현재 기술의 한계를 실증
- **우리 연구 관련도**: ★☆☆ — 벤치마크 연구로 직접적 기술 관련성은 낮으나, speech representation이 다자간 환경에서 얼마나 효과적인지를 측정하는 프레임워크로 참고 가치 있음

## 3. Speech Foundation Model

### **[CleanCodec: Efficient and Robust Speech Tokenization via Perceptually Guided Encoding] (2026-06-03)** — arxiv preprint
- https://arxiv.org/abs/2606.04418
- **기존 문제**: 기존 음성 코덱이 배경 소음, 녹음 아티팩트 등 지각적으로 불필요한 정보에 토큰을 낭비하여 토큰 효율성이 낮고, 노이즈 환경에서 성능이 저하됨
- **기존 방법**: RVQ(Residual Vector Quantization) 기반 코덱(EnCodec, SoundStream 등)이 모든 음향 정보를 무차별적으로 인코딩. 전처리 단계에서 별도의 음성 향상 모듈을 추가하는 방식도 있었으나 파이프라인이 복잡해짐
- **제안 방법**: 오디오 토큰화를 선택적 정보 병목(selective information bottleneck)으로 취급하는 denoising 코덱. 지각적으로 중요한 특성만 보존하고 불필요한 정보를 제거. Dual-decoder 구조와 TitaNet 기반 화자 conditioning 적용
- **핵심 차별점**: 지각적 가이드를 통해 노이즈를 자연스럽게 제거하면서 토큰 효율성을 극대화. 전처리 없이 코덱 자체에서 denoising 수행
- **실험 결과**: 12.5 tokens/sec의 효율로 화자 유사도와 음성 명료도에서 SOTA 달성. TTS 및 음성 변환에서 최대 17배 빠른 추론 속도
- **우리 연구 관련도**: ★★★ — VQ 기반 speech representation에서 어떤 정보를 보존하고 어떤 정보를 제거해야 하는지에 대한 설계 원칙을 제시. Prediction-free SSL에서의 정보 선택 메커니즘 설계에 직접 참고 가능

### **[F3-Tokenizer: Taming Audio Autoencoder Latents for Understanding and Generation] (Dinghao Zhou, Xingchen Song, Di Wu, Pengyu Cheng et al., Nanjing University & WeNet, 2026-06-04)** — arxiv preprint
- https://arxiv.org/abs/2606.06357
- **기존 문제**: 연속 오토인코더(continuous autoencoder)는 재구성 품질은 좋지만 이해 태스크에 부적합한 잠재 공간을 형성하고, self-supervised 음성 인코더는 의미론적 정보는 잘 포착하지만 오디오 디코딩이 불가능한 이분법적 한계
- **기존 방법**: 이해와 생성을 별도 토크나이저로 처리하거나, 시맨틱-어쿠스틱 분리를 위한 2단계 코덱 사용. 단일 토크나이저로 두 능력을 동시에 갖추는 것이 어려웠음
- **제안 방법**: (1) Noise-regularized autoencoder bottleneck — KL 기반 변분 학습 대신 채널 정규화와 확률적 섭동을 사용. (2) Latent-side representation encoder — frozen autoencoder 잠재 공간 위에서 RQ-MTP(Residual Quantized Multi-Target Prediction)와 frozen LLM supervision으로 학습. 이해용 고차원 표현과 생성용 연속 잠재 변수를 동시 제공
- **핵심 차별점**: 하나의 토크나이저로 이해(understanding)와 생성(generation)을 모두 지원. Autoencoder 잠재 공간과 SSL 표현 학습을 통합하는 새로운 프레임워크
- **실험 결과**: ESC-50에서 75.2% 정확도, NSynth 악기 분류에서 58.12%, Seed-EN TTS에서 1.88 WER (제3자 소스 기반, 미검증)
- **우리 연구 관련도**: ★★★ — RQ 기반 multi-target prediction과 self-supervised representation learning을 결합한 접근법이 우리의 VQ 기반 representation 연구와 직접적으로 관련. Prediction-free SSL과의 비교 관점에서도 참고 가치 높음

### **[An Ultra-Low-Bitrate Neural Speech Codec with Plain-to-Pseudo Synergistic Vector Quantization] (Xiao-Hang Jiang, Yang Ai et al., 2026-06-04)** — Interspeech 2026 accepted
- https://arxiv.org/abs/2606.05876
- **기존 문제**: 대부분의 신경 음성 코덱이 사용하는 RVQ에서 후반 양자화 단계가 거의 기여하지 않으면서도 동일한 비트레이트를 소비하는 비효율성 문제
- **기존 방법**: RVQ(Residual Vector Quantization)의 여러 단계를 순차적으로 적용하여 잔차를 줄이는 방식. 각 단계가 동일한 전송 비트레이트를 필요로 하여 총 비트레이트가 선형 증가
- **제안 방법**: P2PSynCodec — 하나의 plain VQ(인코더 출력을 직접 양자화)와 여러 pseudo VQ로 구성. Pseudo VQ는 신경망 예측을 통해 보조 토큰을 생성하며 전송 비트레이트를 소비하지 않음(0 bits). 경량 합성곱 네트워크와 MDCT 표현 기반
- **핵심 차별점**: Pseudo VQ가 전송 비트를 사용하지 않으므로 0.5 kbps에서 2.0 kbps 코덱과 동등한 품질 달성. RVQ의 비트레이트 비효율 문제를 근본적으로 해결
- **실험 결과**: 0.5 kbps에서 경쟁 코덱의 2.0 kbps 수준 재구성 품질 달성. Ablation 연구에서 pseudo VQ 3개 구성이 최적
- **우리 연구 관련도**: ★★★ — VQ 기반 음성 표현의 효율성을 극대화하는 방법으로, prediction 기반 보조 양자화가 전송 비용 없이 표현력을 향상시키는 접근법. 우리 연구의 VQ-based representation 설계에 직접 참고 가능하며, prediction vs. prediction-free 양자화의 역할 분석에 유의미한 사례
