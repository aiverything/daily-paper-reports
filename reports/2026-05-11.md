## 1. ASR

### **Moonshine v2: Ergodic Streaming Encoder ASR for Latency-Critical Speech Applications (Manjunath Kudlur et al., 2026-02)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2602.12241
- 기존 문제: 실시간 전사, 음성 명령, 실시간 번역 등 지연 시간이 극도로 중요한 음성 애플리케이션에서, 기존 full-attention 기반 모델은 시퀀스 길이에 비례하여 계산량이 증가하고 에지 디바이스에서의 배포가 어려움.
- 기존 방법: Whisper 등 full-attention 인코더 기반 모델은 높은 정확도를 달성하지만 긴 지연 시간과 큰 모델 크기를 요구. 기존 스트리밍 모델은 정확도-지연 트레이드오프에서 열세.
- 제안 방법: 슬라이딩 윈도우 셀프 어텐션을 사용하는 Ergodic 스트리밍 인코더 설계. 절대적/상대적 위치 임베딩 없이(position-free) 인코더가 로컬 어텐션 윈도우 내 콘텐츠만으로 구조를 추론하는 "에르고딕" 구조. 오디오 전처리기는 80-sample 비중첩 윈도우에 CMVN, asinh 비선형 변환, 인과적 stride-2 합성곱 적용. 디코더는 RoPE를 사용하는 인과적 Transformer.
- 핵심 차별점: 위치 임베딩 제거로 시간 변환 불변(translation-invariant) 인코더를 달성하여 임의 길이 스트리밍에 자연적으로 대응. 알고리즘적 lookahead 80ms로 초저지연 달성. 약 300K 시간의 음성 데이터로 학습.
- 실험 결과: 표준 벤치마크에서 SOTA WER 달성하며, 6배 큰 모델과 동등한 정확도를 유지하면서 추론 속도는 크게 빠름. 로컬 어텐션만으로 full-attention 수준의 정확도를 달성할 수 있음을 입증.
- 우리 연구 관련도: ★☆☆ (스트리밍 ASR 아키텍처 최적화로 SSL/VQ 표현 연구와 직접 관련은 낮으나, 위치 임베딩 없는 에르고딕 인코더 설계는 temporal representation의 position-invariance 관점에서 간접 참고 가능)

### **Audio-Conditioned Diffusion LLMs for ASR and Deliberation Processing (Mengqi Wang, Zhan Liu, Zengrui Jin et al., 2025-09)** — ICASSP 2026 accepted
- arxiv URL: https://arxiv.org/abs/2509.16622
- 기존 문제: LLM 기반 ASR은 자기회귀 디코딩의 단방향 컨텍스트 한계로 인해 deliberation(숙고) 기반 후처리에서 양방향 문맥 활용이 어려움. 기존 텍스트 전용 LLM deliberation은 음향 정보 부재로 인해 정확도 향상에 한계.
- 기존 방법: Whisper-LLaMA 등 자기회귀 LLM 기반 ASR, 텍스트 전용 언어 모델 deliberation, 별도 rescoring 모듈.
- 제안 방법: 확산(diffusion) 기반 LLM인 LLaDA를 ASR에 최초 적용. Whisper 인코더의 음향 특징을 조건으로 하는 audio-conditioned 확산 LLM 구성. Random masking, low-confidence masking, semi-autoregressive 전략 등 다양한 deliberation 방식 탐구. 양방향 어텐션과 디노이징 능력으로 전사 품질 개선.
- 핵심 차별점: 확산 LLM을 ASR에 최초 적용한 연구. 양방향 문맥을 자연스럽게 활용하는 디노이징 메커니즘. 텍스트만의 LLaDA는 성능 향상에 실패하여 audio-conditioned 임베딩의 중요성을 실증.
- 실험 결과: LibriSpeech test-clean/test-other에서 2.25%/4.94% WER 달성. Whisper-LLaMA 베이스라인 대비 test-other에서 12.3% 상대 개선.
- 우리 연구 관련도: ★☆☆ (확산 모델 기반 ASR deliberation으로 SSL/VQ 표현 연구와 직접 관련은 낮으나, 확산 모델의 음향 조건부 디노이징 메커니즘은 VQ 기반 토큰의 불확실성 모델링 관점에서 간접 참고 가치)

### **Speak in Context: Multilingual ASR with Speech–Context Alignment via Contrastive Learning (Yuchen Zhang et al., 2026-03)** — LREC 2026 accepted
- arxiv URL: https://arxiv.org/abs/2603.06505
- 기존 문제: 다국어 대화 음성 인식에서 문맥 정보(대화 이력, 바이어싱 단어 등)의 효과적 활용이 부족하며, 사전학습된 모델의 모듈성을 유지하면서 문맥을 통합하는 것이 어려움.
- 기존 방법: 단일 모델 end-to-end 학습, 문맥 무관 ASR 후처리, 별도 언어 모델 rescoring.
- 제안 방법: 동결된(frozen) 음성 인코더와 디코더 전용 LLM을 경량 프로젝션 모듈로 연결하는 문맥 인식 다국어 ASR 프레임워크. 대조 학습(contrastive learning) 목적 함수로 음성과 문맥 표현을 공유 임베딩 공간에 정렬. 대화 이력, 바이어싱 단어 등 구조화된 문맥 프롬프트 지원.
- 핵심 차별점: 사전학습 모델을 동결한 채 대조 학습으로 음성-문맥 정렬을 달성하여 모듈성 보존. 11개 언어와 5개 영어 방언에 걸친 1,500시간 이상의 실제 대화 음성으로 평가.
- 실험 결과: 문맥 입력이 인식 품질을 일관적으로 향상. 대조 정렬이 다양한 문맥 유형에서 추가 성능 향상 제공. 전체적으로 5% 이상의 성능 개선 달성.
- 우리 연구 관련도: ★★☆ (대조 학습을 통한 음성-문맥 표현 정렬은 temporal contrastive learning의 방법론적 유사성이 있으며, 동결 인코더 기반 표현 활용 전략은 speech SSL 표현의 하류 활용 연구에 참고 가치)

## 2. SpeechLLM

### **Kimi-Audio Technical Report (Kimi Team / Moonshot AI, 2025-04)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2504.18425
- 기존 문제: 기존 오디오 LLM은 음성 인식, 오디오 이해, 음성 대화 등 개별 태스크를 위해 별도 모델이 필요하거나, 대규모 사전학습이 부족하여 범용적 오디오 처리 능력이 제한적.
- 기존 방법: 태스크 특화 모델, 제한된 오디오 사전학습의 LLM, 캐스케이드 ASR→LLM→TTS 파이프라인.
- 제안 방법: 12.5Hz 오디오 토크나이저(이산 시맨틱 토큰 추출) + Whisper 인코더(연속 음향 특징) → 오디오 LLM(텍스트/오디오 출력 생성) → flow matching 기반 청크 단위 스트리밍 디토크나이저(파형 복원)로 구성. 1,300만 시간 이상의 다양한 오디오(음성, 음악, 소리)와 텍스트 데이터로 대규모 사전학습. 사전학습된 LLM에서 초기화 후 오디오-텍스트 연속 사전학습, 이후 다양한 오디오 태스크로 파인튜닝.
- 핵심 차별점: 연속 특징 입력 + 이산 토큰 출력의 하이브리드 아키텍처. 1,300만 시간 규모의 대규모 다모달 사전학습. Flow matching 기반 스트리밍 디토크나이저로 실시간 음성 생성. 오픈소스 공개(모델, 코드, 평가 툴킷).
- 실험 결과: 10개 이상의 오디오 벤치마크에서 SOTA. LibriSpeech 1.28/2.42 WER, MMAU·VocalSound 등 오디오 이해, VoiceBench 음성 대화에서 최고 성능 달성.
- 우리 연구 관련도: ★★☆ (12.5Hz 오디오 토크나이저의 시맨틱 토큰 설계와 연속-이산 하이브리드 구조는 VQ-based speech tokenizer 연구에 직접 참고 가치. Flow matching 기반 디토크나이저는 VQ 토큰으로부터의 고품질 복원 연구에 시사점 제공)

### **InteractiveOmni: A Unified Omni-modal Model for Audio-Visual Multi-turn Dialogue (SenseTime-FVG, 2025-10)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2510.13747
- 기존 문제: 기존 옴니모달 LLM은 단일 턴 응답에 최적화되어 멀티턴 대화에서의 장기 기억 능력이 부족. 텍스트·이미지·비디오·오디오를 통합적으로 이해하면서 음성 응답을 생성하는 멀티턴 상호작용 평가 체계도 부재.
- 기존 방법: GPT-4o, Qwen2.5-Omni 등 대규모 옴니모달 모델(단일 턴 중심), 개별 모달리티별 전용 모델.
- 제안 방법: 비전 인코더, 오디오 인코더, LLM, 음성 디코더를 통합한 4B/8B 규모의 end-to-end 옴니모달 모델. 다단계 학습 전략: (1) 옴니모달 이해 사전학습, (2) 음성 대화 및 오디오-비주얼 상호작용 후처리 학습. 새로운 벤치마크 2종 제안: MMMB(멀티모달 멀티턴 메모리, 300 대화 그룹/최대 15턴), MSIB(멀티턴 음성 상호작용, 6개 차원 평가).
- 핵심 차별점: 4B 모델이 7B급 Qwen2.5-Omni와 동등한 성능 달성. 8B 대비 50% 크기로 97% 성능 유지. 멀티턴 장기 기억 평가를 위한 MMMB 벤치마크와 음성 상호작용 평가를 위한 MSIB 벤치마크를 최초 제안.
- 실험 결과: 이미지·비디오·오디오 이해에서 동급 오픈소스 모델 대비 경쟁력 있는 성능. OmniBench에서 InteractiveOmni-4B가 평균 59.19점으로 SOTA. ASR 벤치마크에서도 경쟁력 있는 결과. 멀티턴 기억 능력에서 기존 모델 대비 우월.
- 우리 연구 관련도: ★☆☆ (옴니모달 멀티턴 대화 시스템으로 SSL/VQ 표현 연구와 직접 관련은 낮으나, MSIB의 음성 상호작용 평가 6차원 체계는 speech representation 평가 설계에 간접 참고 가능)

### **MiniMind-O Technical Report: An Open Small-Scale Speech-Native Omni Model (Jingyao Gong, 2026-05)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2605.03937
- 기존 문제: 기존 옴니모달 모델(GPT-4o, Qwen-Omni 등)은 수십~수백억 파라미터 규모로, 전체 학습 파이프라인의 투명한 검증과 교육적 재현이 어려움. 소규모 옴니 모델에서의 최적 설계 원칙이 미확립.
- 기존 방법: 대규모 옴니모달 LLM(7B 이상), 불투명한 학습 파이프라인, 대규모 음향 모델에 의존하는 audio-code 예측.
- 제안 방법: 0.1B 규모의 MiniMind 언어 모델 기반 오픈 옴니 모델. Thinker(MiniMind 본체)가 텍스트·음성·이미지 입력을 처리하고, Talker(4-layer 독립 모듈)가 오디오 코드를 생성하는 이중 구조. 동결된 SenseVoice-Small(음성)과 SigLIP2(이미지) 인코더를 MLP 프로젝터로 연결. Mimi의 8-codebook 표현을 유지하되, 극소규모 모델에 부착.
- 핵심 차별점: 0.1B 규모에서의 3가지 스케일 핵심 설계 원칙 도출: (1) 중간 레이어 시맨틱 브릿징, (2) 공개 멀티모달 시퀀스 포맷, (3) 파라미터 효율적 8-codebook 인터페이스. 모델 코드, 체크포인트, 학습 데이터셋(Parquet)을 완전 공개하여 전체 학습 루프 검증 가능.
- 실험 결과: 768차원 Talker에서 dense/MoE 변형이 평균 CER 0.0897/0.0900, 음성 복제 유사도 0.5995/0.5937 달성. Thinker-Talker 일관성 평가에서 극소규모에서도 유의미한 음성 상호작용 능력 확인.
- 우리 연구 관련도: ★☆☆ (극소규모 옴니 모델의 설계 원칙 연구로 SSL/VQ 표현과 직접 관련은 낮으나, 8-codebook 인터페이스의 파라미터 효율적 설계와 중간 레이어 시맨틱 브릿징은 VQ 코드북 설계의 규모 효율성 관점에서 간접 참고 가능)

## 3. Speech Foundation Model

### **StableToken: A Noise-Robust Semantic Speech Tokenizer for Resilient SpeechLLMs (Tencent, 2025-09)** — ICLR 2026 accepted
- arxiv URL: https://arxiv.org/abs/2509.22220
- 기존 문제: 현존하는 시맨틱 음성 토크나이저는 의미와 무관한 음향 교란에 놀라울 정도로 취약함. 높은 SNR에서도 음성이 완벽히 인지 가능한 상황에서 출력 토큰 시퀀스가 급격히 변화하여, 노이즈 환경에서 SpeechLLM의 성능이 크게 저하.
- 기존 방법: HuBERT, vq-wav2vec 등 기존 시맨틱 토크나이저는 clean 환경에서 학습되어 노이즈 강건성 미확보. 사후 노이즈 증강은 근본적 해결이 아님.
- 제안 방법: (1) Voting-LFQ(Lookup-Free Quantization): 다중 투표자(multi-voter) 양자화 메커니즘으로 비트 단위 투표를 통해 노이즈 하에서도 안정적 합의를 달성. (2) Noise-Aware Consensus Training: 다분기(multi-branch) 학습 패러다임으로, 노이즈 분기와 클린 분기 간의 글로벌 합의를 통해 표현 안정성 강화. 다분기 아키텍처가 오디오를 병렬 처리하고, 비트 단위 투표 메커니즘으로 단일 안정 토큰 시퀀스를 생성.
- 핵심 차별점: Unit Edit Distance(UED)를 60% 이상 상대 감소(26.17% → 10.17%)하며, 복원 충실도(reconstruction fidelity)는 최상위 수준 유지. 내재적 강건성이 ASR, SER, TTS 등 하류 태스크에서 일관되게 우월한 성능으로 전이.
- 실험 결과: UED 60% 이상 상대 감소(26.17% → 10.17%). ASR, 감정 인식(SER), TTS에서 특히 노이즈 조건에서 기존 토크나이저 대비 일관적 우위. 클린 조건에서도 복원 품질 최상위 유지.
- 우리 연구 관련도: ★★★ (VQ 기반 이산 토큰의 안정성·강건성을 직접 다루는 핵심 연구. Voting-LFQ의 다중 투표 양자화 메커니즘은 VQ-based representation의 코드북 설계에 직접 참고 가치. 노이즈-클린 분기 간 합의 학습은 contrastive learning 방법론과 구조적 유사성. 시맨틱 토큰의 음향 교란 불변성 연구는 prediction-free SSL의 표현 안정성 목표와 밀접)

### **Latent Speech-Text Transformer (Yen-Ju Lu, Yashesh Gaur, Wei Zhou et al. — Meta / JHU, 2025-10)** — ICLR 2026 Oral
- arxiv URL: https://arxiv.org/abs/2510.06195
- 기존 문제: 자기회귀 음성-텍스트 모델은 음성 토큰이 텍스트 토큰 대비 훨씬 긴 시퀀스를 형성하여 계산 비효율적. 이 모달리티 불균형이 사전학습과 추론에서 음성에 과도한 계산 자원을 배분.

- 우리 연구 관련도: ★★☆ (음성 토큰을 잠재 패치로 압축하는 설계는 speech tokenizer의 시간 해상도(토큰 레이트) 최적화와 직접 관련. HuBERT 토큰 기반 잠재 표현 학습은 VQ-based representation의 상위 추상화 연구에 참고 가치. 패치-텍스트 granularity 정렬은 시맨틱-음향 분리 설계에 시사점 제공)

### **Tracking the Emergence of Linguistic Structure in Self-Supervised Models Learning from Speech (Univ. Amsterdam, Radboud Univ., Tilburg Univ., 2026-04)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2604.02043
- 기존 문제: 자기 지도 학습(SSL) 음성 모델이 언어 구조를 어떤 순서와 방식으로 학습하는지에 대한 이해가 부족. 기존 분석은 최종 학습 모델의 레이어별 분석에 국한되어, 학습 과정(trajectory) 중의 언어 구조 출현 양상이 미해명.
- 기존 방법: 학습 완료된 SSL 모델의 레이어별 프로빙(probing). 최종 체크포인트만을 대상으로 한 정적 분석.

- 핵심 차별점: SSL 모델의 학습 과정에서 언어 구조의 출현 순서를 최초로 체계적 추적. 음소적 구분이 어휘적 구분에 선행하고, 구문 구조가 가장 나중에 출현함을 실증. 사전학습 목적 함수의 수준이 높을수록(higher-order prediction) 언어 구조 간 더 큰 병렬성이 유도됨을 발견.
- 실험 결과: 서로 다른 수준의 언어 구조가 명확히 구분되는 레이어별 패턴과 학습 궤적을 보임. 음향 신호 근접도와 시간 통합 스케일의 차이로 부분적 설명 가능. Higher-order prediction 사전학습 목적이 레이어 구조의 조직화와 학습 궤적 모두에 강한 영향.
- 우리 연구 관련도: ★★★ (Speech SSL 모델의 표현 학습 동역학을 직접 분석하는 핵심 연구. Wav2Vec2/HuBERT의 temporal representation 출현 순서 분석은 prediction-free SSL의 학습 목적 함수 설계에 직접적 시사점 제공. Higher-order prediction이 표현 구조에 미치는 영향 분석은 temporal contrastive learning의 예측 범위 설계에 핵심 참고 자료. 레이어별 언어 구조 출현 패턴은 VQ 코드북의 계층적 정보 인코딩 설계에 활용 가능)
