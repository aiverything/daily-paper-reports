## 1. ASR (Automatic Speech Recognition)

### **[Omnilingual ASR: Open-Source Multilingual Speech Recognition for 1600+ Languages] (Meta FAIR Team, 2025-11)** — arxiv preprint
- https://arxiv.org/abs/2511.09690
- **기존 문제**: 기존 다국어 ASR 시스템은 수백 개 언어까지만 지원하며, 전 세계 7,000여 개 언어 중 대다수(특히 저자원 언어)에 대한 음성 인식이 불가능했음
- **기존 방법**: MMS, Whisper 등 다국어 ASR 모델이 존재했으나, 라벨 데이터 부족으로 지원 언어 수가 수백 개 수준에 머물렀음
- **제안 방법**: wav2vec 2.0 기반 7B 파라미터 인코더를 430만 시간의 비라벨 다국어 음성으로 사전학습하고, LLM 디코더를 결합하여 1,690개 언어의 라벨 데이터(AllASR 코퍼스, 12만 시간)로 학습. Zero-shot in-context learning으로 5,400개 이상 언어로 확장 가능
- **핵심 차별점**: 사상 최대 규모(1,600+ 언어)의 오픈소스 ASR 모델군(300M~7B) 공개; 이전에 어떤 ASR 시스템도 지원하지 않던 500+ 언어를 최초로 포함; Apache 2.0 라이선스로 완전 공개
- **실험 결과**: 지원 언어의 78%에서 문자 오류율(CER) 10% 이하 달성; 극단적 저자원 조건에서 기존 시스템 대비 큰 폭의 성능 향상; 학습 시 미등장 언어에 대해서도 강한 일반화 능력 확인
- **우리 연구 관련도**: ★★☆ — wav2vec 2.0 SSL 사전학습을 7B 스케일로 확장한 사례로, speech SSL representation의 스케일링 법칙 연구에 참고 가치가 높음

### **[SpeakerLM: End-to-End Versatile Speaker Diarization and Recognition with Multimodal Large Language Models] (SpeakerLM Team, 2025-08)** — AAAI 2026 accepted
- https://arxiv.org/abs/2508.06372
- **기존 문제**: 기존 화자 분리 및 인식(SDR) 시스템은 화자 분리(SD)와 음성 인식(ASR)을 캐스케이드 방식으로 연결하여 오류 전파가 발생하고, 중첩 발화 처리 및 공동 최적화가 어려웠음
- **기존 방법**: 별도의 화자 분리 모듈과 ASR 모듈을 순차적으로 연결하는 캐스케이드 파이프라인이 주류; 화자 등록 조건도 고정적이었음
- **제안 방법**: Qwen2.5-7B-Instruct를 백본 LLM으로 사용하고, 오디오 인코더와 프로젝터를 통해 다화자 오디오 임베딩을 LLM 피처 공간에 주입. 유연한 화자 등록 메커니즘을 통합하여 다양한 등록 설정에서 SDR을 엔드투엔드로 수행
- **핵심 차별점**: 단일 멀티모달 LLM 내에서 화자 분리와 인식을 동시에 처리하는 통합 아키텍처; 7,000시간 이상의 실제 회의 데이터로 학습하여 강력한 데이터 스케일링 능력과 일반화 성능 확보
- **실험 결과**: 인도메인 및 아웃오브도메인 공개 SDR 벤치마크 모두에서 SOTA 캐스케이드 베이스라인을 상회하는 성능 달성
- **우리 연구 관련도**: ★☆☆ — LLM 기반 SDR 시스템으로, speech SSL representation 연구와의 직접적 연관은 낮으나 speech foundation model의 다운스트림 활용 사례로 참고 가능

### **[Adapting Diarization-Conditioned Whisper for End-to-End Multi-Talker Speech Recognition] (Martin Kocour, Martin Karafiat, Alexander Polok, Dominik Klement, Lukáš Burget, Jan Černocký, 2025-10)** — ICASSP 2026 accepted
- https://arxiv.org/abs/2510.03723
- **기존 문제**: 다화자 중첩 발화 환경에서 각 화자의 발화를 정확히 인식하고 화자에 귀속(speaker attribution)하는 것이 어려웠음
- **기존 방법**: DiCoW(Diarization-Conditioned Whisper)와 같은 타겟 스피커 ASR은 각 화자를 개별적으로 디코딩하여 계산 비용이 높고, SOT(Serialized Output Training) 기반 방법은 화자 정보 활용이 제한적이었음
- **제안 방법**: DiCoW 인코더를 활용하여 타겟 스피커 임베딩을 추출한 뒤, 이를 하나의 표현으로 연결(concatenate)하여 공유 디코더에 전달. 모든 화자의 발화를 화자 태그 및 타임스탬프와 함께 직렬화된 출력 스트림으로 공동 디코딩
- **핵심 차별점**: 타겟 스피커 모델링과 SOT를 결합하여, 디코더가 모든 화자의 컨텍스트를 동시에 활용하면서도 단일 패스로 디코딩 가능; 개별 디코딩 대비 효율적
- **실험 결과**: LibriMix 등 다화자 혼합 데이터셋에서 기존 SOT 기반 방법 및 DiCoW를 상회하는 성능 달성
- **우리 연구 관련도**: ★☆☆ — Whisper 기반 다화자 ASR 아키텍처 연구로, speech representation 연구와는 간접적 관련

## 2. SpeechLLM (Speech-Language Model)

### **[Liberating LLM Capabilities in Full-Duplex Speech Models] (LWS Team, 2026-06)** — arxiv preprint
- https://arxiv.org/abs/2606.07547
- **기존 문제**: 기존 풀듀플렉스 음성 모델은 음성 입출력에 집중하면서 LLM 고유의 텍스트 기반 능력(코드 생성, 표 작성, 수학적 추론 등)을 상실하는 문제가 있었음
- **기존 방법**: 풀듀플렉스 모델들은 음성 토큰만 생성하거나, 텍스트 출력을 위해 별도 모듈을 필요로 하여 아키텍처 수정이 불가피했음
- **제안 방법**: Listen-Write-Speak(LWS), 단일 오토레그레시브 LLM이 (1) 사용자 오디오를 지속적으로 수신(Listen), (2) 가시적인 자유 형식 텍스트를 생성(Write), (3) 실시간 음성 응답을 병렬 출력(Speak)하는 텍스트 우선 3채널 패러다임. 토큰 스키마만으로 구현하여 아키텍처 수정 불필요
- **핵심 차별점**: "Free lunch" — 모델 아키텍처 변경 없이 토큰 스키마만으로 가시적 텍스트 채널 추가; 코드, 테이블, 수식 등 텍스트 네이티브 출력을 실시간 음성과 동시 생성 가능
- **실험 결과**: Full-Duplex-Bench에서 강력한 상호작용 성능, VoiceBench AlpacaEval 4.72점, 쓰기-말하기 일관성 92.6%, URO-Bench에서 내부 어블레이션 대비 일관된 우위
- **우리 연구 관련도**: ★★☆ — 음성-텍스트 토큰 스키마 설계와 멀티모달 representation 통합 관점에서 참고 가치 있음

### **[DuplexSLA: A Full-Duplex Spoken Language Model with Synchronized Speech, Language, and Action] (Haoyang Zhang, Jun Chen, Donghang Wu et al., 2026-05)** — arxiv preprint
- https://arxiv.org/abs/2605.20755
- **기존 문제**: 기존 풀듀플렉스 모델은 음성 대화 중 계획(planning) 및 도구 호출(tool calling)을 위한 네이티브 채널이 없어, 에이전트 행동이 턴 경계에 묶이거나 외부 캐스케이드에 의존해야 했음
- **기존 방법**: 대화 중 도구 호출은 턴이 끝난 후에만 가능하거나, 별도의 텍스트 기반 파이프라인을 거쳐야 했음
- **제안 방법**: 듀얼 스트림 3채널 구조 — (1) 연속적 사용자 오디오 채널, (2) 이산적 어시스턴트 오디오 채널, (3) 속도 제한된 텍스트 액션 채널을 단일 백본이 공유 160ms 청크 타임라인에서 공동 디코딩. 의미 기반 턴테이킹과 대화 중 도구 호출을 모델 내부에서 통합
- **핵심 차별점**: 듣기, 말하기, 계획, 도구 호출이 하나의 공유 클록에서 동시 진행되는 네이티브 풀듀플렉스 에이전트 아키텍처; 외부 VAD나 캐스케이드 불필요
- **실험 결과**: Spoken QA에서 +7.4%, FullDuplexBench 1.5에서 +28.5% 향상으로 SOTA 달성; 추론 효율성 저하 없음
- **우리 연구 관련도**: ★☆☆ — 음성 에이전트 아키텍처 연구로, speech representation 자체보다는 representation 활용 방식에 초점

### **[VoiceChat-TTS: A Low-Latency Continuous Speech Synthesis Model for Interactive Agents] (Edresson Casanova, Jaehyeon Kim et al., 2026-08)** — arxiv preprint (NVIDIA)
- https://arxiv.org/abs/2608.13831
- **기존 문제**: 기존 TTS 모델은 음성 에이전트의 실시간 대화 요구사항(스트리밍, 중단 처리, 무음 생성)을 충족하지 못해, 자연스러운 대화형 음성 합성이 어려웠음
- **기존 방법**: 표준 TTS 모델은 발화 단위로 합성하며 중단(interruption) 처리나 무음 생성을 지원하지 않아, 별도의 VAD와 후처리가 필요했음
- **제안 방법**: LLM 텍스트 토큰 스트림으로 직접 구동되는 연속적·스트리밍 가능한 TTS 모델. 명시적 무음 모델링, 중단 제어 토큰, 단일턴/멀티턴 대화 합성을 위한 통합 학습 방법을 도입. KV 캐시 리셋 없이 발화 중간 중단 지원
- **핵심 차별점**: Audio Flamingo 3-Chat 음성 디코더를 확장하여 명시적 무음 모델링과 제어 토큰 기반 중단 메커니즘을 통합; 대화형 에이전트에 특화된 엔드투엔드 TTS
- **실험 결과**: 단일턴 설정에서 WER 4.51% → 2.00%로 개선, Squim-MOS 3.60 → 4.38로 향상
- **우리 연구 관련도**: ★☆☆ — TTS/음성 합성 모델로 speech representation 연구와의 직접적 관련은 낮음

### **[JoyAI-Talker: Full-Duplex Speech Interactive Large Model Built for Empathetic Voice Agents] (Yinhao Bai, Jinming Chen et al., 2026-08)** — arxiv preprint
- https://arxiv.org/abs/2608.01119
- **기존 문제**: LLM에 음성 모달리티를 추가하면 텍스트 기반 추론 능력(수학, STEM, 논리)이 심각하게 저하되는 "인지 퇴화(cognitive degradation)" 현상이 발생했으며, 공감적 대화 능력도 부족했음
- **기존 방법**: 기존 풀듀플렉스 모델들은 음성-텍스트 공동 학습 시 텍스트 추론 능력 유지에 실패하거나, 화자의 감정·속성을 활용한 공감적 응답 생성이 불가능했음
- **제안 방법**: Thinker-Talker 모듈러 아키텍처를 채택하고, JoyAI-LLM Flash(48.9B MoE 모델, MLA 어텐션)를 백본으로 사용. PAER(Persona-Adaptive Empathetic Response) 프레임워크를 통해 화자의 성별·나이·감정 상태를 추출하여 CoT 추론에 통합. Joy-Duplex로 실시간 턴 제어. 중간 학습 단계부터 음성-텍스트 공동 학습
- **핵심 차별점**: 48.9B MoE 기반의 대규모 풀듀플렉스 모델로, 텍스트 추론 능력을 유지하면서 음성 상호작용 가능; PAER를 통한 계층적 공감 파이프라인(음성 이해 → CoT 추론 → 공감적 대화 생성)
- **실험 결과**: MATH 94.62%, MMLU 88.57% 달성하면서 음성 능력 유지; 사용자 중단 시 응답률 0.88, 배경 음성 하에서 극히 낮은 오탐 비율
- **우리 연구 관련도**: ★☆☆ — 대규모 SpeechLLM 시스템 연구로, speech representation 자체보다는 시스템 아키텍처에 초점

## 3. Speech Foundation Model

### **[CleanCodec: Efficient and Robust Speech Tokenization via Perceptually Guided Encoding] (Eugene Kwek, Rui Zhang, Feng Liu, Wenpeng Yin, 2026-06)** — arxiv preprint (Penn State)
- https://arxiv.org/abs/2606.04418
- **기존 문제**: 기존 오디오 코덱은 배경 소음, 녹음 아티팩트 등 지각적으로 중요하지 않은 정보까지 모두 인코딩하여, 토큰 효율성이 낮고 노이즈에 취약했음
- **기존 방법**: 표준 오디오 코덱(EnCodec, SoundStream 등)은 모든 신호 정보를 최대한 보존하는 것을 목표로 하여, 중요 정보와 노이즈를 구분하지 않았음
- **제안 방법**: "디노이징 오디오 코덱" 개념 — 표준 오디오 복원 목표와 음성 향상(speech enhancement) 태스크를 공동으로 학습하여, 인코딩 전에 지각적으로 중요하지 않은 특성을 제거. 추가로 언어적(linguistic) 및 음색(timbre) 정보 인코딩을 촉진하는 조건부 목표 적용
- **핵심 차별점**: 코덱이 "무엇을 인코딩할지" 선택적으로 학습하여, 초당 12.5 토큰이라는 극한의 효율성 달성; 노이즈 로버스트한 토큰화와 고품질 복원을 동시에 확보
- **실험 결과**: 12.5 tokens/s에서 SOTA 토큰화 효율성, 화자 유사도 및 음성 명료도에서 기존 코덱 대비 큰 폭 우위; 다운스트림 TTS 및 음성 변환에서 최대 17배 빠른 추론 속도
- **우리 연구 관련도**: ★★★ — VQ 기반 representation 연구와 직접 관련. 지각적 가이드를 통한 선택적 정보 인코딩은 prediction-free speech SSL 및 temporal contrastive learning에서의 정보 선별 문제와 맞닿아 있음

### **[F3-Tokenizer: Taming Audio Autoencoder Latents for Understanding and Generation] (Dinghao Zhou, Xingchen Song, Di Wu, Pengyu Cheng, Shengfan Shen, Sixiang Lv, 2026-06)** — arxiv preprint
- https://arxiv.org/abs/2606.06357
- **기존 문제**: 연속(continuous) 오디오 오토인코더는 파형 복원은 잘하지만 이해(understanding)에 약한 잠재 표현을 생성하고, 자기지도 학습 인코더는 의미를 잘 포착하지만 디코딩이 불가능하여, 이해와 생성을 단일 토크나이저로 통합하기 어려웠음
- **기존 방법**: 이해용 토크나이저(HuBERT, WavLM 등)와 생성용 토크나이저(EnCodec 등)를 별도로 사용하거나, 두 representation을 결합하는 복잡한 파이프라인이 필요했음
- **제안 방법**: (1) 노이즈 정규화 오토인코더 보틀넥: KL 기반 변분 학습 대신 채널 정규화와 확률적 교란을 사용하여 스케일 제어된 연속 잠재 변수 생성. (2) 잠재 공간 representation 인코더: 동결된 오토인코더 잠재 변수 위에서 RQ-MTP(Residual Quantization Multi-Target Prediction)와 동결된 LLM 감독으로 학습
- **핵심 차별점**: 단일 토크나이저가 이해를 위한 고차원 representation과 생성을 위한 정규화된 연속 잠재 변수를 동시에 제공; KL 기반 학습의 불안정성을 노이즈 정규화로 해결
- **실험 결과**: 다양한 오디오 분류 및 생성 벤치마크에서 58~96% 정확도 범위의 강력한 성능 달성
- **우리 연구 관련도**: ★★★ — RQ 기반 토큰화와 representation learning을 통합하는 접근으로, VQ-based representation 연구 및 prediction-free SSL 연구와 핵심적으로 연관됨

### **[Codec2Vec: Self-Supervised Speech Representation Learning Using Neural Speech Codecs] (Wei-Cheng Tseng, David Harwath, 2025-11)** — arxiv preprint (UT Austin)
- https://arxiv.org/abs/2511.16639
- **기존 문제**: 기존 자기지도 음성 representation 학습(wav2vec 2.0, HuBERT 등)은 원시 파형이나 멜 스펙트로그램 등 연속 입력을 처리해야 하여 저장 공간, 전송 비용, 학습 시간이 크고 데이터 프라이버시 문제도 존재했음
- **기존 방법**: wav2vec 2.0, HuBERT, WavLM 등이 연속 음성 입력에서 SSL로 표현을 학습; 뉴럴 오디오 코덱은 압축과 합성에만 주로 사용
- **제안 방법**: 뉴럴 오디오 코덱의 이산 단위만을 사용하는 최초의 speech SSL 프레임워크. DAC(Deep Audio Codec)로 16kHz 오디오를 사전 압축하여 12개 코드북 시퀀스(50Hz)를 생성하고, BASE 크기의 Transformer 인코더(12층, 768 임베딩)로 처리
- **핵심 차별점**: 연속 입력 없이 사전 계산된 이산 코덱 단위만으로 SSL 학습이 가능함을 최초로 증명; 저장 16.5배 절감, 학습 속도 2.3배 향상; 데이터 프라이버시 이점(원시 파형 불필요)
- **실험 결과**: SUPERB 벤치마크에서 연속 입력 모델 대비 경쟁력 있는 성능 달성하면서, 저장 요구량 16.5배 절감 및 학습 시간 2.3배 단축
- **우리 연구 관련도**: ★★★ — 이산 코덱 토큰 기반 speech SSL이라는 새로운 패러다임을 제시하여, VQ-based representation 연구와 prediction-free SSL 연구 모두에 핵심적으로 관련됨

## 이번 주 트렌드 요약 (2026-09-28 ~ 2026-10-02)

### 1. 풀듀플렉스 음성 모델의 에이전트화
이번 주 가장 두드러진 트렌드는 풀듀플렉스 음성 모델이 단순한 대화를 넘어 **에이전트 기능**(도구 호출, 계획, 액션)을 통합하는 방향이다. DuplexSLA의 3채널 아키텍처, LWS의 텍스트 쓰기 채널, JoyAI-Talker의 Thinker-Talker 구조 등이 이를 보여준다. 대화 중 실시간으로 코드 생성, 도구 호출, 구조화된 추론이 가능한 "말하면서 생각하는" 모델이 핵심 연구 방향으로 자리잡고 있다.

### 2. 극한 다국어 ASR로의 스케일링
Meta의 Omnilingual ASR(1,600+ 언어)이 보여주듯, 다국어 ASR의 커버리지가 수백 개에서 수천 개 언어로 급격히 확장되고 있다. wav2vec 2.0 SSL 사전학습의 7B 스케일 확장과 zero-shot 일반화가 핵심 기술이다. Interspeech 2026 MLC-SLM Challenge(21개 언어)도 다국어 대화 음성의 통합 평가 프레임워크를 제시했다.

### 3. 코덱 기반 Speech Representation의 새 패러다임
Codec2Vec(이산 코덱 토큰만으로 SSL), CleanCodec(지각적 가이드 선택적 인코딩), F3-Tokenizer(이해+생성 통합), MOSS-Audio-Tokenizer(1.6B 스케일 코덱) 등에서 보듯, 뉴럴 오디오 코덱이 단순 압축 도구를 넘어 **speech representation learning의 핵심 프레임워크**로 진화하고 있다. 특히 이산 토큰 기반 SSL과 이해-생성 통합 토크나이저가 주요 연구 흐름이다.

### 4. 텍스트 추론 능력 유지 문제
SpeechLLM에 음성 모달리티를 추가할 때 발생하는 "인지 퇴화" 문제를 해결하기 위한 다양한 접근(MoE 아키텍처, 공동 학습 전략, 토큰 스키마 설계)이 활발히 연구되고 있다. JoyAI-Talker(MATH 94.62%), LWS(쓰기-말하기 일관성 92.6%) 등이 이 문제에 대한 유의미한 진전을 보였다.

### 5. 다화자 환경의 엔드투엔드 통합
SpeakerLM, Adapting DiCoW, MLC-SLM Challenge 참가 시스템들에서 보듯, 화자 분리와 음성 인식의 엔드투엔드 통합이 LLM 백본 위에서 이루어지고 있으며, 실제 회의·대화 데이터 기반의 평가가 확대되고 있다.
