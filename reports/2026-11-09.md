## 1. ASR (Automatic Speech Recognition)

### 1-1. Confucius4-R2T2: A Stable-Prefix Streaming ASR Model for Real Real-Time Transcription

**[Confucius4-R2T2: A Stable-Prefix Streaming ASR Model for Real Real-Time Transcription] (NetEase Youdao, 2026-11)** — arxiv preprint

- https://arxiv.org/abs/2611.06043
- **기존 문제**: 스트리밍 ASR 모델은 실시간 전사 시 이미 출력된 텍스트를 반복적으로 수정(revision)해야 하는 문제가 있어, 라이브 자막이나 음성 에이전트에 적합하지 않았음. 특히 Qwen3-ASR 같은 full-context 모델은 높은 정확도를 보이지만 160ms 청크 단위 스트리밍에서는 WER이 22.30%까지 급격히 하락함
- **기존 방법**: 기존 스트리밍 ASR은 고정 청크 크기에서 동작하며, 디코딩 후 텍스트를 반복 수정하거나, 별도의 endpointing 모듈로 발화 종료를 감지하는 방식. Whisper 기반 모델은 autoregressive 디코딩의 지연 시간 문제가 있었음
- **제안 방법**: Longest Stable Prefix (LSP) 학습 기법을 제안. Qwen3-ASR-1.7B를 기반으로, 각 오디오 청크(80ms~2초)마다 충분한 문맥이 확보된 토큰만 확정(commit)하고 불확실한 후행 토큰은 대기 상태로 유지하는 append-only 메커니즘을 학습. 학습 데이터는 stable prefix, forced time alignment, token-level audio segmentation을 결합하여 구성
- **핵심 차별점**: 한번 출력된 텍스트를 절대 수정하지 않는(append-only) 스트리밍 ASR을 달성. unfixed_token_num 파라미터로 대기 토큰 수를 제어하여 정확도-지연 시간 트레이드오프를 조절 가능
- **실험 결과**: LibriSpeech test-clean에서 160ms 청크 기준 WER 2.13% 달성 (Qwen3-ASR base 160ms: 22.30%, Nemotron: 3.71%). 평균 인식 지연 200~600ms로 오프라인 ASR에 근접한 정확도 유지 (자체 보고 수치)
- **우리 연구 관련도**: ★☆☆ — 스트리밍 ASR 최적화 연구로, prediction-free SSL이나 temporal contrastive learning과는 직접적 관련 낮음. 다만 token-level segmentation 학습 방식이 speech representation의 시간 정렬 연구에 참고 가능

### 1-2. Neural Multichannel Distant Speaker Diarization and Source Separation with Beta Speaker Activity Prior

**[Neural Multichannel Distant Speaker Diarization and Source Separation with Beta Speaker Activity Prior] (Sicheng Mao et al. — Telecom Paris / SJTU, 2026-08-21)** — arxiv preprint

- https://arxiv.org/abs/2608.28661
- **기존 문제**: 원거리 다채널 환경에서 화자 분리(diarization)와 음원 분리(source separation)를 동시에 수행하는 것은 어려운 과제. 기존 neural FCASA 프레임워크는 주로 분리 성능에 초점을 맞추어 화자 활동 패턴의 사전 지식을 충분히 활용하지 못함
- **기존 방법**: Neural FCASA (Frequency-domain Channel-Attention-based Source Activity)가 다채널 분리와 다이어리제이션을 공동 학습하는 대표적 접근법. 그러나 화자 활동 확률에 대한 명시적 사전 분포를 두지 않아 대화 역학(conversational dynamics)을 반영하지 못함
- **제안 방법**: 화자 활동(speaker activity)에 대해 Beta 분포 사전(prior)을 도입. Beta 분포는 [0,1] 구간의 확률값에 적합하고 Bernoulli 우도에 대한 켤레 사전(conjugate prior)이므로 다루기 쉬운 variational 추론이 가능. 이 사전은 화자 행동 및 상호작용 패턴과 같은 대화 역학을 포착
- **핵심 차별점**: 화자 활동에 대한 명시적 확률적 사전을 neural diarization에 도입한 최초 시도. Conjugate prior의 수학적 편리성으로 학습 안정성 향상
- **실험 결과**: AMI 데이터셋에서 DER 기준 최소 3% (상대적 16%) 이상 개선 보고
- **우리 연구 관련도**: ★☆☆ — Diarization 연구로 직접적 관련은 낮으나, probabilistic prior를 neural speech model에 통합하는 방법론이 VQ 기반 representation의 사전 분포 설계에 간접 참고 가능

### 1-3. Clean-Anchored Excess-Emission Control for CTC Adaptation Under Competing Speech

**[Clean-Anchored Excess-Emission Control for CTC Adaptation Under Competing Speech] (저자 미확인, 2026-11)** — arxiv preprint

- https://arxiv.org/abs/2611.03900
- **기존 문제**: CTC 기반 ASR 모델은 경쟁 음성(competing speech) 환경에서 성능이 크게 저하됨. 배경에 다른 화자의 음성이 존재할 때 불필요한 토큰을 과다 출력(excess emission)하는 문제 발생
- **기존 방법**: 기존 CTC adaptation 방법들은 잡음 환경 적응에 초점을 맞추었으나, 경쟁 음성이라는 특수한 간섭 유형에 대한 체계적 대응이 부족. 일반적 도메인 적응이나 multi-condition training이 주요 접근법이었음
- **제안 방법**: Clean anchor를 기준으로 CTC의 과다 출력(excess emission)을 제어하는 적응 기법 제안. 깨끗한 음성 조건에서의 출력 분포를 앵커로 활용하여 경쟁 음성 환경에서의 불필요한 토큰 생성을 억제
- **핵심 차별점**: CTC의 excess emission 문제를 경쟁 음성 환경에 특화하여 해결하는 새로운 관점 제시
- **실험 결과**: LibriSpeech 음성 간섭 조건에서 WER 45.198% → 44.323%로 소폭 개선
- **우리 연구 관련도**: ★★☆ — CTC 출력 분포 제어 기법이 prediction-free SSL에서의 토큰 출력 제어와 방법론적 유사성이 있을 수 있음

## 2. SpeechLLM (Speech Language Model)

### 2-1. When Does a Speech Model Know to Hand Off? Reading Competence from Hidden States for Real-Time Escalation

**[When Does a Speech Model Know to Hand Off? Reading Competence from Hidden States for Real-Time Escalation] (저자 미확인, 2026-11)** — NeurIPS 2026 accepted

- https://arxiv.org/abs/2611.01639
- **기존 문제**: 로컬 full-duplex 음성 모델은 실시간 대화를 유지할 수 있지만 복잡한 질문에 대한 정확도가 낮음. 반면 대형 전문가 모델은 정확하지만 응답 지연이 큼. 언제 로컬 모델이 처리하고 언제 전문가에게 넘길지(escalation) 판단하는 것이 핵심 과제
- **기존 방법**: 기존 접근법은 별도 언어 모델 패스를 추가하거나, 전체 시스템을 재학습하는 방식. 또는 항상 전문가 모델에 의존하여 높은 지연 시간 발생
- **제안 방법**: MiniCPM-o 4.5 (full-duplex omni-modal 모델)를 동결(freeze)한 상태에서, 답변 시작(answer-onset) 시점의 hidden state에 경량 readout probe를 학습. 별도의 언어 모델 패스나 duplex 재학습 없이 로컬 모델의 자체 능력 한계를 판단. 한계 초과 시 gpt-5.5 + web search를 전문가로 escalation
- **핵심 차별점**: 음성 fine-tuning과 full-duplex 학습을 거친 모델에서도 hidden state에 자기 능력 판단 신호가 보존됨을 최초 확인. 추가 학습 없이 추론 시점에서 경량 probe만으로 escalation 결정
- **실험 결과**: 240개 내부 벤치마크에서 선택적 전문가 위임(selective handoff)으로 비가중 답변 정확도 40.8% → 62.9% 향상. 첫 답변 오디오까지 평균 대기 시간: 적극적 위임 시 6.10초 vs 항상 위임 시 9.43초
- **우리 연구 관련도**: ★★☆ — Hidden state에서 모델 능력을 읽는 probing 기법이 speech SSL representation의 정보 분석 관점에서 참고 가능. Speech foundation model의 layer별 정보 인코딩 연구와 방법론적 연결점 존재

### 2-2. Qwen-Audio-Agent Technical Report

**[Qwen-Audio-Agent Technical Report] (Chong Deng, Yunjie Ji, Yuxiang Kong et al. — Alibaba Qwen Team, 2026-09-21)** — arxiv preprint

- https://arxiv.org/abs/2609.25195
- **기존 문제**: 음성 에이전트가 실시간 대화를 유지하면서 동시에 복잡한 도구 호출(tool call)이나 백그라운드 작업을 수행하기 어려움. 직접 도구 호출 시 대화 흐름이 중단되고, 모든 작업을 위임하면 비효율적
- **기존 방법**: 기존 음성 에이전트는 단일 모델로 대화와 도구 호출을 모두 처리하거나, 파이프라인 방식으로 ASR → LLM → TTS를 순차 처리. 대화 유지와 작업 수행 간의 트레이드오프 존재
- **제안 방법**: Frontend-Backend 이중 에이전트 아키텍처 제안. Frontend Agent(Qwen Audio 3.0 Realtime Plus)가 실시간 full-duplex 대화를 처리하며, 직접 도구 호출과 위임(delegation) 중 선택. Backend Agent(qwen3.8-max)가 위임된 복잡한 작업을 별도 컨텍스트에서 수행. Agent Client Protocol, Agent2Agent 등 다양한 백엔드 어댑터 지원
- **핵심 차별점**: 대화 유지와 복잡한 작업 처리를 구조적으로 분리하여 두 목표를 동시 달성. 혼합 실행(mixed execution) 전략으로 간단한 도구는 직접 호출, 복잡한 작업은 위임
- **실험 결과**: 134개 케이스 내부 cockpit 벤치마크에서 혼합 실행(mixed) 91.04% 작업 성공률 달성 (직접 전용 72.39%, 위임 전용 80.60%)
- **우리 연구 관련도**: ★☆☆ — 음성 에이전트 시스템 아키텍처 연구로, speech representation 연구와 직접적 관련 낮음. 다만 음성 이해 기반 의사결정 파이프라인이 speech foundation model의 실용적 적용 방향 참고

### 2-3. Thinking While Speaking: Inference-Time Knowledge Transfer for Responsive and Intelligent Conversational Voice Agents

**[Thinking While Speaking: Inference-Time Knowledge Transfer for Responsive and Intelligent Conversational Voice Agents] (Vidya Srinivas, Zachary Englhardt, Vikram Iyer, Shwetak Patel — UW Seattle, 2025-11-10, v3 revised 2026-07-01)** — EMNLP 2026 Findings accepted

- https://arxiv.org/abs/2511.07397
- **기존 문제**: 음성 에이전트에서 응답성(responsiveness)과 지능(intelligence) 사이의 근본적 트레이드오프 존재. 추론, 검색, 도구 사용이 가능한 대형 foundation model은 높은 정확도를 보이지만 응답 지연이 큼. 소형 실시간 모델은 빠르지만 복잡한 작업 처리 불가
- **기존 방법**: 소형 모델과 대형 모델을 순차적으로 사용하거나, 모델 증류(distillation)를 통해 소형 모델의 성능을 높이는 방식. 그러나 순차 방식은 지연이 누적되고, 증류는 오프라인 학습 필요
- **제안 방법**: ConvFill이라는 추론 시점(inference-time) 지식 전달 시스템 제안. 소형 모델이 즉시 응답을 시작하면서 동시에 대형 모델(frontier reasoner)이 병렬로 추론. 대형 모델의 결과를 실시간으로 소형 모델의 대화에 주입하여 밀리초 수준의 첫 응답 시간(time-to-first-response)을 유지하면서 정확도 격차를 좁힘
- **핵심 차별점**: 오프라인 학습 없이 추론 시점에서만 대형-소형 모델 간 지식 전달을 수행. 대화 흐름을 중단하지 않으면서 점진적으로 응답 품질 향상
- **실험 결과**: Frontier reasoner 대비 6.3% 이내의 정확도 차이를 유지하면서 밀리초 수준의 첫 응답 시간 달성
- **우리 연구 관련도**: ★☆☆ — 추론 시점 지식 전달 기법으로 speech representation 연구와 직접 관련 낮음. 다만 실시간 음성 시스템에서의 representation 활용 효율성 관점에서 참고 가치 있음

## 3. Speech Foundation Model

### 3-1. TTSonic: A Unified Framework for Composable and Controllable Speech Generation

**[TTSonic: A Unified Framework for Composable and Controllable Speech Generation] (저자 미확인, 2026-11)** — arxiv preprint

- https://arxiv.org/abs/2611.04282
- **기존 문제**: 기존 음성 생성 시스템에서 의미(semantic) 정보와 음향(acoustic) 정보가 토크나이저 내부에서 얽혀(entangled) 있어, 언어적 내용과 화자 스타일을 독립적으로 제어하기 어려움
- **기존 방법**: SpeechTokenizer, DSA-Tokenizer 등이 semantic-acoustic 분리를 시도했으나, 대부분 RVQ 레이어별 역할 분리에 의존하거나 별도의 SSL 모델을 필요로 함
- **제안 방법**: ASR 지도 학습(ASR-supervised semantic learning)과 재구성 기반 생성적 정제(reconstruction-guided generative refinement)를 통한 semantic-acoustic 분리형 음성 토크나이저 개발. Text-to-semantic 언어 모델과 acoustic flow-matching 모델을 결합한 통합 프레임워크
- **핵심 차별점**: ASR 지도 학습으로 semantic 토큰의 언어적 충실도를 보장하면서, generative refinement로 acoustic 토큰의 재구성 품질을 높이는 이중 최적화 전략
- **실험 결과**: 검색 시점에서 구체적 벤치마크 수치 미확인 (논문이 매우 최근 게시되어 상세 정보 미공개)
- **우리 연구 관련도**: ★★★ — Semantic-acoustic 분리형 토크나이저는 VQ-based representation 연구의 핵심 주제와 직결. ASR-supervised semantic learning은 prediction target 설계와 관련되며, speech SSL 토큰의 의미-음향 분리 방법론에 직접 참고 가능

### 3-2. Benchmarking Speaker Embedders in the Sub-Second Regime for Real-Time Voice AI Agents

**[Benchmarking Speaker Embedders in the Sub-Second Regime for Real-Time Voice AI Agents] (저자 미확인, 2026-11)** — arxiv preprint

- https://arxiv.org/abs/2611.09516
- **기존 문제**: 실시간 음성 AI 에이전트는 1초 미만의 극초단 음성 세그먼트에서 화자를 식별해야 하지만, 기존 화자 임베딩 모델은 주로 수 초 이상의 발화를 기준으로 평가되어 sub-second 성능이 충분히 벤치마킹되지 않음. 배경 음성이 존재할 때 하류 ASR에서 false acceptance 문제 발생
- **기존 방법**: ECAPA-TDNN, ResNet 기반 화자 임베딩이 주류이나, 평가 프로토콜이 3초 이상 발화 중심. SdSV Challenge 2020 등 단시간 화자 검증 벤치마크가 있으나 최신 모델과 sub-second 극단 조건을 포괄하지 못함
- **제안 방법**: 다양한 최신 화자 임베딩 모델을 sub-second(1초 미만) 조건에서 체계적으로 벤치마킹. 실시간 음성 AI 에이전트 시나리오에 특화된 평가 프로토콜 제안
- **핵심 차별점**: 실시간 음성 에이전트의 실제 운용 조건(sub-second 지연 예산)에서의 화자 임베딩 성능을 최초로 체계적 평가
- **실험 결과**: 검색 시점에서 구체적 벤치마크 수치 미확인 (논문이 매우 최근 게시되어 상세 정보 미공개)
