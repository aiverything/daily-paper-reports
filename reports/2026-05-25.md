## 1. ASR (End-to-End, Multilingual, Contextual Biasing)

### **JSPG: Dynamic Dictionary Filtering via Joint Semantic-Pinyin-Glyph Retrieval for Chinese Contextual ASR (Shilin Zhou et al., 2026-05)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2605.16896
- 기존 문제: 중국어 Contextual ASR에서 대규모 키워드 사전을 사용할 경우, 불필요한 후보가 노이즈로 작용하여 인식 정확도가 저하됨. 기존 의미 기반(semantic) 텍스트 검색기로 필터링하려 해도, 베이스 ASR 모델이 동음이의어(homophonic) 오류를 생성하면 음운은 보존되나 의미가 왜곡되어 검색기가 올바른 키워드를 찾지 못함.
- 기존 방법: 베이스 ASR의 1차 가설을 기반으로 의미적 유사도(semantic retrieval)로 사전 필터링하는 2단계 파이프라인이 주류. 그러나 중국어에서는 동음이의 오류가 의미를 심하게 왜곡하여 semantic retriever의 실패율이 높음.
- 제안 방법: Semantic, Pinyin, Glyph 세 가지 특징을 공동으로 활용하는 JSPG 필터링 프레임워크. Pinyin(병음)은 음운 유사성 기반으로 대상 키워드를 효과적으로 검색하고, Glyph(자형)는 중국어 고유의 일대일 문자-자형 대응 관계를 활용하여 병음만으로는 구분 불가능한 다수의 동음이의어를 구조적으로 필터링.
- 핵심 차별점: 동일 발음의 다수 한자를 자형(glyph) 구조로 변별하는 접근이 핵심. 음운·의미·자형 세 축의 공동 검색으로 중국어 특유의 동음이의 문제를 직접 해결.
- 실험 결과: 기존 semantic-only 필터링 대비 키워드 리콜과 ASR 정확도 모두 유의미한 향상. 대규모 키워드 사전(수만 개)에서도 노이즈 없는 정밀 필터링 달성.
- 우리 연구 관련도: ★☆☆ (Contextual ASR 후처리 기법으로, speech SSL이나 VQ-based representation과 직접 관련도는 낮음)

### **Sometin Beta Pass Notin (SBPN): Improving Multilingual ASR for Nigerian Languages via Knowledge Distillation (Sewade Ogun, 2026-05)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2605.17710
- 기존 문제: 현대 다국어 ASR 시스템이 나이지리아 언어들을 지원하지만, 고자원 언어(영어, 프랑스어) 대비 성능이 크게 뒤처짐. 나이지리아 언어는 극심한 데이터 부족, 비일관적 정서법(orthography), 성조 부호(tonal diacritics), 다양한 억양, 빈번한 코드스위칭, 지역 고유명사 등 고유한 모델링 난제를 가짐.
- 기존 방법: 각 언어별 개별 단일언어(monolingual) 모델 학습이 주류이나, 데이터 부족과 언어 간 전이 학습 부재로 성능이 제한적. 기존 다국어 모델(Whisper 등)은 나이지리아 언어에 대한 학습 데이터가 부족.
- 제안 방법: 2단계 지식 증류 프레임워크 — (1단계) 기존 단일언어 모델을 교사(teacher)로, 언어별 N-gram 언어 모델로 조건화된 student-teacher 지식 증류 수행, (2단계) 의사 레이블링(pseudo-labelling) 데이터를 활용한 반복적 자기 개선(iterative self-improvement)으로 정확도를 추가 향상. Yorùbá, Hausa, Igbo, Nigerian Pidgin, Nigerian English 5개 언어를 커버하는 SBPN-Base(120M)와 SBPN-Large(600M) 두 모델 공개.
- 핵심 차별점: 단일언어 전문 모델의 지식을 다국어 모델로 증류하면서 언어별 N-gram LM으로 정밀도를 보강하는 2단계 접근. 의사 레이블 기반 자기 개선으로 저자원 환경의 데이터 부족을 보완.
- 실험 결과: 단일언어 베이스라인 대비 평균 WER 29% 상대 감소. Common Voice 및 FLEURS 벤치마크에서 기존 SOTA 다국어 모델을 전 언어에 걸쳐 능가.
- 우리 연구 관련도: ★☆☆ (저자원 다국어 ASR 지식 증류 기법으로, speech SSL과 직접 관련도는 낮으나, 저자원 환경에서의 표현 전이 방법론이 간접적 참고 가능)

### **Benchmarking Commercial ASR Systems on Code-Switching Speech: Arabic, Persian, and German (Sajjad Abdoli, Ghassan Al-Sumaidaee, Clayton W. Taylor, Ahmad ElShiekh, Ahmed Rashad, 2026-05)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2605.19069
- 기존 문제: 코드스위칭(code-switching) — 한 발화 내에서 두 언어를 자연스럽게 번갈아 사용하는 현상 — 은 ASR의 가장 까다롭고 과소 연구된 조건 중 하나. 기존 상용 ASR 벤치마크는 깨끗한 단일언어 음성만을 평가하며, 단일 WER 수치만 보고하여 실제 다국어 환경 성능에 대한 정보가 부족.
- 기존 방법: 상용 ASR 시스템의 성능 평가가 단일언어 환경에 편중. 코드스위칭 환경에서의 체계적 벤치마크가 부재하여, 실배포 시 다국어 사용자 경험에 대한 예측이 어려움.
- 제안 방법: 5개 상용 ASR 제공업체를 4개 언어 쌍(이집트 아랍어-영어, 사우디 아랍어(나즈디/히자지)-영어, 페르시아어-영어, 독일어-영어)에 걸쳐 평가하는 체계적 벤치마크 구축. 각 데이터셋은 300개 샘플로 구성되며, 2단계 파이프라인(5가지 구조적 코드스위칭 신호 기반 휴리스틱 필터 → GPT-4o/Gemini 1.5 Pro 앙상블 스코어링)으로 코드스위칭 발화를 선별.
- 핵심 차별점: 코드스위칭 ASR에 특화된 최초의 상용 시스템 벤치마크. 다중 언어 쌍과 다양한 아랍어 방언(이집트, 나즈디, 히자지)을 포괄하는 체계적 평가 설계.
- 실험 결과: 상용 ASR 시스템 간 코드스위칭 성능 격차가 크게 존재함을 실증. 언어 쌍별로 시스템 순위가 달라지며, 단일언어 성능이 코드스위칭 성능을 예측하지 못하는 경우가 빈번.
- 우리 연구 관련도: ★☆☆ (상용 ASR 벤치마크 연구로, speech SSL과 직접 관련도는 낮으나, 다국어 코드스위칭 환경에서의 표현 품질 평가 관점에서 간접 참고 가능)

## 2. SpeechLLM (Speech-Language Model, Audio Understanding with LLM)

### **PlanRAG-Audio: Planning and Retrieval Augmented Generation for Long-form Audio Understanding (Masao Someki, Chien-yu Huang, Siddhant Arora, Samuele Cornell, Markus Müller, Nathan Susanj, Rupak V Swaminathan, Grant P Strimel, Jing Liu, Shinji Watanabe — CMU LTI, Amazon AGI, 2026-05)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2605.20414
- 기존 문제: Large Audio Language Models(LALMs)이 장시간 오디오를 처리할 때, 극단적으로 긴 시퀀스 길이와 시간에 분산된 이질적 음향 단서(발화 내용, 화자 정체, 감정, 음향 이벤트 등)에 대한 추론이 동시에 요구됨. 기존 LALMs은 전체 녹음을 직접 입력으로 처리하여 컨텍스트 윈도우 한계에 부딪히거나 성능이 저하됨.
- 기존 방법: 전체 오디오를 LALM에 직접 입력하는 방식이 표준. 오디오 길이가 증가할수록 추론 비용이 선형적으로 증가하고, 장시간 녹음에서의 정확도가 급격히 저하. 기존 RAG 접근은 텍스트 중심이며, 멀티모달 오디오 특성을 충분히 활용하지 못함.
- 제안 방법: Planning 기반 검색 증강 생성 프레임워크 PlanRAG-Audio. (1) 질의(query)에 대해 필요한 모달리티와 시간 구간을 명시적으로 계획(planning), (2) 구조화된 텍스트·오디오 데이터베이스에서 질의 관련 정보만 선택적으로 검색(retrieval). 각 선택 스트림에 대해 스트림별 CTE(Common Table Expressions)로 컴파일하고, 하이브리드 LLM–규칙 기반 SQL 생성기로 통합 쿼리를 구성.
- 핵심 차별점: 추론 비용을 원시 오디오 길이에서 분리(decouple)하여, 오디오 길이 증가에도 성능이 안정적으로 유지. 모달리티별 계획(planning)으로 텍스트와 오디오 스트림을 선택적으로 활용하는 최초의 오디오 RAG 프레임워크.
- 실험 결과: 다양한 음성/오디오 검색 태스크에서 PlanRAG-Audio가 추론 정확도를 향상시키고, 오디오 길이 증가에 따른 성능 저하를 안정화. 직접 입력 대비 대폭적인 효율성 개선.
- 우리 연구 관련도: ★★☆ (오디오 인코더가 생성한 speech representation을 구조화된 데이터베이스로 변환하여 활용하는 프레임워크. Speech SSL 모델 출력의 실용적 활용 관점에서 참고 가능. 오디오 표현의 모달리티별 계획 활용이 representation 품질 평가에 시사점 제공)

### **Analyzing Error Propagation in Korean Spoken QA with ASR-LLM Cascades (Donghyuk Jung, Youngwon Choi, 2026-05)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2605.17443
- 기존 문제: ASR-LLM 캐스케이드 파이프라인에서 ASR 오류가 하류 LLM의 질의응답(QA) 성능에 어떻게 전파되는지에 대한 체계적 분석이 부족. 특히 한국어처럼 교착어(agglutinative) 특성이 강한 언어에서는 단일 음절 오류가 의미 전체를 변질시킬 수 있으나, 기존 WER/CER 같은 ASR 지표가 이러한 의미적 실패를 포착하지 못함.
- 기존 방법: ASR과 LLM을 순차적으로 연결하는 캐스케이드 파이프라인이 표준이나, ASR 오류의 하류 영향에 대한 정량적 분석이 부족. 기존 연구는 주로 영어 중심이며, 한국어의 형태소 특성에 따른 오류 전파 패턴이 미분석.
- 제안 방법: 한국어 음성 질의응답(Spoken QA)에서 ASR 오류가 LLM 캐스케이드를 통해 어떻게 전파되는지 체계적으로 분석. (1) 다양한 LLM 백본에 걸쳐 ASR 오류로 인한 상대적 하류 성능 저하가 일관적임을 확인, (2) 단일 한글 음절 ASR 오류가 고유의 의미적 실패 채널(semantic-failure channel)로 작용하여, 최소한의 전사 차이에도 불구하고 정답이 완전히 소실되는 현상을 식별.
- 핵심 차별점: 한국어 교착어 특성에 기인한 단일 음절 오류의 치명적 의미 전파를 최초로 정량화. 캐스케이드 성능 저하가 LLM 절대 성능과 무관하게 ASR 단계의 정보 손실에 비례함을 실증.
- 실험 결과: 서로 다른 절대 성능의 LLM에서도 ASR 오류에 의한 상대적 성능 저하가 일관적이며, 대형 오디오 언어 모델(LALM)이 동일 언어 백본의 ASR-LLM 파이프라인을 능가.
- 우리 연구 관련도: ★☆☆ (ASR-LLM 캐스케이드 오류 분석 연구로, speech SSL과 직접 관련도는 낮으나, 음성 표현의 의미적 충실도 평가 관점에서 간접 참고 가능)

## 3. Speech Foundation Model (Speech Tokenizer, Representation Learning, Audio Codec)

### **SemaVoice: Semantic-Aware Continuous Autoregressive Speech Synthesis (Huimeng Wang, Hui Lu, Jiajun Deng, Haoning Xu, Youjun Chen, Xueyuan Chen, Zhaoqing Li, Shuhai Peng, Shiyin Kang, Xunying Liu — CUHK, Tsinghua University, SenseTime Research, 2026-05)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2605.16964
- 기존 문제: 연속 자기회귀(continuous autoregressive) 음성 합성이 유망한 zero-shot TTS 방향으로 부상하였으나, 기존 방법은 의미-운율 모델링(semantic-prosodic modeling)과 재구성 기반 연속 음성 표현(reconstruction-driven continuous speech representation) 간의 근본적 불일치(mismatch)를 겪고 있음. 이 불일치는 TTS 모델이 고수준 의미 일관성(semantic coherence) 대신 저수준 음향 텍스처(acoustic textures)에 과도하게 집중하게 하여, 자기회귀 생성에서의 오류 누적을 심화.
- 기존 방법: 기존 연속 자기회귀 TTS는 오디오 코덱의 연속 잠재 표현을 자기회귀적으로 예측. 그러나 코덱 표현이 재구성에 최적화되어 있어 의미적 구조를 반영하지 못하고, 자기회귀 예측 시 로컬 음향 텍스처에 갇히는 문제가 발생.
- 제안 방법: Speech Foundation Model(SFM) 가이드 정렬(alignment) 메커니즘을 도입한 SemaVoice. SFM의 표현을 활용하여 연속 음성 표현을 정제(refine)하여 로컬 의미 일관성(local semantic consistency)과 글로벌 구조적 관계(global structural relationships)를 동시에 포착. 이 정제된 표현이 자기회귀 프레임워크 내의 패치 단위 확산 헤드(patch-wise diffusion head)를 조건화하여 고품질 음성 합성을 수행.
- 핵심 차별점: Speech Foundation Model의 표현을 코덱 연속 표현에 정렬하여 의미-음향 불일치를 직접 해소. 기존 코덱 기반 TTS가 놓치는 고수준 의미 구조를 SFM에서 보충받는 접근.
- 실험 결과: Seed-TTS 벤치마크에서 영어 WER 1.71% 달성. 객관적·주관적 평가 모두에서 기존 오픈소스 SOTA 시스템과 동등 이상의 성능.
- 우리 연구 관련도: ★★★ (Speech Foundation Model의 표현을 활용하여 연속 음성 표현의 의미적 품질을 향상시키는 핵심 연구. SFM-guided alignment이 prediction-free SSL 표현의 의미적 구조 보존 능력을 검증하는 데 직접 참고 가능. 연속 표현과 이산 표현 간 의미 정렬이 VQ-based representation 연구에도 시사점 제공)

### **AffectCodec: Emotion-Preserving Neural Speech Codec for Expressive Speech Modeling (Jiacheng Shi et al., 2026-05)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2605.11098
- 기존 문제: 뉴럴 음성 코덱이 Speech LLM을 위한 이산 표현을 제공하나, 양자화 과정에서 감정적 단서(emotional cues)가 손상됨. 기존 코덱은 음향 재구성(acoustic reconstruction)에 최적화되어 있어 표현(representation) 수준에서의 감정 표현력(emotion expressiveness)이 불충분하게 모델링됨.
- 기존 방법: EnCodec, SoundStream, DAC 등 기존 뉴럴 오디오 코덱은 파형 재구성 품질을 주 목적 함수로 학습. 감정 정보는 부수적으로만 보존되며, 명시적인 감정 모델링이 부재. 이로 인해 감정적 음성 합성에서 표현력이 저하.
- 제안 방법: 감정 가이드 뉴럴 음성 코덱 AffectCodec. 세 가지 핵심 모듈을 결합: (1) Emotion-Semantic Guided Latent Modulation — 감정과 의미 정보를 잠재 공간에서 직접 조절, (2) Relation-Preserving Emotional-Semantic Distillation — 감정-의미 간 관계를 보존하는 증류, (3) Emotion-Weighted Semantic Alignment — 감정적으로 두드러진 단서를 압축 시에도 보존하기 위한 가중 정렬. 이 세 모듈이 협력하여 압축 하에서도 감정적으로 중요한 신호를 유지.
- 핵심 차별점: 코덱 학습 단계에서 감정 정보를 명시적으로 보존하는 최초의 프레임워크. 재구성 품질(content accuracy)을 희생하지 않으면서 감정 일관성(emotion consistency)과 지각 품질(perceptual quality)을 동시에 향상.
- 실험 결과: 음성 재구성, 감정 인식, 하류 TTS 생성 전반에서 개선. 감정 유사도(emotion similarity) 0.87→0.90 향상, 오디오 품질 점수 86.27→88.31 향상.
- 우리 연구 관련도: ★★☆ (VQ 기반 이산 표현에서 특정 속성(감정)을 명시적으로 보존하는 코덱 설계. VQ-based representation에서의 정보 보존 전략이 speech SSL의 표현 설계에 참고 가능. 감정-의미 증류 방식이 disentangled representation learning과 관련)

### **Say More with Less: Variable-Frame-Rate Speech Tokenization via Adaptive Clustering and Implicit Duration Coding (Rui-Chen Zheng, Wenrui Liu, Hui-Peng Du, Qinglin Zhang, Chong Deng, Qian Chen, Wen Wang, Yang Ai, Zhen-Hua Ling, 2025-09)** — AAAI 2026 accepted (Oral)
- arxiv URL: https://arxiv.org/abs/2509.04685
- 기존 문제: 대부분의 음성 토크나이저가 고정 프레임 레이트(25-75Hz)로 동작하여, 무음(silence)이나 지속 모음 구간에도 동일한 토큰 수를 할당. 이는 불필요한 토큰 중복을 유발하고, 하류 음성 언어 모델의 시퀀스 길이를 불필요하게 증가시켜 학습/추론 비용을 높임. 기존 가변 레이트 접근은 보조 지속시간 예측기(duration predictor)에 의존하여 토큰화와 지속시간 모델링이 분리됨.
- 기존 방법: 고정 프레임 레이트(40Hz, 50Hz 등) 기반 음성 토크나이저가 표준. HuBERT k-means, EnCodec, SoundStream 등 모두 고정 레이트로 동작. 일부 가변 레이트 접근(CTC 기반 연속 동일 토큰 병합 등)이 존재하나, 정보 손실이 크거나 보조 모델 의존도가 높음.
- 제안 방법: VARSTok(VAriable-frame-Rate Speech Tokenizer) — 두 가지 핵심 혁신: (1) 시간 인식 밀도 피크 클러스터링(temporal-aware density peak clustering) — 로컬 특징 유사도에 기반하여 음성을 가변 길이 단위로 적응적 분할, (2) 암묵적 지속시간 코딩(implicit duration coding) — 내용(content)과 시간 범위(temporal span)를 단일 토큰 인덱스에 동시 임베딩하여 보조 지속시간 예측기를 제거.
- 핵심 차별점: 완전 동적(fully dynamic) 가변 프레임 레이트 음향 토크나이저를 하류 음성 언어 모델에 원활히 통합한 최초의 연구. 토큰 정체성과 지속시간을 단일 인덱스에 통합하는 암묵적 코딩이 핵심.
- 실험 결과: 40Hz 고정 프레임 레이트 베이스라인 대비 최대 23% 적은 토큰으로 우수한 재구성 자연스러움(naturalness) 달성. Zero-shot TTS에서 더 낮은 WER과 향상된 자연스러움을 기록.
- 우리 연구 관련도: ★★★ (가변 레이트 음성 토큰화는 VQ-based representation의 시간적 효율성 문제를 직접 다루는 핵심 연구. 밀도 피크 클러스터링 기반 적응적 분할이 temporal contrastive learning에서의 시간 해상도 설계에 직접 참고 가능. 암묵적 지속시간 코딩이 이산 표현의 정보 밀도를 높이는 새로운 방향을 제시)
