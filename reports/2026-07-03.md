## 1. ASR (Automatic Speech Recognition)

### 1-1. Beyond Words: Towards Effective Modeling of Non-Verbal Vocalizations in ASR

**[Beyond Words]** (Gene Yang, Haibin Wu et al., 2026.07) — arXiv preprint (Meta)

- arxiv URL: https://arxiv.org/abs/2607.01563
- **기존 문제:** 기존 ASR 시스템은 비언어적 발성(Non-Verbal Vocalizations, NV) — 웃음, 기침, 한숨 등 — 의 인식에 어려움을 겪는다. 특히 희귀 NV 범주에 대한 학습 데이터가 심각하게 부족하여, 모델이 이러한 발성을 무시하거나 오분류하는 문제가 있다.
- **기존 방법:** 기존 end-to-end ASR 모델은 텍스트 전사에 집중하며, NV를 별도 범주로 모델링하지 않거나 학습 데이터 불균형 문제를 해결하지 못했다.
- **제안 방법:** 세 가지 기법을 제안. (1) 커리큘럼 학습(curriculum learning) — 쉬운 NV 범주에서 어려운 범주로 점진적으로 학습, (2) 토큰 간 전이(inter-token transfer) — 풍부한 NV 범주의 지식을 희귀 범주로 전이, (3) 음성 변환 기반 데이터 증강(voice-conversion augmentation) — 희귀 NV 범주의 학습 데이터를 합성하여 데이터 불균형 완화.
- **핵심 차별점:** ASR에서 비언어적 발성을 체계적으로 모델링하는 최초의 본격적 연구. 데이터 희소성 문제를 세 가지 상호 보완적 기법으로 동시에 해결.
- **실험 결과:** 희귀 NV 범주에 대한 인식 성능이 크게 향상되었으며, 기존 ASR 모델의 텍스트 전사 정확도를 유지하면서 NV 인식 능력을 추가적으로 확보.
- **우리 연구 관련도:** ★☆☆ — ASR의 비언어적 발성 모델링이 주요 기여. 음성 표현이 NV 정보를 어떻게 인코딩하는지에 대한 관점에서 참고 가능하나, prediction-free SSL/VQ와의 직접적 연관은 제한적.

### 1-2. Preference-ASR: A Preference-Aware Test Set for Benchmarking ASR in the Era of Speech LLMs

**[Preference-ASR]** (Nithin Rao Koluguri, Lukas Meister, Aleksandr Karpov, Piotr Zelasko, Bhavin Raj, Jagadeesh Balam, Boris Ginsburg, 2026.06) — Interspeech 2026 accepted (NVIDIA)

- arxiv URL: https://arxiv.org/abs/2606.29534
- **기존 문제:** Speech LLM 시대에 ASR 시스템은 단순 전사를 넘어 사용자 선호도(preference)에 맞는 출력을 생성해야 하지만, 이를 체계적으로 평가하는 벤치마크가 부재했다. 텍스트 정규화, 고유명사, 비유창성(disfluency), 대소문자 처리 등에서 사용자 의도에 맞는 전사 형식을 요구하는 상황이 증가.
- **기존 방법:** 기존 ASR 벤치마크(LibriSpeech, CommonVoice 등)는 정답 전사와의 WER/CER 비교에 집중하며, 전사 형식의 선호도를 평가하는 메커니즘이 없었다.
- **제안 방법:** Preference-ASR — ASR 시스템의 선호도 따르기(preference-following) 능력을 평가하는 벤치마크 제안. 텍스트 정규화(숫자/약어 표기 방식), 고유명사(entity) 정확한 표기, 비유창성 처리(필러 워드 포함/제거), 대소문자 규칙 등 여러 차원에서 ASR이 사용자 지시에 따라 출력을 조정할 수 있는지 평가.
- **핵심 차별점:** Speech LLM 시대에 맞는 새로운 ASR 평가 패러다임 제안. 정확도뿐 아니라 출력 형식의 제어 가능성(controllability)을 측정하는 최초의 체계적 벤치마크.
- **실험 결과:** 주요 ASR 시스템 및 Speech LLM을 대상으로 선호도 따르기 능력을 평가. 대부분의 기존 시스템이 선호도 지시에 일관되게 대응하지 못하는 한계를 확인.
- **우리 연구 관련도:** ★☆☆ — ASR 평가 벤치마크 연구로, speech SSL/VQ 표현 학습과 직접 관련 낮음. 다만 Speech LLM의 제어 가능성 평가 관점에서 참고 가치 있음.

### 1-3. CTC-Seeded Token Edit Refinement for Non-Autoregressive Speech Recognition

**[CTC-Seeded Token Edit Refinement]** (Wanting Huang, Weiran Wang, 2026.06) — SLT 2026 (University of Iowa)

- arxiv URL: https://arxiv.org/abs/2606.28728
- **기존 문제:** 비자기회귀(NAR) ASR 모델은 병렬 디코딩으로 빠른 속도를 달성하지만, 자기회귀 모델 대비 정확도가 낮다. 특히 CTC 기반 초기 출력의 삽입/삭제/치환 오류를 효과적으로 교정하는 것이 과제이다.
- **기존 방법:** Mask-CTC는 저신뢰 CTC 토큰을 마스킹 후 재예측하는 방식으로 NAR 정제를 시도했으나, 토큰 수준의 편집(삽입/삭제)을 직접 모델링하지 못하는 한계가 있었다. Align-Refine 등 반복 정렬 방법도 존재하나 효율성이 제한적이었다.
- **제안 방법:** CTC 출력을 초기 시드(seed)로 활용하여, 토큰 수준의 편집 연산(삽입, 삭제, 치환)을 통해 반복적으로 전사를 정제하는 NAR ASR 프레임워크 제안.
- **핵심 차별점:** CTC의 빠른 초기 디코딩과 토큰 편집 기반 정제를 결합하여, NAR의 속도 이점을 유지하면서 AR 수준의 정확도에 근접. 편집 연산을 명시적으로 모델링하는 점이 기존 마스킹 기반 접근과 차별화.
- **실험 결과:** 구체적 수치는 논문 원문 참조 필요. 동일 저자의 관련 연구(Align-Consistency, Interspeech 2026)에서는 NAR ASR의 일관성 정규화를 통한 성능 개선을 보고.
- **우리 연구 관련도:** ★☆☆ — NAR ASR 디코딩 정제가 주요 기여. CTC 출력의 이산 토큰 편집은 이산 표현 처리 관점에서 참고 가능하나, speech SSL/VQ와의 직접적 연관은 제한적.

## 2. SpeechLLM (Speech Language Model)

### 2-1. CORTIS: Text-Only Adaptation of Spoken Language Models for Task-Oriented Voice Agents

**[CORTIS]** (Youngwon Choi, Hyeonyu Kim, Taeyoun Kwon, Donghyuk Jung, Myeongkyun Cho, 2026.06) — arXiv preprint (Maum AI / SNU / KAIST)

- arxiv URL: https://arxiv.org/abs/2606.21453
- **기존 문제:** 음성 언어 모델(SLM)을 태스크 지향 음성 에이전트(task-oriented voice agent)에 적용할 때, 구조화된 출력(API 호출, 슬롯 채우기 등)을 생성하기 위한 음성-타겟 쌍 학습 데이터를 대규모로 확보하기 어렵다.
- **기존 방법:** 기존 SLM 미세조정은 음성 입력과 대응하는 텍스트/구조화 출력 쌍이 필요하며, 이를 위해 대규모 음성-타겟 주석 데이터를 수집해야 한다. 텍스트 전용 LLM의 태스크 지향 능력을 SLM으로 전이하는 효율적 방법이 없었다.
- **제안 방법:** 텍스트 전용(text-only) 미세조정만으로 SLM이 음성 입력에 대해 구조화된 출력을 생성하도록 적응시키는 방법 제안. 음성-타겟 주석 없이 텍스트 데이터만으로 태스크 지향 능력을 학습하여, SLM의 음성 이해 능력과 텍스트 LLM의 구조화 출력 생성 능력을 결합.
- **핵심 차별점:** 음성-타겟 쌍 데이터 없이 텍스트만으로 SLM을 태스크 지향 에이전트로 적응시키는 최초의 접근. 데이터 수집 비용을 크게 절감하면서 실용적 음성 에이전트 구축 가능.
- **실험 결과:** 텍스트 전용 미세조정만으로도 음성 입력에 대해 구조화된 출력 생성 성능이 유의미하게 향상됨을 확인. 음성-타겟 쌍 학습 대비 경쟁적 성능을 달성.
- **우리 연구 관련도:** ★★☆ — SLM의 모달리티 간 전이 학습(텍스트→음성)은 음성 표현의 텍스트 정렬 특성을 활용하는 연구로, 음성 SSL 표현이 텍스트와 얼마나 잘 정렬되는지에 대한 시사점 제공.

### 2-2. ProsodyLM: Uncovering the Emerging Prosody Processing Capabilities in Speech Language Models

**[ProsodyLM]** (Kaizhi Qian, Xulin Fan et al., 2025.07) — arXiv preprint

- arxiv URL: https://arxiv.org/abs/2507.20091
- **기존 문제:** 기존 음성 언어 모델(SLM)이 운율(prosody)을 어떻게 처리하는지 체계적으로 이해되지 않았다. SLM이 음성 토큰을 통해 운율 정보를 학습하고 활용하는 능력이 명시적으로 분석된 바 없다.
- **기존 방법:** 기존 SLM은 음성 토큰(코덱 기반 또는 SSL 기반)으로 음성을 처리하지만, 이산 토큰이 연속적인 운율 정보(피치, 강세, 리듬, 억양 패턴)를 얼마나 효과적으로 보존하는지 불분명했다.
- **제안 방법:** 단어 수준 운율 토큰화(word-level prosody tokenization) 체계를 제안하여, SLM의 운율 처리 능력을 체계적으로 분석. 약 3만 시간의 오디오북 데이터로 사전학습된 SLM에서 운율 처리 능력이 자연 발생(emerging)함을 밝힘.
- **핵심 차별점:** SLM에서 운율 처리 능력의 창발(emergence)을 체계적으로 입증한 최초의 연구. 단어 수준 운율 토큰화 체계를 통해 이산 음성 표현과 연속 운율 특성 간의 관계를 정량적으로 분석.
- **실험 결과:** 약 3만 시간 오디오북 사전학습으로 SLM이 운율 패턴을 자발적으로 학습하는 것을 확인. 운율 토큰화가 SLM의 운율 인식 및 생성 능력 향상에 효과적임을 실증.
- **우리 연구 관련도:** ★★☆ — 이산 음성 토큰의 운율 정보 보존 능력 분석은 VQ 기반 표현 학습에서 어떤 음향 정보가 인코딩되는지 이해하는 데 직접적 참고 가치. speech tokenizer 설계의 운율 보존 관점에서 중요.

## 3. Speech Foundation Model

### 3-1. DTM-Codec: Dynamic Token Masking for VFR Speech Coding with Efficient Boundary Selection

**[DTM-Codec]** (Hoyeol Sohn, Juhan Nam, 2026.06) — Interspeech 2026 accepted (KAIST MAC Lab)

- arxiv URL: https://arxiv.org/abs/2606.29480
- **기존 문제:** 가변 프레임 레이트(Variable Frame Rate, VFR) 음성 코딩은 고정 프레임 레이트 대비 효율적이지만, 유지할 타임스텝에 대한 부가 정보(side information)를 전송해야 하는 오버헤드가 존재한다. 기존 VFR 방법들은 이 오버헤드를 고려하면 고정 프레임 레이트 대비 실질적 이득이 미미하다.
- **기존 방법:** 기존 VFR 코덱은 중요 프레임만 선택하여 전송하지만, 선택된 프레임 위치 정보의 전송 비용이 절감분을 상쇄했다. 또한 적응적 세그먼트 경계 선택에 높은 계산 비용이 소요되었다.
- **제안 방법:** 두 가지 핵심 기법 제안. (1) Dynamic Token Masking — 선택된 인코더 토큰은 유지하고, 나머지 위치를 학습된 \<MASK\> 임베딩으로 대체하여 위치 인식 디코딩 수행. 이진 유지 마스크(binary keep-mask)만 전송. (2) Path Length Equalization (PLE) — 선형 시간 복잡도의 새로운 경계 선택기로, 적은 계산 비용으로 균일하게 분포된 적응적 세그먼트를 생성.
- **핵심 차별점:** 부가 정보 전송 비용까지 포함한 엄밀한 동일 총 비트레이트(matched-total-bitrate) 프로토콜에서 고정 프레임 레이트 대비 실질적 이득을 달성. 선형 시간 경계 선택으로 VFR의 실용성 확보.
- **실험 결과:** 동일 총 비트레이트 조건에서 고정 프레임 레이트 베이스라인 대비 일관된 품질 향상을 달성. 부가 정보 오버헤드를 포함해도 VFR의 이점이 유지됨을 실증.
- **우리 연구 관련도:** ★★☆ — VFR 코딩에서의 동적 토큰 마스킹은 VQ 기반 음성 토크나이저의 프레임 레이트 최적화와 직접적으로 관련. 적응적 프레임 선택 전략은 speech tokenizer의 토큰 효율성 연구에 참고 가치.

### 3-2. BEST-RQ-2: Contextualize-Then-Predict, a Two-Step Approach for Self-Supervised Audio Representations

**[BEST-RQ-2]** (Ludovic K. Tuncay, Etienne Labbé, Thomas Pellegrini, 2026.06) — Interspeech 2026 accepted (IRIT-SAMoVA, Université de Toulouse)

- arxiv URL: https://arxiv.org/abs/2606.30700
- **기존 문제:** BEST-RQ(BERT-based Speech pre-Training with Random-projection Quantizer)는 랜덤 프로젝션 양자화기를 통해 효율적인 음성 SSL을 수행하지만, 컨텍스트화(contextualization)와 예측(prediction)을 단일 단계에서 동시에 수행하여 표현 학습의 최적화가 제한될 수 있다.
- **기존 방법:** 기존 BEST-RQ는 마스킹된 음성 입력에서 랜덤 프로젝션 양자화기가 생성한 이산 레이블을 예측하는 단일 단계 학습. HuBERT, wav2vec 2.0 등 다른 SSL 방법은 각각 고유한 학습 목적함수를 사용하지만, 컨텍스트화와 예측의 분리를 명시적으로 다루지 않았다.
- **제안 방법:** "Contextualize-Then-Predict" — 컨텍스트화와 예측을 명시적으로 분리한 2단계 자기지도 학습 접근법 제안. 먼저 입력을 컨텍스트화하여 풍부한 문맥 표현을 구성한 후, 이를 기반으로 마스킹된 위치의 타겟을 예측.
- **핵심 차별점:** BEST-RQ의 랜덤 프로젝션 양자화기 효율성을 유지하면서, 컨텍스트화와 예측의 명시적 분리를 통해 표현 품질을 향상. BEST-RQ 패러다임의 자연스러운 확장.
- **실험 결과:** 구체적 다운스트림 벤치마크 수치는 논문 원문 참조 필요. 코드가 공개되어 있으며(GitHub: LudovicTuncay/audio-embeddings), Audio-JEPA, RQA-JEPA, BEST-RQ 등과 통합된 프레임워크로 제공.
- **우리 연구 관련도:** ★★★ — BEST-RQ 기반 SSL의 직접적 후속 연구로, prediction-free SSL과 VQ 기반 표현 학습에 가장 밀접하게 관련. 랜덤 프로젝션 양자화기의 개선 방향과 컨텍스트화-예측 분리 전략은 우리 연구의 학습 목적함수 설계에 직접적 시사점 제공.

## 이번 주 트렌드 요약 (2026.06.29 – 07.03)

이번 주 총 **47편** (월 10편 + 화 9편 + 수 9편 + 목 12편 + 금 7편)의 논문을 조사하였으며, 다음과 같은 주요 트렌드가 관찰되었다.

### 1. 비자기회귀(NAR) ASR의 확산 모델 적용 가속화

이번 주 ASR 분야에서 가장 두드러진 트렌드는 확산(diffusion) 및 흐름 매칭(flow matching) 기반 비자기회귀 디코딩의 빠른 발전이다. Whisfusion(마스크 확산 디코딩, 6/29), MDM-ASR(확산 기반 NAR, 6/30), Drax(이산 흐름 매칭, 6/30), CTC-Seeded Token Edit Refinement(CTC 시드 편집 정제, 7/3)이 모두 AR 디코딩의 순차적 병목을 극복하면서 정확도를 유지하는 방향을 탐구했다. VocalNet-MDM(7/2)은 이를 스트리밍 SpeechLLM까지 확장하여, 확산 모델이 ASR 디코딩뿐 아니라 음성 생성 전반의 병렬화 패러다임으로 자리잡고 있음을 보여준다.

### 2. 다화자 ASR + 다이어리제이션의 LLM 통합 심화

다화자 음성 인식과 화자 분리를 LLM 백본으로 통합하는 연구가 집중적으로 등장했다. TagSpeech(시간 앵커 기반 동기화, 7/1), Balancing ASR and Diarization(듀얼 인코더 + 적응적 손실, 7/1), G-STAR(캐시 기반 글로벌 화자 추적, 7/1), DM-ASR(다중 턴 대화 재구성, 7/2)이 모두 "누가, 언제, 무엇을" 동시 추정 문제를 Speech-LLM 프레임워크 내에서 해결하려 했다. 특히 의미-화자 정보의 분리(disentanglement)와 시간 구조의 명시적 모델링이 공통 설계 원칙으로 부상하고 있다.

### 3. SpeechLLM의 실시간 상호작용 및 추론 능력 확장

SpeechLLM 분야에서는 실시간 전이중(full-duplex) 상호작용과 추론 능력 강화가 핵심 주제였다. Audio Interaction Model(항상 켜진 인지-응답 루프, 7/1), STITCH(청크 추론으로 CoT + 동일 지연, 7/1), WavAlign(의미-음향 채널 분리 후학습, 7/1)이 SpeechLLM의 실용적 한계를 각기 다른 각도에서 공략했다. CORTIS(7/3)는 텍스트 전용 적응으로 실용적 배포 비용을 절감하는 방향을, ProsodyLM(7/3)은 운율 처리 능력의 창발적 학습을 밝히며 SLM의 내부 표현 이해를 심화시켰다.

### 4. 음성 토크나이저/코덱의 다양화와 정보 선택적 인코딩

음성 Foundation Model 분야에서는 "어떤 정보를, 얼마나 효율적으로" 토큰화할 것인가에 대한 다양한 해답이 제시되었다. SiTok(확산 오토인코더, 극저 비트레이트, 7/2), AffectCodec(감정 보존, 7/2), DTM-Codec(동적 토큰 마스킹 VFR, 7/3)이 각각 의미-음향 최적화, 감정 정보 보존, 가변 프레임 레이트라는 서로 다른 축에서 토크나이저 설계를 탐구했다. FlexiCodec(6/30)의 동적 프레임 레이트와 함께, 고정 구조에서 벗어나 입력 특성에 따라 적응적으로 토큰을 할당하는 방향이 명확한 트렌드로 확인된다.

### 5. 음성 SSL의 학습 메커니즘 분석 및 개선

BEST-RQ-2(컨텍스트화-예측 분리, 7/3), SpidR(자기 증류 + 온라인 클러스터링, 7/1), Tracking the Emergence of Linguistic Structure(SSL 학습 동역학 분석, 7/2), SPEAR(다중 코드북 VQ 통합 SSL, 7/2), Codec2Vec(코덱 기반 SSL, 7/1)이 음성 SSL의 학습 메커니즘을 다양한 관점에서 분석하고 개선했다. 특히 BEST-RQ-2의 컨텍스트화-예측 분리와 SpidR의 중간 레이어 자기 증류는 prediction-free SSL 설계에 직접적 참고가 되며, Tracking the Emergence 연구는 대조 학습(wav2vec 2.0) vs. pseudo-label(HuBERT) 간 학습 궤적 차이를 실증적으로 밝혀 SSL 목적함수 선택에 중요한 근거를 제공한다.
