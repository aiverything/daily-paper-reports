## 1. ASR (Automatic Speech Recognition)

**[Factorized Delayed Streams Modeling for LLM-based Streaming ASR] (Tatsunari Takagi, Kai Washizaki, Atsushi Kojima, Lianbo Liu, Koki Nikaido, Yui Sudo, 2026-10-03)** — arxiv preprint (ICASSP 2027 제출)

- https://arxiv.org/abs/2610.04333
- **기존 문제:** Decoder-only LLM을 스트리밍 ASR에 활용하는 Delayed Streams Modeling(DSM) 방식은 음성과 텍스트를 하나의 타임라인에 정렬하지만, ASR 전용 토큰(대기 토큰 등)이 텍스트 vocabulary에 섞여 대규모 softmax 연산 부담과 텍스트 LM 성능 저하를 유발한다.
- **기존 방법:** DSM은 오디오 프레임과 텍스트 토큰을 인터리빙하여 스트리밍 디코딩을 구현하되, 대기(waiting) 결정과 텍스트 생성을 동일한 출력 공간에서 처리한다. RNN-T, CTC 등 전통적 스트리밍 방식과 달리 LLM의 사전학습 지식을 활용할 수 있으나, 효율성 문제가 있다.
- **제안 방법:** Factorized DSM(F-DSM)은 대기 확률(waiting probability)을 텍스트 분포와 분리하여 모델링한다. 먼저 word-start 토큰 제거가 인식 성능에 큰 영향이 없음을 보이고, 대기 결정을 별도 헤드로 분리하여 대기 스텝에서 전체 vocabulary softmax를 생략할 수 있게 한다.
- **핵심 차별점:** ASR 전용 토큰을 텍스트 예측 공간에서 완전히 분리함으로써 GPU 메모리 사용량을 대폭 절감하고, 추론 시 softmax 스킵으로 속도를 향상시키며, 텍스트 전용 perplexity 저하를 줄인다.
- **실험 결과:** CSJ(일본어 자발 발화)와 LibriSpeech에서 DSM 대비 인식 성능 향상, GPU 메모리 사용량 대폭 감소, 유사한 학습 처리량 유지, 추론 속도 소폭 개선을 보고한다.
- **우리 연구 관련도:** ★★☆ — LLM 기반 스트리밍 디코딩에서 vocabulary 분리 전략은 prediction-free 접근과 직접 관련은 없으나, 효율적 표현 공간 설계라는 측면에서 참고할 만하다.

**[Child ASR Adaptation with Adult Retention: An Empirical Study] (QCRI 연구팀, 2026-10-08)** — arxiv preprint

- https://arxiv.org/abs/2610.08827
- **기존 문제:** 성인 음성에 최적화된 ASR 모델을 아동 음성에 적응시키면 성인 음성 인식 성능이 급격히 저하되는 catastrophic forgetting 문제가 발생한다. 특히 아랍어-영어 이중언어 환경에서 이 문제가 두드러진다.
- **기존 방법:** Full fine-tuning은 아동 음성 성능을 높이지만 성인 성능을 희생한다. LoRA 같은 parameter-efficient 방법이 대안으로 시도되었으나, 적응-보존 간 최적 균형에 대한 체계적 비교가 부족했다.
- **제안 방법:** Full fine-tuning, LoRA, 그리고 post-hoc weight-space merging(LERP, TIES) 기법을 4개 모델 패밀리(이중언어 encoder-decoder, Whisper Large v3, 이중언어 encoder-CTC, Qwen2.5-Omni-7B AudioLLM)에 걸쳐 체계적으로 비교한다.
- **핵심 차별점:** 단순 WER 비교를 넘어 Retention Index, Child Adaptation Gain, Adaptation Recovery 등 적응-보존 트레이드오프 전용 지표를 도입하여 다차원적으로 평가한다. 이중언어 동시 적응이 단일 언어 적응보다 안정적임을 발견했다.
- **실험 결과:** Weight-space merging이 encoder-CTC, Whisper, AudioLLM 모델에서 적응-보존 트레이드오프를 개선한다. LERP는 성인 정확도 보존에, TIES는 아동 적응 성능 회복에 강점을 보인다. Encoder-decoder 모델에서는 이중언어 직접 fine-tuning이 가장 낮은 WER을 달성한다.
- **우리 연구 관련도:** ★☆☆ — 도메인 적응 시 표현 보존 문제는 일반적으로 중요하나, prediction-free SSL이나 VQ 기반 표현 학습과의 직접적 관련성은 낮다.

**[When Forgetting Looks Like Improvement: Metric Masking in Streaming Diarizer Adaptation and the Price of Rehearsal] (Mo Yu, Yang Liu, Jing Qian, 2026-10월 초)** — arxiv preprint

- https://arxiv.org/abs/2610.08828
- **기존 문제:** 스트리밍 화자 분리(diarization) 모델을 새로운 도메인에 적응시킬 때, 전체 DER(Diarization Error Rate) 점수가 개선되더라도 화자 동일성 추적(identity consistency) 능력이 실제로는 악화될 수 있는 "metric masking" 현상이 존재한다.
- **기존 방법:** 기존 적응 방식은 target-only fine-tuning이나 rehearsal(기존 데이터 혼합 학습)을 사용하며, DER이라는 단일 지표로 성능을 평가한다. 이는 탐지 정확도 향상이 동일성 추적 저하를 가리는 문제를 포착하지 못한다.
- **제안 방법:** Streaming Sortformer v2를 7.5시간의 2인 대화 데이터에 적응시킨 후, 6개 코퍼스에서 평가한다. DER을 분해하고, 프레임별 활성 출력 수를 균등화하여 동일한 탐지 오류 조건에서 화자 할당을 비교한다. Short-window 화자 재매핑과 히스토리 개입 실험으로 스트리밍 상태 민감도를 탐색한다.
- **핵심 차별점:** 점수 수준의 보존(score-level retention)과 화자 할당 보존(speaker-assignment retention) 사이의 괴리를 정량적으로 밝힌다. Rehearsal이 할당 저하를 줄이지만 동시에 cross-domain transfer도 감소시킨다는 트레이드오프를 보고한다.
- **실험 결과:** 적응된 모델은 in-domain 탐지 성능이 향상되고 독립 코퍼스로의 전이도 확인되지만, 추가 오류는 주로 시간에 걸친 동일성 일관성 약화에서 발생한다. 기준 DER에 가까운 점수에서도 할당 저하가 숨어있을 수 있음을 보인다.
- **우리 연구 관련도:** ★★☆ — 스트리밍 환경에서의 temporal consistency 분석은 temporal contrastive learning 연구에서 시간적 일관성 평가 방법론으로 참고할 수 있다.

**[Conversation Is a Two-Body Problem: Dyadic Evaluation of Full-Duplex Dialogue Models] (Sungnyun Kim, Sungwoo Cho, Jihwan Oh, Se-Young Yun — KAIST AI, 2026-10-06)** — arxiv preprint

- https://arxiv.org/abs/2610.08125
- **기존 문제:** Full-duplex 음성 대화 모델의 평가가 일방적이다. 기존 벤치마크는 사전 녹음된 오디오나 고정 스크립트 심사관을 상대로 한쪽만 평가하는데, 실제 대화에서는 양측이 서로에게 영향을 미치는 동적 상호작용이 핵심이다.
- **기존 방법:** Full-Duplex-Bench 등 기존 벤치마크는 한쪽 모델만 점수를 매기는 단방향 평가를 수행한다. 자동화된 심사관(examiner)이 반응하되 고정된 테스트 스크립트를 따르며 자신은 평가받지 않는다.
- **제안 방법:** DyaFDB 벤치마크를 제안한다. 두 full-duplex 모델이 협력적 또는 갈등적 목표를 가진 역할을 부여받고 서로 대화하며, 양측 모두 외부 판정자에 의해 오프라인 평가된다. 어느 모델도 특권적 심사관이 아닌 양방향 설정이다.
- **핵심 차별점:** 140개 시나리오, 4개 과제에서 6개 self-play 및 cross-play 조합으로 7,560개 대화를 생성하여 평가한다. 한 모델의 행동이 상대의 행동을 지속적으로 변화시킨다는 것을 정량적으로 보인다.
- **실험 결과:** 상대가 주제를 이탈할 때 PersonaPlex의 역할 준수도가 0.51→0.29로 하락하는 반면, Raon은 0.68→0.83으로 상승하는 등 모델 간 상호작용 역학을 포착한다. 고정된 단일 대화 상대로는 이런 양방향 효과를 측정할 수 없음을 입증한다.
- **우리 연구 관련도:** ★☆☆ — Full-duplex 모델 평가 프레임워크로서 의미 있으나, speech SSL이나 VQ 표현 학습과의 직접적 관련성은 낮다.

**[Hiding Tool Latency in On-Device Cascaded Voice Agent through Speculative Execution] (Kyudan Jung 외 7인, 2026-10-06)** — arxiv preprint

- https://arxiv.org/abs/2610.07641
- **기존 문제:** Tool-augmented 음성 비서는 음성 인식→LLM 추론→도구 실행을 순차적으로 처리하여, 도구 지연(tool latency)이 사용자가 말을 끝낸 후에야 시작된다. 이로 인해 첫 응답까지의 시간(time-to-first-audio)이 길어진다.
- **기존 방법:** 기존 cascaded voice agent는 ASR→LLM→TTS 파이프라인을 직렬로 실행하며, 도구 호출이 필요한 경우 LLM이 도구를 식별한 후에야 호출이 시작된다. 전체 지연은 각 단계의 합이 된다.
- **제안 방법:** 부분적 ASR 결과로부터 도구 요청을 예측하여, 사용자가 아직 말하는 중에 도구를 투기적으로 실행(speculative execution)하고 결과를 캐싱한다. Predictor 모듈이 음성 인식 중 도구 호출을 예측하고, 캐싱된 결과를 LLM 프롬프트에 주입한다.
- **핵심 차별점:** 사용자의 발화 중 자기 수정(self-correction)을 처리하기 위한 rule-based 검증 메커니즘으로 유효한 캐시 결과만 선택적으로 주입한다. 최악의 경우에도 기존 직렬 파이프라인과 동일한 지연으로 바운드된다.
- **실험 결과:** 완전 구현된 Android 음성 비서에서 중앙값 time-to-first-audio를 5.79s→4.60s로 단축하고, 표준편차를 3.49s→2.81s로 줄여 응답 지연의 예측 가능성을 높였다.
- **우리 연구 관련도:** ★☆☆ — 시스템 최적화 논문으로, speech representation 연구와의 직접적 관련성은 낮다.

**[CharDuplex: Building Character-Consistent Full-Duplex Spoken Dialogue Models] (Donghang Wu, Yisi Liu, Chen Chen, Hexin Liu, Eng Siong Chng, 2026-09-28)** — arxiv preprint

- https://arxiv.org/abs/2609.34461
- **기존 문제:** Full-duplex 음성 대화 모델이 발전하고 있으나, 일관된 캐릭터 페르소나를 유지하면서 실시간 양방향 대화를 수행하는 것은 여전히 어렵다. 기존 모델들은 캐릭터 일관성과 full-duplex 능력을 동시에 달성하지 못한다.
- **기존 방법:** PersonaPlex 등 기존 접근법은 텍스트 역할 설명으로 full-duplex 대화를 조건화하지만, 캐릭터 일관성이 제한적이다. GLM-4-Voice 같은 모델은 강력한 음성 이해·생성 능력을 갖추었으나 turn-based로 동작한다.
- **제안 방법:** GLM-4-Voice를 기반으로 always-on 이중 스트림 아키텍처로 확장하고 full-duplex 대화를 위해 학습한다. 그 후 오픈소스 캐릭터 설명으로부터 완전 자동화된 파이프라인으로 캐릭터 조건부 대화 데이터를 구축하여 SFT를 수행한다. 마지막으로 FDGym에서 LLM 시뮬레이션 사용자와 동적 상호작용하며 강화학습으로 정제한다.
- **핵심 차별점:** 캐릭터 일관성 + full-duplex 능력을 단일 모델에서 동시에 달성하는 3단계 학습 파이프라인(full-duplex 적응→캐릭터 SFT→FDGym RL)을 제안한다. 데이터 구축부터 학습까지 완전 자동화되어 있다.
- **실험 결과:** SpeechRole-Eval에서 오픈소스 모델 중 최고 평균 점수를 달성하며, 클로즈드소스 시스템과도 경쟁적인 성능을 보인다. Full-Duplex-Bench에서도 강한 상호작용 능력을 유지한다. PersonaPlex 대비 4개 평가 차원 모두에서 크게 우위를 보인다.
- **우리 연구 관련도:** ★☆☆ — Full-duplex 음성 모델의 학습 방법론으로서 흥미롭지만, speech SSL이나 VQ 기반 표현 학습과의 직접적 관련성은 낮다.

**[GS-Codec: A Gaussian-Splatting Bottleneck for Neural Audio Coding] (Ron Aluf, Alon Canfi, Eliya Nachmani — Ben-Gurion University, 2026-10-03)** — arxiv preprint

- https://arxiv.org/abs/2610.04651
- **기존 문제:** 거의 모든 주류 neural audio codec(EnCodec, DAC 등)은 VQ-VAE 템플릿을 따라 인코더 잠재 표현을 codebook이나 고정 스칼라 그리드로 분할(partitioning)한다. Residual VQ, Finite Scalar Quantization, 단일 codebook 변형 모두 이 패러다임 내에 있다.
- **기존 방법:** RVQ(Residual Vector Quantization)가 지배적이며, FSQ(Finite Scalar Quantization), 그룹 VQ 등 양자화 방식의 개선에 초점이 맞춰져 있었다. 양자화 자체의 필요성을 의문시하는 접근은 드물었다.
- **제안 방법:** 양자화 대신 파라메트릭 신호 분해(parametric signal decomposition)를 bottleneck으로 사용한다. 3D 그래픽스의 Gaussian Splatting을 1차원 잠재 표현에 적응시켜, 각 오디오 세그먼트의 잠재 표현을 지역화된 Gaussian 프리미티브의 가중합으로 근사한다. 양자화는 학습 후(post-training)에 프리미티브 파라미터에만 스칼라로 적용된다.
- **핵심 차별점:** 단일 체크포인트로 프리미티브 수와 파라미터별 bit depth를 조절하여 재학습 없이 세밀한 비트레이트 제어가 가능하다. 인코더, 디코더, 학습 레시피를 동일하게 유지한 채 bottleneck만 Gaussian으로 교체하여 RVQ, FSQ와 직접 비교한다.
- **실험 결과:** LibriTTS, LJSpeech, LibriSpeech에서 유사 비트레이트 대비 EnCodec, DAC와 동등하거나 우수한 화자 유사도(SIM), 명료도(STOI), 지각 품질(UTMOS)을 달성하며, 의미적 성능(WER)도 비슷하다. 6kbps와 3kbps에서 비교 결과를 제시한다.
- **우리 연구 관련도:** ★★★ — VQ 기반 표현을 대체하는 새로운 bottleneck 설계로, VQ-based representation 연구에서 양자화 패러다임 자체에 대한 재고를 촉발할 수 있는 중요한 연구이다.

**[SpeechGym: An Audio-Native Gym for Training Voice Agents via Reinforcement Learning] (Jiajun Fan, Jingyuan Li, Prashanth Gurunath Shivakumar 외 — UIUC / Amazon AGI, 2026-08-26)** — arxiv preprint

- https://arxiv.org/abs/2608.26432
- **기존 문제:** Voice agent 학습에서 기존 접근법은 독점 음성 API를 TTS/ASR로 감싸 gradient flow를 차단하거나, 텍스트 영역에서만 평가하여 음성 채널의 실제 영향을 측정하지 못한다. On-policy RL이 너무 비싸거나 불가능한 상황이다.
- **기존 방법:** Cascaded 시스템(STT→LLM→TTS)으로 음성 에이전트를 구축하되, 학습은 텍스트 기반 에이전트 벤치마크에서 수행한다. 음성 채널로 인한 성능 저하를 측정할 수 있지만 개선할 수 없다.
- **제안 방법:** 두 개의 omni-modal 모델이 외부 ASR/TTS 없이 네이티브 오디오로 직접 대화하는 학습 환경을 구축한다. 기존 텍스트 에이전트 벤치마크의 과제, 도구, 성공 판정을 차용하여 음성 채널만 변수로 분리한다. 사용자 시뮬레이터, 도구, 보상이 환경 내에 통합되어 음성 롤아웃이 학습 가능하다.
- **핵심 차별점:** 음성이 도입하는 오류의 성격을 분석: 대부분 추론 실패가 아닌 지각적 실패(perceptual failure)이며, 에이전트가 올바른 도구와 인자를 선택하되 잘못 들은 값을 채워 넣어 에러가 연쇄된다. 행동적 실패(강압적 사용자 앞에서 무단 쓰기 작업 수행)도 보고한다.
- **실험 결과:** Voice agent의 과제 완수율이 31-51% 수준으로, GPT-5의 85%에 크게 못 미치는 것으로 보고된다 (다만 이 수치는 2차 출처에서 확인한 것이므로 원문 확인 필요).
- **우리 연구 관련도:** ★★☆ — 음성 네이티브 RL 환경은 speech representation이 downstream 에이전트 성능에 미치는 영향을 직접 측정할 수 있는 프레임워크로, SSL 표현의 실용적 평가에 활용 가능성이 있다.

**[Can LLM Agents Automate Reinforcement Learning for Text-to-Speech?] (Xuanjun Chen, Zixiong Su, Hao Shi, Chang Zeng, Kai Li, Jyh-Shing Roger Jang, Hung-yi Lee, 2026-10-03)** — arxiv preprint (work in progress)

- https://arxiv.org/abs/2610.04488
- **기존 문제:** RL 후처리(post-training)는 zero-shot TTS의 국소적 분절 오류를 교정할 수 있지만, 작동하는 RL 레시피를 찾기까지 데이터, 보상 함수, 알고리즘에 대한 수동 튜닝이 필요하다.
- **기존 방법:** 연구자가 보상 함수를 설계하고, 데이터를 선별하며, 학습 하이퍼파라미터를 수동으로 조정하는 trial-and-error 방식으로 RL 레시피를 개발한다.
- **제안 방법:** AgenticTTS-Forge라는 워크플로우를 통해 LLM 에이전트가 인간 가이드와 공유 워크스페이스에서 협업하여 RL 레시피를 자동으로 구성하고 개선한다. CosyVoice2-0.5B를 대상 모델로 적용한다.
- **핵심 차별점:** 에이전트가 불완전한 레시피를 복원한 후 개선하며, 성능 향상이 정체되면 자발적으로 문헌을 검토하여 LM carrier에서 flow carrier로 전환하는 등의 자율적 의사결정을 수행한다. 동시에 에이전트 자율성이 초래하는 3가지 함정(데이터 누출, 자체 생성 보상의 프록시 점수 부풀림, 개별 튜닝 정책의 비가법적 결합)을 발견한다.
- **실험 결과:** Flow carrier 전환으로 bad-case rate을 절반으로 감소시킨다. 하지만 측정(measurement)이 추론(reasoning)이 아닌 바인딩 제약이며, 평가 하네스가 에이전트가 사용할 수 있는 모든 채널을 검증해야 한다고 결론짓는다.
- **우리 연구 관련도:** ★★☆ — 음성 생성 모델의 자동화된 학습 파이프라인 설계는 speech foundation model의 학습 효율화에 영감을 줄 수 있으며, 특히 보상 설계와 평가 프레임워크에 대한 통찰이 유용하다.
