## 1. ASR (Automatic Speech Recognition)

### 1-1. Whale: Large-Scale Multilingual ASR Model with w2v-BERT and E-Branchformer with Large Speech Data

**[Whale] (Yosuke Kashiwagi, Hayato Futami, Emiru Tsunoo, Satoshi Asakawa — Sony, 2025-06)** — arxiv preprint

- arxiv URL: https://arxiv.org/abs/2506.01439
- **기존 문제**: 오픈소스 대규모 다국어 ASR 모델(Whisper, OWSM 등)은 성능이 우수하지만, 독점 데이터와 학습 파이프라인의 차이로 인해 학술·산업 커뮤니티에서 재현 및 확장이 어려웠음
- **기존 방법**: Whisper(encoder-decoder, 680K시간), OWSM v3.1(공개 데이터 기반) 등이 대표적. CTC 또는 attention 기반 디코딩을 사용
- **제안 방법**: Self-supervised w2v-BERT 프론트엔드 + E-Branchformer 인코더 + Joint CTC-Attention 디코딩을 결합한 대규모 다국어 모델. 공개 코퍼스와 사내 데이터를 혼합하여 다양한 발화 스타일과 음향 조건을 커버
- **핵심 차별점**: w2v-BERT의 자기지도학습 표현을 E-Branchformer의 효율적 인코딩과 결합하여, 기존 Whisper large-v3 대비 개선된 성능을 공개 모델 수준에서 달성
- **실험 결과**: LibriSpeech test-clean 2.4% WER, CSJ eval3 3.4% CER — Whisper large-v3 및 OWSM v3.1 대비 우위 보고
- **우리 연구 관련도**: ★☆☆ — 대규모 지도학습 ASR 모델로, prediction-free SSL이나 VQ 표현과는 직접적 관련 낮음

### 1-2. Diarization-Guided Qwen-ASR Adaptation for Multilingual Two-Speaker Conversational Speech

**[Diarization-Guided Qwen-ASR] (Hao Wu, RongQi Han, Zhen Wang, Wei Liang, Wei Xu, 2026-07)** — MLC-SLM 2026 Challenge

- arxiv URL: https://arxiv.org/abs/2607.08208
- **기존 문제**: 다국어 2인 대화에서 화자분리(diarization)와 음성인식(ASR)을 동시에 수행하는 것은 언어 다양성, 화자 중첩, 코드스위칭 등으로 인해 난제
- **기존 방법**: 별도의 화자분리 모듈 + ASR 파이프라인 구성이 일반적. 최근에는 LLM 기반 end-to-end 접근(DM-ASR 등)이 등장
- **제안 방법**: Diarization 프론트엔드(VAD + 화자 임베딩 + 2화자 클러스터링) + Qwen3-ASR-1.7B를 3단계로 적응: (1) 전체 파인튜닝, (2) TTS 합성 데이터 기반 LoRA 파인튜닝, (3) GRPO 강화학습(WER/CER 보상 + hallucination/반복/길이 페널티)
- **핵심 차별점**: GRPO 강화학습을 ASR 적응에 도입하여 hallucination과 반복 오류를 직접 최적화. TTS 합성 데이터를 통한 데이터 증강 전략 활용
- **실험 결과**: MLC-SLM 2026 공식 dev셋 tcpMER 23.70 (베이스라인 대비 6.83p 감소), 최종 평가셋 17.97
- **우리 연구 관련도**: ★☆☆ — 지도학습 ASR 파인튜닝 중심으로, SSL 표현학습과는 직접적 관련 낮음

### 1-3. Diarization Error Decomposition Under Pause Annotation Ambiguity

**[DER Decomposition] (Shota Horiguchi, Marc Delcroix, Naohiro Tawara, Alexis Plaquet — NTT, 2026-09)** — arxiv preprint

- arxiv URL: https://arxiv.org/abs/2609.11007
- **기존 문제**: 표준 DER(Diarization Error Rate) 평가 시, 발화 간 pause 구간의 주석 불일치가 오류율을 왜곡하여 실제 화자분리 성능을 정확히 반영하지 못함
- **기존 방법**: Morphological closing을 적용한 pause-tolerant 평가가 사용되었으나, 이는 세그먼트 수준의 구분 정보를 잃어버리는 문제가 있음
- **제안 방법**: DER을 pause-attributable 부분과 core(본질적 오류) 부분으로 정확하게 분해하는 overlap-aware 분석법 제안. 전체 DER 값은 보존하면서 오류 원인을 분리
- **핵심 차별점**: 기존 closing 기반 방법과 달리 DER 총량을 변경하지 않으면서도, pause 기인 오류와 본질적 오류를 단조(monotone) 분리하여 더 정밀한 진단 가능
- **실험 결과**: 합성 변환, 주석 불일치, cross-domain 평가, tight-boundary diarization 등 다양한 시나리오에서 기존 DER로는 보이지 않던 오류 원인을 정확히 분리
- **우리 연구 관련도**: ★☆☆ — 평가 메트릭 연구로, 표현학습 연구와의 직접적 관련은 낮음

## 2. SpeechLLM (Speech Language Model)

### 2-1. TASTE2: Text-Aligned Speech Modeling and Deployment toward Full-Duplex Voice Interaction

**[TASTE2] (MediaTek Research, National Taiwan University, NVIDIA Taiwan, 2026-09)** — arxiv preprint

- arxiv URL: https://arxiv.org/abs/2609.08956
- **기존 문제**: 기존 음성 대화 모델은 turn-based 방식에 제한되어, 실시간 끼어들기(barge-in)와 자연스러운 turn-taking이 어려움
- **기존 방법**: TASTE v1(utterance-level 변환), 기존 duplex 모델들은 음성 품질 저하 또는 텍스트 LLM 능력 손실 문제
- **제안 방법**: 공유 텍스트 토큰 어휘(word-level averaging 제거) + 텍스트 토큰당 하나의 연속 오디오 latent 예측 + CosyVoice2 기반 incremental detokenizer로 실시간 스트리밍
- **핵심 차별점**: 텍스트 LLM(Qwen2.5-7B) 능력의 98.2% 유지하면서 full-duplex 대화 지원. Barge-in 시 KV 캐시 리셋 없이 60ms 이내 응답 중단
- **실험 결과**: LLaMA-Questions에서 텍스트 전용 대비 98.2% 성능 유지(56.3% vs 57.3%). Full-Duplex-Bench v1.0에서 우수한 interruption handling
- **우리 연구 관련도**: ★★☆ — 음성 토큰화 및 text-speech alignment 기법이 speech tokenizer 연구와 관련

### 2-2. DuplexSLA: A Full-Duplex Spoken Language Model with Synchronized Speech, Language, and Action

**[DuplexSLA] (Haoyang Zhang 외 — StepFun, Nanyang Technological University, 2026-06)** — arxiv preprint

- arxiv URL: https://arxiv.org/abs/2605.20755
- **기존 문제**: Full-duplex 음성 모델에서 turn-taking, backchannel, tool calling을 단일 모델로 통합 처리하기 어려움. 외부 semantic VAD에 의존하는 구조적 한계
- **기존 방법**: 별도의 VAD/turn-taking 모듈 + LLM 파이프라인. 또는 반이중(half-duplex) 음성 모델
- **제안 방법**: 160ms 고정 청크 단위로 assistant speech, user audio, action(tool call)을 동기화하여 단일 백본에서 처리. Step-Audio-2-mini (~7B) 기반으로 CPT + post-training
- **핵심 차별점**: Interruption, pause, backchannel을 외부 VAD 없이 동일 모델 내부에서 처리. Action 채널이 speech와 독립적으로 동작하여 tool calling 시 음성 출력 중단 없음
- **실험 결과**: DuplexSLA-Bench에서 4가지 시나리오(turn-taking, barge-in, backchannel, tool call)에서 sub-second 응답. Tool calling 정확도는 ASR+LLM cascade와 동등하면서 3~4배 낮은 latency
- **우리 연구 관련도**: ★☆☆ — Full-duplex 시스템 설계 중심으로, 표현학습과의 직접적 관련 낮음

### 2-3. VoiceChat-TTS: A Low-Latency Continuous Speech Synthesis Model for Interactive Agents

**[VoiceChat-TTS] (Edresson Casanova, Jaehyeon Kim 외 — NVIDIA, 2026-08)** — arxiv preprint

- arxiv URL: https://arxiv.org/abs/2608.13831
- **기존 문제**: 기존 duplex speech-to-speech 모델은 latency를 줄이지만 음성 품질이 저하됨. 반면 고품질 TTS는 실시간 상호작용(interruption, always-on)을 지원하지 못함
- **기존 방법**: 오프라인 TTS + LLM 파이프라인, 또는 end-to-end duplex 모델(음성 품질 타협)
- **제안 방법**: LLM 텍스트 토큰 스트림을 입력으로 받아 continuous speech를 생성하는 스트리밍 TTS. Silence modeling + interruption control token으로 always-on 동작 지원. Audio Flamingo 3-Chat 기반
- **핵심 차별점**: KV 캐시 리셋 없이 mid-utterance interruption 처리. 텍스트 입력이 없을 때 자동으로 silence 생성하여 상시 대기 상태 유지. 단일 학습으로 single-turn/multi-turn 모두 지원
- **실험 결과**: 오프라인 및 스트리밍 베이스라인 대비 경쟁력 있는 음성 품질을 유지하면서 latency 및 interruption 요구사항 충족
- **우리 연구 관련도**: ★☆☆ — TTS 시스템 설계로, 표현학습 연구와의 직접적 관련 낮음

### 2-4. Decoupling Conversational Dynamics in Full-Duplex Spoken Models through Reinforcement Learning

**[DuplexPO] (Yuxin Li, Donghang Wu, Guan-Ting Lin, Hung-yi Lee, Chengwei Qin, Zhehuai Chen, Chen Chen, 2026-07)** — IWSDS 2026

- arxiv URL: https://arxiv.org/abs/2607.07148
- **기존 문제**: Full-duplex 모델에서 대화 역학(turn-taking, backchannel 등) 개선 시 추론(reasoning) 및 instruction-following 능력이 저하되는 trade-off 존재
- **기존 방법**: 대화 데이터로 직접 파인튜닝하거나, 별도 모듈로 turn-taking 처리. 두 목표를 동시에 최적화하는 체계적 방법 부재
- **제안 방법**: DuplexPO — 대화 역학을 독립적 최적화 대상으로 분리하는 RL 프레임워크. 긴 다자간 대화에서 dynamic-critical window(턴 전환, backchannel, barge-in 구간)를 샘플링하고, Factorized Conversational Dynamics Reward를 RL 신호로 활용
- **핵심 차별점**: 대화 역학 최적화를 reasoning 능력과 분리(decouple)하여, 한쪽 개선이 다른 쪽을 저해하지 않도록 설계. HiPLEX, STEERABLEPLEX 등 후속 연구에서 활발히 인용
- **실험 결과**: Backchannel 적시성, smooth turn-taking, barge-in handling이 크게 개선되면서도 reasoning/instruction-following 성능 유지
- **우리 연구 관련도**: ★☆☆ — RL 기반 대화 최적화로, 표현학습 연구와의 직접적 관련 낮음

## 3. Speech Foundation Model

### 3-1. StableToken: A Noise-Robust Semantic Speech Tokenizer for Resilient SpeechLLMs

**[StableToken] (Peking University, WeChat AI / Tencent, 2025-09)** — **ICLR 2026 accepted**

- arxiv URL: https://arxiv.org/abs/2509.22220
- **기존 문제**: 기존 semantic speech tokenizer(HuBERT k-means 등)는 노이즈에 매우 취약. 높은 SNR에서도 토큰 시퀀스가 크게 변동하여 하류 LLM 성능 저하 초래
- **기존 방법**: 단일 경로(single-path) 양자화 설계로, 중간 토큰의 안정성을 학습 신호에 반영하지 않는 구조
- **제안 방법**: Multi-branch 설계 + Voting-LFQ(비트 단위 다수결 투표). 홀수 개 branch의 출력을 비트별 majority voting으로 결합하여 노이즈에 의한 산발적 비트 오류를 교정
- **핵심 차별점**: 토큰 시퀀스의 노이즈 강건성을 구조적으로 보장(단순 학습 trick이 아닌 아키텍처 수준 해결). 기존 tokenizer 대비 UED 60% 이상 감소
- **실험 결과**: Unit Edit Distance 26.17% → 10.17% (60%+ 상대 감소). 노이즈 환경 ASR에서 SpeechLLM 기준 30%+ 상대 WER 감소. 재구성 품질 유지
- **우리 연구 관련도**: ★★★ — VQ 기반 speech tokenization의 핵심 연구. Voting-LFQ는 VQ-based representation의 robustness 향상과 직결

### 3-2. Codec2Vec: Self-Supervised Speech Representation Learning Using Neural Speech Codecs

**[Codec2Vec] (Wei-Cheng Tseng, David Harwath — UT Austin, 2025-11)** — **ASRU 2025 accepted**

- arxiv URL: https://arxiv.org/abs/2511.16639
- **기존 문제**: 기존 Speech SSL(wav2vec 2.0, HuBERT 등)은 연속 파형/스펙트로그램을 입력으로 사용하여 저장 및 학습 비용이 높음
- **기존 방법**: 연속 오디오 입력 → masked prediction 기반 자기지도학습. 대규모 데이터에서 학습 시간과 저장 공간이 큰 병목
- **제안 방법**: Neural audio codec(DAC, 16kHz, 12 codebook, 50Hz)의 이산 토큰만을 입력으로 사용하는 SSL 프레임워크. Masked prediction으로 사전학습하되, 타겟은 원래 codec unit의 재구성. 다중 projection layer로 전체 codebook 시퀀스 예측
- **핵심 차별점**: 연속 파형 대신 이산 codec 토큰만 사용하여 저장 16.5배, 학습시간 2.3배 절감하면서도 SUPERB 벤치마크에서 연속 입력 모델과 경쟁력 있는 성능
- **실험 결과**: SUPERB 벤치마크에서 continuous-input 모델 대비 경쟁적 성능. 저장 16.5x 절감, 학습시간 2.3x 절감
- **우리 연구 관련도**: ★★★ — Codec 기반 이산 표현에서의 SSL은 VQ-based representation learning과 직접 관련. Prediction 기반 학습 vs prediction-free 접근의 비교 대상

### 3-3. MOSS-Audio-Tokenizer: Scaling Audio Tokenizers for Future Audio Foundation Models

**[MOSS-Audio-Tokenizer] (OpenMOSS, 2026-02)** — arxiv preprint

- arxiv URL: https://arxiv.org/abs/2602.10934
- **기존 문제**: 기존 neural audio codec은 CNN 기반 구조로 스케일링에 한계. Speech/sound/music 등 도메인별로 별도 tokenizer가 필요한 비효율
- **기존 방법**: SoundStream, EnCodec 등 CNN 기반 codec. 도메인별 최적화 필요, 스케일링 법칙 미확인
- **제안 방법**: CAT(Causal Audio Tokenizer with Transformer) — CNN 없이 순수 causal Transformer 블록만으로 구성된 end-to-end audio tokenizer. 1.6B 파라미터, ~3M 시간 일반 오디오로 사전학습
- **핵심 차별점**: 순수 Transformer 기반으로 스케일링 법칙 적용 가능. 단일 모델로 speech/sound/music 모두 커버. 보조 인코더 없이 ASR 지원, 순수 autoregressive TTS 가능
- **실험 결과**: 다양한 비트레이트에서 기존 codec 대비 speech/sound/music 전반에 걸쳐 우수한 성능. 스케일 증가에 따른 예측 가능한 품질 향상 확인. v2(2B, 48kHz stereo) 공개
- **우리 연구 관련도**: ★★☆ — 대규모 audio tokenizer 스케일링 연구. VQ-based representation 관점에서 tokenizer 아키텍처 설계에 참고 가치

### 3-4. What do Speech Foundation Models Learn? Analysis and Applications

**[SFM Analysis] (Ankita Pasad — Ph.D. Thesis, 2025-08)** — arxiv preprint (학위논문)

- arxiv URL: https://arxiv.org/abs/2508.12255
- **기존 문제**: Speech Foundation Model(SFM)이 범용 표현으로 우수한 성능을 보이지만, 각 레이어가 실제로 어떤 음향적·언어적 정보를 학습하는지에 대한 이해가 부족
- **기존 방법**: Probing classifier 등 기존 분석 도구는 프로브 자체의 용량이 결과를 왜곡할 수 있어 해석이 모호
- **제안 방법**: Projection-Weighted Canonical Correlation Analysis(PWCCA) 등 통계적 도구와 training-free task를 활용한 경량 분석 프레임워크. 다수의 SFM을 체계적으로 비교
- **핵심 차별점**: 로컬 음향 특징 재구성을 학습한 모델은 autoencoder 패턴, 외부 신호(텍스트, 이미지) 복원 모델은 깊은 레이어에서 입력 오디오와 괴리가 커지는 패턴 발견. 이러한 분석이 하류 작업 성능 예측에 활용 가능
