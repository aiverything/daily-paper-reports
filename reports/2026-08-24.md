## 1. ASR (Automatic Speech Recognition)

### 1-1. SegAug: CTC-Aligned Segmented Augmentation For Robust RNN-Transducer Based Speech Recognition

**[SegAug] (Khanh Le, Tuan Vu Ho, Dung Tran, Duc Thanh Chau, 2025.02)** — ICASSP 2025
- https://arxiv.org/abs/2502.14685
- **기존 문제:** RNN-Transducer(RNN-T)는 내부 언어 모델(ILM)의 텍스트 패턴 편향으로 인해 음향 특징 활용이 제한되며, 훈련 데이터의 문장 수준 의미에 과도하게 의존하여 다양한 음향 조건에서의 강건성이 부족
- **기존 방법:** SpecAugment 등 음향 수준 데이터 증강이나, 텍스트와 무관한 랜덤 증강 기법 적용. ILM의 텍스트 패턴 다양화를 명시적으로 고려하지 않음
- **제안 방법:** CTC 정렬(alignment)을 활용하여 오디오-텍스트 쌍을 세그먼트 단위로 분할한 뒤, 문맥적으로 다양한 오디오-텍스트 쌍을 생성하는 정렬 기반 증강 기법(SegAug) 제안. 문장 수준 의미를 낮춤으로써 모델이 음향 특징에 집중하도록 유도하고, ILM이 학습하는 텍스트 패턴을 다양화
- **핵심 차별점:** CTC 정렬을 증강의 분할 기준으로 활용하여, 음향-텍스트 간 정합성을 유지하면서도 ILM의 텍스트 패턴 편향을 체계적으로 완화
- **실험 결과:** 논문에서 RNN-T 기반 ASR 시스템의 강건성 향상을 보고
- **우리 연구 관련도:** ★☆☆ — RNN-T 증강 기법으로, CTC 정렬 활용이라는 점에서 방법론적 참고 가치. 음성 표현 학습과의 직접적 관련은 낮음

### 1-2. TurboBias 2.0: Streaming Context-Biasing for Production-Efficient ASR Systems

**[TurboBias 2.0] (Vladimir Bataev, Lilit Grigoryan, Andrei Andrusenko, Nikolay Karpov, Vitaly Lavrukhin, Boris Ginsburg — NVIDIA, 2026.08)** — arXiv preprint
- https://arxiv.org/abs/2608.21343
- **기존 문제:** 문맥 바이어싱(context biasing)은 도메인 특화 용어의 ASR 인식 정확도를 높이는 핵심 기법이지만, 기존 방법들은 프로덕션 환경의 실질적 요구사항—스트리밍 추론, 효율적 배치 디코딩, 사용자별 개별 컨텍스트 리스트, 낮은 런타임 오버헤드—을 충분히 충족하지 못함
- **기존 방법:** GPU 가속 TurboBias(v1)의 Phrase-Boosting Tree 기반 문맥 바이어싱. 대소문자 구분(case-sensitive) 부스팅 그래프와 배치 내 공유 컨텍스트 리스트 제약
- **제안 방법:** TurboBias 2.0 — Transducer 기반 ASR 시스템을 위한 프로덕션 지향 문맥 바이어싱 프레임워크. 대소문자 무관(case-insensitive) 부스팅 그래프와 스트림별 배치 디코딩(per-stream batched decoding)을 도입하여, 배치 내 각 발화가 독립적인 문맥 바이어싱 구성을 사용 가능
- **핵심 차별점:** 다수 동시 사용자가 각자 고유한 컨텍스트 리스트를 사용하면서도 배치 디코딩의 효율성을 유지. 스트리밍 및 오프라인 추론 모두 지원
- **실험 결과:** 스트리밍 및 오프라인 추론에서 사용자별 독립 컨텍스트 바이어싱의 실용성 검증
- **우리 연구 관련도:** ★☆☆ — 프로덕션 ASR 시스템의 문맥 바이어싱 최적화 연구. NVIDIA의 최신 ASR 인프라 동향 참고 가치

### 1-3. Easper: An Accessible ASR Pipeline for Language Documentation

**[Easper] (Aso Mahmudi, Ting Dang, Ekaterina Vylomova, Nick Thieberger — University of Melbourne, 2026.08)** — Interspeech 2026 accepted
- https://arxiv.org/abs/2608.11629
- **기존 문제:** 저자원 위기 언어(endangered language)의 문서화(documentation)에 ASR을 활용하려면, 언어학자가 코딩 없이 반복적으로 모델을 미세조정하고 전사(transcription) 우선순위를 결정할 수 있는 접근성 높은 도구가 필요
- **기존 방법:** 범용 ASR 모델(Whisper 등)의 제로샷 적용 또는 수작업 전사. 언어학자 친화적인 반복 미세조정(iterative fine-tuning) 워크플로우 부재
- **제안 방법:** ELAN 어노테이션에서 직접 클라우드 리소스를 활용하여 ASR 모델을 반복적으로 미세조정하는 오픈소스 노코드(no-code) 파이프라인 Easper 제안. SpeechBrain과 Pyannote를 통합하여 화자 분할(speaker diarization) 지원. 전사 우선순위 전략(transcription prioritisation strategies)을 평가
- **핵심 차별점:** 코딩 경험 없는 현장 언어학자(field linguist)가 ELAN 워크플로우 내에서 직접 ASR 모델을 반복 개선 가능. 전사 우선순위 전략을 체계적으로 비교
- **실험 결과:** 바누아투 3개 언어(Bislama, Nafsan, Nguna)에서 전사 우선순위 전략별 성능 평가 수행
- **우리 연구 관련도:** ★☆☆ — 저자원 언어 ASR 도구 연구. 음성 표현 학습보다는 실용적 ASR 파이프라인 구축에 초점

## 2. SpeechLLM (Speech Language Model)

### 2-1. TurnGuide: Enhancing Meaningful Full Duplex Spoken Interactions via Dynamic Turn-Level Text-Speech Interleaving

**[TurnGuide] (Wenqian Cui, Lei Zhu, Xiaohui Li, Zhihan Guo, Haoli Bai, Lu Hou, Irwin King, 2025.08 / revised 2026.06)** — arXiv preprint
- https://arxiv.org/abs/2508.07375
- **기존 문제:** End-to-end Full-Duplex Speech Language Model(FD-SLM)은 실세계 이중 채널 대화 데이터에서 자연스러운 턴테이킹 패턴을 학습하지만, 장시간 음성 시퀀스와 고품질 음성 대화 데이터 부족으로 인해 순수 텍스트 대화 대비 대화 능력이 저하됨
- **기존 방법:** 음성 전용 생성 또는 단순 텍스트-음성 연결. 이산 텍스트 토큰을 연속적 이중 채널 오디오 스트림에 통합 시 실시간 시간 정합성(time alignment) 훼손 문제
- **제안 방법:** TurnGuide — e2e FD-SLM을 위한 동적 턴 수준 텍스트-음성 인터리빙 생성 방식. 어시스턴트 음성을 대화 턴 단위로 동적 분할(segmentation)하고, 턴 수준에서 텍스트를 인터리빙하여 이중 채널 오디오 스트림의 시간 정합성을 유지하면서 텍스트 LLM의 대화 능력을 활용
- **핵심 차별점:** 턴 수준 동적 분할을 통해 텍스트 인터리빙 시 실시간 시간 정합성 보존 문제를 해결. FD-SLM의 대화 품질을 텍스트 LLM 수준으로 향상
- **실험 결과:** FD-SLM의 대화 의미 품질(semantic quality)이 텍스트 인터리빙을 통해 향상되며, 실시간 상호작용 능력(인터럽션, 백채널 등)을 유지
- **우리 연구 관련도:** ★☆☆ — Full-duplex 음성 대화 모델의 텍스트-음성 인터리빙 기법. 음성 표현 학습보다는 음성 대화 시스템 아키텍처에 초점

### 2-2. X2Streaming-TTS: Causal Token-Level Text-to-Speech from Streaming Text with Speech-State Inheritance

**[X2Streaming-TTS] (Rime Wen, Zehan Liu, Shawn Qin, Lights Shi, Roy Gan, Hao Wang, Qian Wang — X Square Robot, 2026.08)** — arXiv preprint
- https://arxiv.org/abs/2608.18661
- **기존 문제:** 대부분의 TTS 시스템은 전체 텍스트가 입력된 후 음성을 생성하는 비스트리밍(non-streaming) 방식으로, LLM 토큰 스트리밍 환경에서 실시간 대화형 에이전트에 필요한 저지연(low-latency) 음성 합성을 지원하지 못함
- **기존 방법:** 의사 스트리밍(pseudo-streaming) TTS — 전체 텍스트를 수신한 후 음성을 생성하거나, 고정 길이 청크 단위로 분할하여 독립 합성. 세그먼트 간 음성 상태(speech state)의 연속성 부재
- **제안 방법:** X2Streaming-TTS — 비동기적으로 도착하는 텍스트 토큰을 소비하면서 미래 입력에 접근하지 않고 음성을 출력하는 인과적(causal) TTS 프레임워크. (1) 불확실성 인식 버퍼링(uncertainty-aware buffering)과 용량 적응형·구두점 인식 세그멘테이션을 통한 인과적 커밋(causal commitment), (2) Code2Wav 상태 전체와 선택된 Talker 이력 상태를 세그먼트 경계를 넘어 전달하는 인과적 음성 상태 계승(speech-state inheritance)
- **핵심 차별점:** 세그먼트 간 음성 상태를 완전히 계승하여 스트리밍 환경에서도 음성 연속성과 일관성을 유지. 기존 의사 스트리밍 모델 대비 대부분의 주관적·객관적 지표에서 우수
- **실험 결과:** 기존 의사 스트리밍 TTS 모델 대비 대부분의 주관적 및 객관적 평가 지표에서 우수한 성능
- **우리 연구 관련도:** ★☆☆ — 스트리밍 TTS 아키텍처 연구. 음성 토큰 기반 생성과 상태 계승이라는 점에서 음성 생성 모델링 참고 가치

### 2-3. Represented but Ignored: A Causal Account of Prosodic Underuse in Audio-Language Models

**[Represented but Ignored] (Linkai Peng — University of Connecticut, Baorian Nuchged — UT Austin, 2026.06)** — arXiv preprint
- https://arxiv.org/abs/2608.19211
- **기존 문제:** Audio-LLM은 발화의 내용(what)뿐 아니라 발화 방식(how)—운율(prosody), 감정, 강세 등—을 이해해야 하지만, 운율 정보가 내부적으로 인코딩되어 있음에도 최종 응답에 충분히 반영되지 않는 현상이 존재
- **기존 방법:** Audio-LLM의 음성 이해 능력을 전체 파이프라인 수준에서 평가. 실패가 인코딩 단계, 내부 해석 단계, 의사결정 단계 중 어디에서 발생하는지 구분하지 않음
- **제안 방법:** 세 가지 실패 모드를 정의 — F1: 운율이 지각되지 않음, F2: 운율이 내부적으로 잘못 해석됨, F3: 운율이 올바르게 표현되었으나 의사결정 단계에서 활용되지 않음. 이를 진단하기 위한 단계별 프로브 사다리(stage-specific probe ladder)와 숨겨진 상태 개입(hidden-state intervention) 기법 도입
- **핵심 차별점:** 운율 정보의 "표현은 되지만 무시됨(represented but ignored)" 현상을 인과적으로 입증. 실패 지점을 파이프라인 단계별로 정밀 진단하는 최초의 프레임워크
- **실험 결과:** 4개의 이해 전용(understanding-only) audio-LLM에서 테스트. 운율 정보는 오디오 경로에 보존되고 후기 LLM 상태에서 디코딩 가능하지만, 최종 응답에는 부분적으로만 반영됨을 확인
- **우리 연구 관련도:** ★★☆ — 음성 표현의 내부 인코딩과 활용 간 괴리를 분석한 연구. 음성 SSL 표현이 다운스트림에서 어떻게 활용(또는 무시)되는지에 대한 통찰 제공

## 3. Speech Foundation Model

### 3-1. Emotion Across Speech and Faces: Shared Affective Mechanisms in Multimodal Foundation Models

**[Emotion Across Speech and Faces] (Xiutian Zhao, Luqi Sun, Björn Schuller, Berrak Sisman, 2026.08)** — arXiv preprint
- https://arxiv.org/abs/2608.17102
- **기존 문제:** 멀티모달 파운데이션 모델(MFM)이 음성과 얼굴 감정 인식에서 빠른 진전을 보이지만, 음성 감정과 얼굴 감정을 공유된 감정 기능 유닛(shared affective functional units)으로 인식하는지, 아니면 모달리티별 독립 경로(modality-specific pathways)를 사용하는지 불분명
- **기존 방법:** MFM의 감정 인식 성능을 태스크 수준에서 평가. 내부 뉴런 수준에서 감정 처리 메커니즘을 분석하지 않음
- **제안 방법:** 감정 민감 뉴런(Emotion-Sensitive Neurons, ESNs) — 감정 범주와 선택적으로 연관된 희소 디코더 뉴런을 탐색. Gemma-4-12B-it, MiniCPM-o-4.5, Qwen2.5-Omni-7B 세 가지 MFM에서 음성 감정 인식(SER)과 얼굴 표정 인식(FER)을 상보적 프로브로 사용하여 음향 및 시각 ESN을 식별
- **핵심 차별점:** 시각 ESN의 인과적 유의미성(causal meaningfulness) 입증 — 해당 뉴런을 비활성화하면 연관된 얼굴 감정 인식이 선택적으로 저하됨. 활성화 조향(activation steering)을 통한 감정 인식 제어 가능성 제시
- **실험 결과:** 3개 MFM에서 음향·시각 ESN을 식별하고, 시각 ESN 비활성화 시 해당 감정의 인식 정확도가 선택적으로 저하됨을 실험적으로 확인
- **우리 연구 관련도:** ★★☆ — 멀티모달 파운데이션 모델의 내부 표현 분석 연구. 음성 표현이 감정 인식에서 어떻게 인코딩·활용되는지에 대한 뉴런 수준 분석은 음성 SSL 표현 연구에 참고 가치

### 3-2. Luna-TTS Family Technical Report

**[Luna-TTS] (VUI Labs 연구진, 2026.08)** — arXiv preprint
- https://arxiv.org/abs/2608.11593
- **기존 문제:** 자기회귀(AR) 코덱 언어 모델 기반 TTS는 발화 길이에 비례하는 지연(latency), 오류 누적(error accumulation), RVQ 토큰 그리드에 인위적 생성 순서를 부과하는 한계가 있음
- **기존 방법:** AR 코덱 언어 모델이 RVQ 토큰을 순차적으로 생성. 지연이 발화 길이에 선형 비례하며, 각 단계의 오류가 후속 단계에 전파
- **제안 방법:** Luna-TTS Family — 사전훈련된 AR 텍스트 LLM을 점진적으로 적응(progressive adaptation)하여 인과적(causal) → 양방향(bidirectional) → 블록 인과적(block-causal) 어텐션으로 전환. 공유 토크나이저, 데이터 파이프라인, 0.6B 백본 계보를 가진 두 변형 모델 제공. Luna-TTS는 완전 비자기회귀(fully non-autoregressive)로, 고정 횟수의 병렬 정제(parallel refinement) 단계에서 전체 RVQ 토큰 그리드를 생성. 제로샷 음성 복제(voice cloning)와 음성 편집이 인필링(infilling)으로 자연스럽게 구현됨. 중국어, 영어, 일본어, 한국어 100만 시간 음성으로 사전훈련
- **핵심 차별점:** 텍스트 LLM에서 점진적 적응을 통해 AR에서 비AR로 전환하는 통합 프레임워크. 100만 시간 규모 대규모 사전훈련. 인필링 기반 제로샷 음성 복제 및 편집
- **실험 결과:** 4개 언어(중국어, 영어, 일본어, 한국어) 100만 시간 사전훈련 수행. 비자기회귀 생성으로 고정 단계 수에서 전체 RVQ 그리드 생성
- **우리 연구 관련도:** ★★☆ — 대규모 사전훈련 기반 음성 생성 파운데이션 모델. RVQ 토큰 기반 표현과 LLM 적응이라는 점에서 VQ 기반 음성 표현 연구와 관련

### 3-3. SlimDiffuSE: Towards Efficient Diffusion-Based Speech Enhancement using Slimmable Networks

**[SlimDiffuSE] (Nagashree K. S. Rao, Shrishti Saha Shetu, Mohamed Elminshawi, Emanuël A. P. Habets, Andreas Brendel, 2026.08)** — arXiv preprint
- https://arxiv.org/abs/2608.21188
- **기존 문제:** 확산 모델(diffusion model) 기반 음성 향상(speech enhancement)은 높은 품질을 달성하지만, 데이터 생성 시 대규모 신경망을 다수 평가해야 하므로 전체 연산 복잡도가 높아 실시간 또는 자원 제약 환경에서의 배포가 어려움
- **기존 방법:** 고정 네트워크 폭(fixed network width)의 확산 모델을 전체 생성 과정에 걸쳐 동일하게 적용. 연산 복잡도와 품질 간 유연한 트레이드오프 메커니즘 부재
- **제안 방법:** SlimDiffuSE — 데이터 생성 과정 전반에 걸쳐 적응적 네트워크 폭(adaptive network widths)을 사용하는 슬리머블 확산 모델(slimmable diffusion model) 제안. 탐욕적 탐색 알고리즘(greedy search algorithm)으로 슬리밍 스케줄(slimming schedule)을 최적화하여, 각 확산 단계에서 필요한 최소 네트워크 용량을 결정
- **핵심 차별점:** 확산 단계별 네트워크 폭을 적응적으로 조절하여 최대 87.5%의 연산 복잡도 감소를 달성하면서도 음성 향상 품질 유지. 품질-효율 간 유연한 트레이드오프 제공
- **실험 결과:** PESQ 및 SI-SDR 지표에서 유의미한 성능 저하 없이 연산 복잡도를 최대 87.5% 감소. 자원 제약 하드웨어에서의 실시간 확산 기반 음성 향상 가능성 제시
- **우리 연구 관련도:** ★☆☆ — 확산 모델의 효율화 연구. 음성 처리를 위한 효율적 신경망 설계라는 점에서 참고 가치가 있으나, 음성 SSL/VQ 기반 표현 학습과의 직접적 관련은 낮음

## 요약

오늘 보고서에서는 ASR 3편, SpeechLLM 3편, Speech Foundation Model 3편 총 9편의 신규 논문을 다루었다. ASR 분야에서는 NVIDIA의 프로덕션 지향 스트리밍 문맥 바이어싱(TurboBias 2.0), CTC 정렬 기반 RNN-T 증강(SegAug), 저자원 언어 문서화를 위한 접근성 높은 ASR 파이프라인(Easper)이 주목할 만하다. SpeechLLM 분야에서는 Full-duplex 대화의 텍스트-음성 인터리빙(TurnGuide), 스트리밍 텍스트로부터의 인과적 TTS(X2Streaming-TTS), 그리고 Audio-LLM에서 운율 정보가 "표현은 되지만 무시되는" 현상의 인과적 분석(Represented but Ignored)이 흥미롭다. Speech Foundation Model 분야에서는 멀티모달 파운데이션 모델의 감정 민감 뉴런 분석(Emotion Across Speech and Faces), 100만 시간 규모 사전훈련 기반 비자기회귀 TTS(Luna-TTS), 확산 모델의 적응적 효율화(SlimDiffuSE)가 다루어졌다.
