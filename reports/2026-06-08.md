## 1. ASR (Automatic Speech Recognition)

### **Reducing the Offline-Streaming Gap for Unified ASR Transducer with Consistency Regularization (Andrei Andrusenko, Vladimir Bataev, Lilit Grigoryan, Nune Tadevosyan, Vitaly Lavrukhin, Boris Ginsburg — NVIDIA, 2026-04)** — arxiv preprint
- https://arxiv.org/abs/2604.19079
- **기존 문제:** 하나의 ASR 모델로 오프라인(고정확도)과 저지연 스트리밍(실시간) 디코딩을 동시에 지원하는 것이 어려움. 통합 모델에서 스트리밍 모드의 정확도가 오프라인 대비 크게 떨어지는 성능 격차가 존재.
- **기존 방법:** 오프라인 전용과 스트리밍 전용 모델을 각각 별도로 학습하거나, 청크 기반 어텐션(chunk-limited attention)을 적용한 통합 모델을 학습하되 모드 간 정합성을 명시적으로 강제하지 않는 방식이 주류.
- **제안 방법:** 통합 RNN-Transducer 프레임워크에 청크 제한 어텐션과 오른쪽 컨텍스트(right context), 동적 청크 합성곱(dynamic chunked convolutions)을 적용하고, 모드 일관성 정규화(MCR-RNNT)를 Triton 커널로 효율 구현하여 오프라인-스트리밍 모드 간 출력 합의를 강제.
- **핵심 차별점:** 학습 시 오프라인 모드와 스트리밍 모드의 출력 분포를 명시적으로 정합시키는 일관성 정규화를 RNN-T에 최초 적용. 대규모 모델 및 대규모 데이터셋으로의 확장성 확보. 프레임워크와 영어 모델 체크포인트를 오픈소스로 공개.
- **실험 결과:** 저지연 스트리밍 정확도가 기존 대비 유의미하게 개선되면서, 오프라인 성능은 동일 수준 유지. 대형 모델과 대규모 학습 데이터로 확장 시에도 일관된 효과 확인.
- **우리 연구 관련도:** ★☆☆ — RNN-T 통합 학습 프레임워크로 speech SSL/VQ 연구와 직접 관련은 적으나, 모드 간 일관성 정규화 개념이 표현 학습에서의 augmentation robustness 설계에 간접 참고점 제공.

### **Diarization-Aware Multi-Speaker Automatic Speech Recognition via Large Language Models (Yuke Lin, Ming Cheng, Ze Li, Beilong Tang, Ming Li — Wuhan University / Duke Kunshan University, 2025-06)** — arxiv preprint
- https://arxiv.org/abs/2506.05796
- **기존 문제:** 다화자 ASR에서 겹치는 발화(overlapped speech)를 전사하는 것이 핵심 난제. 기존 SOT(Serialized Output Training) 방식은 절대적 시간 정보를 버리므로, 시간에 민감한 응용(회의 전사 등)에서 활용이 제한됨.
- **기존 방법:** SOT 방식이 다화자 ASR의 표준이었으나, 화자 변환 시점의 절대 타이밍 정보가 소실. 별도 화자 분리(diarization) 후 ASR을 순차 적용하는 캐스케이드 파이프라인은 오류 전파 문제 존재.
- **제안 방법:** 구조화된 화자 분리 입력(structured diarization inputs)과 프레임 수준의 화자 임베딩 및 시맨틱 임베딩을 LLM에 함께 제공하여, LLM이 세그먼트 수준의 전사를 생성. Qwen2.5-3B를 기반 LLM으로, Whisper-large-v3-turbo를 음성 특징 추출기로 활용.
- **핵심 차별점:** 화자 분리 정보를 LLM의 조건 입력으로 명시적으로 통합하여 시간 정보를 보존. SOT의 타이밍 정보 소실 문제를 해결하면서 LLM의 언어 모델링 능력을 활용.
- **실험 결과:** 다국어 이인 대화(dyadic conversations)에서 견고한 성능을 달성하며, 고중첩(high-overlap) 다화자 회의 시나리오에서 우수한 전사 품질 확인.
- **우리 연구 관련도:** ★☆☆ — LLM 기반 다화자 ASR 프레임워크로, speech SSL과의 직접 관련은 낮으나, 프레임 수준 화자-시맨틱 임베딩의 분리적 활용이 표현 학습의 disentanglement 관점에서 참고 가능.

### **BEST-RQ-Based Self-Supervised Learning for Whisper Domain Adaptation (Raphaël Bagat, Irina Illina, Emmanuel Vincent — Université de Lorraine, CNRS, Inria, LORIA, 2025-10)** — arxiv preprint
- https://arxiv.org/abs/2510.24570
- **기존 문제:** Whisper 모델은 범용 도메인에서 높은 성능을 보이지만, 특수 도메인(항공 관제 통신 등 비원어민 화자, 잡음, 전문 용어가 혼재하는 환경)에서는 성능이 급격히 저하. 특히 도메인 특화 전사(transcription) 데이터가 극히 제한적인 상황에서의 적응이 어려움.
- **기존 방법:** 소량 도메인 데이터로 Whisper를 파인튜닝하는 방식이 주류이나, 데이터 부족으로 과적합 위험이 존재. 대규모 비전사 데이터의 효과적 활용 방안이 미흡.
- **제안 방법:** BEARD(BEST-RQ Encoder Adaptation with Re-training and Distillation) 프레임워크 제안. BEST-RQ 자기지도 학습 목적함수와 동결된 교사 인코더로부터의 지식 증류를 결합하여, 비전사 데이터로 Whisper 인코더를 도메인에 적응. 적응된 인코더가 사전학습된 디코더와의 상보성을 유지하도록 설계.
- **핵심 차별점:** SSL 기반 인코더 적응과 지식 증류를 결합하여, 대규모 비전사 데이터를 효과적으로 활용하면서도 인코더-디코더 간 호환성을 보존. BEST-RQ의 랜덤 프로젝션 양자화를 Whisper 도메인 적응에 최초 적용.
- **실험 결과:** 항공 관제 통신(ATCO2) 코퍼스에서, 약 5,000시간 비전사 음성으로 BEARD 적응 후 2시간 전사 데이터로 파인튜닝하여, 파인튜닝만 적용한 모델 대비 12% 상대 WER 개선 달성.
- **우리 연구 관련도:** ★★☆ — BEST-RQ의 랜덤 프로젝션 기반 양자화를 활용한 자기지도 학습이 VQ-based representation 연구와 방법론적으로 연관. SSL 목적함수를 기존 사전학습 모델의 적응에 활용하는 전략이 speech SSL 연구의 downstream 활용 관점에서 참고 가치가 높음.

## 2. SpeechLLM (Speech Language Model)

### **IRAF: Interference-Resilient Adaptive Fusion for Noise-Robust End-to-End Full-Duplex Spoken Dialogue Systems (CUHK / Huawei AudioLab Hong Kong / NTU, 2026-06)** — arxiv preprint
- https://arxiv.org/abs/2606.06559
- **기존 문제:** 전이중(full-duplex) 음성 대화 모델에서, 현실 음향 환경의 방해 화자(interfering speaker)가 사용자 마이크에 유입되면 사용자 쿼리가 오염되어, LLM의 조건화가 교란되고 턴테이킹(turn-taking) 불안정 및 응답 품질 저하를 초래.
- **기존 방법:** 기존 전이중 대화 모델은 사용자 스트림과 에이전트 스트림을 이중 채널로 공동 인코딩하나, 방해 화자에 의한 채널 오염에 대한 명시적 대응 메커니즘이 부재.
- **제안 방법:** IRAF — 경량 스트리밍 호환 모듈로, 타겟 화자 임베딩과 사용자 오디오 임베딩으로부터 스칼라 신뢰도 게이트(scalar reliability gate)를 프레임별로 예측하여, 사용자 표현이 에이전트 임베딩과 융합되기 전에 기여도를 재조정(rescale).
- **핵심 차별점:** 프레임 단위의 적응적 신뢰도 게이팅으로 방해 화자 간섭을 명시적으로 억제하면서, 스트리밍 환경에서의 실시간 처리 호환성 유지. 기존 전이중 모델에 플러그인 방식으로 적용 가능.
- **실험 결과:** MS-MARCO 및 InstructS2S-200K 데이터셋에서, 방해 화자 조건하에서 응답 품질과 전이중 상호작용 모두에서 일관된 성능 향상 확인.
- **우리 연구 관련도:** ★☆☆ — 전이중 대화 시스템의 간섭 제거 모듈로, speech SSL과의 직접 관련은 낮으나, 프레임 수준의 표현 신뢰도 추정 개념이 noisy 환경에서의 표현 학습 견고성 연구에 참고 가능.

### **The Silent Thought: Modeling Internal Cognition in Full-Duplex Spoken Dialogue Models via Latent Reasoning (Donghang Wu, Tianyu Zhang, Yuxin Li, Hexin Liu, Chen Chen, Eng Siong Chng, Yoshua Bengio — NTU / Mila, 2026-03)** — arxiv preprint
- https://arxiv.org/abs/2603.17837
- **기존 문제:** 기존 전이중(full-duplex) 음성 대화 모델은 사용자가 말하는 동안 동시적 추론(concurrent reasoning)을 수행하지 못함. NLP의 기존 "사고" 메커니즘은 사후적(post-hoc) 생성 방식이어서, 실시간 대화의 인과성(causality) 제약과 지연 요구에 부합하지 않음.
- **기존 방법:** 기존 전이중 모델은 사용자 발화 완료 후 추론을 시작하거나, 명시적 텍스트 토큰을 생성하는 CoT(Chain-of-Thought)를 적용하나, 추가 지연이 발생하고 음성의 연속적 특성과 정합되지 않음.
- **제안 방법:** FLAIR(Full-duplex LAtent and Internal Reasoning) — 인간이 듣는 동안 무의식적으로 병행 사고를 수행하는 방식에서 영감을 받아, 음성 인지(perception)와 동시에 잠재 사고(latent thinking)를 수행. 이전 스텝의 잠재 임베딩 출력을 다음 스텝에 재귀적으로 피드하여, 사용자 발화 구간 동안 인과성을 엄격히 준수하면서 연속적 추론을 수행.
- **핵심 차별점:** 명시적 토큰 생성 없이 잠재 공간에서의 재귀적 추론으로, 추가 지연 없이 고품질 응답 생성. 전이중 대화의 인과성 제약을 자연스럽게 충족하면서 추론 능력 확보.
- **실험 결과:** 기존 전이중 모델 대비, 추가 지연 없이 응답의 의미적 일관성과 품질이 향상됨을 실증.
- **우리 연구 관련도:** ★★☆ — 잠재 공간에서의 재귀적 추론이 prediction-free 접근과 개념적으로 연관. 명시적 토큰 생성 없이 잠재 표현만으로 정보를 전달하는 설계가, speech SSL의 표현 공간 설계 및 temporal representation 연구에 방법론적 시사점 제공.

### **Chain-of-Thought Training for Open E2E Spoken Dialogue Systems (Siddhant Arora, Jinchuan Tian, Hayato Futami, Jee-weon Jung, Jiatong Shi, Yosuke Kashiwagi, Emiru Tsunoo, Shinji Watanabe — CMU / Sony, 2025-05)** — Interspeech 2025 accepted
- https://arxiv.org/abs/2506.00722
- **기존 문제:** 엔드투엔드(E2E) 음성 대화 시스템은 전체 미분 가능성을 유지하고 비음소적(non-phonemic) 정보를 보존할 수 있으나, 대규모 학습 데이터가 필요하며 생성되는 응답의 의미적 일관성이 부족.
- **기존 방법:** 기존 E2E 접근법은 대규모 음성-텍스트 쌍 데이터에 의존하거나, ASR→LLM→TTS 캐스케이드 파이프라인으로 각 모듈을 별도 최적화. E2E 모델의 사전학습 태스크(ASR, TTS, 텍스트 LM)와 대화 학습 간의 정합성이 부족.
- **제안 방법:** CoT(Chain-of-Thought) 정형화를 통해, 대화 데이터에 대한 학습이 멀티모달 언어 모델의 사전학습 태스크(ASR, TTS, 텍스트 LM)와 긴밀하게 정렬되도록 설계. 공개된 인간-인간 대화 데이터셋으로 학습하며 계산 효율적.
- **핵심 차별점:** E2E 음성 대화 모델의 학습 목표를 사전학습 태스크와 명시적으로 정렬하는 최초의 CoT 정형화. 대규모 독점 데이터 없이 공개 데이터만으로 효과적 학습 가능.
- **실험 결과:** 베이스라인 대비 ROUGE-1에서 1.5 이상의 개선을 달성. 공개 인간-인간 대화 데이터셋으로 계산 효율적인 학습 성공.
- **우리 연구 관련도:** ★☆☆ — E2E 대화 시스템의 학습 전략 연구로, speech SSL과의 직접 관련은 낮으나, 사전학습 태스크와 downstream 태스크의 정합성 설계가 speech representation의 태스크 전이 연구에 참고 가능.

## 3. Speech Foundation Model

### **WavJEPA: Semantic Learning Unlocks Robust Audio Foundation Models for Raw Waveforms (Goksenin Yuksel, Pierre Guetschel, Michael Tangermann, Marcel van Gerven, Kiki van der Heijden, 2025-09)** — ICLR 2026 accepted
- https://arxiv.org/abs/2509.23238
- **기존 문제:** 원시 파형(raw waveform)에서 직접 오디오 표현을 학습하면 스펙트로그램 계산의 긴 지연과 위상 정보 손실을 극복할 수 있으나, 기존 시간 영역(time-domain) 파운데이션 모델은 다양한 다운스트림 벤치마크에서 스펙트로그램 기반 모델(wav2vec 2.0, HuBERT, WavLM 등) 대비 성능이 떨어짐. 또한 잡음 및 잔향이 있는 실환경에서 성능 저하가 심각.
- **기존 방법:** 스펙트로그램 기반 SSL 모델(wav2vec 2.0, HuBERT, WavLM)이 SOTA를 점유. 시간 영역 모델은 존재하나 학습 효율과 표현 품질이 제한적. JEPA 아키텍처가 비전 분야에서 성공했으나 오디오 원시 파형에의 적용은 미탐구.
- **제안 방법:** WavJEPA — JEPA(Joint-Embedding Predictive Architecture)를 원시 파형에 적용한 시간 영역 오디오 파운데이션 모델. 고수준 시맨틱 표현 학습을 통해 음성 단위(speech unit/token) 수준 학습의 한계를 극복. 잡음·잔향 환경에서의 성능 저하를 해결하기 위해 WavJEPA-Nat(다채널 확장)을 제안하여 자연주의적(naturalistic) 장면의 시뮬레이션 데이터로 학습.
- **핵심 차별점:** JEPA의 시맨틱 표현 학습을 원시 파형에 최초로 적용하여, 기존 시간 영역 SOTA 모델을 광범위한 다운스트림 태스크에서 대폭 초과하면서 계산 자원은 상당히 절약. 다채널 확장(WavJEPA-Nat)으로 잔향·잡음에 대한 강건성 확보.
- **실험 결과:** 다양한 다운스트림 벤치마크에서 기존 시간 영역 오디오 파운데이션 모델을 상당히 초과하는 성능 달성. 계산 자원 요구량도 기존 대비 절감. WavJEPA-Nat은 잔향 및 잡음 환경에서 높은 강건성 확인. ICLR 2026에 채택.
- **우리 연구 관련도:** ★★★ — JEPA 기반 시맨틱 표현 학습이 prediction-free SSL과 직접적으로 연관. 마스크 예측이 아닌 임베딩 예측 방식의 자기지도 학습으로, prediction-free 접근의 핵심 대안 아키텍처. 원시 파형 입력에서의 표현 학습 전략과 잡음 강건성 확보 방법이 speech representation learning 연구에 핵심 참고점.

### **Leveraging Soft Distributions of SSL-Derived Discrete Speech Tokens for Downstream Inference (Kentaro Onda, Satoru Fukayama, Daisuke Saito, Nobuaki Minematsu — The University of Tokyo / AIST, 2026-06)** — Interspeech 2026 accepted
- https://arxiv.org/abs/2606.06806
- **기존 문제:** SSL 모델에서 파생된 이산 음성 토큰은 데이터 압축과 효율적 처리에 유리하지만, 경성 할당(hard assignment — 각 프레임을 하나의 토큰에 배타적으로 매핑)은 양자화 오류로 인해 표현의 풍부함이 소실되어 다운스트림 태스크 성능이 제한됨.
- **기존 방법:** SSL 모델(HuBERT 등)의 연속 표현을 k-means 클러스터링으로 이산화한 뒤 경성 할당된 토큰을 다운스트림에 사용하는 방식이 표준. 학습과 추론 모두에서 동일한 경성 토큰을 사용.
- **제안 방법:** 학습 시에는 경성 이산화의 효율성을 유지하되, 다운스트림 추론(inference) 시에만 연성 토큰 할당(soft token assignment)을 적용. 각 프레임에 대해 복수의 토큰에 대한 확률 분포를 활용하여 표현의 풍부함을 복원.
- **핵심 차별점:** 학습 효율성과 추론 시 표현력을 동시에 확보하는 비대칭적(asymmetric) 접근. 학습 파이프라인 변경 없이 추론 단계의 간단한 수정만으로 성능 향상 달성.
- **실험 결과:** ASR과 음성 합성(speech synthesis) 양쪽에서 경성 할당 대비 일관된 성능 향상. 특히 비원어민(non-native) 음성 ASR에서는 연속 SSL 특징을 사용하는 모델마저 초과하는 성능 달성. Interspeech 2026 채택.
- **우리 연구 관련도:** ★★★ — 이산 토큰의 연성 분포 활용이 VQ-based representation의 양자화 오류 완화 연구와 직접적으로 연관. 경성-연성 이산화의 비대칭 전략은 prediction-free SSL에서 이산 표현 활용 시 핵심 설계 선택지. SSL 모델의 이산 표현이 연속 표현에 근접하거나 초과할 수 있음을 실증한 점이 speech tokenizer 연구에 중요한 시사점.
