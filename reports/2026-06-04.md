## 1. ASR (Automatic Speech Recognition)

### 1-1. SoulX-Transcriber: A Robust End-to-End Framework for Multi-Speaker Speech Transcription

**(Yuhang Dai, Haopeng Lin, Zhennan Lin, Jiale Qian, Jun Wu, Hanke Xie, Hao Meng, Hanlin Wen, Chuang Ding, Shunshun Yin, Ming Tao, Lei Xie, Xinsheng Wang — 2026-06-01)** — arxiv preprint

- **arxiv:** https://arxiv.org/abs/2606.02400
- **기존 문제:** 다화자(multi-speaker) 환경에서 음성 인식은 화자 음색의 유사성, 빠른 화자 전환, 겹치는 발화, 부정확한 화자 경계 분할 등으로 인해 정확한 전사가 매우 어렵다.
- **기존 방법:** 기존에는 ASR과 화자 분리(diarization)를 별도 파이프라인으로 구성하는 캐스케이드 방식이 주류였으며, 각 모듈 간 오류가 전파되는 문제가 있었다.
- **제안 방법:** LLM 기반 프레임워크 내에서 화자 분리와 ASR을 통합적으로 모델링하는 end-to-end 시스템. 2단계 훈련 전략을 채택하여 1단계에서 화자 인식 다중과제 연속 사전훈련으로 화자 표현 학습 및 경계 인식을 강화한다.
- **핵심 차별점:** 캐스케이드 파이프라인 대신 단일 프레임워크에서 화자 귀속(speaker attribution), 시간 기반 분할(timestamped segmentation), 전사를 동시에 학습하여 겹치는 발화와 빠른 화자 전환에서도 화자 일관적 전사를 생성한다.
- **실험 결과:** AISHELL-4, AliMeeting, AMI 벤치마크에서 우수한 성능을 달성하며, 다양한 도메인 시나리오에 대한 높은 적응성을 보임. 코드와 모델 가중치가 Apache 2.0 라이선스로 공개됨.
- **우리 연구 관련도:** ★☆☆ — LLM 기반 다화자 인식 프레임워크로, prediction-free SSL이나 temporal contrastive learning과는 직접적 관련이 적으나, 화자 표현 학습 측면에서 참고 가능.

### 1-2. LaSR: Context-Aware Speech Recognition via Latent Reasoning

**(Heyang Liu, Ziyang Cheng, Jiayi Huang, Wenyang Xiao, Ronghua Wu, Qunshan Gu, Yanfeng Wang, Yu Wang — 2026-05-30)** — arxiv preprint

- **arxiv:** https://arxiv.org/abs/2606.00507
- **기존 문제:** Speech LLM이 음성 언어 이해와 추론에서 진전을 보였지만, 맥락 인식(contextual awareness)이 제한적이어서 화자의 의도와 주제적 맥락을 반영하는 음성 인식에 어려움이 있었다. 특히 전문 용어 인식에서 성능이 떨어진다.
- **기존 방법:** 기존 Speech LLM은 명시적 중간 토큰(chain-of-thought)을 생성하여 추론을 수행하지만, 이는 추론 지연을 유발하고 음향 특성과의 정렬이 부족하다.
- **제안 방법:** LaSR(Latent Speech Reasoning)은 명시적 중간 토큰 대신, 대상 단어의 음향 특성 영역에 CoT 감독(supervision)을 정렬하고, 맥락 정보 기반(grounding)과 전사 전환을 위한 잠재 추론 기간(latent reasoning period)을 도입한다.
- **핵심 차별점:** 명시적 토큰 생성 없이 잠재 공간에서의 추론을 통해 맥락 인식 능력을 향상시키며, 추론 지연 없이 전문 어휘 인식 정확도를 개선한다.
- **실험 결과:** 전문 학술 용어 인식을 위한 대규모 벤치마크 Spoken Darwin-Science를 제안하여, 맥락 인식 음성 인식의 체계적 평가를 가능하게 함.
- **우리 연구 관련도:** ★★☆ — 잠재 공간에서의 추론(latent reasoning)은 prediction-free 접근과 개념적으로 연관되며, 표현 공간에서의 맥락 정보 활용 방식이 참고할 만함.

### 1-3. Efficient ASR Training with Conversations that Never Happened

**(Máté Gedeon, Péter Mihajlik — 2026-06-02)** — arxiv preprint

- **arxiv:** https://arxiv.org/abs/2606.03957
- **기존 문제:** 저자원 언어 및 특정 도메인에서의 대화형 ASR은 도메인에 맞는 다화자 훈련 데이터의 부족으로 성능이 제한된다.
- **기존 방법:** 단일 화자 TTS 합성 데이터를 사용하거나, 실제 대화 데이터를 소량으로 활용하는 방식이 주류였으며, 시나리오 수준의 대화 맥락이 반영되지 않았다.
- **제안 방법:** LLM으로 시나리오 수준의 대화와 참가자 메타데이터를 생성하고, 화자 속성을 TTS 음성 프로파일에 매핑한 후, 합성된 발화를 화자 인식 모의 대화로 조립하는 증강 파이프라인을 제안한다.
- **핵심 차별점:** 단순 TTS 합성이 아닌, 대화 시나리오 생성 → 화자 프로파일 매핑 → 대화 조립의 파이프라인으로, 실제 대화와 유사한 맥락적 다양성을 확보한다. 5개 LLM 패밀리에 대해 단일 생성기, 고정 예산 혼합, 스케일업 설정을 체계적으로 평가.
- **실험 결과:** 헝가리어 BEA-Dialogue 벤치마크에서 67시간 실제 대화 + 636시간 합성 데이터만으로, 2700시간 헝가리어 음성으로 훈련된 zero-shot 모델보다 높은 성능을 달성. FastConformer-Large 아키텍처 사용.
- **우리 연구 관련도:** ★☆☆ — 데이터 증강 파이프라인 연구로, SSL 기반 표현 학습과의 직접적 관련은 적으나, 저자원 환경에서의 효율적 훈련 전략으로 참고 가치가 있음.

## 2. SpeechLLM (Speech Language Model)

### 2-1. Audio Interaction Model

**(Zhifei Xie, Zihang Liu, Ze An, Xiaobin Hu, Yue Liao, Ziyang Ma, Dongchao Yang, Mingbao Lin, Deheng Ye, Shuicheng Yan, Chunyan Miao — 2026-06-03)** — arxiv preprint

- **arxiv:** https://arxiv.org/abs/2606.05121
- **기존 문제:** 현재의 Large Audio Language Model(LALM)은 오프라인 처리 방식이며, 스트리밍 오디오 모델들은 스트리밍 ASR이나 음성 채팅 등 단일 태스크만 처리한다. 실시간으로 소리, 환경, 지시를 듣고 반응하는 통합 모델이 부재했다.
- **기존 방법:** 오프라인 LALM(음성→텍스트 후 처리)과 단일 태스크 스트리밍 모델(streaming ASR 전용, voice chat 전용)이 별도로 존재했다.
- **제안 방법:** 항상 켜진(always-on) 인지-판단-응답(perceive-decide-respond) 루프를 통해 실시간으로 오디오 스트림을 처리하는 통합 스트리밍 LALM인 Audio-Interaction을 제안. SoundFlow 프레임워크로 스트리밍 네이티브 데이터 구축, 이해력 인식 훈련, 비동기 저지연 추론을 end-to-end로 구현한다.
- **핵심 차별점:** 오프라인 태스크 실행 능력을 유지하면서, 온라인 일반 오디오 지시 수행과 음성 대화를 포함한 실시간 상호작용을 하나의 모델에서 가능하게 함. 스트림의 의미(semantics)를 기반으로 언제 응답할지 자율 판단.
- **실험 결과:** StreamAudio-2M 데이터셋(260만 항목, 7개 핵심 능력, 28개 서브태스크)과 Proactive-Sound-Bench를 구축. 8개 벤치마크에서 기존 오디오 태스크 성능을 유지하면서, 실시간 ASR·스트리밍 오디오 지시 수행·능동적 도움 등 오프라인 LALM이 불가능한 기능을 추가로 달성.
- **우리 연구 관련도:** ★★☆ — 실시간 오디오 표현 처리와 스트리밍 인코더 설계가 speech representation learning 관점에서 참고할 만하며, 다중 태스크 통합 학습 방식이 foundation model 설계에 시사점을 줌.

### 2-2. Sympatheia: Emotionally Adaptive Voice Assistant with Continuous Affect Conditioning

**(Sukru Samet Dindar, Riki Shimizu, Xilin Jiang, Nima Mesgarani — 2026-05-30)** — arxiv preprint

- **arxiv:** https://arxiv.org/abs/2606.00851
- **기존 문제:** 기존 음성 대화 시스템은 감정 인식과 감정 표현을 독립적으로 처리하며, 사용자의 감정 상태에 따라 적응적으로 응답하는 연속적 감정 제어가 부족했다.
- **기존 방법:** 이산적(discrete) 감정 분류 기반의 접근이 주류였으며, 감정 인식→텍스트 응답→감정 TTS의 캐스케이드 방식이 사용되었다. 감정을 고정된 클래스 레이블로 처리하여 미세한 감정 변화를 반영하지 못했다.
- **제안 방법:** 연속적 valence-arousal(VA) 제어 신호로 조건화된 speech-to-speech 대화 프레임워크. 12개 명명된 감정이 VA 평면의 해석 가능한 앵커 포인트로 기능하며, 모델이 연속 공간에서 감정 제어를 학습한다. 다중 모달 감지 모듈(얼굴 표정, 생체 신호, 텍스트 감정 기술)로부터의 감정 추정을 동일한 VA 인터페이스로 통합 가능.
- **핵심 차별점:** 이산 감정 분류 대신 연속 VA 공간에서의 감정 제어로 미세한 감정 변화 반영. 음성만으로 감정 증거가 부족한 경우에도 다중 모달 소스를 통합하여 응답 정합성 향상.
- **실험 결과:** Sympatheia-18k(12개 감정 앵커의 감정 조건 합성 음성 대화 코퍼스) 구축. 음성 대화 베이스라인 대비 의미적 내용과 발화 전달 모두에서 감정 적합성이 우수한 응답을 생성함을 실증.
- **우리 연구 관련도:** ★☆☆ — 감정 조건화 표현에 초점을 맞춘 연구로, speech SSL이나 VQ 기반 표현과의 직접적 관련은 낮으나, 연속적 제어 신호 기반 표현 학습의 관점에서 참고할 수 있음.

### 2-3. AURA: Agent for Understanding, Reasoning, and Automated Tool Use in Voice-Driven Tasks

**(Leander Melroy Maben, Gayathri Ganesh Lakshmy, Srijith Radhakrishnan, Siddhant Arora, Shinji Watanabe — 2025-06-29)** — arxiv preprint

- **arxiv:** https://arxiv.org/abs/2506.23049
- **기존 문제:** 대부분의 에이전트(agentic) 연구가 텍스트 기반 상호작용에 집중하여, 자연스러운 모달리티인 음성을 통한 복잡한 목표 지향 태스크 수행이 불가능했다. 기존 음성 어시스턴트는 외부 ASR에 의존하는 단순 명령 수행에 한정되었다.
- **기존 방법:** 텍스트 기반 에이전트 프레임워크(ReAct, ToolFormer 등)가 주류였으며, 음성 입력은 ASR 전처리 후 텍스트 에이전트에 전달하는 캐스케이드 방식이 사용되었다. 오픈소스로 음성-네이티브 에이전트 시스템은 부재했다.
- **제안 방법:** 오픈 가중치 ASR(Whisper-v3-large), TTS, LLM(LLaMA3.3-70B)을 캐스케이드 파이프라인으로 조합한 최초의 오픈소스 음성 네이티브 어시스턴트. 캘린더 예약, 연락처 검색, 웹 검색, 이메일 등의 도구를 동적으로 호출하며, 자연어 프롬프트와 액션 클래스만으로 새 도구를 손쉽게 통합할 수 있는 모듈형 설계.
- **핵심 차별점:** 다중 턴 음성 대화를 통한 복잡한 목표 지향 태스크 수행이 가능한 최초의 오픈소스 시스템. 모듈형 설계로 도구 확장이 용이하며, 폐쇄형 시스템에 근접하는 성능 달성.
- **실험 결과:** VoiceBench에서 OpenBookQA 92.75%(모든 오픈 가중치 시스템 중 최고, GPT-4o 기반 92.97%에 근접), AlpacaEval 4.39(오픈 가중치 시스템과 경쟁적). 인간 평가에서 복잡한 다중 턴 음성 태스크 90% 성공률.
- **우리 연구 관련도:** ★☆☆ — 음성 에이전트 시스템 아키텍처 연구로, speech SSL과의 직접적 관련은 낮으나, 음성 이해 파이프라인에서의 표현 활용 방식을 참고할 수 있음.

## 3. Speech Foundation Model

### 3-1. UniWav: Towards Unified Pre-training for Speech Representation Learning and Generation

**(Alexander H. Liu, Sang-gil Lee 등 — 2025-03)** — ICLR 2025 accepted

- **arxiv:** https://arxiv.org/abs/2503.00733
- **기존 문제:** 음성 분야에서 인식(discriminative) 태스크용 foundation model(wav2vec 2.0, HuBERT 등)과 생성(generative) 태스크용 foundation model이 별도로 존재하여, 각각을 별도로 사전훈련해야 하는 비효율이 있었다.
- **기존 방법:** wav2vec 2.0, HuBERT, data2vec 등은 마스크 예측 기반의 인식 중심 사전훈련을 수행하며, Voicebox, SoundStorm 등은 생성에 특화된 별도의 사전훈련을 수행한다. 두 유형을 통합하는 시도는 없었다.
- **제안 방법:** 표현 인코더와 Flow Matching 디코더를 통합한 인코더-디코더 프레임워크. 인코더는 self-distillation(교사 모델은 인코더의 EMA)과 마스크 오디오 모델링으로 훈련되며, 동시에 디코더를 통한 생성 목적함수로부터도 가이드를 받아 end-to-end로 공동 훈련된다. 이산 병목(discrete bottleneck)을 도입하여 저비트레이트 음성 토큰화도 가능.
- **핵심 차별점:** 인식과 생성을 위한 최초의 통합 사전훈련 프레임워크. 하나의 범용 foundation model로 별도의 특화 모델들을 대체할 수 있음을 실증.
- **실험 결과:** LibriSpeech test-other에서 100h 라벨 데이터로 WER 4.8%, 960h로 WER 4.0% 달성(data2vec 2.0의 4.3%/3.5%에 근접). 음성 인식, TTS, 음성 토큰화에서 각 특화 모델과 동등한 성능. 저비트레이트 토큰화에서 기존 방법 대비 우수한 재합성 품질.
- **우리 연구 관련도:** ★★★ — self-distillation 기반 표현 학습과 생성 목적함수의 공동 훈련은 prediction-free SSL 및 VQ 기반 표현 연구와 직접적으로 관련됨. Flow Matching 디코더와 이산 병목 설계가 speech tokenizer 연구에 중요한 참고점.

### 3-2. EntangleCodec: A Unified Discrete Audio Tokenizer via Semantic-Acoustic Entanglement

**(Hui Li, Yangfan Gao, Junlin Shang, Changhao Jiang, Tao Gui, Qi Zhang, Xuanjing Huang — 2026-06-01)** — arxiv preprint

- **arxiv:** https://arxiv.org/abs/2606.02739
- **기존 문제:** 기존 오디오 토크나이저는 의미(semantic)와 음향(acoustic) 정보를 분리된 스트림으로 처리하여, 스트림 간 중복이나 정렬 불일치가 발생했다. 음성·음악·일반 오디오를 통합 처리하는 범용 토크나이저가 부족했다.
- **기존 방법:** 의미 토큰(ASR 기반)과 음향 토큰(VQ 기반)을 별도로 추출하여 결합하는 분리형(disentangled) 접근이 주류. 대표적으로 SpeechTokenizer, DSA-Tokenizer 등이 별도 스트림으로 의미/음향을 처리.
- **제안 방법:** ASR 전사(transcript) 대신 풍부한 캡션(caption)과 오디오를 정렬하여 양자화 전에 통합된 의미-음향 표현을 학습. Flow-matching 확산 디코더로 음성, 음악, 일반 오디오를 아우르는 고품질 재구성을 달성.
- **핵심 차별점:** 분리(disentanglement) 대신 얽힘(entanglement) 접근으로 언어 내용, 화자 정체성, 감정, 운율, 음향 장면을 하나의 컴팩트한 토큰 스트림에 포착. 캡션 정렬을 통해 ASR 전사보다 더 풍부한 의미 정보를 토큰에 인코딩.
- **실험 결과:** 오디오 이해에서 코덱 기반 베이스라인 대비 MMAR +7.4% 향상. 재구성 품질은 특화 코덱과 경쟁적(UTMOS 3.96 vs 4.02). TTS와 TTA 생성을 통합 프레임워크로 지원. 0.6B에서 8B까지 일관된 스케일링, MMAU에서 8B로 최고 성능.
- **우리 연구 관련도:** ★★★ — VQ 기반 표현 연구에 직접적으로 관련됨. 분리 vs 얽힘 설계 선택의 비교가 speech tokenizer 연구에 핵심적 시사점을 제공하며, 캡션 정렬 기반 표현 학습이 contrastive learning과 개념적으로 연결됨.

### 3-3. PairAlign: A Framework for Sequence Tokenization via Self-Alignment with Applications to Audio Tokenization

**(Adhiraj Banerjee, Vipul Arora — 2026-05)** — arxiv preprint

- **arxiv:** https://arxiv.org/abs/2605.06582
- **기존 문제:** 기존 오디오 토크나이저는 양자화(quantization), 클러스터링, 코덱 재구성 등을 통해 토큰을 로컬하게 할당하므로, 시퀀스 일관성(sequence consistency), 컴팩트함, 길이 제어, 종료 판단, 편집 거리 유사성이 직접 최적화되지 않는다.
- **기존 방법:** RVQ 기반 코덱(SoundStream, EnCodec), 클러스터링 기반(HuBERT k-means), 재구성 기반(VQ-VAE) 등이 주류였으며, 프레임 단위로 로컬하게 토큰을 할당하여 시퀀스 수준의 속성은 부산물이었다.
- **제안 방법:** 토큰화를 조건부 시퀀스 생성으로 취급. 인코더가 음성을 연속 조건으로 매핑하고, 자기회귀 디코더가 BOS로부터 토큰을 생성하여 토큰 정체성, 순서, 길이, EOS 배치를 학습. 콘텐츠 보존 두 뷰(view) 간의 교차 정렬(cross-view alignment)을 통해 자기 감독 학습 수행.
- **핵심 차별점:** 시퀀스 수준의 일관성과 컴팩트함을 직접 최적화하는 최초의 오디오 토큰화 프레임워크. 로컬 할당이 아닌 전체 시퀀스 관점에서 토큰화를 학습.
- **실험 결과:** 3초 음성에서 컴팩트하고 비퇴화(non-degenerate) 시퀀스를 학습하며 넓은 어휘 활용과 강한 교차 뷰 일관성을 달성. TIMIT 검색에서 편집 거리 기반 탐색 성능을 유지하면서 아카이브 토큰 수를 55% 감소.
- **우리 연구 관련도:** ★★☆ — 자기 정렬(self-alignment)을 통한 시퀀스 수준 토큰화는 temporal contrastive learning과 개념적으로 유사하며, 콘텐츠 보존 뷰 간의 일관성 학습이 contrastive 목적함수와 연결됨.
