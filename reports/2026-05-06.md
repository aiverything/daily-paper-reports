## 1. ASR

### **SpeakerLM: End-to-End Versatile Speaker Diarization and Recognition with Multimodal Large Language Models (Han Yin et al., 2025-08)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2508.06372
- 기존 문제: 기존 화자 분리 및 인식(SDR) 시스템은 화자 분리(SD)와 음성 인식(ASR)을 캐스케이드로 수행하여 오류 전파, 중첩 발화 처리 어려움, SD-ASR 간 시너지 미활용 등의 한계가 있음.
- 기존 방법: 캐스케이드 SDR 파이프라인(화자 분리 → ASR), 개별 모듈 최적화, target speaker extraction 후 ASR.
- 제안 방법: Audio-text MLLM 기반의 end-to-end SDR 시스템. SenseVoice-large 오디오 인코더와 Transformer 기반 프로젝터로 오디오 임베딩을 텍스트 임베딩 공간에 정합한 뒤, Qwen2.5-7B-Instruct LLM으로 처리하는 encoder-projector-LLM 아키텍처. 유연한 화자 등록 메커니즘으로 사전 화자 정보가 없는 경우, 알려진 경우, 과다한 경우 모두 대응.
- 핵심 차별점: SDR을 수행하는 최초의 audio-text MLLM. 단일 모델에서 화자 분리·인식·ASR을 통합 수행하며, 화자 등록 조건에 유연하게 대응. 데이터 스케일링에 따른 성능 향상이 뚜렷함.
- 실험 결과: in-domain 및 out-of-domain 공개 SDR 벤치마크 모두에서 기존 SOTA 캐스케이드 베이스라인을 상회. 강한 데이터 스케일링 능력과 일반화 성능 확인.
- 우리 연구 관련도: ★☆☆ (MLLM 기반 SDR 시스템 설계로 SSL/VQ 표현 연구와 직접 관련은 낮으나, 오디오 인코더-LLM 간 표현 정합 구조는 참고 가능)

### **Scaling Multi-Talker ASR with Speaker-Agnostic Activity Streams (Xiluo He, Alexander Polok, Jesús Villalba, Thomas Thebaud, Matthew Maciejewski, 2025-10)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2510.03630
- 기존 문제: 다화자 ASR에서 화자 활동 신호(speaker activity)로 단일 화자 ASR 모델을 적응시키는 패러다임이 일반적이나, 화자 수만큼 ASR 모델을 반복 실행해야 하므로 추론 비용이 화자 수에 비례하여 증가함.
- 기존 방법: 화자별 활동 신호 기반 조건부 ASR(화자당 1회 ASR 추론), serialized output training(SOT), target speaker ASR.
- 제안 방법: 화자별 활동 출력을 2개의 화자 비의존(speaker-agnostic) 스트림으로 변환하여 추론 비용을 화자 수로부터 분리. HEAT(Heuristic Encoding Assignment Training) — 발화를 시작 시간 순으로 비중첩 스트림에 할당하는 휴리스틱 기반 학습 방법. 대화 연속성을 보존하면서 기존 사전학습 ASR 모델과의 호환성 유지.
- 핵심 차별점: 추론 비용이 화자 수에 독립적인 최초의 활동 조건부 다화자 ASR 접근법. 2-스트림 구조로 단순 병합 시 발생하는 성능 저하를 휴리스틱 설계로 해결.
- 실험 결과: 화자 수 증가에도 추론 비용이 일정하면서, 기존 화자별 추론 방식 대비 경쟁력 있는 인식 성능 유지.
- 우리 연구 관련도: ★☆☆ (다화자 ASR 추론 효율화 중심으로 SSL/VQ 표현 연구와 직접 관련은 낮음)

### **Towards Pretraining Robust ASR Foundation Model with Acoustic-Aware Data Augmentation (Dancheng Liu, Amir Nassereldine, Chenhui Xu, Jinjun Xiong — University at Buffalo, 2025-05)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2505.20606
- 기존 문제: Whisper의 뛰어난 강건성은 680K 시간 대규모 학습 데이터에 기인하지만, 이러한 규모의 데이터 수집은 대부분의 연구자에게 비현실적. 학습 데이터의 어떤 속성이 ASR 강건성에 핵심적으로 기여하는지 체계적으로 분석된 바 없음.
- 기존 방법: 대규모 weakly-supervised 학습(Whisper), 노이즈 추가 기반 데이터 증강, 사전학습 후 fine-tuning.
- 제안 방법: 학습 데이터의 언어적 다양성(linguistic diversity)과 음향적 다양성(acoustic diversity)의 기여를 체계적으로 분리하여 분석. 음향적 변이가 전사 일반화의 주요 동인임을 밝히고, 이에 기반한 targeted acoustic augmentation 방법을 제안.
- 핵심 차별점: "언어적 다양성이 아닌 음향적 다양성이 ASR 일반화의 핵심"이라는 실증적 발견. 대규모 데이터 없이도 targeted augmentation으로 강건성 향상 가능.
- 실험 결과: 960시간 LibriSpeech 학습 데이터에서 targeted acoustic augmentation 적용 시 미지 데이터셋에 대한 WER 최대 19.24% 감소.
- 우리 연구 관련도: ★★☆ (음향적 다양성이 표현 학습의 일반화에 핵심적이라는 발견은 speech SSL의 데이터 설계 및 augmentation 전략에 직접 시사점 제공. 특히 prediction-free SSL에서의 data augmentation 설계에 참고 가치)

## 2. SpeechLLM

### **TiCo: Time-Controllable Training for Spoken Dialogue Models (Kai-Wei Chang — MIT, Wei-Chih Chen, En-Pei Hu, Hung-yi Lee — NTU, James Glass — MIT, 2026-03)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2603.22267
- 기존 문제: 기존 spoken dialogue model(SDM)은 자연스러운 음성 응답을 생성하지만, 시간 인식(time awareness)이 부재하여 응답 지속 시간(duration)에 대한 제어가 불가능함. "15초 이내로 답변해줘"와 같은 시간 제약 지시를 따르지 못함.
- 기존 방법: 고정 길이 음성 응답 생성, 후처리 기반 잘라내기(truncation), 캐스케이드 TTS의 속도 조절.
- 제안 방법: 2단계 post-training 프레임워크 — (1) Self-generation으로 Spoken Time Marker(STM)가 주석된 응답을 생성하고 이를 시간 인식 학습의 supervision으로 활용, (2) RLVR(Reinforcement Learning with Verifiable Rewards)로 STM 기반 보상을 통해 실시간 응답 길이 조절을 최적화.
- 핵심 차별점: SDM에 시간 제어 능력을 최초로 부여하는 post-training 방법. 학습 시 관찰된 duration 범위를 넘어서도 일반화되며, speech-query뿐 아니라 text-query 입력에도 전이.
- 실험 결과: 오픈소스·상용·캐스케이드 베이스라인 대비 duration 제어 성능 대폭 개선. 응답 품질은 backbone 모델과 동등 수준 유지.
- 우리 연구 관련도: ★☆☆ (SDM의 temporal control 기법으로 SSL/VQ 표현 연구와 직접 관련은 낮으나, 음성의 시간적 구조를 명시적으로 모델링하는 접근은 temporal contrastive learning에서의 시간 해상도 설계에 간접 참고 가능)

### **EmoOmni: Bridging Emotional Understanding and Expression in Omni-Modal LLMs (Wenjie Tian, Zhixian Zhao, Jingbin Hu, Huakang Chen, Haohe Liu, Binshen Mu, Lei Xie, 2026-02)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2602.21900
- 기존 문제: 기존 Omni-Modal LLM(Omni-LLM)은 통합 오디오-비주얼 인식과 음성 응답이 가능하지만, 복잡한 실세계 감정 시나리오에서 피상적 이해와 맥락 불일치 감정 응답이 빈번. Thinker-Talker 아키텍처에서 hidden state를 통한 암묵적 연결로 감정 디테일이 손실됨.
- 기존 방법: Thinker-Talker 아키텍처의 암묵적 hidden state 전달, 감정 레이블 기반 분류, 단일 모달 감정 인식.
- 제안 방법: Perception–Reasoning–Expression 인과 체인을 모방하는 프레임워크. (1) Perception: fine-grained 멀티모달 인식으로 미세한 음향·시각 신호 추출, (2) Reasoning: Emotional Chain-of-Thought(E-CoT) 메커니즘으로 사용자 의도·감정을 명시적으로 추론, (3) Expression: E-CoT를 고수준 감정 지시로 활용하여 Talker의 정확한 감정 표현 유도. EmoOmniPipe 데이터 파이프라인과 EmoOmniEval 벤치마크 구축.
- 핵심 차별점: 감정 이해·추론·표현을 명시적으로 분리(disentangle)하여, Thinker-Talker 간 감정 정보 손실을 해결. E-CoT가 감정 표현의 명시적 가교 역할.
- 실험 결과: EmoOmni-7B가 동일 Talker 조건에서 Qwen3Omni-30B-A3B-Thinking과 동등한 성능 달성(4배 이상 작은 모델 규모).
- 우리 연구 관련도: ★★☆ (감정·paralinguistic 정보의 명시적 분리(disentanglement)와 표현 전달 구조는 speech representation에서의 정보 분리 학습 관점과 관련. 특히 VQ-based representation에서 semantic/acoustic/paralinguistic 요소 분리 연구에 참고 가치)

### **UAF: A Unified Audio Front-end LLM for Full-Duplex Speech Interaction (Yadong Li, Guoxin Wu, Haiping Hou, Biye Li — Alibaba Inc., 2026-04)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2604.19221
- 기존 문제: Full-duplex 음성 상호작용에서 기존 캐스케이드 음성 처리 파이프라인(VAD → 화자 인식 → ASR 등)은 누적 지연, 정보 손실, 모듈 간 오류 전파가 심각. 각 front-end 태스크가 독립 모델로 처리되어 통합 최적화가 불가능.
- 기존 방법: 개별 VAD·화자 인식·ASR 모델의 캐스케이드 파이프라인, 일부 태스크만 통합하는 부분적 멀티태스크 모델.
- 제안 방법: 다양한 오디오 front-end 태스크(VAD, 턴 감지, 화자 인식, ASR, QA)를 단일 auto-regressive 시퀀스 예측 문제로 재정의한 최초의 통합 오디오 front-end LLM. 600ms 고정 길이 스트리밍 오디오 청크를 입력받고, 참조 오디오 프롬프트로 타겟 화자를 고정한 뒤, 시맨틱 콘텐츠와 시스템 제어 신호(인터럽션 등)를 인코딩하는 이산 토큰을 auto-regressively 생성. 6,000시간 VAD+ASR 데이터와 1,000시간 턴 감지 데이터로 학습.
- 핵심 차별점: Full-duplex를 위한 모든 front-end 태스크를 단일 LLM으로 통합 처리하는 최초 시스템. 스트리밍 청크 입력으로 실시간 처리 가능.
- 실험 결과: VAD에서 F1 97.57%, Recall 97.99%로 3개 오픈소스 VAD 모델 상회. 턴 감지에서 인터럽트 유형 100.0%, 백채널 유형 95.7% 정확도. 개별 front-end 태스크 전반에서 SOTA 달성.
- 우리 연구 관련도: ★★☆ (오디오 front-end 태스크의 이산 토큰 시퀀스 재정의와 auto-regressive 생성 구조는 speech tokenizer 설계와 관련. 스트리밍 환경에서의 오디오 표현 설계에 참고 가치)

## 3. Speech Foundation Model

### **SPEAR: A Unified SSL Framework for Learning Speech and Audio Representations (Xiaoyu Yang, Yifan Yang, Zengrui Jin, Ziyun Cui, Wen Wu, Baoxiang Li, Chao Zhang, Phil Woodland, 2025-10)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2510.25955
- 기존 문제: 음성 중심 SSL 모델(HuBERT, WavLM 등)과 일반 오디오 SSL 모델(BEATs, AudioMAE 등)이 각각 발전해 왔으나, 두 도메인의 표현을 통합적으로 학습하는 프레임워크가 부재. 복잡한 사운드 장면(음성+비음성 혼합)에서의 강건성이 부족.
- 기존 방법: HuBERT/WavLM(음성 중심 masked prediction SSL), BEATs/AudioMAE(일반 오디오 SSL), 도메인별 개별 사전학습 후 태스크별 fine-tuning.
- 제안 방법: 음성 중심 SSL 교사 모델과 일반 오디오 SSL 교사 모델로부터 상보적 지식을 단일 통합 모델로 증류. 교사 표현에 multi-codebook VQ를 적용하여 semantic·acoustic 정보를 포착하는 fine-grained 이산 토큰 생성. 마스킹된 입력으로부터 이질적 교사 표현을 비대칭 사전학습 손실(asymmetric pre-training loss)로 공동 예측. 복잡한 사운드 장면에서의 강건성을 위한 token mixing 메커니즘 도입.
- 핵심 차별점: 음성+일반 오디오의 통합 SSL 프레임워크. Multi-codebook VQ 기반 이산 타겟과 비대칭 손실로 이질적 표현의 효과적 통합. Token mixing으로 복잡 장면 강건성 확보.
- 실험 결과: SUPERB 벤치마크에서 WavLM Large를 15개 태스크 중 12개에서 상회하며 신규 SOTA 달성. HEAR 벤치마크에서도 경쟁력 있는 성능.
- 우리 연구 관련도: ★★★ (multi-codebook VQ 기반 이산 타겟, 비대칭 사전학습 손실, masked prediction SSL이 VQ-based representation 및 prediction-free SSL 연구와 매우 밀접. 교사 표현의 VQ 이산화 전략과 token mixing은 temporal contrastive learning에서의 타겟 설계에 직접 참고 가치)

### **Cross-lingual Matryoshka Representation Learning across Speech and Text (Yaya Sy, Dioula Doucouré, Christophe Cerisara, Irina Illina, 2026-02)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2602.19991
- 기존 문제: 저자원 언어 화자는 언어 장벽(온라인 지식이 소수 지배 언어에 집중)과 모달리티 장벽(정보가 텍스트 중심이나 많은 언어가 구어 중심)을 동시에 직면. 기존 교차언어 검색은 ASR→번역 파이프라인에 의존하여 비용과 오류 전파가 큼.
- 기존 방법: ASR + 기계 번역 캐스케이드 파이프라인, 단일 언어 음성-텍스트 임베딩, 고정 차원 표현 모델.
- 제안 방법: 불어-울로프어(French-Wolof) 이중언어 음성-텍스트 Matryoshka 임베딩 모델 학습. 동결된 텍스트 Matryoshka 모델 내부에 모달리티 융합(modality fusion)을 적용하는 전략이 최적. 대규모 데이터 큐레이션 파이프라인과 새로운 벤치마크 구축. Matryoshka 차원과 rank에 따른 성능-비용 트레이드오프 분석.

### **Quantifying Dimensional Independence in Speech: An Information-Theoretic Framework for Disentangled Representation Learning (Bipasha Kashyap et al., 2026-02)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2602.20592
- 기존 문제: 음성 신호는 감정적·언어적·병리학적 정보를 공유된 음향 채널에 인코딩하나, 이러한 차원 간의 통계적 독립성을 정량적으로 측정하는 체계적 프레임워크가 부재. 기존 disentangled representation 연구는 독립성 가정을 검증하지 않고 적용.
- 기존 방법: 독립성을 가정한 disentangled representation learning(β-VAE, FHVAE 등), 태스크별 개별 특성 추출, 비검증적 독립성 가정.
- 제안 방법: bounded neural mutual information(MI) 추정과 비모수적 검증을 통합한 정보이론적 프레임워크. 수작업 음향 특성에서 차원 간 통계적 의존성을 정량화. Source-Filter 이론에 기반한 기여도 분석(attribution analysis).
- 핵심 차별점: 음성 표현의 차원 간 독립성을 실증적으로 정량화하는 최초의 체계적 프레임워크. "어떤 차원이 실제로 독립적이고, 어떤 차원이 결합되어 있는가"에 대한 실증적 답변 제공.
- 실험 결과: 6개 코퍼스에서 차원 간 MI가 낮음(< 0.15 nats, tight bounds)을 확인하여 약한 통계적 결합을 실증. Source-Filter MI는 상대적으로 높음(0.47 nats). 기여도 분석에서 감정 차원은 source 지배(80%), 언어·병리 차원은 filter 지배(60%, 58%).
- 우리 연구 관련도: ★★★ (음성 표현의 차원별 독립성 정량화가 VQ-based disentangled representation 연구와 매우 밀접. Source-Filter 기여도 분석 결과는 speech tokenizer의 semantic/acoustic 분리 설계에 직접적 가이드라인 제공. Prediction-free SSL에서의 학습 타겟 분리 전략 설계에 높은 참고 가치)
