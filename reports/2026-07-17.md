## 1. ASR (Automatic Speech Recognition)

**[SE-DiCoW: Self-Enrolled Diarization-Conditioned Whisper] (Alexander Polok et al., 2026-01)** — ICASSP 2026 accepted
- https://arxiv.org/abs/2601.19194
- 기존 문제: 다화자 음성에서 화자 분리와 음성 인식을 동시에 수행할 때, 화자 간 완전 중첩(full overlap) 구간에서 STNO(Silence-Target-Non-target-Overlap) 마스크의 모호성이 발생하여 서로 다른 화자의 전사 결과가 혼동되는 문제가 있었음
- 기존 방법: Diarization-Conditioned Whisper(DiCoW)는 화자 분리 출력을 조건 정보로 활용하여 Whisper를 미세 조정하는 방식으로 다국어·다도메인 성능을 보였으나, 완전 중첩 화자 구간에서 STNO 마스크가 거의 동일해지는 한계가 있었음
- 제안 방법: 대화 내에서 목표 화자가 가장 활발하게 발화하는 구간을 자동으로 찾아 enrollment segment로 사용하고, 이를 인코더 각 레이어에서 cross-attention을 통해 고정 조건으로 주입하는 Self-Enrolled 방식을 도입
- 핵심 차별점: 외부 화자 임베딩 없이 대화 자체에서 화자 특성을 추출하여 조건으로 활용함으로써, 중첩 화자 구간의 모호성을 해소
- 실험 결과: DiCoW 대비 macro-average tcpWER을 52.4% 감소시켰으며, Libri3Mix clean에서 75% 이상의 상대적 개선을 달성. 실제 대화 데이터에서도 일관된 성능 향상 확인
- 우리 연구 관련도: ★★☆ — 화자 분리와 음성 인식의 결합은 직접적 관련은 낮으나, self-enrollment 방식의 조건 주입 메커니즘은 representation learning 관점에서 참고 가능

**[BLR-MoE: Boosted Language-Routing Mixture of Experts for Domain-Robust Multilingual E2E ASR] (Guodong Ma et al., 2025-01)** — ICASSP 2025 accepted
- https://arxiv.org/abs/2501.12602
- 기존 문제: 다국어 ASR에서 MoE(Mixture of Experts) 아키텍처를 사용하더라도, 특히 도메인 불일치(mismatched domain) 시나리오에서 언어 혼동(language confusion) 문제가 지속됨
- 기존 방법: LR-MoE(Language-Routing MoE)는 FFN에 MoE를 적용하고 언어 ID 기반 라우터를 사용했으나, self-attention 내 언어 혼동과 라우터의 도메인 불일치에 취약
- 제안 방법: 언어 혼동을 self-attention과 라우터의 두 가지 요인으로 분리(decouple)하고, FFN뿐 아니라 self-attention에도 MoE를 적용하는 attention-MoE 아키텍처를 제안. 추가로 expert pruning과 router augmentation으로 LID 기반 라우터의 견고성을 향상
- 핵심 차별점: 기존의 FFN-only MoE 대비 self-attention까지 MoE를 확장하여 언어 혼동의 근본 원인을 다층적으로 해결하며, expert pruning으로 불필요한 전문가를 제거
- 실험 결과: 10,000시간 규모의 다국어 ASR 데이터셋(Netease)에서 도메인 불일치 조건에서도 안정적인 성능을 검증
- 우리 연구 관련도: ★☆☆ — MoE 기반 다국어 ASR 구조로, speech representation 연구와의 직접 관련도는 낮음

**[NIM4-ASR: Towards Efficient, Robust, and Customizable Real-Time LLM-Based ASR] (Yuan Xie et al., 2026-04)** — arxiv preprint
- https://arxiv.org/abs/2604.18105
- 기존 문제: LLM 기반 ASR 시스템은 높은 정확도를 제공하지만, 실시간 스트리밍과 엔티티 인식(entity-intensive) 시나리오에서의 효율성·견고성이 부족했음
- 기존 방법: 기존 LLM-ASR은 인코더와 LLM의 역할 구분이 명확하지 않아 학습 단계 간 기능 충돌이 발생하거나, 대규모 파라미터로 인해 실시간 추론이 어려웠음
- 제안 방법: 인코더와 LLM 간의 기능적 역할을 원칙적으로 구분하고, 각 모듈의 의도된 능력 경계에 맞춰 다단계 학습 패러다임을 재설계한 production-oriented 프레임워크
- 핵심 차별점: 2.3B 파라미터만으로 대규모 모델 수준의 성능을 달성하면서, 저지연 스트리밍과 엔티티 인식에서 명확한 우위를 보임
- 실험 결과: 25개 벤치마크에서 평가하여 여러 벤치마크에서 SOTA 성능 달성. 스트리밍 능력과 엔티티 집약적 시나리오에서 기존 모델 대비 우위 확인
- 우리 연구 관련도: ★☆☆ — LLM-ASR 시스템 설계로, speech SSL/VQ 연구와는 직접적 관련이 낮음

## 2. SpeechLLM (Speech Language Model)

**[ASPIRin: Action Space Projection for Interactivity-Optimized Reinforcement Learning in Full-Duplex Speech Language Models] (Chi-Yuan Hsiao et al., 2026-04)** — arxiv preprint
- https://arxiv.org/abs/2604.10065
- 기존 문제: Full-duplex speech LM의 temporal dynamics(언제 말할지)를 표준 RL로 최적화하면 semantic quality가 저하되어 심각한 생성 붕괴(generative collapse)와 반복이 발생
- 기존 방법: 기존의 raw-token 수준 RL(GRPO 등)은 발화 타이밍과 발화 내용을 동시에 최적화하려 해서 의미적 일관성이 훼손됨
- 제안 방법: Action Space Projection을 통해 텍스트 어휘를 이진 상태(active speech vs. inactive silence)로 매핑하여 "언제 말할지"와 "무엇을 말할지"를 명시적으로 분리. GRPO에 rule-based reward를 결합하여 사용자 인터럽션과 응답 지연의 균형을 조절
- 핵심 차별점: 타이밍 최적화를 토큰 선택과 분리함으로써 의미적 일관성을 보존하고, duplicate n-gram 비율을 표준 GRPO 대비 50% 이상 감소
- 실험 결과: Turn-taking, backchanneling, pause handling 전반에서 상호작용성 향상. 표준 GRPO 대비 반복 생성을 효과적으로 제거하면서도 대화 반응성은 유지
- 우리 연구 관련도: ★☆☆ — Full-duplex 대화 최적화로, speech representation 연구와의 직접 연관은 낮으나, RL 기반 speech model 학습 방법론에 참고 가치 있음

**[Full-Duplex-Bench v1.5: Evaluating Overlap Handling for Full-Duplex Speech Models] (Guan-Ting Lin et al., 2025-07)** — ICASSP 2026 accepted
- https://arxiv.org/abs/2507.23159
- 기존 문제: Full-duplex speech model은 동시 말하기와 듣기가 가능하지만, 음성 중첩(overlap) 상황에서의 행동을 체계적으로 평가하는 자동화된 벤치마크가 부재
- 기존 방법: 기존 평가는 turn-taking 능력에 초점을 맞추거나 수동 평가에 의존했으며, 다양한 중첩 시나리오를 포괄적으로 다루지 못함
- 제안 방법: 사용자 인터럽션, 사용자 백채널, 타인과의 대화, 배경 음성의 4가지 대표적 중첩 시나리오를 시뮬레이션하는 최초의 완전 자동화된 벤치마크. 범주적 대화 행동, 중지/응답 지연, 운율 적응을 분석하는 포괄적 메트릭 제공
- 핵심 차별점: 오픈소스 및 상용 API 모델 모두와 호환되며, 중첩 처리에 특화된 세분화된 평가 프레임워크를 제공
- 실험 결과: 5개 SOTA 에이전트 벤치마킹에서 두 가지 상반된 전략 발견 — 사용자 입력에 빠르게 반응하는 responsive 접근법과 대화 흐름을 유지하며 중첩 음성을 필터링하는 floor-holding 접근법
- 우리 연구 관련도: ★☆☆ — 평가 벤치마크로, speech representation 연구와의 직접 관련도는 낮으나 spoken dialogue 모델 평가에 참고 가능

**[VITA-Audio: Fast Interleaved Cross-Modal Token Generation for Efficient Large Speech-Language Model] (Zuwei Long et al., 2025-05)** — NeurIPS 2025 accepted
- https://arxiv.org/abs/2505.03739
- 기존 문제: End-to-end speech LM은 오디오 토큰 생성 시 첫 오디오 출력까지의 지연(latency)이 크고, 추론 속도가 느려 실시간 대화에 부적합
- 기존 방법: 기존 speech LM은 텍스트 토큰 생성 후 오디오 토큰을 순차 생성하거나, 별도의 TTS 모듈을 사용하여 지연이 누적됨
- 제안 방법: Multiple Cross-modal Token Prediction(MCTP) 모듈을 도입하여 단일 forward pass에서 여러 오디오 토큰을 동시 생성. 4단계 progressive training 전략으로 음성 품질 손실을 최소화하면서 가속화 달성
- 핵심 차별점: 최초의 end-to-end speech model로서 첫 forward pass에서 바로 오디오를 생성 가능. 32개의 prefill 토큰을 활용하여 첫 오디오 토큰 청크 생성 시간을 236ms → 53ms로 단축
- 실험 결과: 7B 파라미터 규모에서 3~5배 추론 속도 향상 달성. 첫 오디오 지연을 78% 감소시키면서 음성 품질은 유지
- 우리 연구 관련도: ★★☆ — Cross-modal token generation은 speech tokenization과 연관되며, 효율적인 speech-text 매핑 연구에 참고 가능

## 3. Speech Foundation Model

**[F3-Tokenizer: Taming Audio Autoencoder Latents for Understanding and Generation] (Nanjing Univ. & WeNet, 2026-06)** — arxiv preprint
- https://arxiv.org/abs/2606.06357
- 기존 문제: Continuous audio autoencoder는 파형 복원은 잘하지만 latent의 의미 구조가 약하고, self-supervised encoder는 의미를 잘 포착하지만 직접 디코딩이 불가능하여, 이해와 생성을 동시에 지원하는 단일 토크나이저 구축이 어려움
- 기존 방법: 이해용(HuBERT, WavLM)과 생성용(SoundStream, Encodec) 토크나이저를 별도로 사용하거나, 하나의 토크나이저에 두 능력을 결합하려 할 때 trade-off 발생
- 제안 방법: (1) Noise-regularized autoencoder bottleneck — KL 기반 variational training 대신 channel normalization과 stochastic perturbation으로 스케일 제어된 continuous latent 생성. (2) Latent-side representation encoder — frozen autoencoder latent 위에서 RQ-MTP와 frozen-LLM supervision으로 학습
- 핵심 차별점: Autoencoder latent를 직접 활용하되, noise regularization으로 구조화하여 생성용 continuous target을 보존하면서 이해용 high-dimensional representation도 동시에 제공
- 실험 결과: 이해 태스크에서 높은 차원의 representation 성능을 보이면서, 정규화된 continuous latent로 복원 및 autoregressive 생성도 지원
- 우리 연구 관련도: ★★★ — 이해와 생성을 통합하는 토크나이저 설계는 prediction-free speech SSL 및 VQ-based representation 연구와 직접적으로 관련. Noise regularization이 VQ 대안으로서 탐구 가치 높음

**[DashengTokenizer: One Layer is Enough for Unified Audio Understanding and Generation] (Xiaomi Research, 2026-02)** — arxiv preprint
- https://arxiv.org/abs/2602.23765
- 기존 문제: 기존 audio tokenizer는 acoustic tokenizer를 먼저 학습한 후 frozen semantic knowledge를 통합하는 순서로 진행되어, 의미와 음향 정보의 통합이 비효율적
- 기존 방법: 별도의 semantic encoder와 acoustic codec을 결합하거나, multi-layer 아키텍처로 의미-음향 정보를 분리·통합하려는 시도
- 제안 방법: 기존 패러다임을 역전 — pretrained semantic encoder의 frozen semantic features를 유지하면서, mel-spectrogram에서 linear projection 한 층만으로 acoustic 정보를 주입. Linear projection과 표준 acoustic decoder만 학습
- 핵심 차별점: "One layer is enough" — 단일 linear projection으로 semantic-acoustic 통합을 달성하여 극도로 경량화된 학습. 기존의 complex multi-stage 학습 파이프라인을 제거
- 실험 결과: 22개 다양한 태스크의 linear evaluation에서 기존 audio codec 및 audio encoder 베이스라인을 큰 폭으로 초과. 음성 감정 인식, 음악 이해, 음향 장면 분류에서 acoustic injection의 효과 확인. 오디오 복원 품질도 경쟁력 유지
- 우리 연구 관련도: ★★★ — Frozen semantic features에 acoustic 정보를 주입하는 방식은 speech SSL representation의 활용과 직결. Contrastive learning이 아닌 간단한 linear projection의 효과를 보여주어 VQ-based representation 연구에 새로운 시사점 제공

**[MOSS-Audio-Tokenizer: Scaling Audio Tokenizers for Future Audio Foundation Models] (OpenMOSS, 2026-02)** — ICLR 2026 accepted
- https://arxiv.org/abs/2602.10934
- 기존 문제: 기존 audio tokenizer(Encodec, SoundStream 등)는 CNN 기반의 상대적으로 작은 규모로, 대규모 스케일링 시 아키텍처적 한계와 학습 불안정성이 존재
- 기존 방법: CNN 기반 encoder-quantizer-decoder 구조가 주류이며, 이종 아키텍처(CNN encoder + Transformer decoder 등)의 혼합이 스케일링을 어렵게 만듦
- 제안 방법: CAT(Causal Audio Tokenizer with Transformer) — 순수 Transformer 기반으로 encoder, quantizer, decoder를 처음부터 end-to-end로 공동 최적화. 1.6B 파라미터, 3백만 시간의 다양한 오디오 데이터로 사전학습
- 핵심 차별점: 동종(homogeneous) Transformer 아키텍처로 스케일링의 일관성을 확보하고, 24kHz 오디오를 12.5Hz의 극저 프레임 레이트로 압축하면서 무손실급 복원 품질과 높은 수준의 semantic alignment을 동시 달성
- 실험 결과: SOTA 복원 품질을 달성하고, 생성과 이해 양쪽에서 강력한 성능을 보여 차세대 native audio LM의 통합 인터페이스로 기능
- 우리 연구 관련도: ★★★ — 대규모 Transformer 기반 토크나이저의 discrete representation은 VQ-based representation 연구와 직접 관련. 12.5Hz 극저 프레임 레이트의 효과적 양자화는 temporal contrastive learning의 시간 해상도 설계에 시사점 제공

**[XY-Tokenizer: Mitigating the Semantic-Acoustic Conflict in Low-Bitrate Speech Codecs] (Yitian Gong et al., 2025-06)** — arxiv preprint
- https://arxiv.org/abs/2506.23325
- 기존 문제: Speech LM을 위한 이상적인 코덱은 음향 정보 보존과 풍부한 의미 정보 포착을 동시에 해야 하지만, 기존 코덱은 저비트율에서 두 능력 간 충돌(semantic-acoustic conflict)이 발생
- 기존 방법: 단일 양자화 구조에서 semantic과 acoustic을 함께 인코딩하거나, 별도 스트림으로 분리하되 학습 파이프라인이 복잡해지는 문제
- 제안 방법: Multi-stage, multi-task learning을 통해 semantic과 acoustic 능력 간 충돌을 완화하는 코덱. 약 1kbps의 저비트율에서 양쪽 성능을 균형있게 달성
- 핵심 차별점: 저비트율(~1kbps)에서 semantic과 acoustic 성능 모두 SOTA 코덱 수준을 달성하며, 기존 코덱들이 한쪽에만 뛰어난 것과 대조적으로 균형을 이룸
- 실험 결과: ~1kbps에서 semantic 성능과 acoustic 성능 모두 유사 비트율의 SOTA 코덱에 필적하는 성능 달성
- 우리 연구 관련도: ★★★ — 저비트율 speech tokenization에서의 semantic-acoustic 균형 문제는 VQ-based speech representation의 핵심 설계 이슈와 직결. Multi-task learning을 통한 충돌 완화 전략은 prediction-free SSL에서의 representation 목표 설정에 참고 가능

## 이번 주 트렌드 요약 (2026-07-14 ~ 2026-07-17)

1. **Speech Tokenizer 전쟁 가속화**: F3-Tokenizer, DashengTokenizer, MOSS-Audio-Tokenizer, XY-Tokenizer 등 이해(understanding)와 생성(generation)을 동시에 지원하는 통합 토크나이저 연구가 급증. 특히 "semantic-acoustic 충돌 해소"가 공통 주제로, 단순 linear projection(DashengTokenizer)부터 noise regularization(F3-Tokenizer), 대규모 Transformer 스케일링(MOSS-Audio-Tokenizer)까지 다양한 접근법이 제시됨.

2. **Full-Duplex Speech LM의 RL 최적화**: ASPIRin의 Action Space Projection처럼, full-duplex 대화에서의 "언제 말할지"와 "무엇을 말할지"를 분리하는 RL 기법이 등장. 타이밍 최적화와 의미 품질 보존의 균형이 핵심 과제로 부상.

3. **LLM-ASR의 실용화 단계 진입**: NIM4-ASR, VITA-Audio 등 LLM 기반 ASR/Speech LM의 효율성과 실시간 추론에 초점을 맞춘 연구가 증가. 2.3B 파라미터로 SOTA를 달성하거나, 첫 오디오 지연을 78% 줄이는 등 production-ready 수준으로 발전.

4. **다화자 ASR과 화자 분리의 융합**: SE-DiCoW는 외부 화자 임베딩 없이 대화 내에서 자체적으로 화자를 등록(self-enrollment)하는 방식으로 다화자 ASR을 개선. End-to-end 다화자 처리의 실용성이 높아지는 추세.
