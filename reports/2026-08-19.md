## 1. ASR (Automatic Speech Recognition)

### 1-1. AgenticASR: Refining Speech Recognition in Real-World Scenarios via an Agentic Approach

**[AgenticASR] (Zixuan Jiang, Binghao Qiang, Jiaying Chi, Yanqiao Zhu, Kai Yu, Xie Chen — SJTU, 2026.07)** — arXiv preprint
- https://arxiv.org/abs/2607.28175
- **기존 문제:** 기존 ASR은 verbatim 전사(필러, 반복, 자기 수정 등 포함)를 출력하여, 가독성이 떨어지고 다운스트림 태스크(음성 에이전트, 회의록 등)에 불필요한 노이즈를 전파함
- **기존 방법:** 표준 ASR 파이프라인이 원시 전사를 출력한 뒤, 별도의 오프라인 후처리(disfluency removal)로 정제하는 2단계 접근
- **제안 방법:** "Agentic Speech Recognition"이라는 새로운 태스크를 정의하고, ASR-Refiner 아키텍처를 통해 고정 크기 활성 컨텍스트 윈도우 내에서 반복적으로 전사를 정제. 스트리밍 환경에서 실시간으로 깨끗한 전사를 생성
- **핵심 차별점:** 오프라인 후처리가 아닌 온라인/점진적 정제로, 스트림 길이와 무관하게 일정한 연산량으로 동작. AASR-Bench라는 이중언어 벤치마크와 atomic rubric 기반 평가 체계도 함께 제안
- **실험 결과:** AASR-Bench에서 FormalASR 대비 ~27.4점 향상. 두 가지 Qwen 모델 스케일에서 모두 최고 점수 달성. 자동 평가와 전문가 평가 간 높은 일치도 확인
- **우리 연구 관련도:** ★☆☆ — ASR 후처리 중심이며 SSL/표현 학습과는 직접적 관련 낮음

### 1-2. Enhancing Multilingual LLM-based ASR with Mixture of Experts and Dynamic Downsampling

**[MoE-CIF ASR] (Guodong Lin, Ziqi Chen, Yuxiang Fu, Ke Li, Wei-Qiang Zhang — Tsinghua Univ., 2026.06)** — arXiv preprint
- https://arxiv.org/abs/2606.10439
- **기존 문제:** LLM 기반 ASR에서 다국어 일반화(cross-lingual adaptability)와 모달리티 정렬(가변 속도 음성→LLM 토큰 공간 매핑)이 동시에 해결되지 않음
- **기존 방법:** 단일 dense adapter/projector와 고정 비율 다운샘플링을 사용하는 projector 기반 LLM-ASR — 언어별 특화와 적응적 속도 정렬에 한계
- **제안 방법:** Projector에 Mixture-of-Experts(MoE) 아키텍처를 적용하여 언어별 라우팅을 가능하게 하고, 수정된 Continuous Integrate-and-Fire(CIF) 메커니즘으로 콘텐츠 적응적 다운샘플링 수행
- **핵심 차별점:** MoE를 통한 언어 특화와 CIF를 통한 적응적 속도 정렬을 하나의 projector 설계에서 동시 해결. 기존 방법들이 이 두 문제를 별개로 다뤘던 것과 차별화
- **실험 결과:** MLCSLM-dev WER 15.27%, FLEURS 10.46%, CommonVoice 13.87% (11개 언어 out-of-domain 평가에서 기존 방법 대비 최고 성능)
- **우리 연구 관련도:** ★☆☆ — 다국어 ASR 파이프라인 설계 중심, 표현 학습 자체와는 간접적 관련

### 1-3. Fast and Robust On-Device Speaker Diarization: Relative Minimum Cluster Size for Stride-Accelerated Pipelines

**[On-Device Diarization] (Fumiaki Yamaguchi, 2026.06)** — arXiv preprint
- https://arxiv.org/abs/2606.08505
- **기존 문제:** 온디바이스 화자 분리(diarization)에서 추론 비용 절감을 위해 segmentation stride를 늘리면, 실제 환경 데이터에서 정확도가 급격히 하락
- **기존 방법:** Pyannote 3.1 파이프라인에서 고정(절대) 최소 클러스터 크기를 사용. 기존 가속 연구들은 실제 환경 강건성 저하 원인을 분리하지 못함
- **제안 방법:** 가속 시 정확도 하락의 근본 원인을 '고정 최소 클러스터 크기'로 인한 화자 수 과소 추정(under-counting)으로 진단. 상대적 최소 클러스터 크기(mcs = round(f·n), f ≈ 0.01)를 제안하여 임베딩 수에 비례하도록 적응
- **핵심 차별점:** 새로운 diarization 아키텍처가 아닌, stride 가속 시 발생하는 특정 실패 모드를 진단하고 단순하면서 효과적인 하이퍼파라미터 적응으로 해결
- **실험 결과:** AMI(Apple M4)에서 RTF 0.061→0.005 (~12.2배 가속), DER 동일 유지. VoxConverse에서 naive 가속 DER 0.075→0.113 상승을 0.079로 복구(손실의 ~89% 회복). 60분 회의를 M4에서 30-50초, RTX 5070 Ti에서 10초 미만으로 처리
- **우리 연구 관련도:** ★☆☆ — 클러스터링 하이퍼파라미터 최적화 중심, 표현 학습과는 무관

## 2. SpeechLLM (Speech Language Model)

### 2-1. DuplexOmni: Real-Time Listening, Seeing, Thinking, and Speaking for Full-Duplex Interaction

**[DuplexOmni] (Muye Huang, Lingling Zhang, Xingyu Yu, Lei Shi et al., 2026.06)** — arXiv preprint
- https://arxiv.org/abs/2606.09186
- **기존 문제:** 기존 "omni" 풀듀플렉스 모델은 복잡한 추론이나 도구 사용 시 실시간 응답성이 떨어짐 — 스트리밍 오디오+비디오 입력 처리와 심층 추론이 단일 모놀리식 모델에서 충돌
- **기존 방법:** VITA, Freeze-Omni, OmniFlatten 등이 내부 텍스트 매개 또는 음성/텍스트 토큰 플래트닝을 사용하지만, 추론 중 실시간 반응 유지 메커니즘 부재
- **제안 방법:** 풀듀플렉스 상호작용을 연속적 멀티턴 대화로 모델링. Interaction layer(실시간 오디오+비디오 스트리밍 처리)와 Thinking layer(복잡한 추론/도구 사용)를 분리하여 비동기 병렬 실행 — System 1/2 인지 구조에서 영감
- **핵심 차별점:** 오디오뿐 아니라 비디오까지 포함하는 멀티모달 풀듀플렉스에서, 심층 추론 수행 중에도 상호작용이 끊기지 않는 구조적 디커플링
- **실험 결과:** 다수의 공개 벤치마크에서 자연스러운 풀듀플렉스 상호작용 능력과 함께 강한 성능 보고 (상세 벤치마크 수치는 원문 참조)
- **우리 연구 관련도:** ★☆☆ — 멀티모달 에이전트 아키텍처 중심, 음성 표현 학습과는 간접적 관련

### 2-2. Liberating LLM Capabilities in Full-Duplex Speech Models (Listen-Write-Speak)

**[Listen-Write-Speak] (Luoyuan Zhang, Bokai Xu, Junbo Cui, Weiyue Sun et al., 2026.06)** — arXiv preprint
- https://arxiv.org/abs/2606.07547
- **기존 문제:** 풀듀플렉스 Speech LLM은 모든 출력이 음성으로 제한되어, 기저 LLM이 가진 텍스트 네이티브 능력(코드 생성, 구조화된 분석, 다단계 추론)이 억제됨
- **기존 방법:** 기존 풀듀플렉스 Speech LLM은 단일 음성 출력 채널만 생성하며, 모델의 텍스트 추론 역량을 노출하지 않음
- **제안 방법:** Listen-Write-Speak(LWS) — 텍스트 우선 3채널 패러다임. 하나의 autoregressive LLM이 동시에 (1) 사용자 오디오를 듣고, (2) 자유형식 텍스트를 주 출력으로 작성하며, (3) 실시간 음성 응답을 병렬 생성. 토큰 스키마 변경만으로 구현(아키텍처 수정 불필요)
- **핵심 차별점:** 텍스트를 주 채널로, 음성을 병렬 파생물로 설정하여 풀듀플렉스 음성 인터페이스 내에서 LLM의 텍스트 네이티브 능력(코드, 구조화된 추론)을 복원
- **실험 결과:** 방법론 및 아키텍처 확인됨 (상세 벤치마크는 원문 참조)
- **우리 연구 관련도:** ★☆☆ — LLM 능력 활용 패러다임 중심, 음성 표현 학습과는 무관

### 2-3. Overcoming State Inertia in Full-Duplex Spoken Language Models via Activation Steering

**[State Inertia / Activation Steering] (Cheng-Kuang Chang, Kai-Wei Chang, Alexander H. Liu, James Glass — MIT CSAIL, 2026.06)** — arXiv preprint
- https://arxiv.org/abs/2606.11386
- **기존 문제:** 풀듀플렉스 음성 언어 모델(FD-SLM)이 "생성"(말하기)과 "인지"(듣기) 상태 간 전환 시 내부 상태가 지연되는 "state inertia" 현상 — 갑작스러운 사용자 인터럽트 처리 불량
- **기존 방법:** PersonaPlex 등 기존 FD-SLM은 턴테이킹/인터럽트를 학습 데이터에만 의존하여 암묵적으로 처리, 내부 상태 전환의 명시적 메커니즘 제어 없음
- **제안 방법:** Hidden representation의 기계적 해석(mechanistic interpretability) 분석을 통해 스트림별 예측 패턴을 발견. "Perception vector"(생성 vs 인지 상태의 hidden state 차이)를 추론 시 더하는 **training-free activation steering** 기법으로 상태 전환 가속
- **핵심 차별점:** 재학습이나 RL 기반 정렬 없이, 해석 가능성 기반의 추론 시점 개입(activation steering)만으로 인터럽트 처리 개선 — 기존 RL 기반 접근과 근본적으로 다른 패러다임
- **실험 결과:** Full-Duplex-Bench(FDB)에서 PersonaPlex의 correctness 28%→45%, IWOR 메트릭 40%→72%로 향상. 전체 응답 품질은 유지하면서 인터럽트 처리 능력 대폭 개선
- **우리 연구 관련도:** ★★☆ — 내부 표현의 해석과 조종이라는 관점에서 speech representation 연구와 방법론적 연결점 존재

## 3. Speech Foundation Model

### 3-1. HybridCodec: Fast Dual-Stream, Semantically Enhanced Neural Audio Codec

**[HybridCodec] (Arjun Gangwar, S. Umesh — IIT Madras, 2026.06)** — Interspeech 2026 accepted
- https://arxiv.org/abs/2606.06743
- **기존 문제:** 멀티모달 LLM의 음성 토크나이저로 사용되는 신경 오디오 코덱에서, 의미 정보(semantic)를 통합하려면 (a) 단일 스트림 RVQ의 첫 레이어에 SSL 증류 또는 (b) 이중 스트림 아키텍처 사용 — 후자가 더 효과적이지만 계산 비용이 높음
- **기존 방법:** SpeechTokenizer 스타일의 단일 스트림 SSL 증류 코덱, 또는 DualCodec 같은 느린 이중 스트림 코덱
- **제안 방법:** 의미(semantic)와 음향(acoustic) 브랜치를 분리한 통합 아키텍처. SSL 표현을 semantic 스트림에 증류하되, 추론 시 SSL 모델 불필요
- **핵심 차별점:** 단일 스트림 증류와 이중 스트림 분리의 장점을 결합. 기존 이중 스트림 코덱 대비 ~3배 속도 향상하면서도 동등한 품질 유지. 초저 프레임 레이트(6.25 Hz) 달성
- **실험 결과:** LibriSpeech에서 RVQ-1 WER 15.36% (최저), 화자 유사도 97.1. In-domain 및 zero-shot 다국어 설정 모두에서 강건한 성능
- **우리 연구 관련도:** ★★★ — SSL 증류 기반 의미-음향 분리 코덱으로, VQ 기반 표현 학습 연구와 직접적으로 관련. 프레임 레이트 설계도 참고할 만함

### 3-2. ReLMCodec: Designing Predictable Speech Tokens from Pre-Quantization Phoneme Structure

**[ReLMCodec] (Zixiang Wan, Xusheng Yang, Zheng Wang, Peiji Yang et al. — Peking Univ. / Tencent, 2026.08)** — arXiv preprint
- https://arxiv.org/abs/2608.08286
- **기존 문제:** 신경 코덱 언어 모델에서, 고충실도 재구성에 최적화된 토큰이 반드시 autoregressive LM이 예측하기 쉬운 토큰은 아님 — 예측 가능성(predictability) vs 재구성(reconstruction) 간의 긴장 관계
- **기존 방법:** X-Codec2, FocalCodec, SemantiCodec 등 재구성 중심의 단일 코드북 코덱 — 파형 충실도만 최적화하고 토큰 예측 가능성은 명시적으로 고려하지 않음
- **제안 방법:** "preserve-control-refine" 3단계 설계: (1) 양자화 전 SSL feature의 음소 구조를 보존, (2) Pre-quantization Anchor-Preserving Adaptation(PAPA)으로 재구성에 의한 표현 drift 제어, (3) WavLM-Large layer-24 teacher로 양자화된 잠재 공간 정제
- **핵심 차별점:** "양자화 전 음소 구조가 명확할수록 autoregressive 토큰 예측이 쉬워진다"는 경험적 연결 고리를 최초로 명시적으로 활용. 재구성만 최적화하는 기존 접근과 차별화
- **실험 결과:** 650 bps에서 FocalCodec, SemantiCodec 대비 거의 모든 메트릭 향상. 800 bps에서 X-Codec2 대비 WER 5.53→3.96, SIM 0.801→0.804, PESQ 2.13→2.40. 다운스트림 TTS에서도 명료도·화자 유사도 개선
- **우리 연구 관련도:** ★★★ — VQ 기반 음성 토큰 설계에서 예측 가능성과 재구성의 균형 문제를 직접 다루며, speech tokenizer 연구에 핵심적 시사점 제공

### 3-3. LATTE: Exploring Token-Space Manipulation in Latent Audio Tokenizers

**[LATTE] (Francesco Paissan, Luca Della Libera, Mirco Ravanelli, Cem Subakan et al. — Mila / Université Laval / Concordia, 2026.05)** — arXiv preprint
- https://arxiv.org/abs/2605.11192
- **기존 문제:** 대부분의 신경 오디오 코덱은 프레임 수준에서 시간 정렬된 토큰을 생성하여, 화자 정체성이나 배경 소음 같은 전역(utterance-level) 변동 요인을 분리·조작하기 어려움
- **기존 방법:** 표준 프레임 정렬 RVQ/latent 코덱에서는 모든 토큰이 로컬 시간 윈도우에 대응하여, 전역 속성 편집에 별도의 지도 학습 편집 모델이나 테스트 시점 최적화 필요
- **제안 방법:** LATTE(Latent Audio Tokenizer for Token-space Editing) — 학습 가능한 잠재 토큰(learnable latent tokens)을 오디오 feature 시퀀스에 추가하고, 이 비시간 정렬 토큰만 양자화/디코딩에 사용. 컴팩트한 전역 병목(global bottleneck) 생성
- **핵심 차별점:** 비지도/학습 없는(training-free) 전역 속성 편집이 가능 — 발화 간 잠재 토큰 위치를 교환하는 것만으로 화자 정체성이나 배경 환경 변환. 별도 편집 모델이나 테스트 시점 최적화 불필요
- **실험 결과:** Jaccard 관련성 분석으로 개별 잠재 슬롯이 비균일하게 특화됨을 확인(화자 정체성, 노이즈 정보 등 집중). 소음 관련 슬롯 교환으로 배경 환경 변경, 화자 관련 슬롯 교환으로 부분적 화자 전이 성공. 저비트레이트 음성 코딩에서도 경쟁력 있는 재구성 품질 유지
- **우리 연구 관련도:** ★★★ — 비시간 정렬 잠재 토큰을 통한 전역 표현 분리는 prediction-free SSL 및 VQ 기반 표현 학습 연구와 직접적으로 관련. 시간 축과 분리된 표현 설계라는 점에서 temporal contrastive learning과도 방법론적 접점
