## 1. ASR (Automatic Speech Recognition)

### 1.1 Back to Basics: Revisiting ASR in the Age of Voice Agents

**[Back to Basics: Revisiting ASR in the Age of Voice Agents]** (Geeyang Tay, Wentao Ma, Jaewon Lee, Yuzhi Tang, Daniel Lee, Weisu Yin, Dongming Shen, Silin Meng, Yi Zhu, Mu Li, Alex Smola, 2026.03) — arXiv preprint (Boson AI)

- arxiv URL: https://arxiv.org/abs/2603.25727
- **기존 문제**: 현재 ASR 시스템은 정제된 벤치마크에서 인간 수준의 정확도를 달성하지만, 실제 음성 에이전트 환경에서는 환경 열화, 인구통계 변동, 언어 다양성 등 체계적으로 평가되지 않는 조건에서 실패함
- **기존 방법**: 기존 ASR 벤치마크가 실세계 조건을 체계적으로 커버하지 못하며, 모델 강건성을 다차원적으로 진단하는 도구가 부재
- **제안 방법**: WildASR — 4개 언어의 실제 인간 발화로 구성된 다국어 진단 벤치마크 제안. 환경 열화(environmental degradation), 인구통계 변동(demographic shift), 언어 다양성(linguistic diversity) 3개 축으로 ASR 강건성을 분리 분석. 실무 배포 의사결정을 위한 3가지 분석 도구 제공
- **핵심 차별점**: 실제 음성 에이전트 시대에 ASR 강건성을 체계적으로 진단하는 최초의 다축 벤치마크. 모델의 안전 위험(환각 현상)까지 분석
- **실험 결과**: 7개 주요 ASR 시스템 평가 결과, 심각하고 불균등한 성능 저하 확인. 모델 강건성이 언어 간/조건 간 전이되지 않음. 부분적/열화된 입력에서 모델이 실제 발화되지 않은 그럴듯한 콘텐츠를 환각(hallucinate)하여 하위 에이전트 동작에 안전 위험 초래
- **우리 연구 관련도**: ★☆☆ — ASR 벤치마크/평가 연구로, speech SSL 표현 학습과 직접 관련 낮음. 다만 음성 표현의 강건성 평가 관점에서 참고 가치 있음

### 1.2 Whisfusion: Parallel ASR Decoding with Masked Diffusion

**[Whisfusion]** (Taeyoun Kwon, Junhyuk Ahn, Taegeun Yun, Heeju Jwa, Yoonchae Choi, Siwon Park, Nam-Joon Kim, Jangchan Kim, Hyun Gon Ryu, Hyuk-Jae Lee, 2025.08) — ASRU 2025

- arxiv URL: https://arxiv.org/abs/2508.07048
- **기존 문제**: 자기회귀(AR) ASR 디코딩은 순차적 토큰 생성으로 인해 긴 발화에서 지연 시간이 크며, 처리량이 제한적
- **기존 방법**: Whisper 등 AR 기반 디코더가 순차적으로 토큰을 생성하여, 긴 오디오에서 디코딩 속도가 병목
- **제안 방법**: Frozen Whisper-large-v3 오디오 인코더 위에 마스크 확산(masked diffusion) 디코더를 처음부터 학습. 모든 블록에서 오디오 임베딩에 대한 교차 어텐션 수행. ~68k시간 11개 언어 데이터로 학습하고, Parallel Diffusion Decoding으로 소수 스텝만에 전사 생성
- **핵심 차별점**: 확산 모델을 ASR 디코딩에 적용한 최초의 본격적 시도. AR 모델 대비 병렬 디코딩으로 처리량을 극대화하면서도 정확도 유지 또는 향상
- **실험 결과**: 다수 벤치마크에서 Whisper-large-v3 대비 정확도 우위 달성, 속도 4~5배 향상. Canary, Qwen3-ASR과 경쟁적 정확도에서 3~7배 빠른 속도. AR 대비 14배 높은 처리량 (3,180 vs 230 tokens/s). 20초 이상 긴 발화에서 최대 2.6배 빠른 지연 시간
- **우리 연구 관련도**: ★☆☆ — ASR 디코딩 효율화 연구로, 음성 표현 학습과 직접 관련 낮음. 확산 모델의 이산 시퀀스 적용 관점에서 참고 가능

### 1.3 Speaker Targeting via Self-Speaker Adaptation for Multi-talker ASR

**[Speaker Targeting via Self-Speaker Adaptation]** (Weiqing Wang, Taejin Park, Ivan Medennikov, Jinhan Wang, Kunal Dhawan, He Huang, Nithin Rao Koluguri, Jagadeesh Balam, Boris Ginsburg, 2025.06) — Interspeech 2025 (NVIDIA)

- arxiv URL: https://arxiv.org/abs/2506.22646
- **기존 문제**: 다화자 ASR에서 목표 화자의 음성만 인식하려면 화자 임베딩이나 등록 오디오 등 명시적 화자 쿼리가 필요하여 실용성이 제한됨
- **기존 방법**: 목표 화자 임베딩(target speaker embedding) 또는 등록 발화(enrollment audio)를 통해 화자를 특정하는 방식이 주류. 추가 화자 정보 입력이 필수적
- **제안 방법**: 화자별 음성 활동 예측(speaker-wise speech activity prediction)을 통한 자기 화자 적응(self-speaker adaptation) 방법 제안. 화자 감독 활성화(speaker supervision activations)로 화자 특화 커널을 생성하여 ASR 인코더 선택 레이어에 주입
- **핵심 차별점**: 명시적 화자 등록이나 임베딩 없이 스트리밍 환경에서 완전 중첩 음성 처리가 가능한 최초의 자기적응형 다화자 ASR
- **실험 결과**: 오프라인 및 스트리밍 시나리오 모두에서 SOTA 성능 달성. 심각한 음성 중첩 상황에서도 효과적인 화자 중심 인식 수행
- **우리 연구 관련도**: ★☆☆ — 다화자 ASR 기법 중심으로 표현 학습과 직접 관련 낮음. 화자 표현 학습 관점에서 간접 참고 가능

## 2. SpeechLLM (Speech Language Model)

### 2.1 OpenS2S: Advancing Fully Open-Source End-to-End Empathetic Large Speech Language Model

**[OpenS2S]** (Chen Wang, Tianyu Peng, Wen Yang, Yinan Bai, Guangfu Wang, Jun Lin, Lanpeng Jia, Lingxiang Wu, Jinqiao Wang, Chengqing Zong, Jiajun Zhang, 2025.07) — arXiv preprint (CASIA)

- arxiv URL: https://arxiv.org/abs/2507.05177
- **기존 문제**: 기존 대형 음성 언어 모델(LLaMA-Omni2, Qwen2-Audio, GLM-4-Voice, Kimi-Audio 등)이 학습 데이터, 사전학습 코드, 미세조정 코드를 모두 공개하지 않아 재현성과 투명성이 부족
- **기존 방법**: 대부분의 LSLM이 모델 가중치만 공개하거나, 학습 파이프라인의 일부만 공개하여 완전한 재현이 불가능
- **제안 방법**: BLSP-Emo 기반 공감적 음성-텍스트 모델에 스트리밍 인터리브 디코딩 아키텍처를 결합하여 저지연 음성 생성. Qwen3-8B-Instruct를 LLM 백본으로 사용. 지도 의미 음성 토크나이저와 자기회귀 TTS 언어 모델을 통해 엔드투엔드 학습. 다양하고 고품질의 공감적 음성 대화를 저비용으로 합성하는 자동 데이터 구축 파이프라인 포함
- **핵심 차별점**: 모델, 학습 데이터, 사전학습 코드, 미세조정 코드를 모두 공개한 최초의 완전 오픈소스 공감형 LSLM. V1.5(2025년 10월)에서 성능 대폭 개선
- **실험 결과**: 12개 오픈소스 모델 및 GPT-4o-Audio와 EchoMind 벤치마크에서 비교 평가 수행. 공감적 음성 상호작용에서 유의미한 성능 달성
- **우리 연구 관련도**: ★☆☆ — 음성 언어 모델 시스템 연구로, speech SSL과 직접 관련 낮음. 음성 토크나이저 설계 관점에서 간접 참고 가능

### 2.2 ParaS2S: Benchmarking and Aligning Spoken Language Models for Paralinguistic-aware Speech-to-Speech Interaction

**[ParaS2S]** (Shu-wen Yang, Ming Tu, Andy T. Liu, Xinghua Qu, Hung-yi Lee, Lu Lu, Yuxuan Wang, Yonghui Wu, 2025.11) — arXiv preprint (NTU & ByteDance Seed)

- arxiv URL: https://arxiv.org/abs/2511.08723
- **기존 문제**: 기존 S2S 모델이 감정, 톤, 화자 특성 등 준언어적(paralinguistic) 단서를 처리하고 콘텐츠와 스타일 모두에서 적절하게 응답하는 능력이 충분히 탐구되지 않음
- **기존 방법**: 기존 S2S 모델 평가가 텍스트 콘텐츠 정확도에 집중하며, 발화 스타일의 적절성을 체계적으로 평가하는 프레임워크 부재. SFT(지도 미세조정)가 주된 최적화 방법
- **제안 방법**: ParaS2SBench — 다양하고 도전적인 입력 쿼리로 S2S 모델의 콘텐츠와 스타일 적절성을 종합 평가하는 벤치마크. PolyTone 학습 전략과 다단계 프레임워크로 스타일 환각을 방지하는 자동 심사기 구축. ParaS2SAlign — GRPO(Group Relative Policy Optimization)를 통한 RL 정렬로 비레이블 음성에서 탐색 및 학습
- **핵심 차별점**: 파형 수준에서 응답 콘텐츠와 발화 스타일을 직접 평가·최적화하는 최초의 RL 프레임워크. 준언어적 인식을 위한 체계적 벤치마크와 정렬 방법을 동시 제안
- **실험 결과**: 기존 S2S 모델들이 준언어적 속성에 적절히 응답하지 못하며 파이프라인 기반 베이스라인과 동등한 수준. RL 접근법(ParaS2SAlign)이 SFT 대비 응답 콘텐츠 및 발화 스타일 적절성에서 10% 상대적 개선 달성
- **우리 연구 관련도**: ★★☆ — 준언어적 특성의 음성 표현 관점에서 speech SSL 표현이 포착하는 정보의 질적 평가와 관련. 음성 표현의 준언어적 정보 보존 연구에 참고 가치

### 2.3 OSUM-EChat: Enhancing End-to-End Empathetic Spoken Chatbot via Understanding-Driven Spoken Dialogue

**[OSUM-EChat]** (Xuelong Geng, Qijie Shao, Hongfei Xue, Shuiyuan Wang, Hanke Xie, Zhao Guo et al., 2025.08) — arXiv preprint (ASLP@NPU)

- arxiv URL: https://arxiv.org/abs/2508.09600
- **기존 문제**: 공감적 음성 대화 시스템이 대규모 대화 데이터셋에 과도하게 의존하며, 공감 전달에 중요한 준언어적 단서 추출이 부족. 공감 특화 데이터셋 및 평가 프레임워크 부재
- **기존 방법**: 기존 엔드투엔드 음성 대화 모델이 공감적 응답 생성에 한계를 보이며, 언어적 내용과 준언어적 특성을 통합적으로 활용하지 못함
- **제안 방법**: (1) 3단계 이해 기반 음성 대화 학습 전략 — 대형 음성 이해 모델의 능력을 음성 대화 태스크로 확장. (2) 언어-준언어 이중 사고 메커니즘 — 준언어적 이해를 사고의 사슬(Chain of Thought)로 통합하여 대화 생성과 결합. (3) EChat-200K 데이터셋(~20만 공감적 S2S 대화) 및 EChat-eval 벤치마크 구축
- **핵심 차별점**: 음성 이해 모델을 기반으로 한 이해 주도(understanding-driven) 접근법으로, 준언어적 CoT를 통해 제한된 데이터 환경에서도 공감적 응답 생성. 대규모 공감 대화 데이터셋과 평가 벤치마크를 동시 제공
- **실험 결과**: 다중 레이블 시나리오에서 GPT-4 점수 72.0 달성. 음향 이벤트 인식 및 응답 생성에서 87.1점. 기존 엔드투엔드 음성 대화 모델 대비 공감적 응답성에서 우위 입증
- **우리 연구 관련도**: ★★☆ — 준언어적 이해를 위한 음성 표현 활용 관점에서 참고 가치. 음성 SSL 표현의 공감/감정 정보 포착 능력과 관련

### 2.4 MTR-DuplexBench: Towards a Comprehensive Evaluation of Multi-Round Conversations for Full-Duplex Speech Language Models

**[MTR-DuplexBench]** (He Zhang, Wenqian Cui, Haoning Xu, Xiaohui Li, Lei Zhu, Haoli Bai, Shaohua Ma, Irwin King, 2025.11) — arXiv preprint (Tsinghua, CUHK, Huawei)

- arxiv URL: https://arxiv.org/abs/2511.10262
- **기존 문제**: 전이중(full-duplex) 음성 언어 모델(FD-SLM) 평가가 단일 라운드 상호작용에 국한되어, 다중 라운드 대화의 복잡성(턴 경계 모호성, 맥락 불일치 등)을 다루지 못함
- **기존 방법**: 기존 벤치마크가 단일 라운드 평가만 제공하여 실제 다중 라운드 대화에서의 FD-SLM 성능을 정확히 측정 불가
- **제안 방법**: MTR-DuplexBench — 연속적 전이중 대화를 이산 턴으로 분할하여 턴별 평가를 가능하게 하는 벤치마크. 대화 특성(턴테이킹, 인터럽션, 일시정지, 배경), 대화 품질, 지시 따르기, 안전성의 4개 평가 차원 포함
- **핵심 차별점**: 전이중 대화의 모호한 턴 경계와 모델 추론 시 맥락 불일치 문제를 직접 해결하는 최초의 다중 라운드 FD-SLM 벤치마크
- **실험 결과**: 현재 FD-SLM들이 다중 라운드 및 다양한 평가 차원에서 일관된 성능 유지에 어려움을 겪고 있음을 확인. 벤치마크의 필요성과 유효성 입증
- **우리 연구 관련도**: ★☆☆ — 전이중 대화 평가 벤치마크 연구로, speech SSL 표현 학습과 직접 관련 낮음

## 3. Speech Foundation Model

### 3.1 S-JEPA: Soft Clustering Anchors for Self-Supervised Speech Representation Learning

**[S-JEPA]** (Georgios Ioannides, Adrian Kieback, Judah Goldfeder, Linsey Pang, Aman Chadha, Aaron Elkins, Yann LeCun, Ravid Shwartz-Ziv, 2026.06) — arXiv preprint

- arxiv URL: https://arxiv.org/abs/2606.19398
- **기존 문제**: 자기지도 음성 인코더가 마스크 위치에서 이산 하드 클러스터 ID를 예측하는 방식으로 학습되는데, 이는 카테고리 경계에서의 음향적 모호성을 붕괴(collapse)시키며 반복 학습마다 전체 코퍼스를 오프라인으로 재클러스터링해야 함
- **기존 방법**: HuBERT 등이 k-means 기반 하드 클러스터링으로 이산 타겟을 생성하고, 학습 반복마다 오프라인 재클러스터링 수행. 클러스터링할 트랜스포머 레이어도 수동 선택 필요
- **제안 방법**: JEPA 스타일 인코더-예측기 쌍이 마스크 위치에서 가우시안 혼합 모델(GMM)의 소프트 사후확률을 KL 발산으로 매칭하도록 학습. 2단계 학습: (1) MFCC 특징 위의 고정 GMM, (2) 인코더 특징 위의 온라인 GMM으로 전환. 클러스터링할 레이어를 레이블 없는 신호로 자동 적응 선택하여 오프라인 재클러스터링 단계와 수동 레이어 선택을 모두 제거
- **핵심 차별점**: 하드 클러스터 ID 대신 소프트 GMM 사후확률을 타겟으로 사용하여 음향 모호성을 보존하고, 단일 연속 최적화 궤적으로 재클러스터링 없이 학습. JEPA 아키텍처를 음성 SSL에 적용한 연구
- **실험 결과**: 51.8M 파라미터 인코더로 SUPERB ASR 프로토콜에서 LibriSpeech test-clean WER 12.10% (그리디 CTC; 4-gram LM 리스코어링 시 8.50%) 달성, 90M 미만 SSL 방법 중 최저 WER. 감정 인식 64.83% 정확도로 HuBERT-Base의 55% 파라미터 수준에서 대등한 성능. 약 83,000시간 영어 데이터로 사전학습
- **우리 연구 관련도**: ★★★ — JEPA 기반 음성 SSL에 소프트 클러스터링을 적용한 핵심 연구. 하드 클러스터 vs 소프트 타겟의 비교는 prediction-free SSL 연구와 직접 관련. 오프라인 재클러스터링 제거와 적응적 레이어 선택은 VQ 기반 표현 학습 효율화에 시사점 제공

### 3.2 Bridging Self-Supervised Learning and Speech Enhancement: A Wav2Vec2-Conditioned Framework

**[Bridging SSL and Speech Enhancement]** (Shuubham Ojha, Carol Espy-Wilson, 2026.06) — arXiv preprint

- arxiv URL: https://arxiv.org/abs/2606.22591
- **기존 문제**: 확산(diffusion) 모델이 음성 향상(speech enhancement)에서 잠재력을 보이지만, 언어적 안내(linguistic guidance)가 부족하여 노이즈 제거 시 음성 콘텐츠 보존이 불충분
- **기존 방법**: 기존 확산 기반 음성 향상 모델이 조건 없이(unconditioned) 역확산 과정을 수행하여, 음소 수준의 언어적 구조를 활용하지 못함
- **제안 방법**: 동결된(frozen) wav2vec 2.0 인코더로 잡음 입력에서 음소 표현을 추출하고, 학습된 FiLM(Feature-wise Linear Modulation) 생성기를 통해 U-Net 병목(bottleneck) 지점에서 스케일 및 시프트 파라미터로 변조. 최소한의 오버헤드로 자기지도 표현이 역확산 과정을 안내
- **핵심 차별점**: 음성 SSL 표현(wav2vec 2.0)을 확산 기반 음성 향상의 조건으로 활용하는 최초의 프레임워크. 동결 인코더 + 경량 FiLM 어댑터로 추가 파라미터 최소화
- **실험 결과**: VoiceBank-DEMAND 및 LibriMix에서 PESQ, STOI, SI-SDR, DNSMOS 기준 비조건 베이스라인 대비 경쟁적 성능. PESQ에서 일관적으로 0.4점 향상 기록
- **우리 연구 관련도**: ★★☆ — wav2vec 2.0 SSL 표현의 다운스트림 활용 연구로, speech SSL 표현의 범용성과 음소 정보 보존 능력을 검증. 자기지도 표현의 응용 확장 관점에서 참고 가치

### 3.3 Beyond Fixed Frames: Dynamic Character-Aligned Speech Tokenization (DyCAST)

**[DyCAST]** (Luca Della Libera, Cem Subakan, Mirco Ravanelli, 2026.01) — arXiv preprint (Mila)

- arxiv URL: https://arxiv.org/abs/2601.23174
- **기존 문제**: 현재 뉴럴 오디오 코덱이 고정 프레임 레이트로 동작하여, 시간에 걸쳐 균일하게 토큰을 배분함으로써 불필요하게 긴 시퀀스를 생성. LLM 기반 음성 처리에서 시퀀스 길이가 효율성의 병목
- **기존 방법**: FocalCodec 등 기존 코덱이 고정 프레임 레이트(예: 50Hz)로 동작하여, 묵음이나 지속 구간에서도 동일한 토큰 수를 할당
- **제안 방법**: DyCAST — 소프트 문자 수준 정렬(soft character-level alignment)과 명시적 지속시간 모델링을 통한 가변 프레임 레이트 토크나이저. 학습 시 토큰을 문자 수준 언어 단위와 연관시키고, 추론 시 정렬 없이 토큰 지속시간을 직접 제어 가능. 저프레임 레이트에서 품질 향상을 위한 검색 증강 디코딩(retrieval-augmented decoding) 메커니즘 도입
- **핵심 차별점**: 언어 단위(문자)와 정렬된 가변 프레임 레이트 토크나이제이션으로 고정 프레임 레이트 대비 토큰 수를 대폭 절감. 비트레이트 증가 없이 검색 증강으로 저프레임 레이트 재합성 품질 개선
- **실험 결과**: 경계 예측기 min_gap 설정에 따라 평균 프레임 레이트 약 14Hz, 9Hz, 6Hz 달성 (고정 50Hz 대비 최대 ~8배 토큰 절감). 고정 프레임 레이트 코덱 대비 경쟁적 음성 재합성 품질과 다운스트림 성능 유지
- **우리 연구 관련도**: ★★☆ — 음성 토크나이저 효율화 연구로, VQ 기반 표현의 프레임 레이트 최적화와 직접 관련. 가변 레이트 토크나이제이션은 speech tokenizer 설계의 새로운 방향 제시
