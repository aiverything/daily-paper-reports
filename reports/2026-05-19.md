## 1. ASR (End-to-End, Streaming, Multilingual, LLM-based ASR)

### **Contextual Biasing for Streaming ASR via CTC-based Word Spotting (Kai-Chen Tsai, Tien-Hong Lo, Yun-Ting Sun, Berlin Chen, 2026-05)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2605.18222
- 기존 문제: 도메인 특화 희귀 단어(고유명사, 전문 용어 등)의 인식률이 범용 ASR 모델에서 현저히 낮음. 기존 문맥 바이어싱(contextual biasing) 방법은 대부분 오프라인 설정에 초점을 맞추어 스트리밍 ASR의 실시간 제약을 명시적으로 다루지 않음.
- 기존 방법: CTC-based Word Spotting(CTC-WS)이 오프라인 환경에서 강력한 성능을 보였으나, 전체 발화에 대한 접근이 필요하여 스트리밍 환경에서 사용 불가. 신경망 기반 바이어싱 방법은 모델 재학습이 필요하거나 추론 비용이 높음.
- 제안 방법: CTC-WS의 스트리밍 확장을 제안. 상태 유지형 토큰 패싱 알고리즘(stateful token passing algorithm)으로 오디오 청크 간 활성 키워드 경로를 유지하여, 여러 청크에 걸쳐 나타나는 키워드도 탐지 가능. 증분 커밋 메커니즘(incremental commitment mechanism)으로 미래 오디오에 영향받지 않는 세그먼트만 출력하고, 불확실한 영역은 보류.
- 핵심 차별점: 모델 재학습 없이 기존 CTC/Transducer ASR에 플러그인 방식으로 적용 가능. 스트리밍 환경에서 저지연 실시간 문맥 바이어싱 최초 구현. 청크 간 키워드 탐지와 안정적 출력을 보장하는 커밋 메커니즘 도입.
- 실험 결과: 스트리밍 환경에서 오프라인 CTC-WS에 근접한 문맥 바이어싱 성능 달성. 저지연 출력을 유지하면서 희귀 단어 인식률 유의미하게 향상.
- 우리 연구 관련도: ★☆☆ (CTC 기반 스트리밍 디코딩 전략으로, speech SSL 표현 학습과의 직접적 관련도는 낮으나 CTC 확률 기반 토큰 매칭 방법론이 이산 토큰 분석에 참고 가능)

### **Phonemes vs. Projectors: An Investigation of Speech-Language Interfaces for LLM-based ASR (Li Dong, Yusuyin Zhao, Ou Ziwei, Lukuang Saierdaer, Xianyu Zhijian, 2026-04)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2604.09332
- 기존 문제: 사전학습된 음성 인코더를 LLM에 연결하여 ASR을 수행할 때, 음성-언어 인터페이스 선택이 성능과 데이터 효율성에 큰 영향을 미치나, 이에 대한 체계적 비교 연구가 부재.
- 기존 방법: 학습 가능한 프로젝터(projector)로 인코더 특징을 LLM 임베딩 공간에 매핑하는 방식이 주류. 음소(phoneme) 시퀀스를 LLM에 직접 노출하는 방식은 체계적으로 탐구되지 않음.
- 제안 방법: 동일한 인코더-LLM 백본 하에서 (1) 학습 가능 프로젝터, (2) 이산 음소 시퀀스, (3) BPE-음소 인터페이스(빈번한 음소 패턴을 BPE로 그룹핑하되 단어 경계를 명시적으로 보존)를 체계적으로 비교. 고자원 영어(LibriSpeech)와 저자원 타타르어에서 평가.
- 핵심 차별점: 음소 기반 인터페이스가 저자원 환경에서 프로젝터 방식을 크게 상회함을 실증. BPE-음소 인터페이스는 고자원 환경에서도 추가 성능 개선 달성. 음성-언어 인터페이스 설계의 체계적 가이드라인 제시.
- 실험 결과: LibriSpeech에서 음소 기반 인터페이스가 프로젝터와 동등, BPE-음소가 추가 개선. 타타르어에서는 음소 기반 인터페이스가 프로젝터를 크게 상회. 저자원 환경일수록 이산 음소 인터페이스의 이점이 커짐.
- 우리 연구 관련도: ★★☆ (음소 수준 이산 표현이 LLM 기반 ASR에서 연속 표현과 경쟁력 있음을 입증. VQ-based representation 연구에서 이산 단위의 언어적 정보 보존 및 LLM 연동 전략에 직접 참고 가능)

### **Dolphin-CN-Dialect: Where Chinese Dialects Matter (DataoceanAI & Tsinghua University, 2026-05)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2605.08961
- 기존 문제: 중국어 방언(Dialect) ASR은 극심한 데이터 불균형과 표준 만다린과의 발음 체계 차이로 인해 성능이 크게 저하. 기존 다국어 ASR 모델은 방언 데이터가 부족하여 방언 인식에 약점을 보임.
- 기존 방법: 기존 Dolphin 모델은 동아시아 언어에 특화된 대규모 ASR 모델이나, 방언 데이터 불균형 문제를 직접적으로 해결하지 못함. 범용 다국어 모델(Whisper 등)은 중국어 방언에 대한 지원이 제한적.
- 제안 방법: (1) 온도 기반 샘플링 전략(temperature-based sampling)으로 표준 만다린과 저자원 방언 간 학습 데이터 균형 달성. (2) 중국어는 문자 수준(character-level), 영어는 서브워드 수준(subword) 모델링을 채택하고, 확장 가능한 방언 토큰 도입으로 토크나이저 재설계. (3) 데이터 전처리, 학습 안정성, 샘플링 전략 전반에 걸쳐 개선.
- 핵심 차별점: 방언 불균형 데이터 문제를 온도 기반 샘플링으로 체계적으로 해결. 스트리밍/비스트리밍 모드 모두 지원하며, 핫워드(hotword) 커스터마이징과 전용 하드웨어 최적화 배포 제공. 최근 SOTA 오픈소스 ASR 모델과 경쟁적 성능을 훨씬 작은 모델 크기로 달성.
- 실험 결과: 이전 Dolphin 대비 방언 인식 정확도 향상 및 CER 감소. 최근 SOTA 오픈소스 ASR 모델과 경쟁적 성능을 유지하면서 모델 크기 대폭 축소.
- 우리 연구 관련도: ★☆☆ (방언 데이터 불균형 해결을 위한 온도 기반 샘플링 전략은 다양한 음성 도메인의 사전학습 데이터 구성에 참고 가능. 문자/서브워드 혼합 토크나이저 설계는 다국어 표현 학습에 간접 참고)

## 2. SpeechLLM (Speech-Language Model, Voice Agent, Audio LLM)

### **From Text to Voice: A Reproducible and Verifiable Framework for Evaluating Tool Calling LLM Agents (Md Tahmid Rahman Laskar, Xue-Yong Fu, Seyyed Saeed Sarfjoo, Quinten McNamara, Jonas Robertson, Shashi Bhushan TN, 2026-05)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2605.15104
- 기존 문제: 음성 에이전트(voice agent)에서 도구 호출(tool calling) 능력이 중요해지고 있으나, 기존 도구 호출 벤치마크는 텍스트 기반으로만 존재. 음성 입력을 통한 도구 호출 평가 방법론이 부재.
- 기존 방법: 텍스트 기반 도구 호출 벤치마크(Confetti, When2Call 등)가 주류. 음성 에이전트 평가 시 기존 벤치마크를 음성으로 변환하면 도구 스키마와 정답 레이블 재작성이 필요하여 비효율적.
- 제안 방법: 데이터셋 무관(dataset-agnostic) 프레임워크로, TTS(Text-to-Speech)·화자 변이(speaker variation)·환경 노이즈를 활용하여 기존 텍스트 벤치마크의 주석을 보존한 채 텍스트-오디오 쌍 인스턴스를 자동 생성. 7개 옴니모달 모델(Gemini-3.1-Flash-Live, GPT-Realtime-1.5, Qwen3-Omni 등)을 Confetti와 When2Call 벤치마크의 음성 변환 버전으로 평가.
- 핵심 차별점: 텍스트 벤치마크의 검증된 정답 레이블을 재활용하여 음성 도구 호출 평가를 위한 재현 가능한 프레임워크 최초 제안. 텍스트-음성 간 성능 격차(text-to-voice gap)를 정량적으로 측정.
- 실험 결과: Confetti에서 Gemini-3.1-Flash-Live가 최고 점수(70.4), When2Call에서 GPT-Realtime-1.5가 최고 점수(71.9). 텍스트-음성 격차는 모델별로 Qwen3-Omni 1.8pp부터 GPT-Realtime-1.5 4.8pp까지 존재.
- 우리 연구 관련도: ★☆☆ (음성 에이전트의 도구 호출 벤치마크로, speech SSL 연구와의 직접 관련도는 낮으나, 음성 표현의 의미 보존 능력을 테스트-음성 격차로 간접 평가하는 방법론에 참고)

### **Can Large Audio Language Models Ignore Multilingual Distractors? An Evaluation of Their Selective Auditory Attention Capabilities (Heejoon Koo, 2026-05)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2605.17225
- 기존 문제: 대형 오디오 언어 모델(LALM)이 다국어 환경에서 대상 음성에 선택적으로 주의(selective auditory attention)를 기울이는 능력이 체계적으로 평가되지 않음. 실제 환경에서는 다국어 방해 음성이 존재하는 칵테일 파티 상황이 빈번.
- 기존 방법: 기존 LALM 벤치마크는 단일 오디오 입력의 이해 능력에 초점. 다국어 방해 음성 하에서의 선택적 청각 주의 능력을 평가하는 벤치마크가 부재.
- 제안 방법: MUSA — 칵테일 파티 영감 다국어 벤치마크 제안. 영어 대상 대화에 영어·스페인어·한국어·중국어 방해 음성을 의미적으로 그럴듯하게 페어링. (1) 단일 입력, (2) 음원 분리 기반 2단계, (3) 종단간 칵테일 파티 설정에서 다양한 SNR 조건으로 평가. 2개 폐쇄형·4개 오픈소스 LALM 모델 평가.
- 핵심 차별점: 단일 입력에서의 높은 성능이 칵테일 파티 환경의 선택적 주의력을 보장하지 않음을 실증. 방해 음성에 기반한 음원 혼동(source confusion)이 주요 오류 유형임을 규명. 음원 분리가 음향 중첩을 줄이지만 음원 귀속(attribution) 문제는 해결하지 못함을 발견.
- 실험 결과: 높은 SNR에서는 대부분 모델이 양호하나, 낮은 SNR에서 칵테일 파티 정확도가 급격히 저하. 음원 분리 후에도 "틀린 스트림의 정보로 확신 있는 오답"을 생성하는 패턴 확인. 폐쇄형 모델이 오픈소스 대비 전반적으로 우수하나, 모든 모델이 극심한 SNR에서 취약.
- 우리 연구 관련도: ★★☆ (다국어 환경에서 음성 표현의 음원 분리·귀속 능력을 평가하는 벤치마크로, speech SSL 모델의 화자/음원 분리 표현 학습 연구에 참고. 선택적 주의 메커니즘은 disentangled representation 설계에 시사점 제공)

### **Reducing Linguistic Hallucination in LM-Based Speech Enhancement via Noise-Invariant Acoustic-Semantic Distillation (Zheng Wang, Xiaobin Rong, Hang Su, Tianyi Tan, Junnan Wu, Lichun Fan, Zhenbo Luo, Jian Luan, Jing Lu, 2026-05)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2605.08608
- 기존 문제: LM 기반 음성 향상(Speech Enhancement) 모델이 자연스러운 음성을 생성할 수 있으나, 심한 잡음 환경에서 신뢰할 수 없는 조건화(conditioning)로 인해 언어적 환각(linguistic hallucination) — 지각적으로 그럴듯하지만 언어적으로 부정확한 출력 — 이 발생.
- 기존 방법: 기존 LM 기반 음성 향상은 잡음 입력에서 직접 음향 토큰을 예측하여, 심한 잡음에서 언어 정보가 손상됨. WavLM 등 SSL 모델의 표현을 활용하나, 잡음에 대한 불변성(noise-invariance)이 보장되지 않음.
- 제안 방법: L3-SE — 잡음 불변 음향-의미 증류(noise-invariant acoustic-semantic distillation) 프레임워크. 단일 WavLM 백본에서 두 가지 특화 교사 모델 생성: (1) WavCodec — 음성 코덱 목적으로 최적화하여 음향 충실도 담당, (2) WavS2T — 음성-텍스트 목적으로 최적화하여 언어 일관성 담당. 잡음 음성에서 잡음 불변 조건화 인코더를 학습하여 두 교사로부터 음향·의미 표현을 공동 증류. 결과 표현으로 디코더 전용 자기회귀 LM을 조건화하여 클린 음향 토큰 예측.
- 핵심 차별점: WavLM으로부터 음향(WavCodec)과 의미(WavS2T)를 분리하여 증류하는 이중 교사 구조 최초 제안. 잡음 불변 표현 학습으로 심한 잡음에서도 언어적 환각 대폭 감소. 고충실도 코덱 재구성과 언어적 정확성을 동시 달성.
- 실험 결과: 기존 LM 기반 음성 향상 대비 언어적 환각 발생률 대폭 감소. 음향 품질과 언어 일관성 지표 모두에서 개선 달성.
- 우리 연구 관련도: ★★★ (WavLM 기반 이중 교사 증류를 통한 음향-의미 분리 표현 학습은 speech SSL의 disentangled representation 연구와 직접 관련. 잡음 불변 표현 학습 프레임워크는 temporal contrastive learning의 불변성 목적함수 설계에 참고. VQ-based representation에서 음향·의미 정보 분리 전략에 핵심 참고)

## 3. Speech Foundation Model (Speech Tokenizer, Speech SSL, Representation Learning)

### **MOSS-Audio-Tokenizer: Scaling Audio Tokenizers for Future Audio Foundation Models (Yitian Gong, Kuangwei Chen, Zhaoye Fei, Xiaogui Yang, Ke Chen, Yang Wang, Kexin Huang, Mingshu Chen, Ruixiao Li, Qingyuan Cheng, Shimin Li, Xipeng Qiu, 2026-02)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2602.10934
- 기존 문제: 기존 오디오 토크나이저는 CNN 기반 인코더/디코더에 의존하거나, HuBERT·Whisper 등 사전학습된 인코더의 증류에 의존하여 아키텍처가 이질적이고 확장성이 제한적. 스트리밍과 가변 비트레이트를 동시에 지원하는 대규모 토크나이저가 부재.
- 기존 방법: SoundStream, EnCodec 등 CNN 기반 코덱은 확장성이 제한적. WavTokenizer, SpeechTokenizer 등은 외부 SSL 모델의 표현 증류에 의존. 기존 토크나이저는 음성·사운드·음악을 범용으로 처리하는 데 한계.
- 제안 방법: CAT (Causal Audio Tokenizer with Transformer) — 순수 Transformer 기반의 동질적(homogeneous) 아키텍처로 인코더·양자화기·디코더를 처음부터 공동 최적화. CNN 없이 Causal Transformer 블록만으로 구성. 16억(1.6B) 파라미터 모델을 300만 시간의 다양한 오디오 데이터로 사전학습. 사전학습된 인코더(HuBERT, Whisper 등)나 교사 모델 증류 없이 원시 데이터에서 자율적으로 모든 표현을 학습.
- 핵심 차별점: CNN 없이 순수 Transformer 기반의 완전 종단간(end-to-end) 학습. 1.6B 파라미터로 오디오 토크나이저 분야 최대 규모. 24kHz 오디오를 12.5Hz 프레임 레이트로 압축하면서도 의미적으로 풍부한(semantic-rich) 이산 토큰 생성. 스트리밍·가변 비트레이트 지원. 음성·사운드·음악 전 도메인에서 SOTA 재구성 품질.
- 실험 결과: 음성·사운드·음악 전 도메인에서 기존 코덱 대비 넓은 비트레이트 범위에서 일관된 SOTA 재구성 품질. 규모 확대에 따라 예측 가능한 성능 향상 관찰. 다운스트림 ASR·TTS 태스크에서도 강력한 성능.
- 우리 연구 관련도: ★★★ (순수 Transformer 기반 대규모 오디오 토크나이저로, VQ-based representation 연구에 직접 참고. 외부 SSL 모델 증류 없이 원시 데이터에서 의미적 표현을 자율 학습하는 접근은 prediction-free speech SSL 연구와 철학적으로 연결. 12.5Hz 저프레임 레이트의 semantic-rich 토큰 설계는 temporal structure 연구에 핵심 참고)

### **A Study of Data Selection Strategies for Pre-training Self-Supervised Speech Models (Ryan Whetten, Titouan Parcollet, Marco Dinarelli, Yannick Estève, 2026-01)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2601.20896
- 기존 문제: 자기지도 음성 모델(SSL)의 사전학습은 대규모 비라벨 데이터에 의존하나, 데이터 양·다양성·특성 중 어떤 요소가 성능에 가장 중요한지 체계적으로 연구되지 않음. 대규모 데이터 사용은 계산 비용의 병목.
- 기존 방법: 기존 연구는 가용한 모든 데이터를 최대한 활용하는 전략을 채택. 음향적·화자적·언어적 다양성을 극대화하는 방향으로 데이터를 구성하는 것이 일반적 가정.
- 제안 방법: 데이터 선택 전략을 체계적으로 비교: 무작위 샘플링, 최장 발화 우선 선택, 음향 다양성 최적화, 화자 다양성 최적화, 언어적 다양성 최적화 등. 전체 데이터셋의 절반만 사용하는 조건에서 각 전략의 ASR 성능을 평가.
- 핵심 차별점: 발화 길이가 데이터 다양성이나 전체 데이터 양보다 SSL 사전학습 성능에 훨씬 중요한 요소임을 실증. 최장 발화 우선 선택만으로 전체 데이터셋의 절반만 사용하여도 우수한 ASR 성능 달성. 음향·화자·언어적 다양성 최적화는 무작위 샘플링 대비 명확한 개선 없음.
- 실험 결과: 최장 발화 우선 선택 전략이 전체 데이터셋 절반만으로 최고 ASR 성능 달성. 사전학습 시간 24% 감소. 다양성 최적화 전략들은 무작위 샘플링 대비 개선 없음.
- 우리 연구 관련도: ★★★ (speech SSL 사전학습의 데이터 효율성 연구로, prediction-free speech SSL의 데이터 구성 전략에 직접 참고. 발화 길이가 핵심 요소라는 발견은 temporal contrastive learning에서 긴 시간 컨텍스트의 중요성과 일맥상통. VQ-based representation 학습의 사전학습 데이터 선택 기준에 핵심 참고)
