## 1. ASR (Automatic Speech Recognition)

### **[FASTDIAR: Frame-level Speaker Encoder for Streaming Diarization] (Nikita Torgashov, Okan Köpüklü — Microsoft, 2026-10-02)** — arxiv preprint (submitted to ICASSP 2027)
- https://arxiv.org/abs/2610.02941
- **기존 문제**: 스트리밍 화자 분할(diarization)은 실시간 응용에서 필수적이지만, 기존 시스템들은 화자 수가 증가하면 성능이 크게 저하되고, 캐시 기반 시스템은 지연 시간이 높아 실시간 처리가 어려웠음
- **기존 방법**: 오프라인 클러스터링 기반 화자 분할, EEND (End-to-End Neural Diarization), 캐시 기반 온라인 시스템 등이 있었으나, 스트리밍 환경에서의 정확도-지연 트레이드오프가 큰 제약이었음
- **제안 방법**: 최신 화자 인식 아키텍처를 인과적(causal) 프레임 레벨 인코더로 변환하여, 2초 과거 윈도우에서 80ms마다 임베딩을 출력하고, 스트림의 자기유사도(self-similarity)에 기반한 온라인 클러스터링과 결합
- **핵심 차별점**: 한 번의 스트림 읽기로 프레임 단위 임베딩 생성 가능하며, 화자 수 증가 시에도 캐시 기반 시스템 대비 성능 저하가 훨씬 적음
- **실험 결과**: 저중첩(low-overlap) 벤치마크에서 가장 정확한 스트리밍 다이어라이저. 단일 CPU 스레드에서 실시간 대비 5배 빠른 처리 속도, 1초 미만 지연 시간 달성
- **우리 연구 관련도**: ★☆☆ — 화자 분할 특화 연구로, speech SSL이나 VQ representation과의 직접적 관련은 낮음

### **[Whale: Large-Scale Multilingual ASR Model with w2v-BERT and E-Branchformer with Large Speech Data] (Yosuke Kashiwagi, Hayato Futami, Emiru Tsunoo, Satoshi Asakawa — Sony, 2026-06-02)** — arxiv preprint
- https://arxiv.org/abs/2506.01439
- **기존 문제**: Whisper, OWSM 등 대규모 다국어 ASR 모델들이 존재하지만, 자기지도 사전학습(SSL)과 E2E ASR 아키텍처의 최적 결합에 대한 탐구가 부족했음
- **기존 방법**: Whisper는 약한 지도학습(weakly-supervised)으로 대규모 데이터를 활용하고, OWSM은 오픈소스 Whisper-style 접근을 사용. 대부분 Transformer/Conformer 인코더 기반
- **제안 방법**: w2v-BERT 자기지도 모델을 인코더로, E-Branchformer 기반 인코더-디코더 백본에 joint CTC-attention 디코딩 전략을 결합. 공개 코퍼스와 자체 데이터를 모두 활용한 대규모 학습
- **핵심 차별점**: SSL 사전학습(w2v-BERT)과 최신 E2E ASR 아키텍처(E-Branchformer)의 시너지를 체계적으로 활용하여 다양한 발화 스타일과 음향 조건에 대한 강건성 확보
- **실험 결과**: LibriSpeech test-clean WER 2.4%, CSJ eval3 CER 3.4%로 Whisper large-v3 및 OWSM v3.1을 능가
- **우리 연구 관련도**: ★★☆ — w2v-BERT SSL 사전학습을 ASR에 활용하는 방식으로, speech SSL representation의 downstream 효과를 보여주는 사례

- https://arxiv.org/abs/2609.33204
- **기존 문제**: Speech Language Model(SLM)들이 음성 질의를 이해할 수 있지만, 대부분 소수의 고자원(high-resource) 언어만 지원하여 수백만 사용자가 접근 불가
- **기존 방법**: 기존 다국어 SLM은 영어 중심으로 학습되어 저자원 언어에서 성능이 크게 떨어지며, 고품질 다국어 음성 QA 데이터셋이 부재
- **제안 방법**: MULTISPEECHQA — 23개 다양한 유형의 언어를 포함하는 9,200시간 규모의 합성+인간 검증 데이터셋(10.8M 음성 QA 쌍) 구축. MULTISPEECH-BENCH 다중 과제 벤치마크 도입
- **핵심 차별점**: 대규모 합성 데이터셋으로 SLM의 다국어 능력을 저비용으로 향상시키는 방법론 제시. 23개 언어 규모의 체계적 벤치마크 최초 구축
- **실험 결과**: Qwen 2.5-Omni를 MULTISPEECHQA로 파인튜닝하여 벤치마크 성능 향상을 입증. 고품질 합성 데이터가 다국어 SLM 역량 개선에 효과적임을 실증
- **우리 연구 관련도**: ★☆☆ — 다국어 음성 이해 데이터/벤치마크 연구로, speech representation 자체보다는 응용 측면의 기여

## 2. SpeechLLM (Speech Language Model)

### **[MoshiRAG: Asynchronous Knowledge Retrieval for Full-Duplex Speech Language Models] (Chung-Ming Chien, Manu Orsini, Eugene Kharitonov, Neil Zeghidour, Karen Livescu, Alexandre Défossez — Kyutai, 2026-04)** — ICML 2026 accepted (PMLR 306)
- https://arxiv.org/abs/2604.12928
- **기존 문제**: Full-duplex 음성 대화 모델은 실시간 상호작용이 가능하지만, 외부 지식에 접근하지 못해 사실적 정확성(factuality)이 non-duplex 모델에 비해 크게 떨어졌음
- **기존 방법**: 기존 full-duplex 모델(Moshi 등)은 파라메트릭 지식에만 의존하여 사실 오류가 빈번. Non-duplex RAG 시스템은 정확하지만 실시간 대화가 불가능
- **제안 방법**: 모듈형 프론트엔드/백엔드 설계 — Moshi 기반 full-duplex 프론트엔드가 실시간 대화를 처리하고, 비동기 검색 시스템이 병렬로 외부 정보를 가져옴. 응답 시작과 핵심 정보 전달 사이의 자연스러운 시간 간격을 활용
- **핵심 차별점**: 재학습 없이 plug-and-play 방식으로 검색 방법을 교체할 수 있으며, full-duplex의 상호작용성을 유지하면서 non-duplex 수준의 사실적 정확성 달성
- **실험 결과**: 공개된 non-duplex SLM들과 비슷한 수준의 사실적 정확성 달성, 동시에 full-duplex 상호작용 유지. 도메인 외 수학적 추론 과제에서도 강건한 성능
- **우리 연구 관련도**: ★☆☆ — RAG와 full-duplex 결합 시스템 연구로, speech representation 연구와의 직접적 관련성은 낮음

### **[Covo-Audio Technical Report] (2026-02-10)** — arxiv preprint
- https://arxiv.org/abs/2602.09823
- **기존 문제**: 기존 Large Audio Language Model(LALM)들은 음성 이해, 대화, full-duplex 상호작용 중 일부만 지원하며, 하나의 통합 아키텍처로 모든 기능을 달성하기 어려웠음. 또한 음성 스타일/화자 커스터마이징에 별도의 대규모 TTS 데이터가 필요했음
- **기존 방법**: Moshi, Freeze-Omni 등 full-duplex 모델들이 등장했지만, 대화 지능(dialogue intelligence)과 음성 렌더링(voice rendering)이 결합되어 화자 커스터마이징이 어려웠음
- **제안 방법**: 7B 파라미터 규모의 end-to-end LALM으로, 연속 오디오 입출력을 단일 아키텍처에서 처리. 지능-화자 분리(intelligence-speaker decoupling) 전략으로 대화 지능과 음성 렌더링 분리. Full-duplex 변종(Chat-FD)은 1:4 비율의 청크 인터리빙으로 동시 듣기/말하기 구현
- **핵심 차별점**: 대규모 큐레이션된 사전학습과 목적별 후학습을 통해, 비슷한 규모 모델 중 음성-텍스트 모델링, 대화, 음성/오디오 이해, full-duplex 전 영역에서 SOTA 또는 경쟁력 있는 성능 달성
- **실험 결과**: Covo-Audio-Chat-FD가 URO-Bench에서 Moshi, Freeze-Omni를 크게 능가 — 턴테이킹 99.7%, 일시정지 처리 97.6%, 백채널링 93.89%, 인터럽션 96.81% 성공률
- **우리 연구 관련도**: ★☆☆ — End-to-end 음성 대화 시스템으로, speech representation보다는 시스템 아키텍처 중심 연구

## 3. Speech Foundation Model

### **[Phonological Tokenizer: Prosody-Aware Phonetic Token via Multi-Objective Fine-Tuning with Differentiable K-Means] (Kentaro Onda, Hayato Futami, Yosuke Kashiwagi, Emiru Tsunoo, Shinji Watanabe — U. Tokyo / Sony / CMU, 2026-01)** — ICASSP 2026 accepted
- https://arxiv.org/abs/2601.19781
- **기존 문제**: 음성 토크나이저는 음향 토큰(acoustic token)과 음성 토큰(phonetic token)으로 나뉘는데, 음성 토큰은 언어적 내용만 포착하고 운율(prosody) 정보를 버려 음성 생성에 활용하기 어려웠음
- **기존 방법**: SSL 모델(HuBERT 등)의 표현에 k-means 클러스터링을 적용하여 의미적 토큰 생성. 음향 토큰(codec)은 재구성에는 좋지만 언어적 구조가 부족하여 LM 학습에 비효율적
- **제안 방법**: 미분 가능한 k-means(differentiable k-means)를 통해 음성 토큰을 파인튜닝하며, ASR과 음성 재합성(resynthesis)의 다중 목표 프레임워크로 학습. 단일 코드북으로 음운적(phonological) 정보 — 언어+운율 — 을 동시에 포착
- **핵심 차별점**: 기존의 음향/음성 이분법을 넘어, 하나의 토크나이저가 언어적+운율적 정보를 유지하면서 화자 정체성은 적절히 제거하는 "음운적 토큰" 개념 제시
- **실험 결과**: 음성 이해(ASR)와 생성(resynthesis) 과제 모두에서 높은 성능 달성. SpeechLM 응용에서도 효과적임을 검증. 화자 정체성 제거와 음운 정보 유지의 균형 실증
- **우리 연구 관련도**: ★★★ — VQ 기반 토큰화와 speech SSL 표현의 파인튜닝을 핵심으로 다루며, prediction-free SSL과 VQ-based representation 연구에 직접적으로 관련

- https://arxiv.org/abs/2609.30975
- **기존 문제**: 음성 변환(voice conversion), 음성-음성 번역, 멀티모달 언어 모델 등에서 음성 콘텐츠 표현이 핵심이지만, 다양한 표현 방식들이 공통된 생성 프레임워크 하에서 체계적으로 비교된 적이 없었음
- **기존 방법**: SSL 특징(HuBERT, wav2vec 2.0 등), 지도 학습 토큰, 사후 확률(posteriorgram), 뉴럴 오디오 코덱 등 다양한 콘텐츠 표현이 각각 다른 평가 환경에서 개별적으로 연구됨
- **제안 방법**: 각 표현 유형에 대해 동일한 생성 모델을 조건부로 학습시키고, 생성된 오디오를 콘텐츠·화자 정체성·운율 세 축으로 체계적 평가
- **핵심 차별점**: 통일된 프레임워크에서의 공정한 비교를 통해 두 가지 뚜렷한 레짐 발견: (1) 원본 오디오를 거의 재구성하는 표현과 (2) 화자 정체성을 효과적으로 분리하는 표현
- **실험 결과**: SSL 특징, 지도 토큰, 사후 확률, 뉴럴 코덱 전반에 걸쳐 재구성-분리 트레이드오프를 정량적으로 매핑. 각 표현의 장단점을 콘텐츠/화자/운율 축에서 명확히 규명
- **우리 연구 관련도**: ★★★ — Speech SSL 표현과 VQ 기반 코덱 표현을 직접 비교 분석하는 연구로, speech representation learning의 설계 방향에 직접적 시사점 제공

### **[Language Discrimination Improves Linguistic Learning in Multilingual Speech Models] (Maureen de Seyssel, Jie Chi, Zakaria Aldeneh — Apple, 2026-09)** — arxiv preprint
- https://arxiv.org/abs/2609.33345
- **기존 문제**: 다국어 자기지도 음성 모델은 언어 간 정보 공유의 이점이 있지만, 단일 언어 모델 대비 언어적 학습(음소 구별, 어휘, 운율)에서 성능 격차("multilingual gap")가 존재
- **기존 방법**: HuBERT 등 SSL 모델을 다국어 데이터로 학습하되, 언어 정보를 명시적으로 활용하지 않아 언어 간 간섭이 발생. 언어 ID를 모델에 통합하는 시도는 주로 ASR downstream에 한정
- **제안 방법**: HuBERT 사전학습에 두 가지 언어 판별 강화 개입: (1) 보조 언어 분류기(auxiliary language classifier), (2) 언어별 k-means 타겟(per-language k-means targets). 통제된 영어/프랑스어 이중 언어 환경에서 검증
- **핵심 차별점**: 언어 판별 능력을 SSL 사전학습 단계에서 직접 강화함으로써, 단순한 ASR 성능이 아닌 연속 음성 표현의 음운·어휘·운율 품질 자체를 개선
- **실험 결과**: 음소 구별 오류율 11.6% → 10.4%, 어휘 성능 52.1% → 56.7%, 운율 성능 68.9% → 72.9%. HuBERT 학습의 첫 번째 반복에서 언어 판별을 도입할 때 가장 큰 효과
