## 1. ASR (Automatic Speech Recognition)

**[SpeakerLM: End-to-End Versatile Speaker Diarization and Recognition with Multimodal Large Language Models] (Han Yin, Yafeng Chen et al., 2025.08)** — AAAI 2026 accepted
- https://arxiv.org/abs/2508.06372
- 기존 문제: 기존 Speaker Diarization and Recognition(SDR) 시스템은 화자 분리(SD)와 음성 인식(ASR)을 별도 모듈로 구성하는 cascade 방식을 사용하여, 오류 전파(error propagation), 겹침 음성(overlapping speech) 처리 어려움, 모듈 간 공동 최적화 부재 등의 한계가 존재
- 기존 방법: SD 모듈과 ASR 모듈을 순차적으로 결합하는 pipeline 방식. 각 모듈이 독립적으로 학습되어 전체 시스템의 최적화가 제한적
- 제안 방법: Multimodal LLM 기반 통합 모델 SpeakerLM을 제안. 화자 분리와 음성 인식을 end-to-end로 동시 수행하며, 유연한 화자 등록 메커니즘(flexible speaker registration mechanism)을 도입하여 다양한 화자 등록 설정에서 SDR 수행 가능
- 핵심 차별점: 단일 MLLM으로 SD와 ASR을 공동 모델링하여 오류 전파를 근본적으로 제거. 데이터 스케일링에 강한 확장성을 보이며, 화자 등록 방식에 유연하게 대응
- 실험 결과: in-domain 및 out-of-domain 공개 SDR 벤치마크에서 기존 SOTA cascade 베이스라인을 능가하는 성능 달성
- 우리 연구 관련도: ★☆☆ — 화자 분리 중심으로 SSL 표현 학습과 직접적 관련성은 낮으나, end-to-end 통합 모델링 패러다임은 참고 가치 있음

**[Balancing ASR and Diarization in End-to-End LLMs for Multi-Talker Speech Recognition] (Naijun Zheng, Yuke Lin, Sanli Tian et al., 2026.06)** — arxiv preprint
- https://arxiv.org/abs/2606.13095
- 기존 문제: LLM 기반 multi-talker ASR 접근법이 유망하지만, 대규모 multi-talker 코퍼스의 어노테이션 비용이 높아 학습 데이터 확보가 어려움. ASR과 화자 분리 두 태스크 간의 학습 균형을 맞추는 것이 어려움
- 기존 방법: 단일 인코더에서 의미적(semantic) 특징과 화자(speaker) 특징을 동시에 추출하거나, 별도 모듈을 cascade로 연결하는 방식
- 제안 방법: (1) 의미 특징과 화자 특징을 분리 추출하는 dual-encoder 아키텍처, (2) 두 특징을 LLM 입력으로 병합하는 feature interleaving 포맷, (3) 화자 분리 성능 강화를 위한 length-aware speaker ID loss, (4) 음성 겹침으로 인한 hallucination을 억제하는 adaptive threshold ASR loss
- 핵심 차별점: 제한된 실제 녹음 데이터로도 ASR과 화자 분리 간 학습 균형을 효과적으로 달성. Dual-encoder로 의미/화자 정보를 명시적으로 분리하여 각 태스크의 성능 저하 방지
- 실험 결과: AliMeeting 코퍼스에서 18%, Aishell4 코퍼스에서 24%의 상대적 성능 향상 달성 (오픈소스 베이스라인 대비)
- 우리 연구 관련도: ★★☆ — 의미 특징과 화자 특징의 분리(disentanglement) 접근은 speech representation 연구와 관련. Dual-encoder 설계가 다른 표현 학습에도 적용 가능

**[WhisperPipe: A Resource-Efficient Streaming Architecture for Real-Time Automatic Speech Recognition] (Erfan Ramezani et al., 2026.04)** — arxiv preprint
- https://arxiv.org/abs/2604.25611
- 기존 문제: Whisper 같은 대규모 Transformer 모델의 실시간 스트리밍 ASR 배포 시, 전사 정확도와 계산 효율성 간의 근본적 트레이드오프 존재. 기존 스트리밍 접근법은 공격적 chunking으로 정확도를 희생하거나, 무제한 컨텍스트 축적으로 메모리 비용이 과도
- 기존 방법: 고정 길이 chunking 기반 스트리밍, 또는 전체 오디오를 버퍼링하는 비스트리밍 방식
- 제안 방법: (1) Silero VAD와 에너지 기반 필터링을 결합한 하이브리드 VAD 파이프라인 (허위 활성화 34% 감소), (2) 오버래핑 컨텍스트 윈도우를 활용한 동적 버퍼링 메커니즘, (3) 발화 특성에 따라 지연과 정확도를 조절하는 적응형 처리 전략
- 핵심 차별점: 메모리 소비를 유한(bounded)하게 유지하면서 전사 품질 보존. 세그먼트 경계에서의 정보 손실 방지
- 실험 결과: 중앙값 end-to-end 지연 89ms (90th percentile: 142ms), 기존 Whisper 대비 피크 GPU 메모리 48% 절감, 평균 GPU 활용률 80.9% 감소
- 우리 연구 관련도: ★☆☆ — 스트리밍 ASR 엔지니어링 중심으로 표현 학습과 직접적 관련성은 낮으나, 효율적 추론 아키텍처로서 참고 가치 있음

## 2. SpeechLLM (Speech-Language Model)

**[DuplexSLA: A Full-Duplex Spoken Language Model with Synchronized Speech, Language, and Action] (Haoyang Zhang, Jun Chen et al., 2026.05)** — arxiv preprint
- https://arxiv.org/abs/2605.20755
- 기존 문제: 기존 full-duplex 음성 대화 모델은 실시간 에이전트 행동(도구 호출, 계획 수립)을 위한 네이티브 채널이 부재. 대화 중 도구 호출이 턴 경계에 종속되거나 외부 cascade 시스템에 의존
- 기존 방법: Pipeline 기반 음성 대화 시스템 또는 단일 채널 duplex 아키텍처. 발화와 동시에 도구 호출이나 계획 수립이 불가능
- 제안 방법: Dual-stream 3채널 구조를 제안 — (1) 연속 사용자 오디오 채널, (2) 이산 어시스턴트 오디오 채널, (3) rate-limited 텍스트 액션 채널. 단일 backbone이 160ms 청크 타임라인 위에서 세 채널을 동시 디코딩. 의미 기반 turn-taking 제어(인터럽트, 일시정지, backchannel) 내장
- 핵심 차별점: 어시스턴트 음성 출력을 중단하지 않고도 계획 텍스트와 구조화된 도구 호출을 액션 채널로 동시 출력 가능. 외부 VAD 없이 backbone 내부에서 turn-taking 처리
- 실험 결과: DuplexSLA-Bench(pause, interrupt, backchannel turn-taking + 3종 도구 호출 시나리오) 벤치마크에서 SOTA 서브초 지연 달성. Pipeline 및 대안 duplex 아키텍처 대비 응답성과 유창성에서 우위
- 우리 연구 관련도: ★★☆ — 음성 토큰 기반 동시 다채널 디코딩 구조는 speech tokenization 및 representation 설계에 시사점 제공

**[CORTIS: Text-Only Adaptation of Spoken Language Models for Task-Oriented Voice Agents] (Maum AI, SNU, KAIST 연구진, 2026.06)** — arxiv preprint
- https://arxiv.org/abs/2606.21453
- 기존 문제: 태스크 지향 음성 에이전트는 음성 입력을 semantic frame, 실행 가능 액션, 함수 호출 등 구조화된 출력으로 매핑해야 함. Cascade 방식(ASR+텍스트 LLM)은 전사 오류가 하위 구조화 출력 생성에 전파되며, 특히 노이즈 환경에서 심각. Spoken Language Model(SLM) 직접 활용 시에는 음성-타겟 쌍 어노테이션이 필요하여 적응 비용이 높음
- 기존 방법: (1) ASR + 텍스트 LLM cascade, (2) 음성-타겟 쌍으로 SLM을 직접 fine-tuning
- 제안 방법: CORTIS는 텍스트 형태의 태스크 supervision만으로 SLM을 fine-tuning하여, 추론 시에는 음성 기반 구조화 출력 생성이 가능하게 하는 프레임워크. 태스크별 음성-타겟 어노테이션 없이 적응 가능
- 핵심 차별점: 텍스트 데이터만으로 SLM의 태스크 적응이 가능하여 어노테이션 비용을 대폭 절감. 추론 시에는 음성을 직접 처리하므로 ASR 오류 전파 문제 회피
- 실험 결과: Qwen2.5-Omni backbone 2종과 3개 태스크 지향 음성 데이터셋(사내 제품 데이터 포함)에서 평가. 텍스트 전용 적응으로도 음성-타겟 쌍 학습에 준하는 성능 달성
- 우리 연구 관련도: ★★☆ — 텍스트와 음성 모달리티 간의 cross-modal transfer가 핵심으로, speech representation이 텍스트 공간과 어떻게 정렬되는지에 대한 통찰 제공

**[WavAlign: Enhancing Intelligence and Expressiveness in Spoken Dialogue Models via Adaptive Hybrid Post-Training] (MM-Speech 연구진, 2026.04)** — ACL 2026 Findings accepted
- https://arxiv.org/abs/2604.14932
- 기존 문제: End-to-end 음성 대화 모델이 cascade 시스템 대비 표현력과 지각 능력에서 더 높은 잠재력을 가지지만, 현재 오픈소스 모델들의 지능(intelligence)과 표현력(expressiveness)이 기대에 미치지 못함
- 기존 방법: 표준 RL(RLHF/DPO) 기반 post-training. 그러나 음성 대화 모델에 직접 적용 시 의미적 품질과 음향 품질 간의 갈등 발생
- 제안 방법: Modality-aware adaptive post-training 레시피 제안. (1) Preference 업데이트를 semantic 채널에 제한, (2) 음향 행동은 explicit anchoring으로 개선, (3) Rollout 통계 기반으로 두 요소의 혼합 비율을 동적 조절하여 신뢰할 수 없는 preference gradient 회피
- 핵심 차별점: 의미 품질과 음성 표현력의 동시 향상을 달성하는 modality-aware RL 기법. 기존 RL 적용 시 발생하는 semantic-acoustic 품질 갈등을 해소
- 실험 결과: 다수의 음성 대화 벤치마크와 대표적 아키텍처에서 semantic quality 및 speech expressiveness 모두 일관된 개선 확인
- 우리 연구 관련도: ★★☆ — 음성 표현의 semantic/acoustic 분리 및 RL 기반 최적화는 speech representation 품질 향상 연구에 참고 가능

## 3. Speech Foundation Model

**[MOSS-Audio-Tokenizer: Scaling Audio Tokenizers for Future Audio Foundation Models] (OpenMOSS Team, 2026.02)** — arxiv preprint
- https://arxiv.org/abs/2602.10934
- 기존 문제: 이산 오디오 토크나이저는 LLM에 네이티브 오디오 처리/생성 기능을 부여하는 핵심 구성요소이나, 기존 토크나이저들은 CNN 기반의 이질적(heterogeneous) 아키텍처를 사용하여 확장성이 제한적이고, 학습 데이터 규모도 부족
- 기존 방법: EnCodec, SoundStream 등 CNN 기반 encoder-decoder + RVQ 구조. 아키텍처의 이질성(CNN encoder, Transformer decoder 등 혼합)으로 인해 대규모 스케일링이 어려움
- 제안 방법: CAT(Causal Audio Tokenizer with Transformer) — 순수 Transformer 기반 아키텍처로 encoder, quantizer, decoder를 처음부터 end-to-end 공동 최적화. 16억 파라미터, 300만 시간의 다양한 일반 오디오 데이터로 사전학습. 24kHz 원시 오디오를 12.5Hz의 극저 프레임 레이트로 압축, 32-layer RVQ로 0.125kbps~4kbps 범위의 가변 비트레이트 지원
- 핵심 차별점: 순수 Transformer 아키텍처로 동질적(homogeneous) 설계를 실현하여 스케일링 법칙 적용 가능. 3M 시간 규모의 대규모 사전학습으로 다양한 오디오 도메인 커버
- 실험 결과: 다양한 비트레이트에서 SOTA 재구성 품질 달성. 스트리밍 지원과 가변 비트레이트로 생성 및 이해 태스크 모두에서 강한 성능
- 우리 연구 관련도: ★★★ — VQ 기반 오디오 표현 학습의 대규모 스케일링 사례로, VQ-based representation 연구에 직접적 참고. 프레임 레이트와 RVQ 설계 선택이 우리 연구와 밀접

**[Continuous First, Discrete Later: VQ-VAEs Without Dimensional Collapse] (MIT, UPenn, Google 연구진, 2026.05)** — arxiv preprint
- https://arxiv.org/abs/2605.06870
- 기존 문제: VQ-VAE로 학습된 표현이 극도로 낮은 차원의 부분공간(전체 rank의 1-2%)에 집중되는 dimensional collapse 현상 발생. 이로 인해 코드북 활용률이 저하되고 재구성 품질에 hard loss lower bound 형성
- 기존 방법: 코드북 재초기화, EMA 업데이트, commitment loss 조절 등 다양한 코드북 개선 기법이 제안되었으나, dimensional collapse 자체를 해결하지 못하여 loss lower bound를 극복하지 못함
- 제안 방법: Rate-distortion 이론을 도입한 분석 프레임워크로 VQ가 낮은 분산 방향을 억제하여 latent collapse를 유발함을 이론적으로 규명. 해결책으로 AE Warm-Up — VQ 도입 전에 먼저 양자화 없는 autoencoder로 학습하는 warm-up 단계를 제안
- 핵심 차별점: Dimensional collapse의 이론적 원인을 최초로 규명하고, 단순하지만 효과적인 해결책 제시. 기존 코드북 개선 기법들이 실패하는 근본 원인을 설명
- 실험 결과: VQGAN에서 코드북 유효 차원이 3-5에서 17-19로 증가, rFID 17-35% 개선. WavTokenizer(오디오)에서 코드북 차원 4→17-19, PESQ 11-14% 향상
- 우리 연구 관련도: ★★★ — VQ-based representation 연구의 핵심 문제인 dimensional collapse에 대한 이론적 해석과 실용적 해결책 제시. 우리의 VQ 기반 표현 학습 연구에 직접 적용 가능

**[DTM-Codec: Dynamic Token Masking for VFR Speech Coding with Efficient Boundary Selection] (Hoyeol Sohn, Juhan Nam / KAIST, 2026.06)** — Interspeech 2026 accepted
- https://arxiv.org/abs/2606.29480
- 기존 문제: 기존 neural speech codec은 고정 프레임 레이트(Fixed Frame Rate)로 동작하여, 음성의 정보 밀도 변화를 반영하지 못함. 묵음이나 단순 구간에 불필요한 토큰을 할당하고, 복잡한 구간에는 토큰이 부족
- 기존 방법: 고정 프레임 레이트 코덱(EnCodec, SoundStream 등). Variable Frame Rate(VFR) 시도들은 경계 선택의 계산 비용이 높거나 세그먼트 분포가 불균등
- 제안 방법: DTM-Codec — 선택된 encoder 토큰만 유지하고, 마스킹된 위치에 학습된 MASK 임베딩을 채워 position-aware 디코딩 수행. 경계 선택을 위해 Path Length Equalization(PLE) 제안 — 선형 시간 복잡도로 균등하게 분포된 적응형 세그먼트 생성
- 핵심 차별점: Dynamic token masking으로 가변 프레임 레이트를 효율적으로 구현. PLE가 기존 경계 선택 방법 대비 무시할 수 있는 오버헤드로 균등 세그먼트 생성
- 실험 결과: 동일 총 비트레이트 조건에서 고정 프레임 레이트 베이스라인 대비 재구성 품질과 명료도(intelligibility) 전반적 향상
- 우리 연구 관련도: ★★★ — VQ 기반 speech tokenization에서 가변 프레임 레이트 접근법은 temporal contrastive learning 및 prediction-free SSL과 직접적으로 관련. 정보 밀도 기반 토큰 할당은 우리의 temporal representation 연구에 핵심적 시사점 제공
