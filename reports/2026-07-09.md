## 1. ASR (Automatic Speech Recognition)

### 1-1. Gradient-Based Speech-to-Text Alignment for Any ASR Model: From CTC to Speech LLMs
**(Albert Zeyer, Ralf Schlüter, Hermann Ney — RWTH Aachen University, 2026.07)** — arxiv preprint

- **arXiv:** https://arxiv.org/abs/2607.06831
- **기존 문제:** 음성-텍스트 정렬(alignment)은 ASR에서 핵심적인 과제이나, CTC/트랜스듀서 모델은 구조적으로 정렬을 제공하는 반면, 어텐션 기반 인코더-디코더(AED)나 Speech LLM은 명시적 정렬 메커니즘이 없어 단어 수준 타임스탬프 추출이 어려웠다. 기존 정렬 방법은 특정 모델 구조에 종속되어 범용성이 부족했다.
- **기존 방법:** CTC/트랜스듀서의 구조적 정렬, 크로스 어텐션 가중치 기반 정렬, 별도 정렬 헤드 추가, 강제 정렬(forced alignment) 도구(MFA 등). 각 방법이 특정 모델 유형에만 적용 가능하며, Speech LLM에 적용 가능한 범용 정렬 기법이 부재했다.
- **제안 방법:** 교사 강제(teacher-forced) 조건에서 각 토큰의 로그 확률에 대한 입력 기울기(gradient)를 계산하고, 이를 프레임별 현저성(saliency) 점수로 축소한 뒤, 단일 동적 프로그래밍(DP) 패스로 단어 경계를 디코딩하는 범용 기울기 기반 정렬 방법. 모델 수정이나 추가 학습이 불필요하며, 인코더 프레임 그리드가 아닌 입력 오디오 그리드에서 정렬을 수행.
- **핵심 차별점:** CTC, 트랜스듀서, AED, Speech LLM 등 모든 미분 가능한 ASR 모델에 범용 적용 가능한 단일 정렬 프레임워크. 모델 구조 변경 없이 기울기만으로 정렬 추출. 16개 모델(TIMIT, Buckeye 데이터셋)에 걸쳐 평가.
- **실험 결과:** 16개 ASR 모델(CTC, 트랜스듀서, AED, Speech LLM 포함)에서 TIMIT 및 Buckeye 데이터셋으로 정렬 품질 평가. 모든 모델 유형에서 유효한 정렬 결과를 생성하며, 특히 Speech LLM에 대한 최초의 범용 정렬 방법을 제시.
- **우리 연구 관련도:** ★★☆ — 기울기 기반 현저성 분석이 SSL 모델의 내부 표현 분석에 참고 가능. 다양한 ASR 모델 구조에 걸친 정렬 메커니즘 비교가 speech representation의 시간적 구조 이해에 기여.

### 1-2. FAMA: The First Large-Scale Open-Science Speech Foundation Model for English and Italian
**(Sara Papi, Marco Gaido, Luisa Bentivogli, Alessio Brutti, Mauro Cettolo, Roberto Gretter, Marco Matassoni, Mohamed Nabih, Matteo Negri — Fondazione Bruno Kessler (FBK), Trento, Italy, 2025.05)** — arxiv preprint

- **arXiv:** https://arxiv.org/abs/2505.22759
- **기존 문제:** 기존 대규모 음성 기반 모델(Whisper, SeamlessM4T 등)은 비공개 데이터로 학습되어 과학적 재현성이 부족했다. 학습 데이터, 전처리 파이프라인, 학습 코드가 공개되지 않아 공정한 비교와 재현 실험이 불가능했으며, 특히 이탈리아어 등 중소 규모 언어에 대한 개방형 음성 모델이 부족했다.
- **기존 방법:** Whisper(1.55B, 비공개 68만 시간), SeamlessM4T(비공개 대규모 데이터), NVIDIA Canary 등. 모두 비공개 또는 부분 공개 데이터로 학습되어 오픈 사이언스 원칙에 부합하지 않았다.
- **제안 방법:** Conformer 인코더 + Transformer 디코더 + Joint CTC 구조. FAMA-small(479M, 인코더 12층/디코더 6층)과 FAMA-medium(878M, 인코더 24층/디코더 12층) 두 변종. 15만 시간 이상의 오픈소스 준수(open-source-compliant) 음성 데이터로 학습. 2단계 학습: ASR 사전학습 → ASR+음성번역(ST) 미세조정. 16 NVIDIA A100 GPU로 학습. 코드, 데이터셋, 모델 가중치 모두 허용적 오픈소스 라이선스로 공개.
- **핵심 차별점:** 최초의 대규모 오픈 사이언스 음성 기반 모델. 학습 데이터부터 코드, 모델까지 완전 공개. 영어/이탈리아어 ASR 및 양방향 음성번역 지원. 비공개 모델 대비 최대 8배 빠른 추론 속도.
- **실험 결과:** 영어 ASR에서 WER 7.9 달성. Whisper, SeamlessM4T 등 기존 모델과 경쟁적 성능을 보이면서 최대 8배 빠른 추론 속도. 이탈리아어 ASR 및 영어↔이탈리아어 음성번역에서도 강력한 성능. Fairseq 및 HuggingFace 체크포인트 공개.
- **우리 연구 관련도:** ★☆☆ — Conformer+CTC 기반 지도학습 모델로 SSL과 직접 관련은 낮으나, 대규모 음성 모델의 오픈 사이언스 학습 파이프라인 설계와 데이터 큐레이션 방법론이 참고 가능. 재현 가능한 음성 표현 연구의 벤치마크 기반.

## 2. SpeechLLM (Speech-Language Model)

### 2-1. Unlocking Speech–Text Compositional Powers: Instruction-Following Speech Language Models without Instruction Tuning (SpeechCombine)
**(Congrui Du, Yang Zhang, Kaizhi Qian, Shiyu Chang, 2026.07)** — arxiv preprint

- **arXiv:** https://arxiv.org/abs/2607.02214
- **기존 문제:** 기존 Speech LLM은 음성 명령어 수행(instruction-following) 능력을 갖추기 위해 대규모 음성-텍스트 명령어 튜닝 데이터가 필요했다. 이러한 데이터의 수집과 큐레이션에는 높은 비용이 들며, 특히 음성 도메인에서의 고품질 명령어 데이터 확보가 어려웠다.
- **기존 방법:** 음성 인코더 + LLM 결합 후 음성 명령어 튜닝(SFT) 수행, 대규모 음성-텍스트 쌍 수집을 통한 지도 학습, 다단계 학습 파이프라인(사전학습 → 명령어 튜닝 → 정렬). 모두 고비용의 음성 명령어 데이터에 의존.
- **제안 방법:** SpeechCombine — 텍스트 LLM 기반 모델에 3만 시간의 음성 데이터로 연속 사전학습(continuous pre-training)을 수행한 뒤, 음성 적응 모델과 원본 텍스트 LLM의 가중치를 모델 병합(model merging) 기법으로 결합. 음성 입력은 이산 음성 토큰으로 변환되어 LLM에 입력되고, LLM 출력도 음성 토큰으로 생성된 뒤 디코더를 통해 음성으로 복원. 명령어 튜닝 없이 가중치 결합만으로 음성 명령어 수행 능력 발현.
- **핵심 차별점:** 명령어 튜닝 데이터 없이 모델 병합만으로 Speech LLM의 명령어 수행 능력을 달성하는 최초의 접근법. 음성 사전학습과 텍스트 LLM의 지식을 가중치 수준에서 조합하여 새로운 합성적(compositional) 능력 발현을 실증.
- **실험 결과:** 가중치 결합이 세 가지 범주(음성 이해, 명령어 수행, 음성 생성) 모두에서 합성적 효과를 발현. 3만 시간 음성 사전학습만으로 명령어 튜닝 모델에 준하는 음성 명령어 수행 능력 달성.
- **우리 연구 관련도:** ★★☆ — 이산 음성 토큰 기반 Speech LLM 아키텍처가 VQ 기반 speech representation 연구와 직접 관련. 모델 병합을 통한 음성-텍스트 지식 전이 메커니즘이 speech representation의 합성적 활용에 시사점 제공.

### 2-2. Escaping the Procrustean Bed: Groupwise Orthogonal Connectors for Audio-Language Models
**(Ho-Lam Chung, Ke-Han Lu, Yi-Cheng Lin, Guan-Ting Lin, Yiming Chen, Hung-yi Lee — National Taiwan University, 2026.07)** — arxiv preprint

- **arXiv:** https://arxiv.org/abs/2607.06014
- **기존 문제:** Audio-Language Model(ALM)에서 음성 인코더의 출력을 LLM에 전달하는 커넥터(connector)가 출력 벡터를 단일 방향으로 붕괴(collapse)시키는 문제가 있었다. 이로 인해 서로 다른 화자의 음성이 거의 구분 불가능한 표현으로 변환되며, 화자 정체성, 성별, 운율 등 준언어적(paralinguistic) 정보가 소실되었다.
- **기존 방법:** 선형 프로젝션, Q-Former, 학습 가능 어댑터 등의 커넥터 아키텍처. 음성 인코더의 고차원 출력을 LLM 입력 공간으로 매핑하는 역할을 수행하나, 매핑 과정에서 정보 손실과 표현 붕괴가 발생.
- **제안 방법:** Groupwise Orthogonal Connector — 커넥터의 출력 벡터 그룹 간에 직교성(orthogonality) 제약을 부과하여 표현 붕괴를 방지. 음성 인코더의 다양한 정보(의미적/준언어적)를 LLM 입력 공간으로 전달할 때 차원별 다양성을 유지하도록 구조적으로 보장.
- **핵심 차별점:** 커넥터의 표현 붕괴 문제를 최초로 체계적으로 분석하고, 직교성 제약 기반의 구조적 해결책 제시. 준언어적 정보(화자, 성별, 운율) 보존이 핵심 기여. NTU Hung-yi Lee 연구실.
- **실험 결과:** 기존 커넥터 대비 화자 구분, 성별 인식 등 준언어적 정보 보존에서 개선. 음성 이해 태스크에서 표현 다양성 향상을 통한 성능 개선 달성.
- **우리 연구 관련도:** ★★☆ — 음성 인코더 출력의 표현 붕괴 분석이 SSL 모델의 레이어별 표현 특성 연구와 관련. 준언어적 정보의 보존 및 분리(disentanglement)가 speech representation 연구의 핵심 주제와 직접 연결.

## 3. Speech Foundation Model

### 3-1. Speaker-Disentangled Chunk-Wise Regression for Syllabic Tokenization
**(Ryota Komatsu, Kota Kawakita, Takuma Okamoto, Takahiro Shinozaki, 2026.07)** — IEEE Open Journal of Signal Processing (OJSP) accepted

- **arXiv:** https://arxiv.org/abs/2607.04064
- **기존 문제:** 사전학습된 HuBERT 기반 교사-학생(teacher-student) 증류로 음절 토크나이저를 학습할 때, 발화 수준(utterance-level) 교차 엔트로피 목적 함수를 사용하면 학생 모델이 언어적 내용 대신 화자 정체성을 예측하는 문제가 발생했다. 이로 인해 음절 토큰의 언어적 순도가 저하되었다.
- **기존 방법:** HuBERT 기반 k-means 클러스터링 토큰, 발화 수준 교사-학생 증류, BPE 기반 음성 토크나이저. 대부분 음소(phone) 수준 토큰화에 집중하며, 음절 수준 토큰화에서의 화자 정보 혼입 문제를 다루지 않았다.
- **제안 방법:** 화자 교란(speaker perturbation)된 학생 표현을 고정 길이 청크(chunk) 단위로 깨끗한 교사 타겟에 회귀(regression)하는 화자 분리(speaker-disentangled) 접근법. 청크 단위 회귀를 통해 발화 수준 목적 함수의 화자 정보 누출을 방지하고, 음절 경계 검출과 음절 세그먼트 클러스터링의 순도를 향상.
- **핵심 차별점:** 음절 수준 토크나이저에서 화자 정보 분리 문제를 최초로 식별하고, 청크 단위 회귀 + 화자 교란이라는 구조적 해결책을 제시. IEEE OJSP 게재 (10페이지, 4 figures).
- **실험 결과:** 음절 경계 검출 및 음절 세그먼트 클러스터링에서 최고 성능(state-of-the-art) 달성. 생성된 음절 토큰으로 학습한 speech language model이 음소 수준 SpiRit-LM 대비 구문적·의미적 이해에서 7% 상대적 개선.
- **우리 연구 관련도:** ★★★ — HuBERT 기반 표현에서의 화자 정보 분리, 음절 수준 토큰화, 교사-학생 증류 프레임워크가 prediction-free speech SSL 및 VQ 기반 representation 연구와 직접 관련. 청크 단위 회귀 접근이 temporal contrastive learning의 대안적 시간 구조 학습 방법을 제시.

### 3-2. Noisy Environment Adaptation of Neural Speech Codec via Focal Mask and Noise Feature Separation
**(Shaokai Li, Weiping Tu, Yuhong Yang, 2026.07)** — Interspeech 2026 accepted

- **arXiv:** https://arxiv.org/abs/2607.04195
- **기존 문제:** 기존 신경 음성 코덱(neural speech codec)은 깨끗한 음성 데이터로 학습되어 소음 환경에서의 성능이 크게 저하되었다. 실제 배포 환경에서 소음 간섭이 불가피하지만, 코덱의 소음 환경 적응 방법론이 체계적으로 연구되지 않았다.
- **기존 방법:** 별도 전처리 단계로서의 음성 향상(speech enhancement) 적용, 소음 데이터 증강을 통한 코덱 재학습, 또는 소음 강건 인코더의 별도 설계. 대부분 코덱 아키텍처 자체의 소음 적응보다는 외부 처리에 의존.
- **제안 방법:** 두 가지 기법을 결합한 소음 환경 적응 프레임워크. (1) Focal Mask — 소음이 포함된 입력에서 음성 관련 특징에 선택적으로 집중하는 마스킹 메커니즘. (2) Noise Feature Separation — 음성 특징과 소음 특징을 명시적으로 분리하여 코덱이 음성 정보만을 효과적으로 인코딩하도록 유도.
- **핵심 차별점:** 신경 음성 코덱의 소음 환경 적응을 코덱 아키텍처 내부에서 해결하는 접근법. 외부 전처리 없이 코덱 자체가 소음 분리와 음성 집중을 수행. Interspeech 2026 채택.
- **실험 결과:** 소음 환경에서 기존 코덱 대비 음성 품질 메트릭 개선 (Interspeech 2026 채택으로 동료 심사 통과).
- **우리 연구 관련도:** ★★☆ — 음성 코덱 내부에서의 특징 분리(음성/소음)가 VQ 기반 speech representation에서의 정보 분리(시맨틱/어쿠스틱/화자/환경) 연구와 관련. focal mask의 선택적 집중 메커니즘이 speech tokenizer의 정보 선택적 인코딩에 참고 가능.

### 3-3. TokAN: Accent Normalization Using Self-Supervised Discrete Tokens with Non-Parallel Data

- **arXiv:** https://arxiv.org/abs/2507.17735
