## 1. ASR (Automatic Speech Recognition)

**[Mega-ASR: Towards In-the-Wild² Speech Recognition via Scaling Up Real-World Acoustic Simulation] (Zhifei Xie, Kaiyu Pang, Haobin Zhang, Deheng Ye, Xiaobin Hu, Shuicheng Yan, Chunyan Miao, 2026-05)** — arxiv preprint
- https://arxiv.org/abs/2605.19833
- 기존 문제: ASR 시스템은 실제 환경에서 심각한 복합 음향 왜곡(잡음, 반향, 채널 변형 등이 동시에 발생)에 노출될 때 음향적 그라운딩을 잃어 누락(omission)이나 환각(hallucination)을 발생시키는 "acoustic robustness bottleneck" 문제가 존재
- 기존 방법: 개별 음향 현상(잡음, 반향 등)에 대한 데이터 증강이나 단일 조건 학습 위주로, 복합적 음향 시나리오에 대한 체계적 대응이 부족
- 제안 방법: 7가지 기본 음향 현상과 54개의 물리적으로 타당한 복합 시나리오를 포함하는 Voices-in-the-Wild-2M 데이터셋을 구축하고, Acoustic-to-Semantic Progressive SFT와 Dual-Granularity WER-Gated Policy Optimization을 결합한 통합 프레임워크 제안
- 핵심 차별점: 단일 음향 조건이 아닌 복합 음향 시나리오를 대규모로 시뮬레이션하여 학습하며, 점진적 최적화(progressive optimization)를 통해 음향-의미 정렬을 강화
- 실험 결과: VOiCES R4-B-F에서 45.69% vs 기존 SOTA 54.01%, NOIZEUS Sta-0에서 21.49% vs 29.34%, 복합 음향 시나리오에서 30% 이상의 상대 WER 감소
- 우리 연구 관련도: ★☆☆ — 음향 강건성 중심으로, speech representation이나 SSL과는 직접적 관련이 낮음

**[Boosting ASR Robustness via Test-Time Reinforcement Learning] (Linghan Fang, Tianxin Xie, Li Liu, 2026-03)** — AAAI 2026 accepted
- https://arxiv.org/abs/2603.05231
- 기존 문제: Whisper 등 사전학습 ASR 모델이 학습 분포 외의 실환경 데이터(잡음, 다양한 억양)에서 성능이 급격히 저하되는 문제
- 기존 방법: Test-Time Adaptation(TTA) 기법들이 제안되었으나, 노이즈 환경과 억양 변이에 대한 적응이 제한적이고 지연시간이 높음
- 제안 방법: ASR-TRA(Test-time Reinforcement Adaptation) — 인과 추론(causal intervention)에서 영감을 받아, 학습 가능한 디코더 프롬프트와 온도 제어 확률적 디코딩으로 다양한 전사 후보를 생성하고, 음성-텍스트 의미 정렬을 측정하는 보상 모델로 강화학습 기반 파라미터 업데이트 수행
- 핵심 차별점: 테스트 시점에서 RL 기반 적응을 수행하여 추가 학습 데이터 없이도 도메인 변화에 대응. 인과 추론 기반 접근으로 노이즈와 억양 변이를 환경적 혼재 변수(confounders)로 분리
- 실험 결과: LibriSpeech 합성 노이즈 및 L2 Arctic 억양 영어 데이터셋에서 기존 TTA 베이스라인 대비 더 높은 정확도와 낮은 지연시간 달성
- 우리 연구 관련도: ★☆☆ — ASR 추론 최적화 중심, SSL representation과는 간접적 관련

**[Indic DiarBench: A Multilingual Joint Diarization and ASR Benchmark for Indian Languages] (Deovrat Mehendale, Aditya Mehndiratta, Dhruv Rathi, Kaushal Bhogale, Mitesh M. Khapra, 2026-07)** — Interspeech 2026 accepted
- https://arxiv.org/abs/2607.23808
- 기존 문제: 인도 언어에 대한 화자 분리(diarization)와 ASR을 동시에 평가할 수 있는 대규모 벤치마크가 부재. 기존 벤치마크는 영어 중심이며 인도 언어의 코드스위칭, 방언 변이, 빈번한 화자 겹침 등을 반영하지 못함
- 기존 방법: 영어 위주 벤치마크(AMI, CALLHOME 등)로 평가하거나, 소규모 인도 언어 데이터셋에 의존
- 제안 방법: 인도의 22개 공식 언어를 모두 포함하는 약 108시간의 자연 다화자 오디오 벤치마크 구축. 근거리/원거리/실환경 녹음을 포함하며, 시간 정렬된 화자별 전사를 인간이 교정
- 핵심 차별점: 22개 인도 언어 전체를 아우르는 최초의 대규모 공동 다이어리제이션-ASR 벤치마크. 영어 코드믹싱, 방언 변이, 화자 겹침을 자연스럽게 포착
- 실험 결과: 상용 음성 API와 멀티모달 LLM을 포함한 주요 시스템들을 평가하여 베이스라인 확립. Hugging Face에 오픈 액세스 공개
- 우리 연구 관련도: ★☆☆ — 다국어 평가 벤치마크로, 직접적 모델 기법보다는 평가 인프라 기여

## 2. SpeechLLM (Speech-Language Models)

**[NemotronLabs VoiceChat: An Open Full-duplex Speech-to-Speech Model with Tool Calling Capabilities] (Jagadeesh Balam et al., NVIDIA, 2026-09)** — arxiv preprint (오픈 웨이트 공개)
- https://arxiv.org/abs/2609.21967
- 기존 문제: 기존 full-duplex 음성 모델은 대화 중 도구(tool) 호출이 불가능하며, 도구 실행 시 대화 흐름이 중단되는 한계. 오픈소스 full-duplex 모델에서 tool calling을 지원하는 사례가 없었음
- 기존 방법: 기존 full-duplex 모델(Moshi, DuplexSLA 등)은 실시간 양방향 대화에 집중하되, 외부 도구와의 연동은 지원하지 않음. 도구 호출이 가능한 모델은 half-duplex 방식
- 제안 방법: 11B 파라미터 모델로, Fast Conformer 음성 인코더 + Nemotron Nano V2 9B LLM 백본 + 스트리밍 TTS 디코더를 결합. 별도의 출력 채널을 통해 대화 중 네이티브 tool calling 스크립트 생성. 보조 RNN-T 브랜치로 사용자 발화의 점진적 전사도 수행
- 핵심 차별점: 오픈소스 최초의 네이티브 tool calling이 가능한 full-duplex 모델. 도구 실행 중에도 자연스러운 대화 흐름 유지
- 실험 결과: Full-Duplex-Bench 1.0에서 가장 낮은 pause-handling takeover rate, 100% 사용자 인터럽트 응답율, 응답 품질 4.33/5. VoiceBench에서 55.1 정규화 평균. Tool-selection F1 82.5% (Full-Duplex-Bench 3.0)
- 우리 연구 관련도: ★★☆ — Full-duplex SpeechLLM 아키텍처와 음성 인코딩 방식이 speech representation 활용과 관련

**[StreamAlign: Streaming Text-Aligned Speech Tokenization] (Kang-wook Kim, Jinyoung Park, Jinsoo Kim, Sehun Lee, Sang Hoon Woo, Gunhee Kim, 2026-09)** — EMNLP 2026 Findings accepted
- https://arxiv.org/abs/2609.09719
- 기존 문제: 기존 speech tokenizer들은 텍스트와의 정렬이 부족하거나 스트리밍을 지원하지 않아, 실시간 음성-텍스트 공동 모델링에 제약. ASR-LLM 간 어휘(vocabulary) 불일치 문제도 존재
- 기존 방법: TASTE 등 텍스트 정렬 토큰화 방식은 오프라인 전체 발화 기반으로 작동하여 스트리밍 불가. 기존 스트리밍 코덱은 텍스트 정렬을 고려하지 않음
- 제안 방법: 문자 수준 RNN-Transducer 정렬과 단어 수준 ASR 가이던스를 결합한 온라인 음성-텍스트 정렬 프레임워크. LLM 서브워드 집계(aggregation)를 통해 ASR-LLM 어휘 불일치 해소. 선제적 단어 경계 검출(proactive word boundary detection)로 지연시간 추가 감소
- 핵심 차별점: 토큰화와 복원 모두에서 스트리밍을 지원하는 최초의 텍스트 정렬 음성 토큰화 프레임워크. 단어 경계 예측으로 지연시간을 560ms → 270ms로 단축
- 실험 결과: LibriSpeech에서 평가 대상 토큰화기 중 최저 WER(4.41)와 최고 UTMOS(4.23). StreamAlign-SLM은 speech continuation 및 SALMon/spoken StoryCloze에서 다른 end-to-end SLM 능가
- 우리 연구 관련도: ★★★ — 음성 토큰화(speech tokenization) 방법론으로, VQ-based representation 및 speech tokenizer 연구와 직접 관련

**[GSRM: Generative Speech Reward Model for Speech RLHF] (Maohao Shen, Tejas Jayashankar et al., Meta, 2026-02)** — arxiv preprint
- https://arxiv.org/abs/2602.13891
- 기존 문제: Speech LLM의 생성 음성 자연스러움을 평가하는 기존 방법들은 원시 오디오를 스칼라 점수로 회귀하여 해석가능성이 낮고, 다양한 음성 분류 체계에 대한 일반화가 부족
- 기존 방법: MOS 예측 모델, UTMOS 등 음성 품질 평가 모델이 있으나, 설명 가능한 판단 근거를 제공하지 못하고 out-of-domain 일반화에 취약
- 제안 방법: GSRM은 음성 자연스러움 평가를 해석 가능한 음향 특징 추출 + 특징 기반 chain-of-thought 추론의 두 단계로 분해하는 생성적 보상 모델. 31K 전문가 평가 데이터셋과 실제 사용자-어시스턴트 음성 상호작용의 OOD 벤치마크 함께 공개
- 핵심 차별점: 기존 회귀 기반 점수 예측이 아닌 생성적(generative) 접근으로 추론 과정이 해석 가능. 온라인 RLHF의 검증기(verifier)로 활용 가능
- 실험 결과: OOD 데이터에서 PCC 0.465 달성 (인간 평가자 간 일치도 0.532에 근접). 기존 음성 자연스러움 예측기를 크게 능가
- 우리 연구 관련도: ★★☆ — Speech LLM 정렬 기법으로, 음성 표현의 품질 평가와 관련되나 SSL 자체와는 간접적

**[WavSLM: Single-Stream Speech Language Modeling via WavLM Distillation] (Luca Della Libera, Cem Subakan, Mirco Ravanelli, 2026-03)** — Interspeech 2026 accepted
- https://arxiv.org/abs/2603.05299
- 기존 문제: 기존 Spoken Language Model(SLM)은 의미(semantic)와 음향(acoustic) 정보를 별도의 다중 스트림/다중 코드북으로 처리하여 아키텍처가 복잡하고, 텍스트 사전학습에 의존하는 경우가 많음
- 기존 방법: GSLM, TWIST 등은 의미 토큰만 사용하거나, SpiritLM/Moshi 등은 계층적/다중 스트림 토큰화를 사용. 대부분 텍스트 기반 사전학습 또는 대규모 데이터에 의존
- 제안 방법: 자기지도학습 WavLM 표현을 단일 코드북으로 양자화 및 증류(distillation)하여, 의미와 음향 정보를 하나의 토큰 스트림에서 공동 모델링. 자기회귀 next-chunk prediction으로 학습하며, 텍스트 지도학습이나 텍스트 사전학습 불필요
- 핵심 차별점: 단일 코드북으로 의미+음향을 공동 캡처하는 최초의 SLM. 계층적/다중 스트림 토큰화 없이 경쟁력 있는 성능 달성. 완전 스트리밍 추론 지원
- 실험 결과: 의미 일관성, 음향 일관성, 음성 생성 태스크에서 대규모 SLM과 경쟁적 성능. 모델 크기와 학습 데이터가 현저히 적음에도 불구하고 강력한 결과
- 우리 연구 관련도: ★★★ — WavLM SSL 표현의 양자화 및 증류 기반 접근으로, prediction-free speech SSL 및 VQ-based representation 연구와 직접적으로 관련

**[JASPER: Joint Audio and Speech Pre-trained Encoder Representations] (Geeth George, Ameenudeen P E, Hrishikesh H Pillai, Sriram Ganapathy, 2026-09)** — arxiv preprint
- https://arxiv.org/abs/2609.27260
- 기존 문제: 음성 SSL(시간 도메인 예측 중심)과 일반 오디오 표현 학습(시간-주파수 패턴 중심)이 별도 트랙으로 발전하여, 음성과 오디오를 모두 잘 처리하는 통합 인코더가 부재
- 기존 방법: wav2vec 2.0, HuBERT 등은 시간 도메인 마스크 예측에 집중. BEATs, Audio-MAE 등은 스펙트로그램 기반 시간-주파수 학습에 집중. 두 접근 간 교차 활용이 제한적
- 제안 방법: 음성 사전학습 모델에 시간-주파수 목적함수를 추가(augment)하여, 긴 오디오 세그먼트에 대해 시간적(temporal) 및 스펙트럴(spectral) 타깃의 마스크 예측을 수행하는 스펙트로-시간적(spectro-temporal) 표현 학습 프레임워크
- 핵심 차별점: 음성과 일반 오디오를 단일 프레임워크에서 통합 학습. 기존 음성 SSL 모델에 시간-주파수 목적함수를 추가하는 방식으로 확장성 확보
- 실험 결과: 다양한 음성, 오디오, 음악 태스크에서 다수의 베이스라인과 기존 음성/오디오 인코더를 일관되게 능가
- 우리 연구 관련도: ★★★ — 마스크 예측 기반 SSL 프레임워크로, temporal contrastive learning 및 speech representation learning 연구와 직접적으로 관련

**[LLM-Codec: Neural Audio Codec Meets Language Model Objectives] (Ho-Lam Chung, Yiming Chen, Hung-yi Lee, 2026-04)** — ACL 2026 Findings accepted
- https://arxiv.org/abs/2604.17852
- 기존 문제: 기존 neural audio codec은 파형 복원(reconstruction)에 최적화되어 있으나, LLM 기반 음성 생성에서 토큰으로 사용될 때는 자기회귀 예측에 적합하지 않음. 음향 중심의 불확실성이 이산 토큰 공간에 주입되어 언어 모델 perplexity를 증가시킴
- 기존 방법: EnCodec, SoundStream 등은 파형 복원 품질을 목적함수로 학습. 코덱 설계와 LM 학습 목적 간의 불일치(mismatch)를 해결하지 못함
- 제안 방법: LLM-Codec은 코덱 학습에 언어 모델 지향 목적함수(language-model-facing objectives)를 추가하여, 코덱과 LLM 아키텍처를 모두 변경하지 않고도 토큰의 자기회귀 예측 적합성을 향상
- 핵심 차별점: 코덱의 압축 목적과 LM의 예측 목적 간 갭을 명시적으로 해소. 아키텍처 변경 없이 학습 목적함수 추가만으로 개선
- 실험 결과: ACL 2026 Findings에 게재 확정. LM perplexity 감소 및 다운스트림 음성 생성 품질 향상
- 우리 연구 관련도: ★★★ — VQ 기반 speech tokenization과 LM 학습 목적의 정렬 문제를 다루며, VQ-based representation 연구에 직접적 시사점 제공
