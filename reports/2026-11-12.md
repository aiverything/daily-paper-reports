## 1. ASR (Automatic Speech Recognition)

### **[Earlybird: Predictive Streaming Speech Recognition in 29M Parameters] (Sahil Mahendrakar, 2026-11-10)** — arxiv preprint
- https://arxiv.org/abs/2611.14421
- **기존 문제**: 기존 스트리밍 ASR 모델은 화자가 단어를 다 발화한 뒤 90~400ms 후에야 해당 단어를 출력하여, 실시간 상호작용에서 체감 지연이 발생
- **기존 방법**: Moonshine, Whistle 등 소형 스트리밍 ASR 모델이 존재했으나, 모두 단어 완료 이후에 인식 결과를 출력하는 반응적(reactive) 방식
- **제안 방법**: Moonshine Streaming Tiny를 기반으로 영어 어휘를 19,007 토큰으로 축소하여 34M→29M(16.8MB at 4-bit) 파라미터로 경량화. 발화를 랜덤 80ms 단위로 절단한 데이터로 학습하여, 화자가 단어를 끝내기 전에 예측적으로(predictive) 단어를 출력
- **핵심 차별점**: 반응적이 아닌 예측적 스트리밍 ASR. 화자 발화 완료 전에 단어를 출력하는 최초의 초소형 모델
- **실험 결과**: LibriSpeech test-clean에서 중앙값 기준 화자 발화 완료 90ms 전에 정확한 단어 예측. 6개 타이밍 테스트셋 모두에서 가장 빠른 출력. Open ASR Leaderboard 8개 영어 셋에서 Moonshine Tiny를 모든 셋에서 상회하고, 동급 크기 Whistle과 동등 수준(평균 WER 12.6%)
- **우리 연구 관련도**: ★☆☆ — 소형 end-to-end ASR 모델로 우리의 prediction-free SSL/VQ 기반 표현 학습과 직접적 관련은 적음. 다만 예측적 디코딩 전략은 temporal representation 활용 관점에서 참고 가능

### **[TID System for Speech-COSER Challenge 2026: ASR Track] (Fernando López, Jordi Luque, 2026-11-08)** — arxiv preprint
- https://arxiv.org/abs/2611.11497
- **기존 문제**: 스페인 농촌 지역 노년층의 자발적 발화(spontaneous elderly speech)는 방언 변이, 비유창성, 배경 소음 등으로 인해 기존 ASR 모델의 성능이 크게 저하됨. 학습 데이터의 품질 불균형도 심각
- **기존 방법**: 사전학습된 대규모 ASR 모델을 직접 미세조정하거나, 수동 데이터 필터링을 통해 학습 데이터 품질을 개선하는 방식
- **제안 방법**: CTC posterior 기반 pseudo-forced alignment 점수를 활용한 자동 데이터 필터링. 참조 전사와 CTC posterior 확률 간의 정렬 경로를 따라 세그먼트별 평균 로그확률 점수를 산출하고, 이를 기준으로 2단계 LoRA 커리큘럼 학습 수행. 이후 LoRA 행렬에 magnitude pruning 적용
- **핵심 차별점**: CTC posterior를 데이터 품질 필터로 활용하여 자동화된 커리큘럼 학습 파이프라인 구축. 수동 라벨링 없이 데이터 품질 기반 학습 스케줄링
- **실험 결과**: Speech-COSER Challenge 2026 ASR 트랙 대상 시스템. CTC 정렬 기반 필터링이 노년층 자발 발화 인식 성능 개선에 효과적임을 보고 (구체적 WER 수치는 원문 참조 필요)
- **우리 연구 관련도**: ★★☆ — CTC posterior를 표현 품질 진단 도구로 활용하는 접근은 speech representation의 정보량 측정과 방법론적 유사성 있음. Prediction-free 접근과 대조적이지만 CTC 기반 표현 분석 관점에서 참고 가치

### **[Off-target posterior mass: A training-free diagnostic for fine-tuning spoken language diarization probes] (Zhuoyan Tao, Aditya Kommineni, Shrikanth Narayanan, 2026-11-10)** — arxiv preprint
- https://arxiv.org/abs/2611.13430
- **기존 문제**: 사전학습된 음성 모델(SSL) 위에 화자분리(SLD) 프로브를 구축할 때, 미세조정(fine-tuning)이 성능을 얼마나 개선할지 사전에 예측하기 어려움. 미세조정 없이 성능 향상 가능성을 진단하는 방법 부재
- **기존 방법**: SSL 모델의 프로브 성능은 실제로 미세조정을 수행한 후에야 평가 가능했으며, 사전 진단 메트릭이 체계적으로 연구되지 않음
- **제안 방법**: Off-target Posterior Mass(OTPM) 메트릭 제안. 언어 식별(LID) posterior 확률 중 목표 언어 이외에 분산된 확률 질량을 측정하여, 미세조정을 실행하지 않고도 SLD 프로브의 성능 향상 가능성을 예측
- **핵심 차별점**: 학습 없이(training-free) 사전학습 표현의 미세조정 이점을 정량적으로 예측하는 진단 도구. 계산 비용 없이 적용 가능
- **실험 결과**: OTPM과 프로브 성능 향상 간 양의 상관관계 확인. 합성 이중언어 데이터에서 Pearson r=0.56, 실세계 코퍼스에서 r=0.23
- **우리 연구 관련도**: ★★★ — SSL 모델 표현의 정보 분포를 분석하는 training-free 진단 방법론으로, prediction-free speech SSL 연구에서 표현 품질 평가 프레임워크로 직접 활용 가능. 표현 내 잔여 정보(off-target mass) 개념은 VQ 기반 표현의 정보 손실 분석과도 연결

## 2. SpeechLLM (Speech Language Model)

### **[Apriel Voice 27B Preview: An Open Model for Speech, Reasoning, and Tool Use] (Aman Tiwari 외 30명, ServiceNow, 2026-10-29)** — arxiv preprint
- https://arxiv.org/abs/2610.40738
- **기존 문제**: 기존 음성 LLM은 단순 음성 인식/이해에 그치거나, 추론(reasoning) 및 도구 호출(tool calling) 기능을 음성 입력에서 직접 수행하지 못함. 음성→텍스트→LLM→도구의 cascaded 파이프라인이 필요
- **기존 방법**: Qwen-Audio, Gemini 등 대규모 멀티모달 모델이 음성 이해를 지원하나, 음성 입력에서 직접적인 추론 체인 생성 및 도구 호출을 통합한 오픈 모델은 부재
- **제안 방법**: Whisper large-v3-turbo 음성 인코더 + learned projector + Gemma 4 26B-A4B 백본으로 구성. 2단계 학습: (1) 음성 인터페이스 설정, (2) projector와 백본을 SFT + text replay + cross-entropy/forward KL distillation으로 공동 적응. 음성 입력에서 직접 텍스트 응답 및 도구 호출 생성
- **핵심 차별점**: 음성에서 직접 추론 및 도구 호출이 가능한 최초의 오픈소스(MIT 라이선스) 음성 LLM. 별도 ASR 파이프라인 불필요
- **실험 결과**: Thinking 모드 기준 Big Bench Audio 98.90, Speech-BFCL 81.13, τ-Voice 태스크 성공률 65.51%(평균 지연 1.91초). 텍스트 및 이미지 입력 기능도 유지
- **우리 연구 관련도**: ★☆☆ — 대규모 음성-LLM 통합 모델로 우리의 SSL/VQ 표현 학습과 직접적 관련은 적음. 다만 Whisper 인코더의 음성 표현이 LLM 추론에 어떻게 활용되는지에 대한 시사점 제공

### **[Do Multi-Turn Conversational Capabilities Carry Over from Text to Speech? A Parallel Multilingual Benchmark] (Jiaming Zhou 외 5명, 2026-11-03)** — arxiv preprint
- https://arxiv.org/abs/2611.04390
- **기존 문제**: 음성 대화 모델의 다중 턴(multi-turn) 대화 능력 평가 시, 텍스트 기반 벤치마크 점수가 음성 모달리티에서의 실제 성능을 대표하는지 불명확. 기존 벤치마크는 주로 단일 턴, 영어 중심
- **기존 방법**: Audio MultiChallenge 등 음성 대화 벤치마크가 있었으나, 텍스트-음성 간 엄밀한 병렬(parallel) 비교가 가능한 다국어 벤치마크 부재
- **제안 방법**: Omnilingua-AudioMC 벤치마크 제시. Audio MultiChallenge의 다국어 병렬 확장으로, 10개 언어에 걸쳐 354개 대화, 1,404개 평가 항목 구성. 동일 대화를 전사(transcript)와 음성(speech) 양쪽 형태로 제공하여 모달리티 간 직접 비교 가능
- **핵심 차별점**: 텍스트와 음성 간 엄밀한 병렬 평가를 통해 모달리티 전이(carry-over) 효과를 정량 측정. 대화 구조, 턴 의존성, 평가 기준을 언어·모달리티 간 완전히 보존
- **실험 결과**: 전사 기반 성능이 다국어 음성 대화 능력의 신뢰할 수 없는 프록시임을 입증. 음성에서 가장 성능이 떨어지는 모델의 경우, 선행 음성 맥락의 표현 방식이 회복 가능한 성능 저하의 주요 원인으로 지목
- **우리 연구 관련도**: ★★☆ — 음성 표현이 다중 턴 맥락 정보를 어떻게 전달하는지에 대한 분석적 시사점 제공. 음성 표현의 정보 보존 능력 평가 관점에서 representation learning 연구와 간접적 관련

### **[ReListen: Training-Free Evidence Localization in Hour-Long Audio with Frozen Audio Language Models] (Ming-Hao Hsu 외 6명, 2026-11-03)** — arxiv preprint
- https://arxiv.org/abs/2611.04480
- **기존 문제**: 1시간 이상의 장시간 오디오는 오디오 언어 모델의 컨텍스트 윈도우에 맞지 않음. 답변에 필요한 정보는 전체 중 수 초에 불과하나, 전사(transcript) 기반 검색은 음향·화자 정보를 소실하고, 오디오 기반 증거 검색은 별도 학습이 필요했음
- **기존 방법**: HARP(에이전틱 검색), LEAP(학습 기반 블록 검색) 등이 장시간 오디오 QA를 다뤘으나, 별도 모듈 학습이나 전사 의존이 필요
- **제안 방법**: ReListen — frozen 오디오 언어 모델이 전사 없이 스스로 증거 구간을 탐지한 뒤 답변하는 training-free 프레임워크. 녹음을 겹치는 20초 윈도우로 분할하여 스캔하고, 관련 구간을 선별하여 최종 답변 생성
- **핵심 차별점**: 학습 없이(training-free), 전사 없이(transcript-free) frozen 모델만으로 장시간 오디오에서 증거 위치를 특정. 모델 자체의 내재적 오디오 이해 능력만 활용
- **실험 결과**: VoiceGiraffe에서 선택된 1분 구간이 정답 증거와 88.5% 오버랩(전사 기반 검색보다 높음). 전체 녹음 전사 대비 +9.2pt 정확도 향상. 80분 이상 녹음에서 49.4% vs 베이스라인 44.3%. 단, 증거 탐지 실패 시 정확도가 무오디오 수준(38.7%)으로 하락
- **우리 연구 관련도**: ★★☆ — Frozen 모델의 내재적 표현이 장시간 오디오에서 의미적 증거를 탐지할 수 있다는 발견은 speech representation의 정보 보존 능력을 시사. SSL 표현의 downstream 활용 가능성 관점에서 참고 가치

## 3. Speech Foundation Model

### **[Improving Large Audio-Language Model Embedding Baselines for Instruction-Aware Speech Retrieval] (Chen-An Li, Cheng-Han Chiang, Hung-yi Lee, 2026-11-06)** — arxiv preprint
- https://arxiv.org/abs/2611.09122
- **기존 문제**: 대규모 오디오-언어 모델(LALM)은 생성 태스크에는 뛰어나지만, 음성 검색(retrieval)을 위한 임베딩 모델로의 전환이 체계적으로 연구되지 않음. 특히 자연어 지시문(instruction)에 따라 검색 기준이 달라지는 instruction-aware 검색이 미흡
- **기존 방법**: ALM2Vec 등이 오디오 LLM 기반 범용 오디오 임베딩을 제안했으나, 음성 특화 검색이나 지시문 기반 검색에서의 성능이 제한적. ECAPA-TDNN 등 특화 모델이 화자 매칭 등 특정 태스크에서 여전히 우위
- **제안 방법**: IRIS-Embed — 대규모 오디오-언어 모델을 대조학습(contrastive training)과 instruction-aware audio layer weighting으로 임베딩 모델로 변환. 서로 다른 검색 태스크가 오디오 인코더의 서로 다른 레이어의 hidden state를 선호한다는 분석에 기반하여, 지시문에 따라 레이어별 가중치를 동적 조정
- **핵심 차별점**: 검색 태스크별로 최적의 오디오 인코더 레이어가 다르다는 발견에 기반한 instruction-aware 레이어 가중치 학습. 단일 모델로 다양한 검색 의도 처리
- **실험 결과**: INSPIRE 벤치마크에서 macro-average Recall@50 62.92%(최강 베이스라인 45.15% 대비 +17.77pt). MAEB 범용 오디오 임베딩 벤치마크에서 베이스라인 대비 9.4~19.8pt 향상. 단, VCTK 화자 매칭에서는 특화 모델 ECAPA-TDNN이 여전히 우위
- **우리 연구 관련도**: ★★★ — 오디오 인코더의 레이어별 표현이 서로 다른 정보를 인코딩한다는 분석은 speech representation learning의 핵심 질문과 직결. Instruction-aware 레이어 가중치는 SSL 표현의 계층적 정보 구조 이해에 직접적 시사점 제공

### **[How Much Prosody Does Your ASR Encoder Already Know] (Rini Sharon, Kadri Hacioglu, Andreas Stolcke, 2026-11-02)** — arxiv preprint
- https://arxiv.org/abs/2611.02602
- **기존 문제**: ASR 인코더가 음성 인식을 위해 학습되면서 운율(prosody) 정보를 얼마나 내재적으로 학습하는지 불명확. 운율 관련 downstream 태스크를 위해 별도 운율 특징을 추가해야 하는지에 대한 체계적 분석 부재
- **기존 방법**: 기존 프로빙 연구들은 SSL 모델(HuBERT, wav2vec 2.0)의 운율 정보를 주로 분석했으나, 실제 ASR 용도로 미세조정된 스트리밍 인코더에서의 운율 정보 보존을 계층별로 체계적으로 분석한 연구 부족
- **제안 방법**: 스트리밍 Zipformer ASR 인코더의 4개 깊이(원시 입력~최종 레이어)에서 운율 정보를 프로빙. 수작업 운율 특징(hand-built prosody features)과 인코더 표현을 조합하여 3가지 테스트로 운율 정보 유무 검증
- **핵심 차별점**: ASR 미세조정된 스트리밍 인코더에서의 운율 정보를 깊이별로 분석. 실용적 ASR 인코더가 별도 운율 모듈 없이도 충분한 운율 정보를 보유하는지 검증
- **실험 결과**: 3가지 테스트 모두 일관된 결과: 원시 오디오에서는 수작업 운율 특징이 큰 도움이 되지만, 첫 번째 인코더 레이어 이후에는 그 이점이 대부분 소멸. 즉, ASR 인코더의 초기 레이어만으로도 운율 정보가 이미 충분히 인코딩됨
- **우리 연구 관련도**: ★★★ — 음성 인코더 표현의 계층적 정보 구조 분석으로, speech representation learning 연구에 직접적 시사점. 인코더 초기 레이어에서 운율 정보가 이미 학습된다는 발견은 temporal contrastive learning 설계에서 어떤 계층의 표현을 활용할지에 대한 지침 제공
