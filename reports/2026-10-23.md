## 1. ASR (Automatic Speech Recognition)

**[VISH-ASR: Viterbi-Guided Selection of Hotwords for Speech-LLM Contextual ASR] (Xiaoyu Gu, Yu Xi, Chencheng Wang, Zonghan Zhou, Haoyu Li, Jing Peng, Kai Yu — 2026-10-20)** — arxiv preprint
- https://arxiv.org/abs/2610.27867
- **기존 문제**: 대규모 핫워드(hotword) 리스트에서 프롬프트 기반 contextual ASR에 적합한 소수의 핫워드를 사전 선별하는 것이 어려움. 기존 방법은 이산적 ASR 가설에 의존하여 음향 증거를 손실하거나, 별도 학습된 검색 모델이 필요함.
- **기존 방법**: 가설 기반 필터링(ASR 1-best/N-best에서 핫워드 매칭) 또는 학습 기반 검색(retrieval) 모델을 사용하여 후보를 줄이는 접근법.
- **제안 방법**: VISH는 학습 불필요(training-free)하고 plug-and-play 방식으로, 각 핫워드 후보의 음향 증거를 프레임 수준 CTC 사후확률에서 직접 확인함. M-VISH는 프레임 동기식 공유 접두사 탐색 및 bounded top-K 가지치기로 대규모 후보 리스트에 대응하며, Bi-MVISH는 역방향 음향 증거를 추가하여 검증 강건성을 높임.
- **핵심 차별점**: 별도 모델 학습 없이 CTC 사후확률을 직접 활용하여 음향 기반 핫워드 검증을 수행. 기존 가설 기반 방법 대비 음향 정보 손실 없이 후보를 선별.
- **실험 결과**: 5개 벤치마크에서 M-VISH가 학습 기반 검색 대비 Best-F1 최대 11.7% 절대 향상, 2,000개 후보 기준 탐색 지연 75.2% 감소.
- **우리 연구 관련도**: ★☆☆ — CTC 사후확률 활용은 흥미로우나, speech SSL이나 VQ 기반 표현학습과의 직접적 연관성은 낮음.

**[Probing and Mitigating Hallucinations in Speech-augmented Language Models for ASR via Small Language Models] (Bi-Cheng Yan, Jhih-Rong Guo, Fu-An Chao, Berlin Chen — 2026-10-18)** — Interspeech 2026 accepted
- https://arxiv.org/abs/2610.25351
- **기존 문제**: 음성 증강 언어 모델(Speech-augmented LM)을 ASR에 사용할 때, 모델이 실제 음성에 없는 단어를 생성하는 환각(hallucination) 현상이 발생함.
- **기존 방법**: 대규모 LLM 기반 ASR이 주류였으나, 환각의 원인 분석 및 체계적 완화 전략이 부족했음.
- **제안 방법**: AudioSLM이라는 소규모 언어 모델(SmolLM2) 기반 ASR 프레임워크를 제안. CTC 정렬 단서와 cross-attention 레이어를 활용하여 음향 모델링을 강화함. 인과적 매개 분석(causal mediation analysis)을 통해 환각의 주요 원인이 텍스트 토큰에 과도한 주의를 부여하는 multi-head self-attention 모듈임을 규명.
- **핵심 차별점**: 대형 LLM 대신 소규모 LM으로도 환각을 크게 줄일 수 있음을 입증. 환각 원인에 대한 메커니즘 수준의 분석(self-attention의 텍스트 편향)을 제공.
- **실험 결과**: LibriSpeech에서 AudioSLM이 ASR 환각을 크게 감소시키며, 일부 LLM 기반 ASR 모델을 능가하는 성능.
- **우리 연구 관련도**: ★☆☆ — ASR 환각 분석은 흥미로운 주제이나, speech SSL이나 VQ 표현학습 연구와의 직접적 관련도는 낮음.

**[Teaching LLMs to Hear Who Spoke What: Metadata-Supervised Pretraining for Encoder-Free Speech-LLMs] (Mohan Shi, Ruchao Fan, Sunit Sivasankaran, Keqi Deng, Jinyu Li — 2026-10-01)** — arxiv preprint (Microsoft)
- https://arxiv.org/abs/2610.01695
- **기존 문제**: 인코더 기반 Speech-LLM은 사전학습된 음성 인코더에 의존하는데, 이 인코더가 언어적 내용을 우선하여 화자 구별에 필요한 음향 디테일을 잃어버리는 문제가 있음.
- **기존 방법**: Whisper, HuBERT 등 사전학습 인코더 + LLM 디코더 조합. 인코더가 이미 음향 정보를 추상화하므로 화자 관련 정보가 병목이 됨.
- **제안 방법**: 인코더 없이(encoder-free) 80차원 로그멜 스펙트로그램을 경량 컨볼루션으로 8배 다운샘플링(12.5Hz)하여 LLM에 직접 입력. 메타데이터 지도 사전학습(MSP)으로 화자 정체, 감정 등을 학습 신호로 사용하고, 화자 인지 발화 구성(speaker-aware utterance composition)과 랜덤 스팬 마스킹을 추가.
- **핵심 차별점**: 사전학습 인코더를 완전히 제거하여 음향 디테일(화자, 감정 등) 보존. 메타데이터 기반 사전학습이 기존 인코더 기반 대비 화자 속성 인식에서 우위.
- **실험 결과**: AMI에서 WDER 5.38 / cpWER 21.27, CH109에서 WDER 2.77 / cpWER 19.08. 인코더 기반 MSP 대비(AMI: 5.79/21.79, CH109: 2.85/19.86) 개선.
- **우리 연구 관련도**: ★★☆ — 인코더 없이 원시 스펙트로그램에서 직접 표현을 학습하는 접근은 prediction-free SSL 연구의 "인코더에 의존하지 않는 표현학습" 관점과 부분적으로 관련.

## 2. SpeechLLM (Speech Language Model)

**[Diffuplex: Full-duplex Spoken Language Modeling with Discrete Diffusion] (Chen Chen, Pin-Jui Ku, Ankita Pasad, Ante Jukić, Zhehuai Chen, Boris Ginsburg — 2026-10-13)** — arxiv preprint (NVIDIA)
- https://arxiv.org/abs/2610.17780
- **기존 문제**: 기존 full-duplex 음성 대화 모델은 자기회귀(autoregressive) 방식으로 매 프레임마다 순차 생성하므로, 고속 응답과 언어적 지능 사이에 트레이드오프가 존재함.
- **기존 방법**: 자기회귀 기반 full-duplex 모델(LSLM, DuplexSLA 등)이 프레임 단위로 생성과 수신을 교대 수행.
- **제안 방법**: 이산 확산(discrete diffusion) 기반 full-duplex 모델로, 자기회귀 브랜치가 사용자 음성을 실시간 추적하고, 확산 브랜치가 256 토큰 캔버스 단위로 응답을 병렬 생성함. DiffusionGemma에서 초기화.
- **핵심 차별점**: 자기회귀가 아닌 이산 확산으로 응답 생성, thinking 모드에서 포워드 패스당 13.0 토큰(평균 1,872 tokens/sec)으로 높은 처리량. 기존 full-duplex 모델의 first-audio latency를 유지하면서 언어적 지능이 크게 향상.
- **실험 결과**: thinking 모드 포워드 패스당 13.0 토큰 생성. thinking 없이도 기존 full-duplex 모델과 동등한 first-audio latency에서 더 강한 언어 능력.
- **우리 연구 관련도**: ★☆☆ — 이산 확산 기반 생성은 흥미로우나, speech SSL이나 VQ 표현학습과의 직접적 연관성은 낮음.

**[DiffuPlex: Accelerating Full-Duplex Spoken Dialog Models via Rolling Masked Diffusion] (Heeseung Kim — 2026-10-08)** — arxiv preprint
- https://arxiv.org/abs/2610.12214
- **기존 문제**: 기존 full-duplex 음성 대화 모델은 매 80ms 프레임마다 모델을 깨워야 하므로 추론 비용이 높고, 실시간 배포에 제약이 있음.
- **기존 방법**: 프레임 단위 순차 생성 방식으로, 한 번의 포워드 패스에 한 프레임만 예측.
- **제안 방법**: 한 번의 백본 포워드 패스로 여러 미래 사용자/어시스턴트 프레임을 예측하는 rolling masked diffusion 방식. 확신도가 높은 초기 부분만 재생하고, 사용자 발화가 예측에서 벗어나면 미재생 부분만 수정.
- **핵심 차별점**: 기존 프레임별 추론을 다중 프레임 예측으로 대체하여 추론 속도를 크게 향상시키면서, 대화 품질 저하를 최소화.
- **실험 결과**: DiffuPlex-LISTEN 1.46×, DiffuPlex-SPEAK 1.59× 벽시계(wall-clock) 속도 향상. 인간 평가에서 LISTEN은 음성 자연스러움과 대화 품질 모두 유지, SPEAK은 대화 품질 유지하나 자연스러움 일부 감소.
- **우리 연구 관련도**: ★☆☆ — full-duplex 추론 효율화에 초점으로, speech SSL 및 VQ 표현학습과의 연관성은 낮음.

**[Reference-Guided Turn-Taking Style Transfer for Full-Duplex Spoken Language Models] (Yuxuan Chen, Yang Xiao, Jack Sun, Chak Sun, Brick Li, Sam — 2026-10-14)** — ICASSP 2027 submitted
- https://arxiv.org/abs/2610.20763
- **기존 문제**: Full-duplex 음성 모델은 학습된 가중치에 따라 고정된 대화 성격(turn-taking 스타일)을 가지며, 이를 유연하게 조절하기 어려움.
- **기존 방법**: 학습 데이터의 turn-taking 분포에 의존하거나, 별도의 학습/파인튜닝으로 대화 스타일을 변경.
- **제안 방법**: "Initiative vector"라는 단일 후기 레이어 잔여 스트림 방향을 모델 자체 대화에서 학습이나 어노테이션 없이 추출. 이 방향을 생성 시 스케일링하여 turn-taking 스타일을 조절하고, 짧은 참조 녹음으로 특정 화자의 turn-taking 스타일을 전이.
- **핵심 차별점**: 학습 없이(training-free) 모델 내부의 단일 방향 벡터만으로 turn-taking 스타일을 제어. 참조 녹음 기반 스타일 전이가 가능.
- **실험 결과**: Initiative vector가 최대 800ms 전에 turn-taking onset을 예측 가능. 스케일링으로 모델의 발화 비율을 6-12%에서 42-61%로 조절(비조절 시 21-30%). 다른 화자 참조 교체 시 93-98% 확률로 매칭 품질 저하 → 화자별 스타일 특이성 확인.
- **우리 연구 관련도**: ★☆☆ — activation steering 기반 행동 제어는 흥미로우나, speech SSL이나 VQ 표현학습과의 직접적 연관성은 낮음.

## 3. Speech Foundation Model

**[SepRQ: Self-Supervised Speech Mixture Representation Learning via Mask-Free, Multi-Scale Source Separation] (Séverin Baroudi, Hervé Bredin, Ricard Marxer — 2026-10-03)** — ICASSP 2027 submitted
- https://arxiv.org/abs/2610.04690
- **기존 문제**: 기존 speech SSL 모델은 마스크 예측(masked prediction) 기반으로, 혼합 음성(speech mixture)에서 개별 화자를 분리하는 능력이 제한적이며, 특히 3명 이상 화자 혼합에서 성능이 크게 저하됨.
- **기존 방법**: HuBERT, WavLM 등 마스크 예측 기반 SSL. WavLM은 노이즈 혼합 데이터로 사전학습하여 화자 분리를 부분적으로 학습하나, 구조적으로는 여전히 마스크 예측에 의존.
- **제안 방법**: SepRQ는 마스크 예측을 의사 음원 분리(pseudo-source-separation) 목적함수로 대체. 동결된 랜덤 프로젝션 코드북(frozen random-projection codebooks)을 사용하여 다중 스케일에서 음원 분리를 수행하는 SSL 프레임워크.
- **핵심 차별점**: 마스크 없이(mask-free) 음원 분리 목적함수로 SSL을 수행하여, 기존 SSL 대비 화자 분리 및 다중 화자 시나리오에서 근본적으로 다른 접근. 랜덤 프로젝션 코드북을 사용하여 학습 대상 코드북 없이도 효과적.
- **실험 결과**: SUPERB 벤치마크에서 Speaker Diarization과 Speech Separation에서 SOTA 달성, Base 및 Large 스케일 모두에서 WavLM 등 기존 SSL 모델 능가(85.68M 추론 파라미터). 타겟 화자 ASR, DIHARD 3 화자 분리, WSJ0-3Mix 3명 화자 분리에서도 강한 성능.
- **우리 연구 관련도**: ★★★ — prediction-free SSL의 직접적 사례. 마스크 예측 없이 음원 분리 목적함수를 사용하는 것은 prediction-free speech SSL 연구와 핵심적으로 관련. 랜덤 프로젝션 코드북은 VQ 기반 표현 연구와도 밀접.

**[ConvexLLM: Scaling Convex-Hull Speech Interfaces to General-Purpose Audio Intelligence] (Ming-Hao Hsu, Shujie Liu, Yuxuan Hu, Yuxiang Wang, Yingda Shen, Jinyu Li, Zhizheng Wu — 2026-10-16)** — arxiv preprint (Microsoft)
- https://arxiv.org/abs/2610.23539
- **기존 문제**: 오디오 표현을 디코더 LLM에 연결할 때, MLP나 Q-Former 같은 기존 인터페이스는 텍스트 능력 저하(catastrophic forgetting) 또는 음향 정보 손실 문제가 있음.
- **기존 방법**: MLP 프로젝터 또는 Q-Former로 음성 인코더 출력을 LLM 임베딩 공간에 매핑. 이 과정에서 LLM의 기존 텍스트 어휘 임베딩과의 정렬이 부족.
- **제안 방법**: C-Gate 인터페이스를 통해 오디오 표현을 동결된 텍스트 임베딩의 볼록 결합(convex combination)으로 표현. 이를 음성 인식, 음성 추론, 지시 따르기, 비음성 오디오 이해까지 확장한 범용 오디오 지능 모델.
- **핵심 차별점**: 오디오를 기존 텍스트 어휘 공간 내의 볼록 조합으로 제한함으로써, LLM의 텍스트 능력을 최대한 보존하면서 오디오 이해 추가. 0.3M시간 미만의 오디오로 적응.
- **실험 결과**: VoiceBench 11개 과제 종합 75.36 (비교 대상 오픈 가중치 모델 중 최고), MMAU Test-mini 62.50%. C-Gate가 spoken language 성능에서 MLP/Q-Former 대비 우위, 전사 및 비음성 과제는 다른 인터페이스가 유리.
- **우리 연구 관련도**: ★★☆ — 음성 표현을 텍스트 임베딩의 볼록 결합으로 표현하는 접근은 speech representation learning의 새로운 관점을 제시. VQ 기반 이산 표현 대신 연속 볼록 결합을 사용하는 점에서 VQ 연구와 대비적 관점 제공.

## 이번 주 트렌드 요약 (2026-10-19 ~ 2026-10-23)

1. **Full-duplex 음성 대화의 다각적 진화**: 이번 주 SpeechLLM 분야에서는 full-duplex 모델의 성숙이 두드러짐. 이산 확산 기반 생성(Diffuplex), 다중 프레임 예측을 통한 추론 가속(DiffuPlex), 그리고 학습 없는 turn-taking 스타일 제어(Reference-Guided Style Transfer)까지, 아키텍처·효율성·제어 가능성 세 축에서 동시에 발전이 진행 중.

2. **ASR 환각(hallucination) 연구 심화**: AudioSLM 논문이 speech-augmented LM의 환각 원인을 self-attention의 텍스트 편향으로 규명하고, 소규모 LM으로도 효과적 완화가 가능함을 보여줌. 대형 모델 의존에서 벗어나는 경량화 트렌드와 맞닿아 있음.

3. **Prediction-free SSL의 부상**: SepRQ가 마스크 예측을 완전히 대체하는 음원 분리 기반 SSL을 제안하여 SUPERB SOTA를 달성. 기존 HuBERT/WavLM의 마스크 예측 패러다임에 대한 대안이 구체적 성과를 내기 시작함. 이는 prediction-free speech SSL 연구 방향의 타당성을 뒷받침.

4. **인코더 의존성 재검토**: Teaching LLMs to Hear는 인코더를 제거하고도 화자 속성 인식에서 인코더 기반 모델을 능가하며, ConvexLLM은 텍스트 어휘의 볼록 결합으로 오디오를 표현. 모두 기존 "인코더 + LLM" 파이프라인의 정보 병목에 문제를 제기하는 연구.

5. **Contextual ASR의 효율화**: VISH-ASR이 CTC 사후확률만으로 학습 없이 핫워드를 필터링하여, 학습 기반 검색 대비 비슷하거나 더 나은 성능을 달성. Training-free 접근법의 경쟁력이 더욱 강화되는 추세.
