## 1. ASR

### **Pushing the Limits of End-to-End Diarization (Samuel Broughton, Lahiru Samarakoon, 2025-09)** — Interspeech 2025 accepted
- arxiv URL: https://arxiv.org/abs/2509.14737
- 기존 문제: End-to-end 화자 분리(EEND) 모델이 다양한 벤치마크에서 여전히 클러스터링 기반 모듈형 시스템에 비해 성능이 뒤처지며, EEND 아키텍처의 학습 용량이 충분히 탐색되지 않았음.
- 기존 방법: EEND-EDA, EEND-TA 등 end-to-end 모델은 주로 2~4명 화자 시뮬레이션 데이터로 사전학습. 클러스터링 기반 파이프라인(VAD → 임베딩 추출 → 클러스터링)이 여전히 주류.
- 제안 방법: EEND-TA(Transformer Attractor) 모델의 사전학습 규모를 8명 화자 시뮬레이션 혼합까지 확장하여 80,000시간 이상의 데이터로 학습. 23차원 log-Mel filterbank, 6층 Conformer, 4-head attention 구조.
- 핵심 차별점: 단일 비자기회귀 모델로 데이터셋별 파인튜닝 없이 9개 테스트셋 중 6개에서 SOTA 달성. 기존 EEND 아키텍처의 미탐색 학습 용량을 대규모 사전학습으로 극복.
- 실험 결과: DIHARD III DER 14.49%, AliMeeting-far, AliMeeting-near, AMI-Mix, AMI-SDM, MagicData RAMC에서 모든 end-to-end 모델 대비 최고 성능. 추론 속도도 효율적으로 유지.
- 우리 연구 관련도: ★★☆ (대규모 사전학습 전략과 Conformer 기반 temporal representation이 speech SSL 모델의 화자 표현 학습에 참고 가능. 다만 VQ 기반 방법론과 직접 관련은 제한적)

### **Phonemes vs. Projectors: An Investigation of Speech-Language Interfaces for LLM-based ASR (Ziwei Li, Lukuang Dong, Saierdaer Yusuyin, Xianyu Zhao, Zhijian Ou, 2026-04)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2604.09332
- 기존 문제: LLM 기반 ASR에서 사전학습된 음성 인코더와 LLM을 연결하는 인터페이스(projector vs. phoneme) 선택이 성능과 데이터 효율성에 미치는 영향이 체계적으로 비교되지 않았음.
- 기존 방법: (1) 학습 가능한 projector로 인코더 특징을 LLM 임베딩 공간에 매핑하는 방식, (2) 이산 음소(phoneme) 시퀀스를 LLM에 직접 노출하는 방식. 두 접근법이 각각 독립적으로 연구됨.
- 제안 방법: 동일한 인코더-LLM 백본에서 projector 기반과 phoneme 기반 인터페이스를 고자원(영어)·저자원(타타르어) 환경에서 공정 비교. BPE-phoneme 인터페이스를 새로 제안하여 빈번한 로컬 음소 패턴을 그룹화하면서 명시적 단어 경계를 유지.
- 핵심 차별점: 저자원 환경에서 음소 기반 인터페이스가 projector 대비 데이터 효율성에서 압도적 우위를 실증. BPE-phoneme은 두 방식의 장점을 결합하여 효율적 시퀀스 길이와 언어학적 정보를 동시 확보.
- 실험 결과: 저자원(20h 데이터) 타타르어에서 phoneme 인터페이스가 projector 대비 test WER을 33.58% → 17.44%로 거의 절반 감소. 고자원 영어에서는 projector가 경쟁력 유지.
- 우리 연구 관련도: ★★★ (음성 표현의 이산화(phoneme) vs. 연속(projector) 인터페이스 비교는 VQ-based speech tokenizer 설계에 직접적 시사점 제공. 저자원 환경에서의 이산 표현 우위는 prediction-free speech SSL의 이산 토큰 학습 방향과 밀접하게 관련)

### **Learnable Pulse Accumulation for On-Device Speech Recognition: How Much Attention Do You Need? (Yakov Pyotr Shkolnikov, 2026-03)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2603.16922
- 기존 문제: Self-attention의 O(n²) 복잡도가 시퀀스 길이에 따라 급격히 증가하여 엣지 디바이스에서의 트랜스포머 기반 음성 모델 배포를 제한. 기존 효율적 attention 대안들은 음성 도메인 특화 설계가 부족.
- 기존 방법: 표준 self-attention, linear attention, sparse attention 등 범용 효율적 attention 메커니즘. wav2vec 2.0 등 SSL 모델의 전체 attention 레이어 유지.
- 제안 방법: Learnable Pulse Accumulator(LPA) — key-query dot product를 학습 가능한 게이팅 함수(content-dependent rectangular pulses, periodic windows, position-dependent basis functions)로 대체하는 O(n) 모듈. wav2vec2-base의 12개 레이어 중 8개를 LPA로 교체.
- 핵심 차별점: 음성 신호의 시간적 구조를 활용한 도메인 특화 O(n) attention 대안. 자기주의 레이어의 대부분을 대체하면서도 인식 품질을 유지하는 계층별 교체 전략 제시. Apple M4 Pro 최적화 MLX 추론 경로 공개.
- 실험 결과: LibriSpeech test-clean WER 10.61% (baseline 3.37% 대비 +7.24pp 상승이나), 120초 오디오 기준 3.27배 속도 향상. 정확도-효율 트레이드오프에서 실용적 엣지 배포 가능성 실증.
- 우리 연구 관련도: ★★☆ (SSL 모델(wav2vec 2.0)의 attention 메커니즘을 효율적으로 대체하는 연구로, speech SSL 모델의 temporal representation 학습 메커니즘 이해에 참고 가치. 다만 VQ/contrastive learning과 직접 관련은 낮음)

## 2. SpeechLLM

### **VITA-Audio: Fast Interleaved Cross-Modal Token Generation for Efficient Large Speech-Language Model (Zuwei Long, Yunhang Shen, Chaoyou Fu, Heting Gao et al., 2025-05)** — NeurIPS 2025 accepted
- arxiv URL: https://arxiv.org/abs/2505.03739
- 기존 문제: 기존 end-to-end 음성 대규모 모델은 오디오 토큰 생성 시 단일 forward pass당 하나의 토큰만 생성하여 추론 지연이 크고, 스트리밍 시나리오에서 첫 오디오 출력까지의 대기 시간이 길었음.
- 기존 방법: 자기회귀 단일 토큰 생성 방식의 SpeechLLM(SpeechGPT, AudioPaLM 등). 텍스트 토큰 생성 완료 후 오디오 토큰을 순차 생성하는 직렬 방식.
- 제안 방법: Multiple Cross-modal Token Prediction(MCTP) 모듈 — 단일 forward pass에서 복수의 오디오 토큰을 동시 생성하는 경량 모듈. 텍스트와 오디오 토큰을 인터리브 방식으로 교차 생성. 4단계 점진적 학습 전략으로 모델 가속과 음성 품질 균형.
- 핵심 차별점: 최초의 forward pass에서 오디오 생성이 가능한 end-to-end 모델. 첫 오디오 토큰 청크 생성 지연을 236ms → 53ms로 단축. 오픈소스 데이터(200K시간)만으로 학습하여 재현 가능.
- 실험 결과: 7B 스케일에서 추론 속도 3~5배 향상. 동일 규모 오픈소스 모델 대비 ASR, TTS, SQA(Spoken Question Answering) 벤치마크에서 최고 또는 경쟁력 있는 성능 달성.
- 우리 연구 관련도: ★★☆ (다중 토큰 동시 예측의 cross-modal 생성 전략은 speech token 설계와 관련. 인터리브 텍스트-오디오 생성은 VQ 기반 이산 표현의 효율적 디코딩 연구에 참고 가능)

### **DuplexCascade: Full-Duplex Speech-to-Speech Dialogue with VAD-Free Cascaded ASR-LLM-TTS Pipeline and Micro-Turn Optimization (Jianing Yang, Yusuke Fujita, Yui Sudo, 2026-03)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2603.09180
- 기존 문제: 기존 음성 대화 시스템은 VAD(Voice Activity Detection) 기반 턴테이킹에 의존하여 자연스러운 전이중(full-duplex) 대화가 어려움. End-to-end SpeechLLM은 텍스트 LLM 대비 대화 지능이 떨어지는 한계.
- 기존 방법: (1) VAD 기반 반이중 캐스케이드 파이프라인(ASR→LLM→TTS), (2) end-to-end SpeechLLM(Moshi, dGSLM 등)으로 전이중 시도하나 대화 품질 저하.
- 제안 방법: VAD 없는 캐스케이드 스트리밍 파이프라인. 기존 발화 단위(long turn)를 청크 단위 마이크로턴(micro-turn)으로 변환하여 양방향 실시간 교환. 대화 특수 제어 토큰을 도입하여 LLM의 스트리밍 제약 하 턴테이킹과 응답 타이밍을 조율.
- 핵심 차별점: 텍스트 LLM의 대화 지능을 보존하면서 VAD 없이 전이중 대화 구현. 마이크로턴 최적화로 캐스케이드 파이프라인의 지연 문제를 구조적으로 해결. 기존 end-to-end 모델의 대화 품질 한계를 캐스케이드로 극복.
- 실험 결과: Full-DuplexBench와 VoiceBench에서 오픈소스 speech-to-speech 대화 시스템 중 SOTA 전이중 턴테이킹 성능 및 강한 대화 지능 달성.
- 우리 연구 관련도: ★☆☆ (캐스케이드 파이프라인 최적화로 speech SSL/VQ 표현 연구와 직접 관련은 낮음. 다만 마이크로턴의 청크 단위 처리는 temporal 표현의 적정 granularity 설계에 간접 시사점)

### **JASTIN: Aligning LLMs for Zero-Shot Audio and Speech Evaluation via Natural Language Instructions (Leying Zhang, Bowen Shi, Haibin Wu, Bach Viet Do, Yanmin Qian, 2026-05)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2605.04505
- 기존 문제: 음성/오디오 품질 평가가 MOS(Mean Opinion Score) 등 주관적 평가에 의존하여 비용이 높고 확장이 어려움. 기존 자동 평가 메트릭은 태스크별로 분리되어 범용 제로샷 평가가 불가능.
- 기존 방법: 태스크별 전용 메트릭(PESQ, STOI, UTMOS 등), 제한된 데이터로 학습된 평가 모델, LLM을 활용한 텍스트 기반 평가.
- 제안 방법: Frozen 고성능 오디오 인코더와 파인튜닝된 LLM을 학습 가능한 오디오 어댑터로 연결. 오디오 평가를 자기지시 추론(self-instructed reasoning) 과제로 정식화. Multi-Source, Multi-Task, Multi-Calibration, Multi-Description 데이터 구성 파이프라인으로 제로샷 일반화 보장.
- 핵심 차별점: 자연어 지시를 통한 범용 오디오/음성 평가 프레임워크. 태스크별 전용 학습 없이 다양한 평가 기준에 제로샷 적용 가능. 인간 주관 평가와의 높은 상관관계.
- 실험 결과: 인간 주관 평점과의 Pearson 및 Spearman 상관계수에서 SOTA 달성. 다양한 오디오/음성 평가 태스크에서 범용적 제로샷 성능 입증.
- 우리 연구 관련도: ★★☆ (LLM 기반 음성 이해·평가 프레임워크의 오디오 인코더-LLM 연결 설계는 speech representation의 의미적 풍부함을 측정하는 간접 도구로 활용 가능. Multi-calibration 학습은 VQ 토큰의 품질 평가 메트릭 개발에 참고 가치)

## 3. Speech Foundation Model

### **UniWav: Towards Unified Pre-training for Speech Representation Learning and Generation (Alexander H. Liu, Sang-gil Lee, Huck Yang, Yuan Gong, Frank Wang, James R. Glass, Rafael Valle — NVIDIA, 2025-03)** — ICLR 2025 accepted
- arxiv URL: https://arxiv.org/abs/2503.00733
- 기존 문제: 음성 사전학습이 판별적(discriminative) 과제와 생성적(generative) 과제를 위해 각각 별도의 파운데이션 모델을 요구. 표현 학습(HuBERT, wav2vec 등)과 생성(codec, flow matching 등)이 분리되어 통합 활용이 어려움.
- 기존 방법: 판별적: self-distillation 기반 SSL(data2vec, DINO). 생성적: neural codec(EnCodec), flow matching 기반 TTS. 각각 독립적 사전학습.
- 제안 방법: 인코더-디코더 통합 프레임워크. 표현 인코더는 self-distillation과 생성적 목적함수로 동시 학습. Flow Matching 디코더가 학습된 표현을 조건으로 오디오 생성. 단일 사전학습으로 판별·생성 양쪽 태스크에 적용.
- 핵심 차별점: 판별적 표현 학습과 생성적 디코딩을 단일 사전학습 프레임워크로 최초 통합. 적절한 설계 선택을 통해 두 목적함수 간 성능 트레이드오프 없이 양쪽 과제에서 경쟁력 있는 결과 달성.
- 실험 결과: LibriSpeech test-other ASR WER: 100h labeled 4.8%, 960h labeled 4.0% (data2vec 2.0의 4.3%/3.5% 대비 근접). TTS와 speech tokenization에서도 태스크 전용 모델과 동등한 성능 달성.
- 우리 연구 관련도: ★★★ (self-distillation + flow matching의 통합 사전학습은 prediction-free speech SSL과 직접적 관련. 표현 학습과 생성을 동시에 달성하는 프레임워크 설계는 VQ-based representation의 양방향 활용 가능성을 시사. NVIDIA 연구팀의 최신 방향성 파악에 핵심 논문)

### **Universal Speech Token Learning via Low-Bitrate Neural Codec and Pretrained Representations (Xue Jiang, Xiulian Peng, Yuan Zhang, Yan Lu — Microsoft Research Asia, 2025-03)** — IEEE/ACM TASLP
- arxiv URL: https://arxiv.org/abs/2503.12115
- 기존 문제: 현재 SpeechLLM은 의미 토큰(semantic tokens)과 음향 토큰(acoustic tokens)을 분리 사용하나, 의미 토큰은 부언어적(paralinguistic) 속성을 버리고, 음향 토큰 기반 합성은 도메인 갭이 있을 때 견고성이 떨어짐.
- 기존 방법: HuBERT/vq-wav2vec 기반 semantic token + EnCodec/SoundStream 기반 acoustic token의 이원화 구조. Prompt 기반 음향 합성으로 화자 특성 복원.
- 제안 방법: UniCodec — 언어적·부언어적 정보를 모두 포함하는 compact한 의미 분리(semantically-disentangled) 통합 토큰. 저비트레이트 압축-생성 프레임워크로 글로벌(화자, 감정)·로컬(음소, 운율) 스케일의 핵심 속성을 이산 토큰에 압축. Self-supervised representation에서 knowledge distillation.
- 핵심 차별점: 단일 통합 토큰으로 언어+부언어 정보를 모두 캡슐화하여 semantic-acoustic 이원 구조 불필요. 500bps의 극저비트레이트에서도 높은 음성 충실도와 부언어적 속성 보존. 다국어 데이터셋에서 범용성 검증.
- 실험 결과: ASR 보존율 99.1%, 화자 동일성 유지. TTS, 음성 변환, 음성-음성 번역에서 자연스러움과 화자 유사도 면에서 강한 성능. 감정 인식 등 음성 이해 과제에서도 표현 능력 입증.
- 우리 연구 관련도: ★★★ (VQ 기반 이산 음성 표현의 핵심 연구. Semantic-acoustic disentanglement 설계는 우리의 VQ-based representation 연구와 직접적으로 관련. 저비트레이트 통합 토큰 설계와 knowledge distillation 전략은 prediction-free speech SSL과 상호 보완적 관점 제공)

### **A Study of Data Selection Strategies for Pre-training Self-Supervised Speech Models (Ryan Whetten, Titouan Parcollet, Marco Dinarelli, Yannick Estève, 2026-01)** — ICASSP 2026 accepted
- arxiv URL: https://arxiv.org/abs/2601.20896
- 기존 문제: SSL 음성 모델의 사전학습 데이터 선택 전략이 하류 ASR 성능에 미치는 영향이 체계적으로 연구되지 않았음. 대규모 비정제 데이터를 무작위로 사용하는 것이 일반적 관행.
- 기존 방법: 무작위 샘플링, 데이터 양 확대, 데이터 증강(data augmentation) 기반 사전학습.
- 제안 방법: 음향 다양성, 화자 다양성, 언어적 다양성 등 다양한 기준으로 사전학습 데이터 부분집합을 큐레이션하여 ASR 성능에 미치는 영향을 체계적으로 비교. 데이터 길이(utterance length) 기반 선택 전략을 포함한 다면적 분석.
- 핵심 차별점: 음향·화자·언어적 다양성 최적화가 무작위 샘플링 대비 명확한 개선을 가져오지 않는다는 반직관적 발견. 긴 발화를 우선 선택하는 단순 전략이 절반의 데이터로 최고 ASR 성능 달성. 사전학습 시간 24% 단축.
- 실험 결과: 최장 발화 우선 선택 시 원본 데이터셋의 50%만으로 전체 데이터 대비 우수한 ASR 결과 달성. 다양성 기반 큐레이션은 무작위 샘플링과 유의미한 차이 없음. 데이터 증강으로도 데이터 양 부족을 완전히 보상하지 못함.
- 우리 연구 관련도: ★★★ (SSL 사전학습의 데이터 전략에 대한 근본적 연구. 발화 길이가 temporal contrastive learning의 효과에 미치는 영향에 직접적 시사점. 다양성보다 시간적 맥락 길이가 중요하다는 발견은 우리의 temporal contrastive learning 프레임워크 설계에 핵심 참고 자료)

## 이번 주 트렌드 요약 (2026-05-05 ~ 2026-05-08)

1. **LLM-ASR 인터페이스 다양화**: 이번 주 다수의 논문이 LLM과 음성 인코더를 연결하는 다양한 인터페이스(projector, phoneme, BPE-phoneme)를 탐구. 저자원 환경에서 이산 언어학적 표현(phoneme)이 연속 projector보다 데이터 효율적이라는 실증적 증거가 축적되고 있음.

2. **통합 사전학습 프레임워크의 부상**: UniWav(ICLR 2025)과 UniCodec(Microsoft)이 보여주듯, 판별적 표현 학습과 생성을 단일 모델에서 통합하는 방향이 가속화. Semantic-acoustic 이원 구조를 넘어 통합 토큰 설계가 새로운 트렌드.

3. **SpeechLLM 효율성 경쟁**: VITA-Audio의 다중 토큰 예측(NeurIPS 2025), DuplexCascade의 마이크로턴 최적화 등 추론 속도와 지연 시간 단축이 핵심 경쟁 축. 첫 토큰 지연을 50ms대로 줄이는 수준에 도달.

4. **SSL 사전학습 데이터 효율성 재조명**: 데이터 다양성보다 발화 길이가 SSL 성능에 더 중요하다는 발견(ICASSP 2026)은 사전학습 전략의 패러다임 전환 가능성을 시사. End-to-end diarization에서도 대규모 시뮬레이션 데이터의 학습 용량 확장이 핵심 성공 요인으로 확인.

5. **LLM 기반 음성 평가 프레임워크**: JASTIN 등 자연어 지시 기반 제로샷 음성 평가가 등장하며, 기존 MOS 중심의 주관적 평가를 자동화·확장하려는 시도가 본격화.
