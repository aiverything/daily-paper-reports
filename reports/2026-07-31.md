**[Mega-ASR: Towards In-the-wild² Speech Recognition via Scaling up Real-world Acoustic Simulation] (Zhifei Xie, Kaiyu Pang, Haobin Zhang, Deheng Ye, Xiaobin Hu, Shuicheng Yan, Chunyan Miao, 2026-05)** — arxiv preprint

- https://arxiv.org/abs/2605.19833
- **기존 문제**: 현재 ASR 모델들은 실세계의 심각한 복합 음향 왜곡(잡음, 반향, 혼합 등이 동시에 발생하는 상황) 하에서 환각(hallucination)을 생성하며, 단일 음향 현상에 대한 학습만으로는 복합 왜곡에 대한 강건성을 확보하기 어려웠다.
- **기존 방법**: 기존 강건 ASR 연구는 단일 잡음 추가, 단일 반향 시뮬레이션 등 개별 음향 현상에 대한 데이터 증강에 의존하였으며, 복합 음향 시나리오를 체계적으로 생성하는 방법이 부재하였다.
- **제안 방법**: 7가지 고전적 음향 현상과 54가지 물리적으로 타당한 복합 시나리오를 포함하는 Voices-in-the-Wild-2M 데이터셋(260만 샘플)을 구축하고, 확장 가능한 복합 데이터 생성과 점진적 음향-의미 최적화(progressive acoustic-to-semantic optimization)를 결합한 학습 전략을 제안한다.
- **핵심 차별점**: 단일 현상이 아닌 복합 음향 왜곡을 체계적으로 시뮬레이션하는 최초의 대규모 벤치마크이며, 점진적 최적화를 통해 모델이 음향 신호에서 의미 정보를 단계적으로 추출하도록 학습시킨다.
- **실험 결과**: 강건 ASR 벤치마크에서 강력한 베이스라인 대비 30% 이상의 상대적 WER 감소를 달성하였다.
- **우리 연구 관련도**: ★★☆ — 복합 음향 환경에서의 음성 표현 강건성 연구로, speech SSL 사전학습 시 음향 왜곡에 대한 불변 표현(invariant representation) 학습 전략에 참고가 될 수 있다.

**[OWSM v4: Improving Open Whisper-Style Speech Models via Data Scaling and Cleaning] (Yifan Peng, Muhammad Shakeel, Yui Sudo, William Chen, Jinchuan Tian, Chyi-Jiunn Lin, Shinji Watanabe — CMU / Honda Research Institute, 2025-06)** — arxiv preprint

- https://arxiv.org/abs/2506.00338
- **기존 문제**: Whisper와 같은 대규모 음성 모델의 오픈소스 복제(replication) 시도인 OWSM은 학습 데이터 규모와 품질이 제한적이어서, 원본 Whisper 대비 다국어 성능 격차가 존재하였다.
- **기존 방법**: 이전 OWSM 버전(v1~v3)은 공개된 음성 데이터셋을 결합하여 사용하였으나, 대규모 웹 크롤링 데이터를 체계적으로 정제(cleaning)하여 활용하는 파이프라인이 부재하였다.
- **제안 방법**: 대규모 웹 크롤링 데이터셋 YODAS를 통합하고, 확장 가능한 데이터 정제 파이프라인을 적용하여 75개 언어에 걸친 166,000시간 규모의 고품질 음성 데이터를 확보. 이를 기반으로 OWSM v4 모델을 학습하였다.
- **핵심 차별점**: 대규모 웹 데이터의 체계적 정제와 통합이 핵심이며, 데이터 규모 확장(data scaling)과 품질 관리(data cleaning)의 균형을 통해 오픈소스 다국어 ASR의 성능 한계를 극복한다. 모든 데이터, 모델, 스크립트가 ESPnet을 통해 공개된다.
- **실험 결과**: 다국어 ASR 벤치마크에서 이전 OWSM 버전 대비 유의미한 성능 향상을 달성하였으며, 75개 언어에서 일관된 개선을 보였다.
- **우리 연구 관련도**: ★★☆ — 대규모 다국어 데이터 정제 파이프라인은 speech SSL 사전학습용 데이터 구축에 직접적으로 참고할 수 있으며, 웹 크롤링 데이터의 품질이 모델 성능에 미치는 영향 분석이 유용하다.

**[Leveraging Audio-Visual Data to Reduce the Multilingual Gap in Self-Supervised Speech Models] (Maria Andrea Cruz Blandon, Zakaria Aldeneh, Jie Chi, Maureen de Seyssel — Tampere University / Apple, 2025-09)** — ICASSP 2026 accepted

- https://arxiv.org/abs/2509.17523
- **기존 문제**: 자기지도 음성 모델은 다국어 학습 시 단일언어 모델 대비 성능 격차(multilingual gap)가 발생하였으며, 텍스트 없이 음성만으로 이 격차를 줄이는 방법이 제한적이었다.
- **기존 방법**: 기존 다국어 SSL 모델은 더 많은 음성 데이터를 추가하거나 언어별 미세조정으로 격차를 해소하려 하였으나, 레이블 없는 환경에서의 근본적 해결책이 부족하였다.
- **제안 방법**: 시각적 그라운딩(visual grounding)을 활용하여 다국어 SSL 모델의 성능 격차를 줄이는 방법을 제안. 음성-이미지 쌍 데이터를 통해 언어에 불변적인(language-invariant) 음성 표현을 학습시킨다.
- **핵심 차별점**: 텍스트 레이블 없이 시각 정보만으로 다국어 음성 표현의 품질 격차를 대폭 줄일 수 있음을 처음으로 체계적으로 입증한 연구로, 시각적 그라운딩이 언어 간 음성 표현의 정렬(alignment)을 촉진한다.
- **실험 결과**: 제로샷 음소 판별(zero-shot phonetic discrimination) 태스크에서 다국어 성능 격차를 오디오 전용 31.5%에서 8.04%로 감소시켰다.
- **우리 연구 관련도**: ★★★ — 시각적 그라운딩을 통한 언어 불변 음성 표현 학습은 prediction-free SSL의 대안적 감독 신호 활용과 직접적으로 관련되며, contrastive learning 기반 다모달 정렬이 temporal contrastive learning 연구에 방법론적 시사점을 제공한다.

**[Speech World Model: Causal State-Action Planning with Explicit Reasoning for Speech] (2025-12)** — ICLR 2026 accepted

- https://arxiv.org/abs/2512.05933
- **기존 문제**: 기존 음성 이해 시스템은 음성을 블랙박스로 처리하여, 음성 신호에 내재된 상태(화자 의도, 감정, 맥락)와 행동(발화 행위) 간의 인과적 관계를 명시적으로 추론하지 못하였다.
- **기존 방법**: 캐스케이드 방식(ASR → NLU)이나 엔드투엔드 방식 모두 음성 이해를 단일 함수 매핑으로 처리하여, 중간 추론 과정이 불투명하고 반사실적(counterfactual) 분석이 불가능하였다.
- **제안 방법**: 월드 모델 관점에서 음성 이해를 모듈러 방식으로 분해하여, 인과 그래프(causal graph)를 통해 소통하는 4개 모듈로 구성. 각 모듈이 명시적 추론을 수행하며, 반사실적 개입(counterfactual intervention)과 해석 가능성을 지원한다.
- **핵심 차별점**: 음성 이해에 최초로 그래프 기반 모듈러 월드 모델을 적용한 연구로, 블랙박스 접근과 달리 각 의사결정 과정이 투명하며, 부분적 감독(partial supervision)에서도 작동한다.
- **실험 결과**: 음성 이해 벤치마크에서 기존 엔드투엔드 및 캐스케이드 모델과 비교하여 경쟁력 있는 성능을 달성하면서도 해석 가능한 중간 추론 결과를 생성하였다.
- **우리 연구 관련도**: ★★☆ — 음성 신호의 인과적 구조 모델링은 speech representation이 인코딩하는 다양한 정보(내용, 화자, 감정)의 분리와 해석에 새로운 프레임워크를 제시하며, 모듈러 접근은 표현 학습 목적 함수 설계에 참고가 될 수 있다.

**[Freeze-Omni: A Smart and Low Latency Speech-to-Speech Dialogue Model with Frozen LLM] (Xiong Wang, Yangze Li, Chaoyou Fu et al., 2024-11)** — ICML 2025 accepted

- https://arxiv.org/abs/2411.00774
- **기존 문제**: 음성-텍스트 멀티모달 LLM에서 음성 입출력 모달리티를 추가 학습할 때, LLM 백본의 텍스트 능력이 저하되는 문제(catastrophic forgetting)가 빈번하게 발생하였다.
- **기존 방법**: 기존 SpeechLLM(VITA, Mini-Omni 등)은 LLM 전체를 음성 데이터로 미세조정하여, 텍스트 모달리티의 지능이 음성 학습 과정에서 훼손되는 트레이드오프가 존재하였다.
- **제안 방법**: LLM 파라미터를 완전히 동결(frozen)한 상태에서 스트리밍 음성 입력 인코더와 스트리밍 출력 디코더를 연결하는 아키텍처를 제안. 음성 모달리티의 지능이 텍스트 LLM의 능력을 그대로 상속받으면서도 낮은 엔드투엔드 지연 시간을 달성한다.
- **핵심 차별점**: LLM 동결 전략이 핵심으로, 텍스트 지능 보존과 음성 대화 능력을 동시에 달성하며, 별도의 대규모 음성 대화 데이터 없이도 고품질 음성 대화가 가능하다.
- **실험 결과**: 음성-텍스트 QA 및 대화 벤치마크에서 LLM 백본의 텍스트 성능을 100% 유지하면서 음성 대화 품질에서 기존 미세조정 모델과 동등한 성능을 달성하였다.
- **우리 연구 관련도**: ★☆☆ — 동결 LLM 아키텍처는 speech representation의 LLM 연동 방식에 대한 참고이나, SSL/VQ 기반 표현 학습 연구와의 직접적 관련성은 제한적이다.

**[PersonaPlex: Voice and Role Control for Full Duplex Conversational Speech Models] (NVIDIA ADLR, 2026-02)** — arxiv preprint

- https://arxiv.org/abs/2602.06053
- **기존 문제**: 기존 풀듀플렉스 음성 대화 모델은 고정된 음성과 역할로만 응답하여, 다양한 페르소나(성격, 톤, 역할)와 음성 특성을 동적으로 제어하는 것이 불가능하였다.
- **기존 방법**: Moshi 등 기존 풀듀플렉스 모델은 단일 화자 정체성으로 학습되어, 배포 시 음성이나 역할을 변경하려면 재학습이 필요하였다.
- **제안 방법**: Moshi 아키텍처 기반으로 텍스트 기반 역할 프롬프트(role prompt)와 오디오 기반 음성 조건화(voice conditioning)를 결합한 PersonaPlex를 제안. 대규모 합성 대화 데이터로 학습하여 실시간 풀듀플렉스 대화에서 페르소나 제어를 가능하게 한다.
- **핵심 차별점**: 텍스트 프롬프트로 역할(어시스턴트, 튜터, 코치 등)을 지정하고 참조 오디오로 음성 특성을 제어하는 이중 조건화가 핵심이며, 풀듀플렉스 환경에서의 페르소나 제어를 최초로 구현하였다.
- **실험 결과**: 역할 준수도(role adherence), 화자 유사도(speaker similarity), 지연 시간(latency), 자연스러움(naturalness) 모든 측면에서 기존 SOTA 풀듀플렉스 모델을 능가하였다.
- **우리 연구 관련도**: ★★☆ — 음성 조건화를 위한 화자 표현 추출 및 활용 방식이 speech representation의 화자 정보 인코딩 연구와 관련되며, 대규모 합성 대화 데이터 생성 전략이 음성 표현 학습용 데이터 구축에 참고가 될 수 있다.

**[InsideSSL: Understanding Self-Supervised Speech Models using a Model-Centric Perspective] (Samir Sadok, Xavier Alameda-Pineda, 2026-07)** — Interspeech 2026 accepted

- https://arxiv.org/abs/2607.06392
- **기존 문제**: Wav2Vec2, HuBERT, WavLM 등 자기지도 음성 모델들의 내부 표현이 레이어별로 어떤 정보를 인코딩하는지에 대한 이해가 부족하였으며, 기존 분석은 특정 다운스트림 태스크에 의존하여 모델 자체의 본질적 특성을 반영하지 못하였다.
- **기존 방법**: 기존 SSL 모델 분석은 주로 프로빙(probing) 실험을 통해 특정 태스크(ASR, 화자 인식 등)에서의 레이어별 성능을 측정하는 방식으로, 태스크 독립적인(task-agnostic) 분석 프레임워크가 부재하였다.
- **제안 방법**: 태스크 비의존적 프레임워크로 SSL 모델을 3가지 본질적 관점에서 분석: (1) 압축(compression) — 레이어별 엔트로피, (2) 기하학(geometry) — 표현 공간의 곡률(curvature), (3) 강건성(robustness) — 섭동에 대한 저항성. 또한 교차 레이어 생성적 호환성 행렬(Generative Compatibility Matrix, GCM)을 도입하여 레이어 간 기능적 전이 가능성을 평가한다.
- **핵심 차별점**: 다운스트림 태스크에 의존하지 않는 모델 중심(model-centric) 분석 프레임워크가 핵심이며, GCM을 통해 안정적인 음소 코어(phonetic core), 화자 정체성의 변동성(identity volatility), 깊은 레이어의 의미적 가지치기(semantic pruning) 등 새로운 현상을 발견하였다.
- **실험 결과**: Wav2Vec2, HuBERT, WavLM에 대한 비교 분석에서 모델별로 압축-기하학-강건성 프로파일이 뚜렷이 다름을 확인하였으며, 중간 레이어에서 음소 표현이 가장 안정적이고 깊은 레이어에서 화자 정보가 급격히 변동함을 규명하였다.
- **우리 연구 관련도**: ★★★ — SSL 모델의 레이어별 표현 특성을 태스크 비의존적으로 분석하는 프레임워크는 prediction-free SSL 연구에서 표현 품질 평가 방법론으로 직접 활용 가능하며, 엔트로피-곡률-강건성 관점은 VQ 기반 표현의 정보 이론적 분석에 핵심적 참고가 된다.

**[SLAP: Scalable Language-Audio Pretraining with Variable-Duration Audio and Multi-Objective Training] (Xinhao Mei, Gael Le Lan, Haohe Liu, Zhaoheng Ni, Varun Nagaraja, Yang Liu, Yangyang Shi, Vikas Chandra — Meta, 2026-01)** — ICASSP 2026 accepted

- https://arxiv.org/abs/2601.12594
- **기존 문제**: CLAP(Contrastive Language-Audio Pretraining) 모델은 고정 길이(fixed-duration) 오디오만 처리할 수 있었으며, 소규모 데이터셋에 제한되어 실세계의 가변 길이 오디오를 다루지 못하였다.
- **기존 방법**: 기존 CLAP 모델은 오디오를 고정 길이(예: 10초)로 자르거나 패딩하여 처리하였으며, 학습 데이터 규모가 수십만 샘플 수준에 머물러 대규모 확장이 어려웠다.
- **제안 방법**: 가변 길이 오디오를 직접 처리할 수 있는 다목적 학습(multi-objective training)을 도입한 SLAP을 제안. 대규모 실세계 오디오 데이터로 언어-오디오 사전학습을 확장하여 기존 CLAP의 한계를 극복한다.
- **핵심 차별점**: 가변 길이 오디오 지원과 다목적 학습의 결합이 핵심으로, 실세계 오디오의 다양한 길이 분포를 그대로 활용하여 더 강건한 오디오-언어 정렬을 학습한다.
- **실험 결과**: 기존 CLAP 모델 대비 오디오 검색, 분류 등 다운스트림 태스크에서 유의미한 성능 향상을 달성하였으며, 가변 길이 오디오에서 특히 큰 개선을 보였다.
- **우리 연구 관련도**: ★★☆ — 대규모 contrastive pretraining의 확장 전략은 temporal contrastive learning 연구에 방법론적 참고가 되며, 가변 길이 오디오 처리는 음성 표현 학습에서의 시간적 구조 모델링과 관련된다.

**[UniAudio-Token: Empowering Semantic Speech Tokenizers with General Audio Perception] (2026-05)** — arxiv preprint

- https://arxiv.org/abs/2605.31521
- **기존 문제**: 기존 의미적 음성 토크나이저(semantic speech tokenizer)는 언어적 내용(linguistic content)에 특화되어, 비언어 오디오(환경음, 음악 등)에 대한 인식 능력이 부족하였으며, 범용 오디오 이해와 음성 능력을 동시에 갖추기 어려웠다.
- **기존 방법**: 기존 토크나이저는 음성 전용(speech-only) 학습으로 설계되어, 범용 오디오 태스크에 적용 시 성능이 크게 저하되었으며, 별도의 오디오 인코더가 필요하였다.
- **제안 방법**: 의미-음향 원시요소(Semantic-Acoustic Primitives, SAP)를 통한 구조적 감독을 도입하여 오디오를 언어적 내용, 음성 속성, 청각-장면 원시요소(auditory-scene primitives)로 분해. 또한 의미-음향 균형(Semantic-Acoustic Equilibrium, SAE)과 내용 인식 게이팅(content-aware gating)을 적용하여 음성과 범용 오디오 능력을 동시에 유지한다.
- **핵심 차별점**: 단일 코드북(single-codebook) 토크나이저로 음성 특화 능력을 유지하면서 범용 오디오 인식까지 확장한 최초의 시도이며, SAP와 SAE를 통해 의미적-음향적 정보의 균형 있는 인코딩을 달성한다.
- **실험 결과**: 음성 이해·생성 태스크와 범용 오디오 이해 태스크 모두에서 기존 단일 코드북 베이스라인을 능가하였으며, 코드와 체크포인트가 공개되었다.
- **우리 연구 관련도**: ★★★ — VQ 기반 음성 표현에서 의미적·음향적 정보의 균형 문제를 직접 다루는 연구로, VQ-based representation 연구에 핵심적으로 관련된다. SAP의 구조적 감독 방식은 prediction-free SSL에서의 대안적 학습 목표 설계에 직접적 시사점을 제공한다.

## 이번 주 트렌드 요약 (2026-07-27 ~ 2026-07-31)

이번 주에는 총 44편의 논문을 조사하였으며, 다음과 같은 주요 트렌드가 관찰되었다.

### 1. 다국어 ASR의 대규모 확장과 저자원 언어 진출
Qwen3-ASR(52개 언어), OWSM v4(75개 언어), MoLGE(대규모 MoE), MEUSLI(28개 유럽 언어), DONDO(27개 아프리카 언어 변종) 등 다국어 ASR이 단순한 언어 수 확대를 넘어 저자원 언어와 코드스위칭까지 포괄하는 방향으로 진화하고 있다. 특히 RL 기반 데이터 효율적 코드스위칭(GRPO with 10% data)과 시각적 그라운딩을 통한 다국어 격차 해소가 새로운 접근으로 주목된다.

### 2. 오디오 코덱/토크나이저의 의미-음향 분리 고도화
HybridCodec, LLM-Codec, TaDiCodec, HH-Codec, UniAudio-Token 등 이번 주에만 5편 이상의 코덱/토크나이저 논문이 등장하였다. 공통 트렌드는 의미적(semantic) 정보와 음향적(acoustic) 정보의 명시적 분리 또는 균형 잡힌 통합이며, 특히 UniAudio-Token의 SAP(Semantic-Acoustic Primitives)처럼 구조적 감독을 통한 정보 분해가 핵심 기법으로 부상하고 있다.

### 3. Full-Duplex SpeechLLM의 정교한 상호작용 제어
BayLing-Duplex, PersonaPlex, Latent-IM, 활성화 조향(Activation Steering) 등 풀듀플렉스 모델이 단순한 동시 청취-발화를 넘어 대화 행위 제어, 페르소나 조건화, 상태 관성 극복 등 정교한 상호작용 관리로 진화하고 있다. 동결 LLM 기반 접근(Freeze-Omni)과 RL 기반 대화 역학 최적화가 두 가지 주요 방법론 축으로 자리잡았다.

### 4. Speech SSL 분석 연구의 심화
InsideSSL(태스크 비의존적 레이어 분석), Dissecting Sensitivity(학습 언어 민감도), From Objectives to Applications(아키텍처 편향 정렬) 등 SSL 모델의 내부 작동 원리를 깊이 있게 분석하는 연구가 증가하고 있다. 특히 엔트로피-곡률-강건성 관점의 모델 중심 분석과 NAC vs SSL 표현의 언어 민감도 차이 발견은 향후 speech representation 설계에 중요한 기초를 제공한다.
