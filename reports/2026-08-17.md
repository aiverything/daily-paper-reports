**[TagSpeech: End-to-End Multi-Speaker ASR and Diarization with Fine-Grained Temporal Grounding] (Mingyue Huo, Yiwen Shao, Yuheng Zhang — AudenAI, 2026.01)** — arxiv preprint

- https://arxiv.org/abs/2601.06896
- **기존 문제**: 다화자 음성 인식에서 "누가, 무엇을, 언제 말했는가"를 동시에 예측하는 것은 어렵다. 기존 시스템은 ASR과 화자 분리(diarization)를 별도 파이프라인으로 처리하거나, 암시적(implicit) 화자 분리만 수행하여 세밀한 화자-발화 정렬이 부족했다.
- **기존 방법**: 별도의 화자 분리 모듈과 ASR을 캐스케이드로 연결하는 방식, 또는 Serialized Output Training(SOT) 기반 end-to-end 모델이 있었으나, 세밀한 타임스탬프 예측과 화자 추적의 동기화가 부족했다.
- **제안 방법**: LLM 백본 위에 (1) 의미(semantic) 스트림과 화자(speaker) 스트림을 분리하여 SOT로 학습하고, (2) 인터리브된 시간 앵커(time anchor) 메커니즘을 도입하여 타임스탬프 예측과 화자 추적을 동기화한다. LLM 백본은 프리즈하고 경량 프로젝터만 학습하는 파라미터 효율적 방식을 채택한다.
- **핵심 차별점**: 화자 속성 전사와 세밀한 시간 정보를 단일 end-to-end 모델로 통합하며, 기존 end-to-end 베이스라인(Qwen-Omni, Gemini 포함) 대비 복잡한 중첩 구간에서 우수한 성능을 보인다.
- **실험 결과**: AMI 및 AliMeeting 벤치마크에서 DER(Diarization Error Rate) 기준 Qwen-Omni, Gemini 등 강력한 end-to-end 베이스라인 대비 일관된 개선. 특히 화자 중첩(overlap) 구간에서 두드러진 성능 향상.
- **우리 연구 관련도**: ★★☆ — 다화자 인식 및 화자 분리 분야로 직접적 연관은 낮으나, LLM 기반 end-to-end 프레임워크 설계와 temporal anchor 개념이 temporal contrastive learning과 구조적 유사성을 가짐.

**[DM-ASR: Diarization-aware Multi-speaker ASR with Large Language Models] (Wuhan University, Tencent Ethereal Audio Lab, CUHK-Shenzhen, 2026.04)** — arxiv preprint

- https://arxiv.org/abs/2604.22467
- **기존 문제**: 다화자 ASR은 "무엇을, 누가, 언제 말했는가"를 동시에 포착해야 하나, end-to-end 모델은 화자 식별이 불안정하고, 캐스케이드 시스템은 오류가 전파되는 문제가 있었다.
- **기존 방법**: 캐스케이드 파이프라인(별도 diarization + ASR), end-to-end 다화자 모델, 대규모 멀티모달 모델(Gemini, Qwen-Omni) 활용 등이 있었으나, 화자 정체성과 시간 구간을 구조적으로 활용하는 방식은 부족했다.
- **제안 방법**: 화자 분리(diarization) 결과를 구조적 프롬프트로 활용하여, 각 화자의 각 시간 구간을 멀티턴 대화 생성 과정으로 분해한다. 선택적 단어 수준 타임스탬프 예측 메커니즘으로 단어-타임스탬프 토큰을 인터리브하여 풍부한 구조적 출력을 제공한다.
- **핵심 차별점**: 화자 분리 시스템의 신뢰할 수 있는 화자 정체성/경계 정보와 LLM의 언어 모델링 능력을 상호보완적으로 결합. 소형 모델로도 Gemini-2.5-Pro, Gemini-3.0-Pro, Qwen2.5-Omni-7B 등 대형 모델 대비 우수한 성능.
- **실험 결과**: AliMeeting 및 AISHELL-4 테스트셋에서 캐스케이드 시스템 대비 cpCER, tcpCER이 크게 감소. Gemini-2.5-Pro, Gemini-3.0-Pro 대비 거의 모든 설정에서 DER, cpCER, tcpCER 우수.
- **우리 연구 관련도**: ★☆☆ — 다화자 ASR 특화 연구로 speech SSL/VQ 연구와 직접 관련은 적으나, diarization 정보의 구조적 활용 방식은 representation 설계에 참고 가능.

**[NPUsper: Eliminating Redundant Computation for Real-Time Whisper on Mobile NPUs] (Sihyeon Lee et al. — Korea University, UW-Madison, 2026.07)** — arxiv preprint

- https://arxiv.org/abs/2607.01108
- **기존 문제**: Whisper는 강력한 ASR 성능을 보이지만, 자기회귀(autoregressive) 디코딩과 KV-cache 연산의 비효율로 모바일 NPU에서의 실시간 처리가 어렵다. 또한 짧은 오디오 입력 시 환각(hallucination) 토큰이 발생하는 문제가 있었다.
- **기존 방법**: Whisper의 경량화를 위한 구조적 가지치기(pruning), 양자화(quantization), 또는 GPU/CPU 기반 최적화가 있었으나, 모바일 NPU의 특성(그래프 기반 실행, 동적 제어 불가)을 고려한 최적화는 부재했다.
- **제안 방법**: (1) 디코더 cross-attention의 시간적 패턴에서 환각 토큰을 온라인으로 감지하여 짧은 오디오 입력으로도 정확한 추론 가능, (2) Controlled Unrolling으로 자기회귀 디코딩을 K-step 청크 그래프로 실행하여 불필요한 KV-cache 연산과 그래프 디스패치 오버헤드를 제거.
- **핵심 차별점**: 모바일 NPU 환경에 특화된 최초의 Whisper 최적화 시스템. 정확도를 유지하면서 지연시간과 전력 소비를 대폭 절감.
- **실험 결과**: 베이스라인 대비 TTFT(Time-to-First-Token) 최대 4.84배 감소, 평균 전력 소비 최대 88.64% 절감. 전사 정확도는 동등 수준 유지.
- **우리 연구 관련도**: ★☆☆ — 모델 효율화/배포 관점의 연구로, speech representation 연구와 직접 관련은 적으나, cross-attention 패턴 분석이 representation 분석에 참고가 될 수 있음.

**[Audio Interaction Model] (Tsinghua University 등, 2026.06)** — arxiv preprint

- https://arxiv.org/abs/2606.05121
- **기존 문제**: 기존 음성 대화 모델은 턴 기반(turn-based) 운영에 제한되어, 항상 켜져있는(always-on) 실시간 오디오 인터랙션이 불가능했다. 환경 소리, 명령, 대화를 실시간으로 인지하고 언제 응답할지 스스로 결정하는 능동적(proactive) 오디오 상호작용이 부족했다.
- **기존 방법**: Moshi, GLM-4-Voice, Qwen2.5-Omni 등 end-to-end 음성 모델이 있었으나, 대부분 턴 기반이거나 스트리밍 처리와 능동적 응답 결정을 통합하지 못했다.
- **제안 방법**: SoundFlow 프레임워크를 통해 perceive–decide–respond 루프를 데이터 구축부터 학습, 배포까지 end-to-end로 구현. (1) StreamAudio-2M: 7개 기본 능력, 28개 서브태스크를 포함하는 260만 항목의 스트리밍 코퍼스 구축, (2) 청크 단위 ⟨Speak⟩/⟨Silent⟩ 결정 학습 + 이해 기반 침묵(comprehension-aware silence), (3) 비동기 FIFO 추론으로 첫 프레임 지연 4.5배 단축.
- **핵심 차별점**: 단일 모델이 매 청크마다 응답 여부를 의미 기반으로 결정하며, 오프라인 태스크 수행과 온라인 실시간 상호작용을 동시에 지원. Proactive-Sound-Bench 벤치마크도 함께 제안.
- **실험 결과**: StreamAudio-2M 기반 학습으로 7개 능력(대화, 환경음 인식 등) 및 28개 서브태스크에서 기존 모델 대비 우수한 성능. 비동기 추론으로 첫 프레임 지연 4.5배 감소.
- **우리 연구 관련도**: ★★☆ — 실시간 오디오 표현 학습과 스트리밍 처리 관점에서 speech representation의 시간적 구조 활용 방식이 temporal contrastive learning과 연결점이 있음.

**[VoiceChat-TTS: A Low-Latency Continuous Speech Synthesis Model for Interactive Agents] (Edresson Casanova et al. — NVIDIA, 2026.08)** — arxiv preprint

- https://arxiv.org/abs/2608.13831
- **기존 문제**: 대부분의 음성 대화 시스템은 턴 기반 운영에 한정되어, 사용자 끼어들기(barge-in) 등 실시간 적응이 불가능했다. 최근 듀플렉스 모델은 지연시간을 줄이지만, ASR/끼어들기 처리/고품질 합성을 동시에 최적화하면서 음성 품질이 저하되는 문제가 있었다.
- **기존 방법**: 멀티스테이지 파이프라인(ASR→LLM→TTS), 또는 end-to-end 음성-음성 모델이 있었으나, 모듈성과 음성 품질을 유지하면서 항상 켜져있는 실시간 생성을 지원하는 모델은 부족했다.
- **제안 방법**: LLM 텍스트 토큰 스트림에 직접 구동되는 저지연 연속 스트리밍 TTS 모델. (1) 제어 토큰을 통한 명시적 끼어들기 지원, (2) 텍스트 입력이 없을 때 침묵 생성, (3) KV 캐시를 리셋하지 않고 발화 중간 끼어들기 처리 가능.
- **핵심 차별점**: 모듈성과 고품질 음성을 유지하면서 항상 켜져있는 반응형 음성 생성 실현. 기존 듀플렉스 모델의 품질 저하 없이 실시간 상호작용 지원.
- **실험 결과**: 기존 턴 기반 TTS 대비 끼어들기 시나리오에서 KV 캐시 유지로 안정적 생성. 음성 품질과 저지연을 동시에 달성. (구체적 수치는 논문 참조)
- **우리 연구 관련도**: ★☆☆ — TTS/음성 생성 특화 연구로 speech SSL 연구와 직접 관련은 적으나, 연속적 음성 표현의 스트리밍 처리 방식이 참고 가능.

**[Spoken Function Calling: A New Perspective on Spoken Language Understanding for Large Audio Language Models] (Yuezhang Peng et al., 2026.08)** — ACM Multimedia 2026 accepted

- https://arxiv.org/abs/2608.05126
- **기존 문제**: 대형 오디오 언어 모델(Large Audio Language Models)의 음성 이해(SLU) 능력 평가가 전사(transcription) 정확도에 편중되어 있었으며, 음성에서 직접 실행 가능한 함수 호출(function calling)을 수행하는 능력에 대한 체계적 평가 프레임워크가 부족했다.
- **기존 방법**: 텍스트 기반 함수 호출(function calling) 벤치마크가 존재했으나, 음성 입력에서의 의도 파악, 파라미터 추출, 함수 선택 능력을 직접 평가하는 음성 전용 벤치마크는 없었다. 기존 SLU 벤치마크는 의도 분류, 슬롯 채우기 등 전통적 태스크에 집중.
- **제안 방법**: 음성 기반 함수 호출(Spoken Function Calling)이라는 새로운 관점에서 SLU를 재정의하고, 이를 평가하기 위한 벤치마크와 방법론을 제안. 음성 입력으로부터 직접 적절한 함수를 선택하고 파라미터를 추출하는 능력을 평가.
- **핵심 차별점**: 음성 이해를 함수 호출 관점에서 재정의하여, 음성 에이전트의 실용적 능력을 직접 평가. 텍스트 중간 단계 없이 음성에서 직접 실행 가능한 액션으로의 매핑을 다룸.
- **실험 결과**: ACM Multimedia 2026에 채택. 다양한 대형 오디오 언어 모델의 음성 함수 호출 능력을 체계적으로 평가. (구체적 수치는 논문 참조)
- **우리 연구 관련도**: ★☆☆ — SLU/에이전트 평가 관점의 연구로, speech representation 연구와 직접 관련은 적으나, 음성 표현이 의미적 태스크에 활용되는 방식에 대한 통찰 제공.

**[F3-Tokenizer: Taming Audio Autoencoder Latents for Understanding and Generation] (Dinghao Zhou et al. — Nanjing University, WeNet, 2026.06)** — arxiv preprint

- https://arxiv.org/abs/2606.06357
- **기존 문제**: 연속적 오디오 오토인코더는 파형 복원은 잘하지만 latent 공간이 이해(understanding) 태스크에 약한 구조를 가지며, 자기지도 학습(SSL) 인코더는 의미를 잘 포착하지만 직접 디코딩이 불가능하다. 하나의 토크나이저로 이해와 생성을 동시에 지원하기 어려웠다.
- **기존 방법**: 별도의 의미적 토큰과 음향적 토큰을 사용하는 이중 스트림 방식, 또는 VQ-VAE 기반 이산 토크나이저가 있었으나, 이해와 생성 성능 간 trade-off가 존재했다.
- **제안 방법**: 연속 오토인코더 latent를 두 가지 컴포넌트로 적응: (1) 노이즈 정규화 오토인코더 병목(채널 정규화 + 확률적 섭동)으로 KL 기반 variational 학습 없이 스케일 제어된 연속 latent 생성, (2) 프리즌 오토인코더 latent 위에 RQ-MTP와 프리즌 LLM 감독으로 학습하는 latent-side 표현 인코더.
- **핵심 차별점**: 고차원 표현으로는 이해 태스크를 지원하면서, 정규화된 연속 latent로는 재구성 및 자기회귀 생성을 지원하는 통합 토크나이저. KL 기반 VAE 학습의 불안정성 없이 안정적 학습 가능.
- **실험 결과**: 이해 태스크에서 고차원 표현의 우수한 성능, 생성 태스크에서 정규화된 연속 latent의 높은 재구성 품질. (구체적 벤치마크 수치는 논문 참조)
- **우리 연구 관련도**: ★★★ — VQ 기반 표현 연구와 직접 관련. 연속 latent와 이산 토큰의 trade-off, 노이즈 정규화를 통한 latent 구조 개선은 VQ-based representation 연구에 핵심 참고 자료. RQ-MTP 기반 표현 학습은 prediction-free SSL 대안으로서 비교 가치가 높음.

**[EntangleCodec: A Unified Discrete Audio Tokenizer via Semantic-Acoustic Entanglement] (Hui Li et al. — Fudan University, 2026.06)** — arxiv preprint

- https://arxiv.org/abs/2606.02739
- **기존 문제**: 기존 오디오 토크나이저는 의미적(semantic) 정보와 음향적(acoustic) 정보를 별도 스트림으로 분리하여 처리했으며, 이를 통합하려면 후단 융합(late fusion)이 필요하여 효율성이 떨어졌다. 또한 ASR 전사 기반 정렬은 비언어적 정보(화자, 감정, 운율, 환경음)를 놓치는 한계가 있었다.
- **기존 방법**: 의미 토큰과 음향 토큰의 이중 스트림 방식(SpeechTokenizer, TiCodec 등), 또는 잔차 양자화(RVQ) 기반 코덱이 있었으나, 하나의 압축된 토큰 스트림으로 의미와 음향을 동시에 인코딩하는 것은 어려웠다.
- **제안 방법**: ASR 전사 대신 풍부한 캡션(caption)과 정렬하여 언어 내용, 화자 정체성, 감정, 운율, 음향 장면을 모두 포착하는 캡션 정렬 의미-음향 표현을 양자화 전에 학습. Flow-matching 확산 디코더로 고품질 재구성 지원.
- **핵심 차별점**: 의미와 음향을 양자화 전 공유 표현 공간에서 통합(entangle)하여 후단 융합 불필요. 0.6B 파라미터 모델로도 13B 이상의 연속 표현 기반 LLM을 3개 벤치마크에서 상회(22배 적은 파라미터).
- **실험 결과**: MMAR 오디오 이해 벤치마크에서 기존 코덱 기반 베이스라인 대비 최대 +7.4% 개선. 8B 스케일에서 MMAR SOTA 달성. 재구성 품질은 특화 코덱과 동등. TTS/TTA 생성을 통합 프레임워크로 지원.
- **우리 연구 관련도**: ★★★ — VQ-based representation 연구와 직접적 관련. 의미-음향 표현의 통합(entanglement) 전략, 캡션 기반 정렬, flow-matching 디코더는 speech SSL 및 VQ 토크나이저 연구에 핵심 참고 자료. 특히 prediction target 설계와 표현 공간 구조화 관점에서 높은 관련도.

**[LoSATok: Low-dimensional Semantic-Acoustic Tokenizer for Cross-Domain Audio Understanding and Generation] (Zhisheng Zhang et al., 2026.05)** — arxiv preprint

- https://arxiv.org/abs/2605.27840
- **기존 문제**: 기존 통합 오디오 토크나이저는 고차원(1280차원 이상) 표현을 사용하여 계산 비용이 높고, 생성 모델(DiT 등)과 결합 시 효율성이 떨어졌다. 저차원 압축 시 의미적 정보가 손실되는 문제가 있었다.
- **기존 방법**: HuBERT, WavLM 등 SSL 모델의 고차원 표현을 그대로 사용하거나, 고차원 통합 토크나이저(예: 1024차원 이상)를 사용하는 방식이 있었으나, 저차원에서 의미와 음향을 동시에 보존하는 것은 어려웠다.
- **제안 방법**: (1) 시맨틱 병목(Semantic Bottleneck)으로 1280차원 SSL 특징을 128차원으로 압축하되, time-relation loss로 시간적 특징 일관성 보장. (2) 이중 수준 의미 감독(dual-level semantic supervision)으로 고차원/저차원 의미 신호를 동시 활용하여 압축된 공간에서도 의미와 음향을 동시에 포착.
- **핵심 차별점**: 128차원이라는 극도로 압축된 latent 공간에서 HuBERT/WavLM 수준의 의미적 능력을 보존하면서 음향 정보도 유지. 동일 또는 더 작은 DiT 구성에서 고차원 토크나이저 대비 우수한 생성 성능.
- **실험 결과**: 15개 크로스도메인 태스크에서 HuBERT, WavLM 등 SSL 표현과 동등 이상의 성능. TTA, TTM, TTS 생성 태스크에서 고차원 통합 토크나이저 대비 동일/소형 DiT로 더 나은 성능 달성.
- **우리 연구 관련도**: ★★★ — speech representation learning 연구와 매우 높은 관련도. 저차원 표현 공간에서의 의미-음향 보존 전략, time-relation loss를 통한 시간적 일관성 유지는 temporal contrastive learning 및 VQ-based representation 연구에 직접적 참고 자료. 차원 축소와 정보 보존의 trade-off 분석이 핵심.
