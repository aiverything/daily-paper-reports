## 1. ASR (Automatic Speech Recognition)

### **[The Second MLC-SLM Challenge: Multilingual Conversational Speech Diarization, Recognition, and Understanding] (Bingshen Mu et al., 2026-09-22)** — Interspeech 2026 Challenge Overview
- https://arxiv.org/abs/2609.27514
- **기존 문제**: 다국어 대화 음성에 대해 화자 분리(diarization), 음성 인식(ASR), 음성 이해(SLU)를 통합적으로 평가할 수 있는 표준 벤치마크와 실제 대화 데이터가 부족했음
- **기존 방법**: 개별 언어·과제별로 분리된 평가가 주를 이루었으며, 합성 데이터나 읽기 음성(read speech) 기반의 벤치마크가 대부분이었음
- **제안 방법**: Interspeech 2026에서 개최된 2nd MLC-SLM Challenge로, Task 1(다국어 대화 음성 화자 분리 + 인식)과 Task 2(다국어 대화 음성 이해)를 정의하고, 실제 대화 음성 데이터셋과 평가 프로토콜, 베이스라인 시스템을 공개
- **핵심 차별점**: 21개 언어에 걸친 실제 대화 음성 데이터를 기반으로 화자 분리·인식·이해를 동시에 평가하는 통합 프레임워크 제시; 전 세계 91개 팀이 참가하여 704건의 유효 결과 제출
- **실험 결과**: 14편의 기술 보고서가 제출되었으며, 참가 시스템들은 베이스라인 대비 유의미한 성능 향상을 달성
- **우리 연구 관련도**: ★☆☆ — 다국어 ASR/화자 분리 벤치마크로, speech SSL representation 연구와의 직접적 연관은 낮으나 downstream 평가 관점에서 참고 가능

### **[The Bairong System for MLC-SLM 2026: Dynamic Question-Aware Evidence Routing for Multilingual Conversational Speech Understanding] (Shangkun Huang, Yunzhang Chen et al., 2026-09)** — Interspeech 2026 Workshop
- https://arxiv.org/abs/2609.22214
- **기존 문제**: 다국어 대화 음성 이해 시 고정된 전사(transcript) 기반 또는 오디오 기반의 단일 정책을 적용하면, 질문 유형에 따라 필요한 증거(evidence) 유형이 달라져 최적 성능을 내기 어려움
- **기존 방법**: 전사 전체를 LLM에 입력하거나, 음성 전체를 Audio LLM에 입력하는 고정 파이프라인 방식이 주로 사용됨
- **제안 방법**: Diarization-ASR front-end로 화자 귀속 전사를 생성한 뒤, Dynamic Evidence Router가 질문·선택지로부터 필요한 증거 유형과 범위를 추론하여 (1) 전체 전사 맥락, (2) 로컬 오디오-텍스트 융합, (3) 화자 연결 증거, (4) 글로벌 음향 샘플 중 적절한 것을 선택
- **핵심 차별점**: 질문 인식(question-aware)에 기반한 동적 라우팅으로, 전사 기반 담화 맥락을 유지하면서 음향 정보가 상호보완적 증거를 제공할 때만 오디오를 활성화
- **실험 결과**: Task 1에서 개발셋 25.70%, 평가셋 18.44% tcpMER 달성; 베이스라인 대비 큰 폭의 성능 향상
- **우리 연구 관련도**: ★☆☆ — 음성 이해 시스템 파이프라인 설계에 초점, speech representation 연구와는 간접적 관련

### **[Boosting ASR Robustness via Test-Time Reinforcement Learning with Audio-Text Semantic Rewards] (Fang, Xie, Liu, 2026-03)** — AAAI 2026 accepted
- https://arxiv.org/abs/2603.05231
- **기존 문제**: Whisper 같은 대규모 ASR 모델이 높은 정확도를 달성했으나, 실제 환경의 노이즈와 다양한 악센트에 대해 여전히 취약하며, 테스트 시 도메인 시프트에 효과적으로 적응하기 어려움
- **기존 방법**: SUTA, SGEM 등 test-time adaptation 방법이 제안되었으나, 엔트로피 최소화 기반의 자기 학습 방식으로 성능과 추론 속도에 한계가 있었음
- **제안 방법**: ASR-TRA(Test-time Reinforcement Adaptation)는 인과적 개입(causal intervention)에서 영감을 받아, 학습 가능한 디코더 프롬프트와 온도 제어 확률적 디코딩으로 다양한 전사 후보를 생성하고, 오디오-텍스트 의미 정합 보상 모델로 강화학습 피드백을 제공하여 모델과 프롬프트 파라미터를 업데이트
- **핵심 차별점**: 기존 엔트로피 기반 방식 대신 RL 기반 보상 모델을 활용하여 의미적 정합성을 직접 최적화하며, 테스트 시 별도 학습 데이터 없이 적응 가능
- **실험 결과**: LibriSpeech+합성 노이즈, L2 Arctic 악센트 영어 데이터셋에서 SUTA, SGEM 등 기존 SOTA 대비 정확도와 추론 속도 모두 유의미하게 개선
- **우리 연구 관련도**: ★☆☆ — 오디오-텍스트 의미 정합 보상 모델이 representation alignment와 일부 관련이 있으나, speech SSL 연구와의 직접적 연관은 낮음

## 2. SpeechLLM (Speech-Language Model)

### **[Qwen-Audio-3.1-Realtime: Towards Reliable Agentic Voice Interaction] (Qwen Team, 2026-09-21)** — arxiv preprint
- https://arxiv.org/abs/2609.25176
- **기존 문제**: 실시간 음성 에이전트가 자연스러운 대화뿐 아니라 도구 사용(tool calling), 작업 실행, 세션 간 기억 등 종합적인 에이전틱(agentic) 능력을 갖추는 것이 어려웠음; Qwen-Audio-3.0-Realtime은 전체 작업 성공률 78.4%에 머물렀음
- **기존 방법**: 기존 음성 LLM들은 단일 모달리티 SFT 또는 단일 교사 모델의 지식 증류에 의존하여 언어 능력 전이와 오디오 고유 능력 개발이 제한적이었음
- **제안 방법**: (1) Think — Core-Cocktail SFT와 Multimodality Multi-Teacher On-Policy Distillation(M²-OPD)으로 언어 능력 전이 및 네이티브 오디오 스킬 개발; (2) Act — 자기 진화 실행 환경과 다중 단위 롤아웃 기반 GRPO로 도구 사용·피드백 해석·작업 완료 학습; (3) Speak and Coordinate — 언제, 어떻게 말하거나 행동할지를 정렬
- **핵심 차별점**: Think-Act-Speak 3단계 프레임워크로 음성 이해·도구 사용·대화 조율을 통합 학습; Voice Harness 프로토타입을 통해 전경-배경 분리 아키텍처로 장기 작업 실행 지원
- **실험 결과**: τ-Voice 기준 전체 작업 성공률 78.4% → 82.0%; FLEURS 매크로 평균 WER 9.01 → 3.98; LibriSpeech clean/other WER 1.19/2.31 달성
- **우리 연구 관련도**: ★☆☆ — 대규모 음성 에이전트 시스템으로, speech representation 연구와의 직접적 연관은 낮으나 speech LLM의 최신 발전 방향 파악에 유용

### **[PACE: A Playback-Aligned Context Engine for LLM-Based Full-Duplex Voice Dialogue] (Shibo Wang, Zicheng Zhang, Libo Wang, Junfeng Ma, 2026-08-07)** — arxiv preprint
- https://arxiv.org/abs/2608.07631
- **기존 문제**: Full-duplex 음성 대화에서 서버가 클라이언트의 재생 속도보다 빠르게 출력을 생성·대화 상태를 진행하면, 사용자가 아직 듣지 못한 내용을 기반으로 후속 발화를 해석하는 Generative Context Mis-anchoring(GCM) 문제가 발생
- **기존 방법**: 인터럽션 시 미재생 오디오를 취소(cancellation)하는 방식이 일반적이었으나, 모델 내부 대화 상태와 사용자의 실제 청취 상태 간 불일치를 근본적으로 해결하지 못함
- **제안 방법**: PACE는 프로바이더 독립적 미들웨어 레이어로, 모델이 참조하는 컨텍스트를 클라이언트 재생 경계(playback boundary)에 고정(anchor); 인터럽션 발생 시 재생되지 않은 어시스턴트 콘텐츠를 컨텍스트에서 제거하면서 저지연 생성을 유지
- **핵심 차별점**: 모델 아키텍처 수정 없이 미들웨어로 GCM을 해결; 사용자가 "실제로 들을 수 있었던 것"을 시스템 관측 가능한 프록시로 추적하는 접근
- **실험 결과**: GCM-Bench에서 Referent Anchoring Accuracy가 cancellation-only 베이스라인 25.0%에서 96.3%로 대폭 향상
- **우리 연구 관련도**: ★☆☆ — Full-duplex 시스템의 컨텍스트 관리 문제에 특화되어 speech representation 연구와의 관련성은 낮음

- **기존 문제**: 기존 대화형 AI 시스템은 턴 기반(turn-based) 상호작용으로, 사용자 입력 처리 중 새로운 입력을 실시간으로 수용하거나 복잡한 워크플로우 에이전트 작업을 동시에 수행하기 어려움
- **기존 방법**: 대부분의 음성 에이전트는 ASR-LLM-TTS 캐스케이드 또는 단일 모달 end-to-end 모델로 구현되며, 비전·오디오 입력의 연속 스트리밍 처리와 비동기 작업 실행을 동시에 지원하지 못했음
- **제안 방법**: Gander는 MiniCPM-o 4.5를 기반으로, 실시간 상호작용을 위한 비동기 에이전트 루프(asynchronous agent loop)를 추가하여 스트리밍 사용자 입력을 지속적으로 처리하면서 full-duplex 상호작용을 구현하는 네이티브 멀티모달 양방향 상호작용 모델
- **핵심 차별점**: 일상 대화와 복잡한 워크플로우 에이전트 시나리오 모두에서 full-duplex 상호작용 지원; 연속적 오디오-비주얼 인식과 비동기 장기 에이전틱 실행을 통합; 오픈소스 공개
- **실험 결과**: 턴 기반 시스템 대비 실시간 응답성과 작업 수행 능력에서 개선을 보이며, 데스크톱 어시스턴트·지능형 콕핏·음성 고객 서비스 등 다양한 시나리오에 적용
- **우리 연구 관련도**: ★☆☆ — 멀티모달 에이전트 시스템으로 speech representation 연구와의 직접적 연관은 낮으나, SpeechLLM의 실용화 방향에서 참고할 만함

## 3. Speech Foundation Model

### **[WavJEPA: Semantic learning unlocks robust audio foundation models for raw waveforms] (WavJEPA Team, 2025-09 / ICLR 2026 accepted)** — ICLR 2026 accepted
- https://arxiv.org/abs/2509.23238
- **기존 문제**: 원시 파형(raw waveform)에서 직접 오디오 표현을 학습하면 스펙트로그램 계산의 긴 지연과 위상 정보 손실을 극복할 수 있으나, 범용 오디오 표현 학습에서 스펙트로그램 기반 방법과 동등한 성능을 달성하지 못했음
- **기존 방법**: Wav2Vec 2.0, HuBERT, WavLM, Data2Vec 등 스펙트로그램 기반 자기지도 학습 모델이 음성 분야에서 성공을 거두었으나, 이를 원시 파형 기반 범용 오디오로 확장하는 데 한계가 있었음
- **제안 방법**: WavJEPA는 Joint-Embedding Predictive Architecture(JEPA)를 파형 도메인에 적용하여, 고수준 의미 표현 학습(semantic representation learning)을 통해 token/unit 수준 학습의 한계를 극복; WavJEPA-Nat은 다채널 확장으로 실제 환경 시뮬레이션 학습
- **핵심 차별점**: 파형에서 직접 고수준 의미 표현을 학습하여 기존 시간 도메인 모델 대비 다양한 다운스트림 벤치마크에서 월등한 성능을 달성하면서 계산 자원은 상당히 절감; WavJEPA-Nat은 노이즈·잔향에 대한 강건성 확보
- **실험 결과**: 다양한 다운스트림 벤치마크에서 기존 시간 도메인 오디오 파운데이션 모델을 크게 능가; WavJEPA-Nat은 Nat-HEAR 벤치마크에서 다른 시간 도메인 모델 대비 노이즈·잔향 강건성 우수
- **우리 연구 관련도**: ★★☆ — JEPA 기반 예측적 학습은 prediction-free SSL과 대비되는 접근이지만, reconstruction 없이 high-level semantic을 학습한다는 점에서 비교 연구 대상으로 유용; 파형 도메인 표현 학습이라는 점에서 참고 가치 높음

### **[S-JEPA: Soft Clustering Anchors for Self-Supervised Speech Representation Learning] (Georgios Ioannides, Yann LeCun, Ravid Shwartz-Ziv et al., 2026-06-17)** — arxiv preprint
- https://arxiv.org/abs/2606.19398
- **기존 문제**: 자기지도 음성 인코더는 주로 마스킹된 위치에서 이산적(discrete) 하드 클러스터 ID를 예측하는 방식으로 학습되며, 이는 카테고리 경계에서의 음향적 모호성을 무시(collapse)하고 학습 중간에 전체 코퍼스를 재클러스터링하는 오프라인 단계가 필요
- **기존 방법**: HuBERT는 오프라인 k-means 클러스터링 → 하드 레이블 예측 방식으로, 반복적 재클러스터링이 필요하고 어떤 트랜스포머 레이어를 클러스터링할지 수동 선택이 필요; 이후 연구들도 대부분 VQ 기반 이산 토큰 예측에 의존
- **제안 방법**: S-JEPA는 JEPA 스타일 인코더-예측기 쌍을 마스킹 위치에서 GMM(가우시안 혼합 모델)의 소프트 사후확률(soft posteriors)을 KL divergence로 매칭하도록 학습; 두 단계 연속 최적화 — (1) MFCC 특징 위의 고정 GMM, (2) 인코더 특징 위의 온라인 GMM — 로 재클러스터링 없이 단일 학습 궤적에서 운영
- **핵심 차별점**: 오프라인 재클러스터링을 완전히 제거하고, 클러스터링 대상 레이어의 수동 선택도 레이블 프리 신호로 자동 적응; 하드 VQ 대신 소프트 클러스터링으로 음향 경계의 모호성을 보존
- **실험 결과**: SUPERB 프로토콜에서 90M 파라미터 이하 SSL 모델 중 최저 WER 달성; 감정 인식에서 HuBERT-Base와 동등한 성능을 약 절반의 파라미터로 달성하여 새로운 Pareto frontier 수립
- **우리 연구 관련도**: ★★★ — prediction-free SSL과 직접 비교 가능한 연구; 하드 VQ 대신 소프트 클러스터링 사용은 VQ-based representation의 대안적 접근으로, 우리의 temporal contrastive learning 및 prediction-free 방법론과 매우 높은 비교·연관 가치

### **[Scaling Speech Tokenizers with Diffusion Autoencoders] (Yuancheng Wang et al., 2026-02-06)** — ICLR 2026 accepted
- https://arxiv.org/abs/2602.06602
- **기존 문제**: 음성 토크나이저가 의미(semantic) 인코딩과 음향(acoustic) 복원 사이에서 트레이드오프가 존재하며, 낮은 비트레이트·낮은 토큰 레이트에서 두 목표를 동시에 달성하기 어려움
- **기존 방법**: VQ-VAE 계열(SoundStream, EnCodec)은 음향 복원에 강하지만 의미 정보가 약하고, HuBERT/wav2vec2 등 SSL 토큰은 의미는 풍부하지만 고품질 음성 복원이 어려움; 이를 결합한 다중 토크나이저 접근은 시스템 복잡도가 증가
- **제안 방법**: SiTok(Speech Diffusion Tokenizer)은 확산 오토인코더(diffusion autoencoder)로 의미 풍부한 표현의 지도 학습과 고품질 음성 복원을 동시 학습; 1.6B 파라미터, 200만 시간 음성 데이터로 스케일링
- **핵심 차별점**: 단일 토크나이저로 의미·음향을 동시에 포착하면서 12.5Hz 토큰 레이트, 200 bps의 극도로 낮은 비트레이트 달성; 확산 모델 기반 디코딩으로 VQ 없이도 고품질 복원
- **실험 결과**: 이해(understanding), 복원(reconstruction), 생성(generation) 과제 모두에서 강력한 베이스라인들을 능가
- **우리 연구 관련도**: ★★☆ — VQ 기반 표현과 직접 비교되는 확산 기반 토크나이저로, VQ-based representation 연구의 대안적 접근에 대한 통찰 제공; 의미-음향 통합 토크나이저 설계에서 참고 가치 높음
