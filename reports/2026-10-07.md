## 1. ASR (Automatic Speech Recognition)

### 1-1. WhisperPipe: A Resource-Efficient Streaming Architecture for Real-Time Automatic Speech Recognition
*Erfan Ramezani, Mohammad Mahdi Giahi, Mohammad Erfan Zarabadipour, Amir Reza Yosefian, Hamid Ghadiri (April 2026)* — arxiv preprint

- **arxiv URL:** https://arxiv.org/abs/2604.25611
- **기존 문제:** Whisper 계열 모델은 높은 인식 성능을 보이지만, 스트리밍 환경에서 지연 시간과 메모리 사용량 간의 트레이드오프가 존재하여 실시간 ASR 적용이 어려움
- **기존 방법:** 고정 길이 청크 기반 스트리밍 방식으로 Whisper를 실시간 적용하거나, 별도의 경량 모델을 스트리밍에 사용
- **제안 방법:** 개선된 Voice Activity Detection(VAD)과 동적 컨텍스트 윈도우(dynamic context windowing)를 결합한 스트리밍 아키텍처. 고정 길이 청크 대신 감지된 음성 경계에 맞춰 컨텍스트 윈도우를 적응적으로 조절
- **핵심 차별점:** 기존 고정 청크 방식의 불필요한 처리를 줄이고, VAD 오탐을 34% 감소시키면서 Whisper급 성능을 스트리밍으로 제공
- **실험 결과:** VAD false activation 34% 감소 보고. 오픈소스로 PyPI 및 Zenodo에 공개
- **우리 연구 관련도:** ★☆☆ — 스트리밍/효율성 중심으로, prediction-free SSL이나 VQ 기반 표현 학습과는 직접 관련 낮음

### 1-2. A Unified Speech LLM for Diarization and Speech Recognition in Multilingual Conversations
*MLC-SLM 2026 Challenge 참가팀 (July 2026)* — arxiv preprint

- **arxiv URL:** https://arxiv.org/abs/2507.02927
- **기존 문제:** 다화자 다국어 대화 환경에서 화자 분리(diarization)와 음성 인식(ASR)을 별도 파이프라인으로 수행하면 오류가 전파되며, 특히 oracle 화자 정보 없이는 성능이 크게 저하됨
- **기존 방법:** 화자 분리 → ASR 순차 파이프라인, 또는 사전 분할된 오디오 기반의 개별 처리
- **제안 방법:** 단일 Speech LLM으로 화자 분리와 음성 인식을 동시에 수행하는 end-to-end 모델. 학습 데이터 포맷 재구성과 추론 절차 수정을 통해 사전 분할 없이 동작
- **핵심 차별점:** Oracle 정보 없이도 화자-음성 동시 처리가 가능하며, 소규모 LLM 백본으로도 경쟁력 있는 성능 달성
- **실험 결과:** MLC-SLM 2026 Task II에서 tcpWER/tcpCER 기준 베이스라인 대비 54.87% 상대 개선, 종합 8위
- **우리 연구 관련도:** ★☆☆ — LLM 기반 다화자 ASR로, SSL 표현 학습과는 직접 관련 낮음

### 1-3. Transsion's Speaker-Attributed Multilingual ASR System for the MLC-SLM 2026 Challenge
*Zhecheng Ren, Xuanji He, Xiaoxiao Li, Zhichen Han, Gaoyang Dong, Gaosheng Zhang, Minchuan Chen, Fengjie Zhu (September 2026)* — arxiv preprint

- **arxiv URL:** https://arxiv.org/abs/2609.20833
- **기존 문제:** 14개 언어, 21개 변형을 포함하는 다국어 대화 환경에서 화자 구분이 포함된 ASR 시스템 구축이 어려움. 화자 중첩, 끼어들기, 다양한 발화 스타일이 존재
- **기존 방법:** 이전 MLC-SLM 2025에서는 Whisper-large-v3 인코더 + Qwen2.5-7B LLM 조합 (WER 9.83%, 3위)
- **제안 방법:** 3단계 캐스케이드 시스템 — (1) DiariZen 기반 화자 분리(로컬 화자 활동 추정 + 글로벌 클러스터링), (2) Qwen3-Omni 기반 장문 다국어 ASR, (3) CTC 기반 정렬 모델로 단어/문자 레벨 타임스탬프 부여 후 화자-전사 융합
- **핵심 차별점:** 2025년 대비 완전히 새로운 아키텍처로 전환. 타임스탬프 기반 overlap 할당 + nearest segment 폴백 방식의 화자-전사 융합 전략
- **실험 결과:** MLC-SLM 2026 Task 1 대상, 약 2,100시간 학습 데이터 + 공개 코퍼스 추가 사용
- **우리 연구 관련도:** ★☆☆ — 시스템 엔지니어링 중심의 챌린지 논문으로, 표현 학습 연구와는 거리 있음

## 2. SpeechLLM (Speech-Language Model)

### 2-1. SALSA: Speech Aware LLM Adaptation via Learned Steering Activation Vectors
*Yekaterina Yegorova, Argyrios Gerogiannis, Haolong Zheng, Julia Hockenmaier, Chang D. Yoo, Mark A. Hasegawa-Johnson — UIUC, KAIST (May 2026)* — arxiv preprint

- **arxiv URL:** https://arxiv.org/abs/2606.00460
- **기존 문제:** Speech-aware LLM은 학습 시 본 도메인에서는 잘 작동하지만, 아동 음성, 다국어, 코드스위칭 등 분포 외(out-of-domain) 데이터에서 성능이 급격히 저하
- **기존 방법:** LoRA 등 파라미터 효율적 파인튜닝, 또는 speech in-context learning 기반 적응
- **제안 방법:** 사전학습된 Speech-aware LLM의 모든 백본 파라미터를 고정한 채, 레이어별 steering vector를 지도학습 목적함수로 직접 최적화. Contrastive activation 차이에 의존하지 않고 직접 최적화하는 것이 핵심
- **핵심 차별점:** 백본 파라미터 변경 없이 경량 steering vector만으로 도메인 적응 달성. 특히 인코더 후반 레이어를 steering하는 것이 LLM 디코더를 steering하는 것보다 효과적임을 발견
- **실험 결과:** Zero-shot 대비 최대 46.8% 상대 개선. 아동 음성, 다국어, 만다린-영어 코드스위칭 벤치마크에서 speech in-context learning 베이스라인 능가
- **우리 연구 관련도:** ★★☆ — 사전학습된 음성 인코더의 표현 공간을 조정하는 방법론으로, 표현 학습의 도메인 전이 관점에서 참고 가치 있음

### 2-2. Interleaved Speech Language Models Latently Work In Text
*Talia Sternberg, Gallil Maimon, Yossi Adi — Hebrew University of Jerusalem (June 2026)* — arxiv preprint

- **arxiv URL:** https://arxiv.org/abs/2606.22473
- **기존 문제:** Interleaved speech-text 모델이 음성을 어떻게 내부적으로 처리하는지 불분명. 음성 인식 학습을 하지 않았음에도 음성 이해가 가능한 메커니즘이 밝혀지지 않음
- **기존 방법:** 음성-텍스트 모델의 성능을 다운스트림 태스크로만 평가. 내부 표현에 대한 체계적 분석 부재
- **제안 방법:** Logit lens 분석을 통해 interleaved speech-text 모델의 중간 레이어에서 암묵적 전사(latent transcription) 현상을 발견. 모델이 음성 인식 학습 없이도 중간 레이어에서 해당 단어의 텍스트 토큰이 디코딩 가능함을 입증
- **핵심 차별점:** 텍스트 LM 사전학습과 음성-텍스트 인터리빙의 결합이 암묵적 전사를 가장 강하게 유발하며, 이 현상의 정도가 음성 기반 사실 지식 검색(factual knowledge retrieval) 성능과 양의 상관관계를 가짐
- **실험 결과:** 다양한 모델 패밀리와 크기에서 logit lens 분석 수행. 중간 레이어에서 음성 단어의 텍스트 토큰이 최대 77%의 데이터에서 상위 후보로 등장
- **우리 연구 관련도:** ★★★ — 음성 표현이 내부적으로 텍스트 공간과 어떻게 정렬되는지에 대한 근본적 분석. Prediction-free SSL에서의 표현 학습 메커니즘 이해에 직접 시사점 제공

### 2-3. Do Spoken Language Models Hear Speech as They Read Text? Bridging Structural Gaps Between Speech and Text
*Maum AI, KAIST, Atmanity 연구진 (August 2026)* — arxiv preprint

- **arxiv URL:** https://arxiv.org/abs/2608.22908
- **기존 문제:** Speech-aware text LLM에서 음성 인코더의 표현과 텍스트 LLM의 표현이 구조적으로 불일치. 연속적이고 시간 변화하는 오디오와 이산적 텍스트 간의 근본적 모달리티 갭 존재
- **기존 방법:** 음성 인코더 출력을 단순 프로젝션하여 LLM에 입력하거나, 어댑터 모듈로 연결. 길이 차이와 의미 정렬을 동시에 해결하지 못함
- **제안 방법:** 음성-텍스트 간 길이 차이(length mismatch)와 의미 정렬(semantic alignment)을 명시적으로 분리하여 처리하는 학습 프레임워크 제안
- **핵심 차별점:** 기존에는 길이 축소와 의미 정렬을 하나의 모듈에서 암묵적으로 처리했으나, 이를 분리함으로써 각각을 독립적으로 최적화 가능
- **실험 결과:** 여러 벤치마크에서 강력한 베이스라인 대비 경쟁력 있는 결과. 코드 공개 (GitHub: jaykim9870/Do_SLMs_Hear_Speech_as_They_Read_Text)
- **우리 연구 관련도:** ★★★ — 음성-텍스트 표현 간 구조적 갭 분석은 speech SSL 표현의 특성 이해와 직결. Temporal contrastive learning에서의 표현 설계에 시사점

## 3. Speech Foundation Model

### 3-1. Do Speech Foundation Models Really Learn Words?
*Robin Huo, Ewan Dunbar (September 2026)* — arxiv preprint

- **arxiv URL:** https://arxiv.org/abs/2609.10434
- **기존 문제:** Speech foundation model(HuBERT, wav2vec 2.0 등)이 단어를 학습한다는 주장이 있으나, 단어 변별 능력이 실제로 단어의 전문화된 표현을 의미하는지 불분명
- **기존 방법:** 프로빙(probing) 기반으로 SSL 모델의 음소/단어 변별 능력을 측정. 변별 가능 = 학습했다고 해석
- **제안 방법:** 잔차화(residualization)를 통해 음소 정보를 제거한 후에도 단어 정체성이 인코딩되는지 분석. 변별 능력이 단순히 좋은 음소 인코딩의 부산물인지, 아니면 음소와 독립적인 단어 수준 표현인지를 구분
- **핵심 차별점:** 음소 정보를 통계적으로 제거한 잔차 표현에서도 후반 레이어의 HuBERT/wav2vec 2.0이 합리적 수준의 단어 인코딩을 유지함을 발견. 단순 음소 인코딩을 넘어서는 단어 수준 표현이 존재함을 입증
- **실험 결과:** 잔차화된 표현이 단어 발견(word discovery) 태스크에서도 개선된 성능을 보임
- **우리 연구 관련도:** ★★★ — Speech SSL 모델이 학습하는 표현의 본질에 대한 근본적 질문. Prediction-free SSL과 VQ 기반 표현이 단어 수준 정보를 어떻게 포착하는지 직접적 시사점

### 3-2. Rethinking Speech Codecs: From Compression to Autoregressive Generative Modeling
*Yazheng Yang, Yao Qiu, Hui Su, Qi Liu (July 2026)* — arxiv preprint

- **arxiv URL:** https://arxiv.org/abs/2609.04237
- **기존 문제:** 기존 speech codec은 압축(compression) 목적으로 설계되어, 언어 모델이 codec 토큰 시퀀스를 autoregressive하게 예측할 때 최적이 아님. 압축-생성 간 목적 불일치(objective mismatch) 존재
- **기존 방법:** RVQ(Residual Vector Quantization) 기반 codec으로 음성을 이산 토큰화한 후, 별도 학습된 언어 모델로 생성. Codec과 LM의 목적함수가 분리
- **제안 방법:** 생성적 모델링 관점에서 음성 이산화를 재설계. (1) Autoregressive 호환 제약 조건을 codec 학습에 도입하여 시간적 일관성과 예측 가능성이 높은 토큰 시퀀스 생성, (2) 시맨틱/어쿠스틱 토큰 레이어를 차별적으로 다운샘플링하는 이종 다운샘플링(heterogeneous downsampling) 전략
- **핵심 차별점:** Codec 학습 단계에서부터 AR 모델의 학습 목적을 고려하여 토큰을 설계. 기존 codec을 수정 없이 이 프레임워크에 적용 가능
- **실험 결과:** 여러 codec에 걸쳐 성능 향상 확인. 기존 LM의 continued pretraining에서도 효과적
- **우리 연구 관련도:** ★★★ — VQ 기반 표현의 설계 원칙에 대한 근본적 재고. Prediction과 표현 학습의 관계를 직접 다루며, prediction-free 접근과 대비되는 시각 제공

### 3-3. Exploring Token-Space Manipulation in Latent Audio Tokenizers
*Francesco Paissan, Luca Della Libera, Mirco Ravanelli, Cem Subakan (May 2026)* — arxiv preprint

- **arxiv URL:** https://arxiv.org/abs/2605.11192
- **기존 문제:** 기존 speech codec/tokenizer는 프레임 단위로 정렬된 토큰을 생성하여, 전체 발화 수준의 전역 속성(화자, 배경 소음 등)이 모든 토큰에 분산되어 조작이 어려움
- **기존 방법:** RVQ 기반 codec에서 서로 다른 코드북 레이어가 시맨틱/어쿠스틱을 분리하는 방식. 프레임 단위 병목(frame-level bottleneck) 구조
- **제안 방법:** LATTE(Latent Audio Tokenizer for Token-space Editing) — 고정 개수의 학습 가능한 latent token을 오디오 특징 시퀀스에 추가하고, 이 latent token만으로 양자화 및 디코딩 수행. 각 토큰이 전체 발화에 대해 attention할 수 있어 시간 정렬에 구애받지 않는 compact 병목 형성
- **핵심 차별점:** 프레임 정렬 없는 latent token 기반 표현으로, 특정 토큰 위치를 발화 간 교환하여 화자 정체성, 배경 소음 등 전역 속성을 조작 가능
- **실험 결과:** Voice conversion과 denoising 태스크에서 latent token 교환 기반 속성 조작 가능성 입증. 저비트레이트 음성 코딩에서도 경쟁력 있는 복원 품질 유지
- **우리 연구 관련도:** ★★☆ — 시간 정렬에서 벗어난 표현 설계는 temporal contrastive learning의 대안적 관점 제공. 다만 SSL보다는 codec 기반 접근
