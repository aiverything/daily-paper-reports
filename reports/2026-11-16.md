## 1. ASR (Automatic Speech Recognition)

### 1-1. Hy ASR 3.0 Technical Report

**[Hy ASR 3.0 Technical Report] (Tencent Hunyuan ASR Team, 2026-11-11)** — arxiv preprint

- https://arxiv.org/abs/2611.14908
- **기존 문제**: 중국어 보통화, 영어, 광둥어 및 13개 중국 방언을 하나의 ASR 시스템으로 고정밀 지원하면서, 핫워드·대화 맥락·요약 등 외부 컨텍스트를 활용하는 범용 음성 인식이 과제였음. 기존 모델들은 방언 인식, 복잡한 음향 조건, 맥락 활용에서 한계를 보였음
- **기존 방법**: Whisper, Qwen-ASR 등 대규모 인코더-디코더 모델이 다국어 ASR을 시도했으나, 중국 방언 13개 그룹을 체계적으로 지원하는 단일 모델은 부재. StepAudio 3 ASR이 범용 벤치마크에서 aggregate WER 5.38%로 선두였음
- **제안 방법**: Tencent의 Hy3 MoE 사전학습 모델(295B 총 파라미터, 21B 활성)을 백본으로 활용. 자체 개발 비지도 음성 인코더(unsupervised speech encoder)와 결합하여 음성-텍스트 공동 사전학습(joint pretraining) 수행. 이후 다단계 사후학습(multi-stage post-training)으로 보통화, 영어, 광둥어 및 13개 방언 그룹에 최적화. 핫워드 목록, QA 대화, 요약 등 외부 컨텍스트 수용 가능
- **핵심 차별점**: 초대규모 MoE 언어 모델을 ASR 백본으로 직접 활용하여 언어 이해 능력을 음성 인식에 전이. 중국 방언 13개 그룹을 단일 모델로 체계적 지원하는 최초의 상용 수준 시스템
- **실험 결과**: 공개 보통화·영어·광둥어 벤치마크에서 aggregate WER 5.22% 달성 (StepAudio 3 ASR의 5.38% 대비 개선). 일반 인식 4.95%, 방언 인식 9.31%, 맥락 평가 4.76%, 복잡 음향 조건 6.36% (Tencent 자체 평가 기준)
- **우리 연구 관련도**: ★☆☆ — 대규모 LLM 기반 ASR 시스템으로, speech SSL이나 VQ representation과 직접적 관련은 낮음. 다만 비지도 음성 인코더의 설계가 speech representation 학습 방법론에 간접 참고 가능

### 1-2. Beyond Word Error Rate: A Failure Taxonomy of Streaming Dictation ASR

**[Beyond Word Error Rate: A Failure Taxonomy of Streaming Dictation ASR] (Harras Mansoor, Muhammad Wisal, Hassan Bhatti, Masood Shakir — heylemon.ai, 2026-11-12)** — arxiv preprint

- https://arxiv.org/abs/2611.16919
- **기존 문제**: 스트리밍 받아쓰기(dictation) ASR에서 WER만으로는 실제 사용자 경험의 실패 모드를 포착할 수 없음. 전체 WER이 유사한 시스템들이 속삭임, 배경 소음, 다국어 상황에서 극적으로 다른 성능을 보이는 문제가 간과되었음
- **기존 방법**: 기존 ASR 평가는 WER, CER 등 단일 지표에 의존하며, 오류 유형을 체계적으로 분류하지 않았음. 프로덕션 환경의 스트리밍 시스템 간 비교는 대부분 전체 WER 기준이었음
- **제안 방법**: 4단계 실패 분류 체계(failure taxonomy) 제안 — (1) 인식 오류(recognition), (2) 출력 포맷팅(output formatting), (3) 언어 처리(language handling), (4) 오디오 손실(audio dropped). 1명 화자의 106개 영어 받아쓰기(조용/팬 소음/속삭임), 11개 언어·방언별 20개 클립, 400개 이중 언어 녹음을 11개 프로덕션 시스템에 스트리밍하여 평가
- **핵심 차별점**: WER 이면의 실패 모드를 체계적으로 드러내는 최초의 스트리밍 받아쓰기 전용 평가 프레임워크. 프로덕션 시스템 간 숨겨진 성능 격차를 정량적으로 노출
- **실험 결과**: 조용한 영어에서 Zoom Scribe과 GPT-Live-Transcribe가 각각 WER 7.4%, 7.3%로 유사하나, 속삭임에서 34.7% vs 8.8%로 극적 차이. Whisper에 Silero VAD 적용 시 속삭임 WER 10.1% → 51.4%로 급등. Gemini, Deepgram, 자체 호스팅 Whisper는 이중 언어 녹음에서 비영어 부분을 86–99% 누락. 벤치마크 코드 공개 (github.com/heylemon-ai/streaming-dictation-asr)
- **우리 연구 관련도**: ★☆☆ — ASR 평가 방법론 연구로 speech SSL과 직접적 관련 낮음. 다만 VAD가 속삭임 인식을 파괴하는 발견은 speech representation의 음성 활동 감지 능력 평가에 참고 가능

### 1-3. Low Language Transfer Speech-to-Text

**[Low Language Transfer Speech-to-Text] (Husein Zolkepli, 2026-11-12)** — arxiv preprint

- https://arxiv.org/abs/2611.16260
- **기존 문제**: 저자원 언어(low-resource language) ASR에서 사전학습 모델의 교차언어 전이(cross-lingual transfer) 효과가 체계적으로 검증되지 않았음. 50개 저자원 언어를 11개 문자 체계에 걸쳐 다수의 오픈소스 다국어 모델로 비교한 대규모 벤치마크가 부재
- **기존 방법**: Whisper, MMS 등 개별 모델의 저자원 언어 성능이 단편적으로 보고되었으나, 28개 오픈 다국어 모델을 50개 저자원 언어에서 체계적으로 비교하고, fine-tuning 전후 성능을 정량화한 연구는 없었음
- **제안 방법**: 28개 오픈 다국어 ASR 모델을 50개 저자원 언어(11개 문자 체계)에서 제로샷 평가. 24개 모델을 언어당 최대 1,000개 클립(총 82시간)으로 fine-tuning. LoRA(4% 파라미터)와 전체 fine-tuning 비교. 새로운 Low-Language-TTS 벤치마크 구축
- **핵심 차별점**: 50개 저자원 언어에 걸친 최대 규모의 체계적 오픈 모델 비교. 사전학습 모델이 랜덤 초기화 대비 16.6–53.1 포인트 macro CER 개선으로 교차언어 전이를 정량적 입증. LoRA의 효율성과 망각 방지 효과 확인
- **실험 결과**: 모든 모델에서 fine-tuning 후 macro CER 대폭 개선 (16.6–53.1 포인트). LoRA(4% 파라미터)가 전체 fine-tuning 대비 1.1 포인트 이내 성능, 3개 모델 중 2개에서 더 적은 망각. MMS 1B + 언어 모델이 테스트셋 최저 macro CER 9.8 달성 (단, WER은 34.4로 여전히 높음). 말레이어 벤치마크에서 Whisper large-v3 제로샷 8.9 → fine-tuning 후 6.0
- **우리 연구 관련도**: ★★☆ — 대규모 교차언어 전이 분석은 speech SSL의 다국어 representation 학습 효과를 간접 검증. MMS 등 SSL 기반 모델의 저자원 적응 성능은 prediction-free SSL의 다국어 확장 가능성에 시사점 제공

## 2. SpeechLLM (Speech Language Model)

### 2-1. Joi-Bench-Task: Benchmarking Task Coordination in Full-duplex Voice Agents through Interactive Simulation

**[Joi-Bench-Task: Benchmarking Task Coordination in Full-duplex Voice Agents through Interactive Simulation] (저자 미확인, 2026-11-09)** — arxiv preprint

- https://arxiv.org/abs/2611.12118
- **기존 문제**: 기존 full-duplex 음성 에이전트 벤치마크(τ-Voice, Full-Duplex-Bench 등)는 태스크 실행과 대화 간 조율(coordination)을 충분히 분리하여 평가하지 못했음. 에이전트가 무엇을 실행 중이고, 무엇을 완료했으며, 무엇을 사용자에게 알렸고, 무엇이 아직 미처리인지를 추적하는 능력이 체계적으로 측정되지 않았음
- **기존 방법**: τ-Voice(ICML 2026)는 그라운디드 태스크 완수율로 평가하나 대화 중 요청 변경이나 인터럽션 하의 조율을 별도 측정하지 않음. Full-Duplex-Bench-v3은 비유창성(disfluency) 하의 도구 호출에 초점. 두 벤치마크 모두 태스크 조율의 세부 차원을 분리하지 않음
- **제안 방법**: 사용자 시뮬레이터, API 기반 음성 에이전트, 비동기 도구 환경으로 구성된 인터랙티브 시뮬레이션 프레임워크. 세 가지 차원으로 평가: (1) 실행 응답성(execution responsiveness), (2) 요청 변경 하 조율(coordination under request changes), (3) 인터럽션 하 조율(coordination under interruptions)
- **핵심 차별점**: 태스크 실행과 대화 간 조율을 명시적으로 분리하여 평가하는 최초의 벤치마크. 요청 변경과 인터럽션이라는 현실적 시나리오에서 에이전트의 약점을 정량적으로 드러냄
- **실험 결과**: 5개 상용 음성 에이전트 평가. 요청 변경 시나리오에서 최고 완수율이 55%에 불과하여, 현재 에이전트들이 기존 약속을 유지하면서 새 요청을 수용하는 데 어려움을 겪음을 확인. 인터럽션 하에서는 에이전트가 중단된 태스크의 상태를 올바르게 복원하지 못하는 경향
- **우리 연구 관련도**: ★★☆ — Full-duplex 음성 에이전트의 태스크 조율 능력 평가는 speech representation이 실시간 대화 맥락 추적에 기여하는 방식에 대한 통찰 제공. 대화 상태 추적과 temporal representation의 관계에 간접 참고 가능

## 3. Speech Foundation Model

### 3-1. Speech Tokenizers are Vulnerable: Transferable Semantic Attack and Robust Tokenizer

**[Speech Tokenizers are Vulnerable: Transferable Semantic Attack and Robust Tokenizer] (Zhisheng Zhang 외 8인, 2026-11-11)** — **NeurIPS 2026 accepted**

- https://arxiv.org/abs/2611.14929
- **기존 문제**: 음성 토크나이저는 Speech LLM과 대형 오디오-언어 모델(LALM)의 핵심 전처리 단계이나, 의미 수준(semantic level)에서의 취약성이 체계적으로 연구되지 않았음. 작은 섭동(perturbation)이 토크나이저의 의미 인코딩 과정을 교란하여 하류 ASR 및 LALM 성능을 심각하게 저하시킬 수 있는 위험이 간과됨
- **기존 방법**: StableToken(ICLR 2026)이 노이즈 강인 의미 토크나이저를 제안했으나, 적대적 공격(adversarial attack)에 대한 체계적 분석이 부족. 기존 오디오 적대적 공격 연구는 ASR 모델 자체를 타겟으로 했으며, 토크나이저의 의미 인코딩 과정을 별도 분석하지 않았음
- **제안 방법**: (1) T-SemAttack — 의미 인코더 앙상블 기반 전이 가능한 의미적 공격. 복수의 의미 인코더를 동시에 공격하여 특정 토크나이저에 의존하지 않는 범용 공격 생성. (2) ROSETok — 노이즈 학습(noisy training)과 강인 의미 증류(robust semantic distillation)를 결합한 방어적 토크나이저
- **핵심 차별점**: 음성 토크나이저의 의미 수준 취약성을 최초로 체계적 분석. T-SemAttack의 전이 가능성은 단일 토크나이저 방어만으로는 불충분함을 시사. ROSETok은 공격 하에서도 재구성 충실도와 하류 태스크 강인성을 동시에 확보
- **실험 결과**: T-SemAttack이 S3 토크나이저에서 99.7% 토큰 변경 유발. 하류 ASR 및 LALM 성능 심각하게 저하. ROSETok은 공격 하에서도 기존 토크나이저 대비 재구성 품질과 ASR/LALM 성능 유지 (구체적 수치는 논문 본문 참조)
- **우리 연구 관련도**: ★★★ — VQ 기반 speech representation의 강인성 연구와 직접 관련. 의미 토큰의 적대적 취약성 분석은 prediction-free SSL에서의 양자화 안정성 설계에 중요한 시사점 제공. ROSETok의 노이즈 학습 + 의미 증류 전략은 VQ-based representation의 강인화에 직접 참고 가능

### 3-2. Marimba: A System One Model for Speech

**[Marimba: A System One Model for Speech] (Solano Amadori — charcot.ai, 2026-11-13)** — arxiv preprint

- https://arxiv.org/abs/2611.18330
- **기존 문제**: 음성에서 화자 변경 감지, 발화 종료 감지, 화자 수 추정 등 비어휘적(non-lexical) 판단과 어휘적(lexical) 질문 응답이 별도의 전문 모델을 필요로 했음. 단일 음성 인코더의 동결된 특성(frozen features)만으로 이러한 다양한 판단을 통합 수행하는 경량 인터페이스가 부재
- **기존 방법**: 화자 다이어리제이션은 pyannote 3.1 등 전용 파이프라인, 발화 종료 감지는 Smart Turn v3.2 등 전문 모델, 어휘적 질문은 ASR + LLM 캐스케이드로 별도 처리. 각 태스크가 독립적 모델 또는 파인튜닝을 필요로 함
- **제안 방법**: Qwen3-ASR 0.6B의 동결된 중간 표현(frozen features)을 활용하는 경량 인터페이스 "System One" 모델. 어휘적 질문은 ASR 전사의 제로샷 스코어링으로, 비어휘적 질문은 질문 조건 헤드(question-conditioned head)로 처리. Layer-12 readout으로 화자 변경 감지, Layer-18 readout으로 발화 종료 감지. 태스크별로 최적 레이어를 선택하는 레이어 특화 전략
- **핵심 차별점**: 단일 동결 ASR 인코더의 중간 레이어 표현만으로 화자 변경, 발화 종료, 화자 수 추정 등 다양한 비어휘적 판단을 수행. 추가 학습 없이 레이어별 readout만으로 전문 모델에 근접하는 성능 달성
- **실험 결과**: 화자 변경 감지 — AMI, VoxConverse에서 AUROC 0.966–0.980 (pyannote 3.1보다 정확한 화자 수 추정). 발화 종료 감지 — AUROC 0.930 (Smart Turn v3.2의 0.982에는 미달하나, 별도 학습 없는 동결 모델 기준으로는 주목할 만한 수치). 화자 수 추정에서 pyannote 3.1 대비 더 정확한 추정 보고
- **우리 연구 관련도**: ★★★ — 동결 ASR 인코더의 레이어별 표현이 다양한 비어휘적 정보를 인코딩한다는 발견은 speech SSL representation의 정보 분포 분석과 직접 관련. 레이어별 최적 readout 전략은 prediction-free SSL 모델의 representation 활용 방식에 중요한 시사점 제공. Temporal contrastive learning으로 학습된 표현에서도 유사한 레이어별 특화가 나타나는지 검증할 가치가 있음
