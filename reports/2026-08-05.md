## 1. ASR (Automatic Speech Recognition)

**[AgenticASR: Refining Speech Recognition in Real-World Scenarios via an Agentic Approach] (Zixuan Jiang, Binghao Qiang, Jiaying Chi, Yanqiao Zhu, Kai Yu, Xie Chen, 2026-07-30)** — arxiv preprint

- https://arxiv.org/abs/2607.28175
- **기존 문제**: 기존 ASR 시스템은 전사(transcription)만 수행하여, 실세계 음성에서 빈번한 비유창성(disfluency), 자기수정(self-correction), 구어체 표현 등을 처리하지 못하며, 화자의 최종 의도에 맞는 정제된 텍스트를 직접 생성하지 못하였다.
- **기존 방법**: 기존 ASR은 음성을 그대로 전사하는 것에 초점을 맞추어, 비유창성 제거나 서면 형식 정규화는 별도의 후처리 파이프라인에 의존하였다.
- **제안 방법**: 에이전틱 음성 인식(AgenticSR)이라는 새로운 태스크를 정의하고, ASR-Refiner 아키텍처를 제안. 제한된 활성 컨텍스트(bounded active context)를 반복적으로 변환하며 출력 구간을 대체하는 방식으로, 임의 길이의 스트리밍 음성에서 지속적으로 발화하고 수정(revision)을 수행한다. 이중언어 벤치마크 AASR-Bench를 함께 도입하였다.
- **핵심 차별점**: 단순 전사를 넘어 비유창성 제거, 자기수정 해결, 서면 형식 정규화를 수행하면서 화자의 최종 의도를 보존하는 에이전틱 ASR 패러다임을 최초로 정의하였으며, 세밀한 원자적 평가 지표(atomic rubrics)를 제시한다.
- **실험 결과**: AASR-Bench에서 세밀한 원자적 평가 지표를 통해 AgenticSR 능력을 정량적으로 평가하였으며, 기존 ASR+후처리 파이프라인 대비 에이전틱 접근의 우수성을 입증하였다.
- **우리 연구 관련도**: ★☆☆ — ASR 후처리 및 에이전트 시스템에 초점. Speech SSL/VQ 연구와의 직접적 관련성은 낮으나, ASR 표현의 정보 충분성에 대한 간접적 시사점을 제공한다.

**[Voice Memory for Agentic Speech Recognition] (Chao-Han Huck Yang, Zih-Ching Chen, Piotr Zelasko, Zhehuai Chen, Jagadeesh Balam, Boris Ginsburg — NVIDIA, 2026-07-29)** — arxiv preprint

- https://arxiv.org/abs/2607.26410
- **기존 문제**: LLM 기반 생성적 오류 교정(generative error correction)은 ASR 가설을 교정할 때 올바른 토큰까지 과도하게 수정(over-correct)하는 문제가 심각하여, 편집의 최대 64%가 정확한 토큰을 변경하는 부작용이 발생하였다.
- **기존 방법**: 기존 ASR 오류 교정은 LLM을 직접 활용하여 가설 전체를 재생성하는 방식이었으며, 도메인별 적응은 파라미터 미세조정에 의존하여 비용이 높았다.
- **제안 방법**: 추론 시에만 작동하는(inference-only) Voice Memory 방식을 제안. 동결된(frozen) 교정기가 도메인별 memory.md 파일을 읽고 발화별로 교정 여부를 결정하며, 비동기 점수 기반 최적기(score-gated optimizer)가 검증 점수가 향상되는 편집만 수용하여 메모리 파일을 점진적으로 갱신한다.
- **핵심 차별점**: 모델 가중치를 전혀 변경하지 않고 도메인별 memory.md 파일만으로 적응하는 완전한 추론 시 접근법으로, 학습된 지식이 감사 가능하고(auditable) 이식 가능하다(portable). 과잉 교정율을 64%에서 35%로 감소시킨다.
- **실험 결과**: 10개 HyPoradise 도메인에서 가중 WER을 8.36%에서 7.52%로 감소시켰으며, 금융 뉴스 도메인에서 과잉 교정을 효과적으로 억제하였다.
- **우리 연구 관련도**: ★★☆ — NVIDIA의 에이전틱 ASR 접근법으로, listener-thinker 아키텍처에서 음성 표현의 활용 방식이 speech representation의 정보 활용 연구에 참고가 될 수 있으며, 도메인 적응 없는 추론 시 접근법은 표현 학습의 범용성 평가에 시사점을 제공한다.

**[Latent Softmax for Data-Efficient Phoneme-Based Multilingual ASR Across Tonal and Non-Tonal Languages] (Saierdaer Yusuyin, Nanling Jiang, Hao Huang, Zhijian Ou, 2026-08-02)** — arxiv preprint

- https://arxiv.org/abs/2608.01281
- **기존 문제**: 성조 언어(tonal languages)와 비성조 언어(non-tonal languages)를 단일 다국어 ASR 시스템에서 공동 학습할 때, 감독 신호의 세분도(granularity) 불일치 문제가 발생하였다. 성조 언어는 성조 표시가 있는 세밀한 음소 레이블이 필요하지만, 비성조 언어는 기본 모음 레이블만 존재한다.
- **기존 방법**: 기존 다국어 ASR은 언어별로 다른 세분도의 음소 레이블을 단순히 통합하거나, 성조 언어와 비성조 언어를 별도로 학습하였다.
- **제안 방법**: CTC와 호환되는 Latent Softmax 출력 레이어를 제안. 성조 표시가 있는 모음을 하위 클래스(subclass), 기본 모음을 상위 클래스(major class)로 모델링하며, 자음과 CTC blank은 단일 레이블로 유지한다. 기본 모음 레이블만 관찰될 때 성조 하위 클래스를 잠재 변수(latent variable)로 처리하여 주변화(marginalize)한다.
- **핵심 차별점**: 성조-비성조 언어 간 감독 세분도 불일치를 잠재 변수 주변화로 우아하게 해결하며, CTC 프레임워크와 완전히 호환되어 추가적인 아키텍처 변경이 불필요하다.
- **실험 결과**: 성조 및 비성조 언어를 포함한 다국어 ASR 벤치마크에서 기존 방법 대비 데이터 효율적인 교차 언어 공유를 달성하였다.
- **우리 연구 관련도**: ★★☆ — CTC 기반 다국어 표현에서 잠재 변수를 활용한 정보 계층 모델링은 speech SSL에서의 다중 해상도(multi-resolution) 표현 학습과 개념적으로 관련되며, 음소-성조 분리 구조는 VQ 기반 표현의 정보 분해 설계에 참고가 될 수 있다.

**[Cocktail-Talker: Multi-Speaker Dialog Modeling in Noisy Social Environments with Turn Action GRPO] (Xilin Jiang, Riki Shimizu, Sukru Samet Dindar, Junkai Wu, Zhongweiyang Xu, Nima Mesgarani, 2026-07-30)** — arxiv preprint

- https://arxiv.org/abs/2607.27756
- **기존 문제**: 기존 음성 대화 시스템은 깨끗하고 이인 대화(dyadic) 환경만을 가정하여, 다수 화자가 동시에 발화하고 배경 소음이 혼재하는 실세계 사회적 대화 환경에서는 적절한 행동(응답, 경청, 무시)을 선택하지 못하였다.
- **기존 방법**: 기존 SpeechLLM은 단일 화자 입력 또는 깨끗한 이중 채널 입력을 가정하였으며, 잡음 환경에서의 다중 화자 대화 모델링은 거의 연구되지 않았다.
- **제안 방법**: 세 가지 행동 토큰(`<|respond|>`, `<|listen|>`, `<|ignore|>`)을 도입하여 어시스턴트의 행동을 모델링하는 SpeechLLM 프레임워크를 제안. 지도 미세조정(SFT) 후 Turn Action GRPO 강화학습으로 학습하며, 현실적인 다중 화자 대화를 시뮬레이션하는 Cocktail-DialogGen LLM 기반 데이터 생성 파이프라인도 함께 제안한다.
- **핵심 차별점**: 잡음 환경에서의 다중 화자 대화에서 "언제 응답하고 언제 무시할지"를 학습하는 최초의 SpeechLLM 프레임워크로, GRPO 기반 강화학습이 행동 선택의 정확도를 크게 향상시킨다.
- **실험 결과**: 잡음 다중 화자 환경에서 적절한 행동 선택 정확도와 응답 품질 모두에서 SFT 전용 베이스라인 대비 유의미한 향상을 달성하였다.
- **우리 연구 관련도**: ★★☆ — 다중 화자 잡음 환경에서의 음성 표현 활용은 speech SSL 표현의 화자 분리 및 잡음 강건성 연구와 관련되며, 행동 토큰 기반 대화 제어는 이산 토큰 기반 SpeechLLM의 설계에 참고가 될 수 있다.

**[DuplexChat: Constructing Speaker-Separated Full-Duplex Dialogue Speech at Scale for Spoken Dialogue Language Modeling] (Wataru Nakata, Yuki Saito, Hiroshi Saruwatari, 2026-07-06)** — arxiv preprint (SLT demo track 제출)

- https://arxiv.org/abs/2607.04941
- **기존 문제**: 풀-듀플렉스 음성 대화 모델은 화자가 분리된(speaker-separated) 대화 음성 데이터가 필요하지만, 기존 대규모 음성 코퍼스는 대부분 모노럴(monaural) 또는 단일 화자 음성으로 구성되어 있어 자연스러운 턴테이킹과 동시 발화 역학을 학습하기 어려웠다.
- **기존 방법**: 기존 풀-듀플렉스 모델은 소규모 대화 코퍼스를 사용하거나, TTS로 합성한 대화 데이터에 의존하여 자연스러운 대화 역학의 학습이 제한적이었다.
- **제안 방법**: 공개 팟캐스트 피드에서 화자 분리된 풀-듀플렉스 대화 음성을 대규모로 구축하는 오픈소스 파이프라인 DuplexChat-Pipe를 제안. 팟캐스트 필터링, 에피소드 오디오 추출 및 정제, 화자 분리(diarization) 기반 이인 대화 클립 추출, 음성 분리(separation) 및 복원을 수행한다.
- **핵심 차별점**: 영어 282,634시간, 일본어 132,723시간 규모의 대규모 오픈소스 풀-듀플렉스 대화 코퍼스를 구축한 최초의 시도이며, 구축된 코퍼스가 실제 인간 대화의 턴테이킹 역학을 보존함을 분석적으로 검증하였다.
- **실험 결과**: 구축된 코퍼스의 턴테이킹 역학(겹침, 일시정지 분포 등)이 실제 대화 데이터의 패턴과 유사함을 확인하였으며, 코퍼스와 파이프라인 전체를 오픈소스로 공개하였다.
- **우리 연구 관련도**: ★★☆ — 대규모 풀-듀플렉스 대화 데이터 구축은 음성 표현 학습용 대화 데이터 확보 전략에 직접적으로 참고 가능하며, 화자 분리 기반 데이터 정제 파이프라인은 speech SSL 사전학습 데이터 구축에도 활용 가능하다.

**[Discriminative Axis, Not Data Volume: What a Contrastive Corpus Teaches an Audio Embedding] (Abdul Basit Tonmoy — Eximius Labs / Wabash College, 2026-08-03)** — arxiv preprint

- https://arxiv.org/abs/2608.01560
- **기존 문제**: 대조 학습(contrastive learning) 기반 오디오 임베딩에서 학습 코퍼스의 어떤 특성이 표현에 인코딩되는 정보를 결정하는지 체계적으로 분석되지 않았으며, 단순히 데이터 규모를 키우면 표현 품질이 향상될 것이라는 가정이 지배적이었다.
- **기존 방법**: 기존 대조 학습 기반 오디오 임베딩(CLAP 등)은 더 많은 데이터와 다양한 캡션을 사용하여 학습하는 데이터 스케일링 접근법에 의존하였다.
- **제안 방법**: 코퍼스 구조(corpus structure)가 데이터 규모나 캡션 어휘보다 대조 학습 오디오 임베딩에 인코딩되는 정보를 결정한다는 것을 실험적으로 입증. 동결된(frozen) 기본 멀티모달 임베딩 모델에 어휘-음성(lexical-speech) 라운드를 추가하면 제로샷 키워드 스포팅이 76포인트 상승하지만 감정 인식이 14포인트 하락하며, 캡션 다양성을 조절하여 감정이 유일한 분리 축(separating axis)이 되면 감정 인식이 회복됨을 보인다.
- **핵심 차별점**: 대조 학습 목적함수가 배치 내 부정 샘플(in-batch negatives)을 분리하기 위해 필요한 속성만 인코딩한다는 핵심 통찰을 제시. 데이터 규모가 아닌 판별 축(discriminative axis)이 표현 학습의 핵심임을 밝혔다.
- **실험 결과**: 어휘-음성 라운드 추가 시 키워드 스포팅 +76pt, 감정 인식 -14pt. 29,428개의 감정 명시 캡션 클립을 추가해도 효과 미미. 캡션 구조 변경으로 감정 축을 강제하면 감정 인식 회복.
- **우리 연구 관련도**: ★★★ — 대조 학습에서 코퍼스 구조가 표현에 인코딩되는 정보를 결정한다는 발견은 temporal contrastive learning 연구에 핵심적으로 관련된다. 부정 샘플 구성이 표현의 판별 축을 결정한다는 통찰은 VQ 기반 표현의 정보 인코딩 제어와 prediction-free SSL의 학습 신호 설계에 직접적인 시사점을 제공한다.

**[CleanCodec: Efficient and Robust Speech Tokenization via Perceptually Guided Encoding] (Eugene Kwek, Feng Liu, Rui Zhang, Wenpeng Yin, 2026-06-03)** — arxiv preprint

- https://arxiv.org/abs/2606.04418
- **기존 문제**: 기존 오디오 코덱은 입력 신호의 모든 정보(잡음, 녹음 아티팩트 포함)를 충실히 복원하려 하여, 이산 토큰에 불필요한 정보가 인코딩되어 토큰 효율성이 저하되고 다운스트림 태스크 성능이 제한되었다.
- **기존 방법**: EnCodec, DAC 등 기존 신경 오디오 코덱은 입력-출력 충실도(fidelity)를 최대화하는 복원 손실에 의존하여, 잡음이나 아티팩트까지 포함한 전체 신호를 인코딩하였다.
- **제안 방법**: 오디오 토큰화를 선택적 정보 병목(selective information bottleneck) 문제로 재정의하는 CleanCodec을 제안. 지각적으로 중요한 특징만 인코딩하고 지각 불가능한 정보(잡음, 아티팩트)를 버리도록 학습하는 잡음 제거 오디오 코덱(denoising audio codec)이다.
- **핵심 차별점**: 초당 12.5 토큰만으로 SOTA 토큰화 효율을 달성하며, 기존 코덱 대비 화자 유사도(speaker similarity)와 음성 명료도(speech intelligibility)에서 대폭 우수. 다운스트림 TTS 및 음성 변환에서 최대 17배 빠른 추론을 달성한다.
- **실험 결과**: 12.5 tokens/sec에서 기존 코덱 대비 화자 유사도와 음성 명료도 SOTA 달성. 다운스트림 TTS에서 최대 17배 추론 속도 향상.
- **우리 연구 관련도**: ★★★ — 선택적 정보 병목 관점의 음성 토큰화는 VQ 기반 표현에서 어떤 정보를 인코딩할지 결정하는 문제와 직접적으로 관련된다. 지각적 중요도 기반 정보 선택은 prediction-free SSL에서의 학습 목표 설계와 표현의 정보 이론적 분석에 핵심적 시사점을 제공한다.

**[SDP-Codec: A Speaker-Decoupled Speech Codec with Pitch Injection for Low-Bitrate Coding and Zero-Shot Voice Conversion] (Hounsu Kim, Juhan Nam — KAIST, 2026-06)** — Interspeech 2026 accepted

- https://arxiv.org/abs/2606.21157
- **기존 문제**: 기존 음성 코덱은 화자 정보가 이산 토큰에 누출(leakage)되어, 음성 변환(voice conversion) 시 원본 화자의 특성이 잔존하고, 화자 독립적인 콘텐츠 표현 학습이 어려웠다.
- **기존 방법**: 기존 화자 분리 코덱은 다단계 최적화나 복잡한 보조 손실 함수를 사용하여, 학습 파이프라인이 복잡하고 분리 품질이 제한적이었다.
- **제안 방법**: 사전학습된 SSL 인코더의 양자화 전(pre-quantization) 연속 특징에서 로컬 토큰을 추출하고, 정규화된 F0를 피치 인코더-디코더를 통해 주입하는 SDP-Codec을 제안. 단일 단계 최적화(single-stage optimization)로 화자 분리와 피치 제어를 동시에 달성한다.
- **핵심 차별점**: 비교 시스템 중 가장 낮은 화자 프로빙 정확도(최소 화자 누출)를 달성하면서, 저비트레이트에서 경쟁력 있는 음성 복원 품질과 강력한 제로샷 음성 변환 성능을 유지한다. 단일 단계 최적화가 복잡한 다단계 파이프라인을 대체한다.
- **실험 결과**: 비교 시스템 중 최저 화자 프로빙 정확도(최소 화자 정보 누출)를 달성하였으며, 저비트레이트에서 경쟁력 있는 복원 품질과 제로샷 음성 변환 성능을 기록하였다.
- **우리 연구 관련도**: ★★★ — SSL 인코더의 양자화 전 연속 표현을 활용한 화자 분리 접근법은 VQ 기반 표현에서의 화자-콘텐츠 정보 분리와 직접적으로 관련된다. 피치 주입 메커니즘은 음성 표현의 속성별 제어 가능성(controllability) 연구에 참고 가능하며, 단일 단계 최적화 전략은 representation learning 파이프라인 설계에 시사점을 제공한다.

**[MeloCodec: Harnessing Melodic Priors for High-Fidelity Singing Voice Representation] (Yizhong Geng, Wenxin Fu, Kecan Mao, Qifei Li, Yingming Gao, Ruimin Wang, Chunfeng Wang, Hao Li, Ya Li, Wei Chen, 2026-08-04)** — arxiv preprint

- https://arxiv.org/abs/2608.03021
- **기존 문제**: 기존 음성/오디오 코덱은 언어 음성(speech)에 최적화되어, 노래 음성(singing voice)의 핵심인 멜로디 구조(pitch trajectory, vibrato, portamento)를 정확하게 표현하지 못하여 피치 일관성과 표현력이 부족하였다.
- **기존 방법**: 기존 코덱에 피치 정보를 외부 조건(conditioning)으로 제공하는 방식이 있었으나, 멜로디 구조가 이산 잠재 공간(discrete latent space)에 내재화되지 않아 LLM 기반 오디오 생성과의 통합이 제한적이었다.
- **제안 방법**: 멜로디 사전지식(melodic priors)을 양자화 루프에 직접 통합하는 MeloCodec을 제안. "Tokenize-then-Fuse" 패러다임으로 이산 멜로디 브랜치를 먼저 사전학습하여 피치 구조를 고정한 후 특징 융합을 수행한다. 2단계 학습 전략으로 코드북 붕괴(codebook collapse)를 방지하고 안정적 수렴을 보장한다.
- **핵심 차별점**: 외부 조건 방식과 달리 멜로디 구조를 이산 잠재 공간에 직접 내재화하여, LLM 기반 오디오 생성과 원활히 통합 가능한 통합적이고 분리된 토큰 인터페이스를 제공한다. 코드북 붕괴 방지를 위한 2단계 학습이 핵심 기여이다.
- **실험 결과**: 노래 음성 표현에서 피치 일관성과 제어 가능한 피치 조작에서 베이스라인을 능가하였다.
- **우리 연구 관련도**: ★★☆ — 이산 잠재 공간에 도메인 특화 사전지식을 내재화하는 접근법은 VQ 기반 표현 학습에서 특정 속성(피치, 화자 등)의 구조적 인코딩 방법론에 참고 가능하며, 코드북 붕괴 방지를 위한 2단계 학습 전략은 VQ-based representation 연구에 직접적 시사점을 제공한다.
