## 1. ASR (End-to-End, Streaming, Multilingual, Diarization)

### **Contextual Biasing for Streaming ASR via CTC-based Word Spotting (Kai-Chen Tsai, Tien-Hong Lo, Yun-Ting Sun, Berlin Chen — National Taiwan Normal University, 2026-05)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2605.18222
- 기존 문제: 스트리밍 ASR에서 희귀 단어 및 도메인 특화 용어의 인식 성능이 낮음. 기존 CTC 기반 키워드 탐지(CTC-WS)는 전체 발화에 접근해야 하므로 오프라인 처리에 제한되어 실시간 스트리밍 환경에서는 사용이 불가능.
- 기존 방법: 기존 contextual biasing 기법 대부분이 오프라인 설정에 초점을 맞추며, 스트리밍 ASR의 청크 단위 처리 특성을 명시적으로 고려하지 않음. CTC-WS는 CTC log-probability에서 직접 키워드를 탐지하여 강력한 성능을 보이나 전체 발화 접근이 필수.
- 제안 방법: CTC-WS의 스트리밍 확장을 제안. 상태 유지형 토큰 패싱(stateful token passing) 알고리즘으로 오디오 청크 간 활성 키워드 경로를 유지하여, 여러 청크에 걸쳐 등장하는 키워드도 탐지 가능. 점진적 확정(incremental commitment) 메커니즘을 도입하여 미래 오디오에 영향받지 않는 세그먼트만 출력하고 불확실한 영역은 보류.
- 핵심 차별점: 오프라인 전용이던 CTC-WS를 모델 재학습 없이 스트리밍으로 확장. 청크 경계에 걸치는 키워드 처리와 저지연 안정 출력을 동시에 달성.
- 실험 결과: 스트리밍 환경에서 오프라인 CTC-WS와 동등한 키워드 탐지 성능을 유지하면서 저지연 출력 달성 (논문 내 정량 결과는 원문 참조).
- 우리 연구 관련도: ★☆☆ (CTC 기반 스트리밍 ASR 기법으로, speech SSL이나 VQ-based representation과 직접 관련도는 낮음)

### **A Unified Speech LLM for Diarization and Speech Recognition in Multilingual Conversations (Phurich Saengthong, Boonnithi Jiaramaneepinit, Sheng Li, Manabu Okumura, Takahiro Shinozaki — Institute of Science Tokyo, 2025-07)** — MLC-SLM 2025 Challenge
- arxiv URL: https://arxiv.org/abs/2507.02927
- 기존 문제: 다국어 다화자 대화에서 ASR과 화자 분리(diarization)를 동시에 수행하는 것은 여전히 난제. 기존 캐스케이드 시스템(ASR + diarization 분리)은 오류 전파와 모듈 간 최적화 불일치로 성능이 저하됨. 특히 사전 세그멘테이션(pre-segmentation)에 의한 모호한 오디오 입력 처리에 한계가 존재.
- 기존 방법: 별도의 ASR 모듈과 화자 분리 모듈을 순차적으로 적용하는 캐스케이드 파이프라인이 주류. MLC-SLM 2025 Challenge 베이스라인은 8B 모델 기반으로 사전 세그멘테이션된 오디오를 입력으로 사용.
- 제안 방법: Speech LLM을 활용하여 화자 분리와 ASR을 end-to-end로 동시 수행하는 통합 모델. 학습 데이터 형식을 재구성하고 추론 절차를 수정하여, 사전 세그멘테이션 없이도 모호한 오디오 입력에 대한 강건한 처리를 달성. Whisper 인코더로 음성 특징을 추출.
- 핵심 차별점: 더 작은 모델(3B)로 더 큰 베이스라인(8B)을 대폭 능가. 학습 데이터 형식과 추론 절차의 재설계만으로 사전 세그멘테이션 의존성을 제거.
- 실험 결과: 공식 베이스라인 대비 tcpWER/tcpCER에서 54.87% 상대 개선 달성 (3B 모델, 베이스라인은 8B).
- 우리 연구 관련도: ★☆☆ (다국어 ASR+diarization 통합 시스템으로, speech SSL과 직접 관련도는 낮으나, Whisper 인코더의 음성 표현 활용 방식이 foundation model 활용 관점에서 간접 참고 가능)

### **Mind the Pause: Disfluency-Aware Objective Tuning for Multilingual Speech Correction with LLMs (Deepak Kumar, Baban Gain, Asif Ekbal, 2026-05)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2605.12242
- 기존 문제: ASR 전사 결과에는 필러(filler), 반복(repetition), 거짓 시작(false start) 등 비유창성(disfluency)이 포함되어 가독성을 저하시키고, 챗봇·음성 비서 등 하류 애플리케이션의 성능을 저해.
- 기존 방법: 비유창성 제거를 위한 별도의 후처리 모듈이 존재하나, 다국어 환경에서의 일반화가 부족하고, 단순 삭제 방식은 문맥 정보를 손실시킴. 기존 LLM 기반 교정은 비유창성 위치를 명시적으로 인식하지 못함.
- 제안 방법: 2단계 다국어 교정 파이프라인을 제안. (1) 시퀀스 태거(sequence tagger)가 비유창 토큰을 먼저 표시하고, (2) 이 신호를 활용하여 LLM을 인스트럭션 파인튜닝하여 전사를 유창한 텍스트로 재작성. 비유창성 인식(disfluency-aware) 목적 함수로 LLM 학습을 유도.
- 핵심 차별점: 비유창성 위치 정보를 명시적으로 LLM에 전달하는 2단계 접근법. 다국어 환경에서 일반화 가능한 프레임워크 설계.
- 실험 결과: 다국어 ASR 전사에서 비유창성 교정 성능 향상을 달성 (논문 내 정량 결과는 원문 참조).
- 우리 연구 관련도: ★☆☆ (ASR 후처리 연구로, speech SSL이나 VQ-based representation과 직접 관련도는 낮음)

## 2. SpeechLLM (Speech-Language Model, Voice Agent, Spoken Dialogue)

### **DuplexSLA: A Full-Duplex Spoken Language Model with Synchronized Speech, Language, and Action (Haoyang Zhang, Jun Chen, Donghang Wu et al. — StepFun, Peking University, NTU, SJTU, UNSW, Imperial College London, 2026-05)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2605.20755
- 기존 문제: 기존 full-duplex 대화 모델은 실시간 대화 중 계획(planning)과 도구 호출(tool calling)을 위한 네이티브 채널이 부재. 에이전틱(agentic) 행동이 턴 경계에 묶이거나 외부 캐스케이드에 의존하여, 대화 중 자연스러운 도구 사용이 불가능.
- 기존 방법: 기존 full-duplex 모델(Moshi, SALM-Duplex 등)은 사용자 오디오 청취와 응답 생성의 동시 처리에 초점. 도구 호출이나 행동 계획은 별도의 턴 경계 후 외부 모듈로 처리하거나 미지원.
- 제안 방법: Speech-Language-Action의 세 채널을 160ms 청크 타임라인에서 동기화하여 동시 디코딩하는 네이티브 full-duplex 모델. 연속 사용자 오디오 채널, 이산 어시스턴트 오디오 채널, 텍스트 액션 채널(계획 텍스트 + 구조화된 도구 호출)을 단일 백본으로 통합. 시맨틱 기반 턴 테이킹으로 외부 VAD 없이 인터럽션, 일시정지, 백채널을 처리.
- 핵심 차별점: full-duplex 대화 + 실시간 도구 호출 + 계획 생성을 단일 모델에서 네이티브로 지원하는 최초의 프레임워크. 160ms 청크 단위의 동기 디코딩으로 세 채널 간 시간 정렬을 보장.
- 실험 결과: DuplexSLA-Bench를 자체 구축하여 일시정지, 인터럽션, 백채널 턴 테이킹과 3가지 대화 중 도구 호출 스타일을 종합 평가. 프로젝트 페이지, 인터랙티브 데모, 평가 스위트를 공개.
- 우리 연구 관련도: ★☆☆ (full-duplex 대화 시스템 아키텍처로, 이산 음성 토큰을 활용하나 speech SSL이나 VQ-based representation 학습과 직접 관련도는 낮음)

### **How Should LLMs Listen While Speaking? A Study of User-Stream Routing in Full-Duplex Spoken Dialogue (Hui Lu, Xueyuan Chen, Huimeng Wang, Shuhai Peng, Shiyin Kang, Xixin Wu, Zhiyong Wu — CUHK, SenseTime, Tsinghua University, 2026-05)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2605.10199
- 기존 문제: full-duplex 음성 대화는 모델이 응답 생성 중에도 사용자 음성을 계속 청취해야 하지만, LLM은 단일 일관된 시퀀스를 확장하도록 설계되어 생성 중 사용자 입력을 자연스럽게 수용하지 못함.
- 기존 방법: 기존 full-duplex 모델은 사용자 스트림의 LLM 내 라우팅 방식을 체계적으로 비교하지 않고 특정 아키텍처를 제안하는 데 그침. 채널 융합, 별도 모듈 등 다양한 접근이 존재하나 어떤 전략이 더 우수한지 정량적 비교가 부족.
- 제안 방법: 사용자 스트림 라우팅(user-stream routing)을 full-duplex 모델의 핵심 설계 축으로 정의하고, 텍스트 전용 LLM을 통합 full-duplex 시스템으로 확장하여 두 가지 라우팅 전략을 체계적으로 비교: (i) 채널 융합(channel fusion) — 사용자 스트림을 LLM 입력에 직접 주입, (ii) 별도 처리 후 통합.
- 핵심 차별점: 기존 연구에서 암묵적으로 선택하던 사용자 스트림 라우팅 방식을 명시적 설계 변수로 격상. 시맨틱 통합(semantic integration)과 컨텍스트 강건성(context robustness) 간의 트레이드오프에 대한 실증적 가이드라인을 제공.
- 실험 결과: 두 라우팅 전략의 시맨틱 통합 정도와 컨텍스트 강건성 간 트레이드오프를 정량적으로 분석하여, full-duplex 모델 설계에 대한 실용적 가이드를 제시 (논문 내 정량 결과는 원문 참조).
- 우리 연구 관련도: ★☆☆ (full-duplex 대화 아키텍처 연구로, speech SSL과 직접 관련도는 낮음)

### **NTPP: Generative Speech Language Modeling for Dual-Channel Spoken Dialogue via Next-Token-Pair Prediction (Qichao Wang, Ziqiao Meng, Wenqian Cui, Yifei Zhang, Pengcheng Wu, Bingzhe Wu, Irwin King, Liang Chen, Peilin Zhao, 2025-06)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2506.00975
- 기존 문제: 기존 음성 대화 모델은 듀얼 채널(양 화자 분리) 음성 데이터를 충분히 활용하지 못함. 단일 채널로 병합하거나 턴 단위로 분리하는 방식은 인간 대화의 구조적 역학(겹침, 백채널, 동시 발화)을 정밀하게 모델링하기 어려움.
- 기존 방법: 기존 음성 언어 모델은 단일 스트림에서의 다음 토큰 예측(NTP)에 의존하며, 듀얼 채널의 시간 정렬 구조를 명시적으로 활용하지 않음. 이로 인해 턴 테이킹 패턴 학습과 응답 일관성에 한계.
- 제안 방법: 다음 토큰 쌍 예측(Next-Token-Pair Prediction, NTPP) — 디코더 전용 아키텍처로 화자 독립적 듀얼 채널 음성 대화 학습을 최초로 구현. 이전에 생성된 대화 기반으로 다음 음성 토큰 쌍(양 화자)을 동시에 예측하며, 듀얼 채널 시퀀스의 시간 정렬 구조를 활용하여 대화 생성 분포의 더 정밀한 표현을 달성.
- 핵심 차별점: 듀얼 채널 데이터의 시간 정렬 구조를 활용한 토큰 쌍 예측으로, 단일 스트림 NTP 대비 대화 역학의 정밀 모델링 달성. 디코더 전용 아키텍처 기반의 화자 독립적 학습.
- 실험 결과: 턴 테이킹 예측, 응답 일관성에서 기존 음성 언어 모델 대비 유의미한 개선. 추론 지연(latency)이 크게 감소하여 실시간 애플리케이션에 적합. 데모와 코드 공개.
- 우리 연구 관련도: ★★☆ (이산 음성 토큰 기반 생성 모델링으로, 토큰 쌍 예측 패러다임이 VQ-based representation의 시간적 구조 모델링과 관련. 듀얼 채널에서의 temporal alignment 활용이 temporal contrastive learning의 다른 관점에서의 시간 구조 활용으로 참고 가능)

## 3. Speech Foundation Model (Speech SSL, Speech Tokenizer, Representation Learning)

### **MOSS-Audio-Tokenizer: Scaling Audio Tokenizers for Future Audio Foundation Models (OpenMOSS Team, 2026-02)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2602.10934
- 기존 문제: 기존 오디오 코덱(EnCodec, DAC 등)은 CNN 기반 아키텍처로, 스케일링 시 성능 향상이 포화되는 경향이 있고, 음성·음향·음악 등 다양한 오디오 도메인에서의 범용성이 부족. 코덱 토크나이저의 규모 확대에 따른 체계적 성능 향상(scaling law)이 검증되지 않음.
- 기존 방법: EnCodec, SoundStream 등 CNN 기반 오디오 코덱이 표준. 대부분 비인과적(non-causal) 아키텍처로 스트리밍에 부적합하고, 소규모 데이터(<100K 시간)로 학습하여 도메인 다양성이 제한적.
- 제안 방법: CAT(Causal Audio Tokenizer with Transformer) — 순수 Transformer 기반 인과적 아키텍처로 인코더, 양자화기, 디코더를 처음부터 공동 최적화. 이 아키텍처 기반으로 1.6B 파라미터, 300만 시간의 다양한 오디오 데이터로 사전학습한 MOSS-Audio-Tokenizer를 개발.
- 핵심 차별점: 순수 Transformer 기반 인과적 오디오 토크나이저로 스케일링 법칙을 실증. 음성, 음향, 음악 전 도메인에서 기존 코덱 대비 일관된 성능 향상. 인과적 설계로 스트리밍과 가변 비트레이트를 네이티브 지원.
- 실험 결과: 음성, 음향, 음악 전 도메인에서 다양한 비트레이트에 걸쳐 기존 코덱을 일관적으로 능가. 순수 자기회귀 TTS 모델로 기존 비자기회귀 및 캐스케이드 시스템을 최초 초과. 보조 인코더 없이도 경쟁력 있는 ASR 성능 달성.
- 우리 연구 관련도: ★★☆ (VQ 기반 오디오 토크나이저의 대규모 스케일링 연구로, VQ-based representation 연구에 직접 관련. 순수 Transformer 인과적 아키텍처와 스케일링 법칙 검증이 speech tokenizer 설계에 중요한 참고 자료)

### **LLM-Codec: Neural Audio Codec Meets Language Model Objectives (Ho-Lam Chung, Yiming Chen, Hung-yi Lee — National Taiwan University, ASUS, 2026-04)** — arxiv preprint
- arxiv URL: https://arxiv.org/abs/2604.17852
- 기존 문제: 뉴럴 오디오 코덱은 파형 재구성에 최적화되어 있으나, 자기회귀 예측에는 최적화되지 않음. 이 불일치가 이산 토큰 공간에 음향 기반 불확실성을 주입하여 언어 모델의 perplexity를 증가시킴. 즉, 코덱의 학습 목표(재구성)와 LLM의 목표(예측) 간 근본적 불일치 존재.
- 기존 방법: 기존 오디오 코덱(EnCodec, SoundStream, DAC)은 파형 재구성 손실로만 학습. 코덱과 LLM을 별도로 학습하고 순차적으로 연결하는 방식이 표준. 시맨틱 정보를 코덱에 추가하려는 시도(SpeechTokenizer, SiTok 등)가 있으나 LLM 예측 목표와의 직접 정렬은 부재.
- 제안 방법: 코덱과 LLM 아키텍처를 변경하지 않고, 코덱 학습에 LM 지향 목적함수를 추가. (i) Medusa 스타일 멀티스텝 헤드를 활용한 미래 토큰 예측(future token prediction)으로 다단계 예측 가능성을 강화, (ii) 메모리 뱅크 대조 손실(memory-bank contrastive loss)을 통한 시맨틱 정렬로 오디오-텍스트 표현을 매칭. 미분 가능 Gumbel 브릿지(differentiable Gumbel bridge)로 이산 양자화를 통한 end-to-end 그래디언트 전달을 달성.
- 핵심 차별점: 코덱의 재구성 목표와 LLM의 예측 목표 간 불일치를 코덱 학습 단계에서 직접 해소. 아키텍처 변경 없이 학습 목적함수만 추가하는 플러그인 방식으로, 기존 코덱 및 LLM과 호환.
- 실험 결과: SALMon 음성 일관성 벤치마크에서 토큰 LM이 61.6% 정확도 달성 (AUV 대비 +12.1 포인트). Perplexity 35% 감소.
- 우리 연구 관련도: ★★★ (VQ 기반 이산 표현과 LLM 간의 정렬을 직접 다루는 핵심 연구. 대조 학습 기반 시맨틱 정렬, Gumbel 양자화를 통한 end-to-end 학습이 VQ-based representation 연구와 매우 밀접. 코덱 토큰의 예측 가능성과 시맨틱 품질을 동시에 최적화하는 접근이 prediction-free SSL에서의 표현 품질 평가에도 시사점 제공)

### **The Interspeech 2026 Audio Encoder Capability Challenge for Large Audio Language Models (Heinrich Dinkel, Jiahao Zhou, Guanbo Wang, Yadong Niu, Junbo Zhang et al. — Xiaomi, 2026-03)** — Interspeech 2026 Challenge
- arxiv URL: https://arxiv.org/abs/2603.22728
- 기존 문제: Large Audio Language Models(LALMs)의 성능은 프론트엔드 오디오 인코더의 표현 품질에 크게 의존하지만, 인코더 개발과 LLM 파인튜닝이 결합되어 있어 오디오 인코더 자체의 성능을 독립적으로 평가하기 어려움. 범용 오디오 표현의 표준화된 평가 프로토콜이 부재.
- 기존 방법: SUPERB, HEAR 등 기존 벤치마크는 SSL 인코더의 분류/회귀 태스크 성능을 평가하나, 생성형 LALM의 프론트엔드로서의 인코더 성능을 직접 측정하지 못함. 인코더 성능과 LLM 성능이 혼재되어 인코더 기여도를 분리하기 어려움.
- 제안 방법: XARES-LLM 통합 생성형 평가 프레임워크를 제안. 참가자는 사전학습된 인코더만 제출하고, 다운스트림 LALM 학습과 평가는 주최측이 통일된 조건에서 수행. 인코더 개발을 LLM 파인튜닝으로부터 분리하여 범용 오디오 표현의 표준화된 평가 프로토콜을 확립. Track A(분류: 스푸핑 탐지, 감정 인식, 의도 분류, 성별 식별, 화자 수 추정, 키워드 탐지, 음향 이벤트, 화자 식별, 언어 식별)와 Track B(생성)로 구성.
- 핵심 차별점: 인코더와 LLM을 분리하여 인코더 표현의 순수 기여도를 측정하는 최초의 대규모 챌린지. LALM 생태계에서 인코더 독립 평가의 표준화를 추구.
- 실험 결과: 156개 팀(18개 국가/지역)이 참가. 9개 분류 태스크와 생성 태스크에 걸쳐 다양한 인코더의 성능을 체계적으로 벤치마킹 (상세 결과는 챌린지 페이지 참조).
- 우리 연구 관련도: ★★☆ (오디오 인코더/speech representation의 품질을 LALM 컨텍스트에서 표준화된 방식으로 평가하는 프레임워크. Speech SSL 모델의 표현 품질 평가에 직접 활용 가능하며, VQ-based representation의 다운스트림 유용성을 측정하는 벤치마크로서 참고 가치 높음)

## 이번 주 트렌드 요약 (2026-05-19 ~ 2026-05-22)

1. **Full-Duplex 대화 모델의 기능 확장**: 단순 동시 청취-발화를 넘어 실시간 도구 호출(DuplexSLA), 사용자 스트림 라우팅 전략 체계화(How Should LLMs Listen)로 진화. 대화 중 에이전틱 행동을 네이티브로 지원하는 방향이 핵심 트렌드.

2. **오디오 토크나이저의 LLM 정렬**: 코덱의 학습 목표를 재구성(reconstruction)에서 LLM 예측 가능성(predictability)으로 전환하는 연구가 부상 (LLM-Codec). 코덱-LLM 간 목표 불일치를 해소하는 것이 Speech Foundation Model의 새로운 과제로 대두.

3. **토크나이저 스케일링**: MOSS-Audio-Tokenizer(1.6B, 3M시간)에서 볼 수 있듯, 오디오 토크나이저도 LLM처럼 스케일링 법칙이 적용됨을 실증. 순수 Transformer 기반 인과적 아키텍처로의 전환이 진행 중.

4. **스트리밍 ASR의 실용화**: CTC 기반 키워드 탐지의 스트리밍 확장, 비유창성 인식 후처리 등 실배포 환경에서의 사용성을 높이는 연구가 지속.

5. **인코더 평가 표준화**: Interspeech 2026 Audio Encoder Challenge가 LALM 프론트엔드로서의 인코더 평가를 표준화하며, speech representation의 품질 측정 방법론이 생성형 모델 시대에 맞게 재정의되는 중.
