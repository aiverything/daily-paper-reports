**[Dual-Form ASR: Semantics-Aware Inverse Text Normalization for Chinese Speech Recognition] (Fengrun Zhang, Li Fu, Wangjin Zhou, Lu Fan, Youzheng Wu, Xiaodong He, 2026.09)** — IEEE SLT 2026 제출

- https://arxiv.org/abs/2609.02901
- **기존 문제**: 중국어 ASR에서 spoken-form(발화 형태) 전사와 written-form(표기 형태, ITN 적용) 전사가 각각 필요하지만, 기존 시스템은 ASR 출력을 별도의 ITN(Inverse Text Normalization) 모듈로 후처리하는 캐스케이드 방식이라 인식 오류에 취약하고 음향-문맥 정보가 정규화에 반영되지 않음
- **기존 방법**: ASR 모델이 spoken-form 전사를 먼저 생성한 뒤, 별도 ITN 모델이 숫자·단위 등을 written-form으로 변환하는 2단계 파이프라인
- **제안 방법**: Dual-Form ASR (DF-ASR) — spoken-form과 written-form의 쌍대 감독(paired supervision)을 통해 ASR 모델 자체가 두 형태를 모두 출력하도록 학습. LLM 기반 generate-and-judge 워크플로로 학습 데이터 구축. ITN-MWER 시퀀스 레벨 목적 함수로 정규화 민감 구간에 높은 비용 부여
- **핵심 차별점**: 프롬프트 수준에서 spoken/written-form 전환 가능. REQUIRE-ITN/FORBID-ITN 프로토콜로 필수 정규화 구간과 보존 구간을 분리 평가
- **실험 결과**: SpeechIO 중국어 수동 어노테이션 셋에서 오픈소스 ASR-ITN 시스템 대비 일관된 우위. 강력한 상용 시스템과도 경쟁적 성능 달성
- **우리 연구 관련도**: ★☆☆ — ASR 출력 형식 최적화에 초점으로, speech representation 학습과는 직접적 관련 낮음

**[The Trade-off Was in the Labels: Causal Supervision for Turn-Aware Streaming ASR] (Bojie Li, Noah Shi, 2026.07)** — arxiv preprint

- https://arxiv.org/abs/2609.04225
- **기존 문제**: Voice agent에서 사용자 발화 종료(end-of-turn) 감지가 핵심 과제. 발화 내 침묵(within-turn pause)이 발화 간 침묵(between-turn gap)보다 긴 경우가 빈번하여 단순 침묵 기반 감지가 불가능
- **기존 방법**: 고정 침묵 타임아웃 기반 end-of-turn 감지, 또는 별도의 VAD/endpointer 모듈 사용. 의미 완결성(semantic completeness)을 고려하지 못함
- **제안 방법**: Qwen3-ASR-0.6B 위에 소규모 LoRA 어댑터를 학습하여 전사(transcription)와 end-of-turn 감지를 동시 수행. 의미와 침묵 정보를 결합한 causal supervision 기법으로 단일 GPU에서 수 시간 내 학습 가능
- **핵심 차별점**: 최초의 오픈 학습 레시피 및 벤치마크 공개. 전사·end-of-turn 감지·받아쓰기(dictation)·문맥 기반 전사를 하나의 모델로 통합
- **실험 결과**: boundary recall 0.97, median latency 0.39초, false fire rate 0.3회/분 달성
- **우리 연구 관련도**: ★☆☆ — 스트리밍 ASR 시스템 최적화 연구로, SSL/representation 학습과는 간접적 관련

**[Automatic Speech Recognition for Multilingual Oral History Research] (Sidney Wong, Chelsea Wong She, Eda Tang, Tiana Marshall Wong, Debbie Sew Hoy, Chelsea Wong, 2026.09)** — Interspeech 2026 accepted

- https://arxiv.org/abs/2609.04232
- **기존 문제**: 구술사(oral history) 아카이브의 수동 전사는 시간과 비용이 매우 높음. 특히 코드스위칭(영어-광둥어 등)이 포함된 다국어 환경에서 ASR 도구의 효과성이 충분히 검증되지 않음
- **기존 방법**: Whisper 등 범용 ASR 모델을 사용하되, 코드스위칭 환경에서의 체계적 평가가 부족
- **제안 방법**: 뉴질랜드 광둥어 커뮤니티 구술사 컬렉션에 대해 Whisper 모델의 다양한 설정을 체계적으로 평가. 커뮤니티 주도 언어 보존 관점에서 ASR 활용 방안 제시
- **핵심 차별점**: 소수언어·코드스위칭 환경에서의 실용적 ASR 평가. 커뮤니티 기반 언어 유지 전략과 결합
- **실험 결과**: 최적 Whisper 설정에서 WER 12.10 달성. 수동 전사 대비 약 1%의 시간으로 초벌 전사 생성 가능
- **우리 연구 관련도**: ★☆☆ — 응용 중심 연구로, 기반 모델 연구와의 직접 관련성은 낮음

**[Alignment-Free Text-Audiobox for Voice Dubbing and Full-Duplex Dialogue Synthesis] (Sanyuan Chen, Min-Jae Hwang, Sho Inoue, Anna Sun, Bokai Yu, David Kant, Dongmin Hyun, Dorian Desblancs, Gregory Antonovsky, Oleg Repin, Peng-Jen Chen, Xutai Ma, Zehai Tu, Juan Pino, Wei-Ning Hsu, 2026.09)** — arxiv preprint (Meta FAIR)

- https://arxiv.org/abs/2609.03992
- **기존 문제**: 음성 더빙, full-duplex 대화 음성 생성 등 다양한 음성 합성 태스크를 통합적으로 처리하는 프레임워크 부재. 기존 시스템은 forced alignment과 명시적 duration prediction에 의존
- **기존 방법**: EnCodec 기반 이산 토큰을 사용하는 음성 합성 모델. 명시적 텍스트-음성 정렬 및 duration 예측 필요
- **제안 방법**: Text-Audiobox (Text-AB) — Diffusion Transformer + flow-matching 기반 통합 프레임워크. DAC-VAE 특징으로 48kHz 파형을 25Hz 잠재 시퀀스로 인코딩(EnCodec 대비 10배 이상 압축). 텍스트 인코더를 통한 cross-attention으로 정렬 자동 학습. 3B 파라미터 모델을 480k 시간 음성으로 사전학습
- **핵심 차별점**: 정렬 없이(alignment-free) 텍스트에서 직접 음성 생성. 교차언어 더빙, full-duplex 대화 합성, 감정 합성 3가지 다운스트림 태스크를 단일 모델로 통합. 480k 시간 규모의 대규모 사전학습
- **실험 결과**: 3B 파라미터 모델로 교차언어 더빙, full-duplex 대화 합성, 감정 합성에서 높은 품질 달성 (구체적 수치는 본문 참조)
- **우리 연구 관련도**: ★★☆ — DAC-VAE 기반 잠재 공간 표현이 VQ-based representation 연구와 관련. 고압축 음성 표현 학습 관점에서 참고 가치

**[Scalable Context Orchestration for Serving LLMs Over Voice] (Linyi Jiang, Silvery D. Fu, Yifei Zhu, 2026.09)** — ACM SOSP 2026 accepted

- https://arxiv.org/abs/2609.04288
- **기존 문제**: 음성 AI 애플리케이션에서 사용자의 발화 속도, 배경 소음, 패킷 손실 등 음성 특유의 컨텍스트가 기존 LLM 서빙 시스템에서 무시됨. 대화 컨텍스트가 단순 평면 시퀀스로 표현되어 음성 관련 정보가 암묵적으로만 처리
- **기존 방법**: 캐스케이드 아키텍처(STT→LLM→TTS) 또는 end-to-end speech-to-speech 모델. 음성 컨텍스트(발화 속도, 환경 조건)를 명시적으로 모델링하지 않음
- **제안 방법**: llmovoice — 음성 컨텍스트를 명시적으로 모델링하고 오케스트레이션하는 미들웨어. 현재 입력, 관련 상호작용 이력, 준언어적(paralinguistic)·환경 상태를 결합하여 bounded voice context 구성. LLM이 이 컨텍스트를 추론하여 시스템 응답 방식을 결정하는 런타임 디렉티브 생성
- **핵심 차별점**: 음성 서빙을 위한 시스템 수준 미들웨어로, 음성 특유의 컨텍스트를 LLM 서빙에 통합. ACM SOSP라는 최정상급 시스템 학회에 채택
- **실험 결과**: 발화 속도 정렬 오차 52.4% 감소, 패킷 손실 하 거짓 인터럽션율 46.0%→0.9%, 모델 사용 비용 79.2% 절감
- **우리 연구 관련도**: ★☆☆ — 시스템/서빙 관점의 연구로, 음성 표현 학습과는 직접 관련 낮음. 다만 음성 컨텍스트 모델링 관점에서 참고 가치

**[GEPARD: Generative, Prosody-aware, Autoregressive text-to-speech model for Realtime Dialogue] (Denis Pavlov, Ulanbek Abdurazakov, Nursultan Bakashov, 2026.07)** — arxiv preprint

- https://arxiv.org/abs/2609.04222
- **기존 문제**: 실시간 대화형 음성 합성에서 LLM 기반 TTS는 표준 LLM 서빙 엔진(vLLM 등)과의 호환성이 부족하여 별도의 추론 파이프라인 필요. 또한 자기회귀 음성 디코더의 "short register" 실패 모드(1-2 단어 수준에서의 품질 저하) 문제 존재
- **기존 방법**: 비자기회귀(non-autoregressive) TTS 또는 별도 추론 커널이 필요한 자기회귀 TTS 모델
- **제안 방법**: GEPARD — LLM 백본에서 텍스트와 오디오 임베딩을 함께 학습하는 단일 decoder-only 모델. FSQ 기반 neural codec으로 파형 디코딩. vLLM 네이티브 서빙을 위한 시스템 수준 솔루션 제공. 2-pass classifier-free guidance를 DPO로 단일 패스 가중치에 증류
- **핵심 차별점**: 표준 vLLM 엔진의 컴퓨트 커널 수정 없이 서빙 가능. "Short register" 실패 모드에 대한 진단 및 완화 기법 제시
- **실험 결과**: 단일 스트림 RTF ~0.067 (실시간 대비 약 15배 빠름). 256개 동시 스트림에서 단일 서버급 GPU로 약 204배 총 가속 달성
- **우리 연구 관련도**: ★☆☆ — TTS 서빙 최적화 연구로, speech representation 학습과는 간접적 관련. FSQ 기반 토크나이저 사용 관점에서 참고

**[Rethinking Speech Codecs: From Compression to Autoregressive Generative Modeling] (Yazheng Yang, Yao Qiu, Hui Su, Qi Liu, 2026.07)** — arxiv preprint

- https://arxiv.org/abs/2609.04237
- **기존 문제**: 기존 음성 코덱은 압축(compression) 최적화에 초점을 맞추어 설계되었으나, 언어 모델의 자기회귀(autoregressive) 학습 특성을 고려하지 않아 압축된 토큰을 모델링할 때 차선의 성능을 보임
- **기존 방법**: EnCodec, SpeechTokenizer 등 RVQ(Residual Vector Quantization) 기반 코덱. 압축 충실도(reconstruction quality) 위주로 학습되며, 토큰 시퀀스의 시간적 일관성이나 예측 가능성은 고려하지 않음
- **제안 방법**: 음성 이산화를 생성적 모델링 관점에서 재검토. 코덱 학습 시 자기회귀 호환 제약(autoregressive-compatible constraints)을 도입하여 시간적 일관성과 예측 가능성을 갖춘 토큰 시퀀스 생성 유도. 의미(semantic)와 음향(acoustic) 계층에 대한 이종 다운샘플링(heterogeneous downsampling) 전략으로 의미 토큰과 텍스트 간 정렬 개선
- **핵심 차별점**: 코덱 설계를 "압축"에서 "생성적 모델링 최적화"로 패러다임 전환. 의미-음향 계층 분리 다운샘플링으로 LLM 기반 음성 생성에 최적화
- **실험 결과**: 제안된 프레임워크가 기존 압축 중심 코덱 대비 자기회귀 음성 언어 모델링에서 향상된 성능 달성 (구체적 수치는 본문 참조)
- **우리 연구 관련도**: ★★★ — VQ 기반 음성 표현의 시간적 구조와 예측 가능성을 분석하는 관점에서 prediction-free SSL 및 temporal contrastive learning 연구와 직접적 관련. 코덱 토큰의 시간적 일관성(temporal consistency) 연구는 핵심 참고 자료

**[Compressing Streaming Neural Audio Encoders via Latent-Space Distillation] (Prasanth Yadla, Mohammad Samragh, Dongseong Hwang, Mingbin Xu, Yuanyuan Zhang, Chung-Cheng Chiu, Yongqiang Wang, Yuan Liu, Zhen Huang, Xiaodan Zhuang, 2026.09)** — arxiv preprint (Apple)

- https://arxiv.org/abs/2609.04102
- **기존 문제**: 온디바이스 음성 인식에서 audio encoder(토크나이저)가 항상 활성 상태로 DRAM을 점유하여 메모리·전력·지연 시간에 직접적 영향. 특히 희소 활성(sparse activation) 언어 모델과 동일한 메모리를 공유할 때 인코더 크기가 병목
- **기존 방법**: 이산 토큰이나 출력 분포를 기준으로 한 지식 증류(knowledge distillation). 또는 프루닝, 양자화 등 일반적 모델 압축 기법
- **제안 방법**: 양자화 전(pre-quantizer) 잠재 공간(latent space)을 증류 대상으로 사용. Teacher 인코더의 프레임별 잠재 표현을 student 인코더가 squared-error 목적 함수로 회귀. 단일 affine layer로 teacher-student 폭 불일치 흡수. 이산 토큰이 아닌 연속 잠재 표현 자체를 전이하는 방식
- **핵심 차별점**: 기존 토큰 수준 증류가 아닌 "pre-quantizer latent" 수준 증류로, 양자화 병목 이전의 풍부한 표현 정보 보존. Apple의 System-wide Dictation 온디바이스 배치에 최적화
- **실험 결과**: 인코더 파라미터를 대폭 줄이면서도 언어 모델이 소비하는 잠재 표현의 품질 유지 (구체적 압축률과 WER 수치는 본문 참조)
- **우리 연구 관련도**: ★★☆ — Pre-quantizer latent space에서의 표현 학습은 VQ-based representation 연구와 직접 관련. 양자화 전후 표현 품질 차이 분석은 speech tokenizer 설계에 시사점 제공
